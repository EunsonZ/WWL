# 场动量与多极辐射：有限例的独立计算

本实践回答两个可复算的问题：有限反射脉冲的镜面受力能否忽略控制体内场动量？电偶极总和为零的有限源是否没有辐射？主解释分别见 [[物理/30-电动力学/07-场动量与Maxwell应力#控制体里存下的动量不能省略|动量账]] 与 [[物理/30-电动力学/08-守恒源展开与多极辐射#两个有限极化球怎样留下四极辐射|双球四极]]。

## 在本目录复现

唯一计算源码是 [balance_multipoles.py](balance_multipoles.py)，Python 3 标准库即可运行，不安装库、不联网、单线程。进入本目录执行：

```bash
python3 balance_multipoles.py
```

脚本只写本目录的 [results.json](results.json)、三个 CSV 和 `assets/` 下三个 SVG；重复运行会覆盖这些可再生产物。若要保存一次实验，先复制整个实践目录再改顶部参数。CSV 保存真实物理量或明示的无量纲量，图直接使用同次计算生成的数组。SVG 英文标签与正文中文解释相互对应。

默认参数为反射场 $E_0=1000$ V/m、$T=10$ ns；辐射源 $f=100$ MHz，环半径 1 cm、环流峰值 1 A，双球半径 1 mm、间距 0.1 m、每球偶极峰值 $10^{-12}$ C·m。$c=299792458$ m/s，$\epsilon_0=8.8541878128\times10^{-12}$ F/m；$\mu_0=1/(\epsilon_0c^2)$ 保持同一近似数值体系，不同时硬编码不兼容常数。

## 反射脉冲的独立核对

解析路线先用 Maxwell 应力与边界场得到压力，再用对脉冲平方的积分原函数计算场储存。数值路线在固定薄层上以 200 子区间 Simpson 积分求瞬时场动量和能量，然后用无量纲步长 $10^{-4}$ 的中心差分求时间导数。251 个时刻覆盖脉冲进入、反射和离开；这一步没有直接把压力式代回当作数值导数。

| 输出 | 默认运行值 |
|---|---:|
| 薄层厚度 | 1.49896229 m |
| 入射能量/面积 | 9.95407023 μJ/m² |
| 镜面压力峰值 | 17.7083756 μPa |
| 镜面冲量/面积 | $6.64064086\times10^{-14}$ N·s/m² |
| 场动量无量纲积分与原函数最大差 | $1.17\times10^{-10}$ |
| 动量差分与边界收支最大差（除 $\epsilon_0E_0^2$） | $1.31\times10^{-7}$ |
| 能量差分与边界收支最大差（除 $\epsilon_0cE_0^2$） | $6.55\times10^{-8}$ |

[mirror-balance.csv](mirror-balance.csv) 中 `incoming` 是左边界动量输入，`pressure` 是镜面压力，`dPfield_dt` 是场动量变化率，均除以 $\epsilon_0E_0^2$；最后一列是储存动量除以 $\epsilon_0E_0^2T$。$t/T=-0.25$ 的反例应读到输入 0.25、镜面压力 0、场动量变化率约 0.25。

同一脚本还把均匀场的能动量矩阵做 $\Lambda T\Lambda^T$，独立用变换后的 $E',B'$ 构造能量、Poynting 与应力，16 个分量一致；$u'/u_0=2.125,S'_x/(cu_0)=-1.875$。

## 两个辐射源的全角核对

电流环的数值路线直接沿闭合环积 $\mathbf J e^{-ik\mathbf n\cdot\mathbf x'}$，每圈 128 个周期节点；之后在整个 $0\le\theta\le\pi$ 上用 240 子区间 Simpson 积分并带 $2\pi\sin\theta$ 权重。将环节点、极角区间各加倍后比较功率。双球从两球相位差及有限球形状因子得到角场，积分整个球面；四极独立路线则用 $Q=dp_0\operatorname{diag}(-2,-2,4)$ 的矩阵范数计算。

| 输出 | 默认运行值 |
|---|---:|
| 环磁偶极领先功率 | 19.0298715 μW |
| 环全源相位的远场功率 | 19.0281997 μW |
| 环功率两次网格相对差 | $1.38\times10^{-9}$ |
| 双球四极领先功率 | 0.152238972 μW |
| 双球全源相位的远场功率 | 0.152000203 μW |
| 双球功率两次网格相对差 | $6.88\times10^{-9}$ |
| 双球实际/四极领先 | 0.998431617 |
| $kd=4$、每球点状极限下的实际/四极领先 | 0.570573085 |

[multipole-angular.csv](multipole-angular.csv) 的三条曲线是 W/sr，顺序为环全相位、双球全相位、双球四极领先；绘图时各自按最大值归一。高阶形状变化因此要同时看绝对功率表，不能只看归一曲线。[quadrupole-limit.csv](quadrupole-limit.csv) 扫描 $kd$，为分离两球间距效应令每球半径趋于零，不能拿这条扫描冒充默认有限球的精确值。

零反冲检查用 $\int U\cos\theta d\Omega$，双球归一残差约 $2.5\times10^{-17}$；横向分量由轴对称性为零。这个结果只验证对称源的全角平均线动量，不验证一般角动量通量。

## 改条件后该检查什么

先在运行前预测，再编辑一份副本：将环半径减半，检验功率约为原来的 $1/16$；将双球频率加倍，固定偶极峰值时四极近似预期 64 倍，固定源电流矩峰值时需同时把 $p_0$ 减半，预期 16 倍。两次都比较保留源相位的积分结果，观察 $kd$ 增大后的偏差。源码中的固定参数断言容许小尺寸近似误差与数值误差分开，不应把所有差异都归为“程序失败”。

本机已实际执行计算、生成图并做 SVG 栅格预览。没有真实镜面、天线、场探头或人体实验；没有测得效率、馈电损耗或辐射反作用。没有执行 Obsidian 客户端显示检查，也没有真人学习结果。反射例是单位面积的理想平面脉冲；环与双球是规定源的稳态远场；无限平面脉冲、有限尺寸谐波源和有限总能量光束不能互相冒称。
