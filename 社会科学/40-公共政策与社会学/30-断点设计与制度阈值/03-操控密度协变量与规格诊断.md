# 操控、密度、协变量与规格诊断

诊断的任务是让设计更容易被推翻。“没有发现异常”只说明一种明显反例未被观测到，不证明全部潜在结果连续。

## 1. 谁能控制运行变量

应检查候选人、政党或行政机关能否精确控制最终票差；重计票、诉讼、无效票规则是否在0附近不对称；数据是否四舍五入造成堆积；无竞争选举、第三党和退出怎样编码。竞选能提高胜率不等于能精确排序；危险的是不可观测优势可把单位准确放到0的一侧。

## 2. 粗分箱密度只是一盏警示灯

按2个百分点对运行变量计数：

| 区间（点） | 个数 | 区间（点） | 个数 |
| ---: | ---: | ---: | ---: |
| [-4,-2) | 135 | [0,2) | 130 |
| [-2,0) | 101 | [2,4) | 117 |
| [-6,-4) | 109 | [4,6) | 133 |

最近两箱101与130有差异，值得正式检验；仅凭柱数既不能判定操控，也不能宣告平滑。这不是 McCrary 或 `rddensity`：箱宽手定，没有估计密度跳跃及稳健区间，也未处理离散质量点。

## 3. 处理前协变量应平滑

同样用 (h=10)、三角核、局部线性：

| 协变量 | 跳跃 | HC1标准误 | 普通95%区间 |
| --- | ---: | ---: | ---: |
| 上一次民主党得票率 | 0.60点 | 1.68点 | [-2.71, 3.90]点 |
| 上一次民主党胜选 | 0.085 | 0.061 | [-0.035, 0.205] |
| 民主党政治经验 | 0.481 | 0.333 | [-0.171, 1.132] |
| 对手政治经验 | -0.025 | 0.275 | [-0.565, 0.515] |
| 民主党参选经验 | 0.472 | 0.340 | [-0.194, 1.137] |
| 对手参选经验 | -0.032 | 0.283 | [-0.587, 0.523] |

区间都跨0，未见明确跳跃；但“不显著”可能是检验力不足，同时检查多个变量还有多重比较。若变量会被当前胜负改变，它也不再是合法的处理前诊断。

## 4. 规格压力测试

| 规格 | 跳跃（点） | 普通HC1 95%区间（点） |
| --- | ---: | ---: |
| (h=10)，局部线性 | 5.937 | [3.403, 8.471] |
| (h=10)，局部二次 | 6.359 | [3.222, 9.495] |
| (h=15)，局部二次 | 5.453 | [2.544, 8.362] |
| (h=10)，排除 $\lvert X\rvert < 1$ 点 | 3.949 | [0.135, 7.763] |

局部二次增加曲率自由度，也增加方差。donut RD丢掉理论上最有价值的临界单位，只在担心计票、编码或操控集中于极近区域时有诊断意义。排除1点内样本使估计降低，说明幅度受极临界样本影响。

## 5. 通过诊断仍可能错

未观测候选人质量在0处跳变、同阈值触发另一制度、州×选区×十年期相关性使HC1过小、结果缺失在0处跳变，或研究者看过很多规格后选择性报告，都可能通过上述有限检查。报告应同时说明样本、零点规则、带宽、阶数、核、方差、缺失和全部敏感性结果。
