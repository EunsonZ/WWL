# 图表示、并查集与动态关系：表达方式决定可支持的操作

> **学习位置**：[[计算机知识/00-开始/课程地图/06-数据结构-课程地图|数据结构课程地图]] · **适用边界**：RAM 模型为默认；均摊、期望和最坏情况分别说明。

## 同一张图可以有不同内存形状

邻接矩阵适合快速判断两点是否相邻，空间为 $\Theta(V^2)$；邻接表在稀疏图中通常占 $\Theta(V+E)$，遍历某点邻居与其度数有关。CSR 用偏移数组和连续边数组压缩邻接表，利于批量顺序扫描，但插入新边不如链式或分块结构方便。无向边常存两份，有向图要区分入边与出边，自环和重边要明确是否允许。

图算法的复杂度必须与表示匹配。BFS 在邻接表上为 $O(V+E)$，若每个点都扫描整行矩阵，则变成 $O(V^2)$。稀疏矩阵、图数据库与编译器 CFG 都在复用这种“边在哪里、怎样枚举”的设计。

## 并查集维护的是等价类

并查集提供 `find` 与 `union`，适合只增加合并关系的连通性问题。用森林表示，每个集合有代表根；按秩或大小合并避免长链，路径压缩让经过的节点更接近根。两者结合的经典均摊界涉及反 Ackermann 函数，实际增长极慢，但它不是对任意单次操作宣称绝对常数时间。

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True
```

这里省略公开输入范围检查以突出算法；在实际库中应明确下标契约。`union` 返回是否真的合并，适合维护连通分量数量。根的编号只是内部代表，不一定是最小元素或最早加入元素。

## 为什么删边不能简单反做 union

一次合并可能由多条边共同支持。删除其中一条边后，两个集合是否仍连通，需要知道其他路径；普通并查集已经丢弃这些细节。可离线反向处理只有删除的问题，或使用回滚并查集配合时间区间分治处理边的生存期。

回滚版本常保留每次修改记录，并避免普通路径压缩带来的大量隐式写入，使用按大小合并控制高度。恢复到快照时撤销记录。它与保存所有版本的持久化并查集不是同一种实现目标。

## 带势能与更高级动态树

带权并查集可保存节点到父节点的差值，从而推导同集合内两节点之间的相对量，适合差分等式、奇偶关系等。必须统一方向，例如 `potential[x] = value[x] - value[parent[x]]`，路径压缩时把沿路差值累加；符号写反会使简单合并测试通过而链式查询失败。

动态森林还可使用 Euler tour tree、link-cut tree 等结构支持连接、切断和路径查询；全动态图连通性更复杂。课程主干不要求立即实现所有结构，但应知道普通并查集不能回答哪些问题，避免拿熟悉工具硬套不适合的更新模型。

## 练习与答案

合并 0–1、1–2，再删去 1–2。普通并查集无法仅靠当前 parent 数组决定是否还有 0–2 等替代边，这就是信息丢失的反例。再实现按大小合并但不压缩路径的回滚版本，保存快照、合并、查询、回滚后与简单图 BFS 对照。记录修改次数，说明支持撤销所付出的时间与空间代价。
