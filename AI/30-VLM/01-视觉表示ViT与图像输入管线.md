# 视觉表示、ViT 与图像输入管线

视觉模型不是读取文件名或人眼看到的“原图”，而是读取经过解码、方向修正、颜色转换、缩放、裁剪和归一化后的张量。因此排查视觉错误首先应显示模型实际收到的输入。

## 输入文件如何变成 token

典型路径为文件字节 → 像素 → `[C,H,W]` → batch → 视觉特征 `[B,N,D_v]`。图像可能带 EXIF 方向、透明通道、不同颜色空间和异常尺寸；应限制解码资源并固定处理规范。预处理版本和模型权重是共同的输入合同。

![视觉 patch 到 Transformer](../90-资源/图示/vit.png)

ViT 把 patch 投影成向量并加入位置信息。位置编码告诉模型 patch 原来在哪里，不能靠任意打乱后仍宣称保留空间。对长宽不同的图，padding、切块和位置插值都可能改变实际几何。[1]

先把这个图像输入写成可检查的账本。图示的 $224\times224$ 输入按不重叠的 $16\times16$ patch 切分，图中标出 $14\times14=196$ 块。这里沿用原练习，把单视图输入改为 $448\times448$ 而保持 patch 大小不变，所以每边由 14 增至 28，共 $N=28\times28=784$ 个 patch token；单图特征 shape 可写作 $[1,784,D_v]$，批量 $B$ 张时为 $[B,784,D_v]$。这里 $H,W$ 以像素计，$N$ 是 token 个数，$D_v$ 是每个 token 的特征向量宽度；三者是不同的轴/计数。该账本不计特殊 token、压缩器或多尺度额外块。

**练习：** 一张 448×448 图用 16×16 patch 有 784 个视觉 token，四张图至少对应 3136 个 patch token，尚未计特殊 token、压缩器或多尺度额外块。注意：下页 CLIP 段的 $N$ 表示 batch 中图文配对数，与这里单张图的 patch 数 $N$ 不同。沿这份账本进入 [[AI/30-VLM/02-CLIP图文对齐连接器与VLM训练|CLIP 图文对齐]]，该页会把 $N$ 对图文写成 $N\times N$ 匹配分数表。

## 分辨率为何是信息问题，不只是性能问题

缩图使小字和小物体消失；大分辨率又增加视觉 token 和上下文成本。多尺度裁剪可提供细节与全局信息，但需要保留裁剪原点、尺度和跨块关系，否则不同裁剪之间的对象会难以关联。

视频增加时间轴。只抽少量帧可能漏掉短暂事件；增加帧率不等于解决动作和因果推断。应记录时间戳、采样策略和音画同步，区分“帧中可见”和“由语言先验补出”。

## 三类验收样例

感知测试：改变图片中的颜色、数量或相对位置，文字问题保持不变。证据依赖测试：遮挡关键区域后，模型应降低确定性或改变回答。语言先验测试：交换图片而保留诱导文字，检查回答是否仍跟着文字走。

文档理解不能只看一句流畅摘要。应分别测字符、表格单元格、阅读顺序、数值/单位、跨页引用和来源定位。小字读错之后再做“逻辑推理”，不会把失去的像素重新找回来。

## 固定四行对照把输入证据带到行动

以同一张图和同一问题为一组，保存预处理后张量、裁剪原点/尺度、版本、回答和引用区域。下表是教学测试设计；没有在本页运行真实 VLM。遮挡会改变可回答性，背景替换也可能改变真实上下文，所以要逐题确认新参考答案，不能默认四行共享一个答案。

| 输入版本 | 正确性应怎样判 | 证据区域与未知出口 | 成本与冻结项 |
| --- | --- | --- | --- |
| 原图 | 对预先确定的问题与参考答案计分；参考有争议则记录分歧 | 指出实际张量中支持答案的区域 | 权重、问题、解码/缩放/裁剪版本与预算冻结 |
| 关键区遮挡 | 原答案可能已无法确定；合理拒答可正确 | 关键证据不可见时写“不可见”，猜中也不算获得证据 | 全部输入计成本与返回率，不能只统计有答案者 |
| 无关背景替换 | 已确认不影响问题事实时，应保持答案；否则重新标注 | 核对证据仍来自目标区域，不能只由文本先验补出 | 保持输入尺寸/预算或单列成本差异 |
| 文件名或文本与图像冲突 | 文件名不应冒充视觉证据；题目若指定外部文本为依据则另定规则 | 清楚报告图文冲突及各自来源；允许暂不能裁决 | 保存实际送入模型的文字，不能假定模型接触过文件名 |

进阶到[[AI/30-VLM/03-视觉语言对齐信息瓶颈与反事实评测#为什么语言先验会伪装成视觉理解|语言先验与反事实对照]]核对这些变换的目的，回来带一组改变证据后的答案，而非仅带总准确率。若变更 EXIF、裁剪原点或 patch 大小，重新显示实际张量与对照结果；本页的 ViT patch 公式不能预测每一题的丢失程度。[1]

若图像用于控制，帧的采样时刻、到达时刻与动作生效时刻分开记录。去[[AI/10-机器学习与深度学习基础/23-从数据到评测与行动#把采样到达预测和动作放回时间|观测与行动时间表]]，带回证据年龄、状态所指时点与超时出口。视觉模型输出没有自动获得 Gaussian 分布或 Kalman 噪声独立性；只有另有依据建立状态/观测模型，才可使用相应估计器。
