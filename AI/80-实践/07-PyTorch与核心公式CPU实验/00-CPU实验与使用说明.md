# PyTorch 与核心公式：离线 CPU 实验

这个实验把张量、梯度、卷积、注意力、MLA 与生成模型的关键等式变成可运行断言。另有一个从零训练的小型 CNN。只生成合成张量，不下载数据、权重，不开启网络服务，不要求 GPU。

## 环境与运行

在已安装 PyTorch 的独立 Python 环境中，进入本页所在目录。依赖只有 PyTorch 与 Python 标准库。安装方式按 [PyTorch 官方安装页面](https://pytorch.org/get-started/locally/) 选择适合操作系统的 CPU 版本，不要照搬不匹配的 CUDA 安装命令。本轮实际环境与测试结果见 [[AI/90-资源/06-修订与验收报告]]，不把文档网站的版本号当成运行版本。

```bash
python -m unittest discover -s . -p 'test_*.py' -v
python train_cnn.py --epochs 10
```

默认 CNN 模型文件写入临时目录，结束后清理。要保留结果，可显式指定知识库以外的目录：

```bash
python train_cnn.py --epochs 10 --output /你自己的实验目录/cnn-lines
```

输出为 `metrics.json` 与本次自己生成的 `model.pt`。不要用本实验加载来历不明的 checkpoint。脚本以 `weights_only=True` 读取自己保存的权重，但这不构成对任意恶意文件的安全承诺。

## 20 个断言验证什么

`test_core.py` 包含 20 个测试方法：张量广播与视图、标量反向传播与数值梯度、模块注册、卷积互相关及形状/参数量、感受野与残差导数、在线 softmax 的分块等价性与数值稳定性、缓存偏移因果掩码、MLA 内容分支的矩阵吸收、全局 token 加权、CTC 折叠次序、扩散代数重建、配对 flow 路径，以及 logits 与交叉熵。

这些测试检查特定数学条件下的小例与实现一致，不是对所有输入、所有 dtype、所有硬件的证明。在线 attention 实现没有 padding 或因果 mask；实际缓存例另用显式掩码的 SDPA 验证。MLA 测试不包含 RoPE 分支，也没有真实模型参数。DDP 例检查归一化代数，不启动多进程通信。扩散实验使用已知噪声重建输入，不代表已经学会去噪。

阅读 [[AI/20-LLM/40-推理/06-FlashAttention在线Softmax与SDPA掩码]] 时先看测试怎样比较完整与分块结果；阅读 [[AI/20-LLM/20-架构/08-MLA低秩缓存与位置解耦]] 时先确认每个矩阵的维度，再调换计算次序。

## CNN 为什么先用横线和竖线

输入是带噪声的单通道 $16\times16$ 图像，标签为横线或竖线。训练、验证、测试分别用独立随机种子生成，样本数为 256、128、128。模型用两层卷积提取方向特征，经全局平均池化和线性层分类。训练时交叉熵直接接收 logits。

验证集只用于选择最低验证损失的 epoch；测试集只在训练与选择完成后计算一次最终指标。保存最佳参数使用深拷贝，防止后续优化悄悄覆盖“最佳模型”。再次加载后，程序逐元素检查同一输入的输出与保存前完全一致。

跑通后改变噪声强度、线宽、缺口、旋转角度或位置范围，观察分布变化的影响。原始标签只定义水平/垂直，任意角度旋转后的标签未必仍有意义。不要把近乎完美的合成测试准确率误当作真实视觉能力。

## 练习与解释要求

把目标张量从 `[B]` 改成 `[B,1]`，先预测哪里应当报错、哪里可能发生意外广播，再运行。把缓存掩码换成未经偏移的上左三角形，观察它与完整因果注意力的结果为何不同。将在线注意力的块归一化后直接平均，构造两个分数尺度不同的块，解释输出为何不再相等。

自检不是“命令返回 0”就结束：每个通过或失败的断言，都应能回到张量形状、概率归一化或数学假设上解释。
