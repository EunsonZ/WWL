## 基础与增强的关系

| 先认识的基础 | 再尝试的插件 | 插件增加了什么 |
| --- | --- | --- |
| 普通 Markdown | Linter | 按规则统一格式；它不会替你判断内容是否正确 |
| 原生表格编辑 | Advanced Tables | 键盘导航、行列操作、排序与公式 |
| MathJax 数学语法 | LaTeX Suite | snippets 和展开能力；公式仍是普通 LaTeX 文本 |
| `- [ ]` checkbox | Tasks | 日期、重复规则和跨文件查询 |
| Properties、Bases | Dataview | DQL 聚合、筛选、排序和计算视图 |
| Core Templates | Templater | 动态变量与高级模板逻辑 |
| 命令面板与模板 | QuickAdd | Capture、Template、Macro 和组合入口 |

> [!warning] 安全边界
> - 不运行来源不明的 Templater、QuickAdd、DataviewJS 或 Excalidraw 脚本。
> - 本实验只使用 Dataview DQL，不包含 `dataviewjs`。
> - 不打开外部 AI、Calendar、webhook、REST API 或 MCP。
> - Linter 只对故意准备的实验页执行“Lint the current file”，不要使用全库命令。

## TaskNotes 的另一种任务模型

Tasks 把任务保存在 checkbox 行里；TaskNotes 则把每项任务保存为一则带 Properties 的 Markdown 笔记。四个静态样例位于 `Obsidian知识/30-实践/04-TaskNotes/Tasks/`，可在 [[Obsidian知识/30-实践/04-TaskNotes/Start Here|TaskNotes 静态教学 Start Here]] 中阅读。该页不加载真实任务或默认 Bases。
