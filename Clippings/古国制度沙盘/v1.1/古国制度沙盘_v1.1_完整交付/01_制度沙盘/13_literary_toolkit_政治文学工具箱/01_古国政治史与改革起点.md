# 古国政治史与改革起点

## 使用边界

本篇是政治文学的虚构史，不是现实史、现实制度说明或改革已经生效的证明。共历七十六年是沙盘基期；本工具箱所引 GG-RGT、GG-GOV、GG-OPN、GG-ECO、GG-CIV、GG-JUS、GG-LAB、GG-WEL、GG-DAT、GG-SEC 与 GG-TRN 文件，在基期均应依其 status 与 effective_phase 阅读。叙事若让某一提案进入试验或生效，必须在该分支明写授权、地点、期限、预算与退出条件，不能由旁白一句“改革开始了”跨过闸门。

## 一、从合地到共历：一部完全虚构的政治时间轴

| 时段 | 虚构时期与公共选择 | 当时解决的问题 | 留下的制度性代价 |
|---|---|---|---|
| 共历前十二年至共历元年 | 三次河道改向和两季歉收使分散城镇缔结“合地约”。各地同意共同维护干渠、粮路和渡口，以圭作为结算单位；共历从最后一段共护堤完工之年起算。 | 降低跨地征粮、修堤和通行的冲突，建立共同计量。 | 紧急协调形成的临时合署被保留下来，权限、账目和地方负担没有同时写清。 |
| 共历一至十二年 | “九仓期”。公共仓、驿路和基础学舍迅速铺开，资源按地区配额集中调运。 | 饥荒与交通隔绝明显下降，最偏远聚落第一次进入稳定交换网。 | 配额以登记人口和可通行道路计算，流动家庭、山坳聚落及无登记劳动常被漏掉。 |
| 共历十三至二十七年 | “炉带期”。河铸、照川等地形成制造带，公共企业承担输能、轨基、粮储和关键材料。地方用未来工业收益预付道路、住居与厂区。 | 就业、城市供给和技术训练扩张，跨域市场成形。 | 所有者、监管者、采购者和运营者经常在同一会议上作决定；维护、退出和污染尾部被推到以后。 |
| 共历二十八至四十年 | “迁潮期”。人口向港湾和制造带移动，原居地账户、学校名额、医疗结算和住居资格跟不上迁移。 | 劳动力和服务网连接加快，家庭收入上升。 | 常住事实被单一证件替代；强衡域先有服务再有账，弱衡域先接任务后等拨付，互不信任由此累积。 |
| 共历四十一至五十三年 | “高架期”。轨路、输能、算力与新住区同时建设。项目按开工速度考核，资本支出显眼，维护和照护却分散在家庭与基层。 | 城际通达、供电与通信显著改善。 | 项目拆分、长期租金和替换成本难以合并；征收补偿常晚于不可逆搬迁，家庭无偿照护成为隐性财政。 |
| 共历五十四至六十三年 | “联册期”。公共服务逐步数字化，跨域数据能快速匹配，平台企业进入物流、用工、学育与支付。 | 办事时间缩短，远地居民可接触更多服务。 | 账号、风险分和历史标签开始替代人工判断；一次错误能跨资格、诊疗、就业和边境传播，线下入口逐渐空心化。 |
| 共历六十四至六十九年 | “缓护期”。人口老化、照护缺口、能源转型和旧设施维修同时出现。若干衡域用短约、志愿班和专项券填补缺口。 | 延缓了服务骤降，也让新技术试点得以继续。 | 券、名册、派班与实际到人混在同一成功率；亲属补班、危险复工和供应商垫资被当成公共能力。 |
| 共历七十至七十三年 | “三断期”。先后出现一场跨域停电、一次支付与通信同日离线、一次药材供应收端断裂。各机关都能拿出已签指令，却无法证明物资、治疗或资金实际到人。 | 社会认识到单一中心和程序文书的脆弱性。 | 机关为了避免被追责，倾向换案号、换理由码和转介；居民则把每次核验理解为拖延，基层执行者不再相信上级承诺的资源。 |
| 共历七十四至七十五年 | “复算争议”。独立统计抽样发现，部分服务到达率把拒绝、预约、派车、出库与付款指令计作成功；若干长期项目没有统一的维护、补偿与退出账。 | 公共争论从“是否要改革”转向“什么证据才算发生”。 | 既得资源持有者担心透明会抹去安全和专业判断；受损者担心新的审计只增加表格，不增加救济。 |
| 共历七十六年 | “改革起点”。各卷提案同时摆上桌面，但全局一百三十九个根成本仍为估算，项目子账为零，真实班次、床车仓、临床口译与稳定财源均未核。 | 形成以权利底线、分权、公开、实体结果和可撤回试点为核心的共同语言。 | 最大风险是把共同语言误当成已经有钱、有人和有项目；第二风险是因证据未齐而冻结一切可逆保护。 |

## 二、共历七十六年的改革起点

改革不是从一张空白纸开始。古国已有广泛的供电、交通、医疗、学育、给付和产业网络，也有能够执行复杂任务的专业人员。问题在于三种账相互错位：法定责任账说“谁应负责”，财政账说“是否有钱”，服务账说“个人是否实际获得结果”。过去常用第一种账替代后两种；新提案要求三账都能由不同主体复核。

基期的财政约束同样是剧情事实，而不是背景装饰。第三年高位暂算为一万五千一百四十亿圭；若对全部 C／D 级参数加百分之二十缓冲，则为一万八千一百六十八亿圭，超过一万七千九百二十亿圭名义线二百四十八亿圭。百分之二十五缓冲则超过一千零五亿圭。这个缺口不能靠角色突然找到“闲钱”解决，也不能用削去权利底线来平账；它只能通过分期、缩小可逆试点、升级证据，或后来形成可核稳定抵补。对应锚点为 GG-TRN-002、GG-TRN-003 与 GG-TRN-007。

## 三、五个持续推动文学冲突的政治结

1. **速度与可复核性。** 两小时规则要求资金可取、治疗开始、人员到场、实际入住或侵害停止，而不是签出工单；可复核拒绝又不能被描写成无情。GG-TRN-008 与 GG-TRN-009 使“诚实地承认做不到”成为一种政治行动。
2. **统一权利与不均能力。** 四十六衡域共享最低权利，却分属九个甲层、十八个乙层、十三个丙层和六个丁层。GG-GOV-008、GG-GOV-009、GG-ECO-004 与 GG-TRN-007 让跨域互助有规则，也暴露谁承担普通服务被挤出的成本。
3. **专业判断与角色分离。** 临床者、调度者、调查者和分析者需要裁量；付款者、监管者和秘密授权者又不能借专业名义决定一切。角色分离若没有真实替班，会从反滥权设计变成空椅子政治。
4. **公开与必要秘密。** GG-OPN-009、GG-JUS-017 与 GG-SEC-004 不要求把脆弱端点公开，却要求期限、授权、受益控制、届期停止和外部复核可证。冲突不在“公开者善、保密者恶”，而在谁能证明隐匿范围确实必要。
5. **当代补偿与未来损害。** GG-RGT-012、GG-DAT-009、GG-DAT-010 与 GG-DAT-012 要求把就业、污染、退出和未来世代并置。零或低折现情景不能自动否决今日的急迫服务，也不能被高折现率静默抹掉。

## 四、改革的法定顺序与叙事纪律

GG-TRN-001 给出共同顺序：先保权利与救济，再锁事实与公开接口，再建立独立复核和付款链，最后才做组织重构或不可逆资产行动。GG-TRN-004 要求依赖失败时保留原号、纸路和最短时钟；GG-TRN-005 要求在搬迁、停业等不可逆节点前预付五类损失；GG-TRN-006 要求同一试点保留未改革、局部改革、改革失败和目标达成四条路径；GG-TRN-010 要求同时记录信任、生活时间、分配公平和公共能力，不能用一个指数覆盖少数意见。

因此，任何故事都应把“提案”“经授权试点”“已生效规则”和“实际兑现”分开。人物可以真诚地误判，可以因职责不同产生冲突，也可以在信息不足时选择暂停；但他们不能凭作者恩赐获得未登记预算、凭一纸命令创造床位，也不能靠一个突然出现的坏人解释长期结构性失败。

## 五、可供作品选择的开场镜头

- 共历七十六年寒潮夜，霁湾的调度屏显示恢复，雪坳的一台生命设备却仍无电；屏幕与插座谁更接近国家的事实？
- 眠沙来的患者在照川医院同时拥有一张有效纸证和一个错误风险分；哪一个岗位有权先做什么？
- 河铸的旧厂若继续生产会增加伤害，若立刻搬迁又没有项目全包行和预付补偿；“等待”对不同人物意味着什么？
- 微湾的预警模型在断网中捕捉到真实风险，雾岭的秘密授权却已届期；停止查询、继续警示和保留证据能否同时发生？

这些镜头不是答案。它们只是把同一制度冲突放到不同身体、地区和时钟上，让读者看见规则如何在资源稀缺时改变人的关系。
