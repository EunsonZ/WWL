# 有限环境退相干复算

先预测：同一系统+x分别接纯+x浴和$I/2$浴，哪些局部曲线会完全相同？L变小时系统能量会不会变？在有理耦合给定的时间重新聚相，又恢复了哪份态？从 [[物理/40-量子力学/18-有限环境与约化态退相干#条件演化怎样把相干变为环境重叠|主解释的条件演化与偏迹]] 进入，写下自己的预测，再运行此处同一张有限卡。

本实践定义整个 $2^{N+1}$ 维封闭系统，初态为系统与各浴自旋的乘积密度矩阵。时间曲线用精确因子公式，不含时间积分、环境重置、拟合率或随机抽样；五个完整矩阵检查点用另一条同模型有限谱路线。它们分别支持解析公式实现与浮点核算，独立验收还要从原H/不同算法核模型，而非只确认程序自比一致。

## 输入、基顺序和可比较的对象

[inputs.json](inputs.json) 是固定卡，[finite_decoherence.py](finite_decoherence.py) 是代码真源；阅读 [[物理/80-实践/40-有限环境退相干/SOURCE|完整源码镜像]] 可逐行对照。所有计算采用Dirac第二位置线性，系统因子最慢，浴最后一因子最快。$Z=\mathrm{diag}(1,-1)$，$Y_{01}=-i$，初态Bloch向量 $(s_x,s_y,s_z)$ 给 $\rho_{S,01}=(s_x-is_y)/2$。

输入严格要求以下字段，不忽略拼错或额外字段：

| 字段 | 单位、形状和允许范围 | 改变它回答什么 |
| --- | --- | --- |
| `units` | 精确为 `time: us`、`angular_frequency: rad/us`、`energy: J` | 防止频率制/时间制混用 |
| `samples`, `t_max` | 整数21–1001；$0<t_{max}\le1000$ μs | 均匀显示采样和观察时长；没有时间步进误差 |
| `dephasing_cases` | 1–12卡；每卡唯一ASCII `name`，1–40字符 | 在同一时间网格比较制备/耦合 |
| `omega_s` | 有限实数、绝对值≤100 rad/μs | 系统自由相位及裸能量；允许负号但能级标签随H判断 |
| `g`, `omega_bath` | N=1–6个有限实数，绝对值≤100 rad/μs；两列表等长 | 纵向耦合及自由浴频率，后者在本对易模型L中消去 |
| `system_bloch` | 三实数、$|\mathbf s|\le1$ | 相干相位、布居与初态纯混 |
| `bath_bloch` | N行×3列、每行$|\mathbf r_k|\le1$ | 同z不同纯度的浴；脚本不输入初始浴间相关 |
| `exchange` | `omega`正、≤100；`kappa`非零、绝对值≤100 rad/μs | 另一个共振单浴H，初态固定$|01\rangle$，对照能量交换 |

零耦合g合法，负g合法；`exchange.kappa=0`被拒，因为本卡的用途是交换反例。Bloch平方范数检查允许$10^{-12}$浮点端点容差，输入不被自动重新归一；远离物理球的态拒绝。JSON重复键、NaN/Infinity、bool冒充数值、长度错、非法单位与非有限参数均在生成前拒绝。所有资源上限限制实现负载，不是一般自旋浴理论边界，也不保证任意图域都有足够显示分辨率。

- `exchange.csv`：同一时间网格的单浴交换$\rho_{00},\rho_{11}$、零相干、局部纯度、系统与浴J能量。

- `coherence.svg`：按当前g与浴z值去重的$|L|$，以及第一卡的x/y概率。图例/参数动态读取输入。
- `correlations.svg`：前两卡全局纯度及第一卡局部熵，再对照第三/第四卡的相干模；若卡数不足则用实际可用卡。默认安排前两卡局部完全相同，图中没有给混态曲线套“纠缠熵”标签。
- `energy.svg`：选择当前卡中非零裸能量模最大的系统，与共振交换比较布居和能量。图纵轴能量除以$10^6\hbar$，单位rad/μs，CSV保留J。选择卡仅改变显示，不改计算数据。

CSV使用标准CRLF，源码/笔记用LF。SVG保留title/desc、坐标单位、线型与文字图例，无插值平滑或指数拟合。图与CSV读取同一数组；局部熵函数只将浮点端点本征值限制在[0,1]再算$0\log0$，没有裁剪L、Born概率或能量来隐藏错误。图使用默认英语坐标文字以减少字体依赖，正文给出中文物理解释。

## 默认卡的手算检查点

默认T=$4\pi$ μs、401点，$g=(0.5,1,1.5,2)$ rad/μs，$\omega_s=1.3$ rad/μs，浴自由频率为$(0.37,0.63,0.89,1.11)$。第一零点$\pi/4$与复现$2\pi$恰落在网格上。五个完整矩阵检查点是$0,T/16,T/4,T/2,T$；这不是用五点证明全部时间正确。

## 自检和独立复核的边界

`results.json`里的全谱/偏迹对比是源码内部另一条同模型路线，不能代替非作者核查。独立复算可从原$D\times D$H构造$U\rho_0U^\dagger$、逐索引偏迹，全部时间点比CSV；也可枚举$2^N$浴z配置计算特征函数，见 [[物理/80-实践/40-有限环境退相干/ANSWERS#不调用乘积公式的一条手算与数值接口|展开配置接口]]。混对角浴的可分性由显式非负分解证明，negativity数值零只是相符；一般混态零值不是充分可分判据。脚本未把小负特征值抹成零，因此可分卡可能报告$10^{-16}$量级positivity噪声；认定纠缠应要求信号超过独立核算的浮点残差，而非只判程序输出大于零。

解释时分别记录：模型定义/推导、浮点矩阵残差、改变输入的实际运行、同源图和显示、真实谱/硬件与学习结果。本实践提供输入和复算，程序本身没有测材料环境谱、实验T₁/T₂、芯片、Obsidian同步或真人理解；有限静态bath的相关函数不衰减，也没有建成Markov极限。

## 改条件后撤去提示

复制输入先做两个迁移：一份把全部g减半，另一份只改浴横向成分而保留各z。写出对L与x/y曲线的不同预测，再从同源CSV比较；不要改成另一份H却继续用原答案。也可把系统改为$I/2$或z本征态，说明为什么L本身可变化，系统却没有横向相干可被削弱。

再尝试把其中一个浴自由频率改为7 rad/μs。在本H中局部L严格不变，联合态/条件浴分支可以改变；这条不变性来自$[H_E,B]=0$，不能带去有横向场的浴。当前脚本未实现横向浴场或关联浴，若提出那个迁移，只能回到条件U±手算或明确扩展H，不能冒称已运行。
