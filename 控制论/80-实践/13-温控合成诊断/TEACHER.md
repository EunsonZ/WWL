# 教师入口：同一记录与不同真实世界

先发 [学生入口](README.md) 和 [data/student](data/student/README.md)，待学生提交预测与证据账后再开放本页、[真值参数](input.json)、[教师数据](data/teacher/summary.json) 与 [源码](thermal_diagnosis.py)。源码是数据真源，[代码镜像](code-sync/thermal_diagnosis.md) 供普通 Markdown 阅读；[单元测试](test_thermal_diagnosis.py) 和 [测试镜像](code-sync/test_thermal_diagnosis.md) 只提供作者自查，独立核查由未参与作者工作的人另做。本页的答案不声称学生实际已经理解。

“回执全绿，物体达标”把接收层的工作调成了温度计的全职岗位。精确说，`status=ok` 只承诺命令接收；本数据的实际功率来自模型的执行端，真实温差来自模型真值。真实设备仍须各自的仪表与时序证据。

## 模型、初态与五个世界

这里 x 是**相对恒定环境的温差**，不同于实践 01 的工作点功率偏差约定；u 是本项目直接施加的加热功率，基准范围 0–10 W，不再另加 10 W。连续模型与采样保持为

$$C\dot x=-hx+u+d,\quad y=x+\beta,\qquad
x_{k+1}=a x_k+b(v_k+d),\quad a=e^{-hT_s/C},\quad b=(1-a)/h.$$

C=10 J/K，h=1 W/K，Ts=1 s，r=2 K，kp=3 W/K，ki=0.4 W/(K·s)。x、y、β、r 单位 K；u、v、d 单位 W；z 单位 K·s；a 无量纲、b 单位 K/W。d 是常值净热扰动，正号增加热量；β 是加性读数偏置。没有随机噪声、抖动或量化物理过程；CSV 的十进制序列化误差用 10⁻⁹ K 容差比较，不能把它叫测量精度。

原始命令、限幅命令、实际功率分别记为

$$u_k=hr+k_p(r-y_k)+k_i z_k,\quad
\ell_k=\min(u_{max},\max(u_{min},u_k)),\quad
z_{k+1}=z_k+T_s(r-y_k).$$

无延迟时 vₖ=ℓₖ；恰一拍延迟时 vₖ=ℓₖ₋₁，必须另给 **ℓ₋₁=0 W**。读数与命令在 kTs 记录，功率在 [kTs,(k+1)Ts) 保持，下一读数位于 (k+1)Ts。本拍始终用旧 zₖ；生成器先计算命令再计算下一状态。日志 `u_cmd_W` 对应 uₖ，`u_applied_W` 对应 vₖ；教师的 `u_limited_W` 对应 ℓₖ。没有把延迟放进采样时间戳来伪装即时执行。

| 中性编号 | 教师解释 | β / K | d / W | x₀ / K | z₀ / (K·s) | 功率范围 / W | 延迟与旧命令 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| case-01 | 健康阳性对照 | 0 | 0 | 0 | 0 | [0,10] | 0 拍；旧命令不使用 |
| case-02 | B：读数高报 | 0.2 | 0 | −0.2 | 0 | [0,10] | 0 拍；旧命令不使用 |
| case-03 | C：恒定净热输入 | 0 | 0.2 | 0 | 0 | [0,10] | 0 拍；旧命令不使用 |
| case-04 | 功率不足饱和 | 0 | 0 | 0 | 0 | [0,1.5] | 0 拍；旧命令不使用 |
| case-05 | 恰好一拍执行延迟 | 0 | 0 | 0 | 0 | [0,10] | 1 拍；ℓ₋₁=0 W |

五份的 y₀ 都为 0 K。学生表没有真实初态或原因参数；教师入口公开这些信息，是为了论证与复算，不能冒充学生在第一阶段已经知道它们。输入文件中的 `meaning` 不参与模拟，也不会流入学生目录。case-04 是不同的执行能力，不通过换目标或偷偷改变热模型制造失败。

## 为什么 B/C 任何同历史确定性控制都分不出

β 为常值，所以 dy/dt=dx/dt。代入 x=y−β：

$$C\dot y=-hy+u+\theta,\qquad \theta=h\beta+d.$$

θ 单位 W。区间保持后同样有

$$y_{k+1}=a y_k+b(v_k+\theta).$$

因为 (1−a)β=b hβ，离散式与原 ODE 一致。B 中 θ=1 W/K×0.2 K=0.2 W；C 中 θ=0.2 W。二者 y₀=0，z₀=0，相同执行范围、时序与控制代码，故第零拍命令相同。假设到第 k 拍观测历史相同，确定性控制器给出相同新命令；相同执行映射又给相同 vₖ，观测递推于是给相同 yₖ₊₁。归纳得全部学生观测相同；这并不限于本例 PI，也不限于增加几阶拟合。若另有控制器内部初态或随机种子，比较时也必须相同，不能从“只依赖同一历史”漏掉它们。

然而 xᴮₖ=yₖ−0.2 K，xᶜₖ=yₖ，所以任意时刻 xᶜ−xᴮ=0.2 K。生成器从原 x 的保持解演化，两份 CSV 在本次固定参数与 12 位有效数字序列化下逐字相同；内部浮点轨迹按 10⁻¹² K 容差核对，数学等价由上面的归纳证明承担。

更一般地，对任意常数 c（单位 K），β′=β+c、d′=d−hc、x₀′=x₀−c 保持 y₀ 与 θ 不变。一个通道只能约束组合 θ，不能在这族世界中唯一选 β 和 d。重复原通道、延长记录或更复杂的拟合不破坏这个变换；改变由相同历史决定的命令也不能破坏它。若加入已知独立真实初态，就能由 β=y₀−x₀ 打破等价，但这已经新增了信息。

## 第二参考为何有效，误差怎样进入结论

在同一时刻新增独立校准参考 q=x+ε，声明 |ε|≤0.02 K，且同一环境基准与对时误差已包含在界内。对任意同一 y：

- B 预测 q∈[y−0.22,y−0.18] K；
- C 预测 q∈[y−0.02,y+0.02] K。

两区间最近间距 0.16 K，故不相交；一次有效参考即可区分**这两个指定世界**。若 β 或 d 还有其他可能，区分这两个候选不等于定位所有未知真实故障。若两个参考误差界分别为 eᴮ/eᶜ，不重叠需要 eᴮ+eᶜ<0.2 K；本题 0.04<0.2。界本身的可靠性、环境基准与同点/同时测量是新增假设，不能由原通道重复读取自我认证。

[reference-release.csv](data/teacher/reference-release.csv) 是第二阶段可发的**合成**新观测：在 150 s，case-02 取 q=x+0.01 K，case-03 取 q=x−0.01 K，均满足 ±0.02 K 界。约为 1.81 K 与 1.99 K；由每个 q 反推的物体温差区间分别约 [1.79,1.83] 与 [1.97,2.01] K。前者明确不达目标带，后者在该时刻可以认证 ±0.05 K。它们仍未提供 140–150 s 全部十一点的独立参考；不能因此填写完整有限窗口的物理验收通过。

## 各案判断与延迟的稳定责任

| 案例 | 从模型可以得出的判断 | 学生现有日志独自能说到哪里 |
| --- | --- | --- |
| 健康 | u*=hr=2 W 可实现；固定 CPU 轨迹 150 s 接近 x=y=2 K，是阳性对照 | 读数带通过，接收与施加对应；真实无偏是教师新增前提 |
| B | 稳定可实现时 y*=2 K，而 x*=1.8 K，真实目标偏低 0.2 K | 与 C 的日志相同，不能唯一定位 |
| C | 稳定平衡 x*=y*=2 K，u*=hr−d=1.8 W | 与 B 的日志相同，不能唯一定位 |
| 功率不足 | 目标需 u*=hr−d=2 W>1.5 W；从 x₀=0、v≤1.5 有 xₖ≤1.5(1−aᵏ)<1.5 K | 读数未达标，实际功率长期在 1.5 W；结合给定模型/无额外热输入假设才能证明目标不可达 |
| 一拍延迟 | 本组参数收敛；首拍 v₀=0，次拍 v₁=8 W，不把“延迟”自动判为“失稳” | 能识别本记录的错拍关系；有限曲线不能单独证明一般稳定 |

功率不足案在无偏无扰动模型下，每拍误差大于 0.5 K，所以 z₁₅₀>75 K·s；没有 anti-windup，积分持续积累。它不能把 1.5 W 的能力变成目标所需 2 W；即使图像有界，目标也不可达。健康的名义数字 PI 稳定判据回 [[控制论/10-系统课程/03-采样保持积分调节与实现边界#数字积分用旧状态，另外证明稳定|03]]，不要重复把有限轨迹当全时证明。

延迟案需要自己的完整 PI 增广状态，不能照搬 03 的“延迟比例”二阶极点。令 q=x−r、ζ=z、w=上一拍限幅前命令−hr。在无偏无扰动、限幅未激活的邻域内：

$$\begin{bmatrix}q_{k+1}\\\zeta_{k+1}\\w_{k+1}\end{bmatrix}
=\begin{bmatrix}a&0&b\\-T_s&1&0\\-k_p&k_i&0\end{bmatrix}
\begin{bmatrix}q_k\\\zeta_k\\w_k\end{bmatrix}.$$

矩阵块各带对应单位；第一状态 K、第二 K·s、第三 W。特征多项式为

$$p(\lambda)=\lambda^3-(1+a)\lambda^2+(a+bk_p)\lambda+b(k_iT_s-k_p).$$

本例系数约为 [1,−1.904837418,1.190325164,−0.247422713]。可用实 Schur 递减核：记后三项为 A、B、D，先核 |D|<1，再核二次多项式

$$\lambda^2+\frac{A-DB}{1-D^2}\lambda+\frac{B-DA}{1-D^2}.$$

它的系数约 [1,−1.715333203,0.765912769]；二次 Schur 三项 1+B₂+D₂、1−B₂+D₂、1−D₂ 分别约 0.050579566、3.481245972、0.234087231，全正，所以未限幅增广线性闭环的全部根在单位圆内。数值根约 0.829029146 与 0.537904136±0.095435273i。这个检查只保证指定线性邻域；固定 150 拍运行还核 v 的范围，不能推广成所有初态/限幅非线性闭环的全局稳定证明。

## 预测题与迁移题的判分依据

第一拍即时案 u₀=2+3×2+0=8 W，z₁=2 K·s；健康 x₁=y₁=8(1−e⁻⁰·¹)=0.761300656 K。延迟案同一 u₀ 仍被接收，但 v₀=0 W、x₁=y₁=0，下一拍用 z₁ 算出 u₁=8.8 W，同时施加旧的 8 W。若答成第一拍 8.8 W，已把新积分状态提前使用；若答成第一拍温度上升 0.7613 K，已把延迟命令提前执行。

读数验收：case-01/02/03/05 在固定窗口都通过，case-04 未通过。教师真值中的 case-02 不通过物体目标，case-01/03/05 通过本合成窗口；学生不能只凭第一阶段记录区分 02/03 的物理结论。收敛的案名或图像形状不能代替测量可信性，命令成功也不能代替功率预算。

[迁移输入](input-transfer.json) 把 C、h、kp、ki 与全部功率输入/能力加倍。h/C、kp/h、ki/h 不变；a 不变、b 减半，功率与 d 加倍，所以 b(v+d)、观测递推、z 的更新均不变。x/y/z 轨迹逐值相同，命令与实际功率逐值加倍；θ 从 0.2 W 变成 0.4 W，B/C 仍等价。不能把 b 仍写成 0.095162582 K/W；新 b=0.047581291 K/W。可接受手算、合法系数证明或独立实现，测试文件不是唯一答案形式。

## 本地复算与输出边界

只需 Python 3 标准库。生成器不联网、不安装包、不写设备；必须显式指定绝对库外输出目录，目录即使已存在但为空也拒绝覆盖。学生入口不要求先运行教师源码。以下从 Vault 根执行；每次改用一个不存在的输出目录：

```bash
python3 -B '控制论/80-实践/13-温控合成诊断/thermal_diagnosis.py' \
  --output-dir '/private/tmp/wwl-temperature-default-new'
python3 -B '控制论/80-实践/13-温控合成诊断/thermal_diagnosis.py' \
  --input '控制论/80-实践/13-温控合成诊断/input-transfer.json' \
  --output-dir '/private/tmp/wwl-temperature-transfer-new'
```

再原样执行第一条，预期退出码 2，已有内容不变。从实践目录运行作者自查：

```bash
python3 -B -m unittest -v test_thermal_diagnosis.py
```
