# 张量、shape、广播与批处理

<!-- deep-review-02 -->
> [!tip] 本轮深化：从当前概念继续追问
> 广播只保证形状可计算，不保证语义正确。把时间轴误当 batch 轴或把 padding 当有效标签，都可能不报错却改变目标。 深化与验证：[[AI/00-开始/06-统一符号形状与公式阅读方法|统一符号形状与公式阅读方法]]；[[AI/12-PyTorch/05-变长批处理Packing与有效Token归一化|变长批处理Packing与有效Token归一化]]。


## 目标与适用场景

读懂深度学习代码里最常见的 shape 不匹配错误。每次看张量都要写出每一轴的语义，而不只是背数字。

## 直觉

张量是多维数组，shape 是各轴长度。shape 为 (32,3,224,224) 还不够，必须补上轴语义，例如 [batch, channel, height, width]。

- 标量：shape 为 ()，一个数。
- 向量：shape 为 [D]，一个样本的 D 个特征。
- 矩阵：shape 为 [B,D]，B 个样本组成的批次。

本页两个容易首次遇到的词：**广播**是让长度为 1 的轴在运算中与较长轴逐项对齐的规则；**logits**是模型给每个类别的原始分数，尚未归一化为概率。

线性代数定义与推导在 [[数学/20-线性代数与几何/00-线性代数与几何-MOC|线性代数与几何]]；本页只解释代码轴代表谁。

## 精确定义

若输入 x 是 [B,D]，权重 W 是 [D,C]，偏置 b 是 [C]：

$$
z=xW+b,\quad[B,D][D,C]\rightarrow[B,C]
$$

广播从末尾轴比较：相同或其中一个为 1 才可对齐。[B,C] 加 [C] 可以，因为后者可看作 [1,C]；[B,C] 加 [B] 通常不行，因为最后一轴不匹配。概念上扩展不表示实现一定复制内存。

## 最小可运行例

脚本在 CPU 上演示每一行加同一个三元素偏置，不下载模型或数据。没有 PyTorch 时会输出 `SKIP:` 并以状态码 77 退出；这表示环境缺少可选依赖，不是测试通过。只有断言全部成立并以状态码 0 退出才记为 passed。

<!-- code-sync: ./03_张量形状广播与批处理.py -->
~~~python
from __future__ import annotations

try:
    import torch
except ModuleNotFoundError:
    print("SKIP: 需要已安装的 CPU PyTorch 才能运行本示例；未下载任何依赖。")
    raise SystemExit(77)

features = torch.arange(6, dtype=torch.float32).reshape(2, 3)
bias = torch.tensor([10.0, 20.0, 30.0])
shifted = features + bias

print("features:", tuple(features.shape), features.tolist())
print("bias:", tuple(bias.shape), bias.tolist())
print("shifted:", tuple(shifted.shape), shifted.tolist())
assert shifted.tolist() == [[10.0, 21.0, 32.0], [13.0, 24.0, 35.0]]
print("广播检查通过：偏置按特征轴对齐。")
~~~

## shape 合同

| 对象 | 常见分类任务 shape | 必问问题 |
| --- | --- | --- |
| 输入 | [B,D] 或 [B,C,H,W] | 第一轴真的是 batch 吗？ |
| logits（每类原始分数） | [B,K] | K 等于类别数吗？ |
| 整数标签 | [B] | 每样本是否只有一类？ |
| one-hot 标签（正确类为 1，其余类为 0） | [B,K] | 损失函数真的要求它吗？ |

不要为了消除报错随手删轴或重排。先写出变换前后每一轴是谁；长度为 1 的 batch 在随意压缩后可能不再有 batch 轴。

## 练习

1. 图像批次为 [8,3,32,32]，每通道均值为 [3]。写出它可广播到图像的 shape。
2. 二分类输出为 [16,1]，标签为 [16]。先查损失函数目标合同，再决定调整哪一端。
3. 把脚本 bias 改成两个元素，解释错误。

## 成功标准

- 能写出数字 shape 与每轴语义。
- 能解释 [B,C] 加 [C] 为什么成立。
- 能说明批处理不改变单样本任务，只是并行处理。
- 能写出第 1 题的 `[1,3,1,1]`，并说明四根轴分别与 batch、channel、height、width 怎样对齐。
- 运行证据明确记录为 `passed (exit 0)` 或 `skipped (exit 77)`，不把缺少 PyTorch 的 skip 写成“检查通过”。
