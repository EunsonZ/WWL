# 两模态热反演：复算与改变一个条件

理论与同一数据的完整推导在 [[信号与系统/50-通信与反演/02-前向算子反卷积与正则化重建|反演主课]]；本实践将它们变成可改输入和真实文件输出。温度偏差、时间、位置先按主课无量纲化，绝热边界只保留归一常数／余弦两个模态。全部矩阵结果用标准库 `fractions.Fraction` 精确计算；SVG 曲线采样和坐标位置才用浮点数。不需要神经模型、训练或第三方数值库。

## 输入、源码和输出

[inputs.json](inputs.json) 是固定输入；[thermal_inverse.py](thermal_inverse.py) 是唯一数值与绘图真源；[[信号与系统/80-实践/10-两模态热反演/04-源码与验证|全文镜像]]供阅读。默认的 `decay_denominator=100` 声明 $T=\ln100$，源码取 $A=\operatorname{diag}(1,1/100)$，其来源是主课的 PDE 模态关系；这段程序不是有限差分 PDE 求解器。把该整数改10便声明 $T=\ln10$，同时更改前向衰减，不能还称原来的 $A$。

每个向量有两个坐标，索引0为常数、索引1为第一余弦。真值、观测、方差、$\lambda$、$D/S$ 的有理数字面量必须是 JSON 字符串（如 `"1/10000"`）；衰减分母与独立重复次数是整数。方差、$\lambda$、$D/S$ 皆须正。全局 `lambda` 只驱动 `estimates` 的岭估计与 SVG 第二幅；每个 `gaussian_cases` 另以自身 `noise_variance/prior_variance` 推出后验对应的正则比率。默认输入让两条比率相同，改变一项不会自动改另一项；比较同一 MAP 时须显式保持它们一致。`repeat_counts` 是假定的独立观测数量，输出只计算协方差，没有生成新观测，也没有为真实数据认证独立性。零奇异方向作为单独丢弃第二投影的反例计算，不表示有限 $T$ 的热衰减为零。

在本目录运行 Python 3.10+：

```bash
python3 -B thermal_inverse.py --input inputs.json --out /tmp/thermal-inverse-first
```

`--out` 必须是新目录；现存目录会拒绝，避免覆盖旧证据。运行输出是下面三个文件；数字单位与主课一致：

| 输出 | 可检查对象 |
| --- | --- |
| [results/results.json](results/results.json) | $A$、有限条件数、真值／无噪声观测、增益／偏差；两次观测和无噪声的两种估计、逐坐标误差平方／平方和／MSE及残差；A/B 的均值／协方差；独立重复与零方向方差；含完整噪声／先验变换的 $x=Dz,\widetilde y=Sy$ 回映 |
| [results/estimates.csv](results/estimates.csv) | 六行估计与误差，数值采用精确分数字符串；MSE 明确是两坐标平均 |
| [results/thermal_inverse.svg](results/thermal_inverse.svg) | 同一参数的温度比剖面、弱坐标估计增益／真值、独立重复后验方差；包含可访问 title/desc、单位／边界与模型卡 |

SVG 第一幅由 $u=x_0/\sqrt\pi+x_1e^{-t}\sqrt{2/\pi}\cos\xi$ 在129个空间点生成，第二幅由同一 $a_1,\lambda$ 的直接／岭直线生成，第三幅由 $[\tau^{-2}+m a_1^2/\sigma^2]^{-1}$ 生成。第三幅每个点表示整数 $m$，线段便于比较，不代表分数观测数。颜色之外有线型与图例；主课说明统计独立性及模型外偏差的限制。

## 先预测，再改一处

先不运行，核对默认主观测的岭第二坐标为什么恰为1；再写出改观测 .011 后的岭第二坐标和误差平方和。运行后查 JSON 的 `estimates`，对照主课表。检查 `residual_y_minus_Ax`：残差为0的是直接逆，它未必更接近指定真值。

把输入复制到一个新文件，改变一个条件，并选择新的输出目录：

- 仅把 `changed_observation[1]` 改 `"1/100"`：直接逆无误差，岭的第二误差平方为 $1/4$；小增益没有消除无噪声偏差。
- 仅把 B 的 `noise_variance` 改 `"1/10000"`，保留其先验方差4：$\lambda=1/40000$，不再与 A 相同；核均值 $(40000/40001,8/5)$ 与第二后验方差 $4/5$。
- 增加独立次数3：条件 A 的第二方差为 $1/4$，零方向仍为1；输入里写3只是假设，不代表设备已经新增观测。

撤去方法提示的题目与答案见 [[信号与系统/50-通信与反演/02-前向算子反卷积与正则化重建#撤去方法提示后的迁移|改变时刻、独立性和先验]]。源码的有限输入范围用于控制教学运行：衰减分母2–10000，每个有理数最多7位整数／分母、绝对值不超过 $10^6$，最多8个 Gaussian 情景及32个不同的重复次数（1–1000）。这些软件限制不是热方程或后验理论的适用上界。

## 运行与证据边界

正式 `results/` 保留独立执行者从这份源码和固定输入实际生成的默认三个产物；核对记录在 [[信号与系统/80-实践/10-两模态热反演/RESULTS|运行结果与独立复核]]。来源、论证与实验独立检查分别支持自己的层：精确有限代数和实际 SVG 生成不证明真实杆满足两模态限制，图的本地渲染不代表 Obsidian 客户端已实走，也不代表真人理解。

本实践仍用规定的 $\lambda$ 解释增益／偏差，没有独立参数选择或保留评估集。一般边界卷积／伴随、二维PSF、边缘先验与独立选择现在进入 [[信号与系统/80-实践/17-二维PSF与保留评估/README|实践17]]，用另一固定二维输入实际复算；本目录的精确热模态证据原样保留。真实数据校准另验，不能用已知评估真值挑 $\lambda$ 再宣称方法普遍优越。
