# 一阶语法、模型与自然演绎

已能区分“写得合法”“在模型中为真”“有合规证明”，下一步是固定一套足够明确的规则：每一次量词代入与假设解除，都能由读者检查。本章采用**经典、单论域、含逻辑等号的一阶自然演绎**。自由变量可以出现在公式、项与假设中；下一章对模型和赋值一起量化，证明这套规则的一般健全性。这里的等号表示对象相同，不是一个可任意解释的二元关系。

入门的量词顺序与权限例仍在[[数学/12-离散数学与逻辑/01-命题谓词量词与形式证明#4. 量词顺序规定见证可以依赖谁|原量词课]]；捕获的关系表例仍在[[哲学与文化/20-论证知识与规范/04-量词有效性与反模型#自由变量、绑定变量与捕获|自由变量与捕获]]。本章固定它们背后的合同，不重复一套入门证明。

## 1. 项指对象，公式提出判断

一个签名指定常量符号、函数符号与谓词符号及各自的有限元数；另有无限多个变量 $x,y,z,\ldots$。项递归生成：变量、常量是项；$f$ 为 $n$ 元函数且 $t_1,\ldots,t_n$ 是项时，$f(t_1,\ldots,t_n)$ 是项。没有函数符号的语言仍然合法。

原子公式是 $P(t_1,\ldots,t_n)$ 或 $s=t$。公式递归生成：原子式和 $\bot$ 是公式；若 $A,B$ 是公式，则 $\neg A$、$A\land B$、$A\lor B$、$A\to B$、$\forall xA$、$\exists xA$ 是公式。括号决定作用域。$\top$ 缩写 $\neg\bot$，$A\leftrightarrow B$ 缩写 $(A\to B)\land(B\to A)$，不另增加推理规则。$\lor$ 是可兼容的或，$\to$ 是材料蕴含。

$FV(t)$ 是项出现的变量集。$FV(P(t_1,\ldots,t_n))$ 是各项自由变量集的并，等式同理；$FV(\bot)=\varnothing$，否定不改变自由变量集，二元连接词取并；$FV(\forall xA)=FV(\exists xA)=FV(A)\setminus\{x\}$。没有自由变量的公式叫句子。量词绑定出现位置，不能把相同字母的所有出现一并替换。记 $Var(A)$ 为自由与绑定变量的全体；每个项、公式都是有限串，故这些集合有限。

## 2. 非空模型与一般赋值

模型 $M$ 给出非空集合 $D$，每个常量 $c$ 的解释 $c^M\in D$，每个 $n$ 元函数的**总函数** $f^M:D^n\to D$，每个 $n$ 元谓词的关系 $P^M\subseteq D^n$。不同常量可以指同一对象；这里没有唯一名称或封闭论域假设。偏函数必须另建语言或加定义域谓词，不能直接冒充这里的函数解释。

赋值 $v$ 是从全体变量到 $D$ 的总映射。$v[x\mapsto d]$ 只改变 $x$ 的值。项的值递归定义为

$$
\llbracket x\rrbracket_{M,v}=v(x),\quad
\llbracket c\rrbracket_{M,v}=c^M,\quad
\llbracket f(\vec t)\rrbracket_{M,v}=f^M(\llbracket t_1\rrbracket_{M,v},\ldots,\llbracket t_n\rrbracket_{M,v}).
$$

模型与赋值满足公式，记 $M,v\models A$：谓词由对应对象元组是否属于关系判断；$M,v\models s=t$ 当且仅当两项值相同；$\bot$ 永假。$\neg,\land,\lor,\to$ 按经典二值语义，尤其 $A\to B$ 仅在 $A$ 真、$B$ 假时为假。量词为

$$
M,v\models\forall xA\iff\text{每个 }d\in D\text{ 都使 }M,v[x\mapsto d]\models A,
$$
$$
M,v\models\exists xA\iff\text{至少一个 }d\in D\text{ 使 }M,v[x\mapsto d]\models A.
$$

因此项一定指对象，量词一定在同一个非空论域取值。句子的真值不依赖赋值；下一章会证明这个事实，不能只凭“看不到自由变量”跳过依据。

## 3. 替换先检查捕获，再写实例

$t$ 对 $x$ 在 $A$ 中**可自由代入**，意思是：$A$ 中每个自由 $x$ 的出现，都不处在绑定 $FV(t)$ 中某变量的量词之下。本章 $A[t/x]$ 只在这一条件成立时有定义：将自由 $x$ 换为 $t$，其余出现不动。项替换不含绑定，始终有定义。该约定使每条规则的合法性可直接检查；遭遇捕获先改绑定名字，再代入。

例如 $A=\exists yR(x,y)$，$t=y$ 不能直接代入；$\exists yR(y,y)$ 丢失了外部指定对象。先将绑定 $y$ 改为新 $z$，再得到 $\exists zR(y,z)$。常量 $a$ 不含自由变量，可直接得到 $\exists yR(a,y)$。

为使改名也可核，本系统允许 **α 改名规则**：在一个公式的任意子公式 $QxB$（$Q$ 为 $\forall$ 或 $\exists$）处，换为 $QzB[z/x]$，要求 $z\notin Var(B)$ 且 $z\ne x$；可正向或反向使用。这只改该量词所绑定的出现，不改更内层同名量词所绑定的出现，不改其他位置。多次新鲜改名能腾出任何有限项所需的变量；下一章由替换引理证明改名前后同真，不把改名当未经证明的便利。

## 4. 推导是带依赖的有限树

$\Gamma\vdash A$ 表示有一棵有限推导树，根为 $A$，所有未解除假设都属于有限上下文 $\Gamma$。上下文是公式的有限集合，$FV(\Gamma)=\bigcup_{B\in\Gamma}FV(B)$；同一公式的不同假设出现仍须标明哪些被解除。$[A]^i\vdots B$ 表示子树暂时假设 $A$，在规则标记 $i$ 处解除相应出现。可以解除零个该假设出现，所以不强迫条件真的被使用。

下列是本系统的**全部规则**。多条前提可先用弱化放到共同上下文；没有隐藏的“事实测试成功，所以写结论”规则。

| 规则 | 形式与依赖 |
| --- | --- |
| 假设 H | 若 $A\in\Gamma$，则 $\Gamma\vdash A$。 |
| 弱化 W | $\Gamma\vdash A$、$\Gamma\subseteq\Delta$，得 $\Delta\vdash A$（上下文均有限）。 |
| $\land I$ | $\Gamma\vdash A$、$\Gamma\vdash B$，得 $\Gamma\vdash A\land B$。 |
| $\land E_1,\land E_2$ | $\Gamma\vdash A\land B$，分别得 $\Gamma\vdash A$ 或 $\Gamma\vdash B$。 |
| $\lor I_1,\lor I_2$ | $\Gamma\vdash A$ 得 $\Gamma\vdash A\lor B$；$\Gamma\vdash B$ 得 $\Gamma\vdash A\lor B$。 |
| $\lor E$ | $\Gamma\vdash A\lor B$、$\Gamma\cup\{A\}\vdash C$、$\Gamma\cup\{B\}\vdash C$，解除两分支假设，得 $\Gamma\vdash C$。 |
| $\to I$ | $\Gamma\cup\{A\}\vdash B$，解除临时 $A$，得 $\Gamma\vdash A\to B$。 |
| $\to E$ | $\Gamma\vdash A$、$\Gamma\vdash A\to B$，得 $\Gamma\vdash B$。 |
| $\neg I$ | $\Gamma\cup\{A\}\vdash\bot$，解除临时 $A$，得 $\Gamma\vdash\neg A$。 |
| $\neg E$ | $\Gamma\vdash A$、$\Gamma\vdash\neg A$，得 $\Gamma\vdash\bot$。 |
| $\bot E$ | $\Gamma\vdash\bot$，得 $\Gamma\vdash C$，$C$ 任意。 |
| RAA（经典反证） | $\Gamma\cup\{\neg A\}\vdash\bot$，解除临时 $\neg A$，得 $\Gamma\vdash A$。 |
| $\forall E$ | $\Gamma\vdash\forall xA$，得 $\Gamma\vdash A[t/x]$，$t$ 是可自由代入的任意项。 |
| $\forall I$ | $\Gamma\vdash A[y/x]$，得 $\Gamma\vdash\forall xA$；$y\ne x$、$y\notin Var(A)$、$y\notin FV(\Gamma)$。 |
| $\exists I$ | $\Gamma\vdash A[t/x]$，得 $\Gamma\vdash\exists xA$，$t$ 是可自由代入的任意项。 |
| $\exists E$ | $\Gamma\vdash\exists xA$、$\Gamma\cup\{A[y/x]\}\vdash C$，解除局部 $A[y/x]$，得 $\Gamma\vdash C$；$y\ne x$、$y\notin Var(A)$、$y\notin FV(\Gamma)\cup FV(C)$。 |
| $=I$ | 任意项 $t$，无前提得 $\Gamma\vdash t=t$。 |
| $=E$ | $\Gamma\vdash s=t$、$\Gamma\vdash B[s/z]$，得 $\Gamma\vdash B[t/z]$；两项均须对 $z$ 在 $B$ 中可自由代入。 |
| α 改名 | 从 $\Gamma\vdash F$ 得 $\Gamma\vdash F'$，$F'$ 是第3节所定的一次绑定改名或其逆。 |

特征变量 $y$ 是真正的变量，通过改变赋值体现“任意对象”或“未知见证”。$y\notin Var(A)$ 是比只排除自由出现更强的便利限制，因变量无限、式子有限，总可选到；$y\notin FV(\Gamma)$ 与存在消去的 $y\notin FV(C)$ 则阻止对象依赖泄漏。这是本文的自由变量版本；不是把教材新常量规则原封不动改标签。RAA 使系统采用经典逻辑，删除它后不能继续直接用本课经典反证推导。

## 5. 一次合法推导，把两个量词条件同时查清

令 $\Gamma=\{\forall x(P(x)\to Q(x)),\exists xP(x)\}$，目标 $\exists xQ(x)$。$y$ 取未在前提或目标出现的新变量：

| 行 | 公式 | 理由与仍开放的假设 |
| --- | --- | --- |
| 1 | $\forall x(P(x)\to Q(x))$ | 前提，依赖 $\Gamma$ |
| 2 | $\exists xP(x)$ | 前提，依赖 $\Gamma$ |
| 3 | $P(y)$ | 局部见证假设，依赖 $\Gamma\cup\{P(y)\}$ |
| 4 | $P(y)\to Q(y)$ | 1，$\forall E$，再弱化到局部上下文 |
| 5 | $Q(y)$ | 3、4，$\to E$ |
| 6 | $\exists xQ(x)$ | 5，$\exists I$，变量 $y$ 可自由代入 |
| 7 | $\exists xQ(x)$ | 2、3–6，$\exists E$；解除3，$y$ 不在 $\Gamma$ 或结论自由出现 |

不能把第5行直接带出子树作为 $\Gamma\vdash Q(y)$，因为其结论含局部见证 $y$；也不能在第3行后做 $\forall I$，因为未解除的 $P(y)$ 含自由 $y$。逐行查依赖，比“这段推理看起来合理”多了一项可证伪的检查。

等号不需要另给对称与传递公理。例如先取不在 $s,t,u$ 中出现的新变量 $z$，从 $s=t$、$s=s$ 用 $B(z)\equiv z=s$ 做 $=E$，得到 $t=s$；从 $s=t$、$t=u$ 用 $B(z)\equiv s=z$ 得 $s=u$。这两例只用已列规则；等号的保真仍由下一章单独证明。

## 6. 撤去方法提示的迁移

尝试后再展开答案；每题交完整依赖、结论及条件或反例。

1. 从 $\forall x(P(x)\to Q(x))$、$\forall xP(x)$ 推出 $\forall xQ(x)$。
2. 从 $P(y)$ 得到 $\forall xP(x)$，从 $\exists xP(x)$ 得到 $P(c)$。分别审查，并给模型支持判断。
3. 对 $\forall x\exists yR(x,y)$ 做全称消去，将外层 $x$ 实例化为项 $f(y)$，写出合法的实例；说明直接写 $\exists yR(f(y),y)$ 改了什么。
4. 从 $a=b$ 与 $\forall xR(a,x)$ 推出 $\forall xR(b,x)$，列出等号替代的 $B,z,s,t$；再说同一推导能否在把“=”解释为普通邻接关系的模型中使用。

> [!success]- 核对答案
> 1. 取 $y$ 新鲜。由两前提分别 $\forall E$ 得 $P(y)\to Q(y)$ 与 $P(y)$，用 $\to E$ 得 $Q(y)$。只开放两条不含自由 $y$ 的原前提，$\forall I$ 得 $\forall xQ(x)$。每条量词代入均可自由代入；若最后用 $\to I$ 包成条件式，也须说明解除哪条前提。
>
> 2. 首式的 $P(y)$ 仍开放，违反 $y\notin FV(\Gamma)$。取 $D=\{0,1\}$、$P^M=\{0\}$、$v(y)=0$，前提真、结论假。次式不存在合法的直接见证指定规则；取同一论域、$P^M=\{1\}$、$c^M=0$，存在前提真而 $P(c)$ 假。可以开新变量局部假设 $P(z)$，但带出结论须不含自由 $z$。
>
> 3. 先用 α 改名将原句写为 $\forall x\exists zR(x,z)$，$z$ 新鲜。$\forall E$ 得 $\exists zR(f(y),z)$。其中外部 $y$ 仍自由；错误式把它绑进 $\exists y$，连 $f(y)$ 所指对象都随内部见证改变。取 $D=\{0,1\}$、$f^M$ 为恒等函数、$R^M=\{(0,1),(1,0)\}$，正确实例任意赋值均真，错误式只查对角、为假。
>
> 4. $B(z)=\forall xR(z,x)$，$s=a,t=b$，新 $z\ne x$；两常项可自由代入，$=E$ 一步得目标。逻辑等号使 $a^M=b^M$，两式读取同一对象。普通邻接关系不保证对象相同，故不满足本系统的模型合同，不能沿用 $=E$。
