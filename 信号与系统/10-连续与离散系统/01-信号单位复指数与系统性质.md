# 信号单位、复指数与系统性质

读者问题：一台装置把输入波形变成另一条波形，怎样判断它可否叠加、平移和实时计算？先预测：`y[n]=n x[n]` 与 `y[n]=x[n]²` 哪一个允许叠加，哪一个允许平移？答案不必相同。

**高中入口**：会代入函数即可先做下表和四点算例。指数与复数只在需要描述旋转时回补。**本科快进**：从“把整个信号作为对象”开始，用算子恒等式逐项证明，不凭图像看着平滑就认定LTI。两入口共用本页例子、条件与迁移题。

## 同一个量，连续时间与样本索引不同

电压记为 $x_c(t)$，$t$ 的单位为秒，$x_c$ 为V。每隔 $T_s=0.125\,\mathrm s$ 取一次值，$x_d[n]=x_c(nT_s)$，$n\in\mathbb Z$ 无量纲。连续时间（CT）信号在所有实数时刻定义；离散时间（DT）只在整数索引定义。DT值仍可为任意实数，离散时间不意味着已经量化。

取 $x_c(t)=2\cos(4\pi t)\,\mathrm V$：$f=2\,\mathrm{Hz}$、$\Omega=2\pi f=4\pi\,\mathrm{rad/s}$，样本角频率 $\omega=\Omega T_s=\pi/2\,\mathrm{rad/sample}$。$n=0,1,2,3$ 的值为 $2,0,-2,0$ V。$2\cos(12\pi t)$ 是6 Hz，却给同样四点；样本并不自带原连续频率的身份证。

CT能量 $E=\int_{\mathbb R}|x_c(t)|^2dt$ 的单位为V²·s，DT平方和 $\sum_n|x_d[n]|^2$ 为V²；它们不是自动相等的物理能量。若计算电阻消耗的焦耳，还要除以电阻。平均功率型量可定义为 $\lim_{T\to\infty}(2T)^{-1}\int_{-T}^T|x|^2dt$；周期余弦幅值A的值为A²/2，而全线能量无穷。不是每个信号的该极限都存在。

## 复指数是一条旋转轨迹

$j^2=-1$，$e^{j\theta}=\cos\theta+j\sin\theta$。乘 $e^{j\phi}$ 是转动 $\phi$，模不变；实部是余弦，虚部是正弦。$Ae^{(\sigma+j\Omega)t}$ 的幅度 $|A|e^{\sigma t}$，旋转速率 $\Omega$。指数必须无量纲，$\sigma$ 的单位为s⁻¹。DT对象为 $Az^n$，$z=re^{j\omega}$ 无量纲，$r$ 决定每一步幅度变化。$e^{j(\omega+2\pi k)n}=e^{j\omega n}$，故DT频率按 $2\pi$ 等价；CT频率在未采样前没有这一等价关系。

## 三个独立的问题

记 $T\{x\}=y$，平移算子 $S_{n_0}x[n]=x[n-n_0]$。

- 线性要求对允许输入及标量 $a,b$，$T(ax_1+bx_2)=aTx_1+bTx_2$；特别地 $T0=0$。复信号空间用复标量，不能只检查实标量后声称复线性。
- 时不变要求 $TS_{n_0}=S_{n_0}T$ 对所有整数平移成立。CT改用所有实数平移；固定开机时刻与固定非零初值须说明，可能破坏这一全线输入输出描述。
- 因果要求两个输入在时刻n及以前相同，则输出在n相同。它是“当前输出不依赖未来”的性质。无记忆要求仅依赖当前输入，强于因果；延迟有记忆但因果。

| 全线DT系统 | 线性 | 时不变 | 因果 | 可检查理由 |
| --- | --- | --- | --- | --- |
| $y[n]=2x[n]$ | 是 | 是 | 是 | 两倍操作与叠加、平移交换 |
| $y[n]=nx[n]$ | 是 | 否 | 是 | 平移后出现n与n−n₀差 |
| $y[n]=x[n]^2$ | 否 | 是 | 是 | $(1+1)^2\ne1^2+1^2$ |
| $y[n]=x[n+1]$ | 是 | 是 | 否 | 当前输出读下一点 |
| $y[n]=x[n]+1\,\mathrm V$ | 否 | 是 | 是 | 零输入输出1 V |

例如 $T S_1x[n]=n x[n-1]$，$S_1Tx[n]=(n-1)x[n-1]$；取 $x[0]=1$、$n=1$ 即分别1与0。这是一个反例，足够否定“对所有输入成立”。证明成立则必须针对任意允许输入。

## 共同前缀怎样检验非预见性

固定同一个算子 $T$、初始状态和外部输入。对任意两个允许输入，离散时间因果性可等价写成

$$
x_{\le i}=\widetilde x_{\le i}\quad\Longrightarrow\quad
(Tx)_{\le i}=(T\widetilde x)_{\le i}.
$$

这里的 $\le i$ 指截至 $i$ 的整个前缀；把前面定义的“当前输出相同”分别用于每个 $k\le i$，就得到整段输出相同。反过来取前缀末项也恢复原定义。连续时间用所有 $t\le t_0$ 同理。它限制**算子怎样使用输入**，不要求线性、时不变或预测准确。

带着这条任意输入命题，到 [[AI/20-LLM/20-架构/02-注意力MHA-MQA与GQA#causal mask 的共同前缀检查|三位置 attention 检查]] 看同一非预见性质怎样由允许集合保持；那里的逐位置变换也必须不偷读未来。再到 [[社会科学/10-共同工具/03-因果图反事实与识别#顺时序且预测相同，干预为何仍不同|同分布双模型]]，检查时间先后为何没有回答“改行动会怎样”。回来仍以本节的输入输出约束判断信号因果性，不把现实干预识别当算子的另一项测试。

## 故意撤去条件

有状态递推 $y[n]=\tfrac12y[n-1]+x[n]$，若固定 $y[-1]=1$，零输入仍给 $y[0]=1/2$，所以从输入x到完整输出y的映射是仿射而非线性。若把初始状态也作为输入，联合映射仍线性。把“方程线性”直接改写为“固定非零初值的输入输出映射线性”是对象偷换。

采样算子从CT到DT可对固定时刻线性，但其时不变要比较两种时间轴的平移：只有 $t_0=mT_s$ 时能和整数样本平移对应。不能直接给跨时域算子贴上未经定义的同一时不变标签。

## 独立迁移：改变时域与状态

某CT装置给 $y(t)=x(t-0.2\,\mathrm s)+3\,\mathrm V$。另一装置给 $q[n+1]=\tfrac12q[n]+x[n]$、$y[n]=q[n]$，从n=0开机且 $q[0]=2\,\mathrm V$。逐项判断两者线性、因果、记忆；说明第二者怎样改写输入集合才可称线性。把第一装置接在8 Hz采样前，0.2 s是否对应整数样本延迟？写出支持判断的等式或反例。

> [!question]- 答案与接受标准
> 第一者不线性（T0=3 V），因果且有记忆。第二者固定非零初值的x→y映射不线性，因果且有记忆；(q[0],x)→y线性，或改为零初值。有限开机协议不能无说明地套用全线时不变。0.2/0.125=1.6，不能用整数延迟精确代替；插值须新条件。正确反例或任意输入推导均接受。
