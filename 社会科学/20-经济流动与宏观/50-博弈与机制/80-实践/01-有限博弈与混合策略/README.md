## 固定输入和可做的复算

[inputs.json](inputs.json) 保留六个完整2×2矩阵、行列行动次序及正仿射参数2、7。程序以 `Fraction` 解析数字字符串，逐格找两方最优回应并列出纯Nash，再解析求非退化2×2的全支持内点候选。另将两组加权匹配矩阵的**行方**逐格立方或正仿射变换，列方保持；按可见先后构造匹配硬币的2×4完整策略表；记录明确同时更新规则的四步循环，以及共同币/独立币的联合概率差异。

## 迁移题完整答案

先答 [迁移题](迁移题.md) 再看下文。参考答案评的是题设内推理，不记录任何真实学习分数；模型独答不是人类理解验收，评分一致也不等于构念效度。

### 一：弱占优留下了什么

面对列C，行C/D均得3，最优回应集为{C,D}；面对列D，行D得1>C的0，回应只有D。列方对称：面对行C，C/D均得3；面对行D，只有D最好。四格里CC双方均已最优、DD也均已最优；CD中行愿改D，DC中列愿改D。因此所有纯Nash是CC和DD。

D只弱占优C；C在对手D处严格差，在对手C处相等。删C只剩DD，丢失了原CC均衡。合格答案要指明“弱占优的严格改进处在CC没有权重”；最近的错解是沿原PD习惯仍说D严格占优。另一错解是“有两个均衡，合作就一定发生”：存在没有提供选择机制。题中没有法律权限、可验证行为、执行成本与价值理由，不能据此证明必须强制合作；若加入强制，须重新写行动和后果。

### 二：行的概率不由行自己的无差异式直接算

行方面对左时上好（3>0），面对右时下好（1>0）；列方面对上时右好（0>-3），面对下时左好（0>-1），所以无纯Nash。列左/右效用为 $-3p$、$-(1-p)$，相等给p=1/4；行上/下效用为3q、1−q，相等给q=1/4。任一方纯选都会引发对方严格回应及前者改动，故双方必须内点，上述是唯一混合Nash。行效用3/4、列-3/4。

仅行立方后，上收益27q、下1−q，给q=1/28；列未变，仍由其无差异给p=1/4。行新效用27/28、列仍-3/4；新博弈不再零和。原半边条件不能混用：旧q=1/4时行上27/4而下3/4，愿改成纯上，原混合已非最佳回应。最近的错解是把行方27代进列的旧收益，让p也改成1/28；这改了没有被题设改动的列偏好。

只改行为2u+7时，行任何彩票期望都变为原值乘2加7，偏离差只乘2，故p=q1/4保持；行均衡效用17/2，列-3/4。全局严格递增立方保持每个确定结果排序，却改变彩票比较；用 $f(Eu)$ 代替 $E[f(u)]$ 会把新偏好偷偷改回旧偏好。须交代效用是偏好表示，不把立方当实发奖金或人际福利变化。

### 三：完整计划和信息集

列方纯计划有HH、HT、TH、TT；第一字母给看见H后的动作，第二给看见T后的动作。题设观察后，后手在每条分支均选异面最好，所以TH两分支都最优。与TH配对，行H/T都得-1、列得1，行改动不改善，故两个纯Nash为(H,TH)、(T,TH)。其余格不是列已匹配得太差，就是行能转到更好的分支；正文完整2×4表可逐格核。行任意混合、列固定TH也均为Nash。

看不见时，列无法区分两条分支，合法策略不能按不可用信息选动作，只可固定H/T或其混合。正常式回到原匹配硬币，无纯Nash、唯一独立混合双方1/2、期望均0。最近的错解是“凡是后手都能反着选”，把时序当作可观察性；另一错解是只写实际到达的那个后手动作，漏掉完整计划与行方改变行动时的后果。

$x\in(0,1)$ 是无限行动集且不紧。任意x都可被 $(x+1)/2$ 严格改进，所以没有纯最大化选择；即使允许任意混合，期望严格小于1，也有更高期望的确定选择。有限博弈存在性不适用，“只有一个人”不等于“行动有限”。连续模型需要它自己的存在条件；也不能由这个失败例反推所有无限行动博弈都没有均衡。

## 真实行为或算法研究需要另有什么

本包不招募、不发任务、不操纵平台，也不生成代理作答冒充人类效果。若以后验证行为，至少要在运行前固定以下接口：

| 环节 | 必需输入与可反驳观察 | 失败/缺失出口 |
| --- | --- | --- |
| 行动和信息 | 任务版本、行列归属、时点、可见内容、信号/通信/合同条件；隐藏信息确实被隐藏的日志；理解题完整回答和缺失 | 错看收益、可偷看或额外通信，不能按原正常式解释；理解筛查规则须事先声明，不事后只留“像均衡”的人 |
| 效用与激励 | 实际后果/报酬、兑换规则、风险和彩票偏好证据、参与/退出与预算；不要默认金额等于线性效用 | 不知道彩票偏好时只能报告选择与实付结果，不能从某个变换反推心理机制；目标不可识别处明确未知 |
| 分配和暴露 | 角色与版本随机化单位/概率、配对、先前接触与反馈、一次或重复互动、共同装置是否可信；若比较信息条件，可在独立配对层分配并保留全部计划 | 对内相互影响正是博弈对象，不能当两份独立受试者；跨对交流或重复匹配须建依赖，不把很多轮当很多独立人 |
| 观察和判断 | 原始行动/时间/信息暴露、收益、完整失败/退出分母；先定检验对象是边缘频率、联合分布、偏离激励还是学习轨迹 | 边缘各半不足以证明独立随机化或主观信念正确；没到均衡可反驳当前行为模型，却不推翻数学存在定理 |
| 比较和外推 | 保留预定分析、组间和时间依赖、样本选择、环境与文化/制度范围；事先列何种结果应收窄主张 | 只看成功配对或改收益直到“拟合”属于选择偏差；不得把实验室矩阵直接写成组织现实或规范处方 |

若研究学习算法，另固定更新规则、同时/轮流、信息、初始化、随机种子、停止与失败界限，以及能证明的收敛对象。当前只执行一个明确规则的有限循环反例；没有训练多智能体、没有断言其他算法收敛。若研究教材理解，须有真人先修/材料暴露、无提示新题与延迟迁移的实际记录和评分设计；本包没有这种学习效果证据。
