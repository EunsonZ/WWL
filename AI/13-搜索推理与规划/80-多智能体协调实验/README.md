# 有限协调：固定对手、独立更新与更换搭档

- [[AI/13-搜索推理与规划/80-多智能体协调实验/code-sync/源码与测试镜像|源码镜像]]只为Markdown阅读，修改仍从`.py`出发。两图在`results/`，嵌入用的`assets/ai-marl/`副本逐字节一致。

数组没有引入新变换框架：Q按`[agent][L/R]`存储，形状2×2；固定对手只更新第0行。联合事件顺序固定`LL,LR,RL,RR`；crossplay是`[actor0训练seed索引][actor1训练seed索引]`的8×8表，输入种子的顺序就是行列顺序。奖励/回报以每episode的教学点数计，成功与错配是[0,1]概率；团队值是两人奖励和，范围[0,4]。

精确的纯均衡、期望收益与单方偏离复用[[社会科学/20-经济流动与宏观/50-博弈与机制/80-实践/01-有限博弈与混合策略/finite_games.py|已交一般有限博弈源码]]的`pure_equilibria`和`deviations`接口。原样使用矩阵`[[2,0],[0,1]]`作为双方收益，传入`Fraction`概率；没复制一般求解器，也没把我们的采样学习输出冒充一般存在性证明。独立核查须用另一条联合事件路线验证此处的具体值，不能只让这两个接口互相签字。

`run_local.py`是本轮本机两槽调度入口，不是课程安装依赖；在另一台没有该临时文件的机器，可直接运行其`--`后的`python3 -B ...`命令。已整合时默认`--vault`可自行定位WWL根；候选目录不含社会科学源码，作者以`--vault /Users/ysz/Misc/Obsidian/Valults/WLM/WWL`显式复用主库只读依赖。`--output`可写新目录保留既有输出。输入/依赖校验先于创建结果目录：概率越界、训练与heldout交集、重复或负种子、非法步长/探索率、块大小不整除回合数都报错。

作者先运行20回合短配置核接口（另一次初版1200回合快速运行未作为正式结果）；将概率显示规范为十进制转有理数后，运行上述正式24×1200配置，stdout为：

## 实验重要性、独立预期与失败判据

| 断言/实验 | 重要性与依据 | 独立预期和容差 | 本机结果/失败含义 |
| --- | --- | --- | --- |
| 联合12行→有效核/期望奖励/阈值/偏离 | 高；混掉奖励、成功或条件分布会推翻核心 | 独立按四联合事件有理枚举，概率归一；q=.8时8/5 vs1/5，q=.2时2/5 vs4/5；阈值1/3，纯LL/RR与混合(1/3,1/3)逐偏离精确无误差 | 正式JSON给出这些值；任何分数不等、漏吸收格、非零混合偏离均失败 |
| 两个本地策略先抽后更新与日志版本 | 高；偷看当轮动作会把同时任务变成串行任务 | 不调用作者`train`，从seed流与CSV旧Q重放28800行；p/actions/version完全一致，Q≤1e-12；两份当前策略不能用本轮奖励 | CSV保留首轮p=.5/.5及全部后继；只输出相似均值而逐行不同不算通过 |
| 训练后固定策略交叉配对与未用q族 | 高；单一高分会掩盖约定依赖 | 独立事件枚举64对：32错配、8原配全成功、32/56异配失败；96项heldout逐项期望/偏离精确相等 | 主文报告精确期望而非新增模拟样本；结果改变应追至冻结Q/评价协议，不能从图推均衡 |
| 公共信号与独立随机源 | 高；边缘相同而联合不同是信息合同反例 | Fraction独立分布[1/9,2/9,2/9,4/9] vs共同信号[1/3,0,0,2/3]，每人2/3 vs4/3；精确 | 同模型SVG展示八根柱；若采用乘积算公共信号则失败 |
| 100回合块的有限学习曲线 | 中；帮助看低回报也可能是稳定约定，非核心理论证明 | 从CSV独立按run/块汇总成功及团队均值≤1e-12，图每折点的像素误差≤1e-3（坐标写4小数） | 原始数值保留，曲线不承担极限/均衡/现实合作证明 |
| 变量输入、复建和图副本 | 中；错误行列/旧标签会让图解释另一模型 | 改seed顺序或alpha/episodes但不改奖励表；图从同次结果动态生成，JSON/CSV/2SVG重建一致，2asset镜像一致 | 固定奖励理论图仍同一模型；未给任意奖励的绘图接口 |

本机执行不是一般证明：有效核归一与Markov条件、最优回应阈值、三个均衡的穷尽、团队上界及同边缘反例由主文论证。八个seed是一个预先指定的小族，无统计功效设计，不估计所有初始化成功概率。固定alpha/epsilon下不能据本有限曲线断言收敛或否定其他方法。

未运行真人互动、深度CTDE、真实通信网络、机器人或远程GPU。若以后做真人协作，至少要固定双方可见通道/响应时限、奖励和退出规则、随机配对单位、搭档族及协议失败计数，比较同搭档与新搭档并记录同意和真实样本；不得将本模拟的点数当真人收益。若以后做重训练，先给有限隐藏状态、actor/critic字段分离、训练/测试对手版本、预算和信息泄漏断言；现有接口足以接续，不是假装这些层已跑过。
