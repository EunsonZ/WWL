# 同一份记录，怎样从 Python 对象走到带单位的统计量？

> 从[[计算机知识/10-编程语言/01-Python/10-系统课程/00-Python系统课程索引|Python唯一系统索引]]进入。本页连通已有基础课与测量记录项目；机制课仍解释对象、协议和并发。主线使用 Python 3.11+ 标准库，四行输入是教学合成数据。

## 阶段零：先说清每个字段代表什么

四个数字能直接代表四次可靠测量吗？先把解释这些数字的条件写出来：

| 字段 | 合同 | 为什么需要 |
| --- | --- | --- |
| sample_id | 1–32 字符；首字符为小写 ASCII 字母，随后可为小写字母、数字、下划线或连字符；唯一身份 | 同一记录重试不能增加统计分母 |
| tick_ms | 非布尔整数；0 到 2⁶³−1；单位 ms | SQLite整数可表示；时间是字段，不是CSV行号 |
| code | 非布尔整数；0 到 4095 | 12位合成码范围，与解释器整数位宽不同 |
| 标定 | v = code × 1 mV；零偏置 | 把码值变成有单位的数；真实仪器另需标定与误差证据 |

实践项目的固定输入为：

```csv
sample_id,tick_ms,code
a,0,2
b,1000,4
c,2000,6
d,3000,8
```

第一次编程仍从[[计算机知识/10-编程语言/01-Python/00-Python基础-MOC#零基础的第一个程序|基础MOC首程序]]开始，随后完成基础01–05。这里的有限例可先用列表与循环复算，不必先懂描述符或C3。

## 阶段一：名字、值对象和一次性记录流

把记录放进列表以后，复制列表会复制测量吗？回[[计算机知识/10-编程语言/01-Python/10-系统课程/01-对象图复制与数值语义|对象图]]画出名字、列表与记录的箭头，再回本段：复制容器没有产生新的采样事实。项目中使用冻结的 `Record(sample_id, tick_ms, code)`；字段均为不可变字符串或整数，但“frozen”本身没有递归冻结能力。

`Record("a", 0, 2)` 合法；`Record("a", 0, True)` 必须抛 `ValueError`。类型标注不会替你拒绝布尔：`bool` 是 `int` 的子类，所以源码明确使用 `type(value) is int`。需要扩展JSON时仍须调用领域构造，不能用 `int(True)` 把错误洗成1。

CSV读取器交出 `Record` 或 `Rejected(line, reason)`；表头须恰为 `sample_id,tick_ms,code`，列数、编码、整数范围都有边界。空串、NaN、Infinity、True、浮点文本、Unicode数字与过长整数均不进入有效记录；文本整数只接受0或无前导零的ASCII十进制非负数。坏表头、损坏CSV框架与坏UTF-8是输入失败，不能当作普通坏数值悄悄忽略。拒绝数值行允许后续合法行继续；两种错误政策服务不同的可解释边界。

CSV迭代器只消费一次。回[[计算机知识/10-编程语言/01-Python/10-系统课程/03-生成器闭包与上下文协议|生成器主解释]]，再解释为什么 `list(stream)` 后再 `list(stream)` 为空；第二次计算应重开原输入或从数据库重建，不应把零行误当作零电压。文件由传入打开流的调用者关闭，生成器不夺走资源所有权。

## 阶段二：先手算，再对照程序

均值、方差和RMS²分别丢掉或保留了什么？本段仅分析固定四条已知合法记录，单位为mV：

$$
N=4,\quad \sum v_i=20\;\mathrm{mV},\quad \bar v=5\;\mathrm{mV},
$$
$$
\sum(v_i-\bar v)^2=9+1+1+9=20\;\mathrm{mV}^2,\quad
\frac1N\sum(v_i-\bar v)^2=5\;\mathrm{mV}^2,
$$
$$
\frac1{N-1}\sum(v_i-\bar v)^2=\frac{20}{3}\;\mathrm{mV}^2,\quad
\frac1N\sum v_i^2=\frac{4+16+36+64}{4}=30\;\mathrm{mV}^2.
$$

`Fraction` 让本例保留精确有理结果；这不消除真实标定、采样或仪器误差。有限源文件位于实践项目 `examples/first_record.py`，正文与源码的同版镜像如下：

<!-- code-sync: 计算机知识/80-实践/01-Python/04-测量记录导入与分析/examples/first_record.py -->
```python
"""Finite synthetic input only; arbitrary external CSV uses core.read_records."""
from fractions import Fraction

records = [("a", 0, 2), ("b", 1000, 4), ("c", 2000, 6), ("d", 3000, 8)]
codes = [record[2] for record in records]
count = len(codes)
total = sum(codes)
mean = Fraction(total, count)
centered = sum((Fraction(code) - mean) ** 2 for code in codes)
print("n =", count)
print("sum_mV =", total)
print("mean_mV =", mean)
print("pvariance_mV2 =", centered / count)
print("variance_mV2 =", centered / (count - 1))
print("rms2_mV2 =", Fraction(sum(code * code for code in codes), count))
```

在实践项目根运行 `python3 -B examples/first_record.py` 应得到 `4,20,5,5,20/3,30` 对应以上六项。脚本故意只有固定有限输入；对外部文件的验证与身份政策由 `measurement_import.core` 负责。空行集的均值、方差与RMS²报告为 `null`，单行集的N−1方差为 `null`，不会把不存在的统计量代填0。

去[[数学/30-概率与统计/02-期望方差协方差与抽样#进阶轨：样本方差为什么除以 $n-1$|抽样主解释]]检查N−1的理由，再回本段回答：使用N−1只改变分母，声称它无偏还需要相应抽样条件；这份合成记录没有提供它们。去[[电子电路/38-随机噪声与测量/01-RMS方差相关与谱密度#同一记录的中心与平方|RMS与中心平方主解释]]，再核对 `30 = 5² + 5`。这里的标准差是记录波动，不是均值置信区间。

## 阶段三：缺失与重复改变的是行集

删掉b或补一个0，何时会给出同样答案？把b的码字段改为空，保留a、c、d：有效行数3，和16，均值16/3，描述性方差56/9，RMS²为104/3。把缺失补0则保留四行，均值4、描述性方差10、RMS²为26。两者回答不同的问题，不能由 `dropna` 或 `fillna(0)` 的默认动作决定。

本项目拒绝缺失数值，单独计数；用户如果要研究缺失机制，应保留原CSV与拒绝原因，再为新研究合同写适配器。重复导入a–d时数据库仍四行；如果同一ID出现不同码值则拒绝当前批，而非取最后一次覆盖。不同ID的相同码值则可保留，它们是不同身份，不能按数值去重。

去[[计算机知识/55-数据库/10-系统课程/03-SQL查询语义与窗口函数#窗口保留行身份，聚合通常压缩行|SQL行身份与汇总]]，再用项目库复算：

```sql
SELECT sample_id, tick_ms, code FROM samples ORDER BY sample_id;
SELECT COUNT(*), SUM(code), AVG(code), SUM(code * code) FROM samples;
SELECT AVG((code-5.0)*(code-5.0)),
       SUM((code-5.0)*(code-5.0))/3.0, AVG(code*code) FROM samples;
```

四条输入对应四条身份行；第二个查询压成一条 `(4,20,5.0,120)`，第三个在已知四行和均值5的前提下独立检查 `(5.0,20/3,30.0)`。SQL主键、Python字典键、pandas索引各自有合同，不能看到都能索引就视为等价。

## 练习、反例与理由答案

1. 不运行代码，预测复制列表并重复求和是否增加独立观测。答案：程序可能数到更多元素，但没有增加采样事实；必须先按身份决定有效行集。
2. 给 `code` 输入 `True`、NaN、4096、空串和合法0。答案：前四项拒绝；0是有效码，不是缺失。允许 `int(True)` 的解析器违反本合同。
3. 撤去步骤提示：输入a=(0,2)、b=(1000,空)、c=(2000,6)、c再次重放，批大小由2改3。声明缺失与身份政策，给最终行集、均值、描述性方差和重跑新增数。答案：只留a、c；均值4、描述性方差4、RMS²20；重跑新增0。批界改变失败时可保留的前缀，不改变成功完成后的身份集合。
4. 按[[计算机知识/10-编程语言/01-Python/10-系统课程/12-可恢复导入器与安装交付#两行一批：失败之后，哪些数据已经存在|下一课回滚例]]运行故障。答案：只剩a、b时均值为3、描述性方差1、RMS²10；不能拿原CSV的四行图冒充库内已提交结果。
