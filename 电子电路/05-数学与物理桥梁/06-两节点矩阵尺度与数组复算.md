# 两节点矩阵、尺度与数组复算

读者问题：两条KCL怎样变成数组，换成mA为什么条件数会变，而实际电路没有变？高中入口先消元和回代；本科入口从尺度、扰动模型与残差进入。本页不要求编程先修，代码每个字段都对应已画节点和单位，不靠变量名猜单位。

## 完整算例：先写两行，再打包矩阵

![[电子电路/80-实践/07-读数单位与计算桥/assets/V03-two-node-currents.svg]]

节点a、b各经2 kΩ到参考0，中间a→b为1 kΩ；理想电流源从0向a注入1 mA。未知v_a/v_b都是对0的电压。取离开各节点的电阻电流：

$$(v_a/2000)+(v_a-v_b)/1000=0.001\ \mathrm A,$$
$$(v_b/2000)+(v_b-v_a)/1000=0.$$

除以1 mS并按V/mA数值记，可写1.5v_a−v_b=1，−v_a+1.5v_b=0。第二行v_a=1.5v_b，代第一行得到1.25v_b=1，故v_b=0.8 V、v_a=1.2 V。a到0电流0.6 mA、a到b0.4 mA、b到0 0.4 mA，逐节点回代KCL；电阻功率0.72+0.16+0.32=1.20 mW，源交付1mA×1.2V=1.20 mW。这既核对矩阵也核对电流方向。

矩阵是多条线性关系的紧凑写法：

$$Y\mathbf v=\mathbf b,\quad Y=10^{-3}\begin{bmatrix}1.5&-1\\-1&1.5\end{bmatrix}\mathrm S,\quad \mathbf v=\begin{bmatrix}v_a\\v_b\end{bmatrix}\mathrm V,\quad \mathbf b=\begin{bmatrix}.001\\0\end{bmatrix}\mathrm A.$$

Y是shape(2,2)、v和b为shape(2,)，每一行都是电流单位。矩阵乘法第i行是Σ_j Y_ij v_j；不会把每个Y元素同每个v元素各自配成一张2×2表。参考节点把公共电位自由度除去；若只留下a/b间电阻、没有到参考的路径，则Y∝[[1,−1],[−1,1]]，只确定v_a−v_b；注入总和非零时甚至无稳态解。它是拓扑/方程问题，不是改代码精度即可解决。

## 有定义尺度的条件数才有解释

先设V0=1 V、I0=1 mA，令x=v/V0、bhat=b/I0，Yhat=Y V0/I0=[[1.5,−1],[−1,1.5]]。Yhat无量纲，特征方向(1,1)与(1,−1)伸缩量0.5和2.5，κ2=5。对固定Yhat、非零bhat，右端相对二范数扰动满足

$$\|δx\|_2/\|x\|_2\le κ_2(Yhat)\|δbhat\|_2/\|bhat\|_2.$$

理由δx=Yhat⁻¹δbhat，再用范数乘法界与||bhat||≤||Yhat||||x||。这是一种给定尺度的最坏方向界，不是说所有扰动都恰放大5倍。数学主解释 [[数学/20-线性代数与几何/17-矩阵范数条件数与数值稳定性#小残差为何可能对应大错误|误差与条件数]]给一般证明；本页负责单位和KCL。

若各到地电导仅g=10 nS，中间1 mS，Y特征值g、g+2mS，κ2=200001。平衡注入(+1,−1)mA给a/b≈±0.4999975 V；叠加每节点+1 nA的微小共同注入，则两电压各增加0.1 V，因为共同方向只靠g泄漏。这个实际指定电流误差模型揭示敏感；再大的偏差会超出低压教学场景，不能直接拿模型预测安排实物实验。

## 混V/A的矩阵不能裸比较κ

另一模型：1 V理想源与1 kΩ并联，v为V、j为从正端进入源的A电流。方程0.001v+j=0（A行），v=1（V行）。用数字矩阵K=[[.001,1],[1,0]]解(v,j)=(1,−.001)，裸κ约1.001；仅把j数字改存mA，K′=[[.001,.001],[1,0]]，解(1,−1)，裸κ约1000。物理电路未变；行残差和列坐标改变，裸数值κ不等于单位无关的物理病态。

取V0=1 V、I0=1 mA，未知x=(v/V0,j/I0)，第一行除I0、第二行除V0，得到Khat=[[1,1],[1,0]]，bhat=(0,1)，解(1,−1)，κ2=(3+√5)/2≈2.618034。相容的单位存储重新映射到该归一化问题给同结果。尺度不是万能修复：仍需声明什么误差、什么范数；奇异rank不会被可逆尺度变换修好，也不能降低真实传感器误差。这一混单位例参考库外network1研究输入后自行回代/SVD复算，不宣称该研究包是一手原文。

## 从单位存储返回正则目标与真实误差

上面的 A/mA 数字矩阵和共同无量纲矩阵描述同一电路。固定 $V_0=1$ V、$I_0=1$ mA 后 $\widehat K=[[1,1],[1,0]]$、$\kappa_2\approx2.618034$；这组尺度与二范数不能从结论中删去。真实电流误差 $\delta j$ 在 A 中为某个数，在 mA 中为其1000倍，归一化后同为 $\delta j/I_0$；换数字存储没有降低它。

去 [[数学/20-线性代数与几何/17-矩阵范数条件数与数值稳定性#换坐标时，预测、惩罚与误差度量要一起带走|坐标与度量表]]，用 $w=Dv$ 带走列坐标，用行尺度同时带走残差权重和扰动集合；再读 [[AI/10-机器学习与深度学习基础/07-过拟合正则化归一化与可复现#同一长度换单位，为什么同一个正则系数会改变预测|米与厘米的正则反例]]。在拟合问题中，只换特征数字而沿用相同 $\lambda I$ 可能改变预测；要维持旧参数偏好需变为 $D^\top\Lambda D$。即使目标保持，[[AI/11-数学与统计桥梁/04-优化曲率条件数与AdamW#同一二维碗换坐标后为何走不同的路|新坐标中的普通梯度]]仍可能改变算法轨迹。

返程问题：调小一个数字残差、缩放矩阵列、改变传感器精度，分别作用在哪里？前两项改变表示、误差度量或求解算法，须检查是否仍为同一目标；第三项才改变实际测量误差。可逆行列尺度保留rank，无法修补缺回流支路或缺观测信息。故裸数值条件数、指定扰动下的问题敏感性、算法后向稳定、统计偏好和仪器误差须分别说明；本迁移不改既有 KCL、代码或实验结果。

## 函数、数组与断言的最小入门

函数把输入映射到输出；参数用单位后缀，让复算者知道填入的是Ω而非kΩ。下面是完整分压函数的核心（完整有限输入检查在实验源码）：

```python
def divider(vs_v, r1_ohm, r2_ohm, rl_ohm=None):
    lower = r2_ohm if rl_ohm is None else 1/(1/r2_ohm+1/rl_ohm)
    return vs_v*lower/(r1_ohm+lower)
values_v = [divider(5, 4000, 1000, load) for load in [None, 1000, 4000, 10000]]
assert abs(values_v[2] - 5/6) < 1e-12
```

None表示负载开路，不用某个巨大数假装∞；list依次保存四个场景结果，索引从0开始，values_v[2]对应第三个场景RL4 kΩ。结果[1,5/9,5/6,25/27] V。assert检查误差阈值，失败必须查式子、单位、输入或假设，不能删断言变绿。有限浮点数不能要求所有十进制分数严格等于；5/6的精确有理检查可用Fraction，数值残差则给明确容差。

矩阵可用numpy数组表达：Y=np.array([[.0015,−.001],[−.001,.0015]])，b=np.array([.001,0])，v=np.linalg.solve(Y,b)。[NumPy solve文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)规定方阵且满秩，奇异/非方阵会报错；求解线性系统直接solve，通常不先显式构造逆矩阵；检查Y.shape==(2,2)、b.shape==(2,)及残差Y@v−b。@是矩阵乘法，*在numpy上是逐元素乘法，两者不是同一操作。本组源码从单位字段到预测JSON/CSV完整对应，见 [[电子电路/80-实践/07-读数单位与计算桥/README|复算入口]]；脚本不能独立证明接线/模型正确。

## 练习与理由

1. 上例注入改2 mA，节点电压与功率如何？答案v_a2.4 V、v_b1.6 V，电压电流加倍，功率4倍；这是线性量与平方量区别。
2. 把两个到地电阻全部去掉并只从a注入1 mA，有解吗？答案无稳态解，因为两KCL相加要求净注入0；指定参考也不能凭空创造回流支路。
3. Y@v−b很小能证明v误差小吗？答案需同时查尺度和条件数，小残差可被小特征值方向放大；上文范数界有可逆/非零右端条件。
4. 给divider的r1传4、r2传1000，称它仍是4 kΩ/1 kΩ可吗？答案不可，字段要求Ω，输出将近5 V；单位后缀不是自动单位系统。
5. 归一化把κ变小就能证明真实实验不敏感吗？答案不可，尺度改变数字扰动的意义；必须把实际输入/元件误差映射成指定无量纲扰动，再评价输出。
