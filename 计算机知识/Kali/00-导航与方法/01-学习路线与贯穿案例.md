# 学习路线与贯穿案例

## 用能力检查点而不是篇数安排进度

阅读顺序是为了减少“会复制却无法诊断”的情况。每段都要求一个可观察能力，但不替你设定学时或填完成率。工具没有安装时，可以先完成机制与离线部分；不要把未运行标成通过。

### 阶段一：会保护实验环境

阅读 [[计算机知识/Kali/01-系统与网络基础/01-Kali定位与安装校验|Kali定位]] → [[计算机知识/Kali/01-系统与网络基础/02-虚拟机快照与网络隔离|虚拟机隔离]] → [[计算机知识/Kali/01-系统与网络基础/03-APT软件源与Python环境|软件管理]] → [[计算机知识/Kali/01-系统与网络基础/04-Shell文件权限与文本处理|Shell权限]] → [[计算机知识/Kali/01-系统与网络基础/05-进程服务日志与本机加固|进程与日志]]。能解释“快照不是独立备份”“NAT不是全部隔离”“命令字符串先由Shell解析”；能找出由自己启动的进程而不误停其他服务。用 [[计算机知识/Kali/00-导航与方法/06-命令阅读与故障定位|命令诊断]] 练习看退出码。

### 阶段二：把协议落到字节与状态

阅读 [[计算机知识/Kali/01-系统与网络基础/06-TCPIP路由DNS与TLS|TCP/IP]] → [[计算机知识/Kali/01-系统与网络基础/07-HTTP浏览器会话与信任边界|HTTP]] → [[计算机知识/Kali/02-信息收集与网络测量/03-Nmap主机发现与端口状态|端口状态]] → [[计算机知识/Kali/02-信息收集与网络测量/04-Nmap服务识别NSE与结果管理|服务识别]] → [[计算机知识/Kali/02-信息收集与网络测量/05-WiresharkTcpdump与Tshark|抓包]]。完成 [[计算机知识/Kali/07-综合实验/02-实验A从路由到HTTP与Nmap|实验A]] 或其纸面推演、[[计算机知识/Kali/07-综合实验/03-实验B抓包重组与证据交叉验证|实验B]]。检查点是解释为什么HTTP错误不等于TCP端口关闭、为何十帧只是一条连接、filtered为什么不能证明没有服务。

**进一步连接。** 阶段二增加 [[计算机知识/Kali/01-系统与网络基础/09-状态防火墙与网络命名空间|状态防火墙]]，然后用 [[计算机知识/Kali/07-综合实验/10-实验G路由与扫描状态推理|G]] 检查最长前缀和扫描推理，用 [[计算机知识/Kali/07-综合实验/11-实验H扫描XML差异与不确定性|H]] 检查未覆盖与未完成如何进入结论。应能在没有真实扫描工具时解释观测合同，再在授权环境验证具体实现。

阶段二先从 HTTP 正文手算缓存年龄，再到 curl/Burp 区分同一请求、不同身份和已经改变的对象状态。接着读 TLS 正文，完成 [[计算机知识/Kali/07-综合实验/14-实验K离线证书链与身份校验|K]]：预测每个案例是信任、名称、用途、时间还是签名失败。没有请求校验身份而成功，不应被写成“身份正确”。

### 阶段三：理解应用的信任边界

阅读 [[计算机知识/Kali/03-Web与API安全/01-Web测试模型与手工基线|Web模型]] → [[计算机知识/Kali/03-Web与API安全/02-curlHTTPie与接口重放|请求重放]] → [[计算机知识/Kali/03-Web与API安全/03-BurpSuite工作流|Burp]] / [[计算机知识/Kali/03-Web与API安全/04-ZAP代理与被动扫描|ZAP]] → [[计算机知识/Kali/03-Web与API安全/08-认证会话越权与API测试|对象授权]] → [[计算机知识/Kali/03-Web与API安全/06-SQL注入原理与sqlmap限界验证|SQL]] → [[计算机知识/Kali/03-Web与API安全/07-XSSCSRF与浏览器安全边界|浏览器边界]] → [[计算机知识/Kali/03-Web与API安全/09-SSRF路径上传与解析边界|服务端解析]]。完成 [[计算机知识/Kali/07-综合实验/04-实验CWeb请求与访问控制|实验C]]，能说明参数化和授权为何互不替代。然后再读 [[计算机知识/Kali/03-Web与API安全/05-ffufGobuster与内容发现|内容发现]] 与 [[计算机知识/Kali/03-Web与API安全/11-Web服务器CMS与依赖评估|服务评估]]，避免把枚举结果当作漏洞本身。

**进一步连接。** 阶段三在对象授权之后读 [[计算机知识/Kali/03-Web与API安全/12-现代API业务逻辑与并发边界|现代 API 与状态]]，完成 [[计算机知识/Kali/07-综合实验/12-实验I多租户字段与动作授权|I]]。v1 的 Alice17/Bob18 所有权模型与 I 的 `reasoning-v2.0` 是两套独立输入，不可混成一份对象历史。检查点是区分认证、对象读权限、字段投影、动作权限、状态转换和并发原子性。

阶段三沿 I 的对象政策进入 [[计算机知识/Kali/07-综合实验/15-实验L事务幂等与并发控制|L]]：解释状态版本为何进入条件更新；亲自比较写入前失败、事件写入失败后回滚、重复幂等键，以及被另一个连接占锁时的不同结果。L 从 I 相同初始定义独立初始化，不修改 I 夹具；原 A–F 的 Alice/Bob 示例仍是另一套模型。

### 阶段四：沿问题扩展，而不是同时学完所有工具

网络/企业环境路线：[[计算机知识/Kali/04-服务身份与主机评估/01-SSHFTPSMTP与SNMP服务|常见服务]] → [[计算机知识/Kali/04-服务身份与主机评估/02-SMBNFS与目录共享|共享]] → [[计算机知识/Kali/04-服务身份与主机评估/03-LDAPKerberos与AD基础|AD]] → [[计算机知识/Kali/04-服务身份与主机评估/04-ImpacketNetExec与身份评估|协议客户端]] → [[计算机知识/Kali/04-服务身份与主机评估/05-BloodHound权限图与修复验证|权限图]] → [[计算机知识/Kali/04-服务身份与主机评估/07-Linux权限边界与配置审计|Linux审计]] / [[计算机知识/Kali/04-服务身份与主机评估/08-Windows权限边界与本机审计|Windows审计]]。已有文档授权但没有靶机时只学习模型，不创建真实组织的数据采集任务。

**进一步连接。** 阶段四把 [[计算机知识/Kali/04-服务身份与主机评估/09-数据库服务与最小权限审计|数据库权限]] 接到服务与应用之间：能连接数据库不等于能读取任意表，有查询结果不等于应用已实施租户授权。

**进一步连接。** 阶段五增加 [[计算机知识/Kali/06-取证逆向与检测/09-模糊测试Sanitizer与崩溃归因|有界解析与检查器]] 和 [[计算机知识/Kali/07-综合实验/13-实验J时间线与检测基率|J]]，解释“未报错”“高熵”“高检出率”和“先发生”分别不能证明什么。

## 贯穿案例与不应混淆的层次

**服务案例**：仅回环8000端口的静态公开文件；解释连接和请求。**授权案例**：Alice拥有17、Bob拥有18；离线纯函数验证允许/拒绝。**查询案例**：临时SQLite只存Alice/Bob两行名字；解释语法与数据。**证据案例**：合成PCAP、日志和无害标记；解释不同观察单位。

它们在概念上相互连接，在来源上保持区分。一个真实应用会把这些层组合起来，但本包没有将它们包装为经过完整安全测试的Web靶场。

## 回到全局而不反复跳页

已有基础时从 [[计算机知识/Kali/00-导航与方法/07-问题驱动的工具选择与理论路线|问题驱动的理论路线]] 选择一条问题链，不必按版本号阅读。HTTP 的多组件解释接在浏览器基础之后，认证与对象权限接到事务之前，取证和检测都回到观察单位与证据来源。

正文会就地解释必要术语；[[计算机知识/Kali/08-模板与速查/05-术语与概念桥梁|术语桥梁]] 只用于回顾和比较，不要求连续打开五个定义才能读懂一段话。遇到不理解的命令先回 [[计算机知识/Kali/00-导航与方法/06-命令阅读与故障定位|命令阅读]]，遇到结论跳步先回 [[计算机知识/Kali/00-导航与方法/04-从观察到结论的安全方法|证据方法]]。每个分支最后都能通过 [[计算机知识/Kali/07-综合实验/08-自检题与答案定位|自检题]] 检查迁移，而不只是重复命令。
