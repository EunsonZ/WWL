# 差分多级与周期稳态：可复算模型

这里分别观察电流怎样分配、负载怎样改变增益、反馈电容怎样改变相位、输出管怎样取得电源能量，以及电容状态怎样从启动进入周期闭合。四个主题共用单位和端口定义，但不需要等待其他新章签收。程序的对象是正文中明确的教学模型；执行成功不能证明实际器件、硬件或学习效果。

从图进入：先识别每个源的正负端和回到参考的路径，按照正文用 KCL 写一次方程，再运行。由数学进入：先读源码中的输入限制，手算一个零频率、零差分或一个周期平均的极限，再比较 `results.json`。这两个入口都要求解释差异，不能仅复印测试输出。

## 文件与命令

`models.py` 是标准库数值真源；`build.py` 导入时不导入 NumPy、Matplotlib、CairoSVG 或 Pillow，不生成缓存或文件。运行构建时才加载 CairoSVG。`test_models.py` 用 NumPy 完整节点矩阵独立解线性系统；其他测试用解析积分、守恒和 RK4。没有 `code-sync` 镜像，也没有安装依赖的动作。

在本目录运行，输出选择库外绝对目录：

```bash
python -B -m unittest discover -s . -v
python -B build.py --output /private/tmp/wwl-amplifier2-run
```

`--output` 必填；程序拒绝候选根、其受 AGENTS 保护的祖先及主库中的输出位置。它生成六个原创可编辑 SVG、各 360/425 像素宽 PNG 和 `results.json`。生成图坐标为 425×360；360 宽版同比例缩放。PNG 是 SVG 的派生，不替代源。构建没有顶层字体缓存或全局 Matplotlib 修改。

所有真实标量 API 在 `float` 前拒绝 bool、复数、字符串、object、嵌套列表、NaN/Inf。`cgd_response_s` 单独允许有限复数 Laplace 变量，并在极点上报错。有限输入若中间量溢出也报错。`differential` 的 `ro=None` 专指忽略输出电导；数值 infinity 不是合法替代。`differential` 的 `ad_single/ac_single` 表示实际第一负载支路的增益；`ad_single_nominal/ac_single_nominal` 单独给匹配参考值，`ac_differential` 使用参考共模系数乘 $2\delta$。实际单端 CMRR 比在此失配模型中保持相同。

周期 RK4 只支持 $a\in[0,0.5]$ V、$\omega\tau\in[0.1,10]$、每圈 512…4096 步、容限 $10^{-9}$…$10^{-4}$ V；域外或要求超出支持精度在迭代前拒绝。每周期固定步数、最多固定周期，总步预算不超过百万；停滞或预算耗尽报错。它逐个比较返回采样状态与解析周期参考，第三返回值为“采样点相对解析参考的误差估计”（差值加保守浮点余量），不是单圈变化、严格舍入界或全时间区间证书。

极小幅度的功率可能下溢为浮点零；效率直接用 $\pi V_m/(4V_{CC})$ 计算，不通过已下溢的功率相除。零幅度效率零仍是约定。少数载流支路采用稳定小支路式，避免用近等电流相减；BJT 先合并 $\ln I_T-|v_d|/V_T-\ln(1+e^{-|v_d|/V_T})$ 再取指数，避免中间指数下溢吞掉最终可表示电流。

`coupling` 分别传播初始状态、直流源和正弦源贡献。短时源响应用原一阶 ODE 的 40 项固定预算增量级数；周期负载直接由独立交流坐标计算，不从两个大直流总量相减。返回的总电容电压若被大直流量支配，其微小纹波可能小于浮点分辨率；这不影响独立返回的可表示负载交流电压。数值 API 另限定 $10^{-150}\le\omega\tau\le10^{150}$、$|\omega t|\le10^{12}$、$t/\tau\le10^6$ 和两电阻比不超过 $10^{12}$；时间常数及正时间坐标必须可表示，域外前置 `ValueError`。这些是教学求值域，不是一般 ODE 的物理限制。谐波先归一为 $1/(1+x^2)$、$x/(1+x^2)$、$x^2/(1+x^2)$ 再乘幅度；大衰减以 $\ln|V|-t/\tau$ 合并缩放后取指数，避免中间量先下溢吞掉最终可表示状态。

表中 RK4 结果绑定本次参数与采样误差限。单圈映射若 $v_{next}=\rho v+b$，到固定点的距离与单圈变化之比为 $1/(1-\rho)$，慢系统可以每圈几乎不动却离周期状态很远；因此这里不以圈差作为误差证书。最后一行是持续饱和候选解，程序逐样本算余量；超出饱和不自动切换器件区域。更大 C 会使收敛更慢，默认预算并不保证所有合法参数都能收敛。

- `differential.svg`：尾源、两漏负载、两输入源及双电源返回完整；宣告源体相连的 MOS 教学符号，未画器件截面和实际衬底。
- `cascade.svg`：上方单向两端口负载模型和下方 CS–CG 连接，中间节点及两偏置源都有返回。顶层等效受控电压源不代表真实放大器的电源/限流。
- `cgd.svg`：两节点全部电阻、电容、跨导受控源与信号源。兑现完整双节点分析；没有声称全器件寄生模型。
- `output.svg`：电阻负载 A 共射拓扑和 B/AB 互补发射极拓扑，明确参考、双轨、负载、两基极驱动及发射极电阻。偏置源是理想驱动，不是可直接装配的温度补偿电路。
- `coupling.svg`：戴维南源—Rs—C—RL 的闭合路径，电容两端状态极性。
- `periodic.svg`：固定 0…10 ms 横轴、漏电压纵轴，实线有限 C 周期解、虚线冻结旧状态；只用于本教学参数的对照。

本轮实际查看六图的 360/425 正常、灰度和反色深色预览。反色预览检验对比与线型，不证明 Obsidian 客户端深色渲染；图自身有白底。未实施 SPICE、真实频响/THD/热测试、硬件、客户端 UI、人的阅读效果或掌握度验证。图信用只限这些明确的模型和局部阅读条件。

## 判断题

1. 单圈变化小是否足以证明周期状态或持续饱和？不够，慢系统的固定点误差可以大；逐样本参考比较仍不能排除采样间的极窄工作区越界。
2. 两节点矩阵与闭式一致是否证明 Miller 近似准确？不够，近似需独立比较极点、零点及工作频段。
3. 热环增益小于一是否证明真实硬件稳定？不够，它只说明单温度线性假设下的局部性质；实际热路径和偏置跟踪须另验。
4. 迁移：更换负载后优先重算什么？直流工作点、峰值电流与余量、实际小信号负载、状态时间常数，而不是只改一个增益数。
