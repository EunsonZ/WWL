# 模与有限群表示课程

为什么整数关系不能像向量空间一样随意选补空间？为什么一个矩阵能对角化，却不能让一个群的全部作用同时对角化？本课程把这两个问题接到已有 Smith、群作用和 Galois 主线。

这是高年级的有限分支：目标是一般模语言、PID 上有限生成模与复数有限群表示的结构，包含整数同调和周期卷积的数学接口。一般环的分类、诱导表示与无限维表示需要继续发展，不能无条件套用本课。

## 先修与已有主解释

先熟悉基、线性映射、核与商、矩阵乘法。环与 PID 条件从 [[数学/25-高等代数/12-环理想商环与同态基本定理|环理想商]]、[[数学/25-高等代数/16-整环Euclid域PID与唯一分解|PID 与分解]] 进入。已有 [[数学/25-高等代数/07-多项式矩阵Smith标准形与有理标准形#从 $tI-A$ 到有理标准形|F[t] 呈示到循环分解]] 继续作为该算子分类的主解释，不复制维护其完整证明。

表示支线另需 [[数学/25-高等代数/15-有限群Cauchy与Sylow计数#S3 与 D4：陪集存在，乘法还要过一关|S3 的群运算]]。Galois 先修并非本课程全部定理的条件；熟悉者可把 [[数学/25-高等代数/30-Galois理论/05-双二次扩张与S3全部对应#六个子群对应六个中间域|三个根的 S3 对称性]] 转为根标签的置换表示。

## 连续解释与计算

1. [[数学/25-高等代数/50-模与有限群表示/01-模同态正合列与PID结构|模、同态、正合列与 PID 结构]]：从自由、挠与商到短正合列；证明一般 PID Smith 存在性及有限生成模分类，并给条件失败的反例。
2. [[数学/25-高等代数/50-模与有限群表示/02-整数Smith核像商与同调接口|整数 Smith 的核、像、商]]：固定左右变换及回原坐标的方向，先求整数核再在其中取商，解释有理化为何丢挠。
3. [[数学/25-高等代数/50-模与有限群表示/03-S3表示Maschke与Schur引理|表示、Maschke 与 Schur]]：用 S3 同一套基分出平凡与二维标准表示，证明平均投影和交织引理，区分域特征与代数闭条件。
4. [[数学/25-高等代数/50-模与有限群表示/04-特征标正交与S3分解|特征标正交与分解]]：从交织空间的平均投影推导正交、重数、完整性和维数平方和，再计算 S3 与张量积。
5. [[数学/25-高等代数/50-模与有限群表示/05-循环移位Fourier基与对称性合同|循环移位、Fourier 基与对称性]]：把循环群的一维分量算成 DFT，说明周期、零填充、反射边界及两种模型重编号的作用对象。
6. [[数学/25-高等代数/50-模与有限群表示/06-整数Smith与表示精确复算|整数 Smith 与表示复算]]：携带完整左右变换的精确源码、固定输入及独立预期答案；实际运行状态从该页接口说明区分。

## 用改变条件检验掌握

- 在 Z 上比较 Z/6、Z²、乘 2 的核像商；换到 Q，说明哪个挠分量消失及为什么。再把基础环改成 F[t]，由多项式关系读出循环算子块，不能把整数阶和多项式次数混为一个数值标准形。
- 为 S3 的 r、s 写矩阵并核对右侧先作用；在同一套基中分块，再算加权特征标内积。删去群阶可逆条件，解释 Jordan 反例在哪里阻止平均投影。
- 固定 n=3 算循环移位三条特征线；加入换位，说明为何两条线只能作为一个二维块。改变周期长度或边界条件时，先重新指定空间及算子。

答案在各课的同名迁移题中。模型走读和计算输出都不能代填真人掌握程度。
