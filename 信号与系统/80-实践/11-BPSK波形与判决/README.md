# BPSK波形、采样账与先验判决

要核的是“物理波形积分出的一个数”，而非数组越长看上去越平滑。先读[[信号与系统/50-通信与反演/01-数字通信波形检测同步与均衡|通信主解释]]，把 $p$ 的单位能量、实双边 $N_0/2$、理想同步、位1→正号和等代价条件带来；本实验不另立噪声约定。

## 输入、单位与有限预算

[fixed-inputs.json](fixed-inputs.json) 是唯一运行输入卡：$E_b=10^{-6}$ J，$N_0=5\times10^{-7}$ J，$T=10^{-3}$ s，网格4与16，发送先验 $\pi_+=0.5,0.9$，每先验每seed 100000次发送。基础seed为181、20261016；第 $j=0,1$ 个先验用 `seed+j*1000000007` 建立独立 `random.Random` 流，故实际seed分别为181、20261016和1000000188、1020261023，输出逐行保留实际seed。每次先以 uniform 抽发送正负，再产生16个Gaussian小格平均噪声。独立是概率模型假设；PRNG是其有限可重复实现，不声称数学独立随机源认证。

矩形脉冲每格 $p_i=1/\sqrt T$，小格平均噪声方差为 $N_0/(2\Delta t)$；4格噪声是同一16格噪声每4格平均，两个统计量使用 $Y=\Delta t\sum r_i p_i$。这是一对相关的网格观察，不是两个独立重复样本。两seed提供两个独立流的有限重复；每先验各200000实现，整组400000实现。输出按两网格各写一行，共8行MC，不能把成对重复算成800000次独立试验。

输入卡还给16个确定噪声幅值（$\sqrt{\mathrm W}$），用于逐格追踪积分；它们是人为有限向量，不声称服从Gaussian，也不用来估计噪声方差。码字账本固定消费网络1101→1101001；没有新写CRC实现，也没有随机帧蒙特卡洛。

[bpsk_lab.py](bpsk_lab.py) 是规范源码，[test_bpsk_lab.py](test_bpsk_lab.py) 是作者回归检查，[plot_bpsk.py](plot_bpsk.py) 从完成的结果及其输入生成图；三个文件都只需Python 3.10+标准库，无网络、设备、NumPy或额外安装。默认单进程、单线程；固定输入每次运行约数秒，本批预先限定每次180秒、全组3分钟；读者可在自己的进程管理器设时限。

## 运行前声明的预期与失败判据

**能量、噪声与阈值是高重要性**：单位或因子2错误会直接改变BER结论，并且更细采样可能制造虚假收益。**有限MC是中重要性**：它帮助定位实现偏差，无法证明任意长度、真实噪声或硬件行为。正文密度推导与积分协方差是一手理论依据；作者函数的输出不能自封为独立oracle。

事先预期由正文两密度及小格平均的解析协方差决定：

- 两网格 $\Delta t\sum p_i^2=1$；$\Delta t\sum s_i^2=10^{-6}$ J；投影噪声方差 $2.5\times10^{-7}$ J。数值自查相对容差 $10^{-12}$，脉冲能量绝对容差 $10^{-12}$。固定16格噪声总和0.05 $\sqrt{\mathrm W}$，所以两网格 $Y=0.001098821176880262\sqrt{\mathrm J}$；网格差不得超过 $10^{-12}\sqrt{E_b}$。
- 网格4/16的每格噪声方差为0.001/0.004 W；投影方差相同。把每格方差错误固定0.001 W，两个投影方差却是 $2.5\times10^{-7}$ 与 $6.25\times10^{-8}$ J。这是故意错误模型的解析反例，不另用MC浪费运行量。
- $\pi_+=0.5$：阈值0，两个条件率与总体率均 $Q(2)=0.0227501319482$。$\pi_+=0.9$：阈值 $-0.000274653072167\sqrt{\mathrm J}$，正/负条件错误率约0.00539687505913与0.0734325635795，总体约0.0122004439112；若保持零阈值，总体仍0.0227501319482。
- 每种条件/总体错误计数的事先诊断容差为 $|k-np|\le6\sqrt{np(1-p)}+2$，条件项的 $n$ 用本次实际正/负发送数，整体项用100000。它是宽的二项波动诊断带，不是严格分布无关覆盖保证；通过不能证明PRNG或理论正确，失败须保全结果、检查归一化/实现/模型，而非换seed刷通过。
- 投影噪声均值诊断 $|\bar W|\le6\sqrt{v/n}$、总体分母样本方差 $|\widehat v-v|\le6v\sqrt{2/n}$，其中 $v=N_0/2,n=100000$。16格中第0、1格经验协方差满足 $|\widehat{\mathrm{Cov}}(n_0,n_1)|\le6v_{\rm cell}/\sqrt n$，理论值0。这些是正态大样本尺度的预设诊断，不是对每一次运行的确定保证，也没有检查全部16×16经验矩阵。
- 同一次实现两网格 $Y$ 的最大绝对差须 $\le10^{-12}\sqrt{E_b}$，判决计数须相同。此项只核聚合/积分的实现恒等式；**噪声总体方差由解析协方差和MC方差诊断另外核对**，不拿共享同一噪声自证其分布。

输入显式限制正有限物理量、两个递增整除网格(2至64)、1至4个不同uint32基础seed、先验0.05至0.95、每流10000至100000符号、总独立实现至多800000。全部 `seed+j*1000000007` 派生seed还须跨先验组合唯一；例如基础seeds `[181,1000000188]` 在两个先验时会派生重复1000000188，显式拒绝，不能把它称为独立流。有限噪声向量与细网格同长且每幅绝对值≤1。bool不当计数，NaN、非正量、非整除网格及越界量拒绝；`python -O`不会移除这些 `ValueError` 检查。限制是运行预算/接口范围，不是通信定理的定义域；更换卡片可能改变误码稀有程度及诊断带的适用性。

每行的两个网格计数相同；MC表完整保存网格、样本分母、理论率、容差、投影均值/方差和相邻格协方差。四流投影方差约 $2.49145$ 至 $2.50710\times10^{-7}$ J，目标为 $2.5\times10^{-7}$ J；成对网格最大 $Y$ 差约 $8.67\times10^{-19}\sqrt{\mathrm J}$，小于事先容差 $10^{-15}\sqrt{\mathrm J}$。先验0.9下，总体错误下降同时少数负号更容易被判错；用总体一栏不能代替负号一栏。

## 改一个条件，先预测再执行

把先验0.9换为0.1：先不运行，写出两个条件错误率应交换、总体率应相同；再改输入到新目录核对。把网格改为8、32时，先把固定噪声向量改成32格、明确其与旧16格是否同一实现；不允许把新向量叫作同一物理噪声。正负映射若换向，发送序列、判决映射、先验含义也须一起换。改变有限噪声向量只改变确定性示例，不改变Gaussian MC的统计模型。

## 独立核查、硬件接口与未验层

本目录的回归检查与正式MC执行由作者完成。非作者随后从两密度与小格积分独推阈值、条件/总体BER及噪声协方差，以未导入作者函数的计算核对，并检查有限结果与接口；最终逐项结论由该批独核/接收记录承担。作者回归与独立核查是两层证据。

RF、同步与多径的硬件验证是**高重要性**：错误参考面、时钟或失配会使整条BER解释无效。保留以下接口供以后获授权测量，本实验不连接设备：

| 需记录 | 为什么缺它不能把硬件曲线接回本页 |
| --- | --- |
| 发送/接收参考面、阻抗、负载/可用功率、增益与校准 | 发射 $E_b$ 不能和接收 $N_0$ 直接拼比值 |
| 噪声PSD单/双边、SSB/DSB、实/复分量、模拟滤波及等效带宽 | $N_0/2$ 与测得噪声总功率之间有具体积分和尺度 |
| symbol/s、sample/s、脉冲及已知位序列/映射 | 确定采样时间、积分对象和每符号能量 |
| 对齐位置、载波/定时估计、训练数据与独立评测数据 | 理想已知参数的判决不能认证同步算法 |
