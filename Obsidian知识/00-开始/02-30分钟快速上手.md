# 30 分钟快速上手

这条路线不追求讲完所有按钮，而是在半小时内走通 Obsidian 最有代表性的闭环：**写一篇 Markdown → 建立链接 → 添加结构化属性 → 观察反向链接 → 用 Canvas 和 Base 换一种视角查看同一批内容。**

## 0–5 分钟：打开、写作、预览

1. 打开 [[Obsidian知识/30-实践/01-实验区/Markdown/01-自由草稿纸|自由草稿纸]]。
2. 输入一个标题、一段正文和下面的清单：

   ```markdown
   ## 我想用 Obsidian 做什么
   - [ ] 记录灵感
   - [ ] 整理项目
   - [ ] 建立自己的知识网络
   ```

3. 在实时预览与阅读视图间切换。

深入学习：[[Obsidian知识/10-基础/01-Markdown基础/01-基础排版|基础排版]]、[[Obsidian知识/10-基础/01-Markdown基础/02-列表任务与表格|02-列表任务与表格]]。

## 5–10 分钟：建立两条链接

在第一篇笔记中加入：

```markdown
我正在体验 [[Obsidian知识/10-基础/02-链接与知识网络/01-Wikilink、别名与未解析链接|Wikilink]]，
并参考示例项目 [[00-周末读书会项目主页|周末读书会]]。
```

点击其中一条链接，再打开右侧反向链接面板。你刚才只编辑了一篇笔记，但目标页已经能看到“谁提到了我”。

## 10–15 分钟：添加属性和标签

回到第一篇笔记，在文档顶部添加或通过 Properties 视图填写：

```yaml
---
type: experiment
status: doing
topics:
  - obsidian
rating: 5
tags:
  - playground/exercise
---
```

然后打开 [[Obsidian知识/40-视图/02-Bases/课程进度.base|课程进度]] 或 [[Obsidian知识/40-视图/02-Bases/示例笔记目录.base|示例笔记目录]]，观察属性怎样把文件变成可筛选的数据。

深入学习：[[Obsidian知识/10-基础/03-属性标签与检索/01-属性类型|属性类型]]、[[Obsidian知识/10-基础/03-属性标签与检索/02-嵌套标签|嵌套标签]]、[[Obsidian知识/20-功能/01-官方插件实验室/05-Bases|05-Bases]]。

## 15–20 分钟：链接到一段，而不只是整篇

打开 [[Obsidian知识/30-实践/03-示例项目/周末读书会/概念/双向链接|双向链接]]，找到带 block ID 的定义段，复制其块链接并在第一篇笔记中嵌入：

```markdown
![[Obsidian知识/30-实践/03-示例项目/周末读书会/概念/双向链接#^definition-bidirectional-link]]
```

如果示例页使用了不同的 block ID，就通过“复制块链接”取得实际值。修改原定义后，所有嵌入位置会一起更新。

深入学习：[[Obsidian知识/10-基础/02-链接与知识网络/02-标题链接、块链接与嵌入|标题链接、块链接与嵌入]]。

## 20–25 分钟：观察图谱与 Canvas

1. 从当前笔记打开局部图谱。
2. 把深度设为 2，观察项目、课程和概念如何出现。
3. 打开 [[Obsidian知识/40-视图/01-Canvas/链接网络演示.canvas|链接网络演示]]，比较图谱自动生成的关系和 Canvas 人工表达的关系。

深入学习：[[Obsidian知识/10-基础/02-链接与知识网络/04-全局图谱与局部图谱|全局图谱与局部图谱]]、[[Obsidian知识/20-功能/01-官方插件实验室/04-Canvas|Canvas]]。

## 25–30 分钟：连接一个时间入口

先打开本练习库已有的 [[Obsidian知识/30-实践/02-日记/2026-08-30|日记样例]]，观察一篇日记怎样链接到项目与概念。然后在自己的草稿中加入一条日期复盘。

如果你已经确认这个 Vault 的 Daily Notes 目录、日期格式和模板都符合预期，再通过命令面板运行“打开今天的日记”。首次运行可能创建文件；不想创建新文件时，只做上面的样例阅读即可。

```markdown
今天完成了 [[Obsidian知识/30-实践/01-实验区/Markdown/01-自由草稿纸|自由草稿纸]]。

> [!reflection] 一句话复盘
> 链接、属性或视图中，最让我意外的是……
```

深入学习：[[Obsidian知识/20-功能/01-官方插件实验室/03-Daily Notes|Daily Notes]]、[[Obsidian知识/20-功能/03-完整工作流/02-每日计划任务与复盘|02-每日计划任务与复盘]]。

> [!success] 半小时通关标准
> - 你创建或编辑了一篇 Markdown。
> - 它至少链接到两篇现有笔记。
> - 它至少有三个属性和一个标签。
> - 你检查过反向链接和局部图谱。
> - 你打开过一个 Canvas、一个 Base 和一篇日记（样例或自己确认后创建的今日笔记）。
