## 可复核证据

`integration_test_results.json` 保留综合测试名、实际工具版本、编译命令和输出；`original_course_test_results.json` 保留原课程逐组输出；`cpp_course_build.log` 保留 CMake 构建及 CTest 日志。所有文件位于本 `_meta/` 目录。

从 `_labs/` 目录执行 `python3 integration/run_all.py --report ../_meta/integration_test_results.json` 可复查综合实验。它按实际工具可用性分别标记通过、失败或跳过，不自动下载依赖。原包 Python 测试须从各自实验目录运行 `python3 -B test_对应名称.py`。

## 结果不能证明什么

SQLite 结果不代替 PostgreSQL 所有隔离语义；队列、缓存、页表与调度教学模型不是真实硬件内核；分帧模型不等于实现和验证完整 TCP；有限随机差分不代替算法证明。所有 Markdown 代码块没有全部执行，未执行分区、格式化、驱动更换或外网压力测试。
