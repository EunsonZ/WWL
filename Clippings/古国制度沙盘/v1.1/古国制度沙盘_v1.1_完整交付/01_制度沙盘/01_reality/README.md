# Reality：现实制度基线与来源索引

本目录用于保存截至 2026-08-18 核对的中国大陆现实制度基线。它是古国改革设计的参照库，不是法规汇编，也不代表对制度实际运行效果作出未经证据支持的结论。

## 编写规则

1. 只使用原创摘要，不收录整部法规、政策或长段原文。
2. 优先链接全国人大、政府部门、司法机关和国家行政法规库等一手来源。
3. 明确区分已施行法律法规、政策规划、试点、已通过未施行文本和征求意见稿。
4. “可观察约束”和“信息缺口”是研究问题，不冒充官方结论。
5. Reality 中的现实专名不得直接移入古国制度文件；改革目录只使用抽象问题和原创虚构名称。

## 核对方法

每份文件记录核对日、制度状态、主要接口、可能影响改革可行性的约束及官方来源。若来源在核对日后更新，应重新判断制度状态，不能只替换链接。
