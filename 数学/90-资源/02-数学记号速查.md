# 数学记号速查

速查的目标是把符号还原成“对象、shape、作用范围和条件”。若需要定义与推导，返回 [[数学/03-数学符号表]] 或对应学科课程。

## 先问四个问题

读任何公式前先写出：

1. 每个符号表示标量、向量、矩阵、张量，还是集合/随机变量？
2. 每个轴表示 batch、token、head、feature，还是别的语义？
3. 哪些索引被求和消去，哪些轴保留到输出？
4. 等式成立需要哪些条件，例如概率和为 1、维度可乘、分母非零或函数可导？

## 常见对象

| 记号 | 通常表示 | LLM 中常见例子 |
| --- | --- | --- |
| $x\in\mathbb{R}$ | 标量 | 单个 loss、temperature |
| $x\in\mathbb{R}^{d}$ | 长度 $d$ 的向量 | 一个 token 的 embedding |
| $X\in\mathbb{R}^{n\times d}$ | 矩阵 | $n$ 个 token 的隐藏状态 |
| $X\in\mathbb{R}^{b\times h\times n\times d_h}$ | 四阶张量 | batch、head、token、head dimension |
| $p\in\Delta^{V-1}$ | $V$ 类概率单纯形上的向量 | 词表上的 next-token 分布 |

## 线性代数

| 记号 | 含义 | 核对 |
| --- | --- | --- |
| $A^{\mathsf T}$ | 转置 | 轴是否真的只交换最后两维 |
| $AB$ | 矩阵乘法 | $A$ 的末维必须等于 $B$ 的倒数第二维 |
| $x^{\mathsf T}y$ | 点积 | 两个向量处在同一坐标空间 |
| $\lVert x\rVert_2$ | 二范数 | 是否可能为 0 |
| $\cos(x,y)$ | 余弦相似度 | 分母非零，是否预先归一化 |
| $U\Sigma V^{\mathsf T}$ | SVD | 截断秩、奇异值顺序和误差范数 |
| $P=P^2=P^{\mathsf T}$ | 正交投影矩阵 | 对称和幂等缺一不可 |

课程：[[数学/20-线性代数与几何/00-线性代数与几何-MOC]]。

## 概率、统计与信息论

| 记号 | 含义 | 核对 |
| --- | --- | --- |
| $P(X=x)$ | 离散事件概率 | 非负且全体求和为 1 |
| $p(x\mid y)$ | 条件分布 | 条件事件/密度定义域有效 |
| $\mathbb E[X]$ | 期望 | 对谁的分布取平均 |
| $\operatorname{Var}(X)$ | 方差 | 单位是原单位的平方 |
| $\ell=-\log p(y)$ | 单样本 NLL | 对数底和聚合单位 |
| $H(P,Q)$ | 交叉熵 | 第一个参数是目标/来源分布，第二个是模型分布 |
| $D_{\mathrm{KL}}(P\Vert Q)$ | 从 $P$ 到 $Q$ 的有向 KL | 顺序不可交换；$Q=0,P>0$ 时发散 |

课程：[[数学/30-概率与统计/00-概率与统计-MOC]]、[[数学/50-信息论/00-信息论-MOC]]。

## 微积分与优化

| 记号 | 含义 | 核对 |
| --- | --- | --- |
| $\frac{df}{dx}$ | 单变量导数 | 评价点和局部性 |
| $\frac{\partial f}{\partial x_i}$ | 多变量函数对一维的偏导 | 其余变量暂时固定 |
| $\nabla_x f$ | 标量输出对向量输入的梯度 | shape 与 $x$ 相同 |
| $J_f(x)$ | 向量函数的 Jacobian | 行列约定必须声明 |
| $v^{\mathsf T}J$ / $Jv$ | VJP / JVP | 乘法方向和输出 shape |
| $\theta_{t+1}=\theta_t-\eta g_t$ | 最基本梯度更新 | 学习率、梯度定义和参数组 |

课程：[[数学/40-微积分与优化/00-微积分与优化-MOC]]。

## 数值与量化

| 记号 | 含义 | 核对 |
| --- | --- | --- |
| $\operatorname{softmax}(z)_i$ | 指数归一化 | 先减最大值，处理全 mask 行 |
| $\operatorname{LSE}(z)$ | `log(sum(exp(z)))` | 使用稳定形式 |
| $q=\operatorname{round}(x/s)+z$ | 仿射量化的编码直觉 | scale $s>0$、zero point 范围、截断 |
| $\hat x=s(q-z)$ | 反量化 | 误差来自舍入、截断和分组共享参数 |
| $\epsilon_{\text{machine}}$ | 机器精度尺度 | 不等于任何计算的统一相对误差上界 |

课程：[[数学/60-数值计算与量化/00-数值计算与量化-MOC]]。

## 练习与成功标准

给定 Attention 形状 $Q,K\in\mathbb R^{b\times h\times n\times d_h}$，写出 $QK^{\mathsf T}$ 的 shape，并指出被收缩的轴。成功标准是得到 $b\times h\times n\times n$，并能解释两个 $n$ 分别代表 query 位置和 key 位置。
