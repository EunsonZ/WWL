# 旋转与受驱复算

这个实践回答两件事：角动量标签能否给出完整的测量分布，以及受驱模型里的近似误差能否与数值误差分开。先完成下面的手算，再运行 [rotation_drive.py](rotation_drive.py)。程序是单线程 Python 标准库，不需要 NumPy，不下载包，不接真实量子设备；它只写本目录 `assets/checks.json` 与同方程的 `assets/rwa-comparison.svg`。

## 先给预测，再看程序

| 问题 | 手算出口 |
| --- | --- |
| $j=1$、基顺序 $m=(1,0,-1)$，用正文 $J_i/\hbar$ 相乘 | 三组 $[J_i,J_j]/\hbar^2=i\epsilon_{ijk}J_k/\hbar$，$J^2/\hbar^2=2I_3$ |
| 初态 $|1,0\rangle$ 经 $U_y(\pi/3)$ 后测 $J_z$ | 向量 $(-\sqrt{3/8},1/2,\sqrt{3/8})^T$，概率 $(3/8,1/4,3/8)$，均值零、方差 $3\hbar^2/4$ |
| 圆上 $u_n=e^{in\varphi}/\sqrt{2\pi}$，测势 $V_0\cos\varphi$ 的矩阵元 | 除 $n'=n\pm1$ 外为零，非零值 $V_0/2$；这是指定 Fourier 模式间的精确积分 |
| 自由转子 $I=10^{-46}$ kg·m² 的 $(u_1+u_{-1})/\sqrt2$ | 角密度 $(1+\cos2\varphi)/(2\pi)$ 归一，确定能量 $\hbar^2/(2I)=5.560608593\times10^{-23}$ J，角动量正负各半 |
| 圆偏振模型 $\Delta=\Omega$、$t=\pi/\Omega$ | $P_+=\frac12\sin^2(\pi/\sqrt2)\approx0.3165638355$；最大转移率仅 $1/2$ |
| 共振短时一阶微扰到 $\pi$ 脉冲时间 | 一阶给 $\pi^2/4\approx2.4674$，精确圆偏振给一，概率越界暴露长时展开失效 |

线偏振的强驱动差异没有用手算随意指定数值：先写明完整模型 $H_l/(\hbar\omega_0)=(\sigma_z+2\epsilon\cos\tau\,\sigma_x)/2$，再用下列收敛比较测它与 RWA 的差。这里 $\tau=\omega_0t$、$\epsilon=\Omega/\omega_0$，把物理时间尺度与无量纲计算分开。

## 小程序计算的接口与误差

有限矩阵的形状分别为 $3\times3$ 与 $2\times2$，向量长度三和二；共轭转置由 `dagger` 显式计算。自旋一的指数利用 $K^3=K$ 计算后与手算向量比较，未调用本征求解器。自旋半 $2\pi$ 检查用同一个 Pauli 指数实际作用于向量，得到负号；它只检查本表示，不证明一般覆盖群理论。

圆坐标用 1024 个等距周期点积分 $n,n'=-2,\ldots,2$ 的 25 个矩阵元；这里不是把无限转子改成五维系统求完整谱。有限 Fourier 模的三角函数在此网格没有混叠，网格能准确复算这些有限频率积分，但未检查任意粗糙波函数或高模式截断尾。

含时演化每一步取 Hamiltonian 的中点值，使用准确 $2\times2$ 指数：若 $H/(\hbar\omega_0)=\mathbf b\cdot\boldsymbol\sigma/2$，其中 $\mathbf b$ 无量纲、$\delta\tau=\omega_0\delta t$，则

$$U_{\rm step}=\cos(|\mathbf b|\delta\tau/2)I
-i\sin(|\mathbf b|\delta\tau/2)\mathbf b\cdot\boldsymbol\sigma/|\mathbf b|.$$

每步酉，程序从不额外归一化。按时间先后逐步乘积，仍有冻结中点的离散误差；酉性和小范数漂移不能单独证明时间精度。每条曲线取 401 个观察点，$\Omega t$ 从零到 $2\pi$。观察点间分别取 50、100、200 个子步，连续减半步长；检查中/细概率差 $\le5\times10^{-6}$，并检查该差不超过粗/中差的 0.35 倍，对应本次二阶中点收敛。检查范数漂移 $\le10^{-10}$。这些是本例相关数值阈值，不是所有 Hamiltonian 的误差定理。

另用圆偏振的 $\epsilon=0.2$、$\omega/\omega_0=0.9$ 同例，比较完整数值态与准确 $R(t)U_R(t)|-z\rangle$，连实验室相位一起核对；仅比概率不能发现所有旋转符号错误。还在五个独立角度通过矩阵乘积核 $R^\dagger H R-i\hbar R^\dagger\dot R$，分别比圆偏振常量和线偏振快项。

## 本版实际结果

[checks.json](assets/checks.json) 是本源码实测，状态 `PASS`。有限自旋对易误差 $2.22\times10^{-16}$，$J^2$ 误差 $4.44\times10^{-16}$，旋转向量误差 $1.11\times10^{-16}$；圆坐标选择矩阵元误差 $4.12\times10^{-17}$。旋转框架矩阵恒等式误差 $1.56\times10^{-17}$，圆偏振实验室完整向量最大差 $1.30\times10^{-8}$。

线偏振共振对比固定 $\omega_0=2\pi\times1$ MHz，未将圆偏振式称为线偏振准确解：

| $\Omega/\omega_0$ | 窗口（μs） | 中/细最大概率差 | 与 RWA 的最大采样概率差 | 完整模型 $P_+(\pi/\Omega)$ |
| --- | --- | --- | --- | --- |
| 0.05 | 0–20 | $7.559\times10^{-7}$ | 0.01216395 | 0.99984352 |
| 0.2 | 0–5 | $4.968\times10^{-8}$ | 0.05399496 | 0.99743908 |
| 0.8 | 0–1.25 | $2.945\times10^{-9}$ | 0.21742138 | 0.97748502 |

“最大采样差”仅指这 401 个观察点，不是连续时间上确界或一般理论界。RWA 在共振 $\pi$ 计时一律预测一；表中实际值和全窗差说明何种观测能分辨这项近似。图取第一、第三行，蓝线来自细步长线偏振解、橙虚线来自 RWA 公式，参数与正文相同。
