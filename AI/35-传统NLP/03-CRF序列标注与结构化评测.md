# CRF 序列标注与结构化评测

本课回答：如果全部词已经观察到了，为何要给标签链打分、对整链归一；以及为何词标签正确率很高，实体识别仍然可能失败。这里使用线性链 CRF（条件随机场），并将输出按明确的 BIO2 协议解释成实体区间。

## 条件模型保留链，改变归一对象

HMM 给 $P(x,y)$，需规范化初始、每个状态转移行和发射行；CRF 直接给固定输入下的 $P(y\mid x)$。输入 x 可影响整条链上的特征，例如词形、前后词、大小写；不再需要为所有可能输入文本建生成概率。它仍限制输出标签之间的依赖，使线性链动态规划可用。

设标签数 L，输入长度 T；位置分数 $u_t(j;x)$ shape 为 $T\times L$，转移分数 $a(i,j)$ shape 为 $L\times L$，初始分数 $b(j)$ 长度 L。它们是无单位的实数分数，不是概率；可负，不要求行和 1。固定长度、无末尾附加项：

\[
s(x,y)=b(y_1)+\sum_{t=1}^T u_t(y_t;x)+\sum_{t=2}^T a(y_{t-1},y_t),
\quad Z(x)=\sum_{y\in\mathcal Y(x)}e^{s(x,y)},
\quad P(y\mid x)=e^{s(x,y)-\log Z(x)}.
\]

$\mathcal Y(x)$ 是本协议允许的标签链。给非法开始/转移 $-\infty$ 分数，使其指数权重为零。不能先对每个位置分别 softmax，再乘起来，声称已实现这套全局模型；转移耦合与配分函数会改变结果。另一方面，若全无输出耦合和约束，配分函数可以因子分解，这是独立分类的特殊情况。

训练对已知 gold 链最大化条件 log 似然 $s(x,y^*)-\log Z(x)$；梯度比较 gold 特征与模型特征期望。本课只推断人工分数，没有拟合权重、优化器或真实 NER 基准。HMM 与 CRF 都可以做序列 MAP 解码，不能据“条件模型”三个字断言效果更好。

## 两词 New York：五条合法链算到底

标签按 `O, B-LOC, I-LOC` 排列。本课使用严格 **BIO2**：每个实体第一词一定 B，后续为同类型 I；O 不在实体中。I-LOC 不能出现在第一词，也不能接在 O 后。B 可以紧接 B 或 I，以表示另一个实体。

位置分数如下，所有合法初始/转移分数为 0，非法处为 $-\infty$：

| 位置 | O | B-LOC | I-LOC |
| --- | ---: | ---: | ---: |
| New | 0 | ln 2 | 0（开始规则禁用） |
| York | 0 | 0 | ln 3 |

| 标签链 | 总分 | 指数权重 | 条件概率 |
| --- | ---: | ---: | ---: |
| O O | 0 | 1 | 1/12 |
| O B-LOC | 0 | 1 | 1/12 |
| B-LOC O | ln 2 | 2 | 2/12 |
| B-LOC B-LOC | ln 2 | 2 | 2/12 |
| B-LOC I-LOC | ln 6 | 6 | 6/12 |

另外四条三标签二词组合非法，权重为 0。因此 $Z(x)=12$，最佳链 B-LOC I-LOC 概率 .5。九条链都加进配分函数，会给非法实体质量，成为另一套协议。

动态规划用 log-space：$F_1(j)=b(j)+u_1(j)$，

\[
F_t(j)=u_t(j)+\operatorname{LSE}_i[F_{t-1}(i)+a(i,j)],\qquad
\log Z=\operatorname{LSE}_j F_T(j).
\]

此例把 exp 后的权重列出来更容易跟算：首列 `(1,2,0)`，第二列 `(3,3,6)`，列和 12。例如第 2 格 I 只能接第 1 格 B，得 $2\times3=6$；O 则从首列 O 与 B 收到 $1+2=3$。将 LSE 改为 max、保留回溯指针，即得序列 MAP；固定 x 的 Z 对所有链相同，不影响最佳链排序。后向递推和标签后验可复用上一课同结构的 log-space 算法，但数值是 CRF 权重，并非 HMM 发射概率。

## 从 BIO2 链到实体：边界是答案的一部分

将实体表示为 `(start, end_exclusive, type)`，索引从 0 开始、末端不含。例如 `B-LOC I-LOC O` 得 `(0,2,LOC)`。`B-LOC B-LOC` 得两个相邻实体 `(0,1,LOC)` 与 `(1,2,LOC)`，不能合成一个。评测匹配还要包含句子 ID，避免不同句子相同偏移被当作同一个实体。

十词例：`New York is a city I visited last spring .`，gold 为 `B-LOC I-LOC O O O O O O O O`，预测为 `B-LOC O O O O O O O O O`。9/10 token 标签正确，但 gold `(0,2,LOC)` 与预测 `(0,1,LOC)` 没有精确匹配，故 TP=0、FP=1、FN=1，实体 P、R、F1 都为 0。同一边界而类型 LOC/ORG 不同也算一个 FP 与一个 FN。用字符跨度时必须另行固定字符/字节/Unicode 偏移协议。

本实验按所有句子汇总计数后算 micro 实体指标，通用 P/R/F1 的定义与类别不平衡讨论复用 [[AI/10-机器学习与深度学习基础/10-基线指标阈值误差分析与分布偏移#从混淆矩阵理解指标|已有评测课]]。无 gold 且无预测时本实验的实体 P/R/F1 约定为 0；无 token 时 token accuracy 为 `None`，不伪造 100%。这只是明确的零分母报告约定，真实基准须核对其实现。

非法 BIO2 输入如 `I-LOC` 开头、`O I-LOC`、`B-PER I-LOC` 一律报错，先解决协议再评分，不悄悄纠正成 B。CoNLL-2003 原始数据描述采用 IOB 的历史编码，I 可开始一个实体、B 用于相邻同类型实体的区分；不能把原始标签直接送入本页严格 BIO2 校验。必须先按原协议解析并转换，同时保留转换测试。其论文的**实体完整类型与边界精确匹配**思想与本页一致，编码细节另行处理。

## 边界与反例

线性 BIO2 适合不重叠、非嵌套实体；`[ORG [LOC New York] University]` 若要求两层都标注，一个标签序列不够。词级模型对分词错误也敏感：若 NewYork 被合成一词，旧 token 区间会改变，比较前必须统一单位。普通 CRF 读取未来输入不等于可在线零等待处理；流式约束需要另定输入可见性。

## 跟算练习与答案

1. 第一词 B 后，第二词是 I 的边缘后验是多少？答案：固定整句后验 $P(y_2=I)=6/12=.5$；若额外条件 $y_1=B$，则为 $6/(2+2+6)=.6$，两者不同。
2. 每个位置分数统一加 1000，路径概率变吗？答案：每链总分加 2000，log Z 同加 2000，相减后不变；直接 exp(2000) 会溢出，所以用 log-space。
3. gold `B-X I-X`，预测 `B-X B-X`，实体计数是什么？答案：gold 一个区间，预测两个单词区间；TP=0，FP=2，FN=1，token accuracy=1/2。
4. 只剩一条合法链且分数有限时 Z 和概率是什么？答案：Z 为该链指数权重，该链概率 1；若连这条链也 $-\infty$，Z=0，条件分布不定义。
