# 警务、监察、羁押与社区矫正：现实制度基线

## 核对范围与日期

- 核对截止日：**2026年8月18日**。
- 范围包括人民警察一般职权、治安案件处理、刑事侦查与强制措施的衔接、监察调查、看守所与拘留所、监狱执行、检察监督、社区矫正及有关申诉救济。
- 本文只确认全国层面的法律、行政法规和中央部门制度。地方实施细则、内部办案规范及个案做法未作穷尽核对。
- “现行”指截止日已经施行；“已通过未施行”与“征求意见稿”不作为现行制度依据。

## 制度状态

| 制度文件 | 截止日状态 | 基线意义 |
|---|---|---|
| 《人民警察法》 | **现行法律**，目前适用的是既有文本 | 规定警察职责、权限、组织管理和执法纪律；修订草案尚未成为法律 |
| 修订后的《治安管理处罚法》 | **已于2026年1月1日施行** | 现行治安违法、警告、罚款、行政拘留及相应程序的直接依据 |
| 《刑事诉讼法》 | **现行法律** | 规定刑事立案、侦查、拘留、逮捕、讯问、搜查、起诉和审判的基本程序 |
| 《监察法》2024年修正文本 | **已于2025年6月1日施行** | 规定监察对象、调查权限、强制性措施、案件移送和监督责任 |
| 《看守所条例》 | **现行行政法规**，制定年代较早 | 规范被刑事拘留、逮捕人员及部分短刑人员的羁押管理 |
| 《拘留所条例》 | **现行行政法规** | 规范行政拘留等决定的执行场所、收拘、管理、通信会见和解除 |
| 《社区矫正法》 | **现行法律**，自2020年7月1日起施行 | 适用于管制、缓刑、假释、暂予监外执行等对象的非监禁执行 |
| 2026年修订《监狱法》 | **已通过但尚未施行**，施行日为2026年11月1日 | 截止日不能作为现行规则；可作为明确的近期制度变化单列保存 |
| 《人民警察法（修订草案稿）》 | **公开征求意见稿** | 仅能用来观察改革议题，不得写成已经通过或施行 |

## 现行结构摘要

### 1. 警务组织与权力类型

公安机关承担治安管理、刑事侦查、道路与公共安全、户籍和人口管理等任务。警察现场执法可能依次连接身份查验、盘问检查、行政案件调查、治安处罚，也可能在发现犯罪嫌疑后转入刑事程序。行政处罚与刑事追诉的证据标准、强制措施和救济路径不同，案件定性会直接决定个人受到的程序保障。

### 2. 治安处罚与刑事强制措施

治安处罚由公安机关调查并作出决定，处罚种类包括警告、罚款和行政拘留等。现行法设置告知、陈述申辩、证据审查、特定事项听证及复议、诉讼渠道。刑事拘留、取保候审、监视居住和逮捕则由刑事诉讼制度调整，其中逮捕通常需要人民检察院审查批准或人民法院决定。

### 3. 监察调查

监察机关依法调查公职人员职务违法和职务犯罪，并可依法采取谈话、询问、查询、冻结、搜查、留置等措施。涉嫌职务犯罪的案件调查终结后移送检察机关审查起诉。监察调查、刑事诉讼和干部管理责任之间存在多条接口，程序状态转换会影响当事人的权利告知、辩护帮助和救济方式。

### 4. 羁押与刑罚执行场所

- 看守所主要承接刑事拘留和逮捕后的羁押，并执行法律规定范围内的剩余刑期。
- 拘留所主要执行行政拘留以及法律规定的其他拘留决定。
- 监狱执行有期徒刑、无期徒刑等刑罚，并承担教育改造、劳动、医疗和释放衔接。
- 检察机关对羁押和刑罚执行实施法律监督，监狱领域已建立巡回检察等机制。

### 5. 社区矫正

社区矫正由地方人民政府设置的社区矫正机构负责，司法所等单位根据委托承担具体工作，人民法院、人民检察院、公安机关和有关部门协同。制度同时包含监督管理、教育帮扶、禁止令执行、考核奖惩、收监建议和解除矫正等功能。

## 关键制度接口

| 接口 | 现实运行要点 | 需要核验或留痕的核心材料 |
|---|---|---|
| 现场警务—行政案件 | 现场处置可转为治安调查和处罚 | 执法依据、身份与时间记录、执法音视频、扣押清单、告知与申辩记录 |
| 行政案件—刑事案件 | 发现涉嫌犯罪后转入刑事程序 | 转案理由、证据移交、强制措施起算时间、重复处罚审查 |
| 公安侦查—检察审查逮捕 | 检察机关对是否批准逮捕作专门审查 | 申请材料、社会危险性理由、辩护意见、羁押必要性审查结果 |
| 监察调查—检察起诉 | 职务犯罪案件由监察调查转入刑事审查起诉 | 移送清单、证据合法性说明、措施期限、退回补充调查情况 |
| 办案机关—羁押场所 | 入所、提讯、医疗、会见和换押需相互衔接 | 入所体检、提讯记录、律师会见、伤病处置、换押凭证 |
| 羁押场所—检察监督 | 检察机关监督超期羁押、监管活动和刑罚执行 | 驻所或巡回检察报告、纠正违法通知、事故调查和整改结果 |
| 监禁执行—社区矫正 | 暂予监外执行、假释等使执行方式发生变化 | 法律文书、风险与需求评估、健康材料、接收和监督方案 |
| 社区矫正—社会服务 | 监督管理与就业、教育、医疗和家庭支持相连接 | 个别化矫正方案、帮扶转介、奖惩理由、申诉和解除记录 |

## 可观察约束与信息缺口

1. 现行人民警察法和看守所条例制定时间较早，面对移动终端取证、人脸与轨迹数据、算法研判等新型权力时，公开法律层面的用途边界和审计规则相对有限。
2. 公安侦查和看守所管理处于同一行政系统，外部监督主要依靠检察监督、法院审查、行政复议诉讼和投诉渠道；各渠道能否及时共享材料，公开信息不足。
3. 全国层面缺少统一、稳定、可比较的警察身份查验、搜查、使用强制力、执法音视频缺失、羁押伤亡和医疗转送数据集。
4. 羁押人员的入所体检、独立医疗意见、精神健康、戒具使用、单独管理和突发事件调查，公开资料多为原则性规定，难以从公开信息判断地区执行差异。
5. 治安处罚的裁量基准主要由地方和部门细化，同类案件的处罚分布、撤销率及纠错原因缺少全国统一公开口径。
6. 监察措施具有专门程序。公开信息不足以系统比较留置期间法律帮助、医疗、家属通知、措施复核和移送刑事程序后的证据审查情况。
7. 社区矫正兼具监督和帮扶功能，但全国公开数据较少呈现不同措施的效果、重新违法风险、就业住房结果及被矫正对象的申诉情况。
8. 新修订监狱法尚未生效，现实资料应同时保留“截止日现行法”和“2026年11月后将变化”的双重时间标记。

## 古国改革需回答的问题

1. 警察可以在何种事实门槛下查验身份、盘问、搜查、扣押和调取数字信息？每项权力是否设置最长时限、比例原则和自动留痕？
2. 对住宅、通信、设备和长期轨迹等高侵入性措施，哪些必须由独立司法机关事前授权，紧急例外如何事后复核？
3. 行政拘留是否设置执行前的独立审查、快速听证和法律援助？错误拘留如何即时停止并自动赔偿？
4. 警务投诉由谁受理，调查人员是否独立于被投诉单位，投诉人和证人如何获得反报复保护？
5. 执法记录仪何时必须开启，缺失、关闭或损坏时如何分配举证后果？公众可在什么条件下调取副本？
6. 看守所是否与侦查机关实行组织和预算分离？入所体检、医疗转送、伤情鉴定及死亡调查由谁独立决定？
7. 被羁押人从何时起可以获得律师帮助；会见、通信和阅卷限制应由谁作出并接受何种复核？
8. 未成年人、孕产妇、残障者、精神障碍者和需要长期用药者应适用哪些替代羁押和专门照护规则？
9. 监察调查中的强制措施如何获得外部合法性审查，法律帮助、通知、医疗和申诉怎样保障？
10. 羁押、监狱和社区矫正的监督报告、纠正违法、事故和整改结果公开到何种粒度，如何兼顾隐私？
11. 社区矫正应以风险控制还是社会融入为首要目标，禁止令、电子定位、就业与迁居限制如何保持必要和可申诉？
12. 警务、监察和执行机关的违法决定造成损害时，个人赔偿、机构整改和工作人员责任之间如何衔接，避免压制主动纠错？
