# Wiener估计与预测：同一真值、不同信息窗口

从 [[信号与系统/30-随机信号与推断/03-Wiener滤波线性预测与创新#两样本电压为何胜过只取当前读数|两样本手算]] 带w=(7/15,2/15)、MSE=7/15 V²到这里；快进者带 [[信号与系统/30-随机信号与推断/03-Wiener滤波线性预测与创新#因果谱因子如何把未来项移出允许空间|可逆因果因子]] 与g、r，再用相同真值验证信息集的差异。返回时交实际报告、数据边界和改变噪声后的失效理由。

## 固定对象和独立记录

全部理论均值已知为0，不估截距。s[n]=.5s[n−1]+q[n]，q独立Gaussian、方差.75 V²，平稳初态方差1；x=s+v，v独立Gaussian白噪声方差1 V²。每次训练4096、独立测试8192，重复16次；seed=179000+r、179100+r（r=0…15）。训练仅估R,p及两权重，冻结后评估独立测试；已知目标s只在合成/监督模型可用，真实未知端口没有这份免费真值。

所有滤波方法在共同测试区间n=128…8159评估：当前一抽头、理论两抽头、训练两抽头、延迟一拍三抽头、因果递推、双边半径32截断。因果初态0的影响指数衰减，前128拍舍弃；双边在记录边缘预留32拍，绝无循环卷积或零填充未来冒充无限历史。双边截断仍是有未来信息的近似，不能比实时算法而不注明延迟。

改变前提的记录seed=179200+r：v改成AR(1)系数.5且平稳Varv=1，与s仍独立。原权重的真实理论MSE119/225，新最优两样本权重(.5,0)、MSE.5。独立谱方差实验seed179300，128组，每组8个独立64点白Gaussian段，在内部bin5计算双边角频率数值periodogram |DFT|²/64；理论均值1、单段方差1、平均方差1/8。它没有重叠Welch或现实仪器测量。

## 独立解析参照与预期

| 对象 | 固定解析预期 | 如何独立核 |
| --- | --- | --- |
| 两样本总体权重 | (7/15,2/15)，MSE7/15 | Fraction直接展开误差与代回R；不使用训练统计当理论oracle |
| 非线性三点反例 | 仿射MSE2/9，条件均值MSE0 | 完整有限分布枚举 |
| 一拍平滑 | 权(1/8,7/16,1/8)，MSE7/16 | 独立三点正规方程 |
| 因果无限 | MSE2√3−3 | 独立Riccati正根、impulse g rᵏ与因子乘回 |
| 双边无限 | MSE√3/4 | 几何级数与谱积分；radius32尾误差按正文界 |
| 错噪声沿用旧权 | MSE119/225 | 新R的完整二次型 |
| 相位约定 | θ=π/4，二拍延迟G=−i | Sdx=G Sxx；共轭错得+i |
| 孤立DC零点 | X=u−u过去的log谱可积、创新方差1；加权逆恢复误差1/N，直接截逆误差1 | 独立Fraction按X的三对角协方差与目标u[0]展开二次损失，不用滤波函数自证 |

浮点单元断言只覆盖本小模型；期望损失的普遍最优性靠正文一般投影证明，有限重复的均值/散布不代替它。实际MSE不应逐次强迫等于理论常数；报告16次散布，异常时先查版本、输入、训练/测试切分和相位。原噪声模型的两抽头误差应与当前/过去观测正交；改变ρv=.5后，旧权的总体误差矩分别为−1/15、−7/30 V²，新权(.5,0)恢复两矩为0。JSON另保留lag=−1的未来矩，不强迫因果/有限滤波对未经使用的未来正交。可以把与理论的差相对本次重复标准误作描述，不能由这次数据设一个保证PASS的容差。

一般非有理谱的log条件、Poisson外因子和创新方差在 [[信号与系统/30-随机信号与推断/03-Wiener滤波线性预测与创新#非有理谱的log条件、外因子与创新方差|主课一般合同]]；新增DC零点测试只核有限协方差二次型，不把它签成一般定理或BIBO逆成功。谱原子须分离确定部分，整带密度零则log条件失效。
