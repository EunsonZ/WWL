# 本轮权威资料与版本边界

本轮检索核对日期：2026-09-06。以下是语言/协议作者、标准组织、项目官方文档或教材作者/课程团队入口，不转载整本资料。正文使用明确版本基线，不把网页的 current 等同于用户已安装版本。链接用于进一步核对；教学图示均本地保存，不依赖这些网页加载图片。

## C与C++

[GCC 预处理器手册](https://gcc.gnu.org/onlinedocs/cpp/) 用于头文件、宏和预处理边界；[GCC 整数溢出内建函数](https://gcc.gnu.org/onlinedocs/gcc/Integer-Overflow-Builtins.html) 说明实现提供的检测机制，不能误当 ISO C 的全部要求；[GCC 代码生成选项](https://gcc.gnu.org/onlinedocs/gcc/Code-Gen-Options.html) 用于核对改变溢出假设的编译选项。[C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) 用于资源、接口、异常和并发设计。Guidelines 是建议，不替代标准条文。GNU C 完整语言手册本轮抓取超时，未将其标为成功核验。

## Rust

[The Rust Programming Language](https://doc.rust-lang.org/book/)；[所有权](https://doc.rust-lang.org/book/ch04-01-what-is-ownership.html)；[引用与借用](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html)；[错误处理](https://doc.rust-lang.org/book/ch09-00-error-handling.html)；[标准库](https://doc.rust-lang.org/std/)；[unsafe 参考](https://doc.rust-lang.org/reference/unsafety.html)；[未定义行为边界](https://doc.rust-lang.org/reference/behavior-considered-undefined.html)；[异步书](https://rust-lang.github.io/async-book/)。当前在线书使用的 edition 与本库基础实验的 2021 edition 需区分。

## Python

[数据模型](https://docs.python.org/3/reference/datamodel.html) 用于对象、协议与身份；[协程与任务](https://docs.python.org/3/library/asyncio-task.html) 用于 TaskGroup、取消与失败传播；[PEP 703](https://peps.python.org/pep-0703/) 用于理解可选 GIL 的设计边界。PEP 不等于所有安装环境均已采用某一种构建。

## TypeScript

[官方文档总入口](https://www.typescriptlang.org/docs/)；[基础](https://www.typescriptlang.org/docs/handbook/2/basic-types.html)；[收窄](https://www.typescriptlang.org/docs/handbook/2/narrowing.html)；[泛型](https://www.typescriptlang.org/docs/handbook/2/generics.html)；[结构兼容](https://www.typescriptlang.org/docs/handbook/type-compatibility.html)；[TSConfig](https://www.typescriptlang.org/tsconfig/)。旧版 Handbook 中被标 deprecated 的页面不作为本轮新增路线。

## 数据结构与算法

[MIT 6.006 课程阅读与主题入口](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/pages/readings/) 用于基础结构、图、排序与算法课程组织。原始算法章节内已有进一步资源。本轮新增的手算与反例为独立教学构造，不声称转载课程教材；高级主题概览不代替各定理的完整证明。

## 组成原理

[RISC-V 官方 ISA 文档入口](https://docs.riscv.org/reference/isa/unpriv/rv32.html) 用于继续查具体指令语义；本轮该旧入口仅取得重定向提示，未把目标版 ISA 全文标为已读。正文的 CPI、流水、AMAT 采用明确的教学模型，不能等同于某型号处理器。原系统章节保留其原有硬件资源入口。

## 操作系统与Linux

[OSTEP 作者主页与开放教材](https://pages.cs.wisc.edu/~remzi/OSTEP/) 用于虚拟化、并发、持久化三条主线；[Linux fsync 手册](https://man7.org/linux/man-pages/man2/fsync.2.html) 用于文件与目录持久化边界；[Linux cgroup v2 官方文档](https://docs.kernel.org/admin-guide/cgroup-v2.html) 用于资源限制与控制器。教材理论与具体 Linux 版本实现分别判断。

## 计算机网络

[RFC 9293：TCP](https://www.rfc-editor.org/rfc/rfc9293.html)；[RFC 8200：IPv6](https://www.rfc-editor.org/rfc/rfc8200.html)；[RFC 1034：DNS 基础](https://www.rfc-editor.org/rfc/rfc1034.html)；[RFC 8446：TLS 1.3](https://www.rfc-editor.org/rfc/rfc8446.html)；[RFC 9110：HTTP 语义](https://www.rfc-editor.org/rfc/rfc9110.html)；[RFC 9000：QUIC](https://www.rfc-editor.org/rfc/rfc9000.html)。老 RFC 的具体更新、勘误和扩展应继续核对，不能把基础 RFC 当成所有相关规范的全集。

## 数据库

[PostgreSQL 17 教程](https://www.postgresql.org/docs/17/tutorial.html)；[索引](https://www.postgresql.org/docs/17/indexes.html)；[事务隔离](https://www.postgresql.org/docs/17/transaction-iso.html)；[EXPLAIN](https://www.postgresql.org/docs/17/using-explain.html)；[WAL](https://www.postgresql.org/docs/17/wal-intro.html)。实现示例使用固定 17 文档入口，避免 current 随主版本滚动。SQLite 教学测试只证明 SQLite 实际运行中的断言，不作为 PostgreSQL 并发语义实验。

## 编译原理

[LLVM Language Reference](https://llvm.org/docs/LangRef.html) 用于 IR 语义边界和进一步查阅。LLVM 方言语义不是 C/C++ 或任意源语言语义；完整前端、优化与后端的资料继续见原库编译原理课程。优化正确性说明需明确语言、IR、数值和副作用假设。
