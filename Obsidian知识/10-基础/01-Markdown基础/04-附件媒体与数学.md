# 04 · 附件、媒体与数学

## 内部嵌入：不复制，直接引用

在内部链接前加 `!`，就能把目标笔记、标题或块的内容显示在当前位置。源内容修改后，嵌入处会同步变化。

**源码：**

```markdown
![[01-基础排版#强调与删除线]]
```

**渲染效果：**

![[Obsidian知识/10-基础/01-Markdown基础/01-基础排版#强调与删除线]]

> [!tip] 链接与嵌入的区别
> `[[笔记]]` 把你带到源内容；`![[笔记]]` 把源内容带到这里。知识只维护一份，是 Obsidian 避免复制粘贴的重要方式。

## 图片

### Vault 内附件

把图片拖进笔记，Obsidian 通常会生成内部嵌入。可在竖线后限制显示宽度：

```markdown
![[示例图片.png]]
![[示例图片.png|320]]
![[示例图片.png|320x180]]
```

第三种写法同时给出宽度和高度。示例链接故意不创建附件，以免制造无意义素材。练习时把自己的图片拖到 [[Obsidian知识/30-实践/01-实验区/Markdown/01-自由草稿纸|自由草稿纸]]，观察实际生成的链接和附件目录。

### 网络图片

**源码：**

```markdown
![Obsidian 标志](https://obsidian.md/images/obsidian-logo-gradient.svg)
```

**渲染效果（需要网络连接）：**

![Obsidian 标志](https://obsidian.md/images/obsidian-logo-gradient.svg)

> [!warning] 长期保存时优先本地附件
> 网络图片可能移动、失效或被访问控制拦截。本地附件随 Vault 一起备份；网络图片则更节省 Vault 空间。

## 音频、视频与 PDF

Obsidian 可以嵌入 Vault 中的常见媒体和 PDF：

```markdown
![[录音.m4a]]
![[演示.mp4]]
![[手册.pdf]]
![[手册.pdf#page=3]]
```

文件名、标题和说明文字尽量有意义。可在“设置 → 文件与链接 → 新附件的默认位置”统一附件落点，避免素材散落。

## 行内数学

Obsidian 使用 MathJax 渲染 LaTeX。单个美元符号包裹行内公式。

**源码：**

```markdown
圆的面积是 $A=\pi r^2$，当 $r=2$ 时，$A=4\pi$。
```

**渲染效果：**

圆的面积是 $A=\pi r^2$，当 $r=2$ 时，$A=4\pi$。

## 块级数学

双美元符号单独成行，用于居中的块公式。

**源码：**

```latex
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

**渲染效果：**

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

常用写法：

| 目标 | LaTeX | 效果 |
| --- | --- | --- |
| 分数 | `\frac{a}{b}` | $\frac{a}{b}$ |
| 上下标 | `x_i^2` | $x_i^2$ |
| 根号 | `\sqrt{x}` | $\sqrt{x}$ |
| 希腊字母 | `\alpha, \beta` | $\alpha, \beta$ |
| 向量 | `\vec{v}` | $\vec{v}$ |

> [!example] 插件接力
> 先在 [[Obsidian知识/30-实践/01-实验区/Markdown/03-数学练习场|数学练习场]] 手写几个公式，再进入 [[Obsidian知识/20-功能/02-社区插件实验室/07-LaTeX-Suite|LaTeX Suite]]，体验片段展开如何加速输入。无论插件多快，保存下来的仍是 LaTeX 文本。
