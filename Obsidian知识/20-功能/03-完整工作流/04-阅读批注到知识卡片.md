# 阅读批注到知识卡片

收藏高亮不等于学习。本流程把来源中的一句话转化为可追溯的批注、自己的解释、独立概念和实际用途。

## 四层信息

| 层次 | 内容 | 典型位置 |
| --- | --- | --- |
| 来源 | 书目、作者、文件、页码 | [[Obsidian知识/30-实践/03-示例项目/周末读书会/书目/卡片笔记写作法\|卡片笔记写作法]] 或 PDF |
| 批注 | 原文片段和定位 | 阅读笔记或 PDF++ 链接 |
| 解释 | 用自己的话说明含义 | 阅读笔记 |
| 概念 | 脱离单一来源仍成立的判断 | [[Obsidian知识/30-实践/03-示例项目/周末读书会/概念/双向链接\|双向链接]]、[[Obsidian知识/30-实践/03-示例项目/周末读书会/概念/原子笔记\|原子笔记]] 等概念卡 |

## 第一步：记录来源

打开 [[Obsidian知识/30-实践/03-示例项目/周末读书会/书目/卡片笔记写作法|卡片笔记写作法]]，确认来源信息、阅读状态和关联项目。若使用 PDF，打开 `sample-highlight.pdf`；只对课程样例操作。

建议属性：

```yaml
---
type: book
status: reading
rating: 4
topics:
  - note-taking
project: "[[00-周末读书会项目主页]]"
---
```

## 第二步：保留精确定位

最小方式是记录文件和页码：

```markdown
> 批注摘要或少量必要引文。

来源：[[sample-highlight.pdf#page=2]]
```

完成 [[Obsidian知识/20-功能/02-社区插件实验室/09-PDF++|09-PDF++]] 后，可创建指向精确页面、区域或文本选择的链接。高亮必须保留来源定位，但不要把整页内容复制进 Vault。

## 第三步：写出自己的解释

紧接批注回答：

1. 作者在说什么？
2. 我为什么同意、不同意或不确定？
3. 它与已有哪条笔记发生联系？
4. 什么例子可以检验它？

还要写清两件事：这份材料支持的是哪一个具体主张，以及它的证据能覆盖到什么范围。单一来源可以提示一个值得记录的判断，却不自动排除相反证据、替代解释或不同人群/条件下的例外。

```markdown
### 我的解释

这里的重点不是把笔记切得越碎越好，而是让每张笔记有一个可以被重新组合的明确主张。这与 [[Obsidian知识/10-基础/02-链接与知识网络/05-MOC、原子笔记与渐进式总结|MOC、原子笔记与渐进式总结]] 的边界讨论相关。
```

## 第四步：抽取独立概念卡

只有在观点值得跨来源复用时才抽取。使用 [[Obsidian知识/90-资源/01-模板/核心模板/阅读|核心模板-阅读]] 或 [[Obsidian知识/90-资源/01-模板/Templater/常青笔记|Templater-常青笔记]] 创建概念页：

```markdown
---
type: concept
status: active
topics:
  - note-taking
source:
  - "[[卡片笔记写作法]]"
---

# 笔记的原子性由可独立讨论的主张决定

## 一句话结论

## 解释

## 例子与反例

## 相关
- [[Obsidian知识/30-实践/03-示例项目/周末读书会/概念/原子笔记|原子笔记]]
- [[Obsidian知识/30-实践/03-示例项目/周末读书会/概念/渐进式总结|渐进式总结]]
```

不要让概念标题只剩“原子性”这类主题词；一个完整判断更容易在未来写作中直接使用。

在抽取前做一次小审计：

| 问题 | 在哪里留下答案 |
| --- | --- |
| 作者的原话或结果能定位吗？ | 阅读笔记的批注与页码/链接 |
| 我的主张是什么？ | 概念卡的一句话结论 |
| 哪项证据支持它、哪项材料可能反驳它？ | 概念卡的证据与反例/范围 |
| 这个结论服务于哪个问题或项目？ | 概念卡与项目页的明确链接 |

这不是要求每张卡都做完整文献综述；它是防止把“读过一篇材料”误写成“结论已经被确认”。

## 第五步：放回真实上下文

在 [[Obsidian知识/30-实践/03-示例项目/周末读书会/01-读书会启动会议|01-读书会启动会议]] 或今天的日记中引用新概念，说明它如何改变讨论、写作或决定。再从概念页的 Backlinks 验证它确实参与了输出。

> [!practice] 从一个批注生成一张知识卡
> 你的成果必须包含来源定位、一段自己的解释、一张以完整判断命名的概念卡、至少两个相关链接，以及来自项目/会议/日记的一次反向引用。

> [!success] 成功标准
> 读者能找到来源；概念页不是原文摘抄；它说明支持理由、反例或边界；概念脱离书目页仍可理解；它至少被一个真实上下文使用；删除 PDF++ 后 Markdown 说明仍然可读。
