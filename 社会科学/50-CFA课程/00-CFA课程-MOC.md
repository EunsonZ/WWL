# CFA课程：先判断责任，再读懂报表和投资决策

读者要解决的问题是：**投资数字从哪里来，怎样判断它是否支持一个对客户负责的决定？**已有[[社会科学/30-金融市场与风险/00-金融市场与风险-MOC|金融八讲]]解释现金流、价格和风险机制；这里接入职业标准、财务报表分析与公司财务决策。先读一个完整小课，再沿既有基础扩展，比把所有术语排进目录更有用。

本目录当前提供 **伦理、三表与公司财务基础、财报进阶算例、公司与收入分析，以及收益回归组合、权益市场与估值、其他资产估值、经济学、二级分析首组及三级共同核心限定小课**，不宣称覆盖CFA全部级别、全部LOS或考试深度。原25单元审计仍保留，后续主题见下表；尚无课程的主题用文字说明缺口，不设置空笔记。案例与数据是原创合成；用户学习进度和官方考试/PSM完成状态未知。

建议顺序是01→02→03，以及10→11→12→20→21→80；伦理组可独立读，报表组遇到贴现问题先回到[[社会科学/30-金融市场与风险/01-现金流复利贴现与实际收益|现金流时点与NPV]]，20/21提供具体财务应用，不在这里复制完整公式证明。

收益比较问题沿30→31→32→82读：先固定资金时点，再检查回归假设，最后讨论两资产约束与行为。资产问题在金融基础后沿40→41→42→83读，分别核对利率曲线、合约时点和费用条款。经济学问题沿50→51→84读，先区分成本与市场条件，再固定汇率报价方向；各组可独立选择，不要求读完其他组。

“每股利润为何不能把所有潜在股份一起加进分母？”用 [[社会科学/50-CFA课程/13-每股收益稀释与反稀释|EPS排序]]核对加权股数和反稀释；“利润、义务与付现为何不一致？”沿 [[社会科学/50-CFA课程/14-租赁养老金与股份报酬|租赁、养老金与股酬]] → [[社会科学/50-CFA课程/15-长期资产终止确认与所得税调节|资产处置与税桥]] → [[社会科学/50-CFA课程/16-现金覆盖预测报表与综合判断|现金覆盖与预测三表]]，再用 [[社会科学/50-CFA课程/85-财报进阶算例复算|限定算例复算]]检查工作表。

二级多信息问题先沿 [[社会科学/50-CFA课程/60-时间序列平稳性与预测诊断|平稳性与预测诊断]] → [[社会科学/50-CFA课程/61-公司估值多信息案例与模型选择|正常化利润、FCFF与股权桥]] → [[社会科学/50-CFA课程/62-信用风险含权债与情景估值|信用与含权债状态]]选择需要的一课；[[社会科学/50-CFA课程/86-二级分析案例复算|二级分析链复算]]核对各自条件。三课是独立原创案例，时间序列条件、经营现金/索取权和利率/信用状态各自固定；首组不覆盖全部二级LOS、复杂报表或全部金融模型。

客户目标、负债与投资经理判断，沿 [[社会科学/50-CFA课程/70-三级共同核心/00-三级共同核心-MOC|三级共同核心路线]] 进入：先写私人客户与机构 IPS，再比较资产、负债及目标导向配置，随后用衍生品调整风险，最后区分绩效计量、归因、评价与经理选择。每一步都有固定教学数例和改变条件的迁移题；三级共同核心的剩余模块、三条专门路径与官方 PSM 继续单列，不能由这组小课推断全部覆盖。

读完10–12后，可沿[[社会科学/50-CFA课程/10-公司与收入分析/00-公司与收入分析-MOC|公司与收入分析]]把同一家企业的组织、商业模式和合同账本连起来，再回20/21比较资本选择。年度核对表分别记录这些限定例仍没有覆盖的复杂条件。

权益问题沿新组00→01–05→90阅读：先分清权益工具、市场和订单，再比较指数规则与效率边界，最后把行业/公司驱动写进权益现金流及一级估值。已有金融八讲03/05继续承担股权现金流和有效市场理论主解释；61继续承担二级FCFF/FCFE/剩余收益，不由新组重复替代。

## 年度、级别与路径不能混用

本页核对日期为2026-09-17，以2026与2027官方公开纲要作导航。职业准则采用现行2024生效版本和第12版手册，不因考试年度变化就换成历史准则。考试备考应以报名年度纲要、正式课程及勘误为准。[职业准则现行入口](https://www.cfainstitute.org/standards/professionals/code-ethics-standards)、[课程勘误入口](https://www.cfainstitute.org/programs/candidate-resources/submit-errata)。

2026一级伦理纲要pp31–32包含统一的I–VII guidance及GIPS介绍；2027一级pp29–31改为分列I–VII和Application of the Code and Standards，该段未列GIPS模块。后者是公开纲要中的范围变化，不能推断GIPS职业规范废止，也不能把本库03写成2027一级必考模块。[2026一级纲要](https://www.cfainstitute.org/sites/default/files/docs/programs/cfa-program/2026-l1-topics-combined.pdf)、[2027一级纲要](https://www.cfainstitute.org/sites/default/files/2027levelitopicoutline_online.pdf)。2027更新摘要重点提到数量与股权实践应用改造；课程改名不等于已有页已经满足新LOS。[官方2027更新摘要](https://www.cfainstitute.org/sites/default/files/curriculum-update-2027.pdf)。

Level I建立概念与基本应用；Level II侧重情景材料中的分析；Level III连接客户/机构目标、配置、执行、风险和绩效，并包含所选路径。三级为共同核心加 **Portfolio Management、Private Markets、Private Wealth中一条路径**，不要求每位候选人把三条都作共同必修。[一级年度入口](https://www.cfainstitute.org/programs/cfa-program/candidate-resources/level-i-exam)、[二级入口](https://www.cfainstitute.org/programs/cfa-program/candidate-resources/level-ii-exam)、[三级核心与路径](https://www.cfainstitute.org/programs/cfa-program/candidate-resources/level-iii-exam)。本库情景题和短答用于练习，不冒充官方题库或模拟考试验收。

## PSM是另一个完成状态

官方要求每级完成至少一个可用PSM才能取得考试结果；同一模块不能跨级重复计入。2026/2027选项与名称以官方年度表和候选人LES为准，尤其三级可访问选项受路径影响。官方页面的2027三级年度表和后续路径列表存在名称/列项口径差异，不能从列表拼出“所有人能任意选全部模块”的规则。[官方PSM年度表与FAQ](https://www.cfainstitute.org/programs/cfa-program/candidate-resources/practical-skills-modules)。

本库80、Python学习或案例答案不是官方PSM完成证明，也不自动支持用户已掌握、已满足取得成绩条件或可免除模块的结论。读完F1后可按审计矩阵选择下一束，例如另类尽调或多元金融回归；选择一级、二级还是三级所选路径的下一课应由实际目标决定。
