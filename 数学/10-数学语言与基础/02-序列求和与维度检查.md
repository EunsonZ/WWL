# 序列、求和与维度检查

一个求和号 $\sum$ 的价值不在于把式子缩短，而在于明确：某个索引跑遍一个范围，所得的多个标量被加成一个标量（或在保留其他索引时加成一个更小阶的对象）。这正是矩阵乘法、attention 点积和 batch 损失会“消掉一根轴”的原因。

> [!abstract] 本课目标
> 你将能把序列和 $\sum$ 展开成有限项，辨认自由索引与被求和索引，并用索引和 shape 两种方法检查矩阵乘法、注意力权重与批量损失的结果。

## 1. 直觉：序列给出顺序，求和把一组贡献合并

有限序列是按顺序排列的一组对象，例如

$$
(x_t)_{t=1}^{T}=(x_1,x_2,\ldots,x_T).
$$

其中 `t` 是位置，`T` 是序列长度。求和

$$
\sum_{t=1}^{T}x_t=x_1+x_2+\cdots+x_T
$$

让每个位置的贡献都进入结果。若 `x_t` 是标量，结果是标量；若 `x_t` 都是同一 shape 的向量或矩阵，逐分量相加的结果保持该 shape。**求和符号本身不说明每项是什么；对象类型必须由上下文或显式声明提供。**

在 LLM 中，序列位置可以是 token，`t` 可以表示正在读取的位置，另一个位置 `u` 可以表示被比较或被聚合的位置。它们长度可能同为 `T`，却不应因为字面长度相同而混成一个角色。

## 2. 精确定义：索引范围、自由索引与求和索引

考虑

$$
y_i=\sum_{j=1}^{n} A_{ij}x_j.
$$

若 $A\in\mathbb{R}^{m\times n}$、$x\in\mathbb{R}^n$，则 $i\in\{1,\ldots,m\}$、$j\in\{1,\ldots,n\}$。这里：

- `j` 在 $\sum$ 下运行并被加总，是**求和（虚）索引**；
- `i` 没有被加总，仍出现在左右两边，是**自由索引**；
- 对每一个固定的 `i`，右边得到一个标量 `y_i`；全部 `i` 合起来构成 $y\in\mathbb{R}^m$。

不要把“一个字母出现两次”当作通用规则。爱因斯坦求和约定在一些材料中省略 $\sum$，但并非所有教材、论文和代码都使用它。学习阶段应优先写出 $\sum$ 与上下限；在没有声明约定时，不应擅自把重复下标解释为求和。

### 矩阵乘法：内侧维度必须相接

若

$$
A\in\mathbb{R}^{m\times n},\qquad B\in\mathbb{R}^{n\times p},
$$

则矩阵乘法定义为

$$
(AB)_{ik}=\sum_{j=1}^{n}A_{ij}B_{jk},
\qquad AB\in\mathbb{R}^{m\times p}.
$$

`j` 对应 `A` 的列与 `B` 的行，被求和消去；`i`（`A` 的行）和 `k`（`B` 的列）留下，成为结果的两根轴。这既解释了“内侧 `n` 必须相等”，也解释了输出是“外侧 `m×p`”。它不是元素逐个相乘：逐元素乘法还要求两边按对应位置对齐，输出 shape 的规则完全不同。

## 3. 一张可重复使用的维度检查表

每次读模型公式，按下表走一遍：

| 步骤 | 要写下来的证据 | 出错时常见原因 |
| --- | --- | --- |
| 1. 列对象 | 每个符号的集合、shape、轴语义 | 只写了字母，没写每轴是谁 |
| 2. 拆运算 | 是逐元素、矩阵乘法、求和、拼接还是 softmax？ | 把不同运算都笼统叫“乘” |
| 3. 对齐轴 | 哪些轴必须相同，哪些轴会被求和？ | 两个长度同为 `T` 的轴角色混淆 |
| 4. 留下轴 | 自由索引或外侧轴是什么？ | 结果少写或多写一根轴 |
| 5. 写语义 | 每个保留轴代表什么实际对象？ | 数字对上了，语义却颠倒 |
| 6. 查实现 | 广播、mask、padding、transpose 的 API 规则是什么？ | 把框架的便利规则当成纯数学定义 |

shape 检查能发现很多错误，但不能证明模型语义正确。例如两个长度刚好相等的轴可能被错误地相乘；数学上可行，不代表“样本不能互相混合”等建模边界仍被遵守。

## 4. 用索引读注意力的最小闭环

为简洁起见，先省略 batch 轴。令：

$$
X\in\mathbb{R}^{T\times d_{\mathrm{model}}},\quad
W_Q,W_K\in\mathbb{R}^{d_{\mathrm{model}}\times d_k},\quad
W_V\in\mathbb{R}^{d_{\mathrm{model}}\times d_v}.
$$

投影到 query、key、value：

$$
q_{ti}=\sum_{r=1}^{d_{\mathrm{model}}}X_{tr}(W_Q)_{ri},\quad
k_{ui}=\sum_{r=1}^{d_{\mathrm{model}}}X_{ur}(W_K)_{ri},\quad
v_{uj}=\sum_{r=1}^{d_{\mathrm{model}}}X_{ur}(W_V)_{rj}.
$$

其中 `t` 是 query 位置，`u` 是 key/value 位置，`i` 是 `d_k` 轴，`j` 是 `d_v` 轴，`r` 是原特征轴。投影结果分别具有 shape `(T,d_k)`、`(T,d_k)`、`(T,d_v)`。

每对位置的缩放点积分数是：

$$
s_{tu}=\frac{1}{\sqrt{d_k}}\sum_{i=1}^{d_k}q_{ti}k_{ui}.
$$

`i` 被求和，所以分数只保留 `(t,u)`，即 shape `(T,T)`。先看没有 mask 的情形。在固定 `t` 的一行内归一化：

$$
a_{tu}=\frac{\exp(s_{tu})}{\sum_{v=1}^{T}\exp(s_{tv})}.
$$

分母索引 `v` 是绑定的求和哑指标，而分子中的 `u` 标识当前输出分量。二者职责不同，推荐用不同字母避免遮蔽。把分母哑指标重命名为 `j` 不改变数值；即使写成同名也不会使整个求和与分子自动抵消，必须先澄清指标作用域。对每个固定 `t`，有 `\sum_{u=1}^{T}a_{tu}=1`。最后聚合 value：

$$
o_{tj}=\sum_{u=1}^{T}a_{tu}v_{uj}.
$$

`u` 被加总，输出留下 `(t,j)`，因此 $O\in\mathbb{R}^{T\times d_v}$。若恢复 batch 索引 `b`，每个式子外侧增加独立的 `b`，输出为 `(B,T,d_v)`；batch 轴并没有在这些求和中被混合。

加入 causal 或 padding mask 后，分母只能在该 query 行的**允许 key 集合**上求和，被遮挡位置的最终权重为 0。若某行没有任何允许位置，归一化分母为 0，该行分布未定义；实现必须通过 mask 契约保证至少有一个有效 key，或明确规定特殊处理。

本节只用注意力作为“自由索引与求和索引”的完整读法示例。矩阵乘法、缩放点积与注意力公式的数学权威页是 [[数学/20-线性代数与几何/02-矩阵乘法线性映射与Einsum|矩阵乘法、线性映射与 Einsum]]；[[AI/20-LLM/20-架构/02-注意力MHA-MQA与GQA|注意力、MHA、MQA 与 GQA]] 负责模型叙事、掩码目的和实现选择。后续修订完整推导时应只改权威页，本节仅保留索引教学所需的闭环。

## 5. 批量损失：把样本索引求和后得到标量

设第 `b` 个样本的正确类别是 `c_b`，模型给类别 `c` 的预测概率是 `p_{b,c}`。一个常见的平均负对数似然写作：

$$
\mathcal{L}=-\frac{1}{B}\sum_{b=1}^{B}\log p_{b,c_b}.
$$

每个 $\log p_{b,c_b}$ 是标量；`b` 被求和，故 $\mathcal{L}$ 是标量。若还对序列位置平均，必须再明确写出位置索引、mask 和有效 token 数量；不能仅因为张量原来有 `(B,T,V)` 的 shape 就假定所有位置都该以同样权重进入损失。数据、tokenization、训练目标与流程的工程解释由 [[AI/20-LLM/30-训练/01-数据Tokenization与预训练流程|数据、Tokenization 与预训练流程]] 讨论，本页负责检查其数学汇总是否清楚。

## 6. 常见误解

| 误解 | 修正 |
| --- | --- |
| “求和会把所有轴都消掉。” | 只消去写在求和范围中的索引；未求和的自由索引继续构成结果。 |
| “`T×T` 两根轴完全一样。” | 长度可相同，语义仍可不同；attention 中是 query 位置与 key 位置。 |
| “能做矩阵乘法就代表模型正确。” | 只证明 shape 和运算规则相容，不证明 mask、数据边界、目标定义或语义正确。 |
| “softmax 是把每个元素独立变成概率。” | 它需要指定归一化的轴；该轴上的结果合计为 1。 |
| “batch 平均就是任意维度的 `.mean()`。” | 哪些样本/位置有效、是否要 mask、分母是什么，都属于公式必须说明的假设。 |

## 7. 练习：用自由索引预测输出

1. 令 $C\in\mathbb{R}^{2\times4}$、$D\in\mathbb{R}^{4\times6}$。写出 `(CD)_{ik}` 的求和式、`i/j/k` 的范围，以及结果 shape。
2. 令 $R\in\mathbb{R}^{B\times T\times D}$。若对 `T` 轴求和，结果的 shape 是什么？若对 `B` 和 `T` 都求和呢？为每个答案写出保留轴的含义。
3. 对本节注意力式，解释 `s_{tu}` 里的 `i` 为什么必须与 `q`、`k` 的最后一轴相连；若把 `u` 也求和，结果会失去哪种信息？
4. 写一个有 `(B,T,V)` logits 的训练目标所需的最小符号清单：哪个索引是样本、位置和类别？哪个索引被平均？padding 位置要用什么额外信息排除？无需写代码。

### 成功标准

- [ ] 我能把一个 $\sum$ 完整展开到至少三项，并说明索引的起止范围。
- [ ] 我能从自由索引推出矩阵乘法输出为 `m×p`。
- [ ] 我能按“对象—运算—对齐轴—留下轴—语义”完成一次 shape 检查。
- [ ] 我能解释 attention 输出保留 query 位置和 value 特征轴，而 key 位置被加总。
- [ ] 我能说明 batch 或 token 的平均需要先声明有效元素和分母。
