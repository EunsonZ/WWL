# 01 · 基础排版

> [!example] 本课动作
> 在每个“轮到你”区域直接修改文本，然后按 `Cmd/Ctrl + E` 对比编辑源码与阅读效果。

## 标题与段落

一至六个 `#` 表示六级标题。`#` 后要留一个空格；不要仅为了字体变小而乱跳标题层级。

**源码：**

```markdown
# 一级标题
## 二级标题
### 三级标题

这是第一段。

这是第二段。空行才会真正分段。
想在同一段中强制换行，可在行尾输入两个空格。  
这是新的一行。
```

**渲染效果：**

### 三级标题示例

这是第一段。

这是第二段。空行才会真正分段。  
这是新的一行。

> [!question] 为什么这里没展示一级标题？
> 一篇笔记通常只保留一个一级标题，也就是页面顶端的标题。本页在正文中从三级示例开始，避免破坏大纲层级。

## 强调与删除线

**源码：**

```markdown
**粗体**、*斜体*、***粗斜体***、~~删除线~~、==高亮==、`行内代码`
```

**渲染效果：**

**粗体**、*斜体*、***粗斜体***、~~删除线~~、==高亮==、`行内代码`

用反斜杠转义本来有语法意义的字符：

```markdown
\*这不会变成斜体\*
```

\*这不会变成斜体\*

## 链接：把文件变成知识网络

**源码：**

```markdown
[[02-列表任务与表格]]
[[02-列表任务与表格|下一课：结构化内容]]
[[02-列表任务与表格#任务清单|直接跳到任务清单]]
[Obsidian 帮助文档](https://help.obsidian.md/)
```

**渲染效果：**

- [[Obsidian知识/10-基础/01-Markdown基础/02-列表任务与表格|02-列表任务与表格]]
- [[Obsidian知识/10-基础/01-Markdown基础/02-列表任务与表格|下一课：结构化内容]]
- [[Obsidian知识/10-基础/01-Markdown基础/02-列表任务与表格#任务清单|直接跳到任务清单]]
- [Obsidian 帮助文档](https://help.obsidian.md/)

> [!tip] 链接、标签还是文件夹？
> 文件夹回答“它放在哪里”，标签回答“它属于哪些横切类别”，链接回答“它和什么有关”。一篇笔记可以同时使用三者。

## 行内标签

井号加文字会生成可点击标签；斜杠可以表达嵌套分类。井号前留一个空格，标签中不要放空格。

**源码：**

```markdown
#playground/demo #主题/Markdown
```

**渲染效果：**

#playground/demo #主题/Markdown

顶部 frontmatter 中的 `tags` 也会进入同一个标签系统。标签适合聚合，链接更适合表达两个具体概念之间的关系。

## 分隔线与快捷输入

单独一行的三个连字符会生成分隔线：

```markdown
---
```

注意：文件最顶部成对的 `---` 是 frontmatter；正文里的单独 `---` 才是分隔线。
