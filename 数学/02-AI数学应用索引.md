# AI 数学应用索引

本页连接“我看到了一个模型术语”与“我需要补哪段数学”。它不是把数学压缩成速记：定义、推导、假设、反例和练习仍以 `数学/` 各学科页面为准；AI 页面只保留具体模型与工程语境。读到一个公式时，先确认符号含义，再沿本页回到权威数学页。

> [!note] 本页的唯一职责：按“任务与现象”找先修
> 它是给初学者和排障者的任务入口：从 attention、量化、采样或 `NaN` 等现象找到学科课程。若要查“公式 → 工程检查点”的稳定对照，使用 [[数学/90-资源/01-公式到AI应用映射|公式到 AI 应用映射]]；若要继续到代码、系统和工具实践，使用 [[AI/90-资源/01-概念数学实现与工具映射|概念—数学—实现—工具映射]]。三页是三种视图，不各自复制数学推导。

## 怎么双向使用这个索引

- **从应用回数学：** 例如看到“softmax、交叉熵、注意力”，先在下表找到概念，再打开对应数学页；不要只把 API 参数或公式片段当作理解。
- **从数学回应用：** 例如学完“矩阵乘法”或“条件概率”，在下表找一个模型场景，回答它的输入、输出、假设和失败边界。
- **从实现回检查：** 若结果出现 `NaN`、不收敛、显存/精度异常或指标漂移，先查看数值与数据假设，再去调参。实现错误、数值误差和模型假设不成立是不同问题。

## 一次可验证的回查练习

任选一个你见过的模型术语，例如“交叉熵”或“attention”，在笔记中完成四行：

1. 写下输入对象和输出对象（不要只写符号）。
2. 链接到本页表格中对应的数学 MOC。
3. 写出一个前提或边界，例如分布是否归一化、矩阵形状是否匹配、是否存在零向量。
4. 写出一个可观察检查，例如用两个类别的玩具分布手算，或打印张量形状和数值范围。

完成标准：你能从模型术语回到一个数学定义，也能从该定义说出至少一个应用与一个不适用或需谨慎的边界。
