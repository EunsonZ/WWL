# 金融监管、银行与资本市场（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：中央金融统筹、中央银行、银行保险与非银行金融监管、证券期货监管、地方金融管理、支付、金融消费者保护及风险处置接口。
- 本文区分机构改革后的现实分工与尚未同步完成的法律修订，避免把政策组织结构直接当成成文法条。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 监管架构 | 2023年党和国家机构改革后，中央金融委员会统筹，人民银行承担货币政策和宏观审慎等职责，国家金融监督管理总局监管证券业之外的金融业，证监会监管资本市场。 |
| 法律基础 | 人民银行法、商业银行法、银行业监督管理法、证券法及保险、信托、基金、期货等专门制度并行；机构变化快于部分上位法更新。 |
| 支付 | 《非银行支付机构监督管理条例》自2024-05-01施行，支付业务许可、备付金、公司治理和用户权益进入行政法规层级。 |
| 金融消费者 | 2024年三部门明确分工：金融监管总局统筹并负责银行保险领域，人民银行负责支付、征信等职责范围，证监会负责证券期货基金领域。 |
| 在审立法 | 金融法草案由司法部等五部门于**2026-03-20至04-19**公开征求意见，后于**2026-06-23**提请十四届全国人大常委会第二十三次会议首次审议；截至核对日尚未表决通过、公布或施行。金融稳定法草案、人民银行法修订草案及银行业监管相关修法也仍处立法程序，均不得视为现行法律。 |

## 现行结构摘要

1. **统筹、宏观调控与微观监管分层。** 中央金融统筹机制决定重大方向；人民银行制定执行货币政策并负责宏观审慎、金融市场基础设施和支付结算等；国家外汇管理局由人民银行管理。
2. **证券业之外集中监管。** 国家金融监督管理总局对银行、保险、信托、金融资产管理、金融租赁、消费金融等实施机构和行为监管，并承担相应消费者保护与风险处置职责。
3. **资本市场专门监管。** 证监会监管证券、基金、期货及交易场所，证券发行实行注册制度框架，信息披露、持续监管、市场交易和违法追责构成主线。
4. **中央与地方共同管理风险。** 地方金融管理部门承担地方类金融组织日常监管和属地风险处置责任，中央金融管理部门制定统一规则并监督；非法集资处置由地方政府牵头、多部门协作。
5. **风险安全网由多机制组成。** 存款保险、资本与流动性要求、审慎监管、最后贷款人安排、行业保障基金、接管或重组及司法程序共同发挥作用，但不同机构适用的触发条件和损失承担顺序分散在多部规则中。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 货币政策—财政政策 | 国债、政府存款、政策性金融、地方债和房地产等会同时影响流动性、信用和财政风险，需要跨部门协调。 |
| 宏观审慎—机构监管 | 人民银行关注系统性风险与总体杠杆，金融监管总局和证监会关注机构、产品与市场行为，数据和措施需相互衔接。 |
| 中央监管—地方处置 | 地方承担属地风险责任，但大型机构牌照、规则和流动性支持主要在中央层面，风险识别、问责和资源来源可能分离。 |
| 银行—资本市场 | 银行理财、托管、债券承销、同业业务和金融集团使银行监管与证券监管交叉。 |
| 平台—支付—信贷 | 大型平台可同时连接交易数据、支付、征信和信贷导流，涉及金融许可、数据保护、竞争及消费者规则。 |
| 行政处置—司法清算 | 接管、风险化解、资产转移和破产清算会影响存款人、投资者、普通债权人和公共资金的损失顺序。 |

## 可观察约束与信息缺口

- 监管机构已重组，而部分基本法律仍沿用旧机构名称和职责设计，现实授权需要通过多层规范解释衔接。
- 跨市场、跨行业和金融控股集团的数据口径、风险归属与联合执法结果未形成统一的公众视图。
- 地方风险处置责任明确，但何种情况下可获得中央流动性、财政或行业基金支持，公开触发规则有限。
- 金融机构处置中的股东、次级债、普通债权人、存款保险基金和财政资金承担顺序分散，公众难以事前预判。
- 金融消费者投诉由多个机关分工承接，复杂产品可能横跨支付、银行、证券和数据争议，统一裁决和赔偿渠道不足。
- 资本市场信息披露已有统一规则，但违法所得认定、投资者因果关系证明、代表人诉讼覆盖和实际赔偿仍存在落差。

## 古国改革需回答的问题

1. 中央银行的目标排序、政策工具独立性、紧急流动性权限和民主问责如何同时成立？
2. 金融监管采用统一监管、双峰监管还是行业分业；跨行业产品由谁作最终分类？
3. 系统性风险识别、压力测试和监管数据应公开到何种程度，谁审计监管机关自身？
4. 银行或金融集团失败时，何时接管、由谁估值、债权人按何顺序承担损失，公共资金使用需要何种批准？
5. 地方金融组织的准入、日常监管和风险兜底怎样避免权责错配？
6. 是否设立跨行业金融消费者申诉专员及具有约束力的低成本裁决机制？
7. 资本市场注册、持续披露、做空与操纵监管、集体赔偿和退市保护如何形成闭环？

## 隔离提示

本文件只记录现实金融架构与生效状态。古国正文必须更换金融机构、交易场所和保障基金名称，重新起草监管授权与处置程序；任何现实草案只能作为待决问题，不得移作古国条文或当作现实既成制度。
