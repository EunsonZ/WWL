# 基准与精密误差预算：先把每种误差放回端口

一个“精度1 μV”的运放，不能独自保证整机读数精度。输入偏置电流经过源电阻、参考源被负载拉低、电阻比随温度变化、校准后又发生漂移，都可能比标称失调大。需要一份每项都有单位、条件和观察时间的账本。

初学入口：先读下面单位表，把误差都折算到同一测量端口，再看2.5 V基准的数值账本。快速入口：从有符号输入误差式开始，区分保证界、标准差、峰峰噪声和校准残余。两入口共用同一模型、同一完整例子与四道迁移题。

## 运放误差的单位与有符号模型

| 项目 | 原始单位与含义 | 折算时必须保留的条件 |
|---|---|---|
| Vos | V，输入差模等效失调 | 指定供电、共模、温度、时间与符号约定 |
| Ib+、Ib− | A，两个输入端DC电流 | 流入/流出符号、源电阻、反馈等效电阻；不是A/√Hz |
| CMRR | dB，共模变化到输入等效差模变化的抑制比 | 共模区间、频率；变化相对校准点 |
| PSRR | dB或μV/V，供电变化到输入等效失调 | 数据手册定义、哪条供电轨、频率和供电范围 |
| Vos温漂 | V/K或μV/°C | 局部斜率、全范围box法或给定曲线，不混同 |
| 电阻比漂移 | ppm/K或指定温区的比值界 | 两只电阻的相关跟踪，不是各自TCR简单抵消 |
| 长期漂移 | 指定观察时段的ppm或V | 时间、老化、湿度与焊接条件；不随意变成每小时斜率 |
| 噪声 | V/√Hz、A/√Hz、带宽内Vrms或Vpp | 频带、PSD单双边、观测时间、概率与相关性 |

定义非反相端有效电压为 vin−Ib+Rs+Vos，Ib都取流入端口为正。反相端Rf反馈、Rg接参考Vref，N=1+Rf/Rg，Req=Rf∥Rg。对反相端KCL，vo=Nv−−(N−1)Vref+Ib−Rf；有限A给 vo=A(v+−v−)。整理

\[
v_o=\frac{A}{A+N}\{Nv_{in}-(N-1)V_{ref}+N[V_{os}-I_{b+}R_s+I_{b-}R_{eq}]\}.
\]

因此等效输入失调是 Vos−Ib+Rs+Ib−Req。常见“两个电阻相等可以消Ib”只在电流相等且有符号匹配、Rs=Req时成立；Ib+和Ib−不相等留下 IOS 的贡献，不能用平均Ib的典型值当保证抵消。

若 vin=Vref+vs，输出为 A/(A+N)[Vref+Nvs+Ne]。有限A使信号增益少一点，也使参考中心少一点。N=20、A0=10⁶、Vref2.5 V、vs20 mV时，理想输出2.900000 V，有限A且e=0得到2.899942 V，少57.999 μV，包含中心约−49.999 μV与信号约−8.000 μV。只算N/A的信号比例会漏中心误差。与 [[电子电路/40-反馈噪声与混合信号/03-ADC驱动建立与弱信号预算#偏置基准不是要乘千倍的信号|已有仿射基准式]] 的端口定义一致。

## 一份运放误差的有限数例

教学参数：Rf190 kΩ、Rg10 kΩ，所以N=20、Req9.5 kΩ；Rs2 kΩ，Vos=+10 μV，Ib+=5 nA、Ib−=6 nA。e=10−10+57=57 μV，输出增量约20×57 μV=1.140 mV（有限A再乘0.999980）。这是带符号实例；若只有绝对界，保守输入界应10+10+57=77 μV，而不是从未知符号中假造抵消。

若从校准状态共模变化2 V，假定该范围内有效DC CMRR下界100 dB，则新增输入等效界 ≤2/10^(100/20)=20 μV，输出约400 μV。若供电变化0.2 V，假定对应DC PSRR下界110 dB，则输入等效界≤0.632456 μV，输出约12.649 μV。两个“dB”都通过20log电压比进入；如果数据手册PSRR直接写 μV/V，就使用那个斜率，不能再做一次dB换算。

另假定在校准点附近20 K内有独立保证的Vos斜率界0.05 μV/K，则输入漂移界1 μV、输出20 μV。若此数字实际是125 K全温box法系数，不能据此保证任意20 K子区间的最大变化也只有1 μV。电阻比 k=19 的跟踪斜率界2 ppm/K，在20 K内有 |Δk/k|≤40 ppm，N=1+k，所以 |ΔN/N|≤(19/20)40 ppm=38 ppm。对0.4 V的放大信号部分，误差15.2 μV；不把整个2.9 V参考中心乘以同样信号增益误差。

这些参数是教学假设，**没有声称来自OPA189保证表**。实际表格的条件很具体：例如 [OPA189，SBOS830I，2021修订，印刷页9–11](https://www.ti.com/lit/ds/symlink/opa189.pdf)将共模范围、温度、电流、负载与频率分开列出；轨到轨输出并不保证输入可到两条电源轨。核对条件的方法见 [[电子电路/22-半导体与真实元件/06-数据手册测试条件与模型来源|数据手册测试条件]]。从首页一个典型值推断全温误差是不完整的证据。

## 基准端口既供电压也供电荷

![[电子电路/80-实践/21-传感放大与滤波/assets/reference-load.svg|425]]

DC模型为理想电压源V0串输出电阻Ro。负载电流变化ΔI使参考变化约−RoΔI；Ro=0.1 Ω、ΔI=1 mA时，−0.1 mV，相对2.5 V是−40 ppm。若实际只是电阻负载，需解 vREF=V0Rload/(Ro+Rload)，不把负载电流当完全独立恒定。

ADC参考端可能在每个判位或采集事件取走电荷，瞬时电流与平均电流不同。若一个短事件取走Δq、补充来不及，局部旁路电容使Δv≈−Δq/Cref；随后要由参考/缓冲器补回。例Δq=10 pC、Cref=100 nF时约−100 μV；并不能仅凭此计算认定每次转化都已重新建立。ESR、缓冲输出阻抗、事件间隔、环路稳定与参考噪声仍需验证。[TI SNAA320B，2024修订，印刷页10–11](https://www.ti.com/lit/pdf/snaa320)用于核对参考驱动的动态端口问题。本图是CPU前的简化模型，不画一个“无限电流精密源”掩盖它。

基准噪声会乘ADC输入占参考满量程的比例，不能总等价为与输入无关的固定偏移。ADC输出码理想正比vin/vREF，微扰为 Δcode/code≈Δvin/vin−ΔvREF/vREF；近零输入时宜用绝对码误差式，避免除以零。若传感器激励和ADC参考来自同一源，比率测量可能抵消共同变化，但只有同时性、端口加载、滤波和相关性足够匹配时才成立。

## 保证界、校准与RSS是三件事

教学2.5 V参考的误差分配如下。这里每个界都是假设已获保证的工程分配，尤其长期项不是把典型老化值升级成保证；真实设计须回填器件/实测证据。

| 界项 | 假定条件 | 归一化到2.5V |
|---|---|---:|
| 初始准确度 | 校准前、指定温度 | 500 ppm =1.250 mV |
| 全温box温漂 | max−min除125 K温区，系数≤3 ppm/K | 全区峰差≤375 ppm =0.9375 mV |
| 长期变化 | 指定1000 h观察时段与环境的分配界 | 20 ppm =50 μV |
| 负载变化 | Ro≤0.1 Ω、ΔI≤1 mA | 40 ppm =100 μV |
| 输入线性调整 | ≤10 ppm/V、供电变化≤0.2 V | 2 ppm =5 μV |

box温漂用全区峰差作相对校准温度的保守界；不能把这个系数乘任意小ΔT而得到未提供的局部保证。焊接偏移若发生在出厂校准后，须另列；长期变化没有定义到1000 h以外，所以既不线性外推，也不凭“通常平方根”外推。

最坏绝对界相加937 ppm，即2.3425 mV。假定在实际板上、指定温度与负载做理想消初始偏移的校准，并有10 ppm校准残余，则剩余界375+20+40+2+10=447 ppm，即1.1175 mV。校准残余包含标准源/仪表误差、量化、温度控制、拟合残差；不能写成零。一次校准不消温漂和未来老化。两点仿射校准可消静态增益与偏置，非线性和动态建立误差仍在；多温度校准只有在温度测量、插值曲线与重复性已获证据时才减少全温界。

RSS要求输入项是已定义随机变量的标准差。若五项确有σ=[50,10,5,4,1] ppm且零均值、互不相关，σ总=√(50²+10²+5²+4²+1²)=51.4004 ppm，即128.501 μVrms。这个σ列表是另一份统计模型，**不是上表最大误差直接开方相加**。相关项应使用Var(e)=Σσi²+2ΣCov(ei,ej)；共同参考、同片温漂或同批电阻往往相关。未知分布/相关性时，保留界或明确无法给出统计置信度。给RSS结果也不意味着自动得到“3σ保证”。[SNAA320B印刷页2–6](https://www.ti.com/lit/pdf/snaa320)用于区分初始、温度、校准和线调整；本页统计条件是显式概率模型，未把其应用性RSS例子当作最大界的定理。

5 μVpp的0.1–10 Hz噪声不能无条件除6.6得RMS。需要分布、观测时长、带宽与峰值置信约定；谱积分得到RMS仍与最长时间的漂移不同。PSRR(f)会随频率变化，低频DC数值不能用于高频纹波。随机噪声预算、DC保证界和动态采样建立应分别给出判据。

## 四道带理由的迁移题

1. Rs=Req，但Ib+=5 nA、Ib−=6 nA，偏置误差为零吗？答：不是，剩(6−5)nA×Req。Req9.5 kΩ时9.5 μV输入、约190 μV输出；相等电阻不能消掉不相等电流。
2. 全温125 K的box法3 ppm/K，工作温度只变10 K，能承诺30 ppm吗？答：不能，没有局部变化约束。可保留375 ppm保守峰差，或取得该10 K区段保证/测得曲线及测量不确定度。
3. 把上表五个最大误差做RSS，结果更小，可以宣称更精密吗？答：不可以，最大界没有给出σ与相关性。独立零均值统计模型才可RSS；同号系统误差可能同时叠加，最坏界才承诺端点。
4. 比率传感器和ADC共享2.5 V参考，初始准确度完全不必预算吗？答：静态理想共同乘法项可以消，但两端负载、动态电荷、分压比温漂、延迟不匹配和非比率项仍须预算。能写出vin=kVref并指出ADC读数k只在共同参考成立时抵消，是合格推导。
