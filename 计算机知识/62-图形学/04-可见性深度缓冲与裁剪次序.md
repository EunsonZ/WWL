# 可见性、深度缓冲与裁剪次序

屏幕重叠并不表示几何相同。为每个像素存目前最近的不透明表面深度，收到新的覆盖样本时比较，获胜才写颜色和深度。固定本链 d=(z_NDC+1)/2∈[0,1]，近处小，比较 LESS；教学代码初值 +∞，保证恰在远面 d=1 也可画。实际 API 若清为 1 且 LESS，则恰为 1 的样本不通过，要结合深度状态解释。

本链相机距离 t=−z_view>0 给

$$z_{NDC}=1.25-\frac{2.25}{t},\qquad d=1.125-\frac{1.125}{t}.$$

这是非线性距离映射：t=1→d=0，t=2→.5625，t=4→.84375，t=9→1。导数 d'(t)=1.125/t²，远处单位距离改变对应更少深度变化；量化深度可能让接近的表面落到相同值（z-fighting）。缩小 n 到几乎零却让 f 很大通常恶化常规深度精度。不同深度编码、浮点 reverse-Z 是另外的组合，不能仅把 LESS 换 GREATER 而保留此 P 和清除值。[Cornell Pipeline 讲义第 8–10、16 页](https://www.cs.cornell.edu/courses/cs4620/2015fa/lectures/17pipelineWeb.pdf) 对照 z-buffer 的最近样本和屏幕深度。

完整例题：本链 p=(32.5,32.5) 的 z_NDC=.27880859375，所以 d=.639404296875。放一片灰色后景，world=view 顶点 (−2,−2,−5)、(2,−2,−5)、(0,2,−5)，同一 p 被它覆盖，后景深度 d=.9。先画灰色得 .9，再画前景 .639404296875<.9 覆盖；反顺序时灰色比较失败，颜色相同。这是实验图中的遮挡，背景不是静态涂色。

次序应是对象→world→view→clip→六平面裁剪→除 w→视口→覆盖/插值→深度/着色→颜色输出。先把近面外顶点除 w 可能造成极大包围盒和穿过相机的伪三角形；仅在最后丢弃 depth<0 的 fragment 无法补回正确裁剪几何。背面剔除是对有向表面朝向的优化，深度测试是逐样本可见性，两者目的不同；本代码不做背面剔除，正反绕序都能画。单面材料和封闭网格不能据此自动模拟。

LESS 在深度恰相等时保留先到的样本；因此“任意绘制顺序结果相同”限于赢家深度有严格区别的普通不透明情形。共面不同颜色的面会受顺序和精度影响，不能替同一几何重复建面。

透明失败例：红色 alpha=.5 盖在蓝色上，C=.5R+.5B。若只让最近 fragment 写颜色并深度，后层颜色被丢掉；红、蓝透明层互换合成结果也不同。常见办法先画不透明物，再按每个样本正确的由后向前顺序合成透明层，通常测试不透明深度而不写透明深度；单纯按物体中心排序在互相穿插/遮挡循环时失败，需要切分或更专门的透明算法。此 renderer 没有实现透明，不应用其图验证 alpha 行为；合成数值去读[[计算机知识/60-数据编码与媒体系统/05-图像表示色彩空间采样与图像编码|线性光及 premultiplied alpha]]。

练习：两片投影一致的面位于 t=2、4，各自深度多少，哪片获胜？答案 .5625、.84375，t=2 获胜。若两片都 t=2，用 LESS 能保证换序颜色不变吗？不能，等深度先到者保留。继续到 [[计算机知识/62-图形学/05-法线光照与渲染边界|法线与光照]]。
