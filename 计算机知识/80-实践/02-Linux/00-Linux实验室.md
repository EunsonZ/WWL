# Linux 实验室

这里是 Linux 课程的可修改、可重置实验区。前两项实验只观察系统或操作专用临时目录；Arch 安装只在虚拟机或明确的备用设备上进行。

> [!danger] 不把学习变成数据恢复
> 本实验区不要求在真实系统执行分区、格式化、清空磁盘、重写 bootloader、递归删除系统目录、批量改权限或卸载驱动。看到来自网络的这类命令时，先回到课程理解对象和回退方法。

## 推荐顺序

1. [[计算机知识/80-实践/02-Linux/01-安全命令行练习|安全命令行练习]]：只在新建的临时目录练习路径、查找、管道和归档；
2. [[计算机知识/80-实践/02-Linux/02-系统观察与故障定位|系统观察与故障定位]]：用只读命令画出当前系统；
3. [[计算机知识/80-实践/02-Linux/03-Arch虚拟机安装检查单|Arch 虚拟机安装检查单]]：为安装流程设置停止点、验收和恢复证据。

## 三种实验环境

| 环境 | 适合 | 边界 |
| --- | --- | --- |
| 当前 Linux 用户账户 | 只读观察、临时目录文件操作 | 不改启动、磁盘、驱动和全局配置 |
| 容器 | 用户空间命令、包和进程实验 | 通常共享宿主 kernel，不能代表完整启动/驱动环境 |
| 虚拟机 | systemd、磁盘、引导与 Arch 安装 | 仍要做快照；快照不是异地备份 |

## 完成标准

- [ ] 我先记录 `pwd` 和实验目录，再执行文件操作；
- [ ] 我能指出哪些命令只读、哪些会写文件或改变系统状态；
- [ ] 我不把容器等同于完整虚拟机；
- [ ] 我保留变更前证据和恢复步骤；
- [ ] 我能在不使用 root 的情况下完成前两项实验。
