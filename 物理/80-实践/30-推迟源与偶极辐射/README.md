# 推迟源与偶极辐射复算

这是规定源的解析与数值交叉核对，不是自洽天线设计软件。规范、因果条件和近区适用范围见 [[物理/30-电动力学/00-电动力学-MOC|课程路线]]。代码只使用 Python 标准库，单进程单线程，不需要下载或安装依赖；本次计算墙钟约 0.029 秒，macOS `resource.getrusage` 记录包含解释器的峰值常驻内存 21,856,256 字节（约 20.84 MiB）；资源限制无需依赖多线程数值库设置。

## 手算与数值走两条路

正文先从原始源角积分推 $F(ka)$，再从势求场。源码 [retarded_dipole.py](retarded_dipole.py) 做下列不同入口的检查：

| 检查 | 数值入口与比较对象 | 本次结果 |
| --- | --- | --- |
| 有限源积分 | 直接对原来的 $e^{ikR}/R$ 核做两重 Simpson 积分，取 $a=1,r=3,k=1.2$ 的无量纲测试，比较 $F(ka)e^{ikr}/r$ | 相对差约 $1.23\times10^{-10}$ |
| 小尺寸稳定性 | 积分 $3\int_0^1u^2\operatorname{sinc}(xu)du$，对比多个 $x$ 的闭式/泰勒求值 | 所测绝对差均小于 $2\times10^{-10}$ |
| 从势恢复场 | 对复数势做中心差分，检查 $-\nabla\phi+i\omega\mathbf A$ 和 $\nabla\times\mathbf A$ | 细步长相对差小于 $2.4\times10^{-9}$ |
| 点外 Maxwell | 在无量纲点 $(1.2,0.7,1.5)$ 差分检查两条旋度、两条散度 | 细步长最大归一残差约 $6.27\times10^{-9}$，步长减半约降四倍 |
| 球面积分 | 对 $\sin^3\theta$ 数值积分，与 $4/3$ 比较 | 得到 $D_{\max}\approx1.500000000018$ |
| 有限距离平均能流 | 核对 $\operatorname{Re}[(1+i/x-1/x^2)(1-i/x)]=1$ | 所测 $kr$ 最大绝对差约 $1.43\times10^{-14}$ |

最后一行说明这类稳态偶极外场的**周期平均径向通量**在不同球面给同一辐射功率；它并没有证明整场在近区满足平面波阻抗。瞬时能流仍与近区储能交换，复场近似误差也仍存在。差分测试只在点外、无量纲 $c=\epsilon_0=\mu_0=\omega=p_0=1$ 的测试点运行；SI 数值、有限尺寸积分与脉冲窗口另行核算。它不能证明全部空间误差、边界或点源奇性。

## 复现与改条件

从本实践目录运行，用新的输出目录避免覆盖已有结果：

```bash
python3 -B retarded_dipole.py --out /tmp/wwl-retarded-dipole-recheck
```

输出包含 [results.json](results.json)、[near-far.csv](near-far.csv)、[angular-power.csv](angular-power.csv) 和三张 SVG。这里保存的是作者本次实际运行产物；脚本会重算全部数据，SVG 与 CSV 使用同一组计算结果。命令会写入指定目录，已有同名文件会被覆盖；换一个新目录即可保留旧结果。

主参数在源码顶部：$p_0=10^{-12}$ C·m、$f=100$ MHz、$a=1$ mm、$r=30$ m、脉冲持续 $T=20$ ns。脉冲只用于因果窗口，谐波用于稳态场与平均功率；代码没有以 $20$ ns 有限脉冲输出谐波稳态场。先预测再复制源码到个人实验目录改参数：

- 把频率加倍、保持 $p_0$，点偶极功率应乘 16；保留有限球因子时约为 15.9999578 倍。
- 同时把 $p_0$ 减半，等于保持源电流矩峰值，功率约为 3.99998946 倍。
- 把 $r$ 从 30 m 改为 3 m，源的 $ka$ 不变，但远场复场误差增大。总平均辐射功率不因观察球半径改变。
- 把脉冲观察距离改为 60 m，窗口整体平移，宽度仍为 $T+2a/c$。
