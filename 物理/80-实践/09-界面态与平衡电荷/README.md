# 界面态与平衡电荷：从位置数到空间解

## 同一材料卡如何进入新占据模型

先在 [[物理/50-半导体物理/12-界面态占据电荷与平衡自洽#先数界面位置，再数其中的电子|电荷态账本]] 预测：受主型态增加电子占据后，哪一项电荷变负？再到 [[物理/50-半导体物理/12-界面态占据电荷与平衡自洽#同一张材料卡的完整数例和电荷数账本|完整例]] 对照界面势、占据与 Gauss。

材料参数、共同能量参考、体 MB 统计和中性端点公式来自 [[物理/80-实践/08-异质结与Poisson自洽/README#同一参数卡的运行与输出|实践 08]]。本目录的 [inputs.json](inputs.json) 只增加固定参考片电荷、离散态的位置数/类型/能级/权重、三个网格和两个明确条件变化；[interface_charge_lab.py](interface_charge_lab.py) 从相邻实践 08 导入 `carriers`、`neutral_phi`、常数与三对角线性求解，另写含 `sigma(phi0)` 和其导数的非线性行。08 代码没有被复制或改写。将实践 09 单独移走时必须同时携带 08，或显式给 `--base-dir` 指向拥有其源码与卡的目录；不要偷偷补一份数值不同的材料卡。

默认 600 nm/侧，受主型 $N=8\times10^{14}$ m⁻²、$E_{t0}=-0.27$ eV、$\beta=w_0/w_1=1$；共同 $E_F=-0.5$ eV，无固定片电荷。体全电离与 MB 是声明的教学近似，界面使用两态 FD 权重。能级被要求在两材料共同禁带内；位置最多 100 种、网格最多 5000 格/侧、80 次 Newton 更新、24 次回溯、单步最多 0.1 V、体指数 $|\eta|\le100$。延长域也遵守 5000 格/侧，因此完整扫描的最细网格还须满足其 1.5 倍不超过该限；单次 `solve` 的域与完整 `run` 的域要分别看。概率、密度、权重、温度和预算非法，或电荷/导数/缩放/离散算术非有限时明确失败；物理 MB 尾部另验，不用数值指数许可替代。

从库根运行，Python 3 标准库即可，无安装或服务：

```bash
python3 -B '物理/80-实践/09-界面态与平衡电荷/interface_charge_lab.py'
python3 -B '物理/80-实践/09-界面态与平衡电荷/build_figures.py'
```

默认输出为本目录 `results/`；只想重建到新的实验目录时，给第一个命令 `--out /指定新目录`、第二个命令 `--results /同一目录`。脚本不会修改实践 08 或材料输入。先运行求解再绘图，图只消费本次 JSON/CSV。当前默认常规运行小于 1 秒，是本机有限任务的观测，不是跨机器保证。

## 电荷、极限与独立路线检查

[results/results.json](results/results.json) 保存实际读入的完整双材料卡、界面输入、各案例、网格差和失败分支。默认主解 $\phi_0=0.2015399962$ V、$f=0.2495746518$、$\sigma_s=-3.1989014050\times10^{-5}$ C/m²。三网格同节点差 12.654→3.164 μV；每次从当前势重算体与面电荷，再改势，4 轮更新结束。

每个空间 CSV 在界面有 A/B 两行：同一势、不同材料带边/统计，各占半格。端点也占半格。`quadrature_weight_m` 与 $n,p,N_D-N_A$ 积分成面数；回算电荷，再与控制体积累计电荷对照。`equilibrium-edges.csv` 保存中点位移与场；界面真实单侧位移来自 JSON 的半格校正，不能把两个中点差直接叫片电荷。

实际核对的对象是：

- 离散行残差、校正后的 $D(0^+)-D(0^-)=\sigma_s$，以及 $D_R-D_L=Q_{volume}/A+\sigma_s$；加入左右边界电极 $D_L,-D_R$ 后总电荷为零。各体面数与面电荷均用 SI。
- 零态回到实践 08 的零片电荷剖面；在已经自洽的占据上冻结后重新解，回到同一个固定点。它们支持模型接续，不支持将旧占据沿任意条件变化冻结。
- 共同 $E_F$ 加 0.05 eV、两外端由中性统计重算后，全势减 0.05 V，占据与场不变。源码逐点核这个参考变换。
- 与三对角空间离散不同的半无限连续首积分，将两侧位移与占据片电荷在一个标量根中联立，默认 $\phi_0=0.2015395968$ V。另将半长改成 900 nm、保持相同 $h=1.25$ nm，区分截断和网格误差；半无限根不冒充有限 Dirichlet 精确解。
- 非法负位置数、零退化权重、越界冻结概率和零迭代预算失败。中心差分核片电荷导数仅是实现自查，重要结论仍需非作者从权重、符号、守恒和独立求解路线核对。

本默认结果是标准库有限计算；真实 Obsidian 显示、商用 TCAD、硬件、材料标定、真人学习均未被这些断言认证。代码内首积分与有限网格是两条公式路线，但由同一作者实现，不把这份自查当成独立审阅。

## 先预测再改变位置数或共同费米水平

[results/space.svg](results/space.svg) 的剖面比较无态、联立态与一次性在无态势上算占据再冻结。一次性固定结果 $\phi_0=0.1774935236$ V，与联立相差约 24.046 mV；比较用同一材料与边界。

[results/occupation-and-changes.svg](results/occupation-and-changes.svg) 使用三个扫描 CSV：`occupation-sweep.csv` 由当前输入的占据律生成；`density-sweep.csv` 逐点改总位置数重解；`EF-clamp-sweep.csv` 则明确缩短到 150 nm/侧、固定原两端静电势、改变一个共同 $E_F$。扫描每侧 240 格；完整例与表取 480 格。每张图注明变量、单位、假设和比较对象。第一种 EF 中性端变换是参考变换，最后一种固定端短域是状态改变，两者不能混同。

**半引导。** 改 `density_factor` 为 2，为什么电荷绝对值不是原来的 2 倍？改 `empty_over_filled_weight` 为 2，在 $E_t=E_F$ 时应是多少占据？若想用旧固定片电荷，至少还要核哪项小量？

> [!question]- 解释性答案
> 位置数翻倍还改变势，势抬高能级后每处占据减少；默认新 $f=0.1775018644$，净负电约为原来的 1.4225 倍。权重比 2 给 $f=1/3$，不是 1/2。小扰动要核 $Nf(1-f)$ 的电荷斜率、允许的电荷/势误差与交换时间条件；改变密度还必须计新增位置。实践有 `frozen_f` 字段，可用合法 $[0,1]$ 值声明冻结模型，但不会替你证明冻结的物理时间条件。

**撤提示。** 改成多个施主/受主能级，或把一种连续 DOS 离散成有限能量小格时，哪些输入不可省？如何判断只是离散能量网格变了，还是材料/界面模型也变了？

> [!question]- 解释性答案
> 各格要保留共同 $E_{t0}$、类型、权重与面积位置数 $N_k\approx D(E_k)\Delta E_k$。用不同参考、漏掉 $\Delta E$、将 cm⁻²直接当 m⁻²、把施主空态正电重复入账都会换掉物理问题。先固定同一 DOS/支持区间，再改变能量间距核总位置数、片电荷与空间根的收敛；当前正式结果只核默认离散能级，尚未完成连续 DOS 的能量网格试验。若另加入非平衡俘获/发射或真实温度材料参数，则已是新的模型，需按影响重新核。
