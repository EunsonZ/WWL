# Schottky 接触与端口：同式复算

## 先预测两个不能混合的变化

入口 [[物理/50-半导体物理/07-功函数Schottky能带与热发射端口#同一个真空参考下分清三种能量差|功函数与内建势]]：先预测提高金属功函数会怎样改变 $\phi_{Bn},V_{bi},W,J_s$，再运行。入口 [[物理/50-半导体物理/08-Ohmic接触隧穿边界与电阻辨识#零点可线性化不等于可忽略接触|Ohmic 近似]]：先预测把接触电阻减半是否会令总电导翻倍，再跑独立的端口卡。

本实践三组输入清楚分开：同一热发射接触卡供给能带/C–V/I–V；固定带弯曲扫描仅诊断势垒宽度/WKB 指数，不生成高掺杂自洽化学势；条形体用另给有限线性 $\rho_c$，不据热发射卡宣称工艺 Ohmic。所有单位采用 SI，图上 nm、eV、kΩ、μS 仅为显示换算。

## 运行与接口

在本目录使用已有 Python 3，无第三方依赖：

```sh
python3 contact_lab.py
python3 -m unittest -v test_contact_lab.py
python3 build_figures.py
```

`contact_lab.py` 是公式和输入真源，`results.json` 是同式生成数据，`build_figures.py` 只消费该 JSON 并写三张 SVG。运行单进程单线程，标准库，数据规模为 3×161 个空间点、81 个 C–V 点、161 个 I–V 点、61 个固定带弯曲点和 3 个长度样本。源码不作 Markdown 代码镜像，无 `code-sync` 副本需要维护。

公开数值合同：`Contact` 正参数有限，需正电子势垒；`depletion(V)` 需有限 $V$ 和 $B=V_{bi}-V>0$；`spatial(x,V)` 需有限 $x\ge0$；`current` 与 `linear_error` 需有限 $V$ 且 $|V/V_T|\le500$；`barrier_diagnostic` 与 `bar_resistance` 所有输入为正有限数；长度拟合需至少两组、正有限且有不同长度。代码的这些域是数值接口，**不是物理适用区认证**：`current` 允许的 $|V/V_T|\le500$ 中大量点不满足耗尽/无击穿/无高注入/无串联压降条件；正文只使用默认小范围。`Contact` 不自动求 FD 中性和施主活化，不自动在低温/重掺杂切换模型。比较更大参数前要先依据正文撤销不成立的近似。

## 同一接触卡的独立核对

默认 $T=300\,\mathrm K$，$N_D=10^{22}\,\mathrm{m^{-3}}$ 全电离无补偿，$m_n^*=0.26m_0$、$m_p^*=0.50m_0$，单谷两自旋，$\epsilon_r=11.7$，$\chi=4.05\,\mathrm{eV}$、$W_M=4.65\,\mathrm{eV}$、$E_g=1.12\,\mathrm{eV}$；派生 $N_c,N_v,n_i$。这是本课独立教学卡，不拼接前面复合卡或旧 PN 卡的态数/本征浓度。

检查先复算不需脚本的大关系：$\phi_{Bn}=0.6\,\mathrm V$，$V_{bi}=0.6-0.1501276=0.4498724\,\mathrm V$；$J(0)=0$，$J(+0.1)/|J(-0.1)|=e^{0.1/V_T}=47.8548613$；$E_c(0)-E_{FM}=q\phi_{Bn}$ 在三种偏压下不变；金属面电荷是半导体正电荷的负数，电容 $d(Q_M/A)/dV$ 为正。

测试另从归一 Maxwell **法向速度数值积分**恢复两向发射电流，没有调用热发射前因子来构造积分答案；从空间势的中心差分核 $E=-\varphi'$、$E'=qN_D/\epsilon$；从金属电荷差分核 $C_A$；用两点 $1/C_A^2$ 差分斜率/截距恢复 $N_D,V_{bi}$。这些检验可发现两向通量漏减、重复 $1/2$、势/场符号、面积电容与总电容混淆。

## 固定带弯曲诊断与独立端口卡

宽度扫描固定 $B=0.4498724\,\mathrm V$，$N_D$ 从 $10^{22}$ 到 $10^{25}\,\mathrm{m^{-3}}$；每点记录 $W,E_{00},E_{00}/k_BT$、零法向动能 WKB 作用量和领先透射指数、$N_D/N_c$ 报警。测试独立积分 $2\int\sqrt{2m^*U(x)}dx/\hbar$，并核宽度与能量尺度的 $N_D^{\mp1/2}$ 比例。这里不生成带隙缩窄、简并占据或真实隧穿 I–V，领先指数也没有透射前因子。

条形体卡独立给 $n=10^{21}\,\mathrm{m^{-3}}$、$\mu=0.135\,\mathrm{m^2/(V\,s)}$、$A=A_c=10^{-12}\,\mathrm{m^2}$、每端 $\rho_c=10^{-8}\,\Omega\,\mathrm{m^2}$。每端 $R_c=10^4\,\Omega$；在 $L=1,2,4\,\mathrm{\mu m}$ 记录总电阻、体电阻、电导，恢复长度斜率和截距。测试另用两点差分求斜率，不借三点最小二乘函数生成期望值；检查相同 $n\mu$ 的另一组浓度/迁移率仍有相同体电阻，也检查一条 I–V 无法区分接触和体阻。

![[物理/80-实践/06-Schottky接触与端口/assets/contact-width-port.svg]]

上排是固定带弯曲的机制诊断，下排是另给端口卡。长度截距并不证明真实界面阻抗：同样的接入线常数电阻也进入截距。需要实际几何、四端测量或相应校准才知道端口所量对象；没有硬件数据时只称合成观测。

## 改参数前先说明保留的模型

半引导任务：在源码之外用 `Contact(metal_work_eV=4.70)` 比较默认卡的高度、宽度、$J_s$，先写平方根与指数两个比例。再用独立端口函数把 $\rho_c$ 减半，预测体电阻保留后总电导的变化。它们的答案与两课迁移题相同；不能把更好电导的原因混到另一张卡的参数里。

撤提示任务：有人把 $N_D$ 提至 $10^{25}\,\mathrm{m^{-3}}$ 后仍用 MB 求 $\xi$，再将 $J_s$ 乘一个 WKB 领先透射数称作“真实 Ohmic 电导”。找出至少两条错接，并提出应补的计算/观测。

解释：MB 占据已失效，需 FD/中性和重掺杂材料输入；热越垒电流与势垒下方隧穿是对同一能量分布的不同积分贡献，不能将两个代表值相乘；WKB 的单个法向能量透射率不是全部储库电流；界面、方向质量、透射前因子和工艺活化未定。下一步应构建一致的能量分辨透射/两储库占据模型，并与温度/偏压/几何依赖观测比对，本实验没有替代这些工作。
