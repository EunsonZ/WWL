## 输入、命令与实际结果

规范源码是 [solve_models.py](solve_models.py)，固定 SI 输入是 [inputs.json](inputs.json)。Python 3 标准库即可运行，不安装依赖。常数与首段一致：近似 $\mu_0=4\pi10^{-7}$ H/m、精确 $c_0=299792458$ m/s，$\epsilon_0=1/(\mu_0c_0^2)$；这个 $\mu_0$ 不宣称为现行 SI 精确值。

在此目录运行，可指定新输出目录保存变条件结果：

```bash
python3 -B solve_models.py --input inputs.json --output-dir results
```

2026-10-11 在隔离候选中以 Python 3.14.7 实际执行，退出码0：

```bash
python3 -B solve_models.py --input inputs.json --output-dir results > results/stdout.json
```

输出见 [values.json](results/values.json)、[stdout.json](results/stdout.json)、[skin-fields.csv](results/skin-fields.csv) 与 `results/` 的三张 SVG。命令会覆盖指定输出目录内同名文件；若要保留已有结果，应使用新目录。源码不复制进结果快照，当前输入与规范源码即可复算。

## 数值检查与物理解分别承担什么

矩形能量用40×40复合 Simpson 分别积分解析 $B$ 的平方与源/矢势乘积；表面回流、非线性材料能量、半空间焦耳热使用输入指定的4000个正偶数小区间。矩形网格差分只检查解析解的 PDE 残差变化，**没有求解一套有限元或离散场未知量**。磁路根用80步二分与回代，增量电感再由小扰动差分核验。

完整导体模型保留 $\sigma_c+i\omega\epsilon$，MQS 删位移项；两者使用同样表面 $H_0$ 与深处衰减边界。比较仅判断这个常本构半空间的近似，不认证整体0.1 m馈电结构的传播。平均功率中的1/2来自峰值相量约定；CSV字段写的是 $\operatorname{Re}H,\operatorname{Im}H$、幅度和平均能流，不能把峰值当RMS。

## 预测、运行、返回问题

1. 只把矩形 `a_m` 从0.02改0.04，保持 `current_A` 不变。预测新 $J_0,L'$，再跑新输出目录。答案：$J_0$减半，$L'$乘10/17；图的横轴与参数行必须显示40 mm，不能只改画面不改标题。
2. 只把磁路 `gap_m` 从0.0005改0.001。预测同电流的场强、磁能与增量电感，再看求根和图。答案：线性磁路 $L$与能量下降、气隙能量占比增加；非线性正根也下降，图中气隙应显示1 mm。它仍没有产生真实磁芯的损耗数据。
3. 只把导体 `frequency_Hz` 从 $10^6$ 改 $10^8$。预测 $\delta,d/\delta,\eta_c,kL$，再读对应字段。答案：深度除10，厚度比乘10，另外两比乘100；局部材料内 MQS 的好坏与整体传播条件须分开检查。图的 Hz 与 µm 参数和坐标应随新输入变化。
