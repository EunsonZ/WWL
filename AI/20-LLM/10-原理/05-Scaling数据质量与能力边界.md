# Scaling、数据质量与能力边界

<!-- deep-review-02 -->
> [!tip] 本轮深化：从当前概念继续追问
> Scaling 规律是在数据、架构和预算范围内拟合的经验关系；最优参数/数据比例依赖假设。重复、污染、质量和推理成本会改变实际决策。 深化与验证：[[AI/20-LLM/10-原理/09-Scaling推导数据配比与计算预算|Scaling推导数据配比与计算预算]]；[[AI/20-LLM/30-训练/14-预训练数据配方去重课程与消融|预训练数据配方去重课程与消融]]。


## 直觉：规模是配方的一部分，不是能力开关

扩大参数量、训练 token、计算量或训练时长，常会让某些平均预测指标按平滑趋势改善。这类观察被称为 scaling laws（规模规律）。它很有工程价值：能帮助估计资源和比较训练配方；但它不是“超过某个数字就必然突然聪明”的定律，更不能从训练损失直接推出事实性、安全性或社会适用性。

> [!note] 数学先修
> 经验均值、抽样波动与评测不确定性的定义见 [[数学/30-概率与统计/02-期望方差协方差与抽样|期望、方差、协方差与抽样]]；信息量与交叉熵的完整关系见 [[数学/50-信息论/01-熵交叉熵KL散度与互信息|熵、交叉熵、KL 散度与互信息]]。本页不把经验曲线升级为数学证明。

## 先拆开“规模”

| 常被叫作规模的量 | 它实际改变什么 | 不自动解决什么 |
| --- | --- | --- |
| 参数量 | 函数可表示的容量与部署成本 | 数据缺口、错误目标、访问控制 |
| 训练 token/步数 | 模型看到训练信号的数量 | 去重、版权、偏差、泄漏或污染 |
| 计算预算 | 可尝试的训练工作量 | 实验设计、评测质量和因果解释 |
| 上下文窗口 | 一次调用可放入的条件长度 | 远处信息一定被利用、资料一定可信 |
| 推理时算力 | 搜索、采样或工具循环的资源 | 结果正确、工具有权限或输出安全 |

这些轴应联合匹配。固定训练计算预算时，把几乎所有资源放在参数而不给足训练 token，或反过来用很小容量反复扫描大量数据，都可能不是有效配方。所谓 **compute-optimal** 是在特定模型族、数据、优化器和预算下寻找参数与 token 的经验平衡，不是跨任务永恒不变的常数；训练 FLOPs 最优也不等于部署显存、吞吐、能耗或数据治理最优。

### 一个假想例子

团队 A 把语料从 100 亿 token 扩到 1,000 亿 token，却没有去重，也没有把验证集从来源中隔离。训练损失可能下降，但重复内容会放大，验证集可能受污染，最后的分数无法区分“真正泛化”与“见过近似答案”。团队 B 使用更少但来源清楚、去重、时间隔离并贴合目标任务的数据，可能在实际任务上更可靠。这个例子不宣称一个普遍胜者，而是说明**数据数量、数据质量与评测设计是不同变量**。

## 数据质量是可审计的过程

“高质量数据”不应只是一句赞美。至少要记录：来源与许可、收集日期和范围、去重规则、语言/领域覆盖、个人信息和敏感内容处理、毒性/偏见风险、训练—验证—测试的隔离、已知缺口，以及删除/更正的可行性。若数据无法合法或伦理地用于预期用途，再大的规模也不会修复该边界。

还要区分：训练语料出现过某文本，不等于模型会逐字记住；模型没有逐字记住，也不等于没有隐私、版权、偏见或泄漏风险。风险判断需要针对数据、训练、访问方式和攻击场景做独立证据。

## 能力主张怎样才可检验

把“模型会推理”“模型有某种能力”改写为任务和协议：

1. 明确输入分布、输出格式、允许的工具和时间截止点。
2. 定义正确性或评分规则，保留未答、拒答和不确定回答的处理方式。
3. 用与训练隔离的、代表性的数据做评测，报告样本量、失败类别和不确定性。
4. 加入对抗样本、分布外样本与关键反例；不要只挑成功演示。
5. 对外推结论写明限制：评测集上的平均分不等于所有用户、语言或时间点上的表现。

这也解释了为何“emergence（涌现）”需要谨慎：某个离散指标跨过阈值时看似突变，可能来自评分规则、任务难度、提示方式或测量分辨率。先检查连续指标与复现，而不是把图形拐点直接解释成新本质。

## 练习

1. 为一个“客服摘要”模型列出四条数据质量记录和三项评测边界。
2. 为什么训练损失下降不能单独证明模型更安全或更真实？
3. 给出一种会让“能力突然出现”看起来比实际更突兀的评测设计选择。
4. 固定训练计算预算时，解释为什么“只把参数量增大十倍”不构成完整 scaling 配方，并列出至少三个需要一起报告的量。

## 成功标准

你能分别讨论参数、训练 token、训练计算、上下文与推理预算；能说明 compute-optimal 是带前提的经验资源分配；能把“更强”改写为可复查的任务主张，并会在规模曲线旁同时问数据来源、污染、评测协议、成本与已知失败。
