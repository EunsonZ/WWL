# 综合毕业挑战

不照逐步教程，为一个你真正关心的小主题建立可用的 Obsidian 微型系统。主题可以是一次旅行、一门课程、一个研究问题、一个产品想法或一项生活计划。

> [!rule] 限制会帮助你完成
> 最多创建 8 篇 Markdown、1 个 Canvas、1 个 Base 和 2 个模板；最多选择 2 个社区插件。重点是关系和工作流，不是堆数量。

## 必交成果

### 1. 一个项目或主题主页

至少包含：

- 一句话目标。
- `type`、`status`、`topics` 属性。
- 3 条指向真实笔记的内部链接。
- 当前下一步。
- 一个嵌入的 Base 或相关视图链接。

可参考：[[Obsidian知识/30-实践/03-示例项目/周末读书会/00-周末读书会项目主页|00-周末读书会项目主页]]、[[Obsidian知识/90-资源/01-模板/核心模板/项目|核心模板-项目]]。

### 2. 三张内容笔记

三张笔记必须承担不同角色，例如：

- 概念或判断。
- 人物、资料或来源。
- 会议、决定或实验记录。

其中至少一张应有别名，一张包含 heading link 或 block embed，一张被另外两张反向链接。

### 3. 一篇日记和三个任务

日记链接项目，三个任务至少包含：

- 一个已完成任务。
- 一个有明确下一步的未完成任务。
- 一个链接到人物、资料或概念的任务。

可参考：[[Obsidian知识/20-功能/03-完整工作流/02-每日计划任务与复盘|02-每日计划任务与复盘]]。

### 4. 一个 Base

基于属性显示你的内容笔记，至少包含：

- 一个过滤条件。
- 一个排序条件。
- 两种有意义的视图或一种视图加分组。

不要把正文复制进表格；Base 展示的仍是原始 Markdown 文件。

### 5. 一个 Canvas

用真实笔记卡表达项目结构，并至少包含：

- 一个分组。
- 三张笔记卡。
- 两条带语义的连线。
- 一张说明“下一步”的文本卡。

对照 [[Obsidian知识/20-功能/01-官方插件实验室/04-Canvas|Canvas]] 与 [[Obsidian知识/20-功能/02-社区插件实验室/08-Excalidraw|08-Excalidraw]]，解释为什么这里选择 Canvas。

### 6. 一次搜索和一次反向链接验证

- 写一个能找到目标笔记而排除无关文件的搜索条件。
- 从中心笔记的 Backlinks 找到日记或项目来源。
- 打开局部图谱，检查是否存在意外孤立节点。

### 7. 一份插件取舍说明

最多选择两个社区插件，并为每个回答：

1. 解决什么具体摩擦？
2. 原生替代是什么？
3. 关闭插件后数据是否仍可读？
4. 最终保留、可选还是不用？

记录到 [[Obsidian知识/20-功能/02-社区插件实验室/13-插件实验报告|13-插件实验报告]] 或 [[Obsidian知识/30-实践/01-实验区/我的插件实验报告|我的插件实验报告]]。

## 验收清单

- [ ] 首页能在两次点击内到达全部成果。
- [ ] Markdown 在源码模式中仍清晰可读。
- [ ] 没有为了图谱密度添加无意义链接。
- [ ] 文件夹、标签、属性和链接没有重复表达全部信息。
- [ ] Base 能正确过滤和排序。
- [ ] Canvas 使用真实笔记卡，不是另存一份知识。
- [ ] 日记的记录能通过 Backlinks 回到项目。
- [ ] 任务有明确动词和下一步。
- [ ] 至少使用一次 block link 或 embed。
- [ ] 能说出每个社区插件的原生替代。
- [ ] 知道至少一种恢复单个文件的方法。

## 自评

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 内容 | 只有占位文字 | 有信息但较零散 | 能独立理解且有自己的判断 |
| 连接 | 无或随意链接 | 有基本互链 | 关系明确并能通过 Backlinks 追溯 |
| 结构 | 属性混乱 | 基本一致 | Base、Search 能稳定使用 |
| 工作流 | 只有静态文件 | 有部分步骤 | 捕获、执行/输出、复盘形成闭环 |
| 可维护性 | 依赖插件或重复数据 | 基本可读 | 关闭插件仍可读，入口和恢复清楚 |

总分 7 分以上即通关；低于 7 分时，只修复得分最低的一个维度，不要推倒重来。

> [!success] 真正的毕业标准
> 你能够解释自己的结构为什么存在，也知道什么时候不需要某个功能。一个简单但持续使用的 Vault，胜过一个复杂却无人维护的系统。

## 挑战完成后

回到 [[Obsidian知识/00-开始/00-Playground-首页|00-Playground-首页]]，把常用入口加入 Bookmark；在 [[Obsidian知识/40-视图/02-Bases/课程进度.base|课程进度.base]] 标记完成；最后在今天的日记写下“我会保留的三件事”和“我决定不用的三件事”。
