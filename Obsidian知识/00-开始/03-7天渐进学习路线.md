# 7 天渐进学习路线

每天 30–60 分钟即可。重点是留下自己的笔记、链接和判断，不是把教程全部读完。

## 第 1 天：先会写

- [ ] 阅读 [[Obsidian知识/10-基础/01-Markdown基础/00-Markdown基础-MOC|Markdown 基础 MOC]]。
- [ ] 完成 [[Obsidian知识/10-基础/01-Markdown基础/01-基础排版|基础排版]] 和 [[Obsidian知识/10-基础/01-Markdown基础/02-列表任务与表格|02-列表任务与表格]]。
- [ ] 在 [[Obsidian知识/30-实践/01-实验区/Markdown/01-自由草稿纸|自由草稿纸]] 写一页包含标题、列表、任务和表格的笔记。

**当天成果**：一篇不依赖富文本编辑器也能理解的 Markdown 文件。

## 第 2 天：让笔记互相找到

- [ ] 学习 [[Obsidian知识/10-基础/02-链接与知识网络/01-Wikilink、别名与未解析链接|Wikilink、别名与未解析链接]]。
- [ ] 完成 [[Obsidian知识/10-基础/02-链接与知识网络/02-标题链接、块链接与嵌入|标题链接、块链接与嵌入]]。
- [ ] 在 [[Obsidian知识/30-实践/01-实验区/链接迷宫/00-链接迷宫-说明|链接迷宫]] 修复至少三条关系。
- [ ] 检查 Backlinks、Outgoing Links 和局部图谱。

**当天成果**：三篇相互连接的笔记，以及一个被复用的块。

## 第 3 天：不用翻文件夹也能找到内容

- [ ] 给实验笔记添加属性：[[Obsidian知识/10-基础/03-属性标签与检索/01-属性类型|属性类型]]。
- [ ] 添加一个嵌套标签：[[Obsidian知识/10-基础/03-属性标签与检索/02-嵌套标签|嵌套标签]]。
- [ ] 完成 [[Obsidian知识/10-基础/03-属性标签与检索/07-检索挑战|检索挑战]]。
- [ ] 将一个常用搜索加入 Bookmarks。

**当天成果**：能用属性、标签和搜索回答“哪篇笔记符合这些条件”。

## 第 4 天：掌握官方工作台

- [ ] 用 [[Obsidian知识/20-功能/01-官方插件实验室/02-核心 Templates|核心 Templates]] 创建一篇新笔记。
- [ ] 用 [[Obsidian知识/20-功能/01-官方插件实验室/03-Daily Notes|Daily Notes]] 创建日记并链接项目。
- [ ] 在 [[Obsidian知识/20-功能/01-官方插件实验室/04-Canvas|Canvas]] 增加一个节点。
- [ ] 在 [[Obsidian知识/20-功能/01-官方插件实验室/05-Bases|Bases]] 查看课程文件及作者标记的教材状态。

**当天成果**：一篇日记、一个模板生成的笔记、一个 Canvas 修改和一个 Base 过滤视图。

## 第 5 天：跑通一个工作流

从下面选择一条，不必全做：

- 捕获与整理：[[Obsidian知识/20-功能/03-完整工作流/01-从收件箱到常青笔记|01-从收件箱到常青笔记]]
- 每日执行：[[Obsidian知识/20-功能/03-完整工作流/02-每日计划任务与复盘|02-每日计划任务与复盘]]
- 项目管理：[[Obsidian知识/20-功能/03-完整工作流/03-会议记录与项目管理|03-会议记录与项目管理]]
- 阅读学习：[[Obsidian知识/20-功能/03-完整工作流/04-阅读批注到知识卡片|04-阅读批注到知识卡片]]

**当天成果**：一个从输入到输出的完整闭环，而不是孤立功能演示。

## 第 6 天：审慎尝试社区插件

- [ ] 先读 [[Obsidian知识/20-功能/02-社区插件实验室/01-社区插件的安全与选型|01-社区插件的安全与选型]]。
- [ ] 完成一个捕获/模板实验：[[Obsidian知识/20-功能/02-社区插件实验室/02-Templater与QuickAdd|02-Templater与QuickAdd]]。
- [ ] 完成一个查询实验：[[Obsidian知识/20-功能/02-社区插件实验室/03-Dataview与Bases对比|03-Dataview与Bases对比]]。
- [ ] 再从 [[Obsidian知识/20-功能/02-社区插件实验室/00-社区插件实验室-MOC|00-社区插件实验室-MOC]] 选择两个真正相关的插件。
- [ ] 在 [[Obsidian知识/20-功能/02-社区插件实验室/13-插件实验报告|13-插件实验报告]] 记录保留或不用的理由。

**当天成果**：至少四个基于实验的插件判断，而不是“装得越多越好”。

## 第 7 天：独立完成

- [ ] 完成 [[Obsidian知识/20-功能/03-完整工作流/05-综合毕业挑战|05-综合毕业挑战]]。
- [ ] 打开自己的学习记录，检查尚未完成的练习与下一步；需要查教材时使用 [[Obsidian知识/40-视图/02-Bases/课程进度.base|课程目录视图]]。
- [ ] 用全局图谱观察自己的新节点。
- [ ] 把最常用的主页、日记或 Base 加入 Bookmark。

**当天成果**：一个包含主页、笔记、链接、属性、任务、Base 和 Canvas 的小型主题库。

> [!tip] 中断以后怎样回来
> 把本页和自己的学习记录加入 Bookmarks。在个人记录中链接正在学习的课程，并写下实际停在哪里、已做的尝试和下一步；回来时从这份记录继续。共享课程的 `status` 保持教材含义，不用于登记个人掌握。

## 一周以后

删除没有解决真实问题的复杂性，留下你实际使用的入口、模板、属性和插件。需要完整概念说明时回到 [[Obsidian知识/00-开始/06-Obsidian中文上手指南|06-Obsidian中文上手指南]]，遇到异常先查 [[Obsidian知识/90-资源/02-参考/08-常见问题与排错|常见问题与排错]]。
