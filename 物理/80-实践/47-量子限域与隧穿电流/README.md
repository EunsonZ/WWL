# 量子限域与隧穿电流：同一片、两库和有限势垒

## 运行同一张参数卡

先在 [[物理/50-半导体物理/15-量子限域子带占据与隧穿净电流#把厚度、传播方向和储库分开|几何与储库合同]] 上标出 $z$ 限域、$x$ 势垒、$y$ 模式。预测：同温同化学势时透射可以非零，净流却应为零；交换左右化学势时净流反号。这里的电流结果是每宽度 A/m，电子运动方向的 $K_e>0$ 对应传统 $+x$ 电流 $K_x=-K_e$。

[quantum_sheet_lab.py](quantum_sheet_lab.py) 是唯一求解真源，[inputs.json](inputs.json) 是十一项合成卡；只需 Python 3.10+ 标准库，无安装或商业软件。图源 [build_figures.py](build_figures.py) 仅消费本轮 CSV/JSON，不重新求方程。独立移动本目录可以运行，源码不依赖主库旧实验或隐藏输入。可阅读 [[物理/80-实践/47-量子限域与隧穿电流/SOURCE-MIRRORS#求解真源镜像|求解源码镜像]]，修改时仍以 `.py` 为真源并同步镜像。

在实际库根执行下面两条命令；第一条退出 0 后再执行第二条。输出目录要选新目录或空目录，不能覆写已有运行：

```bash
python3 -B '物理/80-实践/47-量子限域与隧穿电流/quantum_sheet_lab.py' --out /private/tmp/wwl-quantum-sheet-new-run
```

```bash
python3 -B '物理/80-实践/47-量子限域与隧穿电流/build_figures.py' --results /private/tmp/wwl-quantum-sheet-new-run
```

短预跑在第一条增加 `--prototype`，只算 160/32 网格的一个默认案例；预跑不生成完整图，因为图需要十例报告。改变卡时复制输入到自己的新文件，第一条增加 `--inputs /你的路径/inputs-changed.json`，输出仍用新目录。原输入与正式结果保留，避免用换目录名冒充换条件。

维护者本次执行使用库外双槽 guard、单线程、60 秒数值超时；它是本机预算约束，不是学生运行所必需的课程依赖。默认和变化卡已实际有限运行，没有改变系统环境。求积预算限制不构成硬内存上限或跨机器时长保证。

| 输入字段 | 默认 | 含义与单位 |
| --- | --- | --- |
| `mass_ratio` | 0.20 | 同一各向同性 $m^*/m_0$，单谷 |
| `well_nm` | 8.0 | 双 Dirichlet 硬墙的厚度，nm |
| `barrier_eV`、`barrier_nm` | 0.20、3.0 | 沿 $x$ 的固定矩形势高度 eV、宽度 nm |
| `temperature_K` | 300.0 | 两库相同温度，K |
| `mu_left_eV`、`mu_right_eV` | 0.080、0.060 | 同一未限域导带底零参考下的两库化学势，eV |
| `cutoff_eV` | 0.8 | 分别截 $E_x,E_y$，不是截总能量 |
| `subbands` | 6 | 保留 $n=1\ldots6$ 的离散限域态 |
| `energy_steps`、`transverse_steps` | 800、128 | $E_x$ 与 $u=\sqrt{E_{y,\mathrm{eV}}}$ 的偶数 Simpson 区间数 |

许可域：质量比 0.05–1，厚度 4–30 nm，势高 0–1 eV，势宽 0.1–10 nm，温度 100–600 K，两化学势 −0.2–0.4 eV，动能截断 0.6–2 eV，2–16 子带，$E_x$ 80–4000 偶数区间，$u$ 20–512 偶数区间。输入布尔值不能代替数字，三个计数须为实际整数；未知/缺失/重复键、NaN/Infinity、出域均 clean 非零退出。程序完整例还要做倍密网格及宽垒变式，因此若倍密超过上限、宽垒超过 10 nm或半网格成为奇数，它会在写结果前拒绝。若希望使用许可域上缘，应先调整基础网格/势宽，而非误认只有默认案例在运行。

这张卡只提供同温两库；输入不同两温字段会被拒绝。理论两温情况可在正文迁移题分析，真正复建需要另改求解接口并核温度分别进入各库，不把未执行迁移说成已运行。大量子带、高热尾或简并本身不使 FD 失效，但要求验截断、质量抛物近似及真实材料窗口；许可输入域不能认证物理适用性或全部精度。

## 从允许态到片电荷的固定答案

沿 $z$ 的解析归一态为 $\chi_n=\sqrt{2/L_z}\sin(n\pi z/L_z)$，$E_n=E_1n^2$。默认 $E_1=0.029377356378443$ eV，二、三子带分别为 0.117509425513772、0.264396207405987 eV。每子带二维 DOS 含两自旋，片密度用完整 FD 积分，不只保留 $E_n<\mu$ 的态。

左/右储库片密度为 $4.97091896342\times10^{16}$、$3.35735774867\times10^{16}$ m⁻²。左电子片电荷为 $-7.96429021269\times10^{-3}$ C/m²；它不含离化杂质或栅极。左库第二子带仍贡献 $4.54746390587\times10^{15}$ m⁻²，约 9.15%；$T=300$ K 下“高于费米势就完全空”会漏掉这个量。

`subbands.csv` 保存每子带边缘、左右片密度和左电子电荷；`states.csv` 保存三态（合法两子带卡只保存两态）在 241 个 $z$ 点的波函数，单位 nm⁻¹ᐟ²。用 $\int|\chi|^2dz=1$ 验归一；将密度乘 $|\chi|^2$ 得 m⁻³ 之前须将波函数从 nm 单位变回 m。偏置散射区局部电荷不由储库平衡片密度直接给出，本实践没有输出自洽 Poisson。

## 双向供应积分与电流答案

[[物理/50-半导体物理/15-量子限域子带占据与隧穿净电流#DOS 乘速度，留下每通道的流率|单通道态数×速度]] 给 $dE_x/h$；横向每宽度 $dk_y/(2\pi)$，自旋/谷仅乘 $g=2$。图和 CSV 中使用 $u=\sqrt{E_{y,\mathrm{eV}}}$，因此供给列为 $\sum_n\int du\,f_\alpha(E_n+E_x+u^2)$，单位 $\sqrt{\mathrm{eV}}$。乘上包含通量、电子电荷和 eV 转换的前因子再乘 $\mathcal T(E_x)$，得到 A m⁻¹ eV⁻¹ 的谱；按 eV 积分才给 A/m。

默认进流 8.76949708942 A/m、返回流 4.69103049237 A/m、净电子正电荷当量 $K_e=4.07846659705$ A/m；传统电流 $K_x=-4.07846659705$ A/m，宽 1 μm 时 $I_x=-4.07846659705$ μA。反射/透射实势匹配严格满足概率流守恒，左右互易率相同；谱计算显式扣返回，不把裸 $T$ 或 $E_x=0$ WKB 指数称为电流。

完整运行输出十个案例的 `*-spectrum.csv`、`subbands.csv`、`states.csv`、`results.json` 和两 SVG，共 15 个结果文件。每谱有 `Ex_eV`、`transmission`、左右 supply、forward/return/net 三谱；`results.json` 保存各案例完整卡、片密度、电荷、两流、符号转换和尾界，以及本轮输入原始字节、规范源码的 SHA256。输入只读一次，输出所存输入身份来自这次读取。正式图每条曲线用 `data-source` 指向真实 CSV 列或 JSON 路径。

## 尾界、网格与独立路线分别说明什么

`fine-default` 的 $2.36\times10^{-10}$ A/m 是实际求积细化差；它不是解析上界。`tail-default` 约 $-1.00\times10^{-9}$ A/m，同时含积分域扩大后 $\Delta E_x$ 增大的影响，不能命名成纯截尾误差。

源码独立报告 `omitted_sheet_bound_m-2`、`omitted_current_bound_A_m` 和 `cutoff_current_bound_A_m`。利用 $f\le e^{(\mu-E)/kT}$、$T\le1$ 和 $E_n=E_1n^2$，对子带几何尾及动能矩形域外的 Gaussian 尾给保守界，详见 [[物理/50-半导体物理/15-量子限域子带占据与隧穿净电流#净电流、平衡和误差分别检查|界与实际误差的区别]]。默认遗漏片密度界 $3.13319\times10^{-7}$ m⁻²，遗漏子带电流界 $4.41265\times10^{-21}$ A/m，动能域外电流界 $8.91824\times10^{-11}$ A/m。界不包含有限 Simpson 误差；高温案例截尾界上升至约 $3.07\times10^{-6}$ A/m，仍须按所需精度选窗口。

独立 runner 实际用二维 $k_x,k_y$ 中点积分重建默认流，800×256 网格给 4.078466597283182 A/m；它不调用生产 `solve()` 当正确答案。透明例另用先解析积掉 $E_x$ 的 softplus 积分，得 229.673129278838 A/m；复振幅界面匹配另核透射，最大率差 $3.33\times10^{-16}$。两 SVG 已真实 CairoSVG 渲染与目视；默认图 ylabel 与科学刻度的重叠发现后已修正并重新核对。合法势宽 4 nm 新卡完整运行得到 1.07788890368 A/m，片密度不变，说明改变沿 $x$ 障碍与改变沿 $z$ 允许态各自影响不同对象。

上述具体运行支持固定有限教学模型、真源输出和 SVG；一般证明/学习链另由独立内容审阅验收。真实 Obsidian 显示/同步、真实材料/工艺/硬件、商用 TCAD 与真人撤提示能力未验证。

## 学生复建与迁移

1. 先不用程序，写出 $E_1\propto(m^*L_z^2)^{-1}$、每子带 FD 片密度和电子片电荷；指出 $\pm k_y$、两自旋各在哪里数过。
2. 保持原始卡，按 CLI 复建；以两流相减、平衡逐模式零、反偏符号、同温透明上限检查自己的输出。只抄一个 JSON 净流值不能检验完整机制。
3. 复制卡，只把 `well_nm` 改为 12 或 `barrier_nm` 改为 4，先写预测，再用新目录重建和出图。若换小 $N$ 或大温度，先查 tail bound 和细化，不能把相同默认误差结论搬过去。
4. 回正文 [[物理/50-半导体物理/15-量子限域子带占据与隧穿净电流#先预测，再撤掉方法提示|半引导、撤提示与 MOS 迁移答案]]，解释固定势卡为何不能给真实栅压/电荷自洽或偏置 Schottky 接触。返回 [[物理/50-半导体物理/02-带边有效质量与一二三维态密度#先数 k 格点，再改变变量|态计数]] 与 [[物理/50-半导体物理/08-Ohmic接触隧穿边界与电阻辨识#变窄的势垒需要改变发射模型|隧穿转换尺度]] 时携带密度单位、通道方向、储库参考和已积分掉的变量。
