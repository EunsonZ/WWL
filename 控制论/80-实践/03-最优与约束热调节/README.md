# 实践03：最优与约束热调节

这组实验只依赖Python标准库，单进程串行运算，没有训练、联网、硬件输出或新依赖安装。它把 [[控制论/10-系统课程/07-有限时域最优控制Hamiltonian与终点条件|连续边值最优]]、[[控制论/10-系统课程/08-约束预测控制从有限QP到终端保证|两步QP]] 和 [[控制论/10-系统课程/09-有界扰动不变管与模型误差|扰动管]] 放进一份可复算输入；先读模型、单位和条件，再运行程序。

## 源码和执行接口

[optimal_tube_lab.py](optimal_tube_lab.py)是代码真源，[[控制论/80-实践/03-最优与约束热调节/code-sync/optimal_tube_lab|code-sync镜像]]逐字展示源码，修改源码时需同步镜像。程序相对自身目录写入 `assets/`，因此工作目录不影响产物位置。命令：

```sh
python3 -B 控制论/80-实践/03-最优与约束热调节/optimal_tube_lab.py
```

本候选实际运行的命令使用绝对路径：

```sh
python3 -B /private/tmp/wwl-control-optimal-candidate-20261011/控制论/80-实践/03-最优与约束热调节/optimal_tube_lab.py > /private/tmp/wwl-control-optimal-candidate-20261011/控制论/80-实践/03-最优与约束热调节/run-output.txt
```

实际Python版本3.14.7，退出码0。完整输出 [run-output.txt](run-output.txt) 结尾为 `PASS` 和同进程 `RU_MAXRSS_BYTES`；后者是macOS上 `resource.getrusage` 的峰值常驻字节，约19MiB，线程未创建。它说明本机CPU执行的资源规模，没有提供嵌入式设备的时限或性能证书。

程序用 `Fraction` 精确表示离散系数、QP矩阵、KKT与终端移位；连续指数和二分法使用双精度。程序枚举8行不等式中0、1、2条独立活动行，精确解KKT方程并核对所有可行性、乘子和驻点条件；只适用于这份二维教学QP。没有调用通用优化器，没有把有限网格搜索当作连续最优证书。

## 撤去方法提示后交什么

先独立写出这些任务的方程、单位、条件和结论，再与代码比较；不先运行程序猜答案：

1. 终点1.3K、10秒、动作界2W是否可达？终点0.8K时无界最优是否需要限幅？解释“最小能量”与耗电量的差别。
2. 将QP初值变为−0.6K，给最优输入的符号及KKT证书；把终端 $P$ 删掉，解释旧减价等式为什么不成立。
3. 功率扰动界改成0.6W，求新误差管与名义约束；把 $K$ 改成4W/K，比较收缩速度和动作余量，给出两者不能混同的原因。
4. 给一条预测残差很小的辨识报告，但没有参数或传感误差界，指出真实约束承诺缺哪些前提。给0.1K测量偏置，定位必须修改的误差递推和动作余量。

做完后按题目进入同页答案核对推导与失败理由：第1题对应 [[控制论/10-系统课程/07-有限时域最优控制Hamiltonian与终点条件#迁移题参考答案：终点与幅度界|07的终点、幅度界与代价]]；第2题对应 [[控制论/10-系统课程/08-约束预测控制从有限QP到终端保证#迁移题参考答案：符号、终端代价与初始化|08的符号与KKT、删终端代价]]，并可核同段的真实初温1K初始化；第3题对应 [[控制论/10-系统课程/09-有界扰动不变管与模型误差#迁移题参考答案：扰动界、反馈增益与传感偏置|09的新管、增益与功率余量]]；第4题对应同一答案段的传感偏置推导及预测残差的保证边界。默认程序和现有资产对应原参数；改参数题的解析/精确分数答案不表示默认脚本已经执行那些变化。
