# AI

这是本库的 AI 学习入口。先返回 [知识库总入口](../README.md) 选择知识域；进入 AI 后，从 [[AI/00-开始/00-AI-首页|AI 首页]] 选择与你当前问题相符的第一站。

推荐阅读顺序：

1. 用 [[AI/00-开始/02-学习路线与先修诊断|学习路线与先修诊断]] 定位当前基础和目标；
2. 用 [[AI/00-开始/05-问题驱动知识图谱与难点导航|问题驱动知识图谱]] 从具体困难反查课程；
3. 按当前问题选择主线：数据、模型与评估进入 [[AI/10-机器学习与深度学习基础/00-机器学习与深度学习基础-MOC|机器学习与深度学习基础]]；文本生成、检索或工具边界进入 [[AI/20-LLM/00-LLM-MOC|LLM MOC]]；显式规则、代价或计划进入 [[AI/13-搜索推理与规划/00-搜索推理与规划-MOC|搜索推理与规划]]；词级语言结构进入 [[AI/35-传统NLP/00-传统NLP-MOC|传统 NLP]]；读数、状态估计与反馈行动进入 [[AI/45-机器人与具身智能/00-机器人与具身智能-MOC|机器人与具身智能]]。这些是并列入口，不以完成 LLM 为共同前置；
4. 需要动手时，转到 [[AI/80-实践/00-AI实践-MOC|AI 实践 MOC]]，先做小型、可复查的实验；
5. 需要术语、资料或来源定位时，使用 [[AI/90-资源/00-AI资源-MOC|AI 资源 MOC]]。

线性代数、概率、微积分和数值计算的完整定义与推导维护在 [[数学/00-数学-首页|数学首页]]；Python、系统和 CUDA 的入口在 [[计算机知识/00-开始/00-计算机知识-首页|计算机知识首页]]。跨域链接应在本库根目录中打开。
