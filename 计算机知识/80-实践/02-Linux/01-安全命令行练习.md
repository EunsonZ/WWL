# 安全命令行练习

## 目标

在一个全新的临时目录中练习文件、管道、重定向、查找和归档，不触碰个人文件或系统目录。

## 建立实验边界

```bash
lab_origin="$(pwd -P)"
if [ -n "$lab_origin" ] &&
   lab_dir="$(mktemp -d)" &&
   [ -n "$lab_dir" ] &&
   [ -d "$lab_dir" ] &&
   lab_dir_physical="$(cd -- "$lab_dir" && pwd -P)" &&
   [ -n "$lab_dir_physical" ] &&
   cd -- "$lab_dir" &&
   [ "$(pwd -P)" = "$lab_dir_physical" ] &&
   printf '%s\n' 'WorkWithLLM Linux lab' > "$lab_dir/.workwithllm-linux-lab"; then
  lab_dir="$lab_dir_physical"
  printf 'lab=%s\n' "$lab_dir"
  printf 'cwd=%s\n' "$(pwd -P)"
else
  printf '无法建立并进入实验目录；停止实验\n' >&2
  cd -- "$lab_origin" 2>/dev/null || true
  unset lab_dir lab_dir_physical
fi
```

只有 `lab=` 与 `cwd=` 显示同一个物理绝对路径才继续。隐藏文件 `.workwithllm-linux-lab` 是本次实验的清理标记，不要在其他目录仿制。后续写操作全部使用以 `$lab_dir/` 开头的绝对目标；不要依赖当前目录。任一守卫失败就停止该代码块，不把路径改成 `.`、空变量或手写的其他目录。

## 创建合成日志

```bash
if [ -n "${lab_dir:-}" ] &&
   [ -d "$lab_dir" ] &&
   [ "$(cat "$lab_dir/.workwithllm-linux-lab" 2>/dev/null)" = 'WorkWithLLM Linux lab' ]; then
  mkdir -p -- "$lab_dir/input" "$lab_dir/output"
  printf '%s\n' \
    'INFO user=alice action=login' \
    'WARN user=bob action=retry' \
    'INFO user=alice action=logout' \
    'ERROR user=carol action=timeout' \
    > "$lab_dir/input/app.log"
else
  printf '拒绝写入：实验目录或标记未通过核对\n' >&2
fi
```

完成以下任务：

1. 用 `wc -l "$lab_dir/input/app.log"` 验证共 4 行；
2. 用 `grep` 或 `rg` 从 `"$lab_dir/input/app.log"` 找出 ERROR；
3. 用 `cut`、`sort`、`uniq -c` 统计用户出现次数；
4. 用 `tee "$lab_dir/output/errors.log"` 把 ERROR 行同时显示并写入实验输出；
5. 用 `find "$lab_dir"` 列出普通文件及大小；
6. 只把 `output/` 目录归档为 `"$lab_dir/output.tar.gz"`；可使用 `tar -czf "$lab_dir/output.tar.gz" -C "$lab_dir" output`，再用 `tar -tf "$lab_dir/output.tar.gz"` 只读检查。归档成员应包含 `output/` 和 `output/errors.log`，不应包含 `input/`；
7. 用下面的命令创建并观察符号链接。`stat` 的展示格式在 GNU/Linux 与 macOS 上不同；本练习只要求确认“这是符号链接”和“它指向哪个目标”，不要求背固定输出。

   ```bash
   ln -s -- "$lab_dir/input/app.log" "$lab_dir/app.log.link"
   readlink -- "$lab_dir/app.log.link"
   stat -- "$lab_dir/app.log.link"
   ```

## 引用与危险文件名

创建带空格和以连字符开头的文件：

```bash
if [ -n "${lab_dir:-}" ] &&
   [ -d "$lab_dir" ] &&
   [ "$(cat "$lab_dir/.workwithllm-linux-lab" 2>/dev/null)" = 'WorkWithLLM Linux lab' ]; then
  touch -- "$lab_dir/input/two words.txt"
  touch -- "$lab_dir/input/-draft"
else
  printf '拒绝写入：实验目录或标记未通过核对\n' >&2
fi
```

观察为什么这些写法更安全：

```bash
if [ -n "${lab_dir:-}" ] &&
   [ -d "$lab_dir" ] &&
   [ "$(cat "$lab_dir/.workwithllm-linux-lab" 2>/dev/null)" = 'WorkWithLLM Linux lab' ]; then
  ls -- "$lab_dir/input/two words.txt"
  rm -- "$lab_dir/input/-draft"
else
  printf '拒绝操作：实验目录或标记未通过核对\n' >&2
fi
```

`--` 表示选项结束；引号阻止 shell 把空格拆成多个参数。

## 成功标准

- [ ] 我能解释 `>` 与 `>>`、管道与 `tee` 的区别；
- [ ] 统计结果中 alice 为 2，bob 和 carol 各为 1；
- [ ] `tar -tf "$lab_dir/output.tar.gz"` 显示 `output/` 与 `output/errors.log`，且不包含 `input/`；
- [ ] 我能处理带空格和连字符开头的文件名；
- [ ] 所有写入都只发生在已记录的临时目录。

## 恢复

先运行 `pwd` 和 `printf '%s\n' "${lab_dir:-未设置}"`，确认变量仍指向本次 `mktemp -d` 产生的精确路径。若 shell 已更换、变量丢失或路径不能确认，不运行删除命令；保留目录并按记录的绝对路径人工检查。

仍在原 shell 中时，可用标记、非空路径和“不是根目录”三道守卫完成清理：

```bash
cd /
if [ -n "${lab_dir:-}" ] &&
   [ "$lab_dir" != / ] &&
   [ -d "$lab_dir" ] &&
   [ "$(cat "$lab_dir/.workwithllm-linux-lab" 2>/dev/null)" = 'WorkWithLLM Linux lab' ]; then
  rm -- "$lab_dir/input/app.log" "$lab_dir/input/two words.txt" 2>/dev/null || true
  rm -- "$lab_dir/output/errors.log" "$lab_dir/output.tar.gz" 2>/dev/null || true
  rm -- "$lab_dir/app.log.link" 2>/dev/null || true
  rm -- "$lab_dir/input/-draft" 2>/dev/null || true
  rmdir -- "$lab_dir/input" 2>/dev/null || true
  rmdir -- "$lab_dir/output" 2>/dev/null || true
  if [ ! -e "$lab_dir/input" ] && [ ! -e "$lab_dir/output" ]; then
    rm -- "$lab_dir/.workwithllm-linux-lab"
    rmdir -- "$lab_dir"
    test ! -e "$lab_dir" && printf '实验目录已清理\n'
  else
    printf '停止清理：实验目录中仍有未预期文件，请人工检查\n' >&2
  fi
else
  printf '拒绝清理：路径或实验标记未通过核对\n' >&2
fi
```

这里优先逐文件删除并用 `rmdir` 收尾；若出现未预期文件，`rmdir` 会失败并保留目录，先检查残留，不改用递归删除绕过保护。

`cd /` 是为了避免当前 shell 停留在待删除目录内，但它会改变工作目录。清理完成或停止后，只有原路径仍可确认时才恢复：

```bash
if [ -n "${lab_origin:-}" ] && [ -d "$lab_origin" ]; then
  cd -- "$lab_origin"
  printf '已返回：%s\n' "$(pwd -P)"
else
  printf '未自动返回：原目录变量缺失或目录不存在，请不要猜测路径\n' >&2
fi
```
