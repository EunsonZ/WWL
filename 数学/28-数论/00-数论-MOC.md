# 数论：先判断整数对象能否存在

为什么有的同余方程可约、有的不能？为什么两个周期各自有解，合在一起却永远不相遇？这条路线从整数除法出发，把会终止的算法、存在性证据和代数结构接起来。先做小数的精确判断，再讨论公式能否迁移到多项式商与密码协议。

01→02可以直接从整数与初等证明学习，不要求先读完整抽象代数。已有 [[数学/25-高等代数/12-环理想商环与同态基本定理#环版本中国剩余定理|环CRT]] 保留一般结构职责；数论02补整数非互素兼容计算，原 [[数学/25-高等代数/13-域扩张有限域与代数数#有限域为什么大小只能是素数幂|有限域]] 保留F₄/素数幂的构造证明，[[数学/25-高等代数/16-整环Euclid域PID与唯一分解|Euclidean/PID/UFD]] 保留一般环与负十九反例。

消费路线有两个实际终点：从02的三余数比较回 [[计算机知识/35-计算机网络/10-系统课程/02-链路层交换与差错检测#CRC取余怎样变成商映射|CRC输入与基础环]]，再以[x]的单位/阶核帧长；从02的Euler条件回 [[计算机知识/35-计算机网络/10-系统课程/现代密码学RSA加密与签名编码#RSA 正确性不能只证明互素消息|RSA的零/非零分支]]，再回 [[计算机知识/35-计算机网络/10-系统课程/11-TLS身份验证重放与信任边界#临时密钥交换、CertificateVerify 与 Finished 各做什么|TLS认证与上下文职责]]。数学正确性不代替编码、安全假设或真实协议验收。

继续沿02→03学习局部平方条件；04从01与计数的鸽巢原理进入，不要求先掌握互反律。04的范数单位实际回到 [[数学/25-高等代数/13-域扩张有限域与代数数#一次具体扩张运算|Q(√2)的逆]] 与 [[数学/25-高等代数/40-PID与非欧几里得反例/01-负十九二次整数环与理想类#三个名称相近、对象不同的范数|三种范数]]，为下一段代数数论准备对象。

05沿03的互反律进入负十九整数环：一般整环不享有的元素分解权限、完整整数环的理想分解定理、当前PID的既有证明各有位置；直接证明的素数分类再回负十九模2小范数论证。06从01的整数唯一分解接数学分析正项比较，不要求先学Pell或完整代数数论；素数分布的精确问题与Euler积能推出的有限范围分开。

本路线已覆盖整数整除→CRT/单位→二次互反→连分数/Pell、具体整数环/理想分裂，以及Euler乘积与素数分布的有限入口。一般Dedekind/Minkowski定理继续明确调用既有专题与原典；素数定理只陈述并指向完整来源，不在本课证明。一般CF周期分类、最优逼近、通用快速模平方根、整个解析数论不属于这里已证内容。返回 [[数学/00-数学-首页|数学首页]]；课程范围可对照 [MIT18.781讲义目录](https://ocw.mit.edu/courses/18-781-theory-of-numbers-spring-2012/pages/lecture-notes/)。
