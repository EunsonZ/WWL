# 快速切换器、书签与大纲

> [!goal] 你将学会
> 根据问题选择正确的导航工具：Quick Switcher 打开或创建文件，Bookmarks 保存重要入口，Outline 在长笔记内部按标题跳转。

## 三个工具，三个问题

| 工具 | 它回答的问题 | 典型入口 |
| --- | --- | --- |
| Quick Switcher | “我要打开或创建哪篇笔记？” | macOS `Cmd+O`；Windows/Linux `Ctrl+O` |
| Bookmarks | “哪些入口值得长期保留？” | 左侧 Ribbon 或 Bookmarks 侧栏 |
| Outline | “当前长笔记有哪些标题，我要跳到哪里？” | Outline 侧栏 |

若默认快捷键不同，以 Command palette 和 Settings → Hotkeys 中显示的绑定为准。

## Quick Switcher：先学模糊查找

1. 打开 Quick Switcher。
2. 输入 `晨间`，打开 [[Obsidian知识/30-实践/01-实验区/数据/甲-晨间笔记|甲-晨间笔记]]。
3. 再打开，输入别名 `早晨记录`；同一文件也应出现。
4. 输入一段不存在的唯一标题，观察“创建”提示，但按 `Esc` 退出，不创建垃圾笔记。

Quick Switcher 主要匹配文件名与 aliases。它不是全文搜索：如果你只记得正文里出现过“核心观点”，应该用 Search，而不是在快速切换器里反复猜文件名。

> [!tip] 创建之前先看结果
> 没有匹配项时，Quick Switcher 能创建文件。新手最常见的问题是拼写略有差异便创建重复笔记。先搜索关键词与别名，再决定是否新建。

## Bookmarks：保存的是入口，不是副本

Bookmarks 可以保存的不只有文件，还包括文件夹、搜索、标题、块、图谱和外部链接等入口。收藏不会复制源内容；源文件被安全重命名时，内部目标通常会随链接设置更新。

动手做：

1. 打开 [[Obsidian知识/10-基础/03-属性标签与检索/03-核心搜索语法|03-核心搜索语法]]，将文件添加到 Bookmarks。
2. 在同一文件中把“面向样例的查询”标题加入 Bookmark。
3. 执行搜索 `path:"Obsidian知识/30-实践/01-实验区/数据" [status:active]`，把该搜索加入 Bookmark。
4. 新建一个书签组 `Playground`，把这三项放进去。
5. 分别点击它们，观察“文件、标题、动态查询”三种入口的差异。

> [!info] Bookmark 与 Base 的区别
> Bookmark 记住“去哪里”；Base 保存“如何筛选与显示一批文件”。常用 Search 可以成为 Bookmark，结构化目录则更适合 [[Obsidian知识/40-视图/02-Bases/00-MOC-Bases|Base]]。

## Outline：让标题成为导航结构

保持当前课程打开，然后查看 Outline。你应该看到本页的二级标题。点击“Outline：让标题成为导航结构”，视图会滚动到这里。

Outline 的质量取决于标题层级：

```markdown
# 文档标题
## 一级主题
### 主题下的细节
## 下一个一级主题
```

不要为了字体大小跳级使用 `####`；标题是结构，不只是外观。一个文件通常保留一个 H1，正文从 H2 开始。

## 组合练习

完成以下路线：

1. 用 Quick Switcher 通过 alias 打开甲。
2. 用 Search 找到含 `下一步行动` 的样例。
3. 把搜索保存到 `Playground` 书签组。
4. 打开丙，用 Outline 跳到“下一步行动”。
5. 返回 Bookmark 再次打开搜索，确认它会重新计算结果。

## 检查结果

- 记得文件名/别名：Quick Switcher。
- 只记得正文内容或筛选条件：Search。
- 想长期保留文件、标题、块或查询入口：Bookmarks。
- 已在一篇长笔记里：Outline。
- 想查看可排序、可切换视图的数据集合：Bases。

## 复原

删除刚创建的 `Playground` 书签组或其中的练习条目，不会删除任何笔记。若你不小心创建了一篇空白测试笔记，先确认它没有有效内容或反向链接，再从 File explorer 移到系统废纸篓。
