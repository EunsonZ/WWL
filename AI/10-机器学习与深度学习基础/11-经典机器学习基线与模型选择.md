# 经典机器学习基线与模型选择

## 目标与适用场景

在选择神经网络以前，先为一个任务建立可信的最小参照。本课把规则、常数预测、线性模型、近邻、树和聚类放进同一张决策地图；你将能用相同的数据切分与验证指标比较它们，并明确哪些结论只是玩具实验的结论。

## 先有基线，才谈“提升”

**基线**是一个足够简单、可复查、且与候选模型使用相同训练/验证边界的方案。它不是注定要输的稻草人，而是以下问题的参照：

- 更复杂的模型真的带来与维护成本相称的改进吗？
- 数据处理、标签定义和评测脚本是否已经有明显问题？
- 系统能否在模型失效时降级回一个可理解的行为？

| 任务 | 先试的基线 | 它回答什么 |
| --- | --- | --- |
| 二分类 | 多数类、经审计的业务规则 | 特征和模型是否胜过“总猜同一类”或已有流程 |
| 回归 | 训练集均值；目标有离群值时用中位数；时间序列可用上一期 | 模型是否比“不看输入”或简单延续更好 |
| 聚类/探索 | 不聚类、按已有业务分组、随机或距离基准 | 新分组是否稳定、可解释且有实际用途 |

基线中的“多数”“均值”“中位数”只能从**训练集**计算。若先看完整数据再求它们，验证标签已经参与了决策，报告会过于乐观。

## 模型不是排行榜：各自解决什么

| 方法 | 解决的问题与优势 | 常见限制 | 优先场景 |
| --- | --- | --- | --- |
| 线性回归 | 用特征的加权组合预测连续目标；系数可作为条件关联的起点 | 关系强烈非线性、异常值、共线性或外推时要额外检查 | 可解释的数值预测、稳定特征、快速基线 |
| 逻辑回归 | 用线性边界输出二分类分数或概率 | 原始特征之间是复杂曲线/交互时会欠拟合；概率未必天然校准 | 二分类、稀疏或表格特征、需要透明起点 |
| kNN | 让样本由训练集中相近的邻居投票；几乎不假设函数形状 | 预测慢；高维距离常失真；对缩放、噪声和 `k` 敏感 | 小数据、低维、局部相似确有含义的任务 |
| 决策树 | 用一系列可读的阈值分支表达非线性和交互 | 很容易记住训练集；单棵树不稳定；深度和叶子样本数须验证 | 表格数据、规则沟通、需要发现候选交互 |
| 聚类 | 在无标签数据中按相似性形成候选结构，不是在预测“正确类别” | 簇不等于真实人群、因果群体或业务行动；结果依赖距离和参数 | 探索、数据质检、提出可检验假设 |

这些方法不是互斥阵营。例如，可把业务规则、逻辑回归和树都作为候选，并以相同时间截止点、相同特征可得性和预先选定的指标比较。逻辑回归的 sigmoid、距离与优化直觉可分别回到 [[数学/30-概率与统计/00-概率与统计-MOC|概率与统计]]、[[数学/20-线性代数与几何/00-线性代数与几何-MOC|线性代数与几何]] 和 [[数学/40-微积分与优化/00-微积分与优化-MOC|微积分与优化]]；不要把本页的使用判断误读成完整数学推导。

## 何时先不用神经网络

神经网络不是默认更好的选择。以下情况通常应先保留或优先比较经典方案：

1. **数据很少、标签昂贵或表格特征已很强**：简单模型更容易估计不确定性、发现标签和管道问题。
2. **延迟、内存、能耗或审计成本严格**：一个规则、线性模型或小树可能已满足目标，且更易部署和回滚。
3. **需要逐例说明或稳定的业务规则**：树路径、近邻和线性特征贡献能帮助复核；但“可解释”不是自动公平、因果正确或无偏。
4. **输入是结构化数值/类别数据，且没有已验证的大规模表示学习收益**：先建立经典基线，再证明神经网络的净收益。

反过来，原始图像、语音、长文本或大量复杂多模态输入通常需要学习表示；这只是优先试验的理由，仍不免除基线、独立测试、成本和安全评估。

## 共同边界：拆分、缩放、阈值与解释

经典模型也会发生与神经网络相同的实验错误。

- **数据泄漏**：先拆分，再只在训练集拟合均值、标准差、词表、缺失值填充规则、特征选择和超参数。把验证集混入任何一步都会夸大表现。完整的数据边界见 [[AI/10-机器学习与深度学习基础/05-数据集拆分清洗与泄漏|数据集拆分、清洗与泄漏]]。
- **缩放**：kNN 的距离会被量纲大的列主导；线性模型的优化和正则化也常受尺度影响。用训练集的均值和标准差变换训练、验证和未来输入；不要分别给每一份数据“各自标准化”。树通常不需要缩放，但仍要处理缺失、类别编码和训练/验证一致性。
- **阈值**：逻辑回归输出分数或概率后，`0.5` 不是普遍正确的动作阈值。把阈值、人工复核容量和 FP/FN 代价在验证集上确定，冻结后才在测试集报告。指标与阈值证据链见 [[AI/10-机器学习与深度学习基础/10-基线指标阈值误差分析与分布偏移|基线、指标、阈值、误差分析与分布偏移]]。
- **可解释性边界**：线性系数是在给定特征、编码和其他变量条件下的关联，不等于“把该特征改变一个单位会造成结果变化”；树分支也不证明因果。对受影响的人或高风险决定，应保留数据来源、模型版本、复核和申诉路径。
- **分布偏移**：未来输入范围、类别比例、特征含义和条件关系都可能改变。近邻可能找不到相似历史点；固定规则和树阈值也会失效。报告验证分数时必须写清时间窗、人群、数据管道和降级条件，而不是宣称模型在任何未来数据上有效。

## 最小可运行实验：同一验证集比较规则、逻辑回归和 kNN

下面的脚本只用 Python 标准库，构造固定的二维合成数据。规则只看第一个特征；逻辑回归在训练集标准化后的两个特征上做梯度下降；kNN 也只使用训练集的缩放统计量。它在独立验证集上比较准确率，并用断言检查实验合同。

<!-- code-sync: ./11_经典机器学习基线与模型选择.py -->
~~~python
from __future__ import annotations

import math


def make_samples(start: int, stop: int) -> list[tuple[list[float], int]]:
    """生成可重复的合成二分类数据；不能代表任何真实人群。"""
    samples: list[tuple[list[float], int]] = []
    for i in range(start, stop):
        x0 = ((i * 37) % 101 - 50) / 25.0
        x1 = ((i * 17) % 97 - 48) / 24.0
        noise = ((i * 13) % 11 - 5) / 20.0
        label = int(0.7 * x0 + 1.2 * x1 + noise > 0.0)
        samples.append(([x0, x1], label))
    return samples


def fit_scaler(samples: list[tuple[list[float], int]]) -> tuple[list[float], list[float]]:
    columns = list(zip(*(features for features, _ in samples)))
    means = [sum(column) / len(column) for column in columns]
    scales = [math.sqrt(sum((value - mean) ** 2 for value in column) / len(column))
              for column, mean in zip(columns, means)]
    assert all(scale > 0.0 for scale in scales)
    return means, scales


def scale(features: list[float], means: list[float], scales: list[float]) -> list[float]:
    return [(value - mean) / std for value, mean, std in zip(features, means, scales)]


def sigmoid(score: float) -> float:
    return 1.0 / (1.0 + math.exp(-max(-30.0, min(30.0, score))))


def fit_logistic(train: list[tuple[list[float], int]], means: list[float], scales: list[float]) -> tuple[list[float], float]:
    weights = [0.0, 0.0]
    bias = 0.0
    learning_rate = 0.18
    for _ in range(900):
        gradient = [0.0, 0.0]
        bias_gradient = 0.0
        for features, label in train:
            scaled = scale(features, means, scales)
            error = sigmoid(sum(weight * value for weight, value in zip(weights, scaled)) + bias) - label
            gradient = [old + error * value for old, value in zip(gradient, scaled)]
            bias_gradient += error
        weights = [weight - learning_rate * value / len(train)
                   for weight, value in zip(weights, gradient)]
        bias -= learning_rate * bias_gradient / len(train)
    return weights, bias


def rule_predict(features: list[float]) -> int:
    return int(features[0] > 0.0)


def logistic_predict(features: list[float], weights: list[float], bias: float,
                     means: list[float], scales: list[float]) -> int:
    scaled = scale(features, means, scales)
    return int(sigmoid(sum(weight * value for weight, value in zip(weights, scaled)) + bias) >= 0.5)


def knn_predict(features: list[float], train: list[tuple[list[float], int]],
                means: list[float], scales: list[float], k: int = 7) -> int:
    point = scale(features, means, scales)
    neighbors = sorted(
        ((sum((left - right) ** 2 for left, right in zip(point, scale(other, means, scales))), label)
         for other, label in train),
        key=lambda item: item[0],
    )[:k]
    return int(sum(label for _, label in neighbors) * 2 >= k)


def accuracy(predict, samples: list[tuple[list[float], int]]) -> float:
    return sum(predict(features) == label for features, label in samples) / len(samples)


def main() -> None:
    train = make_samples(0, 160)
    validation = make_samples(160, 240)
    means, scales = fit_scaler(train)  # 不能用 validation 拟合这些统计量。
    weights, bias = fit_logistic(train, means, scales)

    rule_score = accuracy(rule_predict, validation)
    logistic_score = accuracy(lambda x: logistic_predict(x, weights, bias, means, scales), validation)
    knn_score = accuracy(lambda x: knn_predict(x, train, means, scales), validation)

    print(f"validation accuracy: rule={rule_score:.3f}, logistic={logistic_score:.3f}, knn={knn_score:.3f}")
    assert len(train) == 160 and len(validation) == 80
    assert logistic_score > rule_score + 0.15
    assert knn_score > rule_score + 0.10
    assert logistic_score >= 0.90 and knn_score >= 0.85
    print("检查通过：候选模型在这份合成验证集上胜过简单规则。")
    print("边界：这不证明它们在真实数据、未来时间窗或任何人群上更好。")


if __name__ == "__main__":
    main()
~~~

运行方式：在本目录执行 `python3 11_经典机器学习基线与模型选择.py`。输出中的数字是这一份固定合成数据的验证结果；断言通过只证明代码、拆分和预设比较在这里成立，**绝不外推为真实业务、真实人群或未来时间窗的模型结论**。

## 练习

1. 将脚本中 `fit_scaler(train)` 错改为 `fit_scaler(train + validation)`，说明它为何构成泄漏；恢复后再运行。
2. 将 `k` 从 7 改成 1、15、31，记录验证准确率。不要据此在同一验证集反复挑到最好；说明你会如何增加开发集或交叉验证来选择 `k`。
3. 对“识别需要人工复核的订单”写出一个规则基线、一个多数类基线、一个逻辑回归特征方案，并说明阈值、人工容量与 FP/FN 代价。
4. 为没有标签的客户行为数据提出一个聚类假设、稳定性检查和一个反例，解释为何不能把簇名直接当作用户本质。

## 成功标准

- 能为分类、回归和无监督探索分别写出一个不泄漏的简单基线。
- 能说明线性/逻辑回归、kNN、决策树和聚类各自解决的问题与至少一个失效边界。
- 能运行伴随脚本，并确认训练集有 160 条、验证集有 80 条，且三项断言通过。
- 能指出脚本只说明固定合成数据上的比较，不是对真实业务效果、因果关系、公平性或未来泛化的证明。
- 能在训练集拟合缩放统计量、在验证集选阈值，并把测试集留作冻结方案后的独立报告。
