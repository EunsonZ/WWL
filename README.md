# WWL 知识库

本库帮助学习者追踪问题中的对象、关系、证据和条件：先形成可以预测现象的直觉，再理解推导或论证，最后在条件改变后重新判断。数学证明、程序执行、历史解释和规范性选择各有自己的依据；学科入口保留独立的深入路线。

从一个知识域的首页进入，再按其中的课程地图（MOC）选择阅读顺序。课程正文、可运行实验与来源材料各有入口；无需按文件夹编号一次读完整个库。

按问题进入：[[00-工作台/按问题找知识|问题入口]] · 日常记录：[[00-工作台/README|工作台]] · 浏览筛选：[[00-工作台/知识目录.base|知识目录]]

如果你想把机器学习、系统与算法的基础连成一条可返回的阅读路径，使用 [[00-工作台/基础理论学习路线|基础理论学习路线]]；它只帮你选择下一页，不把阅读次数或时间当作掌握证明。

## 维护与阅读说明

日常使用不需要管理 agents。把具体卡点交给 AI 即可，例如“这页的公式怎样代入”“两篇解释是不是矛盾”“我记得这个概念，但找不到”。AI 负责定位、必要分工、证据与检查，不要求你维护任务表。

知识维护见 [[00-工作台/维护指南|维护指南]]；多人交接、模型与费用见 [[00-工作台/并行协作与模型路由|并行协作与模型路由]]；AI 的稳定入口是 [[AGENTS|协作约定]]。插件日常与按需使用见 [[00-工作台/插件取舍|插件取舍]]，实际改进、验证和未决项从 [[CHANGES|CHANGES.md]] 进入。

[[NewAgents|旧手册入口]] 只供追溯。迁移执行单在完成后撤出根目录，必要记录归档，不形成长期待办队列。历史交付只证明当时明示的范围，不替当前快照认证。

资料书目中的“本包未提供”表示附件不在上传快照中，不能用空文件冒充恢复。内容可读、证据已核验、个人已掌握是不同状态；并行数量也不是质量证明。
