# 市场准入、竞争与消费者保护（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：市场准入负面清单、公平竞争审查、反垄断、反不正当竞争、经营者登记与行业许可的接口，以及消费者交易保护和平台场景。
- 外商投资另有负面清单与国家安全审查，本文件只提示接口，不替代其专门规则。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 市场准入 | 《市场准入负面清单（2025年版）》为现行全国统一清单，2022年版已废止；清单之外原则上依法平等进入，但仍须遵守登记、标准和事中事后监管。 |
| 公平竞争审查 | 2024年行政法规已施行，2025年实施办法细化审查标准、程序、监督抽查和举报处理，重点约束政策制定机关排除、限制竞争。 |
| 反垄断 | 2022年修正的反垄断法现行有效，覆盖垄断协议、滥用市场支配地位、经营者集中和滥用行政权力排除限制竞争。 |
| 反不正当竞争 | 2025年修订法已于2025-10-15施行，网络经营、平台规则、混淆、商业贿赂、虚假宣传、商业秘密和恶意交易等均进入现行规范。 |
| 消费者保护 | 消费者权益保护法与2024年施行条例共同构成主干，进一步覆盖格式条款、自动续费、预付式消费、直播带货和平台责任等场景。 |

## 现行结构摘要

1. **“全国一张清单”与许可并存。** 准入清单列出禁止和许可事项；未列事项不得另设市场准入障碍。不过行业资格、技术标准、经营登记、土地环保安全条件仍可在准入后或准入过程中发挥作用。
2. **政策制定先审竞争影响。** 涉及经营者经济活动的法规、规章、规范性文件和具体政策措施，应进行公平竞争审查；市场监管部门负责指导、抽查和监督，政策制定机关承担自我审查主体责任。
3. **反垄断兼顾经营者与行政机关。** 国务院反垄断执法机构及授权地方机构调查案件，对经营者集中实行申报审查；行政性垄断另通过调查、建议和上级纠正等机制处理。
4. **竞争规则与平台规则重叠。** 平台可能同时面对反垄断、反不正当竞争、价格、广告、网络交易、算法与数据规则，不同行为的主管机关、证明标准和救济路径并不完全相同。
5. **消费者保护以行政监管和民事救济并行。** 经营者负有安全、真实信息、公平格式条款、个人信息和售后责任；消费者可以协商、投诉、调解、仲裁或诉讼，特定社会组织和检察机关在法定条件下可提起公益诉讼。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 准入清单—行政许可 | 清单决定是否允许进入，许可制度进一步决定资质和程序；地方不得自行增设全国清单之外的准入壁垒。 |
| 公平竞争审查—产业政策 | 补贴、政府采购、招商、标准和要素配置措施需评估竞争影响，但可依法适用维护公共利益等例外并说明理由。 |
| 竞争执法—行业监管 | 电信、金融、能源、交通等行业的技术和价格监管与一般竞争执法并行，案件需要专业数据和机关协作。 |
| 平台—商户—消费者 | 平台同时制定内部交易规则、提供技术和流量并可能参与交易，责任取决于控制能力、知情程度和具体法定义务。 |
| 行政处罚—民事赔偿 | 执法认定可影响后续民事争议，但损害、因果关系、证据取得和群体性低额损失仍需单独处理。 |

## 可观察约束与信息缺口

- 全国负面清单统一后，清单外的资质、标准、审批条件和地方隐性门槛仍需持续逐项核查。
- 公平竞争审查以制定机关自审为基础，审查文本、第三方意见、例外理由和整改结果并非全部公开。
- 经营者集中审查可公开决定和部分案件信息，但市场界定、经济分析、附加条件执行数据的披露程度不一。
- 行政性垄断的纠正依赖行政体系内部协调，受影响经营者的独立复核与损害救济路径相对有限。
- 平台算法、流量分配、收费项目和差别待遇的证据主要掌握在平台，监管机关、商户与消费者存在信息不对称。
- 预付式消费、自动续费、直播交易和跨地区网络纠纷数量大、单笔金额低，个体维权成本与救济收益不匹配。

## 古国改革需回答的问题

1. 如何把准入禁止、许可条件、技术标准和审批时限放进一个可检索、可申诉、定期失效复核的清单？
2. 公平竞争审查应由政策制定者自审、独立机关复审，还是两者结合；例外适用如何公开？
3. 竞争执法机构是否独立，调查权、承诺制度、罚款计算和司法审查怎样配置？
4. 自然垄断、国有企业和承担公共任务的经营者是否适用同一竞争规则，例外由谁证明？
5. 平台应披露哪些排序、收费、封禁和自营优待信息，商业秘密与可审计性如何平衡？
6. 低额、多人的消费者损害如何通过集体救济、举证转移、惩罚性赔偿或公共赔偿基金解决？
7. 预付资金、押金和自动续费应设置何种托管、提醒、退款和经营失败保护？
