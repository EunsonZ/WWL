# 语言模型目标、分词粒度与评测可比性

**先修与定位：** 先读[[AI/11-数学与统计桥梁/03-概率似然贝叶斯与信息论|链式法则、交叉熵与KL]]；本页连接训练定义和可比较评测。

## 预测下一个 token 为什么是在学习联合分布

对于有结束标记的序列，概率链式法则给出

$$
p_\theta(x_{1:T})=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}),\qquad
-\log p_\theta(x_{1:T})=\sum_t-\log p_\theta(x_t\mid x_{<t}).
$$

这不假设 token 之间独立，恰恰允许每个条件项依赖完整过去。训练时把真实前缀输入模型，是直接计算样本的对数似然；因果掩码使多个位置可以并行求值，而不是允许某个位置偷看未来。生成时未来尚不存在，因而必须逐步产生条件。架构来源见 Transformer 原始研究。[^S30]

例如真实序列为 `BOS A B EOS`，监督配对是输入 `BOS A B`，目标 `A B EOS`。若数据管线已经移位，而模型内部又移位一次，就会预测错位的词；若完全不移位且没有正确接口约定，模型可能学到复制输入。验证第一批数据中每个位置的“可见前缀、目标、损失掩码”比盯着下降的 loss 更可靠，见[[AI/12-PyTorch/05-变长批处理Packing与有效Token归一化|变长批处理]]。

## Teacher forcing 与部署差异不是一句“曝光偏差”就解释完

最大似然在训练分布真实前缀上拟合条件分布。部署会访问模型自己生成的前缀，错误积累可能把它带到低密度区域。这是分布偏移问题，但并不证明似然目标在数学上错误。模型容量、训练覆盖、解码策略与任务目标共同决定表现。把训练前缀改成任意混合的模型输出，也可能改变估计目标，不自动成为更一致的似然估计。

还要区分文本概率与任务效用。一个具体正确答案在众多合法表述中概率未必最大；常见但错误的说法也可能高概率。于是[[AI/20-LLM/30-训练/12-从KL约束到DPO的逐步推导|偏好目标]]、验证器和工具执行可以补充任务信号，但这些信号自身也存在误差。

## 困惑度的分母不是无关紧要的小字

平均 token 负对数似然 $\bar\ell$ 用自然对数计算时，困惑度是 $\exp(\bar\ell)$。它表示对应概率模型的指数化平均编码代价，不是每个词都在固定数量的候选中平均挑选。

假想同一段原文在两种确定性分词下都被赋予 $e^{-12}$ 的规范 token 序列概率。分成 6 个 token 时每 token 损失为 2，困惑度约 7.39；分成 12 个时为 1，困惑度约 2.72。原文的总编码代价一样，token 困惑度却差很多。现实中两模型的概率也不同，因此该例只隔离“计量单位”的影响。

可补充每字节位数

$$
\operatorname{BPB}=\frac{-\sum\log p_\theta(\text{规范编码token})}{N_{\rm bytes}\log2}.
$$

要保持原始字节、Unicode 规范化、特殊标记、文档边界、滑窗与计分区域一致。它是对规范编码路径的可比编码代价；若多个 token 序列能解码成同一文本，对规范路径的概率不一定等于把所有路径边缘化后的文本概率。换一个分母不能修复不一致的评测协议。

## 文档与对话边界改变的也是概率问题

将两篇无关文档直接拼接，会让后一篇的开头以先前文档为条件。EOS 是一个可学习标记，不是物理隔离的 attention mask。对话 SFT 若只训练 assistant 部分，应说明是否把 assistant 的结束标记、工具消息和多轮历史纳入目标；“所有非 padding token”与“所有 assistant token”是两种目标。

评价时不能让无限增长的测试历史跨样本泄漏答案。需要明确每个样本可用的提示、检索材料和上下文长度。将概率质量问题接到[[AI/20-LLM/70-工程应用与工具链/10-LLM评测污染裁判偏差与统计检验|LLM评测]]，将分母问题接到[[AI/12-PyTorch/08-DDP全局目标通信与分片边界|DDP全局归一化]]，可以看出理论定义如何直接约束工程代码。

## 自测与参考解

两个模型在不同 tokenizer 上的困惑度为 8 和 10，能否断言前者更好？不能。至少要对齐测试文本、计分单位、上下文、目标掩码与任务效用。即便这些一致，平均似然优势也不等于在所有子群或任务上占优。
