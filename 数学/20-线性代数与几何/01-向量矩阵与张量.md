## 本课目标

- 把标量、向量、矩阵和高阶张量看成“带轴的数字集合”；
- 读写 shape、元素下标和切片含义；
- 区分数学中的向量空间与机器学习里的多维数组；
- 看懂 embedding、权重矩阵和批量序列的常见形状。

## 直觉轨：先看盒子和轴

一个标量是一个数，例如温度 $23$。向量是一列有顺序的数，例如某 token 的三个特征：

$$
x=\begin{bmatrix}2\\-1\\3\end{bmatrix},\qquad x\in\mathbb R^3.
$$

矩阵像一张表。若每行是一个 token、每列是一种特征，三个 token、四个特征可写成 $X\in\mathbb R^{3\times4}$。张量继续增加轴：一批句子可记作

$$
X\in\mathbb R^{B\times T\times D},
$$

其中 $B$ 是 batch size，$T$ 是序列长度，$D$ 是隐藏维度。shape 不是装饰：它记录每条轴在现实中表示什么。

> [!tip] 读 shape 的固定动作
> 从左到右给每条轴命名，再问“一个元素需要几个下标”。$X_{btd}$ 需要 batch、token 位置和特征三个下标，所以是三阶张量。

### 一个数值例

令两条序列、每条三个 token、每个 token 两个特征：

$$
X=
\left[
\begin{array}{ccc}
(1,0)&(0,1)&(1,1)\\
(2,1)&(1,-1)&(0,2)
\end{array}
\right],\qquad \operatorname{shape}(X)=(2,3,2).
$$

$X_{1,2,:}=(0,2)$ 表示第 2 条序列的第 3 个 token 的全部特征；这里下标从 0 开始，是常见程序约定。最后的 `:` 表示取最后一条轴的全部位置，所以结果只剩特征轴，shape 是 $(2,)$。

## 严谨轨：对象、坐标与基

### 向量不是只能“竖着写的数组”

向量空间 $V$ 对加法和数乘封闭，并满足交换、结合、零元、逆元、分配律等公理。选择一组基 $e_1,\ldots,e_n$ 后，任何 $v\in V$ 才能写成坐标列：

$$
v=v_1e_1+\cdots+v_ne_n
\longleftrightarrow
\begin{bmatrix}v_1\\\vdots\\v_n\end{bmatrix}.
$$

同一个几何向量换一组基，坐标会改变；对象本身没有改变。机器学习通常固定标准坐标系，因此很容易把“向量”和“坐标数组”口语化地混在一起。

### 矩阵与线性映射

$A\in\mathbb R^{m\times n}$ 有 $m$ 行、$n$ 列，元素为 $A_{ij}$。它也可表示从 $\mathbb R^n$ 到 $\mathbb R^m$ 的线性映射。第 $j$ 列正是第 $j$ 个标准基向量被映射后的结果：

$$
A e_j=A_{:,j}.
$$

### 张量的两种语境

严谨数学里的张量有与坐标变换相容的定义；深度学习工程里常把任意多维数组都称为 tensor。本组课程采用工程语境，但每次都明确轴的含义。阶数 rank/order 是轴的数量，不要与矩阵的秩 $\operatorname{rank}(A)$ 混淆。

## LLM 应用

- token id 查 embedding 表：$E\in\mathbb R^{V\times D}$，取一行得到 $e_t\in\mathbb R^D$；
- 一层输入常为 $X\in\mathbb R^{B\times T\times D}$；
- 多头 Attention 常把隐藏维拆成 head 轴：$Q\in\mathbb R^{B\times H\times T\times D_h}$；
- 从 embedding 表、token 表示到语义空间的应用解释见 [[AI/20-LLM/10-原理/03-Embedding表示与语义空间|Embedding、表示与语义空间]]；该页也链回本页的数学定义；
- GPU kernel 的性能还取决于 stride、连续性和内存布局，不只取决于抽象 shape，见 [[计算机知识/40-并行与异构计算/01-CUDA/00-CUDA-MOC|CUDA MOC]]。

## 常见误区

| 误区 | 更准确的说法 |
| --- | --- |
| “向量一定是列，行向量不是向量。” | 行/列是坐标排版；做矩阵运算时必须明确采用哪种约定。 |
| “三维张量就是三维空间里的箭头。” | 三阶张量表示有三条轴，轴长度可以是任意正整数。 |
| “reshape 改变了数据含义。” | reshape 通常只重解释同一串元素；轴语义是否仍正确要由人保证。 |
| “tensor 的 rank 就是矩阵秩。” | 工程中的 tensor rank 常指轴数；矩阵秩是独立列/行方向的数量。 |
| “shape 对得上，语义就一定对。” | 把 batch 轴和 token 轴弄反也可能产生合法 shape，却得到错误含义。 |

## 练习

1. 对 $X\in\mathbb R^{4\times128\times768}$，说明三条轴的一种合理 LLM 语义，并写出单个 token 表示的 shape。
2. 权重 $W\in\mathbb R^{768\times3072}$ 若按行向量约定计算 $XW$，输入 $X$ 的最后一维应是多少？输出最后一维是多少？
3. 解释为什么 $X\in\mathbb R^{2\times3\times4}$ 与 reshape 后的 $Y\in\mathbb R^{6\times4}$ 可以包含相同数字，却不表示相同的数据组织。

> [!question]- 核对要点
> 1. 可解释为 batch、token、hidden；单 token 表示为 $(768,)$。
> 2. 输入最后一维 768，输出最后一维 3072。
> 3. $Y$ 合并了原先的 batch 与 token 轴；数值顺序可不变，但分组边界和索引语义改变。

## 成功标准

不看答案时，你能为任意 $B\times T\times D$ 张量给轴命名，能区分“轴数”和“矩阵秩”，并能说明矩阵列与线性映射之间的关系。
