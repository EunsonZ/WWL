# 沙盘总督：世界基期与命名基础报告

## 一、完成范围

已建立并锁定以下六项总督基础文件：

1. 世界概览：统一基期、地域层级、社会产业特征、公共权力骨架与改革起点；
2. 基期参数：覆盖人口、地区、产业、财政债务、劳动、住房、社保、能源、数字和行政能力；
3. 命名规则：规定机构、职位、企业、法源、地域、简称和编号的登记方法；
4. 机构职位词典：登记44个全国性机构及其首席职位、正面职责和禁止边界；
5. 企业名录：登记18个公共企业、10个商业企业样本及其所有权、经营边界与监管接口；
6. 本报告：向后续部门发布不可自行变更的全局硬约束。

## 二、总督取舍

命名采用“功能可读为主、意象区分为辅”。公权机构名称优先暴露职责，避免用华丽称谓掩盖权限；企业品牌使用不承担公权含义的原创复合词，以降低与机构、现实组织或彼此撞名的风险。

数量基线采用区间而非单点。较确定的行政单元和登记覆盖可进入A、B级，平台劳动、长期照护、维护欠账、尾部灾害等保留C、D级。财政上另设扩围暂停阈值，避免部门把区间上界的收入与下界的成本同时当成既定事实。

机构结构执行“立规、执行、裁判、检控、审计、统计、监管、所有权和经营”分离。设联席协调不改变各主体法定责任；政策购买合同不能替代行业监管，公共所有也不产生公权豁免。

## 三、后续部门必须遵守的硬约束

1. **统一基期**：只能使用共历七十六年年末和《古国基期参数与证据等级》的区间；需要新增参数时先报总督登记，不得在部门正文另造全国底数。
2. **地域锁**：一级固定46个衡域；默认推演612个协区。部门不得把高能力样本当作全国平均，也不得取消丁层地区的线下替代服务。
3. **财政锁**：第三年净新增经常性支出不超过基期总产出的1.6%，第十年全包不超过3.8%；公共投资、债务、利息和弱衡域配套触发阈值依参数表执行。
4. **证据锁**：所有预测写区间、等级、误差和证伪条件。目标落在基期误差带内不能宣称有效；C、D级成本须留10%—25%容量缓冲。
5. **名称锁**：机构、首席职位、企业、地域和法源必须使用已登记全称、简称与编号。未登记候选名不得写入生效规则、预算、合同或数据字段。
6. **现实隔离锁**：除现实资料目录外，不出现任何现实国家、机关、法律、公共企业或商业企业专名，也不得通过换一字形成影射。
7. **权力分离锁**：不得合并安序侦查、公益追诉、裁判与羁护矫正的个案指挥链；不得合并财政、币值和金融审慎职责；不得让统计者为政策绩效背书。
8. **公共资产锁**：公业持衡会只做所有者；行业机构只监管；公契采办署只维护采购制度与平台；企业只经营。任何联席会议不得突破这四层边界。
9. **数据锁**：全国信息系统须有目的绑定、最小字段、到期删除、访问日志、人工复核、可用线下渠道和真正独立的双地灾备。
10. **能力锁**：全国扩围前必须分别验证人员、案件负荷、培训、维护、线下服务和灾备门槛；能力不足时提供降级或替代服务，不得宣布权利失效。
11. **公共企业锁**：政策任务必须按合同单列净成本、质量、补偿与退出；公共企业不得借任务交叉补贴竞争业务，不得拥有许可、处罚、征收或裁判权。
12. **存量与失败锁**：每项制度都要保护合法存量，说明补偿、暂停、最低服务和恢复／废止条件；不得把试点成功写成自动全国推广。

## 四、一致性自查

| 检查项 | 结果 | 处置说明 |
|---|---|---|
| 正式机构全称重复 | 未发现 | 44个机构各有唯一编号和登记简称 |
| 首席职位重复 | 未发现 | 每个机构使用专属功能职位；另设任职互斥规则 |
| 企业法定名称重复 | 未发现 | 28个企业使用唯一编号、法定名称和品牌 |
| 企业品牌与机构简称重复 | 未发现 | 企业意象品牌不使用公权保留词根 |
| 监管与经营冲突 | 已消除 | 每个企业均列监管或购买接口，并禁止企业行使监管权 |
| 所有者与采购冲突 | 已消除 | 公业持衡会与公契采办署分立，政策购买者另列 |
| 统计与政策冲突 | 已消除 | 国况计量署只负责定义、测量和修订，不设政策目标 |
| 安序、检控、裁判、矫正冲突 | 已消除 | 四条个案链分别登记，不设共同首长 |
| 财政、货币、金融监管冲突 | 已消除 | 国帑筹理署、币值衡定院、融业慎行署分立 |
| 现实专名风险 | 人工检查未发现 | 全部专名依原创构词生成；仍须纳入主编最终禁用词扫描 |

## 五、留待后续制度具体化的事项

本轮不替部门制定具体制度。后续部门仍须分别完成两庭代表产生细节、独立机构任免程序、地方派出结构、税种与转移支付公式、给付资格、行业许可、司法程序、紧急授权、企业政策任务合同和十年过渡顺序。上述具体化不得改变本报告列明的分权和财政硬锁；确需变更时须形成总督裁决并同步修订所有受影响索引。
