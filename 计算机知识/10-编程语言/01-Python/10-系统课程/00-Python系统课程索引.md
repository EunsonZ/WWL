## 学完要能解释什么

从对象与协议模型理解 Python，并把类型提示、运行时验证、并发和工程依赖分开。

**版本与模型**：Python 3.11+；CPython 实现细节明确注明。

## 从已有基础进入同一项目

第一次编程从 [[计算机知识/10-编程语言/01-Python/00-Python基础-MOC#零基础的第一个程序|基础 MOC 的首程序]] 开始；按其中 01–05 完成函数、容器、文件与异常，运行实践项目的 `examples/first_record.py`，再读第 11 讲。遇到值对象回基础 06，惰性资源回系统 03，运行时边界回系统 07。描述符和 C3 是解决属性机制问题的分支，读 CSV 不必先学它们。

已有编程基础可从第 11 讲的数据合同与手算进入第 12 讲，先预测重放和失败后的行集，再运行工程；若安装或导入失败，回 [[计算机知识/10-编程语言/01-Python/07-模块包导入与项目结构#8. 扩展练习：从导入失败到稳定入口（完成 08、09 后）|模块项目课的隔离安装实验]]。基础 07–09、12、14 提供项目、环境、依赖选择与测试主解释；基础 10–11 是工具选择分支，13 是科学库分支。

| 累积能力 | 这一步的可检查产物 |
| --- | --- |
| 运行、函数和文件 | 说明解释器、脚本、工作目录，读出一份有限记录，解释非法行与零的区别。 |
| 对象和协议 | 选择字典或不可变值对象，说明生成器何时读取及谁关闭文件。 |
| 标准库与数据语义 | 对同一 a–d 行集手算均值、两种方差与 RMS²，标明单位、分母和缺失政策。 |
| 项目交付 | 从 wheel 安装并在异目录运行 CLI，复算 SQL 行集；观察批回滚和修复重跑。 |
| 性能和并发 | 正确同步版本之后再测瓶颈；回系统 04–06、10 选择并发方式与关闭责任。 |
