# 离散扩散语言模型与自回归对照

**先修与定位：** 需要[[AI/20-LLM/10-原理/07-语言模型目标分词粒度与评测可比性|自回归目标]]与[[AI/11-数学与统计桥梁/03-概率似然贝叶斯与信息论|条件概率]]，再连接扩散专题。

## 语言生成不必固定为从左到右

自回归按固定顺序建模下一 token 条件分布。离散扩散可先把一段文本逐渐破坏为遮蔽状态，再训练模型逆向恢复。LLaDA 是采用遮蔽前向过程与 Transformer 逆向预测的语言模型研究实例。[^S59] 这说明另一些生成路径可以获得有用语言能力，不意味着所有自回归优势都被推翻。

离散 token 不能直接当作像素加高斯噪声，因为词表索引间的欧氏距离没有天然语言意义。应明确破坏过程是 mask、替换、离散马尔可夫转移，还是在连续潜空间里进行；它们的训练目标与采样规则不同。

## 遮蔽比例与损失权重为什么连在一起

设原文为 $x_0$，每个位置以概率 $t\in(0,1]$ 替换为 mask，得到 $x_t$。模型用可见位置与噪声时间预测被遮蔽 token。某类吸收态遮蔽构造的似然界相关目标具有如下形态：

$$
\mathcal L=\mathbb E_{t,x_0,x_t}\left[-\frac1t\sum_{i:x_t^i=\mathrm{mask}}\log p_\theta(x_0^i\mid x_t,t)\right].
$$

这里写出核心权重结构，具体归一化、时间采样和条件输入以对应论文定义为准。$t$ 小时被遮蔽位置少，$1/t$ 补偿抽样频率的一部分变化，但每个位置的预测难度也随上下文可见性改变，不能把它当作普通 MLM 随意改概率却目标不变。

$t=0$ 的表达式需要用极限或明确采样端点处理，不能在程序里直接除零。用可见目标位置计算损失还可能让复制输入支配训练，应检查监督掩码，联系[[AI/12-PyTorch/05-变长批处理Packing与有效Token归一化|有效位置]]。

## 并行预测不等于一次前向完成整段生成

采样可从全遮蔽回答开始，逐步填充若干位置，有时重新遮蔽不确定位置，再重复。多个位置在同一轮可并行预测，但它们的联合一致性仍要通过迭代建立。减少轮数可能提速，也可能牺牲质量或多样性。

如果一轮同时独立抽取多个位置，局部条件边缘分布并不自动形成正确联合分布。具体算法如何构造反向转移、选择揭示位置和处理置信度，决定生成分布。把“并行”当成“无近似、无代价的全句联合采样”是不成立的。

## 为什么KV缓存不能原样照搬

因果自回归中，旧 token 不读取未来，因此追加后其旧状态可复用。双向去噪网络中，某个位置被更新，会改变其他位置可见的信息及隐藏状态，旧 K/V 可能过期。分块或近似缓存可以设计，但需证明依赖关系或测试误差，不能直接复制自回归缓存逻辑。

填空、编辑和非左到右约束可能适合这种生成形式，但提示保护、回答长度、EOS 和多轮对话都需要明确协议。固定长度生成与可变长度自回归模型的时延比较尤其要注意长度选择成本。

## 公平比较该测什么

在相同训练数据、tokenizer 或可比计量、参数与计算预算下，对比任务质量、推理步数、吞吐、首可用输出延迟、长文本一致性和编辑能力。似然估计界、真实似然与 token 困惑度不是可随意互换的数字，见[[AI/20-LLM/10-原理/07-语言模型目标分词粒度与评测可比性|可比性]]。

自测：扩散网络用了 Transformer，因此它也是自回归模型吗？不一定。Transformer 是计算架构家族，自回归是概率分解/生成方式；attention mask 和训练目标决定二者如何组合。与[[AI/50-扩散模型/03-Score去噪FlowMatching与CFG的联系|连续扩散与流匹配]]合读，理解哪些是共享的“去噪学习”，哪些依赖连续或离散状态空间。
