# 操作系统 · MOC

操作系统课程解释程序如何成为进程、如何访问文件和设备，以及系统如何管理权限、网络和软件包。Linux 是可操作的主线；计算机系统与 CUDA 课程分别把这条线向底层机制和异构执行延伸。

## 课程入口

| 路线 | 入口 | 重点 | 继续连接 |
| --- | --- | --- | --- |
| Linux | [[计算机知识/20-操作系统/01-Linux/00-Linux基础-MOC\|Linux 基础 MOC]] | 启动、Shell、文件、权限、服务、网络和发行版包管理 | 在虚拟机完成有恢复点的实践 |
| 计算机系统 | [[计算机知识/30-计算机系统/00-计算机系统-MOC\|计算机系统 MOC]] | 指令、内存、进程、I/O、存储、VFS、文件系统、网络与性能 | 理解程序和操作系统的机制与证据边界 |
| CUDA | [[计算机知识/40-并行与异构计算/01-CUDA/00-CUDA-MOC\|CUDA MOC]] | GPU 执行、内存层次和异构并行 | 先具备语言与系统的基本模型 |

## 不要混淆的边界

- Python、C++ 等语言的语法、项目结构和构建方式归 [[计算机知识/10-编程语言/00-编程语言-MOC|编程语言 MOC]]；
- Linux 发行版软件包与 Python 项目依赖是不同层次的包管理问题；
- Linux 课程教你用 `findmnt`、`stat`、日志和服务工具观察系统；[[计算机知识/30-计算机系统/12-VFS文件描述符Inode目录与路径解析|VFS 与路径解析]]、[[计算机知识/30-计算机系统/13-文件系统布局日志CoW与一致性|文件系统一致性]]继续解释这些观察背后的内核对象、缓存和持久化保证；
- GPU 程序仍由主机操作系统、驱动和运行时共同支撑，CUDA 不是与操作系统无关的“另一套电脑”；
- AI 中的模型与训练任务从 [[AI/00-开始/00-AI-首页|AI 首页]] 进入；本域提供其运行所依赖的系统基础。
