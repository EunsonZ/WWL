# 同一相位样点，软件展开选了哪种历史

先在 [[数学/45-复变函数/03-指数对数复幂与分支#先预测跳跃，再复算两种历史|五样点手算]] 预测两次该补 $2\pi$ 的位置，再到这里看同一组数。完整数学证明在原课，不由软件的返回值充当证据。返回 [[数学/36-拓扑学/10-覆盖空间与van-Kampen/01-覆盖的局部副本与路径提升#从圆周相位返回：唯一提升用了哪份输入|覆盖路径输入]] 时说清整条连续路径是否已知；返回 [[信号与系统/20-数字信号处理/04-IIR设计二阶节与幅相取舍#有限复频响样点能确定群延迟吗|群延迟应用]] 时说清频率步的单位。

[固定输入](inputs.json)用有理数记录角速度、间隔与噪声，角度以 $\pi$ rad 为单位，运行时转成binary64的rad。[源码](phase_unwrap.py)是一份 Python 标准库有限展开演示，不需要第三方依赖。`unwrap` 的唯一实现将每个原始相邻差按 `(delta + pi) % (2*pi) - pi` 归约到 $[-\pi,\pi)$，再累加到给定相容起点。初相位 `initial_phase_pi` 同时进入A/B、改变间隔及有噪的真值与展开起点，不只改变圆周代表。半圈时明确选 $-\pi$；另一方向仍符合相同观测，算法端点约定不会补充信息。零幅值有效性另作判断，不能把 `cmath.phase(0j)` 的数值0当作有效相位。

输入卡允许2至64个样点，1至8个不同正采样间隔，1至8个不同非负整数延迟；噪声和非负幅度列表长度须等于样点数。速度、起点、间隔和噪声须为有限有理数或可转成有限有理数的数值，非零输入不得在转成浮点时下溢到0，所有生成的采样时间必须有限且严格递增；频率步严格正，单位固定为 `pi rad` 与 `s`。字段须与固定卡一致；错误单位、零间隔、负幅度、bool样点数及不匹配的列表都会在写输出前拒绝。名字 `safe/unsafe` 是默认卡的案例名；改变参数后看输出的 `strict_short_increment_guarantee` 和实际误差，不由名字认定满足条件。图的时间轴、相位范围、速度和起点标签从实际输入/CSV计算，A/B是否同样本也随卡改变。

在仓库根目录，用 Python 3 标准库运行：

```bash
python3 -B 数学/45-复变函数/80-相位展开实验/phase_unwrap.py --output /private/tmp/wwl-phase-recompute
```
