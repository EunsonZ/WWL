# 难点导读与研究证据

本轮不是另起一套从零教材，而是在原有主干上补齐那些“看过定义，却无法独立推导或排错”的位置。先从 [[计算机知识/00-开始/全局导航/00-总学习地图|总学习地图]] 选学科；每门学科只认一个系统课程主索引。第 1–8 讲建立主干，第 9 讲起做专题深化。旧课程地图和长篇原稿保留，作为兼容路径与补充资料，不要求重复读两套课程。

## 把难题拆成五个能回答的问题

先说清正在观察什么对象，再列出允许的操作，随后画出状态或约束怎样变化。第四步主动撤掉一个前提找反例，最后说明如何验证。如果不知道对象是谁，先画对象图；如果看不懂公式，先代入一组小数值并写单位；如果不理解并发，先写两条时间线，不要直接跳到“加锁即可”。

“编译通过”“模型通过测试”“由不变量证明”“在真实系统测量”是四种不同证据。它们可以互相支持，不能互相冒充。完整实验与命令见 [[计算机知识/_labs/round4/README|本轮实验]]；规范出处和版本边界见 [[计算机知识/90-资源/维护/导入-com/_meta/round4/01-研究证据与版本边界|研究证据索引]]；尚未执行的验证和仍属概览的部分见 [[计算机知识/90-资源/维护/导入-com/_meta/round4/02-缺口回查与后续验证|缺口回查]]。

## 四条可以真正走通的贯通路线

### 路线一：同一个值，换一种观察方式会发生什么

[[计算机知识/10-编程语言/03-C语言/10-系统课程/09-指针步长二维数组与接口形状|从数组形状与指针步长]] → [[计算机知识/10-编程语言/02-C++/10-系统课程/10-借用视图失效与异常提交|借用视图失效]] → [[计算机知识/10-编程语言/04-Rust/10-系统课程/09-借用检查中的量词方差与重借用|重借用与生命周期量词]] → [[计算机知识/10-编程语言/05-TypeScript/10-系统课程/10-运行时边界状态机与取消安全|运行时可信边界]]。

这条路线比较“地址还在”“对象还活着”“引用仍合法”“值满足业务要求”四件不同的事。先给每个引用写出拥有者和失效操作，再解释哪一层负责检查。验收：连续二维数组为什么不能传给双重指针；没有扩容的 vector 在 erase 后哪些借用仍失效；静态类型正确的网络结果为什么仍要校验。

### 路线二：怎样把过去压缩成足以决定未来的状态

[[计算机知识/50-数据结构与算法/10-数据结构系统课程/09-懒标记的代数与完整实现|区间摘要与懒标记复合]] → [[计算机知识/50-数据结构与算法/10-数据结构系统课程/11-字符串索引LCP与自动机状态|KMP 的已匹配前缀]] → [[计算机知识/50-数据结构与算法/20-算法设计系统课程/09-动态规划状态充分性与优化前提|动态规划的状态充分性]] → [[计算机知识/70-编译原理/10-系统课程/09-从项目集到SLR分析表完整推演|LR 项目集与状态栈]] → [[计算机知识/70-编译原理/10-系统课程/10-活跃性不动点与抽象解释|数据流不动点]]。

共同问题不是“都用一张表”，而是保留了哪些信息，丢弃了哪些信息，以及剩下的信息为什么足够。验收：把新旧标记倒序会怎样；0/1 背包为何要倒序更新；SLR 归约后为什么必须再次查 GOTO；迭代稳定为什么不自动等于优化正确。

### 路线三：局部都正确，整体为什么仍然出错

[[计算机知识/10-编程语言/02-C++/10-系统课程/11-原子发布线性化与回收边界|原子操作与整体不变量]] → [[计算机知识/20-操作系统/02-操作系统原理/10-系统课程/10-条件变量丢失唤醒与活性证明|条件变量与活性]] → [[计算机知识/55-数据库/10-系统课程/10-MVCC快照写偏斜与重试协议|MVCC 写偏斜]] → [[计算机知识/85-综合贯通/02-超时重试幂等与事务发件箱|超时、幂等与事务发件箱]]。

先写两个参与者的读、写、等待、确认顺序，再检查整体约束。验收：两个 atomic 操作能否当成一次原子加一；谓词为真是否保证某个等待者最终获得调度；不同写集合的事务怎样违反同一个约束；请求超时后换新 ID 重发为什么可能产生第二次业务效果。

### 路线四：“完成”到底完成到了哪一层

[[计算机知识/30-计算机系统/10-组成原理系统课程/10-流水线乱序与精确异常推演|CPU 执行与架构提交]] → [[计算机知识/20-操作系统/02-操作系统原理/10-系统课程/09-页表写时复制与TLB失效|页表更新与旧翻译失效]] → [[计算机知识/20-操作系统/01-Linux/10-系统课程/09-FD共享epoll与非阻塞状态机|FD、就绪事件与实际读写]] → [[计算机知识/35-计算机网络/10-系统课程/10-TCP窗口RTO与拥塞控制手算|TCP ACK 与应用确认]] → [[计算机知识/55-数据库/10-系统课程/12-WAL日志恢复与副本确认边界|WAL 与副本确认]] → [[计算机知识/20-操作系统/02-操作系统原理/10-系统课程/11-崩溃一致性与恢复状态机|文件替换与掉电持久性]]。

每一步都给“完成”加上观察者和失败模型。验收：较年轻指令先算完时为何不能直接提交；epoll 返回就绪后为何仍要处理 EAGAIN；对端 TCP 确认字节能否证明订单已提交；rename 返回成功后什么证据支持掉电后的结果。

## 阅读顺序与练习的停止条件

第一次读只回答页首问题，第二次遮住结论复算数值、状态表或代码输出，第三次改变一个输入边界或故障发生点。能够说出失败发生在哪个合同边界，才算真正掌握；只会重复名词不算。遇到与当前问题无关的关联链接，可以先略过，避免把知识图谱读成无法退出的递归。
