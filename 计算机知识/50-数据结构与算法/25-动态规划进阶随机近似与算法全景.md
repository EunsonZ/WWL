# 算法设计深化：状态设计、随机近似与完整地图

> 阅读定位：正确性证明、输入假设、复杂度与反例。返回 [[计算机知识/00-开始/课程地图/11-算法设计-课程地图|算法设计 · 课程地图]]；全域入口 [[计算机知识/00-开始/全局导航/00-总学习地图|计算机知识库 · 总学习地图]]。

## 状态必须保存未来需要的信息

加权区间调度中，按结束时间排序，令 p(j) 为与区间 j 兼容的最后一个前驱下标。定义 OPT(j) 为前 j 个区间中的最大总权，则：

$$OPT(j)=\max\bigl(OPT(j-1),w_j+OPT(p(j))\bigr),\quad OPT(0)=0.$$

两支分别是不选 j 与选 j，覆盖全部可行最优解。p(j) 可以用二分求得，但端点相等算不算冲突须先约定。最后若要输出选中的区间，必须保存选择或可回溯信息，而不是只有最终数字。

LIS 的 tails[k] 表示某长度递增子序列能达到的最小尾值，用更小尾值给未来留机会；tails 本身未必就是原序列中的一条完整合法答案。要恢复序列须保存前驱关系。这个例子说明状态可以是证明工具，不必直接等于最终对象。

## 常见 DP 族各自适合什么

序列 DP 处理前缀依赖，区间 DP 处理切分位置，树形 DP 利用子树独立性，DAG DP 按拓扑推进，状压 DP 保存小集合状态，数位 DP 跟踪前缀约束，概率 DP 表达随机过程。记忆化与自底向上是求解方式，状态是否充分才是核心。

空间压缩必须保持每次读取来自正确阶段；背包降序避免重复使用当前物品，完全背包的允许复用又产生不同顺序。DP 优化如分治优化、Knuth 优化、凸包优化要求额外性质，不能因递推式长得像就套模板。

## 随机与近似的保证不能混用

Las Vegas 类算法保证答案正确、运行时间随机；Monte Carlo 类算法通常限定时间但允许受控出错。随机快排的期望代价与哈希随机化依赖相应随机模型，固定坏输入与对抗性选择需重新分析。概率上界要说明独立性与采样方式。

近似算法对最优值给出比率等保证；启发式可能有效却没有同样形式保证。贪心集合覆盖、度量旅行商等教材结论各有输入限制；不能把度量条件下的方法推到任意非度量图。参数化算法把某个参数 k 的昂贵部分与输入规模 n 分开，适合 k 小的实例。

## 不重要也应该知道位置的内容

数论算法有 gcd、扩展 gcd、模运算、快速幂和素性测试；数值算法有误差、条件数与稳定性；多项式运算有 FFT/NTT；计算几何有方向判断、凸包、扫描线和精确谓词；字符串有 KMP、Z、自动机、后缀结构与哈希；外存算法关注 I/O，在线算法关注未来未知，流算法关注有限内存，多线程算法关注工作量与跨度。

分支限界、整数规划、SAT/SMT、动态算法、近似最近邻和压缩算法属于进一步路线。算法课程不要求一次写完所有工业求解器，但必须知道遇到哪类约束时该转向哪个工具，并区分已证明、实测与猜测。

练习：为加权区间调度构造“最早结束优先但权重很差”的反例，手算 OPT 表和回溯答案，再解释为什么原来无权贪心的证明不再适用。
