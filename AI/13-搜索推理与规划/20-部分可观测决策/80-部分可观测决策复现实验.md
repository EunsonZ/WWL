# 部分可观测决策复现实验

这里提供本单元合成模型的可执行真源 [pomdp_lab.py](pomdp_lab.py) 和 [行为测试](test_pomdp_lab.py)。只用Python标准库，全部概率/损失用 `Fraction`精确表示；不下载模型、不访问数据/网络。正文证明说明为什么递推合法，实验只核实现、数字和声明模型是否对应。源码镜像见 [[AI/13-搜索推理与规划/20-部分可观测决策/code-sync/源码与测试镜像|源码与测试镜像]]，修改真源后须同步镜像。

## 固定输入、输出和命令

从本实验目录运行 Python 3.10+。输出默认到终端；`--output`必须为父目录已存在的新文件，使用排他创建，拒绝覆盖旧结果。把结果放在库外自己的实验目录，不把临时路径当课程默认数据路径。`-B`避免写入 `__pycache__`。

```bash
python3 -B -m unittest -v test_pomdp_lab.py
python3 -B pomdp_lab.py --prior 1/10 --cost 1 --prevention 20 --horizon 3
python3 -B pomdp_lab.py --prior 1/10 --cost 3 --prevention 20 --horizon 2
python3 -B pomdp_lab.py --prior 1/10 --cost 6 --prevention 20 --horizon 2
python3 -B pomdp_lab.py --prior 1/10 --cost 0 --prevention 60 --horizon 2
```

输入用整数、分数字符串或精确十进制字符串，如 `1/10`、`0.1`；程序接口拒绝float/NaN以免把二进制近似当精确有理数。`--sensitivity`默认4/5、`--false-positive`默认1/10；damage固定100。horizon限1–4，最后一步不允许测量，提前终止后不继续扣损失。输出分别保存模型口径、Bellman收益、oracle风险、并列根动作、树数量、最优完整树和一信号信息价值；每个Fraction同时给精确字符串及便于读图的十进制近似。

| 输入或可检查量 | 数学预期 | 解释 |
| --- | --- | --- |
| `c=1,K=20,h=2` | risk32/5=6.4 | 买一次信号，再选动作 |
| `c=1,K=20,h=3` | risk623/100=6.23，38树 | 首正后再测，首负后不预防 |
| `c=3,K=20,h=2` | risk42/5=8.4 | RS5.4加费用3 |
| `c=6,K=20,h=2` | optimal risk10 | 不买；强行购买净改善−1.4 |
| 一条免费信号、K20 | R0=10，RS=27/5，EVSI=23/5，EVPI=8 | 后验8/17、2/83 |
| 一条免费信号、K60 | R0=RS=10，EVSI0，EVPI4 | 两分支不预防，认识仍更新 |
| 三状态同均值0 | delta0选安全，±1各半选风险 | 风险收益分别−.5、+.5 |

K60的零EVSI只认证一条信号。允许两条时 `++`后验64/73超过.6，可以改变动作；不能用一阶段结果宣称任意序列均无价值。h3/c0/K60由oracle枚举另算。

## 两条不同实现路径检查同一对象

`belief_update`显式使用旧状态行/新状态列T与状态行/信号列O，验证概率、shape和归一；零概率观测报错。`bellman`在belief上比较终止动作与测量分支，跳过零概率分支。

`policies`枚举每个观测下的完整后续行动树，`state_tree_loss`只读取状态条件观测概率与原始损失，对真状态固定的全部观测路径求风险，不调用belief更新、`signal_branches`或Bellman；`oracle`最后按先验求和取最小。测试在固定prior/h/c/K网格核对两路径，另独立四格联合表核对非恒等T下的filter。这个filter检查不把动态T偷偷用于静态监测策略oracle。

测试还覆盖：第二次测量费用阈值2及并列动作；完美/无信息极限；最后一次不能只测不行动；先验0/1的零概率分支；非法概率和时域；K60在一/两信号下不同；delta0与±1的非线性行动。它们验证有意义的合同，不只让代码和自身重复公式互相对照。

## 改条件前先预测

```bash
python3 -B pomdp_lab.py --horizon 2 --cost 0 --sensitivity 1 --false-positive 0
python3 -B pomdp_lab.py --horizon 3 --cost 1 --sensitivity 1/3 --false-positive 1/3
python3 -B pomdp_lab.py --horizon 1 --cost 0 --sensitivity 1 --false-positive 0
python3 -B pomdp_lab.py --horizon 3 --cost 0 --prevention 60
```

前两项预期风险2和10；第三项因不剩“先测后行动”的机会，风险仍10；第四项有二次信号可能跨.6，不能拿第三课的单信号零EVSI当答案。若将信号变为缓存复制或让测量改变Y，应先扩展模型；当前命令没有这类开关，不能只改一个数字后声称已验证新机制。
