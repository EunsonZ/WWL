# 概率结构、空间结构与知识全景：压缩信息就要说明损失

> **学习位置**：[[计算机知识/00-开始/课程地图/06-数据结构-课程地图|数据结构课程地图]] · **适用边界**：RAM 模型为默认；均摊、期望和最坏情况分别说明。

## 近似结构先写错误合同

Bloom filter 用 m 位和 k 个哈希位置表示已插入元素。在没有删除错误、哈希实现满足假设且状态未损坏时，查询不存在可以作为确定否定；查询存在可能是假阳性。插入 n 项后常用近似为

$$p\approx\left(1-e^{-kn/m}\right)^k,$$

其中指数近似和位置独立性都是模型假设。取 $k\approx(m/n)\ln2$ 可在该模型下优化误报率。它不能返回元素内容，普通位图版本也不能随意清零删除，否则会伤害共享位的其他元素。

例如每元素约 10 位、k 取 7，近似假阳性约 0.82%。这不是所有工作负载的实测承诺；容量超出设计 n 后误报率上升。用已插入样本与独立未插入样本分别检验漏报和误报，并给样本规模与不确定性，而不是看十次都对就宣称零误差。

## 流式摘要保留哪些信息

Count-Min Sketch 用多行计数与取最小值估计频次，在常见非负更新模型中倾向高估；负更新会改变保证。HyperLogLog 通过哈希前导零等统计估计不同元素数量，误差是估计精度而不是布隆式成员误报。水库抽样在未知总长度的流上维护等概率样本，随机源与更新规则必须正确。

这些结构适合监控、候选筛选与大规模摘要，不适合未经核验直接决定高风险授权或删除。原库的概率结构专题给出了更完整的误差合同与流式实验，应与本页一起阅读，而非用本页替换它。

## 优先队列的扩展家族

二叉堆提供顶部最值与对数更新；d 叉堆改变高度与每层比较数。二项堆、Fibonacci 堆和 pairing heap 关注合并、减键与均摊代价，但不同操作界与实现复杂度各异。实际最短路实现常用“重复插入＋弹出时丢弃过期项”，避免复杂减键接口；代价是额外堆项和内存，需要把复杂度算进去。

整数键可利用桶、radix heap 或 van Emde Boas 等结构中的键域信息，突破纯比较模型下的某些界，但必须把位宽、键范围和单调性前提写清楚。

## 空间与压缩结构

k-d tree 交替按坐标划分空间，适合某些低维范围与近邻查询；R-tree 用包围盒组织空间对象，常用于地理索引；四叉树、八叉树按空间递归划分。高维下距离区分与剪枝效率可能恶化，不能无条件承诺近邻查询对数时间。

位向量、rank/select、succinct tree 和 wavelet tree 关注接近信息论下界的表示与快速查询。Rope、piece table 适合大文本编辑；arena、对象池和紧凑句柄适合控制分配与局部性；无锁结构还必须处理 ABA、内存回收和进度保证。每个分支都由具体工作负载驱动，不是数据结构名称收藏。

## 综合验收：构建可解释的索引服务

为事件记录提供按 id 去重、按时间范围扫描和近似成员预筛选。可用哈希表维护 id、平衡树或排序块维护时间、Bloom filter 做前置过滤。一次插入要么同时更新各索引，要么失败后回到一致状态；删除与重建要有策略；所有结构的元素集合应与参考模型一致。

报告查询比例、键长、记录数、峰值内存、平均与尾延迟、误报率及失败注入结果。数据结构学习的终点不是背完复杂度表，而是能够证明表示不变量、解释假设，并用可复现实验发现自己最初选择的局限。
