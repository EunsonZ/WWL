# 绝热演化与非绝热跃迁复算

从 [[物理/40-量子力学/16-绝热演化与二能级非绝热跃迁|正文16]] 带入一个预测：最低瞬时能量的人口保持，是否等于固定 z 标签人口保持？再把速度、隙、初末窗口分别改变，比较有限完整方程、绝热近似与无限时间公式。数值源码 `adiabatic_sweep.py` 只依赖 Python3 标准库；它没有调 CG、LZ 表或真实设备。

## 固定模型和运行接口

```bash
python3 adiabatic_sweep.py --input inputs.json --output assets
```

本次隔离环境已有双槽数值守卫，可作1线程、60秒预跑；它不是读者必须安装的实践依赖：

```bash
python3 /private/tmp/numerical_guard.py --threads 1 --timeout 60 -- python3 adiabatic_sweep.py --input inputs.json --output assets
```

实际作者环境为 Python3.14.7、macOS27.0.1 arm64；预跑约0.6秒，退出0。矩阵始终2×2，标准库单线程，不需要 SciPy/NumPy，也没有改系统依赖。守卫控制两槽和线程环境，不能据此声称强制执行内存上限。新输入请输出到独立目录，例如 `--output /private/tmp/adiabatic-changed`，以保留固定交付结果。

模型为 $H(t)=(\Delta\sigma_x+vt\sigma_z)/2$，基顺序 $(|+z\rangle,|-z\rangle)$，初态是−T的**瞬时基态**。每个时刻主要观测都是当时 $H(t)$ 的激发投影；另外记录固定 z+ 投影，它不是相同事件。标准库使用 $h=6.62607015\times10^{-34}$ J·s、$\hbar=h/(2\pi)$，定义

$$E_0=hf_0,\quad u=2\pi f_0t,\quad d=\Delta/E_0,\quad b=v\hbar/E_0^2,\quad T=L/(2\pi f_0).$$

`energy_scale_frequency_hz=100000` 意味 $E_0/h=100$ kHz；Δ/h=d f0，v=b E0²/ℏ，CSV 的时间是 μs。u、d、b、κ、θ及概率无量纲；θ和相位以 rad 记录。不能把 f0的Hz直接代入角频率指数。

默认四例：基准 `(d,b,L)=(1,.25,32)`、慢五倍 `(1,.05,160)`、快二十倍 `(1,5,1.6)`、同速度同时间小隙 `(.25,.25,32)`。前三例端点偏置/隙保持±8；第四例变±32，起始和终点本征基会跟着变化。另对基准保持 d、b，取 L=8/16/32/64作边界比较。

| `sample_intervals` | 40..1000的整数，默认400，每例包含401个样本 |
| `base_steps` | 400..50000的整数下限，默认1600；源码还按最大转角自动增密 |

## 源码怎样推进完整二态演化

`frozen_step` 用 $A=d\sigma_x+z\sigma_z$、$A^2=(d^2+z^2)I$ 准确计算

$$e^{-ihA/2}=\cos(hr/2)I-i\frac{\sin(hr/2)}r A,\qquad r=\sqrt{d^2+z^2}.$$

右侧的 h 在这条算法式里表示**无量纲数值步长**，不是 Planck 常数；源码变量命名在 `H_PLANCK` 与局部 `h` 之间区分。含时 Hamiltonian一般不对易，准确冻结指数仍不等于完整含时解。

`advance` 对这里的仿射时间依赖用四阶无对易子 Magnus 两指数：先以半步长在 $u+h/6$ 的H作用，再在 $u+5h/6$ 作用。它不是通用于任意H的“两点采样”规则；这两个有效节点来自仿射H的 CF4 系数组合。若写 $A(u)=-iH(u)/E_0$，精确 Magnus 的前三阶是 $hA_{\rm mid}-h^3[A_{\rm mid},A']/12$；两半步的 BCH 展开给相同两项，时间对称性消除偶次局部项，故此仿射光滑问题的局部误差为 $O(h^5)$、全局为 $O(h^4)$。更广波形需要重新选适用积分法。

每次推进完整 U 的两列，从 I2 开始；不把瞬时本征态直接代作解，也不强行归一以遮掩酉性误差。对每例取 N、2N、4N步，输出4N解，对齐所有采样点比较**最大矩阵元绝对差**及激发概率差。定理中的范数则是谱范数，不能将两个数字直接当同一口径。默认前三种非精度底限情形的矩阵差比约16；快扫细网格已近浮点误差底限，观察比约11，未强制将其“修正成16”。

另以二阶中点冻结指数在同样4N网格推进，记录与CF4的概率差。它提供算法阶次的交叉观察，但不当作准确答案；独立 runner 应使用另一条求解路线核完整方程。源码有限步数给收敛证据，不自动成为严格离散误差定理。

## 先预测再复算

- 原LZ式在本约定下是 $e^{-\pi d^2/(2b)}$；Δ已是完整最小隙，不能再把指数的Δ当作非对角元Δ/2。有限−T基态与有限+T投影是本实验接口，不用±∞的边界冒充相同制备。
- 默认慢五倍末概率约1.799e-9，远大于无限值2.271e-14；默认缩步误差又远小于这两者差。这是有限制备/截断合并边界差异，不能靠加密步长消除。保持同一参数路径继续变慢时，也不能承诺有限概率机械地服从无限指数式。
- 改能量尺度 f0而保持d,b,L，预测无量纲概率不变，时间和能隙分别按1/f0和f0缩放、v按f0²缩放。读数单位改变并不代表另算出不同无量纲物理。
- 改本征规范后，要协同改几何相位与初始系数；只改本征列属于换描述，固定基中改变制备相对相位则是不同物理任务。
