## 输入、源码与本机运行日志

- [生产与受众材料](生产与受众材料.md)：完整R1–R5、P1–P6、H1/H2及材料身份；它们不增加原M3的采访样本。
- [固定模型输入](inputs/model.json)：候选评分/约束、四环关系与人工潜在结果、两组缺失记录。它不是抓取语料或真实问卷。
- [规范源码](src/communication_lab.py)，仅Python标准库。`--input`可指定这份固定输入的存放位置；本课交付的是该固定教学模型及已明确的变条件，不宣称任意新模型的图注都自动适用。欲改节点数、量表或评分规则，应同时修改验证、图注和正文承诺。
- [精确JSON](results/communication.json)、[生产图](assets/newsroom-choices.svg)、[网络图](assets/network-effects.svg)来自同一次程序计算；JSON分数用字符串保留精确有理值，`null`表示该全人群目标不可由设计估计。作图坐标允许浮点，不反写计算结果。

2026-10-17本机经共享`run_local.py --timeout 300`执行，进程退出0，未调用网络、GPU或付费资源。实际标准输出：

```json
{"bernoulli_assignments": 16, "balanced_assignments": 6, "optimal_grid": [["F"], ["S", "F"], ["S"]], "outputs": ["results/communication.json", "assets/newsroom-choices.svg", "assets/network-effects.svg"]}
```

在本目录普通Python3下可运行：

```sh
python3 src/communication_lab.py --input inputs/model.json --output-dir .
```

结果目录另写时使用`--output-dir /某个空目录`，不覆盖原输入。源码拒绝非法概率、边/shape、超出枚举规模、量表越界、非法缺失计数等；函数的输入域不等于已验证新的社会解释。运行在两共享槽中的一槽、线程变量为1，低于4线程/8GiB界；无需安装依赖。两SVG已实际CairoSVG栅格化并目视，当前标签英文，中文说明在正文；尚未在Obsidian客户端验证显示或点击。

首次作者目视曾发现空暴露条件的Python空和除法引入浮点尾差，已将空和初始化为Fraction(0)，并禁止JSON中出现float；修后重新运行，期望精确为1、2、2、3。这个修复只认证当前计算实现，不把程序错误史包装成额外理论验证。

## 每个实验究竟支持哪条断言

| 具体断言及重要性 | 为什么做/独立可得的预期 | 容差与失败条件 | 实际结果及可支持范围 |
| --- | --- | --- | --- |
| **高：** 商业评分与核验约束不能混为真假判断 | 手算S−F=4p−2；p=0、1/2、1为F、并列、S；H未核。去掉q时p=1，H=8>S=6 | 分数和可行性必须精确相等；若H穿过核验门槛、漏掉并列即失败 | 输出全部候选分数/可行性及最优集符合；支持这一有限模型，不估真实p或所有权效应 |
| **高：** 正确映射/正概率下HT期望正确，单次不必正确 | 一般证明在04；四环16种分配精确穷尽。μK=1+z+e、μA=3、μR=1/2 | 所有分配概率和为1，输出每人概率、观测与估计；期望须精确，无Monte Carlo容差 | 当前各均值期望与解析值相等；0000的K(00)估计8，揭示设计不确定性，不是认知实测 |
| **高：** 随机化不保证每种暴露可达 | 固定两人设计6种；π(00)=0，π(01)=1/2，π(10)=1/6，π(11)=1/3 | 零概率不得加epsilon后报告可估，未估项须null | 全部6分配给该概率；00均值/相关估计为null；无法由加权恢复不可见条件 |
| **高：** 平均态度0不表示没有个体变化，知识变化不等于说服 | 人工d=(1,1,−1,−1)、s=(1,−1,1,−1)分别和0；K直接/邻居各1，A/R各0 | 个体与平均、量表范围及结果名称须逐一保留 | JSON全行保留三个结果；仅作为反例，不给真实公众态度或行为结论 |
| **中：** 失访足以让完成者相等与全体未知并存 | 分别把未答题分填0和4，A[2,2.8]、B[2.25,2.65]、差[−.65,.55] | 有理端点精确；这不是置信区间，不能凭窄/宽作显著性判断 | 输出[−13/20,11/20]，完成者均5/2；仍未识别实际缺失机制或因果效果 |

图只回答两个问题：p怎样改变S/F相对分数；设计怎样改变暴露机会与平均读数。图中的四节点是输入网络，并非真实朋友圈或模型拟合所得。有限枚举检验实现和反例，一般无偏论证不能由16次枚举代替。
