# U6：噪声中的脉冲检测

要交付一条能复算的决策链：**记录 → 模板内积 → 阈值 → 是否报警 → 到达估计 → 独立计数**。本实验的全量模拟是有限离散模型，信号幅度用任意一致单位、噪声标准差为1；未涉及 ADC、传感器、实时流和真实客户。

## 两个入口与共同停点

- 基础入口：先手算 [[信号与系统/30-随机信号与推断/01-随机过程相关与功率谱#两个入口，同一个问题|四点记录的均方与 DC]]，再算 [[信号与系统/30-随机信号与推断/02-匹配滤波检测与未知到达时间#从短向量到检测统计量|三点模板分数]]。两次手算都能与源码输出对上，即完成第一停点。
- 快进入口：读本页固定协议，然后到同两课的形式模型与似然比。检查能否说明单位置阈值与未知位置阈值不同，进入相同运行与迁移题。

## 固定协议

模板 $s=[0,1,2,1,0]$、长24点记录，完整窗起点共有20个。噪声为 i.i.d. $N(0,1)$。$H_1$ 加 $A=1.25$ 的模板，起点在0至19均匀随机选择；这些位置先验用于生成测试，不宣称 GLRT 已成为该先验下 Bayes 最优。

SeedSequence 由种子62026派生三个独立流：6000条**无目标训练**记录标定最大分数的经验99%分位点（`higher`）；12000条新 $H_0$ 记录与12000条新 $H_1$ 记录作最终评测。最终测试不调阈值。另比较单位置标准正态阈值与20位置 Bonferroni 阈值。发生人改参数时必须重跑训练和独立测试，记录参数，不能复用旧结果称同版。

误报以整条无目标记录为一个试验，检测以整条有目标记录为一个试验。到达绝对误差用样本数，分别给全 $H_1$ 与已检出子集。当前记录未声明物理采样率，所以到达误差**不直接标 ms**；谱示例独立指定 $f_s=64$ Hz。

## 解释结果，而不只读一行通过

1. `fpr_at_one_position` 应在有限抽样误差内靠近0.01；`fpr_global_using_single` 通常更大。重叠窗的相关意味着不能把独立位置公式当精确真值。
2. Bonferroni 在正确的局部模型下有整体不超过0.01的总体保证；一次12000条测试的经验比例可能高于/低于0.01，这不自动推翻/证明总体保证。
3. 训练分位阈值的测试误报是经验结果，未附覆盖保证。已知位置理论检测率仅用于不同任务的参照，不能拿它当未知位置模拟的“期望正确答案”。
4. 全 $H_1$ 的误差和已检出误差回答不同问题；漏检样本不能从评测总表消失。

到 [[数学/30-概率与统计/05-统计估计置信度与模型评测#先定义到底想知道什么|目标量与偏差定义]]说明模拟总体和抽样单位，再回来给结果写限制。当前测试未建立任何置信区间；即使补上二项 Wilson 区间，也只能说明固定模型下独立记录抽样的名义区间，不覆盖模型错设/训练阈值的全部不确定性。

## 条件改变的交付练习

- 把模板翻转或加一个负瓣，手算分数后解释 SNR 变化。合法答案可以指出真实脉冲模板尚未知，需要标定。
- 把搜索窗从20增到200，保留原阈值。提出一种能保护整体误报的办法，并说明保守性或训练量代价。
- 将 $C=\operatorname{diag}(4,1)$ 与白假设对比，使用 `colored_score` 的二点小例验证白化。不要据此声称已实现全记录有色噪声未知位置检测。
- 只有 $H_1$ 标签时调用 `evaluate`：FPR 为 `None`，解释为什么是未知。给出“缺少 $H_0$ 记录”的答案可通过。

四项各3分：模型条件1分、可复算论证1分、限制1分。接受等价的准确统计量/阈值方案；只有曲线变漂亮或准确率单数不满足协议。
