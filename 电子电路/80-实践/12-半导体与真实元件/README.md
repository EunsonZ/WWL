# 半导体与真实元件：复算、图与测试

本组支持M08六主题。所有输出都是声明参数下的教学解析或自绘机制图；没有运行SPICE、安装依赖、搭硬件、读示波器或验证Obsidian客户端。具体LED/Zener数字与官方测试点成组列在正文；具体MLCC偏压曲线未读到，不从通用教学C(V)曲线制造厂商预测。

## 从哪个问题进入

- [[电子电路/22-半导体与真实元件/01-能带载流子掺杂与输运|载流子与输运]]：解释电子/空穴、电中性、漂移/扩散和非平衡。
- [[电子电路/22-半导体与真实元件/02-PN结五空间图与端口指数|PN空间图]]：在同一x轴核对掺杂、n/p、ρ、E、φ及能带，并区分平衡图与偏置耗尽近似。
- [[电子电路/22-半导体与真实元件/03-二极管负载线整流钳位稳压与LED|四个实际电路拓扑]]：从负载线到整流、参考吸流、稳压电流分配、LED限流。
- [[电子电路/22-半导体与真实元件/04-结电容存储恢复与温度|动态与温度]]：Q/V、dQ/dV、结/扩散电容、存储抽取条件、Is(T)与VT(T)。
- [[电子电路/22-半导体与真实元件/05-真实RCL寄生偏置与额定条件|真实RCL]]：按照具体寄生拓扑解释ESR/ESL/漏电、温漂、偏流和SRF。
- [[电子电路/22-半导体与真实元件/06-数据手册测试条件与模型来源|手册测试卡]]：将每个数与版本、上下界类型、测试电路及条件绑定。

## 复算与输出约束

`semiconductor_lab.py` 只用Python标准库。导入不会写文件、输出内容或改Matplotlib全局设置。`build_visuals.py` 只有显式运行时才导入已有CairoSVG并渲染。没有安装任何包。源码不是主库旧器件API的替代，也没有修改旧源码或其镜像；本新源码目前无已有code-sync镜像。

从本目录运行，以调用者选定的**库外**目录接收输出。`--output`必填，指向本库/候选根以内的路径会被拒绝，避免把机器产物写进知识正文位置。例如：

```bash
python3 -B semiconductor_lab.py --output /private/tmp/wwl-semiconductor-run
python3 -B -m unittest -v test_semiconductor_lab.py
python3 -B build_visuals.py --output /private/tmp/wwl-semiconductor-figures
```

第三条需要已有CairoSVG；本批使用主库现有`.venv/bin/python`执行，未自动安装。每个图保留可编辑SVG，并渲染360px/425px PNG。源码生成的结果JSON放调用者库外输出；发布的`assets/parameters.json`只记录固定教学参数，图像是经过检查的候选资产。

实数参数先检查标量类型，再转换float：拒绝bool、complex（包括零虚部）、字符串、object、数组/嵌套序列以及NaN/Inf；物理正量另检查大于0。`capacitor_impedance` 是明确的频域接口，频率/物理参数仍是实数，返回合法复阻抗。`diode_load`仅解非负源、正电阻的正向单管网络；不宣称覆盖反向击穿或多根网络。夹逼二分必须有正整数迭代预算、正容差，预算耗尽/浮点停滞抛出失败，不伪造收敛状态。耗尽模型要求剩余势垒正，指数超范围明确拒绝。

## 可执行学习任务及尚未执行的外层

先手算5V/1kΩ单二极管Q点，再运行脚本，改变R为2kΩ解释交点方向；记录模型参数、手算及残差。接着保持PN掺杂比例，把反偏从0改1V，先预测宽度平方根变化，再对偏置图核算。第三步从Q(V)差分求局部C，比较用标称C和局部C预测同一小纹波RC。

如果后续要做SPICE对照，应先选具体模型卡与版本、引脚顺序、Is/N/Rs/Cjo/TT温度参数，再构建与本页相同5V/1kΩ拓扑：DC扫源0–5V得到Q；小扰动提取dI/dV；瞬态另声明前向稳态、反向抽取回路、寄生和终止阈值。输出需含网表、真实工具版本、命令、exit、模型卡hash、波形和误差。此任务未执行，本README没有虚构日志。

硬件任务另需真实型号、限流、安装、测量地、探头、参考吸流能力及温度；不将计算值填成实测数据。全库结构/114测试、独立语义签收、真实客户端和人的学习体验由批次发布/复核分别记录，本作者不自签。

## 图合同与来源

`pn-five.svg`与`pn-bias.svg`共同提出V19部分候选：掺杂和五空间量共享x；平衡/正反偏分别标；E=-φ′及能带符号一致，明确耗尽ρ与Boltzmann载流子不是完整自洽解。偏置补图只有E/φ，缺偏置ρ和非平衡载流子分布，因此V19仍为partial，不宣称全合同完成。`diode-load.svg`只贡献V21的二极管部分，BJT/MOS族、全组摆幅与Matplotlib原合同由相关组整合，不能据此宣称V21完成。其余能带、应用电路、动态、真实RCL、手册卡为教学补图，不据此计V01实物照片合同。

全部SVG由本组根据声明公式和原创网络几何生成，无复制厂商照片、封装图或版权曲线。大学资料采用devices1明确阅读范围及hash的研究输入，未冒称本作者重读全部PDF；新LED/Zener官方手册文本实际读取p1–3/p1–2，MLCC规格仅读native检索返回p5/6条目17–20、完整图像待核。原始资料支持机制或测试点，独立审阅仍是另一层证据。
