# 先修关系绕回原课程，究竟算几条路径？

学生问“a 是否间接要求 c”，教务员问“它们之间有几条需要排查的依赖链”。两人读取同一份课程目录，却不需要相同的答案。算法给 a、b 各贴一次 `visited`，可以完成可达性判断；若把它直接拿来数链，平行的两条关系、绕回旧节点再离开的链就可能一起消失。省掉结果的算法，当然跑得很轻松。

从 [[计算机知识/55-数据库/10-系统课程/13-键值文档与图模型#三种表示回答同一个查询|同一课表的关系与文档表示]] 进入：那一课回答已知学生和学期时读哪些事实，本课把问题改为**沿课程关系寻找未知长度的关联**。先固定模型和答案集合，再选择遍历、索引与一致性条件；读完回 [[计算机知识/55-数据库/10-系统课程/08-数据库工程安全与扩展专题#分区、分片和不同数据模型|模型选择与迁移]]，比较自己的工作负载是否真的需要路径作为结果。

实际运行分两层：Python 标准库实现一个有限的**教学属性图求值器**，给出完整路径和逻辑访问计数；SQLite **3.53.4** 实际执行约束、索引和两个连接的快照交错。Neo4j **5.26 风格的传统 Cypher 语法**只提供查询与待验接口，没有安装或运行 Neo4j；Python 邻接表不因此成为图数据库的运行证据。完整固定输入、实际 JSON 和命令在 [[计算机知识/_labs/round3/DB/graph_path_semantics/README|实践入口]]。

## 属性图存什么，关系表又存什么

一个节点是一门课程，不是一次选课。`a,b,c,d,z` 都有 `Course` 标签和业务 `id`；另有教师 `t7`，标签 `Teacher`。有向关系 `x-[:REQUIRES]->y` 表示本目录 T1 中 x 要求先修 y；按箭头从 x 展开，得到它的先修。反向查询“哪些课程依赖 y”必须反向展开，不是把箭头忽略。关系也有身份 `id` 和属性 `catalog`；两条关系可以端点相同而身份不同。

最小输入只有 `e1:a→b、e2:b→a、e3:b→c`。互相先修的环是本课故意保留的待审目录错误；图能表示它，不等于教务规则应当批准它。扩展输入的每条边如下，原始数据全部保存在 `spec.json`，不从图像反推输入。

| id | 起点→终点 | type | 用途 |
| --- | --- | --- | --- |
| e1 | a→b | REQUIRES | 第一条依赖记录 |
| e2 | b→a | REQUIRES | 形成有向环 |
| e3 | b→c | REQUIRES | 从环抵达 c |
| e4 | a→b | REQUIRES | 身份不同的平行记录 |
| e5、e6 | a→d、d→c | REQUIRES | 同长度的另一条链 |
| e7 | a→c | TEACHES | 类型不匹配的干扰记录 |
| e8 | t7→a | TEACHES | 另一标签与关系类型 |

全部关系的 `catalog='T1'`。e7 刻意展示**基本结构合法不等于业务合法**：后面的 SQLite 表只约束关系类型枚举和端点存在，没有强制 TEACHES 必须从 Teacher 指向 Course。查询排除 e7 不会替数据导入器补上这项业务校验。若要把目录用于生产，应另约束端点标签、目录版本和先修环；本课不实现选课审批服务。

![[计算机知识/_labs/round3/DB/graph_path_semantics/paths.svg]]

图由同一 `spec.json` 和实际 `actual.json` 生成。`core` 仅 e1–e3；`parallel` 再加 e4；`branching` 再加 e5/e6；`typed` 含全部八边；`without_e3` 从 typed 删除 e3。z 在这些变式里都存在但无边。

可以把同一结构存为 `Node(id,label,title)` 和 `Edge(id,src,dst,type,catalog)` 两张关系表：`id` 是键，src/dst 是外键；长度为 2 的查询连接两份 Edge。属性图则把“节点—带身份的关系—节点”作为直接查询对象，查询文本可以返回整个路径。这里比较的是表示与接口：关系引擎也能用递归查询表示遍历；图接口的紧凑，不证明物理执行一定更快。

为什么不把所有先修嵌成 a 文档里的一棵树？b 被多个课程复用，a↔b 还会成环。递归展开成树必须截断或重复节点事实；修正 b→c 时，所有缓存树都要更新。存引用或图关系保留共享身份，却要支付遍历、索引和同版读取的成本。这与第13讲教师电话副本的维护问题相通，但本课的**返回对象是关联链**，不能只数取回几个文档。

## 路径查询先约定六件事

本实践每条查询明确：起点、终点、向外方向、关系类型 `REQUIRES`、**全部中间节点也必须是 Course**、长度区间与重复规则。不存在的查询端点被输入验证拒绝；存在但标签不符的端点没有候选路径。此处没有 UNKNOWN 分类。

写一条长度 h 的有向路径为

\[
p=(v_0,e_1,v_1,\ldots,e_h,v_h),\quad
\operatorname{src}(e_i)=v_{i-1},\quad \operatorname{dst}(e_i)=v_i.
\]

h 的单位是**关系条数**，不是学分、修课时间或物理距离；节点序列长度为 h+1。答案用有序 `edge_ids` 区分；节点序列相同而经过 e1 或 e4 的两条路径仍不同。要输出“涉及哪些先修课程”，再对终点做集合投影，不能提前将关系身份去掉后继续声称数的是路径。

| 本课规则 | 可以重复什么 | 不可以重复什么 |
| --- | --- | --- |
| walk，游走 | 节点与同一条关系都可重走 | 仍须满足端点、方向、类型与长度 |
| trail，关系不重复的路径 | 节点可重访 | 同一关系 id 不可再用 |
| simple，节点不重复的路径 | 不重复节点；因此也不会重用边 | 回到起点的正长度环也排除 |

有的教材把 path 专指 simple，有的数据库把 path 当节点和关系的序列。本课每次写出规则，不靠同一个汉字“路径”猜意思。**simple 的零长度路径**只含起点；起终点相同且区间含 0 时允许。正长度 a→b→a 则不是 simple。抵达目标并不总是搜索终点：walk 查询 a→a、1..4 时，第一次返回 a 后仍要继续找长度 4 的返回；只有长度界决定本求值器何时停止扩展。

实践返回两个分开的答案：`bounded` 按查询的 `[min_hops,max_hops]` 与规则枚举；`unbounded_bfs` 不使用这个长度界或规则，回答选定标签/类型子图上的可达与**全部最少边数路径**，起终点相同时包含长度 0。因而 a→c 的 `max_hops=1` 可得到有界空集，同时 BFS 可达且最短长度 2；不矛盾。若正长度从 a 回 a，不能用 BFS 的零长度答案替代。

## 在 a↔b→c 上逐条数，再改变一个条件

core 中 a→c、1..5：walk 有 `[e1,e3]` 和 `[e1,e2,e1,e3]` 两条。trail 只允许第一条，因为第二条重用 e1；simple 也只允许第一条，因为第二条重复 a、b。可达为 true；全局最短长度是 2，只有 `[e1,e3]`。

现在只加平行 e4。先预测，再对照完整答案：

- 长度 2：`[e1,e3]`、`[e4,e3]`。
- 长度 4：`[e1,e2,e1,e3]`、`[e1,e2,e4,e3]`、`[e4,e2,e1,e3]`、`[e4,e2,e4,e3]`。

walk 接受六条；trail 从长度4的四条中保留中间两条，共四条；simple 排除全部长度4，共两条。两个最短答案的节点序列都是 `[a,b,c]`，边身份仍不同。`RETURN DISTINCT node_ids` 会合并它们；那是改变输出投影后的结果，不是发现“之前算重了”。

| a→c、1..5 | walk | trail | simple | 全局最短长度／条数 |
| --- | ---: | ---: | ---: | --- |
| core | 2 | 1 | 1 | 2／1 |
| parallel | 6 | 4 | 2 | 2／2 |
| branching | 9 | 7 | 3 | 2／3 |
| typed | 9 | 7 | 3 | 2／3 |
| without_e3 | 3 | 3 | 1 | 2／1 |

typed 多出的 a→c 不是 REQUIRES，因此最短长度没有变成 1。without_e3 仍可沿 e5/e6 抵达 c，而非“删一条边就不可达”。c→a 和 a→z 在全部五变式中不可达：箭头的反向不是隐含边，孤点也不是不存在的节点。

若不限制 walk 的长度，core 的 `(e1,e2)^k,e1,e3` 对每个非负整数 k 都给出不同答案，集合无限。trail 在有限 m 条边上长度最多 m；simple 在 n 个节点上最多 n−1 条边（含零长度约定）。有限不等于小：分支图中路径数量仍可能随长度指数增长。把 `LIMIT 100` 放在结果后不构成“全部路径”认证，也不能保证引擎只扩展一百条候选。

## 把规格写成属性图查询

教学查询是可实际执行的 JSON；例如 `spec.json` 中这一条由求值器读入：

```json
{"id":"a_c_1_5_trail","source":"a","target":"c","direction":"out","type":"REQUIRES","node_label":"Course","min_hops":1,"max_hops":5,"rule":"trail"}
```

对应的 **Neo4j 5.26 传统变长关系语法接口**如下。这里只给文档核对和待验查询；实际运行记录属于前面的本地模型。固定输入全部属于T1；JSON教学求值器没有一般catalog谓词，下面Cypher显式过滤T1。若修改目录属性，不能继续声称这两个查询仍等价。

```cypher
MATCH p=(a:Course {id:'a'})-[:REQUIRES*1..5]->(c:Course {id:'c'})
WHERE all(n IN nodes(p) WHERE n:Course)
  AND all(r IN relationships(p) WHERE r.catalog='T1')
RETURN [n IN nodes(p) | n.id] AS node_ids,
       [r IN relationships(p) | r.id] AS edge_ids
ORDER BY size(edge_ids), edge_ids;
```

默认同一匹配结果不再次遍历同一关系，但可重访节点，故这里对应 trail，而不是无限 walk 或 simple。[Neo4j 官方关系唯一性规则](https://neo4j.com/docs/cypher-manual/5/patterns/unique-relationship-paths/) 明确区分这两点。文档链接目前也展示较新的语法；本课接口没有使用 Cypher 25 的 `REPEATABLE ELEMENTS` 或 `ACYCLIC`。不能给 Neo4j 5.26 发新版本关键词，再用本地模型的成功替它通过验收。

要进一步限制 simple，在候选条件中增加：

```cypher
AND all(n IN nodes(p) WHERE single(m IN nodes(p) WHERE m=n))
```

要从**已经按标签、类型、目录过滤的候选**取全部最少边数结果，把原 RETURN 换为：

```cypher
WITH collect(p) AS candidates, min(length(p)) AS hops
UNWIND [p IN candidates WHERE length(p)=hops] AS p
RETURN hops,[r IN relationships(p) | r.id] AS edge_ids ORDER BY edge_ids;
```

这是有界候选全收集后的清楚写法，可能很费内存，不是优化建议。若先挑最短路径再在外面排除错误中间节点，可能将最短非法链丢掉，却没有继续找较长合法链。专门 shortest 操作符怎样将谓词纳入搜索，必须查具体版本计划；不能将“先过滤候选”和“找最短后过滤”交换。官方[变长路径及谓词](https://neo4j.com/docs/cypher-manual/5/patterns/variable-length-paths/)也强调类型、节点与属性条件对候选扩展的作用。本课最小化 hops；边属性若改成时间或费用，BFS 不能直接最小化加权总和，回 [[计算机知识/50-数据结构与算法/24-图算法网络流匹配与残量网络#三种“连接最好”解决不同目标|最短路的目标与权重条件]] 重新选算法。

待验的完整建图与三组查询放在 [[计算机知识/_labs/round3/DB/graph_path_semantics/README#真实图引擎的未验接口|真实引擎接口]]。预期 typed 得 trail7、simple3、最短2跳共3条；这是待验断言，不是 Neo4j 运行结果。

## 为什么全局 visited 会漏路径

BFS 逐层发现节点。单位边长下，首次发现 v 的层号就是最短距离；以后再用更长前缀抵达 v，不会改善这个距离，所以“v 已发现”可阻止重复入队。但不同前缀可能是不同的合法路径：parallel 中从 a 沿 e1 与 e4 都到 b，若只保存第一条到达边，第二条最短路径已经丢失。

本求值器的 BFS 将每个节点只入队一次，**仍保存所有满足 `dist(u)+1=dist(v)` 的前驱关系**。从目标反向展开这个前驱结构可取回全部同长最短路径；距离每次减少1，所以回溯不会进入环。BFS 的“节点只入队一次”不等于“每个节点只允许一个前驱”。全部最短路径的数量仍可能很大，输出成本不能从 O(n+m) 的距离计算中消失。

枚举器则给每个候选保留自己的节点序列与边序列：walk 不加唯一性条件，trail 查本前缀的关系，simple 查本前缀的节点。其不变量是：**栈中每个前缀都从指定起点开始、按方向连接、满足类型/标签和所选重复规则，长度不超过 L；每个合法前缀恰有一条对应生成链。**

归纳检查：初始空边序列满足条件；扩展只接当前末节点的合法出边，先查本路径的重复限制，因此不产生非法前缀。反过来，任一合法 h+1 长路径去掉末边后仍是合法 h 长前缀；归纳假设保证前缀已生成，该末边必被扫描且不被合法性检查误删，因此完整路径也生成。边 id 唯一使不同生成链不会给出同一边序列。每次长度增加1、到 L 停止，有限图上必终止。**匹配目标只负责输出，不提前截断扩展**，所以目标重访不漏。

独立批量 oracle 不调用上述枚举器或 BFS：它从原始边集取有限笛卡尔积，再检查连接、标签和重复规则；全局最短用至多 n−1 条边的 simple 候选重算，因为任何最短正权 walk 若重复节点，都能删去一个正长度环变短。作者 oracle 与求值器逐查询比较全部路径身份、最短集合和访问计数；另有非作者的 SQLite 逐层连接与集合固定点复核，不能只在末尾比较一个 count。

## 索引减少哪些工作，又没有减少哪些工作

先定位 `Course{id:'a'}`，再扩展 a 的 REQUIRES 出边，是两项不同的访问。节点 id 索引帮助起点定位，不直接把多跳答案提前存好。邻接结构或 `(src,type)` 索引帮助取得一跳候选；反向查询需要相应入边组织或 dst 访问路径。稠密热点 b 仍可能有很多邻边，返回全部路径仍受组合数量限制。Neo4j 的[索引与实际计划](https://neo4j.com/docs/cypher-manual/5/indexes/performance-indexes/using-indexes/)示例展示起点扫描如何被索引定位替换；具体库会选什么计划，必须实际 EXPLAIN/PROFILE，不能从图画了箭头推断。

本地模型作一次**可复算的逻辑计数**。设 P 是长度小于 L、实际要扩展的合法前缀集合，m 是该变式全部边数，d(v) 是按标签和类型过滤后的出度。每前缀全扫边集需 `m|P|` 次边记录检查；预建邻接表需 `Σ[p∈P]d(last(p))` 次。即使前缀已抵达目标或末节点无出边，只要长度未到 L，仍计一次扩展；邻接为空时记录检查为0。

| typed、a→c、1..5 | 前缀扩展 | 全扫边记录检查 | 邻接边记录检查 | 完整输出条数 |
| --- | ---: | ---: | ---: | ---: |
| walk | 25 | 200 | 36 | 9 |
| trail | 17 | 136 | 20 | 7 |
| simple | 7 | 56 | 8 | 3 |

这是同一求值顺序下候选访问差异，不是 SQLite VM 步数、Neo4j DB hits、CPU 时间或磁盘 I/O；没有把36比200称为5.6倍加速。计数不含 O(m) 的邻接构建、字符串/集合比较、路径复制和最终排序；求值器存完整答案，内存至少随输出总长度增长。只做一次很短查询时，预构建成本也许不值；长期反复查同一图，建立并维护访问结构才可能摊薄成本。改边还必须更新邻接结构，旧缓存不能与新边表混用。

SQLite 实际查询 `WHERE src=? AND type=? ORDER BY id` 在本机无该复合索引时显示 `SCAN edge USING INDEX sqlite_autoindex_edge_1`；添加 `edge_src_type(src,type)` 后显示 `SEARCH edge USING INDEX edge_src_type (src=? AND type=?)`，另有 ORDER BY 临时 B-tree，结果同为 e1/e4/e5。没有复合索引时也可能利用主键索引扫描顺序，不能省略 `USING INDEX` 就说“完全没用任何索引”。[SQLite EXPLAIN 文档](https://www.sqlite.org/eqp.html)解释 SCAN/SEARCH；具体文字和节点数字可能随版本变化，不作跨版本测试合同。这次没有测两个方案的延迟。

## 约束与一致性不能由连线代办

教学求值器加载时拒绝重复节点 id、重复关系 id、悬空端点和越界查询。平行边端点相同但 id 不同，按模型允许；是否应增加 `(src,dst,type,catalog)` 唯一性，要由“同一先修允许多条审核依据”还是“先修是集合”决定。把 e4 删掉能减少计数，但若它表示独立证据，删除也是丢事实。无环性更是跨关系约束，单边有外键不会阻止 a↔b。

实际 SQLite 表启用 `PRAGMA foreign_keys=ON`，节点/关系 id 都 `PRIMARY KEY NOT NULL`，端点 `NOT NULL REFERENCES node(id)`，类型有 CHECK。五个故意错误分别触发主键、主键、外键、非空与 CHECK 失败；每次0行变化，原6节点8边保留。另一次事务先插 `transient` 再撞重复 e1，明确 ROLLBACK 后 transient 不在库中。平行 e1/e4 仍同时存在。外键启用条件来自 [SQLite 官方外键说明](https://www.sqlite.org/foreignkeys.html)；这是真实 SQLite 约束，不是 Neo4j 导入失败记录。

Neo4j 属性唯一性也不能顺手说成“该属性必填”：官方[唯一性与存在性约束](https://neo4j.com/docs/cypher-manual/current/schema/constraints/create-constraints/)分别定义两者，缺属性不自动违反属性唯一性；版本、版本系列和版本许可条件仍需核对。给 Course.id 声明唯一，并不保证每个节点都有这个属性，更不保证先修图无环。

再看一致读取。某应用逐跳发两个请求，第一次读到 e1:a→b；写者随后在**同一事务**删除 e1 并插入 e3:b→c；第二次应用读 b 的邻接得到 e3。它拼出 a→b→c，但提交前只有 e1、提交后只有 e3，两个完整版本都没有 a→c 路径。

| 受控步骤 | 未固定同版的应用观察 | 固定读事务的观察 |
| --- | --- | --- |
| 版本 V0 仅有 e1 | 首跳 `[e1]` | BEGIN 后首次 SELECT 得 `[e1]` |
| 写者 COMMIT V1：删 e1、添 e3 | 两次读之间发生版本变化 | 同一个读事务仍见 `[e1]` |
| 再读邻接／全边 | 次跳 `[e3]`，拼出假链 | COMMIT 结束旧读事务；新读见 `[e3]` |

这个结果由两个真实本地 SQLite 连接在 WAL 模式下按顺序交错得到，`synchronous=FULL` 明确设置；不是线程压力测试，也没有进程 kill、断电或 Neo4j 隔离实验。它证明本地这个读取协议能观察到什么，不能据此承诺另一个引擎“一次图查询一定是同一快照”。迁移到真实图引擎要另验事务隔离、跨请求书签/会话因果、复制读取和更新冲突。已有 [[计算机知识/55-数据库/10-系统课程/18-源位置状态快照与目标恢复|恢复课]]处理提交与重启；本课不复制那个协议，也不把固定快照当成已经实现恢复。

```python
"""Finite directed property-graph teaching evaluator, not a database server."""
import argparse
from collections import defaultdict, deque
import json
from pathlib import Path


def validate(spec):
    nodes, edges = spec['nodes'], spec['edges']
    if len(nodes)>20 or len(edges)>12:
        raise ValueError('fixture_limit')
    ids=[n['id'] for n in nodes]
    if len(set(ids))!=len(ids) or any(not isinstance(i,str) or not i for i in ids):
        raise ValueError('node_identity')
    eids=[e['id'] for e in edges]
    if len(set(eids))!=len(eids) or any(not isinstance(i,str) or not i for i in eids):
        raise ValueError('edge_identity')
    if any(e['src'] not in ids or e['dst'] not in ids for e in edges):
        raise ValueError('dangling_endpoint')
    for v in spec['variants']:
        if len(v['edge_ids'])!=len(set(v['edge_ids'])) or not set(v['edge_ids'])<=set(eids):
            raise ValueError('variant_edges')
    for q in spec['queries']:
        if q['source'] not in ids or q['target'] not in ids:
            raise ValueError('query_endpoint')
        if q['direction']!='out' or q['rule'] not in ('walk','trail','simple'):
            raise ValueError('unsupported_query')
        if type(q['min_hops']) is not int or type(q['max_hops']) is not int or not 0<=q['min_hops']<=q['max_hops']<=5:
            raise ValueError('query_length')


def ordered(paths):
    return sorted(paths,key=lambda p:(len(p['edge_ids']),p['edge_ids'],p['node_ids']))


def enumerate_paths(spec, edges, q, access):
    allowed={n['id'] for n in spec['nodes'] if n['label']==q['node_label']}
    adj=defaultdict(list)
    for e in edges:
        if e['type']==q['type'] and e['src'] in allowed and e['dst'] in allowed:
            adj[e['src']].append(e)
    stack=[([q['source']],[])] if q['source'] in allowed and q['target'] in allowed else []
    result=[]
    checks=expanded=0
    while stack:
        ns, es=stack.pop()
        depth=len(es)
        if q['min_hops']<=depth and ns[-1]==q['target']:
            result.append({'node_ids':ns,'edge_ids':es})
        # A target match does not terminate expansion: later visits also count.
        if depth==q['max_hops']:
            continue
        expanded+=1
        candidates=edges if access=='scan' else adj[ns[-1]]
        for e in candidates:
            checks+=1
            if e['src']!=ns[-1] or e['type']!=q['type'] or e['dst'] not in allowed:
                continue
            if q['rule']=='trail' and e['id'] in es:
                continue
            if q['rule']=='simple' and e['dst'] in ns:
                continue
            stack.append((ns+[e['dst']],es+[e['id']]))
    result=ordered(result)
    minimum=len(result[0]['edge_ids']) if result else None
    return {'paths':result,'path_count':len(result),'shortest_within_bounds':minimum,
            'all_shortest_within_bounds':[p for p in result if len(p['edge_ids'])==minimum],
            'cost':{'expanded_prefixes':expanded,'edge_records_tested':checks}}


def breadth_first(spec, edges, q):
    """Unbounded reachability and all shortest edge-distinct paths, zero included."""
    allowed={n['id'] for n in spec['nodes'] if n['label']==q['node_label']}
    if q['source'] not in allowed or q['target'] not in allowed:
        return {'reachable':False,'distance':None,'paths':[]}
    adj=defaultdict(list)
    for e in edges:
        if e['type']==q['type'] and e['src'] in allowed and e['dst'] in allowed:
            adj[e['src']].append(e)
    dist={q['source']:0}
    pred=defaultdict(list)
    queue=deque([q['source']])
    while queue:
        n=queue.popleft()
        for e in adj[n]:
            d=dist[n]+1
            if e['dst'] not in dist:
                dist[e['dst']]=d
                queue.append(e['dst'])
            if dist[e['dst']]==d:
                pred[e['dst']].append(e)
    def build(n):
        if n==q['source']:
            return [{'node_ids':[n],'edge_ids':[]}]
        return [{'node_ids':p['node_ids']+[n],'edge_ids':p['edge_ids']+[e['id']]}
                for e in pred[n] for p in build(e['src'])]
    reachable=q['target'] in dist
    return {'reachable':reachable,'distance':dist.get(q['target']),
            'paths':ordered(build(q['target'])) if reachable else []}


def run(spec):
    validate(spec)
    outputs=[]
    for variant in spec['variants']:
        edges=[e for e in spec['edges'] if e['id'] in variant['edge_ids']]
        queries=[]
        for q in spec['queries']:
            indexed=enumerate_paths(spec,edges,q,'adjacency')
            scan=enumerate_paths(spec,edges,q,'scan')
            assert {k:v for k,v in indexed.items() if k!='cost'}=={k:v for k,v in scan.items() if k!='cost'}
            queries.append({'query_id':q['id'],'bounded':{k:v for k,v in indexed.items() if k!='cost'},
                            'cost':{'adjacency':indexed['cost'],'scan':scan['cost']},
                            'unbounded_bfs':breadth_first(spec,edges,q)})
        outputs.append({'variant':variant['id'],'edge_count':len(edges),'queries':queries})
    return {'input_version':spec['input_version'],'layer':'finite local property-graph model',
            'variants':outputs}


def main():
    p=argparse.ArgumentParser(); p.add_argument('--spec',type=Path,required=True); p.add_argument('--out',type=Path,required=True)
    a=p.parse_args(); result=run(json.loads(a.spec.read_text()))
    a.out.write_text(json.dumps(result,ensure_ascii=True,indent=2)+'\n')
    print(json.dumps({'variants':len(result['variants']),'queries':sum(len(v['queries']) for v in result['variants'])}))
if __name__=='__main__': main()
```

```python
"""Independent exhaustive raw-edge products; does not import graph_model."""
import argparse
import itertools
import json
from pathlib import Path


def sequences(spec, edges, q, low, high, rule):
    allowed={n['id'] for n in spec['nodes'] if n['label']==q['node_label']}
    answer=[]
    if q['source'] not in allowed or q['target'] not in allowed:
        return answer
    for length in range(low,high+1):
        for seq in itertools.product(edges,repeat=length):
            ns=[q['source']]; es=[]
            for e in seq:
                if e['src']!=ns[-1] or e['type']!=q['type'] or e['dst'] not in allowed:
                    break
                ns.append(e['dst']); es.append(e['id'])
            else:
                if rule=='trail' and len(set(es))!=len(es): continue
                if rule=='simple' and len(set(ns))!=len(ns): continue
                answer.append({'node_ids':ns,'edge_ids':es})
    return answer


def check(spec, actual):
    count=0
    for variant, observed in zip(spec['variants'],actual['variants'],strict=True):
        assert variant['id']==observed['variant']
        edges=[e for e in spec['edges'] if e['id'] in variant['edge_ids']]
        assert len(edges)==observed['edge_count']
        for q,row in zip(spec['queries'],observed['queries'],strict=True):
            assert row['query_id']==q['id']
            all_prefixes=sequences(spec,edges,q,0,q['max_hops'],q['rule'])
            paths=[p for p in all_prefixes if len(p['edge_ids'])>=q['min_hops'] and p['node_ids'][-1]==q['target']]
            paths.sort(key=lambda p:(len(p['edge_ids']),p['edge_ids'],p['node_ids']))
            minimum=len(paths[0]['edge_ids']) if paths else None
            assert row['bounded']=={'paths':paths,'path_count':len(paths),'shortest_within_bounds':minimum,
                                   'all_shortest_within_bounds':[p for p in paths if len(p['edge_ids'])==minimum]}
            prefixes=[p for p in all_prefixes if len(p['edge_ids'])<q['max_hops']]
            eligible={n['id'] for n in spec['nodes'] if n['label']==q['node_label']}
            degree={n:sum(e['src']==n and e['dst'] in eligible and e['type']==q['type'] for e in edges) for n in eligible}
            assert row['cost']=={'adjacency':{'expanded_prefixes':len(prefixes),'edge_records_tested':sum(degree[p['node_ids'][-1]] for p in prefixes)},
                                 'scan':{'expanded_prefixes':len(prefixes),'edge_records_tested':len(prefixes)*len(edges)}}
            # Any minimum-hop walk has a node-simple witness (cycle removal).
            limit=sum(n['label']==q['node_label'] for n in spec['nodes'])-1
            simple=sequences(spec,edges,q,0,limit,'simple')
            target=[p for p in simple if p['node_ids'][-1]==q['target']]
            target.sort(key=lambda p:(len(p['edge_ids']),p['edge_ids'],p['node_ids']))
            d=len(target[0]['edge_ids']) if target else None
            assert row['unbounded_bfs']=={'reachable':bool(target),'distance':d,'paths':[p for p in target if len(p['edge_ids'])==d]}
            count+=1
    return {'status':'PASS','input_version':spec['input_version'],'queries_checked':count,
            'method':'all raw edge products, post-filter connectivity/type/labels/uniqueness; cycle removal for global shortest'}


def main():
    p=argparse.ArgumentParser(); p.add_argument('--spec',type=Path,required=True); p.add_argument('--actual',type=Path,required=True); p.add_argument('--out',type=Path,required=True)
    a=p.parse_args(); r=check(json.loads(a.spec.read_text()),json.loads(a.actual.read_text()))
    a.out.write_text(json.dumps(r,indent=2)+'\n'); print(json.dumps(r))
if __name__=='__main__': main()
```

```python
"""Real SQLite integrity/index/snapshot probes; not Neo4j execution."""
import argparse
import json
from pathlib import Path
import sqlite3

SCHEMA='''
PRAGMA foreign_keys=ON;
CREATE TABLE node(id TEXT PRIMARY KEY NOT NULL, label TEXT NOT NULL, title TEXT NOT NULL);
CREATE TABLE edge(id TEXT PRIMARY KEY NOT NULL, src TEXT NOT NULL REFERENCES node(id), dst TEXT NOT NULL REFERENCES node(id), type TEXT NOT NULL CHECK(type IN ('REQUIRES','TEACHES')), catalog TEXT NOT NULL);
'''


def run(spec, path):
    if path.exists(): raise FileExistsError('use a fresh database path')
    db=sqlite3.connect(path,isolation_level=None)
    try:
        assert db.execute('PRAGMA journal_mode=WAL').fetchone()[0]=='wal'
        db.execute('PRAGMA synchronous=FULL')
        db.executescript(SCHEMA)
        db.execute('BEGIN')
        db.executemany('INSERT INTO node VALUES(:id,:label,:title)',spec['nodes'])
        db.executemany('INSERT INTO edge VALUES(:id,:src,:dst,:type,:catalog)',spec['edges'])
        db.execute('COMMIT')
        failures=[]
        probes=[('duplicate_node','INSERT INTO node VALUES(?,?,?)',('a','Course','dup')),
                ('duplicate_edge','INSERT INTO edge VALUES(?,?,?,?,?)',('e1','a','c','REQUIRES','T1')),
                ('missing_endpoint','INSERT INTO edge VALUES(?,?,?,?,?)',('bad','a','absent','REQUIRES','T1')),
                ('null_endpoint','INSERT INTO edge VALUES(?,?,?,?,?)',('bad','a',None,'REQUIRES','T1')),
                ('unknown_type','INSERT INTO edge VALUES(?,?,?,?,?)',('bad','a','c','UNKNOWN','T1'))]
        for name,sql,args in probes:
            before=db.total_changes
            try: db.execute(sql,args)
            except sqlite3.IntegrityError as error:
                failures.append({'probe':name,'error_name':error.sqlite_errorname,'message':str(error),'rows_changed':db.total_changes-before})
            else: raise AssertionError(name)
        query='SELECT id FROM edge WHERE src=? AND type=? ORDER BY id'
        before_plan=[list(r) for r in db.execute('EXPLAIN QUERY PLAN '+query,('a','REQUIRES'))]
        rows_before=[r[0] for r in db.execute(query,('a','REQUIRES'))]
        db.execute('CREATE INDEX edge_src_type ON edge(src,type)')
        after_plan=[list(r) for r in db.execute('EXPLAIN QUERY PLAN '+query,('a','REQUIRES'))]
        rows_after=[r[0] for r in db.execute(query,('a','REQUIRES'))]
        assert rows_before==rows_after==['e1','e4','e5']
        # A whole finite import is one actual transaction. A later failure undoes the earlier insert.
        db.execute('BEGIN')
        db.execute("INSERT INTO edge VALUES('transient','c','a','REQUIRES','T1')")
        try: db.execute("INSERT INTO edge VALUES('e1','a','c','REQUIRES','T1')")
        except sqlite3.IntegrityError: db.execute('ROLLBACK')
        assert not db.execute("SELECT 1 FROM edge WHERE id='transient'").fetchall()
        constraint_state={'node_count':db.execute('SELECT count(*) FROM node').fetchone()[0],
                          'edge_count':db.execute('SELECT count(*) FROM edge').fetchone()[0],
                          'foreign_key_check':list(db.execute('PRAGMA foreign_key_check')),
                          'parallel_ids':[r[0] for r in db.execute("SELECT id FROM edge WHERE src='a' AND dst='b' ORDER BY id")],
                          'rolled_back_transient':True}
        # Two real connections: unpinned multi-statement traversal can mix revisions.
        db.execute('BEGIN'); db.execute('DELETE FROM edge');
        e1=next(e for e in spec['edges'] if e['id']=='e1'); e3=next(e for e in spec['edges'] if e['id']=='e3')
        db.execute('INSERT INTO edge VALUES(:id,:src,:dst,:type,:catalog)',e1); db.execute('COMMIT')
        reader=sqlite3.connect(path,isolation_level=None)
        try:
            reader.execute('PRAGMA foreign_keys=ON')
            first=[r[0] for r in reader.execute(query,('a','REQUIRES'))]
            reader.execute('BEGIN')
            pinned_before=[r[0] for r in reader.execute('SELECT id FROM edge ORDER BY id')]
            db.execute('BEGIN'); db.execute('DELETE FROM edge'); db.execute('INSERT INTO edge VALUES(:id,:src,:dst,:type,:catalog)',e3); db.execute('COMMIT')
```
