# 正交、透视投影、齐次裁剪与视口

## 从相机空间到裁剪空间

正交相机保持同一 XY 位置的投影不随深度变化。对对称视箱 x∈[−r,r]、y∈[−t,t]、view z∈[−f,−n]，P_ortho=diag(1/r,1/t,−2/(f−n),1)，另加 z 平移 −(f+n)/(f−n)。于是近 z=−n 映到 −1，远 z=−f 映到 +1，w 恒为 1。

透视相机从相机原点发射射线。与距离为 1 的参考像平面相交给 x/(-z)、y/(-z)。设 s=cot(θ/2)，宽高比 a=W/H，本链列向量矩阵是

$$P=\begin{bmatrix}s/a&0&0&0\\0&s&0&0\\0&0&-(f+n)/(f-n)&-2fn/(f-n)\\0&0&-1&0\end{bmatrix}.$$

w_clip=−z_view；在 n=1,f=9,θ=90°,a=1 时，第三行 (0,0,−1.25,−2.25)。第一课 B 的 z=−4，所以 z_clip=5−2.25=2.75，w=4，z_NDC=.6875；A 的 z=−2 得 .25/2=.125。距离缩放为两倍的 B 与 A 投影大小可以相同，这就是近大远小。正交箱若 r=t=2，则同一 A/B/C 映到 xy_NDC=(−.5,−.5)/(1,−1)/(0,.5)，与透视结果不同。

## 在透视除法以前裁剪

对 q=(x,y,z,w)，内部由六个线性有符号值决定：x+w、w−x、y+w、w−y、z+w、w−z 都非负。边从 q₀ 到 q₁，某平面值 d₀≥0,d₁<0 时交点参数 t=d₀/(d₀−d₁)，q(t)=(1−t)q₀+tq₁。颜色和未归一化法线等原属性也按同一 t 插值；不能先插 a/w 再按 t 当成原属性。逐平面对凸多边形做进/出裁剪，再扇形三角化即可；相邻边交点必须用一致输入，浮点实现的极端缝隙另属精度问题。

例题：把 A 改为 view (−.25,−.25,−.5)，C 保持 (0,1,−2)。A 的近面值 z_clip+w=−1.625+.5=−1.125，C 的值 .25+2=2.25；从 A 向 C 的 t=1/3。交点 view=(−1/6,1/6,−1)，clip=(−1/6,1/6,−1,1)，是合法近平面点。若 A 为红、C 为蓝，交点颜色 (2/3,0,1/3)。不能因为 A 在近面外就丢掉整片三角形，否则本来可见的部分也丢了。

失败例：view z=0 时 w=0，除法未定义；相机背后 z>0 时 w<0，直接除法可能产生“看似落在屏幕”的点。先用齐次六平面裁剪，标准本链矩阵的存活点距离至少 n>0，所以 w>0；不是给 w 加一个小 epsilon 来伪造位置。

齐次除法的数学对象见 [[数学/25-高等代数/60-交换代数与代数几何/06-齐次坐标射影闭包与无穷远#齐次点与仿射图：除法有明确区域|射影类与非零坐标图]]；[[数学/25-高等代数/60-交换代数与代数几何/06-齐次坐标射影闭包与无穷远#坐标图不等于有效相机观测|相机代表的反例]] 用 $(0,0,0,1)$ 与 $(0,0,0,-1)$ 说明同一射影类和相同除法读数可以有不同裁剪结果。数学闭包新增无穷远点不等于相机可见性，也不恢复沿射线丢失的深度；返读本节保留矩阵选定的代表、六半空间及近平面合同。

## 从 NDC 到离散像素中心

之后 NDC=clip.xyz/w，视口 x=(x_NDC+1)W/2，y=(1−y_NDC)H/2；+1 边映到 W 或 H，这是图像边界，不是有效像素索引。像素中心落在 [0,W)×[0,H)。

练习：view 点 (0,0,−1)、(0,0,−9)、(0,0,−.5) 的 z_NDC？答案 −1、1、−3.25；最后一点在近面外。若改用 z∈[0,w] 的 API 约定，能只改裁剪判据吗？不能；P 的 z 行、NDC 深度映射和测试必须一起变更。[Khronos OpenGL 4.6 §§13.7–13.8](https://registry.khronos.org/OpenGL/specs/gl/glspec46.core.pdf) 明确存在不同 clip-control 深度模式，本页固定其中一种。
