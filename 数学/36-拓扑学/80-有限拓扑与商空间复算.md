# 有限拓扑与商空间复算

## 逐个原像，比猜图可靠

本实验只处理有限点集上的精确集合运算。没有浮点近似，没有通过采样估计开集；它不能判断无限空间的序列紧性、任意积紧致或圆周基本群。理论结论仍由正文证明承担。源码 [topology_lab.py](./topology_lab.py) 是真源，测试 [test_topology_lab.py](./test_topology_lab.py) 与本页镜像一起保存。

固定源 $X=\{a,b,c\}$、开集 $\varnothing,\{a\},\{a,b\},X$，令 $q(a)=q(c)=A,q(b)=B$。商的四个候选子集 $\varnothing,\{A\},\{B\},\{A,B\}$ 的原像依次是 $\varnothing,\{a,c\},\{b\},X$。所以商只有空集和全集开，连通但非Hausdorff。源开集 $\{a\}$ 的像 $\{A\}$ 不开；反例揭示“连续”“商”“开映射”是不同要求。改变识别为 $a\sim b$ 后商出现开单点，见下方练习。

从库根运行，不需安装依赖：

.venv/bin/python -B -m unittest discover -s 数学/36-拓扑学 -p 'test_topology_lab.py' -v

计数分别对应0、1、2、3个**有标号**点；同胚类型计数不是这个数字。空空间只有唯一拓扑 $\{\varnothing\}$，此处按通常定义同时连通、Hausdorff且紧致。

## 为什么算法只查两两并与交

一般拓扑需要任意并。有限点集只有有限多个不同子集，所以任意开集族去重后只是有限族。含空集、全集，再对两两并与交封闭，由归纳便对有限并交封闭，进而对任意并封闭。这个理由依赖有限点集，不能在无限空间的输入中仅查两两并。

`continuous` 检查每个目标开集的原像；`quotient` 检查满射后枚举目标全部子集，并保留开原像对应者；`minimum_neighborhood` 取包含某点的全部开集之交，因为在有限拓扑中交只有有限项，所以仍开。`connected` 寻找非空真且既开又闭（clopen）的子集，`hausdorff` 逐对检查不交邻域。每个有限空间紧致，无论是否Hausdorff；选择覆盖中的至多一成员每点便给有限子覆盖。

点标签只支持字符串或整数，排除布尔值；输入缺点、重复点、越界集合、漏空集/全集、不封闭的开集族、非满射商、NaN/Inf标签均拒绝。一般集合输入最多8点；全拓扑族枚举仅支持最多3点。8点的幂集有256项，而直接枚举所有集合族有 $2^{256}$ 项，所以不能把一般幂集上限误读成全拓扑枚举上限。实验没有近似误差或迭代不收敛问题；超过范围会显式报错。

## 独立核对与图的生成

测试用另一种数学模型作oracle：枚举所有反身、传递关系（预序），再找相应向上封闭集，得到有限拓扑。其与原算法的“枚举集合族并查并交”不同。对应理由如下：有限拓扑中令 $x\preceq y$ 当 $y$ 属于每个含 $x$ 的开集；这是预序，每个开集向上封闭。反过来，最小邻域 $U_x$ 由所有含 $x$ 的开集之交形成，任何向上封闭集 $V$ 满足 $V=\bigcup_{x\in V}U_x$，所以开。这说明两种枚举为何应得相同集合族。

连续性再用局部邻域条件检查全部两点函数；商用“饱和源开集取像”独立核对，并穷举三点源到两点商及商再映到两种两点目标，核对 $g$ 连续当且仅当 $gq$ 连续。它验证的是有限实例，不声称穷举证明一般泛性质。其他测试检查子空间最小邻域、三点Hausdorff等价离散、所有有限覆盖的至多三成员子覆盖、空空间及非法输入。

三张图由同一源码的固定坐标/公式生成：商圆使用 $e^{2\pi it}$、方形识别箭头使用 $(0,v)\sim(1,v)$ 或 $(1,1-v)$、提升图使用 $\theta(t)=2t$。可在希望保存图的目录运行：

```bash
.venv/bin/python -B 数学/36-拓扑学/topology_lab.py --figures /tmp/topology-figures
```

生成器固定SVG坐标、显式白底、UTF-8及LF行尾，无时间metadata、无随机ID，重复生成字节一致。图中坐标均为无量纲；提升纵轴是圈数。图显示识别方向与标准路径，不能代替商拓扑、Hausdorff或绕数不变性的证明。

## 练习与完整答案

**题1。** 将 `demo` 中的映射改为 $q(a)=q(b)=A,q(c)=C$，手算商开集，再运行比较。

> [!question]- 解答
> 原像分别为 $\varnothing,\{a,b\},\{c\},X$，所以商开集是 $\varnothing,\{A\},\{A,C\}$。仍连通，因没有非平凡clopen；仍非Hausdorff，因含 $C$ 的唯一开邻域是全集。全部源开集的像此时都开，所以此商投影是开映射。与原例比较能看出“商投影必开”为假。

**题2。** 到两点目标 $S=\{0,1\}$、开集 $\varnothing,\{1\},S$ 的八个函数中，为什么恰好四个连续？

> [!question]- 解答
> 只需 $f^{-1}(\{1\})$ 是源开集。八个函数分别对应源的八个子集，四个开集恰好给四个连续函数。可以用 `product([0,1], repeat=3)` 枚举值，再用 `continuous` 检查；这是对01题1的精确复算。

**题3。** 能否把三点链拓扑解释为实平面中三个点的通常子空间拓扑？

> [!question]- 解答
> 不能。任意有限个不同Euclid点可以逐点用小球避开其余点，所以子空间离散且Hausdorff；三点链拓扑不离散、不Hausdorff。画在平面中只是标签的展示，不改变所规定的开集。

"""Exact finite examples, not a solver for infinite-space topology.

Labels are strings or integers (excluding bool); at most eight points.
The optional SVG output uses fixed sets/parameters and has no time metadata.
"""
from dataclasses import dataclass
from itertools import combinations
from pathlib import Path
import argparse
import json
import math


def labels(values):
    if isinstance(values, (str, bytes)):
        raise ValueError('supply an iterable of labels, not one string')
    try:
        result = tuple(values)
    except TypeError as exc:
        raise ValueError('labels must be iterable') from exc
    if any(type(x) not in (str, int) for x in result):
        raise ValueError('labels must be strings or integers, excluding bool')
    if len(result) != len(set(result)):
        raise ValueError('labels must be distinct')
    if len(result) > 8:
        raise ValueError('exact powersets are limited to eight points')
    return result


def powerset(values):
    xs = labels(values)
    return tuple(frozenset(c) for k in range(len(xs) + 1)
                 for c in combinations(xs, k))


@dataclass(frozen=True)
class FiniteTopology:
    points: frozenset
    opens: frozenset

    def __post_init__(self):
        points = frozenset(labels(self.points))
        try:
            raw = tuple(self.opens)
            opens = frozenset(frozenset(labels(u)) for u in raw)
        except TypeError as exc:
            raise ValueError('opens must be an iterable of subsets') from exc
        if any(not u <= points for u in opens):
            raise ValueError('an open set contains a point outside the space')
        if frozenset() not in opens or points not in opens:
            raise ValueError('empty set and whole space must be open')
        if any(u | v not in opens or u & v not in opens
               for u in opens for v in opens):
            raise ValueError('opens are not closed under pairwise union/intersection')
        object.__setattr__(self, 'points', points)
        object.__setattr__(self, 'opens', opens)

    def subspace(self, subset):
        subset = frozenset(labels(subset))
        if not subset <= self.points:
            raise ValueError('subspace must be contained in the source')
        return FiniteTopology(subset, {u & subset for u in self.opens})

    def minimum_neighborhood(self, point):
        if type(point) not in (str, int) or point not in self.points:
            raise ValueError('point is outside the space')
        result = self.points
        for u in self.opens:
            if point in u:
                result = result & u
        return result

    def hausdorff(self):
        return all(any(x in u and y in v and not u & v
                       for u in self.opens for v in self.opens)
                   for x in self.points for y in self.points if x != y)

    def connected(self):
        return not any(u and u != self.points and self.points - u in self.opens
                       for u in self.opens)


def validate_map(source, target_points, mapping):
    if not isinstance(mapping, dict) or set(mapping) != source.points:
        raise ValueError('map must specify exactly every source point')
    if any(type(y) not in (str, int) or y not in target_points
           for y in mapping.values()):
        raise ValueError('map value is outside the declared target')


def continuous(source, target, mapping):
    validate_map(source, target.points, mapping)
    return all(frozenset(x for x in source.points if mapping[x] in u)
               in source.opens for u in target.opens)


def quotient(source, target_points, mapping):
    target_points = frozenset(labels(target_points))
    validate_map(source, target_points, mapping)
    if set(mapping.values()) != target_points:
        raise ValueError('quotient map must be surjective')
    opens = {u for u in powerset(target_points)
             if frozenset(x for x in source.points if mapping[x] in u)
             in source.opens}
    return FiniteTopology(target_points, opens)


def all_topologies(points):
    points = labels(points)
    if len(points) > 3:
        raise ValueError('all topology families are limited to three points')
    subsets = powerset(points)
    optional = tuple(u for u in subsets if u and u != frozenset(points))
    # Here we enumerate families of subsets, not labels. Avoid the label API.
    for mask in range(1 << len(optional)):
        family = {frozenset(), frozenset(points)}
        family.update(u for i, u in enumerate(optional) if mask & (1 << i))
        try:
            yield FiniteTopology(frozenset(points), family)
        except ValueError:
            continue

def demo():
    source = FiniteTopology({'a','b','c'}, [set(), {'a'}, {'a','b'}, {'a','b','c'}])
    q = {'a':'A','b':'B','c':'A'}
    result = quotient(source, ['A','B'], q)
    return {'quotient_opens': sorted([sorted(u) for u in result.opens], key=lambda u:(len(u),u)),
            'quotient_connected': result.connected(),
            'quotient_hausdorff': result.hausdorff(),
            'labeled_topology_counts': [len(list(all_topologies(range(n)))) for n in range(4)]}

"""Independent preorder oracle and exhaustive checks for n <= 3."""
from itertools import product
from pathlib import Path
import tempfile
import unittest
from topology_lab import FiniteTopology, all_topologies, continuous, quotient, powerset, write_figures


def preorder_topologies(n):
    pairs = [(i,j) for i in range(n) for j in range(n) if i != j]
    families = set()
    for bits in product([False,True], repeat=len(pairs)):
        r = {(i,i) for i in range(n)} | {p for p,b in zip(pairs,bits) if b}
        if any((a,c) not in r for a,b in r for bb,c in r if b == bb):
            continue
        families.add(frozenset(u for u in powerset(range(n))
                              if all(b in u for a,b in r if a in u)))
    return families


def local_continuity(source, target, mapping):
    for x in source.points:
        for v in target.opens:
            if mapping[x] in v and not any(x in u and all(mapping[a] in v for a in u)
                                           for u in source.opens):
                return False
    return True


class TopologyTests(unittest.TestCase):
    def test_preorder_oracle(self):
        for n,count in enumerate([1,1,4,29]):
            actual = {t.opens for t in all_topologies(range(n))}
            self.assertEqual(len(actual),count)
            self.assertEqual(actual,preorder_topologies(n))

    def test_continuity_all_two_point_maps(self):
        spaces = list(all_topologies(range(2)))
        for source,target in product(spaces,repeat=2):
            for values in product(range(2),repeat=2):
                m = dict(enumerate(values))
                self.assertEqual(continuous(source,target,m),local_continuity(source,target,m))

    def test_quotient_universal_property(self):
        targets = [FiniteTopology({0,1},[set(),{1},{0,1}]),
                   FiniteTopology({0,1},powerset([0,1]))]
        for source in all_topologies(range(3)):
            for values in product(range(2),repeat=3):
                if set(values) != {0,1}:
                    continue
                q = dict(enumerate(values))
                target = quotient(source,[0,1],q)
                self.assertTrue(continuous(source,target,q))
                image_opens = set()
                for u in source.opens:
                    image = frozenset(q[x] for x in u)
                    if frozenset(x for x in source.points if q[x] in image) == u:
                        image_opens.add(image)
                self.assertEqual(target.opens,frozenset(image_opens))
                for z in targets:
                    for pair in product(range(2),repeat=2):
                        f = dict(enumerate(pair))
                        self.assertEqual(continuous(target,z,f),
                            continuous(source,z,{x:f[q[x]] for x in source.points}))

    def test_subspaces_hausdorff(self):
        for s in all_topologies(range(3)):
            self.assertEqual(s.hausdorff(),len(s.opens)==8)
            for a in powerset(range(3)):
                sub = s.subspace(a)
                for x in a:
                    self.assertEqual(sub.minimum_neighborhood(x),s.minimum_neighborhood(x) & a)

    def test_compactness_every_cover(self):
        for s in all_topologies(range(3)):
            opens = list(s.opens)
            for bits in product([False,True],repeat=len(opens)):
                cover = [u for u,b in zip(opens,bits) if b]
                if frozenset().union(*cover) == s.points:
                    chosen = [next(u for u in cover if x in u) for x in s.points]
                    self.assertEqual(frozenset().union(*chosen),s.points)
                    self.assertLessEqual(len(chosen),len(s.points))

    def test_empty(self):
        e = FiniteTopology([],[set()])
        p = FiniteTopology(['p'],[set(),{'p'}])
        self.assertTrue(e.connected())
        self.assertTrue(e.hausdorff())
        self.assertTrue(continuous(e,p,{}))
        self.assertEqual(quotient(e,[],{}),e)
        with self.assertRaises(ValueError):
            quotient(e,['p'],{})

    def test_invalid(self):
        cases = [([0],[]),([0],[set()]),([0],[set(),{0},{1}]),
                 ([0,1,2],[set(),{0},{1},{0,1,2}]),([0,0],[set(),{0}]),
                 ([float('nan')],[set()]),([float('inf')],[set()]),([True],[set()]),
                 (range(9),[set()]),('ab',[set()])]
        for points,opens in cases:
            with self.assertRaises(ValueError):
                FiniteTopology(points,opens)
        p = FiniteTopology([0],[set(),{0}])
        for m in ({},{0:1},{0:float('nan')},{0:0,1:0},[0]):
            with self.assertRaises(ValueError):
                continuous(p,p,m)
        with self.assertRaises(ValueError):
            quotient(p,[0,1],{0:0})
        with self.assertRaises(ValueError):
            p.subspace([1])
        with self.assertRaises(ValueError):
            p.minimum_neighborhood(1)
        with self.assertRaises(ValueError):
            list(all_topologies(range(4)))

    def test_figures_deterministic(self):
        with tempfile.TemporaryDirectory() as d:
            write_figures(d)
            first = {p.name:p.read_bytes() for p in Path(d).glob('*.svg')}
            write_figures(d)
            second = {p.name:p.read_bytes() for p in Path(d).glob('*.svg')}
            self.assertEqual(first,second)
            self.assertEqual(len(first),3)
            self.assertTrue(all(b'Date' not in b and b'\r' not in b for b in first.values()))
            self.assertTrue(all(b'fill="#ffffff"' in b for b in first.values()))


if __name__ == '__main__':
    unittest.main()
