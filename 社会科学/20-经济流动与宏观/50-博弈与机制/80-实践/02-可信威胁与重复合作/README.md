## 两条数值路线与无限证明的分工

进入模型直接列全部四个正常式纯组合、逐人纯偏离；混合均衡的连续区间由正文解析分类，不用概率网格代替。合同先分别求签/不签后的纯策略续局，再对每组纯续局求初始最优选择；并列纯动作保留，不强行选一个。`pure_contract_SPNE`列完整的纯策略应对计划（含离轨），不宣称列出平局时另可能存在的混合SPNE；原进入树的全部混合区间由正文(1)另作解析。所有未走到分支仍在输出。

重复模型固定对方的公共grim。G中自己选C得R且仍G；选D得T，下期以ρ到B、以1−ρ仍G。B中对手D且不再恢复，自己D得P、C得S。这里阶段收益不在下次选择前私下泄露对手动作；该信息合同与正文一致。

第一条路线对任意剩余H逐步最大化两状态价值；分别用守约续值(G=R,B=P)和零终值。第二条对H=3的全部2^(2H)=64份时点×状态纯计划枚举，并从每个初始状态沿报警分支取精确期望；随机化只是纯动作收益的平均，不增加最大值。在固定对手、已证明状态充分的条件下，任何更长私人过去不会增加最优可达值，所以有限递推不是任意删历史。

无限最优偏离值可再独立解析：B的最优值P。G中始终C给R；每次未被发现都继续D直至报警，给

$$W_D=(1-\delta)T+\delta[(1-\rho)W_D+\rho P]
=\frac{(1-\delta)T+\delta\rho P}{1-\delta(1-\rho)}.$$

取W_G=max(R,W_D)可代回两个动作的Bellman最大式：若W_D≤R，C取等而D不超过R；若W_D≥R，D取等而C不超过W_D。B相同。用有界尾项的望远镜不等式即证明它挡住全部偏离，所取策略实现该值。这与正文用守约V认证均衡是两个目标：若均衡失败，一次D后恢复只是一个有利偏离，不必是最佳偏离；反复D直到被发现可能更优。

零终值的H期最优值与无限最优值之差绝对值≤Mδ^H，M=max(|R|,|T|,|P|,|S|)。理由是任一策略被删除的归一化尾项绝对值≤Mδ^H，取双方最优后仍保持该界。零终值会使最后一期倾向D，这是假定没有剩余价值的截断边界，不能把它误叫无限均衡的偏离。守约终值则保留原续值，适合核(3)是否每层仍为等式。

默认δ3/4、ρ1/2：合作值3，单次D后回计划为11/4，增益−1/4；W_D=13/5<3，故最佳偏离仍为守约3。完美监测ρ1另枚举首次D的τ0–8，最大值与永不D比较；只有“首次D后最优一直D”的正文论证成立，这个缩减才合法。无限SPNE/PPE充分性仍由正文对所有策略的证明承担，有限结果不代替它。

## 迁移题完整答案

### 一、威胁与外部执行

纯NE仍为(O,F)、(I,A)。若p=P(I)、q=P(F)，进入净收益3−5q；既有方F减A期望为−4p。因此全部Nash是p0、q∈[3/5,1]，另有p1/q0；没有其他内点，因为p>0即迫使q0。进入后A2>F−2，故唯一无合同SPNE(I,A)。观察O只能约束某个解释模型，不能观察到未执行的F，更不能认证它可信。

有合同b5/k1/2：签后O给既有方7/2；IF为−5/2；IA为2−5−1/2=−7/2，故I后F严格最优，进入者O。无合同I/A给既有方2。初始7/2>2，故签。完整计划写签后F/O、不签后A/I和初始签；不能只写实际O。执行费3时，签后O给1<不签2，所以不签；保证金不能没收时，签后A仍优于F，进入者I，签者付费后仅3/2<不签2，仍不签。

最近错解“保证金5和费用1/2都永久扣，签后退出得−3/2”把退还本金记为终局损失；“费用已经沉没，最早签约时也不算”则在错误时点删除真实支出。最弱可信F条件是b≥4，b=4时有并列，不应宣称唯一F；本题b5避开该边界。没有新增执行能力时，纸面威胁不改变原续局。

### 二、期限、检测与等号

已知恰好3期时末期每个历史DD；倒数第二期未来DD与当前行动无关，仍DD；向前每个历史三期全DD。不是先假定大家永远不合作，而是该收益与共同已知终点下的SPNE结论。

无限δ3/4，T6/R3/P1/S0。阈值δ*=(6−3)/[(6−3)+ρ(3−1)]=3/(3+2ρ)。ρ1/2时δ*=3/4，单次偏离(1/4)6+(3/4)[(1/2)3+(1/2)1]=3，弱无差异；B中P1>S0，所以惩罚仍最优，全策略势函数给PPE。可支持不代表必选或严格稳健。

ρ1/4时阈值6/7>3/4；单次偏离为3/2+(3/4)(5/2)=27/8，较守约3多3/8，故不是PPE。最佳反复D直到报警值为[3/2+3/16]/[1−9/16]=27/7，甚至高于27/8。近错解“δ很高，两者都行”漏了检测对未来损失的影响；“一次偏离27/8就是全局最大”则忽略没被发现时继续利用合作。

### 三、可见性是策略限制

可见时列方四纯计划HH/HT/TH/TT，第一字母应对H，第二应对T；列方最优TH在两分支都选异面，纯Nash也是SPNE的(H,TH)/(T,TH)。行方任意混合、列方TH构成全部均衡，收益(−1,1)：若行方对两行动给正概率，列方必须两分支皆TH；若行方纯H，另个离轨分支若使行方改T可得1，则会偏离，最终也迫使TH；纯T同理。

隐藏时列方两节点同一信息集，纯策略只能H/T；不能给H节点T、T节点H再称可执行。原匹配硬币无纯，唯一混合各1/2，收益(0,0)。没有真子博弈分开这两个节点，不能逐节点逆推来偷得后手可见优势。近错解“时钟上后行动，所以总能应对”抹掉了信息合同。

重复模型ρ0时，G中D即时提高2，且不改变对方以后接收的任何报警，归一化增益2(1−δ)>0；任何δ<1都不能靠此公共grim维持C。记得自己的动作不等于对手能监测。外生POMDP核没有发送者私人类型、信号行动、成本或接收者一致信念，仅是给定信道，不是信号博弈均衡；本课被监测者可选动作改变报警概率，也没有因此自动完成私人信号理论。

### 四、同观察记录只约束兼容性

A在δ3/4≥1/2且惩罚阶段DD可信，grim支持CC；B在对手C时C3>D2，恒C逐期最优，未来无需威胁即可支持。两者都给20期CC/无报警，记录不能独立识别谁怕未来损失或谁在当期更愿意C。

可接续的证据包括实际可选动作与收益/外部选项、对未来期限的知识、报警原始记录与漏检/误报、执行者权力、真实结算是否泄露动作；预定改变监测或公布终点的授权设计可比较行为预测，并保留信念、理解、退出与失败。固定有限终点在原A同质完全信息模型中导致倒推DD，在B仍可恒C，但现实类型或收益若未固定，这也不是万能识别。不能用代理角色扮演代真实行为，也不应为证明惩罚制造未经授权的损害。此处只写接口，未招人、发合同或运行外部干预。

评分先看完整策略/信息/目标，再看偏离式与结论；接受等价手算或枚举。有利单方偏离一个即足以否定候选；证明无利则须覆盖全部可行偏离或给有效的缩减证明。把均衡、效率、学习收敛与值得实施混成一项，不算对应理解完成。没有真人评分一致性或学习效果数据。

## 现实与行为接口：高重要性，但尚未运行

重要性高的外部断言是“参与者面对给定激励/信息会采用这种策略”和“某执行制度改善结果”，都不能由均衡计算认证。接续输入须有版本/授权、实际角色与可行动作、收益与第三方后果、时间零点、期限及续存、信息可见性、私有结算、原报警及漏检/误报、谁承担成本及谁实际执行；私有类型/关系退出/重新谈判均需列替代解释。不能因为连续合作就反推折现或偏好。

若获得合适授权并有风险可控的真人设计，先固定目标总体/单位、角色分配与顺序、收益版本和理解检查、公开/隐藏条件和信道生成、是否可退出；随机分配要与实际暴露区分。每轮保存分配、看到的记录、自己的行动、实际报警与结算、惩罚是否执行、缺失/退出及其原因。不得只保留完成合作的关系或删除破坏预测的轮次；依赖以关系/组和共同冲击为单位，不把一段关系的多轮当独立受试者。

观察与失败须事先写：不同完整计划可同路径，报告离轨执行证据的缺失；若监测/合同不可实施、真实结算额外泄露行动、玩家对期限理解不同、群体间干扰或类型/收益不稳定，则原模型解释失败或需改对象。真实制度因果比较复用计量/政策识别主解释，不能从前后变化或模型参数比较冒实效。保持参与者自主退出，不为验证威胁强迫制造损害。
