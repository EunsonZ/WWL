# 控制论：从调节问题到闭环设计

一间保温盒温度太低，为什么“再加一点功率”有时管用，有时反复振荡？先问目标、可见信息、允许动作和时间，再问控制公式。这里从一个有限调节表开始，把同一个热对象走到连续反馈、数字采样、积分和失效条件。

零基础从 [[控制论/10-系统课程/01-调节目标信息与行动#先做一个无需微积分的诊断|三行调节诊断]] 进入，再依次读热模型和采样实现。已有 ODE、状态空间经验的读者可直达 [[控制论/10-系统课程/02-热模型从物理到连续反馈#先固定对象和每个端口|带单位模型]]，核对模型、初值与噪声端口后直接推闭环极点。两条路线使用相同主解释、相同例题。

按现有课号分八段读；停点是可以自行说明或复算的结果，重新进入时从该段首课继续，并用下面的原课程列表定位具体任务。需要回补或核完整建设范围，返回 [[控制论/00-开始/01-控制课程路线与覆盖边界|课程路线与覆盖边界]]。

入口段采用理想集中参数教学模型。它提供可复算的数学设计与 CPU 执行；真实设备参数、热损耗变化、时限和安全条件需要实测。这也只是独立控制课程的起步段，07–09增加连续最优、标量约束与鲁棒管，10–12继续闭环辨识和标量直接MRAC的条件/证明；更广多变量、非线性、鲁棒综合、完整最优与辨识、自适应推广沿课程路线继续建设；13–14落实指定混杂/切换与标量网络链，一般非线性混杂、多变量时变时延及实际事件/设备实现仍待完成。

15与实践06落实一个局部受控摆单元：可测有界外扭矩、未饱和域和严格输入界由同一证明承担；16与实践07继续SISO相对阶、局部正规形与内部零动态，明确输出跟踪的内部/输入代价。17与实践08接一般连续无源/耗散、负反馈适定性和零耗散不变集条件，以指定机械/电路与隐藏模态复算；更广非线性综合、多端口具体模型、数字端口/时延与真实设备实现仍沿完整课程责任继续。

18与实践09落实固定二维多胞体、全状态即时反馈、共同严格有界实证书和一次真实数值综合；任意可测方框内参数变化的保证来自固定储能证明。19与实践10将固定状态反馈改为一组固定观测器驱动的动态输出反馈，完整四状态、过程扰动/传感噪声及公共耗散证书重新核验。一般动态输出反馈综合、动态权重/结构化不确定性、约束与数字实现以及完整课程仍须继续。

20与实践11接有限连续LTI的常值MIMO目标、全输出积分增广及普通观测器实现；以指定双端口对象核内部稳定、估计偏差与零测量误差，原点零点、偏置和饱和明确停止条件。一般时变外系统、数字/约束调节、鲁棒动态输出反馈综合与完整课程仍沿路线继续。
