# 视觉任务、迁移学习与 ViT 桥梁

<!-- deep-review-02 -->
> [!tip] 本轮深化：从当前概念继续追问
> 从分类迁移到定位、分割或图文任务时，监督单位和评估协议都变了。全局相似度不能直接证明局部关系理解，必须设计对应的反事实任务。 深化与验证：[[AI/15-卷积神经网络/06-检测分割匹配损失与评估协议|检测分割匹配损失与评估协议]]；[[AI/30-VLM/03-视觉语言对齐信息瓶颈与反事实评测|视觉语言对齐信息瓶颈与反事实评测]]。


同一张图片可以有完全不同的监督目标。分类问整图属于什么，检测问对象在哪里，语义分割给每个像素一个类别，实例分割还要区分同类的不同对象。输出结构决定损失与指标，不能把准确率当作所有视觉任务的共同答案。

## 指标必须对应输出

分类看准确率、宏平均 F1、校准与关键类别召回。检测需先按类别和交并比阈值匹配预测框与真实框，然后计算 precision-recall 和 AP；重复检测会形成假阳性。AP 要声明 IoU 阈值、类别平均、置信分数排序和具体评测实现。

二值分割常用：

$$
\operatorname{IoU}=\frac{TP}{TP+FP+FN},\qquad
\operatorname{Dice}=\frac{2TP}{2TP+FP+FN}.
$$

它们不看真阴性，因此不会因背景占 99% 就自动得到漂亮分数。但空掩码、类别平均、边界误差和大小目标权重仍需约定。微小但关键的区域应单独统计。

## 迁移学习先冻结什么

先固定预处理和输入范围，再把预训练 backbone 的表示接到新任务头。线性探测只训练头，成本低，也能诊断表示是否有用。逐步解冻可以减少一次性改变所有参数的风险；不同层学习率不是必需魔法，而是要验证的超参数。

预训练规范化和颜色通道不能随意替换。冻结参数不等于冻结 BatchNorm 状态。类别不平衡时，重采样和类别权重会改变有效训练分布，验证仍应代表实际使用。

旋转、翻转和裁剪是否保留标签，取决于任务。数字 6 和 9、左右手、医学影像方向都可能在增强后改变标签含义。数据增强不是“越多越好”，而是表达你愿意假设的对称性。

## 从卷积到视觉 Transformer

![图片到 patch token 的形状流程](../90-资源/图示/vit.png)

把 $H\times W$ 图像切成不重叠的 $P\times P$ patch，在尺寸整除时 token 数 $N=HW/P^2$。每个 patch 展平成 $P^2C$ 后投影到 $D$ 维，加入位置，再送入 Transformer。224×224 RGB 图像、patch 为 16，得到 196 个 patch，每个有 768 个原始像素分量；加入分类 token 后序列长是 197。[1]

步长等于核大小的卷积可以实现这种线性 patch 投影，因此 ViT 和 CNN 不是两个不能连接的数学世界。区别在于后续 token 混合：卷积偏向固定局部连接，注意力依输入计算跨位置权重。

在 patch 大小不变、每边分辨率加倍时，token 数变四倍，全注意力的成对位置数变十六倍。实际总耗时不会严格十六倍，因为投影、MLP、预处理和硬件利用率也在其中。进入 VLM 后视觉 token 还占用语言模型上下文，成本不能只算视觉编码器。

**练习：** 输入图片被裁掉一个小目标后，模型错误应先归给“推理能力”还是输入管线？先检查模型实际看到的像素。进一步阅读 [[AI/30-VLM/01-视觉表示ViT与图像输入管线|视觉输入管线]]。
