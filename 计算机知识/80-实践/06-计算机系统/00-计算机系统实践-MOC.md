# 计算机系统实践 MOC

这组实验把 [[计算机知识/30-计算机系统/00-计算机系统-MOC|计算机系统稳定课]] 中的抽象变成 macOS/Linux 普通用户可观察的现象。它们不读写块设备、不挂载文件系统、不需要 `root`/`sudo`，不修改现有项目或用户数据。

## 证据分层

| 证据 | 能说明 | 不能说明 |
| --- | --- | --- |
| 源码与静态解释 | 调用了哪些 API，奇偶分支与资源边界是什么 | 本机一定观察到某个计数或性能排序 |
| 自测试或单元测试 | 结果契约、边界值与清理路径成立 | 虚拟内存、缓存或持久化机制的全部内核实现 |
| 一次实际运行 | 当前机器、当前负载下的观察值 | 其他 CPU、内核、文件系统或负载下必然相同 |
| 重复测量与中位数 | 将单次调度噪声与趋势初步分开 | 自动消除频率、热管理、预取、页缓存等混杂因素 |

## 开始前检查

1. 在终端中运行 `python3 --version` 和 `cmake --version`；Python 实验只要 Python 3，C++ 实验要求 CMake 3.20+ 与 C++20 编译器。
2. 每个 README 的命令都在**该 README 所在的实验目录**执行；命令中的 `.` 指当前实验目录，不是 Vault 根目录。
3. 只想使用 Python 时，先做虚拟内存和原子替换；想使用 C++ 时，先做数据表示，再做缓存和 POSIX pipe。
4. 如果出现需要 `sudo`、真实设备、外部 PID 或真实用户路径的步骤，已经超出这些实验的安全边界，应立即停止。

## 三条实践路线

### 内存、表示与性能

1. 稳定课 01 → [[计算机知识/80-实践/06-计算机系统/01-数据表示与对齐/README|数据表示与对齐]]：对比原生对象字节与显式小端编码，观察结构体填充。
2. 稳定课 02 → [[计算机知识/80-实践/06-计算机系统/02-虚拟内存mmap与页错误/README|虚拟内存、mmap 与页错误]]：逐页首次访问，读取进程级 minor/major fault 计数差。
3. 稳定课 04 → [[计算机知识/80-实践/06-计算机系统/03-缓存局部性benchmark/README|缓存局部性 benchmark]]：同一 row-major 矩阵按行或按列读取，比较多轮耗时分布。

### Unix I/O 与持久化

1. 先读 [[计算机知识/30-计算机系统/09-进程线程调度同步与IPC|进程、线程、调度、同步与 IPC]] 和 [[计算机知识/30-计算机系统/12-VFS文件描述符Inode目录与路径解析|VFS、文件描述符、inode 与路径解析]]，再做 [[计算机知识/80-实践/06-计算机系统/04-文件描述符pipe-dup与进程/README|文件描述符、pipe、dup 与进程]]。
2. 先读 [[计算机知识/30-计算机系统/11-存储设备块层页缓存与持久化|存储设备、块层、页缓存与持久化]]、[[计算机知识/30-计算机系统/12-VFS文件描述符Inode目录与路径解析|VFS、文件描述符、inode 与路径解析]] 和 [[计算机知识/30-计算机系统/13-文件系统布局日志CoW与一致性|文件系统布局、日志、CoW 与一致性]]，再做 [[计算机知识/80-实践/06-计算机系统/05-文件系统原子替换与fsync/README|文件系统原子替换与 fsync 边界]]。

### 地址翻译、资源视图与时间

1. 先读 [[计算机知识/30-计算机系统/16-地址翻译TLB页表遍历与大页|地址翻译、TLB、页表遍历与大页]]、[[计算机知识/30-计算机系统/17-通用内存分配器Arena碎片与驻留|通用内存分配器、Arena、碎片与驻留]] 和 [[计算机知识/30-计算机系统/18-CPU拓扑缓存一致性NUMA与设备亲和性|CPU 拓扑、缓存一致性、NUMA 与设备亲和性]]，再做 [[计算机知识/80-实践/06-计算机系统/06-地址翻译分配器与拓扑观察/README|地址翻译、分配器与拓扑观察]]。它观察的是进程级 RSS、玩具 arena 账本和只读拓扑，不直接计数 TLB miss、IOTLB 或物理页位置。
2. 先读 [[计算机知识/30-计算机系统/19-容器虚拟机Namespace-Cgroup与虚拟IO|容器、虚拟机、Namespace、Cgroup 与虚拟 I/O]] 和 [[计算机知识/30-计算机系统/20-时间时钟计时器Deadline与跨主机关联|时间、时钟、计时器、Deadline 与跨主机关联]]，再做 [[计算机知识/80-实践/06-计算机系统/07-资源视图与时间预算/README|资源视图与时间预算]]。实验只读当前进程的受限视图并在不支持时 `SKIP`，不创建容器、不改 cgroup 或系统时钟。

## 统一安全边界

- C++ 实验要求 CMake 3.20+ 和 C++20；Python 实验只使用 Python 3 标准库。
- 实验运行时样本数据位于匿名映射或 `tempfile.TemporaryDirectory` 创建的精确临时目录；上下文结束后由标准库清理。三个 CMake README 中的默认命令会在当前实验目录创建 `build` 或 `build-release` 本地构建产物，它们不属于样本数据，也不会自动清理；每个 README 都给出了该实验的精确清理边界和可选 `/private/tmp` 外部构建方式。
- 不对基准耗时、页错误数量或 major fault 必须大于零写硬断言。
- 若你修改实验使其接收外部路径，必须重新设计目标校验、失败清理和恢复方法；默认版故意不接收真实文件路径。

## 完成标准

七个实验的测试全部通过；你能把每个输出归类为“语言/API 契约”、“当前进程观察”或“含测量噪声的性能样本”；能说明为何这些结果不证明物理页号、TLB/cache 命中率、生产 NUMA 收益、宿主机全局资源或突然断电后的实际持久性。
