# 词级分词与 n-gram 平滑

本课回答：语言模型到底在数什么，以及训练时没出现过的词对能否获得合理概率。这里的单位是**预先固定的词**，不是字符，也不是 BPE 子词。先定义词级边界，再数频次；反过来，概率表也可以参与选择分词，但那需要明确解码目标。

## 分词本身有歧义

中文 `研究生命起源`，字典设为 `{研究, 研究生, 生命, 命, 起源}`。左到右最长匹配第一步选“研究生”，随后得到 `研究生 / 命 / 起源`；枚举字典允许的全部切分，还有 `研究 / 生命 / 起源`。最长匹配是一个确定性策略，字典中最长词不保证句子语义最好。若字典不含“命”，贪心第一步甚至会导致后续失败，而较短第一步可完成切分。本实验遇到未知字符报错，不偷偷将它当成已知词。

英文小语料直接给出 token 列表，免去标点、大小写、缩写规则；真实项目必须冻结规范化、分词版本和标注单位。子词与 Unicode 的详细区别去读 [[AI/20-LLM/10-原理/01-文本Unicode-Token与词表#tokenizer 不只是“按空格切开”|已有 Token 课]]。语言学上的词与某个程序输出的 token 也不自动相同。

## 一个三句训练集：上下文是条件的一部分

原创训练集为 `fish swim`、`fish fish`、`birds swim`。每句加起始 `<s>` 与终止 `</s>`。目标词表固定为

\[
V=\{fish,swim,birds,</s>,<UNK>\},\qquad |V|=5.
\]

`<s>` 只作上下文、不作预测目标；`</s>` 是目标、预测到它就停止；未在词表内的原词映射为 `<UNK>`。词表在训练前按本实验协议固定，不能看测试集再扩充。实际项目可只用训练集建词表并把训练中的低频词换成 `<UNK>`。

| 前一个词 h | fish | swim | birds | 终止 | UNK | 行和 C(h,·) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 起始 | 2 | 0 | 1 | 0 | 0 | 3 |
| fish | 1 | 1 | 0 | 1 | 0 | 3 |
| birds | 0 | 1 | 0 | 0 | 0 | 1 |
| swim | 0 | 0 | 0 | 2 | 0 | 2 |
| 目标 unigram 总数 | 3 | 2 | 1 | 3 | 0 | 9 |

bigram 的对象是 $P(w_t\mid w_{t-1})$；一般 n-gram 只保留前 $n-1$ 个词，这是建模近似，不是概率链式法则本身。链式分解和神经自回归训练的区别见 [[AI/20-LLM/10-原理/02-自回归建模Logits损失与困惑度]]。

最大似然估计为 $P_{MLE}(w\mid h)=C(h,w)/\sum_v C(h,v)$。本例 `fish→birds` 的计数为零，所以整个 `fish birds </s>` 的 MLE 概率为零；没见过的上下文分母也可能是零，此时不能把 0/0 当作概率。

## 加性平滑与插值：两步都要归一

选 $k>0$，定义

\[
P_k(w\mid h)=\frac{C(h,w)+k}{C(h,\cdot)+k|V|},\qquad
U_k(w)=\frac{C(w)+k}{N+k|V|},\quad N=9.
\]

分子对全部 $w\in V$ 求和正好等于各自分母，所以两者归一。未知上下文行的 $C(h,\cdot)=0$ 时，加性模型成为均匀分布。加性平滑从已见目标抽出概率质量给未见目标；它并不创造词表外的独立新词。

再取固定 $0\le\lambda\le1$：

\[
P_{mix}(w\mid h)=\lambda P_k(w\mid h)+(1-\lambda)U_k(w).
\]

和为 $\lambda+(1-\lambda)=1$。这是两个**已经归一**的模型的凸组合。先把两个原始计数表相加而不处理分母，不会自动得到同一模型；$\lambda>1$ 也可能造成负概率。

取 $k=1,\lambda=3/4$，在 `fish` 后的完整表为：

| 目标 | 加性 bigram | 加性 unigram | 插值 |
| --- | ---: | ---: | ---: |
| fish | 2/8 | 4/14 | 29/112 ≈ 0.258929 |
| swim | 2/8 | 3/14 | 27/112 ≈ 0.241071 |
| birds | 1/8 | 2/14 | 29/224 ≈ 0.129464 |
| 终止 | 2/8 | 4/14 | 29/112 ≈ 0.258929 |
| UNK | 1/8 | 1/14 | 25/224 ≈ 0.111607 |

例如加性模型给 `fish birds </s>` 的概率为 $(3/8)(1/8)(1/6)=1/128$，三项依次来自起始、fish、birds 的行。用 log 概率加和避免长序列乘积下溢。实现计算加性比率时先按 $m=\max(C(h,\cdot),k)$ 缩放分子分母：$(C(h,w)/m+k/m)/(C(h,\cdot)/m+(k/m)|V|)$；unigram 同样处理。这样 $k=10^{308}$ 虽会让朴素的 $k|V|$ 溢出，结果仍能稳定得到约 1/5。若极小 $k$ 让未见事件的正概率低于浮点可表示范围，代码显式报错并要求增大 $k$，不输出零概率再取 log；数学公式在实数下仍定义，并不意味着所有正实数参数都能用双精度实现。终止符和正平滑也保证本模型几乎必然最终终止：有限词表各上下文终止概率有共同正下界。仅行归一而终止概率为零的模型可能永远生成，不能据此宣称有限句子的总概率是 1。

## 划分、选择与失败条件

训练集负责计数和词表规则；开发集负责选择 $k,\lambda,n$；最后冻结后用测试集比较。文档重复、同一来源的相邻句泄漏会使“新文本”评测过于乐观。这里三个训练句只用于教学，没有用它们声称泛化收益。空句仍预测一次 `</s>`，其概率不是空乘积 1。

加性平滑是清楚的入门基线，在大词表下可能分走太多质量；插值也不保证真实任务改善。词级与子词 PPL 的分母和事件不同，比较限制复用 [[AI/20-LLM/10-原理/07-语言模型目标分词粒度与评测可比性#困惑度的分母不是无关紧要的小字|已有评测可比性课]]，不在此再定义一套 PPL。

## 跟算练习与完整答案

1. `fish` 后只给五个分子各加 1，却仍除以原行和 3，错在哪里？答案：分子总和为 8，行和为 8/3；应除以 8。
2. 在未见上下文 `sharks` 后取 $k=1,\lambda=1$，五个目标各是多少？答案：输入上下文映射为 UNK，该行计数 0，各为 1/5；若训练中 UNK 有计数则不必均匀。
3. 取 $\lambda=0$，下一词还依赖 `fish` 吗？答案：完全使用 unigram，不依赖上下文；这提供比较上下文价值的基线。
4. 把第一句复制到测试集，用它选 $\lambda$ 再报同一测试分数，能验证什么？答案：只能描述已见/调参样本上的分数，不能当冻结模型对独立测试集的泛化估计。
