# 从仿真到实测的故障树

## 两个入口先给差异命名

基础入口：实测曲线与仿真不一致，先把“哪里不同”写成可观察量。快进入口：把残差按竞争模型的参数灵敏度、时间结构和环境依赖拆开。两入口共同目标是安排下一次能排除解释的实验，而不是把每一种误差都塞进一个更复杂拟合器。本页图、数据与残差全部为**合成教学数据**；没有真实实验或仪器读数。

## 先保留基线，逐层检查

基线仍为R=1kΩ、C=1μF、U=1V、v0=0、理想无载，τ=1ms。仿真端口v=a–0，电流方向源→R→C→0。拟合或比较前保存输入波形、时间零点、初值、元件工作条件、仪器终端/探头及环境。源标着1V不保证连接DUT后实际输入1V；50Ω源端与高阻负载的设置含义尤其要核查，比较需使用实际DUT输入参考。

排查树第一层是对象与连接：单位、峰值/RMS、节点参考、源幅度、触发/时间零点、初始电荷、读的是输入还是输出。第二层是已知物理：容差、偏置、温漂、ESR/ESL/漏电、连线。第三层是测量系统：探头加载/补偿/回路、带宽、时标、采样、噪声、校准。第四层才是模型失配及未知机制。这个顺序是便于辨别的流程，不是证明所有故障必按此因果排序。

## 用数值给竞争解释不同签名

对同一记录时间t=1ms：

| 合成假设 | 机制与保持的条件 | 预测v(t)或参数 |
|---|---|---|
| 理想基线 | 无载、零初值、1V输入 | .632120559V，τ=1ms |
| R+1%、C+5% | 其他条件不变 | τ=1.0605ms；v≈.610523V |
| 初值.4V | 同一R/C与U | v=.779272335V；终值仍1V |
| RL=10kΩ | 并联到电容端、Cp=0 | K=.909091、τ=.909091ms；v≈.606480833V |
| 记录时标放大1% | t_record=1.01 t_true | 记录τ=1.01ms；1ms记录点约.628460V |
| 电压偏置+2mV | 后处理加常偏置 | .634120559V；全程残差常2mV |

实践另画RL=10kΩ并加Cp=12pF，τ=(R∥RL)(C+Cp)，与表中Cp=0的近似明确区分。微小Cp不代表所有高频布局寄生都小。

容差改变τ，单用电压还不能归因R还是C。已知v0错误可改变早期残差；未知输入边沿和有限仪器带宽也可能产生额外指数。只有测实际输入/独立初值或改变输入速度才能区分。终值偏小可由负载、源幅度或增益标定导致；改变RL并测输入，不只重复同一次输出。高频振铃可能来自真实寄生，也可能来自地线回路；短地线/低容探头/改变连接的对照才检验测量系统贡献。

## 控制变量检验竞争机制

| 当前差异 | 下一次受控改动 | 保持/另测什么 | 支持的解释与仍未排除的项 |
|---|---|---|---|
| 起点高、差异衰减 | 固定等待/放电过程，读v0 | 记录实际U与触发零点 | IC若同步改变支持初值；带宽/输入边沿仍须查 |
| 终值低 | 换已知RL或低加载探头 | 同时测DUT输入U | 按K变化支持加载；仪器增益或源设置仍可共存 |
| 振铃随连接变 | 缩短参考回路、改变探头 | 不改DUT元件和源边沿 | 频率/幅度变化支持测量回路参与；不能证明DUT无寄生 |
| 平均后散布变小 | 分段重复、改变平均次数 | 检查温度/时间漂移与相关性 | 独立噪声可减小；共同偏差与漂移不必消失 |
| τ随温度/偏置变 | 定温或定偏置对照 | 校准及探头保持一致 | 参数工作条件可能变化；需另测R/C或Z支持归因 |
| 局部拟合好、留出失败 | 新时间/频段或额外电流观测 | 预先固定模型/拟合范围 | 支持原模型范围不足；不等于已知新模型唯一 |

[Tek探头原文](https://www.tek.com/en/documents/whitepaper/abcs-probes-primer)ground-lead与“Determining the source of noise”段核对通过测量连接改变检验回路参与的思路；本表是独立构造的RC实验设计。[JCGM 100](https://www.bipm.org/documents/20126/2071204/JCGM_100_2008_E.pdf)§3.4.2提醒数据提示模型不完整时需修订模型，不把不确定度数字当未知失配已被覆盖。

## 结课：用两次连接检验元件偏差与加载

这是一份待真实执行的设计，表内只有合成预测。固定源、温度、偏置、放电过程及记录时间范围；测DUT实际输入U，同时在两次连接分别使用已知教学总输入负载RL=10kΩ、100kΩ，Cp都假设为12pF。RL包括测量支路/外加已知负载的合成，数值不冒充某型号探头参数。每次测终值比K和时间常数τ，而不是只强迫终值为1。

若DUT仍R=1kΩ、C=1μF，预测两次(K,τ)分别(.909091,.909102ms)、(.990099,.990111ms)。若同R但C实际+5%，两次τ分别.954556ms、1.039616ms，而K不变。每次由 $R=R_L(1/K-1)$、$C=\tau/(R\parallel R_L)-C_p$ 还原教学DUT参数，再比较两次及其传播不确定度：共同恢复标称参数支持加载解释；两次都恢复1.05μF支持该工作条件下的容量差异。真实RL/Cp、源阻抗、增益、时标须有可信值与预算；若两次还原不一致，不能马上宣判某元件，需检验测量模型/条件改变。该设计用“换连接后会怎样”作留出预测，不靠第一次曲线的训练残差签收。

## 残差通过与真实验收分层

数值求解满足KCL、合成数据再生成一致，能证明指定模型实现与有限复算结果；不能证明真实元件、接线或仪器校准。实际实验需要记录仪器型号/配置/校准信息、连接图、原始数据、重复与环境条件、修正/预算，以及预先约定的留出检验。现场缺这些信息时写“未测/未知”，不要用本实践CSV补填真实读数。

残差小可同时发生于正确参数、同τ等价族、强先验选点和错误模型的窄窗口近似。更完整模型降低训练残差也可能是过拟合；新观测中竞争模型给不同预测时，才有下一次辨別价值。本页未作SPICE、仪器/VNA、硬件、客户端或真人学习验收。

## 四个理由与迁移题

1. 仿真零残差能证明R/C各已测准吗？答：不能。同τ族有同样零残差；代码正确性和参数唯一性还不同。
2. 平均100次后散布变小，终值仍低，先判电容坏合理吗？答：不合理。独立散布减少不移除加载、源设置或增益偏差；应测输入与改变负载检验K。
3. 温度变化后τ增加，只有电压阶跃，能断定C增加吗？答：不能，R/C乘积、负载及测量系统都可变化；用电流或Z等额外观测并保持/校核其他条件。
4. 撤提示迁移：早期点拟合出的τ与晚期点不同，加入第二个指数后拟合优良。下一步是什么？答：声明两指数只是竞争模型；测实际输入、改变探头/边沿、检查初值，用留出时间或频率检验预测。参数更多和残差更小本身不能识别第二指数的物理来源。
