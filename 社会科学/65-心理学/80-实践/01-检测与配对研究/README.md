# 本机检测模型与配对研究：输入、复算和未验层

这里完成可独立重建的数学教学实践。没有人参加，没有真实逐试次反应，没有刺激呈现、脑活动或健康测量。inputs.json明确标注合成来源；实际原研究来自正文链接，不与此目录结果混合。

## 先作答，再运行

先单独摘出 [迁移任务纸](迁移任务纸.md) 的A—G，不把答案、原研究提示和生成结果同发。答后再读 [[社会科学/65-心理学/07-条件改变研究解读与完整答案|完整解读]]。这是撤提示的材料接口，尚无本库真人作答；独立模型核算只认证数学／方法，不能记录为学习者掌握。

在本目录执行，Python 3.10+，只需标准库，无网络、GPU或第三方库：

```bash
python3 -B psychology_lab.py --input inputs.json --out results
```

输出目录由命令创建；重复执行会替换其中这五个固定文件，请对自己的输入使用新输出目录。作者本机实际在资源门控下运行成功：

```bash
python3 -B /private/tmp/wwl-next-context/run_local.py --timeout 300 -- python3 -B psychology_lab.py --input inputs.json --out results
```

第二条的门控路径属于本轮本机环境，不是课程依赖；换机可直接用第一条。计算规模受输入验证限制，默认为64个符号分配，单进程低内存；本轮遵守两并发槽、各至多4线程／总8GiB约束。

## 每份产物回答什么

| 文件 | 对象与独立预期 |
| --- | --- |
| inputs.json | 分布均值、两个阈值、先验列表；六个单位的正确反应时中位数、试次数和错误数。是摘要，不可逆推出原始试次。 |
| psychology_lab.py | 唯一规范源码；输入验证先完成，再写产物。见 [镜像](code-sync/psychology_lab.md)。 |
| results/exact-results.json | 记录模型假设、每阈值H/F/d′/判准/按基率准确率、最优等代价阈值、配对差、精确均值／方差／尾概率、错误率。 |
| results/curves.csv | 181个证据位置及同一方程生成的两密度、H、F；不是采样的参与者分布。 |
| results/randomization.csv | 六个独立符号的64种分配与精确有理数平均；双侧尾部含等号。 |
| results/detection.svg | 固定证据分布与同一ROC上的两个阈值，密度不是点概率。 |
| results/paired.svg | 每点一个配对单位，保留负向变化；平均线不是置信区间或个体规律。 |

默认独立核算：$d'=1$，$C=k-.5$；$\pi=.5$两阈值准确率均约.670672，$\pi=.1$时$k=1$约.807210、$k=0$约.534134。配对差40、60、20、−10、50、20ms，均值30、样本方差640，双侧锐零尾数4/64即1/16；A错5/120、B错7/120。浮点值以$10^{-9}$绝对误差核对；有理数、64行枚举应精确相等。图和表使用同一结果对象生成，不能另手调图点以配结论。

输入拒绝未知／缺字段、非有限数字、布尔冒充数值、超范围参数、重复单位ID、非法错误计数等，退出码2且不创建新输出目录。只改副本，别在原输入上试错。当前教学支持正均值分离$\mu\in[.125,4]$、两个$k\in[-3,3]$、先验在程序验证区间$[.001,.999]$、2—16个配对单位；这些是程序的有限演示范围，不是心理学自然边界。

## 两个条件改变，先预测再重算

复制inputs.json为新文件，把signal_mean改2，另给新输出目录：预期$d'=2$，且$C=k-1$；不能只用原$d'=1$的图。等代价最优阈值变为$\mu/2+\log[(1-\pi)/\pi]/\mu$，当前两种先验只是列表，不改变条件密度。若仅改变先验，H/F不变而总体准确率与最优阈值可变。

另把六个B_ms都设成各自A_ms，且不改错误摘要：每个配对差0，均值0、方差0；64个统计量都与观察同样极端，$p=1$。错误率此时仍可不同，这正提醒速度与错误是不同读数。若改均值差正负抵消，也须按绝对观察统计量重新枚举，不能机械沿用4/64。枚举成立仍依赖随机区块、锐零与无携带；程序不会替真实设计保证这些条件。
