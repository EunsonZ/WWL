# 01 · 命令面板、页面预览与文件浏览器

> [!example] 本课动作
> 用键盘找命令，用悬停读链接，用文件浏览器看清“Vault 就是一个本地文件夹”。

## 目标

- 用 Command palette 搜索并执行命令。
- 在编辑视图和阅读视图中触发 Page preview。
- 使用 File explorer 创建、定位、排序和链接文件。
- 区分“执行动作”“查找正文”和“管理文件”三个入口。

## 动手

### 1. 用命令面板发现功能

1. 按 `Cmd+P`（macOS）或 `Ctrl+P`（Windows / Linux）。
2. 搜索“切换阅读视图”并执行。
3. 再次打开命令面板，搜索“本地图谱”或 “local graph”。
4. 在“设置 → 核心插件 → 命令面板”中观察 **Pinned commands**；先固定两三个真正高频的命令即可。

命令面板支持模糊匹配，也会显示最近运行过的命令。固定命令只是把入口放到面板顶部；它不会自动创建快捷键。

### 2. 用 Page preview 不离开当前页

把鼠标放到这个链接上：[[Obsidian知识/20-功能/01-官方插件实验室/02-核心 Templates|02-核心 Templates]]。

- 在编辑视图中：按住 `Cmd`（macOS）或 `Ctrl`（Windows / Linux）再悬停。
- 在阅读视图中：直接悬停。
- 再到 File explorer、Search 或 Backlinks 的结果中悬停同一个文件。

暂时关闭 Page preview 后，链接仍然可以打开，只是悬停预览会消失。实验完成后重新启用。

### 3. 用 File explorer 看见真实文件

1. 在 `04-官方插件实验室` 下新建一个临时文件夹。
2. 在其中新建 `文件浏览器练习.md`。
3. 把文件拖进当前笔记正文，观察 Obsidian 自动插入内部链接。
4. 打开 File explorer 的 **Auto-reveal active file**，在不同课程间切换。
5. 尝试按文件名、修改时间和创建时间排序。
6. 完成后可把练习文件保留，或在确认目标后移到你自己的实验区。

## 成功标准

- [ ] 我能用 `Cmd/Ctrl+P` 找到一个不知道完整名称的命令
- [ ] 我能解释 Pin 与 Hotkey 的区别
- [ ] 我在编辑视图中用 `Cmd/Ctrl + hover` 看到了页面预览
- [ ] 我通过 File explorer 创建并定位了一篇真实 Markdown 文件
- [ ] 我知道正文搜索应使用 Search，而不是 Command palette

## 限制与边界

- 可用命令取决于已启用的插件，名称也会随界面语言变化。
- Page preview 默认开启；编辑视图通常需要 `Cmd/Ctrl + hover`。
- Page preview 是只读预览，不是可固定、可编辑的浮动编辑器。
- File explorer 的删除、移动和重命名会修改真实文件；操作前确认目标。
- 若启用了“自动更新内部链接”，在 Obsidian 内重命名笔记会同步更新链接；不要把系统文件管理器中的盲目移动当成同样安全。
