## 本机实验为什么属于高重要性

偏置、电流、隐藏共模和失稳根决定电路究竟是不是题设那个对象；错误往往不表现为语法错误，甚至能得到好看的差模曲线。故本卡用同一电路的**工作点、全节点小信号与有限扰动**交叉核验，而不是只测试一个公式的返回值。它是器件级教学电路的本机可执行实验；未假定真实PDK、探针台或硅已经存在。

默认输入：3.3 V、27 °C、主输入共模1.5 V、共模目标1.65 V、Iref50 µA、两个200 kΩ检测器、输入差模反馈0.1、CL各20 pF、控制节点10 nF，其余五节点各5 pF。模型KPn100 µA/V²、KPp50 µA/V²、阈值+0.6/−0.7 V、λ0.04 V⁻¹，几何见主文/网表。

`LEVEL1`卡中 `GAMMA=0`、`IS=1e-30`、重叠/结电容置0，KP/VTO显式给定。`TOX=1e3`是数值上压低内置Meyer电容的教学设置，不是物理氧化层或工艺参数；所有需要的动态电容另画。官方手册说明TOX指定时会启用内置薄氧化层电容，故没有假称仅把CGSO/CGDO置0就已关掉全部寄生。真实器件模型恢复体效应和电荷后，需重新形成含交叉项的C矩阵并复验，不能沿用本结果。

输出前先完成全部计算和JSON有限数检查，已有目录显式拒绝。CLI不会改正文、模型或旧结果。正式data目录保持只读；先把证据/检查脚本复制到新的库外目录，或把新生成网表复制到相应新分析目录，用 `ngspice -b nominal-op.cir`、`ngspice -b nominal-ac.cir`、`ngspice -b nominal-tran.cir`；各分析目录分开，防止同名wrdata输出互相覆盖。本项目执行时先取得约定数值槽；安装/构建与仿真应分开记录。

要在同一模型只改一项，可导入 `Config` 并用 `dataclasses.replace`：`load_scale=1.1`同时代表主负载组几何偏大；`plus_mismatch=1.02`只改M3；`plus_cap_scale=2`只改op电容；`control_c=20e-12`只改控制节点电容。先调用 `operating_point` 再 `linearization`，不得在新偏置上沿用旧gm/ro。`cmfb=False`表示主PMOS栅改接 `fixed_gate` 理想源，误差级仍在电路里，只失去作用于主负载的连接。

迁移的独立预测在主文末尾：单侧电容加倍不改DC却破坏动态交换对称；单侧器件变宽先改Q再出现交叉偏导。等价节点解、不同正确求根算法都可，不强迫照抄作者代码。
