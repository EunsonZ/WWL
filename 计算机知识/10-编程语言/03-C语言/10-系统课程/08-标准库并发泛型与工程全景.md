# C 的完整知识边界：标准库、并发、嵌入式与接口工程

> **学习位置**：[[计算机知识/00-开始/课程地图/01-C语言-课程地图|C语言课程地图]] · **适用边界**：ISO C17；C23 与 POSIX 扩展另行标识。

## 把标准库按解决的问题组织

内存和字节处理由 `stdlib.h`、`string.h` 等提供，但分配、复制、比较的前提不同；数字范围与表达式需要 `limits.h`、`stdint.h`、`inttypes.h`、`float.h`；数学函数、复数和浮点环境分别涉及 `math.h`、`complex.h`、`fenv.h`。不是每个目标环境都具备同样的运行库能力，freestanding 与 hosted 环境应区分。

文本分类和 locale 由 `ctype.h`、`locale.h` 处理；多字节与宽字符另有 `wchar.h`、`wctype.h`、`uchar.h`。时间、诊断、非局部跳转及信号分别看 `time.h`、`assert.h`、`setjmp.h`、`signal.h`。可变参数 `stdarg.h` 允许实现格式化类接口，但类型不匹配不能靠运行时自动推断恢复。

`assert` 用于开发期不变量，可能在定义 `NDEBUG` 后被移除，因此不要把必要副作用或外部输入校验只放在断言里。`setjmp`/`longjmp` 跨越正常返回路径，必须理解自动变量状态和资源清理限制，不能把它当成不需代价的异常机制。

## 存储期、作用域和链接是三个坐标

局部自动对象通常随块执行创建与结束，但“局部”不必然意味着自动存储期：函数内 `static` 对象持续存在。文件作用域名称也不必然对其他翻译单元可见：`static` 可以给它内部链接。

线程存储期对象为每个线程保留独立实例，适合线程本地缓存，却仍要考虑线程退出和跨线程传递指针。`register` 不是现代硬件寄存器分配命令；`auto` 在 C17 的意义也不是 C++ 的类型推导。关键词长得相同不能越过语言版本边界解释。

## 原子计数与复合状态

两个线程执行 `counter++`，即使单次读写在某硬件上不撕裂，也不代表读—改—写整体原子。原子 `fetch_add` 可以解决共享计数，但无法独自维护“计数等于链表节点数”这种跨多个对象的不变量；这个不变量可能需要锁、事务式协议或专门的无锁设计。

C11 原子和线程库是重要知识，实际实现支持应检查。无锁不等于无等待，lock-free 表示系统总体能推进，wait-free 对每个操作有更强的有限步骤保证。CAS 循环仍可能饥饿，ABA 和内存回收也不是原子类型自动解决的问题。

## 嵌入式代码的额外前提

裸机程序还要处理启动代码、链接脚本、中断向量、内存映射外设、栈容量和有限堆。中断与普通线程不是完全相同的执行环境；中断处理通常必须短小，并遵守可以调用哪些函数的约束。

DMA 让设备直接访问内存时，CPU 缓存一致性、地址映射与缓冲区生命周期成为协议的一部分。“写入了 volatile 指针”不能作为所有设备上 DMA 已看到新数据的证明。正确序列来自目标芯片、操作系统驱动接口和总线规范。

实时系统关注最坏响应时间，而不仅是平均吞吐。动态分配、无界循环、阻塞 I/O 和不可控优先级反转都可能破坏时限；这些地方应该给出资源上界，而不是只跑一次计时。

## C 与其他语言交互

跨语言 ABI 常用固定宽度整数、指针加长度、不透明句柄和显式释放函数。不要跨运行库边界随意让一侧 `malloc`、另一侧用不兼容分配器 `free`。回调还需规定线程、重入、异常是否允许越过边界以及上下文何时失效。

Rust 的 `repr(C)` 和 C++ 的 `extern "C"` 各解决一部分布局或链接问题，不等于把全部对象语义转换成 C。字符串编码、错误表示、所有权和版本协商仍要单独设计。

## 版本差异怎样学习，而不是怎样追新

主线先掌握 C17 的明确契约。C23 的 checked arithmetic、类型推导相关语法、`nullptr`、二进制字面量等变化应在工具链与标准库支持矩阵中单独试验；编译器接受某个特性，也可能只是扩展模式。编译参数写明标准模式，避免无意依赖扩展。

更进阶的工作包括安全编码规范、静态分析、形式化契约、fuzzing、性能剖析和构建供应链。它们不取代语言基础，而是把“我认为没问题”变成可检查的证据。

## 结课任务与判据

实现一个读取 UTF-8 文本文件、统计 ASCII 单词频率、按频率排序输出的工具。明确非 ASCII 如何处理，拒绝超长输入或用有界增长策略处理；哈希表拥有键，排序数组只借用键；全部失败路径可清理；空文件、重复词、超长词、分配失败都有测试。

合格标准不是输出几个词频，而是能解释：每段内存由谁拥有；分配长度为何不会溢出；比较器是否满足契约；文件关闭失败如何报告；扩容后哪些指针失效；多文件构建如何重现。配套回归实验从这些可验证的不变量入手，不把示例当作生产工具的完整替代。
