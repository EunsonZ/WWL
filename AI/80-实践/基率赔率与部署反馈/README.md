# 基率赔率与部署反馈：有限模型复算

这里的合成总体用于复算数学关系，不估计真实检测率、部署效果或社会机制。所有脚本仅用 Python 标准库，读取同目录输入、向标准输出报告，不访问网络、不改数据。普通 CPU 足够，不需要训练模型。

## 先验赔率修正

主解释在[[AI/10-机器学习与深度学习基础/17-概率校准保形预测与分布偏移#纯标签偏移下的赔率修正|校准页]]。输入 [label_shift_inputs.json](label_shift_inputs.json) 固定源/目标基率、TPR、FPR 和一个改变 FPR 的目标；[label_shift.py](label_shift.py) 用精确分数按赔率推导输出两端后验。脚本限定内点，端点边界由正文 Bayes 解释承担。

在本目录运行：

```bash
python3 -B label_shift.py
python3 -B label_shift.py | python3 -B verify_label_shift.py
```

第二个程序 [verify_label_shift.py](verify_label_shift.py) 不导入第一个程序的函数，直接从源200例和目标100万例的整数混淆矩阵计算后验；AUC枚举正负配对的胜负与半权重ties。这是与赔率路线不同的计算核对，并不代替非作者对假设和论证的独立审阅。

预期：告警 `90/91 → 10/121`，未告警 `10/109 → 10/98911`；两总体AUC均 `189/200`；改变目标FPR至 `1/50` 后告警后验 `5/116`。这些整数是精确总体比例的表示，不是实际抽样数据。

迁移时先独立修改输入，再明确oracle的总体表是否相应更改。不能改了输入、继续用旧固定oracle失败，就宣布公式错误；也不能只改预期值让程序通过。运行输出、独立审阅、真实检测、Obsidian显示与真人学习分别记录；文件存在不表示任何运行已完成。

2026-10-09已对固定输入实际执行，两个后验分支、二值分数AUC和FPR改变反例均通过精确oracle；独立实跑记录、原始输出、输入与环境见[[AI/80-实践/基率赔率与部署反馈/实验结果-20261009/README|2026-10-09实验记录]]。该记录不包含训练、未知先验估计或真实部署。
