# 耦合热状态复算

本实验只用Python标准库，单进程、串行运行，主要运算为2×2/4×4矩阵和有限RK4轨迹；不安装依赖。x/x̂/测量误差单位K，功率偏差W、时间s；真实集中参数、执行器和仪器条件未测。真源为[coupled_state_lab.py](coupled_state_lab.py)，笔记内[[控制论/80-实践/02-耦合热状态/code-sync/coupled_state_lab|源码镜像]]逐字相同。

## 实际执行与固定输入

基准是两个C=10 J/K节点，环境散热h=1 W/K、内部耦合κ=1 W/K。单输入B=[0.1,0]ᵀ K/(W·s)、单输出H=[0,1]，连续K=[4,4] W/K、L=[0.9,0.6]ᵀ s⁻¹。名义原点调节：x₀=[1,0] K、x̂₀=[0,0] K、d=n=0，无饱和、无延迟。另有无估计器的全状态参考r=0.5 K和常值测量偏置n=0.1 K两个独立案例。

连续输出反馈的RK4分别用dt=0.2、0.1、0.05 s，20 s终值对照4×4缩放平方Taylor矩阵指数，最大温差坐标差依次3.86×10⁻⁹、2.33×10⁻¹⁰、1.43×10⁻¹¹ K。两种算法的方程坐标不同：RK4直接推进真实温度与估计，矩阵指数推进温度与估计误差，因而能检查误差符号与右上BK块。小型矩阵指数只承担本固定矩阵的浮点对照，不认证任意病态或高维矩阵。

对象保持另用原二维ODE独立核对A𝒹/B𝒹：从x=[0.7,−0.2] K、保持u=2.3 W、d=0，积分1 s；RK4细分1、2、4、8步时与模式解析保持模型的差依次1.36×10⁻⁶、7.53×10⁻⁸、4.43×10⁻⁹、2.69×10⁻¹⁰ K。这只支持给定恒输入积分。连续观测器积分步长与数字采样周期分别记录，不能把缩步后曲线稳定作为采样闭环证明。

## 预测之后改变一个条件

1. 对两输入两输出热模型，要求平衡x*=[2,1] K，分别求u*。若限制第二路只能u₂=0，该目标是否仍可保持？
2. 去掉热耦合κ，仍u仅进入节点1、只测节点2。x₀=[1,0]、无输入时，输出曲线是否能认证x₁已为零？观测器L能把漏看的模态极点改成−0.6吗？
3. 本单输入连续全状态反馈K=[4,4]，如果同样Ts=1 s的程序保持旧一拍命令，是否仍能引用无延迟的两个极点？请给增广状态及矩阵。

> [!question]- 题解
> 1. u*=[[2,−1],[−1,2]][2,1]ᵀ=[3,0] W，符合当前平衡关系x₁=2x₂，第二路固定0仍可保持；把目标改成[1,2]时需[0,3]，不能省掉第二路。每路还要检查实际功率/线性范围。
> 2. κ=0时节点1按e⁻⁰·¹ᵗ衰减，节点2输出一直0，读数没有认证第一温度恰为零。A−LH的第一模态−0.1保持不可观，L不能任意更改它；它原本稳定，所以仍可检测。
> 3. 令寄存命令dₖ单位W，实际本区间用dₖ、下一拍设dₖ₊₁=−Kxₖ。增广[xₖ,dₖ]∈ℝ³，矩阵[[A𝒹,B𝒹],[−K,0]]，块分别2×2、2×1、1×2、1×1；必须另外检查它的极点。时间模型已经不同，无延迟2×2结果不适用。此题只交模型，不宣称已执行该延迟变体。
