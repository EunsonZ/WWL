# 制度沙盘的成本、容量与纠错证据

一项规则写明“两小时内保护”，文书也准时签出，为什么人仍可能没有拿到药、见到律师或住进临居？最容易漏掉的，是从规则到个人结果之间的人、钱、专业权限和连续时钟。古国制度沙盘提供了可以反复追问这些缺口的虚构案例：审议者提出反例，作者修改规则，裁决者认可文本，同时保留真实资源的阻断。

原件入库后的静态检查发现，历史总督最终裁决簿152处相对路径漏了`01_制度沙盘/`层，原稿的`review_date`也混用文本和日期。冻结原文保留这些缺陷，历史报告中的链接PASS不代表本轮链接全通过；从 [[Clippings/古国制度沙盘/制度ID阅读索引|制度ID阅读索引]] 进入152份实际正文，并按ID查共同终裁表。下文的章节链接另按本库实际路径核对，形式可达仍不证明成本、能力或服务结果。

本页把三组实际存在的制度ID接成阅读链，随后接回财政、劳动、组织、伦理、因果和操作系统主解释。读完应能给同一个案例分别写出“规则成立”“费用口径成立”“资源可用”“个人结果发生”各自需要什么证据，并指出哪个问题仍未回答。

> 古国、衡域、机构、圭及两小时／四小时等期限都是虚构设定，不能用作现实法定标准。v1.1包内的终审日期为2026-08-19；本页在2026-10-09静态读取接收原文。历史报告自述运行过验证器、读取过Catalog与成本JSON；本次收到的325份实物全部为Markdown，没有这些程序和独立JSON，不能重现它们的执行结果。本页没有运行包内脚本、实验、测试或模拟，也没有完成现实部署、客户端预览或真人试读。

## 先分开四种“闭环”

| 所说的闭环 | 足以支持它的对象 | 不能由它推出 |
| --- | --- | --- |
| 文本与权限 | 规则对象、授权、决定者、失败分支和复核入口互相一致 | 人员已到岗、钱已付、决定能落地 |
| 费用口径 | 同一经济费用只计一次，增量与共享分摊边界明确 | 共享资源足够、成本是真实报价 |
| 容量与排班 | 同人同资产的时段占用、技能、地点、休息、替补、需求和普通服务挤出可核 | 每个案已经按时完成 |
| 个人结果 | 对象本人可复核的到账、会见、治疗、入住、到货或实际释放 | 因果效果已识别、规则已经正当 |

这个区分使“纠错”具体起来。纠正文本可避免明知无权仍下令；共享登记可暴露冲突；停止新增不利行动可限制缺资源时的损害；个人端核验则能发现文书已经走完而生活没有改变。每一层都有用途，也都存在自己的失败方式。

```mermaid
flowchart LR
    Q[质询提出具体失败] --> A[答辩承认或反驳]
    A --> T[核当前正文与元数据]
    T --> V[裁决注明可关闭的范围]
    V --> R[独立复核与残余问题]
    R --> E[另取付款 实班 收端证据]
    E --> Q
```

图中的箭头是取证顺序。找到后一个文件，不能自动证明前一个问题已经解决；要比对同一对象、同一时钟、同一费用和同一状态。

## 案例一：律师接触和医疗为何不能等到事后

案例ID为`GG-RGT-004`人身自由、`GG-JUS-002`短时留置、`GG-JUS-010`律师接触、`GG-JUS-013`法律援助和`GG-JUS-014`羁押医疗。最初的瓶颈是时限彼此不相容：控制只有四小时，某些远程或到场承诺却晚得多；“已转介”又可能被当成按期保护。

按下面五步读原文，每一步都回答不同问题：

1. **质询具体攻击什么？** [Q1]的B-03指出最初四小时内的健康筛查、红旗升级、律师与口译真空；I-03同时攻击丁层多急案对同一人员车辆的争用。它列出了首控、临床、接通、转运和释放时间戳，质询可以被事实反驳。
2. **答辩改了什么？** [A1]的B-03补十五分钟筛查、红旗三十分钟场所外临床判断；[A1b]的C-RT-02规定转场、换班、换名和所谓自愿谈话都不重启首次事实控制时钟。C-RT-04明确撤回“已实现唯一排班表”，改写共同登记规则。
3. **当前正文是否仍这样写？** [T1]第三、四节把筛查超时释放、红旗转医、缺口译／律师释放分开；转医不能代替律师或口译。[T1b]第五节由中立登记台维护`REG-JUS-CAP-001`，三个制度读各自权限视图；同人或资产同刻重叠即无容量。
4. **裁决究竟允许什么？** [V]第五节的`GG-JUS-002/010/013/014`行只签文本PASS、仍为提案；真实值守、律师／口译／临床、纸路、释放执行及收端未证，G2 HOLD，G3与全国扩围RETURN。
5. **独立核对到哪一层？** [R1]第三节、第五节及§6.3核这些制度的文本分支和登记范围；[R1f]§12.4强调登记台仅统一JUS010/013/014占用，不能覆盖全部司法业务，也未证明实班或融资。包级[RF]第四、六、八节保留相同边界，并非每ID一份收端复核记录。

规则改变的收益，是让缺专业服务时的安全退出可解释，减少部门通过换称谓延长控制的空间；代价是不能靠收件速度装作服务成功，真实缺员会显露，非核心业务可能延后。拒绝应给理由、替代和复核时点，但拒绝本身不能放进“已会见”或“已治疗”的成功分子。

**接回权力与问责主解释。** 先读[[社会科学/40-公共政策与社会学/10-政治制度公共决策与问责#问责要有后续动作|问责的说明、审查、纠正三层]]，再回到本案分别填谁有决定权、谁执行释放或专业服务、谁记证、谁能要求纠正。保密律师和临床有专业边界；登记台能拒绝重叠占用，却不因此获得裁判、医疗或付款权。自己的读后产物应是一条完整责任链，而不是多列几个机构名称。

## 案例二：寒夜供热中断，谁能要求原班返险

案例ID为`GG-LAB-009`停工权与事故调查，以及`GG-CIV-008—013`电、水、燃热、轨路和公交通行。供热泄漏时，劳动者停止危险工序，居民仍需要最低供给。两条要求同时有理由，却可能竞争唯一的防护装备和替代班。

1. **质询：** [Q2]的`LAB-X-02`攻击双重调度和重复费用；劳动机关安排公用事业替代班，可能越权，双方也可能因相互等待而都不执行。KEEP-02要求保留工人停工和不返险。
2. **答辩：** [A2]的`LAB-X-02`把劳动保护官的权限限于停工、反报复、工资准入、证据和安全替代任务；居民供给另开CIV服务号，由合法运营者或已授权应急执行者决定和执行。劳动成本只保劳动增量，共同资源通过CIV父键关联。
3. **正文：** [T2]第三、四节继续保留上述分权；第五节明确劳动增量不包含居民供给人车燃料防护夜班，第十六、十七节要求双方联合原班表，重叠和强迫返险都失败。正文给的是待申请条件，未证明这张真实原班表已存在。
4. **裁决：** [V]第五节`GG-LAB-009`及`GG-CIV-008—013`各行均文本PASS；工资／替班、实班、付款和外部收端继续待证。LAB009即使写了“场所与班次级G2候选”，也未取得实体认证。
5. **复核：** [R2]第四节“102根行、动态项目账与父键的去重语义”、第八节“执行、付款与到场容量”及第九节LAB009行核LAB009/CIV共享分界、实际容量仍未核；包级[RF]第四、六、八、九节维持分权和HOLD。本页没有把另一些仅审LAB004／014的窄复验报告移作LAB009的直接签收。

这一修订使工人不返险和居民最低供给分别找到负责链，但它不能凭文字造出另一套防护装备。若没有安全替班，行业链须缩减非核心服务或给具体拒绝，劳动保护仍保留；“居民有需要”不能直接成为劳权机关命令原班返险的权限来源。

**接回劳动与家庭归宿。** [[社会科学/20-经济流动与宏观/08-工资劳动关系税费与生活成本#从个人到账到家庭生活|工资到家庭资源]]已经区分到手现金、消费、还本、公共服务和时间。用于本案时，分别记录停工工资是否到账、家庭是否增加照护或交通、居民是否得到供热、普通检修是否挤出。公共账写家庭份额为零，是本沙盘的规范设计；没有收端证据，不能宣布实际家庭负担为零。设备成本减少也不自动等于工人生活改善。

**接回公品与组织条件。** [[社会科学/40-公共政策与社会学/03-外部性公共品公地与集体行动#要解决的问题|竞争性与排他性的辨别]]让我们区分供热服务、拥挤的车辆、防护设备与共享预警信息；“公共服务”不意味着每样资源都是低竞争公共品。再用该页“集体行动为什么不只由人数决定”的交易、监测、执行条件，比较运营者、行业监管、雇主与居民的责任。读后应能说明哪一困境需要协调，哪一种资源不能同时给两队，以及谁有安全执行条件。

## 案例三：同一灾害仓车为什么被记成两份新增能力

案例ID为`GG-WEL-016`灾害救助、`GG-SEC-008`关键供应链储备与紧急配给。最初疑点不是缺一串编号，而是两根D级增量可能把同一灾需、配给、执行、异核四席和共同仓车班次系统各计一次。

1. **质询：** [Q3]§三的`W3-DEF-WEL-01`要求同一灾害行动的共同席位、车辆、库存和付款通道只有一个经济费用与占用，福利专属增量应另拆。
2. **答辩：** [A3]§2.1表保留三项福利增量：现金最低支持、临居收端个案、恢复选择个案；共同四席仓车班系统只归SEC008，WEL016通过`COST-SEC-008`父谱系读取。各年度低中高金额由三组件相加是历史答辩报告；本次没有JSON来逐格重算。
3. **正文：** [T3]第五节仍明写同一共同能力计一次；第三、十一、十四节区分出库装车与实际收到、入住。[T3b]第三、七、十一节进一步规定拒绝单列、家庭库存不算公共库存、家庭不垫送达费。
4. **裁决：** [V]第三节只关闭静态父谱系；第五节`GG-WEL-016/SEC-008`行保留项目九组件、首付、维护、退出、实班与到人交付HOLD，项目登记0行。
5. **复核：** [R3]第十节为国防审查方的独立静态复验，文本／静态成本谱系PASS；[R3f]§5.2及§十一要求真实数量×单价、个案工时、72小时共用资源表与allocation。该报告仍不签经济实质去重。

注意[Q3]和[R3]保留了初审与终局的时间变化；[A3]第六节专门解释旧审阅中一条现在时“双增量重新打开”的残句。读档案要同时看当前正文和后来的复验范围，既不能删旧异议，也不能把已注明的初审句当成最新裁决。

**接回财政合并主解释。** [[社会科学/40-公共政策与社会学/11-税制公共预算与中央地方关系#从收入到服务：两级预算怎样合并|两级预算的内部转移抵销]]展示中央支付与地方收到不能形成两份合并收入。本案换成共享仓车：同一真实费用在合并边界计一次，部门分摊只是说明谁用多少；它不是另一笔新增费用。转移抵销和共享分摊对象不同，不能只因都有“去重”就采用同一算式。

设一个**本页原创的教学反例**：共同安全运输班一班总成本100圭，福利专属交付支持30圭，其他条件固定、不含资本利息与补偿。若WEL记130、SEC又记100，直接相加会报230；同一合并范围的真实费用只有100+30=130。可把共同100分摊WEL60、SEC40，再加福利30，得到90+40=130；分摊份额0.6+0.4=1。不能再把父项100加到130上。若车辆同时被两案占满，分摊费用算对仍没有可用车。这些100/30/60/40只检验核算逻辑，绝非包内金额或现实估值。

## 名义92人池：唯一而不足的手算反例

[R1f]§3.3、§12.3记录`GG-OPN-001—010`同一92人池名义工时分配为18%、8%、9%、8%、10%、8%、14%、11%、8%、6%，合计100%。`GG-OPN-007`正文第五节明确不能按十套、即920人计价。它纠正人数口径，却没有证明全年、全夜、全地域或峰值覆盖。不要与司法`REG-JUS-CAP-001`混同：前者是开放域共享池，后者只覆盖三项司法共享登记。

继续做一个**本页原创、条件已声明的教学计算**：假设这92人每周名义40小时，休假、训练、交接和原岗释放不足使其中20%不可用于这十模块；所有技能与地点暂可互换，不计通勤和夜间差别。名义3680人时／周，可用2944人时／周。若十模块按名义100%安排需求3680人时，缺口736人时。即使把全部需求一次性压到2944，仍未证明某夜需要两个具特定语言技能的同时服务席位能够满足。

更局部地，46衡域每域名义2人，若两人各只有40可用小时，合计80人时／周；假设新增需求是“每域持续一人在岗”，需24×7=168人时／周，至少缺88。持续一席是本反例另加的条件，包内没有证明所有开放模块都必须如此值守；算例只反驳“92个唯一人名足以保证任意连续服务”的推论。它也没有现实劳动法或真实工时含义。

这类计算从数量转向时段是必要的一步，之后还要按技能、地点、最大同时需求、休息替岗和普通服务长尾拆开。历史审计已撤回旧稿“每模块30学时、每人300学时”作为终版训练承诺，本页不把它重新带入成本账。

## 执行能力、公共理由与试点识别各回答一个问题

**文化和组织：谁能让规范持续发挥作用？** [[哲学与文化/10-主题/01-文化政治与组织结构/01-问题重述与四层分析框架#四层分析框架|规范—组织—法律物质—横向社会四层]]用于案例一：权利声明属于规范，登记台与援助组织是载体，稳定财源、专业人员和诉求通道是物质及权限条件，跨域承接涉及横向协作。应分别找证据，不把其中一层的名称当作四层均有能力。该专题含历史待证命题，本页只迁移分析框架，不用虚构古国证明中西历史规律。

**权利和正当性：有能力之后，为什么可要求别人承受？** [[哲学与文化/20-论证知识与规范/02-伦理与政治正当性#从道德评价走向强制权力：还缺一层理由|向受约束者辩护]]要求回应最强反对。用灾援案练习：支持按需求优先者，可说明生命健康与同等地位；反对一套具体排序者，可提出普通低收入居民被挤出、数据泄露与退场后的风险。再查较少侵入替代、负担分布和复核。双方都要给经验前提和规范理由。组织存续、多数同意或实际到货，均未独自回答这一问题；[RF]第六节保存的七组少数意见仍是可继续争论的材料。

**试点和因果：结果是否由这项改变造成？** `GG-TRN-006`[TP]第三、五、十、十四节要求预注册、分层样本、处理窗口、额外资源、跨点转案、样本流失和独立分析。[TP]的这些规则是虚构设计，包内没有现实试点数据。沿[[社会科学/10-共同工具/03-因果图反事实与识别#先固定单位、时点与目标总体|单位、时点与目标总体]]，为案例二定义单位“场所与班次”、处理“停工保护与独立安全替班的具体版本”、结果“人身伤害与居民最低供给分别记录”、目标“指定能力层的候选场所”。资金援助、外援队伍或复杂案件外移若只发生在处理点，就可能改变处理版本或反事实；共享车被调往试点也可能伤害对照点，不能默默假定无干扰。

本页给的研究接口，是分别保留最初分配和实际接受口径、登记额外资源与原案号、报告主指标和护栏及等待尾部，再根据实际资料选择设计。它尚未识别任何改革净效应；即使局部效果成立，也须另论外推到弱域后的技能、财源和需求变化。

## 操作系统资源分配的有限类比

制度ID和程序对象都能帮助避免身份混乱，共享资源也都需要记录已分配与可用量。但社会中的服务不是可以任意暂停、回收和归还的计算任务，人的权利不会因优化吞吐自动改变。

| 具体命题 | 本案怎么检查 | 操作系统知识能提供什么；哪里停下 |
| --- | --- | --- |
| 前置关系无环 | 制度`dependencies`可拓扑排序 | 前置图无环不等于实际人车等待图无环 |
| 无重复占用 | 真实人／资产、同一时段和地点核占用 | 类似互斥不变量；唯一字符串仍可能给同一辆车起两个名 |
| 容量足够 | 可用人时、技能、同时需求与截止时间 | 可用量和最大需求应分别给；人时总额不证明夜间覆盖 |
| 无饥饿 | 普通阅卷、工资案、维修的最长等待与挤出 | 平均等待改善仍可能使某类长期无服务 |
| 排序正当 | 自由、生命、儿童、住居与普通服务的公开理由和异议 | 算法本身不决定该价值顺位是否应被接受 |

先用[[计算机知识/20-操作系统/02-操作系统原理/10-系统课程/04-死锁银行家与资源分配#银行家算法用未来最大需求换取保守保证|银行家模型]]区分可用量与未来需求，带回“若最大需求未知，安全保证依赖什么”的答案；再用[[计算机知识/20-操作系统/02-操作系统原理/01-进程线程调度与定量指标#不同指标会选出不同策略|调度指标与饥饿反例]]，检查案例一优先急案后普通服务尾部。银行家算法假设未来最大需求已知、资源完成后可归还；不可逆伤害、专业人审和最低权利不满足这些简化。因此本页只借它们区分证明对象，不推荐把某操作系统算法直接用作权利分配器。

## 财政边界为什么仍然HOLD

[RF]第八节与[R3f]第一、十、十一节记载：139固定成本根均是估算（C级15、D级124），项目登记0行，预算行、余额、合法承诺、实付、首付和稳定抵补未形成；G1认证点位0、G2实体认证0。这些是历史报告锁定的快照，本轮没有账本JSON和现实支付系统，不能把它们当今天重新核过的政府财务。

历史第3年高位为15140亿圭，名义线17920。手工检查20%缓冲得到15140×1.20=18168，超过248；25%得18925，超过1005。这里仅复核报告中三数的算术，不重跑成本模型，不验证15140、17920或缓冲比例的经验依据。为了过线临时挑10%或15%不能补足适用缓冲的证据。[R3f]明确要求分期、缩围或升级证据。

五闸分别涉及第3年1.6%、第10年3.8%、债务92%、利息17%、弱衡域8%的设定，分子、分母、时期、来源和等级各自要核。总额没超过某一线，不能替其他闸签收；宏观总额较小也可能掩盖弱域配套或普通服务挤出。资本、运维、利息、补偿、替换、退出和或有责任应核各自经济边界，项目空账尤其不能解释成零成本。
