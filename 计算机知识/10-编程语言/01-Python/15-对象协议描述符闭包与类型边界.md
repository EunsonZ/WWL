# Python 深化：名字、对象、协议与类型边界

> 阅读定位：核心语言与标准库；结构化并发示例需要 Python 3.11+。返回 [[计算机知识/00-开始/课程地图/04-Python-课程地图|Python · 课程地图]]；全域入口 [[计算机知识/00-开始/全局导航/00-总学习地图|计算机知识库 · 总学习地图]]。

## 赋值绑定名字，不自动复制对象

`a = [[1]]; b = a` 让两个名字指向同一个列表。`b = a.copy()` 只复制最外层列表，内层列表仍共享。因此修改 `b[0].append(2)` 也会通过 a 看见变化。深拷贝会递归处理对象图，但是否需要复制外部资源、缓存和身份，仍须由领域设计决定。

默认参数在函数定义时建立，`def f(xs=[])` 会跨调用共享同一个列表。闭包捕获名字绑定，不是为每次循环自动截图；创建回调时需要明确捕获当前值还是未来读取的绑定。`is` 比较身份，`==` 按类型协议比较值，整数缓存和字符串驻留不应成为业务逻辑。

## 协议把语法变成方法调用

`for` 使用迭代协议，`with` 使用上下文管理协议，属性访问涉及对象和描述符协议。实现 `__iter__`/`__next__` 可以惰性生成数据，避免一次性载入全部结果，但一次性迭代器被消费后不会自动重置。生成器暂停保留局部状态，也可能让文件等资源比预期存活更久。

描述符对象通过 `__get__`、`__set__` 等参与属性访问。数据描述符通常优先于实例字典中的同名项，非数据描述符与实例字段的优先级不同；property 和方法绑定可在这个框架里理解。多继承的 MRO 确定查找顺序，`super()` 沿 MRO 协作，不是简单的“直接父类名称替换”。

## 类型标注不是运行时防火墙

```python
def parse_age(value: object) -> int:
    if type(value) is not int:
        raise TypeError("age 必须是整数，且不能是布尔值")
    if not 0 <= value <= 150:
        raise ValueError("age 超出允许范围")
    return value
```

这里刻意用 `type(value) is int` 拒绝 bool，因为 Python 的 bool 是 int 的子类。需要支持自定义整数类型时，应改用更合适的协议并单独排除布尔值，而非把本例当通用模板。`TypedDict`、dataclass、Protocol 和泛型表达不同的静态合同，均不自动验证从 JSON、数据库或网络来的数据。

`__eq__` 与 `__hash__` 要一致：相等对象应有相等哈希；作为键期间改变影响哈希的状态会破坏查询。不可变元组里可以包含可变成员，因此“容器不可变”不等于“整个可达对象图不可变”。

## 进阶知识落点

装饰器是定义时的函数变换，注意保留元数据和可测试性；元类控制类创建，很多任务用普通类或 `__init_subclass__` 更简单。weakref、gc、buffer protocol、memoryview、contextvars、pickle、multiprocessing、C 扩展都有专门用途。不要对不可信数据使用 pickle 反序列化，类型标注也不能使它安全。

练习：用迭代器读取有上限的记录流，用上下文管理关闭文件，再用纯函数校验每条记录。测试空数据、bool 混入整数、嵌套共享对象和中途异常；解释每一步由哪种协议负责。
