# 实践35：良率、热网络与追溯

## 运行与输出边界

本实验从三个问题出发：测试通过品中的坏品概率有多大，同片共同漂移为何不等于差分失配，0.2 W如何在结与板之间积累和散走。初学者先读参数与结果，再改一个参数观察；已有数学基础者先运行测试中的解析对照，再返回正文核查物理对象与单位。

从库根运行以下命令。生成命令必须选择一个不存在或空的新目录；每次复算换一个输出目录，不覆盖本实验已交付资产。`/private/tmp/production-teaching-replay-1`仅为示例，若已经有内容请另选新路径。

```bash
.venv/bin/python -B -m unittest discover -s '电子电路/80-实践/35-良率热网络与追溯' -v
.venv/bin/python -B '电子电路/80-实践/35-良率热网络与追溯/generate_figures.py' --output /private/tmp/production-teaching-replay-1
```

纯模型与10组测试使用标准库。绘图显式调用才导入已存在的Matplotlib/CairoSVG；无依赖时记录无法生成，不自动安装。唯一CLI的`--output`必填，缺参exit2且不生成文件。`generate(output)`拒绝已有非空目录，`main(argv=None)`仅在显式调用时解析参数。导入三份源码不读取CLI、生成输出或加载绘图库。MPL/XDG缓存被限制到显式输出的`.cache`子目录，生成结束或异常都恢复这两个环境变量；绘图参数用`rc_context`恢复。输出不是多文件原子事务，渲染失败会留下该新目录的部分结果，不能当作成功资产。

每次成功生成29个教学数据/图文件：8份SVG及由同SVG渲染的16份360/425 PNG、3份CSV、`parameters.json`和`results.json`。`.cache`仅运行缓存，不属于资产或发布集合。图真源是生成器及明确模型；不另建平行源码镜像。源码直接链接：[模型](production_model.py)、[必要测试](test_production_model.py)、[生成器](generate_figures.py)。

## 概率与有限随机实验

`poisson_yield`仅接受面积0..1 m²、密度0..10¹² m⁻²的有限实标量，返回均匀独立致命Poisson缺陷假设下的无缺陷概率；该范围是API数值预算，非制造规格。`accepted_bad`接受0..1的三条件概率，接受事件浮点概率为0时拒绝。浮点计算不是精确有理数；极小乘积可能下溢，不能据0结果证明真实零缺陷。

`mismatch_mc`采用2..100000个虚拟片、整数种子0..2³²−1、0..0.2的无量纲共同/局部标准差、0..1的阈值。每片抽一个共同G、两个独立局部L。输出全部样本的有限统计，只保存前300个图点；图点不是另一个300片良率估计。独立正态模型的差分解析方差为2σl²，平均方差为σg²+σl²/2，阈值通过概率为erf(threshold/(2σl))，σl=0单独处理。固定种子用于复算，抽样与真实工艺分布的适配未验证。

`zero_failure_upper`只实现零失败、iid二项样本的单侧上界，n为1..1000000整数，α在10⁻¹²..1−10⁻¹²之间。它不是任意失败计数的完整区间工具。回 [[电子电路/54-制造可靠性与生命周期/03-公差失配与良率#有限 Monte Carlo 与零失败边界|公差章节]]解释抽样单位与覆盖意义。

## 热模型与有限求解

同一P=0.2 W、Ta=300 K下，两节点模型固定Cj=2/Cb=8 J/K，Rjb=5/Rba=20/Rja=100 K/W。`thermal_rhs`接受−100..100 K温升、0..0.5 W功耗与0..0.04 W/K反馈。这些是教学域，不是实际器件额定。`thermal_trace`从零温升开始，时间0..200 s、步长10⁻⁵..0.1 s，每次最多20000个RK4步；超过预算明确拒绝。只有这个固定网络的有界稳定域经过测试，不把它推广到任意刚性热系统。

默认200 s的有限轨迹没有宣称已经达到稳态。解析稳态4/3.2 K用水平线标记；反馈g=0.002时解析稳态4.166667/3.333333 K。测试另用特征根的两个指数对照t=0.1、5、100 s，并检查零功率、零时刻、微小时刻与节点能量守恒。

`thermal_grid`是独立二维模型：9×9索引网格的边界为0 K温升，7×7内部节点，邻接热导0.1 W/K，中心注热0..0.5 W。没有指定米制格距、材料导热率或几何校准。Gauss-Seidel每扫后核最大热流残差，容限10⁻¹²..10⁻⁶ W，最多4000扫，不收敛明确失败。测试用不同的离散正弦谱逆解对照4个节点及边界总热流；图箭头仅方向，不编码热流大小。

`arrhenius_factor`只返回寿命比，Ea为0..5 eV、两个绝对温度1..5000 K，指数超出−700..700拒绝。这是有限计算域，真正机制拟合范围通常窄得多；没有标定A和寿命分布就没有绝对寿命。回 [[电子电路/54-制造可靠性与生命周期/04-热可靠性与失效机理#从温度到失效，需要机制和标定|热可靠性机制]]，不要把这里的数值范围当成物理适用性证明。

## 追溯与合规表

`affected_serials`只接受最多10000条有限字典，每条精确包含非空字符串serial/bom/lot，重复序列号拒绝，因为此小工具未实现维修历史多版本数据库。它按原装配批号返回排序序号，保留输入不变；真实追溯系统还需要时间、物料位号、配置与权限证据。本例U001等标识均虚构。

结果的`compliance_reading`保留5 V教学板假设、待核地域、`limits: null`、`test_results: null`与`status: not_run`。这是阅读边界记录，不是已分类产品的认证模板。到 [[电子电路/54-制造可靠性与生命周期/05-EMC安全与合规阅读#先固定产品与地域再找标准|合规章节]]核产品范围、法规与标准版本，再回这里辨认没有执行哪一层。
