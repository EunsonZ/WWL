# 先编码和判断，再核答案

材料是同目录 [完整原材料与两报道](原材料与两篇报道.md)；固定人数记录与复算见 [运行和研究接口](运行和研究接口.md)。所有答案、表达与记录均为合成教学构造，不代表真实受众。

先不看后文答案，完成三件事：一，给A、B标题及各八句段标记哪些问题被突出，区分事实叙述、引述意见与记者提出的评价问题；二，用给定曝光日志复算三种比例，写不能推出什么；三，为T0—T3拟一段有限更正，并说明怎样知道更正是否到达原受众。

## 编码范围与单位

这是对两篇固定材料的穷举，不是对全部新闻的概率抽样。文章单位共2；正文句段单位共16，按原材料页空行编号A1—A8、B1—B8；引语出现单位共4，A3、A4、B5、B6，每条完整直接引语为1次出现。4次引语只来自M3两条原回答，不是4名独立受访者。标题另作位置／命名分析，不悄悄放进句段分母。

句段可同时含事实与意见：A3“张说了这句话”是资料包内的引述事实，引号内“是好事／希望”是张的价值评价，不变成研究者已证的总体好处。A8提出评估维度，不是夜间服务已经造成便利或安静的因果断言。

本次作一套窄操作定义，允许多码，未出现不补码：

| 码 | 纳入 | 排除 |
| --- | --- | --- |
| C 服务可达的评价 | 明说下班可借书是好事，或提出使用更方便的评价问题 | 仅列开门钟点，不自动等同受众已经更方便 |
| R 公共投入 | 明说追加预算金额、上限或实际开支未知 | 只有‘六周／后续’不自动推成资源不足 |
| N 邻里安静 | 明说离馆照顾住户安静或将安静作为评价维度 | 不把提到夜间就自动标为扰民 |
| U 机构延续决定未知 | 明说主管部门尚未决定长期服务／岗位，需评估后决定 | 居民希望早点知后续，不单凭它认证机构实际未决定 |

## 参考编码及真正可争议的一处

| A句段 | B对应 | C | R | N | U | 依据及类型 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| A1 | B2 | 0 | 0 | 0 | 0 | 时段与六周的事实，不按本码表自动算价值评价 |
| A2 | B3 | 0 | 0 | 0 | 0 | 其他日期、座位限制事实 |
| A3 | B6 | 1 | 0 | 0 | 0 | 张的便利评价与后续信息要求；不是机构决定的直接证据 |
| A4 | B5 | 0 | 0 | 1 | 0 | 林的条件性接受及安静要求，不编码为反对开放 |
| A5 | B4 | 0 | 0 | 0 | 0 | 人次计数及去重边界，不直接编码为效果 |
| A6 | B1 | 0 | 1 | 0 | 0 | 预算上限与开支未知 |
| A7 | B7 | 0 | 0 | 0 | 1 | 主管部门明确未来决定程序 |
| A8 | B8 | 1 | 0 | 1 | 0 | 记者待检的双重评价维度；无效果结论 |

**A3／B6确实可争议。** 一位编码者可能把“若只有六周，希望早点说明后续”也标为“持续性不确定”。若研究问题是“读者表达了哪些未来关切”，这是有依据的不同码；若用它编码“机构尚未决定”，就把愿望当事实，超出了当前窄U定义。可以把U改为更宽的“未来关切”，并将居民与机构表达另列；必须修订定义和所有材料后重算，不能只为某篇临时多计一次。本表不声称窄码是唯一正确的传播分析。

竞争解释也需保留：张可能主要在要求透明信息，不在质疑财务可持续；林可能是在有条件支持服务，而非反对服务。若把一切保留意见都标“反对”，编码会制造冲突。应回看完整语句，未来访谈先请其解释原话，不要求他在研究者预设的正反阵营中选一边。

## 换单位，分母和可支持主张都改变

- **文章有无该码：** 两篇都有C、R、N、U，各项都是 $2/2=100\%$。这只说两篇包含过，不等于两框架同样突出、同样被注意。
- **正文句段出现：** C为 $4/16=25\%$，R为 $2/16=12.5\%$，N为 $4/16=25\%$，U为 $2/16=12.5\%$。A、B各自分别为2/8、1/8、2/8、1/8，完全相同；多码并存，比例不要求加到100%。
- **引语出现：** 4次引语中，明确便利评价2次、安静要求2次，各为50%。不能说“受众一半支持一半反对”：它们是相同两条回答各刊两次，码也不是支持／反对。

正文句段分布相同而标题／导语不同，是本对照的教学用处：关键词或频次相同不保证显著性结构相同；反过来，分析者看见位置差异也不能直接宣称读者被说服。码表一致率高只表明按该表评分稳定，不保证捕捉到所有框架，也不认证受众解释。

## 曝光与选择机制的参考答案

A目标1000人，去重曝光100人、去重点击20人；B目标1000人，去重曝光500人、去重点击50人。曝光率分别10%、50%；曝光后点击者比例分别20%、10%；全目标人群点击者比例分别2%、5%。点击者是曝光者子集，故每组有“全目标点击比例＝曝光比例×曝光后点击比例”。A条件点击较高，B总目标点击较高；两句可以同时为真。

一个**与这些汇总数相容的合成选择反例**：两边目标人群各含100名原先兴趣高者和900名兴趣低者。A只曝光100名高兴趣者，其中20人点击；B曝光100名高兴趣者及400名低兴趣者，分别20和30人点击。高兴趣者两边同为20%，低兴趣者B为7.5%，A未观察到低兴趣曝光；假定两边低兴趣者对相同内容有同样反应规律，仍能产生A20%对B10%的条件比例。此反例说明选择构成足以生成差异，不是从原日志识别出真实兴趣类型或证明框架无效；缺乏A低兴趣曝光也阻止直接比较其分层反应。

还需检验相反方向：相同记录能否排除版本效果？不能。令同一个人在固定展示条件下看A或B时“是否点击”各有一个潜在结果；每人现在只观察本次所见版本。下面是两个**明确合成的潜在结果补全**，不是受众数据，也不是已估效果：

| 世界 | 当前A组100名曝光者：看A／假如看B | 当前B组500名曝光者：假如看A／看B | 已观察的两个格 |
| --- | --- | --- | --- |
| W0，无版本作用 | 20／20；可令每个人两版本结果逐人相同 | 50／50；同样逐人相同 | A下20，B下50 |
| W1，有版本作用 | 20／0；可令这20人仅在A下点开 | 100／50；可令B下点开的50人在A下仍点，另50名本来不点者在A下点开 | A下20，B下50 |

未曝光者在两世界的潜在结果也未观察，可选成逐人两版本相同，仍与全部原日志一致。两世界保持合格人数、实际曝光和实际点击不变，却对版本作用给出不同答案；因此原日志观察等价、反事实缺失，既不证明有效也不证明无效。这里固定展示、无跨人干扰只是逻辑反例的条件，不能悄悄认证真实平台满足它们。


**换计数单位。** 若A的100名曝光者合计产生150次展示，20名点击者每人恰好点1次，则按展示事件定义的点击率为 $20/150=2/15\approx13.33\%$，按曝光人定义仍为20%。若“20”只是去重点击者，而每人可多次点击，事件点击率的分子又未知。不能拿点击人数／展示次数的混合比率冒充刚才的人条件比例，也不能擅自默认所有平台的CTR口径相同。

## 有限更正稿与接收边界

**教学更正稿（未发布）：** “更正：T0将‘试开六周后评估’写为‘已经决定永久保留’，T1—T3转载时未另核。现核M1与M4：试开为六周，长期服务及岗位安排尚未决定。因此撤回‘已决定永久’；这不表示已经决定停止。请以本资料包M1、M4原文为准。”

支持范围逐项列清：M1／M4反驳具体决定主张；T1—T3给出传播依赖；未给T0作者意图或政策未来结果，因此不写“证实蓄意造假”或“永远不会保留”。如果转载页后来做了独立核对，它新增的材料另评，不能因早期转载身份一概抹掉。

发布位置和点击数都不等于更正到达／理解。未来应匹配原错误曝光者的去标识ID与更正实际曝光，记录未触达、重复触达、是否打开及能否用自己话区分“未决定”与“已停止”；未见更正的人不能算已经纠正。真实平台可能无法可靠关联身份，届时应报告可观测交集及未知范围，不补造100%更正覆盖。

## 条件改变题及可反驳评分

**题一，新标题。** 保持正文不变，把B标题改为“预算一万二：夜间服务已经花掉多少？”是否可以说B已证明浪费，A已证明便民？能否称纯框架对照？

**答。** 这仍可作为只改标题的候选，但标题可能暗示金额是已花开支；须预试是否造成事实误读，不能从问号推断已证明浪费。A也只含便利评价与待检目标，未识别实际收益。若标题直接改为“已花一万二且决定永久”，就加入与资料相反的新事实，不再是事实同集的纯框架处理。评分各1点：区分显著性与事实（1）、核预算／决定边界（1）、指出两侧效果都未证（1）、给能区分标题暗示与读者实际理解的观察（1）。

**题二，新受众。** B的曝光对象包含大量原本不关注图书馆的人，A只曝光原本收藏借阅信息者。A条件点击高、B总体点击高，哪一个框架说服力更强？

**答。** 不能由现数确定。写清两个分母并保留两个描述；提出前述选择反例或等价情形；比较同一目标受众随机分配后的理解／态度才接近所问框架效果，且需固定显示位置、事实与时间窗口。评分：两个比例对象（1）、具体选择机制反例（1）、不把点击当赞同／理解（1）、对应因果比较及边界（1）。

**题三，三站与更正。** T1—T3一致支持永久保留，馆方M4却说未决定；这是否说明三站的独立民意推翻馆方，又是否只要发一条更正就完成纠错？

**答。** 三站不是独立取证，更不是民意抽样；回到M1／M4的具体主张校正。保留馆方自身来源边界，实际政策另需当前有效材料。更正发布与原受众实际接收、理解分开。评分：已知依赖不重复计证（1）、事实／解释与未知分列（1）、更正只修可证主张（1）、给接收交集与理解核对并承认缺失（1）。

所有分数只是这些题的材料核对规则，不是受众理解量表；当前没有真人答卷、编码者一致率或模型作答效果。允许其他有具体依据的编码／优先证据，不能只凭用了‘框架’‘选择偏差’几个词给满分。
