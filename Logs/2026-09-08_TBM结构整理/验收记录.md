## 复核命令与恢复

在 Vault 根目录运行：

```bash

python3 -m unittest discover -s Logs/2026-09-08_TBM结构整理/tools -p 'test_links.py' -v

```

上述结构验证的成功含义是“没有未解释的新结构错误”，不表示所列历史缺失或 CMake 镜像错误已修复。

恢复脚本默认只预览，并拒绝覆盖验收后发生的用户修改：

```bash
python3 Logs/2026-09-08_TBM结构整理/tools/rollback.py Logs/2026-09-08_TBM结构整理/artifacts/rollback-manifest.json
```

确需恢复时，在预览通过后追加 `--apply`。恢复只涉及本批源路径和产物，不恢复插件配置或任务数据；仍应保留当前工作再操作。

本次使用本机私密备份及逐步写回日志保障可恢复性，没有宣称文件系统级原子迁移或断电持久性。
