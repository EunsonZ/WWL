# 能带与态计数：从预测到复算

## 先预测再复算

读 [[物理/50-半导体物理/01-周期晶体Bloch与Bragg开隙#离开简并点的色散与完整例|二态完整例]] 和 [[物理/50-半导体物理/02-带边有效质量与一二三维态密度#先数 k 格点，再改变变量|DOS 计数]] 后，先写下预测：耦合趋零时交叉怎样恢复？一个有限周期盒在带边有没有态？把三维 DOS 从每 J 改成每 eV，积分得到的电子数是否改变？再检查代码与结果。

在本实践目录运行；源码只依赖 Python 3 标准库，单线程，无外部软件安装或真实材料求解器。

```bash
python3 -B band_dos_lab.py
python3 -B -m unittest -v test_band_dos_lab.py
```

源码真源：[band_dos_lab.py](band_dos_lab.py)；回归：[test_band_dos_lab.py](test_band_dos_lab.py)；可再生输出：[results.json](assets/results.json)、[避交图](assets/bragg-gap.svg)、[不同维度 DOS 图](assets/dos-dimensions.svg)、[占据谱图](assets/occupied-spectrum.svg)。脚本只在自身 `assets` 目录写这四种结果，数值参数、单位和积分条件保存在结果文件中。定量图由同一源码同例参数生成，不手改坐标或曲线。

## 当前算例怎样核对

区边自由能量 $E_0=1.5041206484\,\mathrm{eV}$，本征值 $1.4541206484$、$1.5541206484\,\mathrm{eV}$，隙 $0.1000000000\,\mathrm{eV}$。在 $\kappa=0.020\,\mathrm{nm^{-1}}$ 时能量 $1.4532272372$、$1.5550445395\,\mathrm{eV}$，平均值有 $\alpha\kappa^2$ 改变，不能仅把区边上下常数往外平移。

独立的抛物带例用 $m^*=0.2m_0$、两自旋、单谷，周期盒每边 $L=200\,\mathrm{nm}$，能窗 $0\le E-E_c\le0.050\,\mathrm{eV}$。直接枚举 $k_i=2\pi\ell_i/L$，与连续球体积估计比较：

| 维度 | 有限盒整数态数 | 连续 DOS 积分对应态数 | 相对差 |
| --- | --- | --- | --- |
| 1D | 66 | 65.230191 | 1.1801% |
| 2D | 1690 | 1670.925883 | 1.1415% |
| 3D | 36074 | 36331.604851 | 0.7090% |

整数计数含带边的 $k=0$ 态，连续估计不单独保留这一孤立点。把盒子扩大应使相对差整体缩小，但格点穿过球面会产生壳层跳变，误差不必随每次尺寸增加都单调减小。二维的盒面积、三维的盒体积已分别乘回，表中比较的是总态数，不是把三种密度混为同一单位。

同带的 $T=300\,\mathrm K$、$E_F-E_c=-0.100\,\mathrm{eV}$ 下，$N_c=2.2444865323\times10^{24}\,\mathrm{m^{-3}}$；MB 解析积分给 $n=4.6901954609\times10^{22}\,\mathrm{m^{-3}}$，FD 数值积分给 $4.6559330076\times10^{22}\,\mathrm{m^{-3}}$。用 FD 作分母，MB 密度相对高估 $0.735888\%$。这是积分误差；带边点态的 MB 相对误差约 $2.08965\%$，二者不等。

数值积分用 $\varepsilon_{\mathrm{eV}}=t^2$ 消除平方根端点的斜率奇性，再用中点法：20,000 小区间，能量上限 $1.0\,\mathrm{eV}$。本次把区间数减到 10,000，以及把上限扩至 $2.0\,\mathrm{eV}$，变化到约浮点舍入尺度；它是此参数下观察到的稳定性，不是任意温度/化学势的通用误差上界。测试另用负化学势下收敛的独立级数

$$n=N_c\sum_{j=1}^{\infty}\frac{(-1)^{j+1}e^{j\eta}}{j^{3/2}},\qquad \eta=\frac{E_F-E_c}{k_BT}<0$$

对照 FD 积分。此式由 $f=\sum_{j\ge1}(-1)^{j+1}e^{j\eta-ju}$ 后逐项积分所得，测试取前 24 项；本例 $e^\eta\approx0.0209$，余项远小于比较容差。$\eta\ge0$ 时不能继续使用这条级数作为 oracle。

## 不同检查各自说明什么

六项回归核对：复耦合二态特征向量残差、零耦合自由分支、可手数的整数格点、DOS 与累积态数的导数/一维可积奇点、独立 FD 级数与 MB 积分、单位和参数边界。每个检查对应一个可能的物理误解；结果不认证模型适用于真实硅或任何待测样品。

半引导变化：只改变 $g_v$ 或质量，先写态数缩放；再改变盒边长，比较有限计数的壳层变化。撤提示选择：把化学势移入导带、把能窗缩到能级间隔以下、把样品限制成只有一个受限子带，各自先选占据/离散/维度模型，再计算；原脚本的默认三维 MB 结果不会自动替你选择正确模型。解释性答案在 [[物理/50-半导体物理/02-带边有效质量与一二三维态密度#参数变化与撤提示选择题|第二课迁移题]]；回到 [[物理/50-半导体物理/00-半导体物理-MOC#首段的迁移终点与边界|课程终点与边界]] 时，应说明还缺哪些统计、散射和接触参数。

## 常数、模型和验证边界

使用 SI 精确定义的 $h,e,k_B$ 与 CODATA 2022 自由电子质量 $m_0=9.1093837139\times10^{-31}\,\mathrm{kg}$，常数来源为 [NIST CODATA 表](https://physics.nist.gov/cuu/Constants/Table/allascii.txt)。有效质量 $0.2m_0$、晶格常数和势系数为教学指定。两个独立模型分别是一维弱周期势二态和三维抛物带，未声称共享一个自洽材料 Hamiltonian。
