# 频率、状态与边界的复算

读者问题：端口扫频相同，能否由图证明初值、收敛域和所有内部状态也相同？本实践把四篇的同参数算例放进一个数值单元，分别用积分、物理方程和状态模型复算。它是解析模型与数值检查，不是SPICE、实体扫频或人已掌握的证明。

RC固定R=1000 Ω、C=1e−6 F、τ=.001 s，开启余弦初值v0=.4 V、峰值1 V、ω=1000 rad/s。RLC固定原串联R=50 Ω、L=.01 H、C=1e−6 F，ω0=10000 rad/s、ζ=.25。主动隐藏反例状态/输入/输出均无量纲、矩阵A/B单位s⁻¹；它不是无源RC的内部运动。

## 安全复现与输出位置

从本目录运行以下命令；使用已有Python环境，依赖NumPy，图的显式生成另需已有CairoSVG。缺依赖时记录未运行，不自动安装。可以使用主库已有`.venv/bin/python`替换python3，本文不安装SciPy。

```bash
python3 -B -m unittest -v test_frequency_state_lab
OUT_DIR=$(mktemp -d /private/tmp/wwl-freqstate-output.XXXXXX)
python3 -B build_visuals.py --output "$OUT_DIR/assets"
```

`frequency_state_lab.py`提供解析RC、二阶频响、物理/归一化A/B/C/D、隐藏模型和rank矩阵。`build_visuals.py`提供`generate(output)`和`main(argv=None)`；必须显式`--output`，缺参退出2且不生成目录。导入不解析调用者argv、不加载CairoSVG、不创建缓存目录/图件。上述命令使用新库外临时输出；显式路径是生成授权，使用者应给自己的新目录。

所有频率输入按rad/s，CSV另列Hz=ω/(2π)，不得混用。数值接口接收有限实标量（拒绝bool、字符串、NaN、Inf）、正R/L/C、正ω0与ζ，时间须非负。RC频响可接受负频率以检验实核对称性；渐近dB限正频率；zero_pair的开关选择左右半平面零。状态模型输入需正确shape、有限值。派生乘积/相位/矩阵/幅度不可表示时明确拒绝；这不是任意极端参数的高精度库。默认浮点rank只作演示，正文给两状态精确非零行列式，不把容差判定当实体可辨识证明。

## 每项数据兑现什么

- `frequency-data.csv`：401个10–100000 rad/s对数样点，列ω、Hz、RC实虚部/dB/相位/渐近dB、RLC dB/相位及左右半平面零的dB/相位。角点ω=1000的RC为.5−.5j、−3.01029995664 dB、−45°；RLC在ω=10000为−2j、+6.02059991328 dB、−90°。
- `time-data.csv`：501个0–5 ms等间隔样点，RC开启余弦电压、RC阶跃电压、两个主动隐藏状态及两种零的1 V阶跃输出。初点分别.4 V、.4 V、0、0、+10 V、−10 V；t=.25 ms余弦输出.5302781121754433 V；t=5 ms隐藏x2≈147.4131591026。
- `parameters.json`：物理参数、输入初值/单位、零/极点/直通、比较阻尼与失效曲线参数、主动模型说明、图名单、425画布和360/425预览宽度，图中理论与比较曲线有各自标签。
