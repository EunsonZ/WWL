# C：并发、未定义行为与进阶知识边界

> 阅读定位：C17 核心；扩展和标准版本差异单独注明。返回 [[计算机知识/00-开始/课程地图/01-C语言-课程地图|C语言 · 课程地图]]；全域入口 [[计算机知识/00-开始/全局导航/00-总学习地图|计算机知识库 · 总学习地图]]。

## 编译器承诺的不是“照着源码顺序搬运字节”

语言允许编译器在保留规定的可观察行为前提下优化。未定义行为意味着语言不再对结果作通常保证，不能拿“我本机输出了某个值”证明正确。典型风险包括越界、悬空访问、有符号溢出、错误对齐，以及违反类型访问规则。未指定行为允许多个结果且未必要求记录选择；实现定义行为要求实现说明其选择。这三类不能混用。

用字符类型观察对象表示与通过任意不兼容类型解引用是不同操作。`memcpy` 可用于在满足大小等条件时复制对象表示，不应随意把一个未对齐字节地址强转成结构体指针。`restrict` 是关于特定访问路径别名的强承诺，不是装饰性优化关键字；违反承诺可令优化后的结果出错。

## 原子性、可见性和顺序分开问

两个线程同时无同步地访问同一非原子对象，且至少一方写入，可能构成数据竞争。`volatile` 不提供互斥，也不建立线程间 happens-before。它主要约束某些可观察访问的优化，硬件寄存器等还受平台规则约束。

一个发布模型是：生产者先写普通数据，再对原子标志做 release 存储；消费者用 acquire 读取到相应发布后，才读取数据。同步关系负责把此前写入安全地传递给读取者。只有“标志位用原子”但读到的不是那次发布，或发布后仍并发修改数据，都不能据此证明安全。

初学并发优先使用互斥锁和条件变量，把“共同维护什么不变量”讲清。`memory_order_relaxed` 可适合独立统计计数，却不能自动发布其他对象。lock-free 不等于 wait-free，也不等于在你的工作负载中更快。

## 不应遗漏但可后学的主题

位域节省声明空间但布局和跨平台序列化需谨慎；联合体复用存储，具体读取规则须按 C 标准而非套用 C++；柔性数组成员适合头部加变长尾部，需要检查总分配大小；VLA 的可用性与栈资源要按标准版本和实现核对；复数、浮点环境、宽字符和多字节转换用于特定数值与国际化场景。

`setjmp`/`longjmp` 是非局部跳转，可能绕过普通资源清理，且部分局部变量的值规则需要特别注意。信号处理器只能调用符合相应安全约束的函数，不能把普通应用代码搬进去。线程库、原子库、静态断言、对齐控制、属性、嵌入式 freestanding 环境、动态链接、FFI 都属于完整 C 工程地图，但平台支持与可移植核心必须分开。

## 验证顺序

先写契约与测试，再启用警告和适当的 AddressSanitizer、UndefinedBehaviorSanitizer；并发竞争另用合适工具。不同检测器可能不兼容，且没有报警不代表无误。审查输入到长度计算、长度到分配、分配到索引、资源到销毁四条链，往往比继续增加零散语法题更有效。
