# 项目现金流与融资现金流：先问创造了什么，再问谁付钱

一个项目今天投100、一年后确定收到132，机会成本10%，融资前净现值是20。借来50，是否又多出50的项目价值？没有。借款改变今天由谁提供资金，也附带明天的偿还；它不会自己长成销售收入。若为取得融资多付2，则发起者少留下2，但还要指出谁收走它，不能把企业成本直接当全社会价值损失。

现有 [[社会科学/30-金融市场与风险/09-AI投资现金流与需求口径校注#2. 一份成本只能扣一次|现金流校注]]已经说明成本去重，[[社会科学/30-金融市场与风险/03-股票所有权现金流与估值#2. 从企业价值桥到每股权利|经营价值到股权的桥]]已经划清现金与债权。本页补可连续完成的决策：建立增量税后项目现金，分列融资支付，选择估值口径，再在互斥、预算和风险变化下重新选项目。

金额均为同一名义货币单位，0为决策时点，1、2是年末；折现率是年有效名义率。所有小额数字都是合成项目。当前目标是**增加决策者可取得的项目净市场价值**，不是用NPV自行决定员工、客户、环境或社会正当性。项目机会有限，不能无限按成本复制并立即出售；正NPV不是一个可无限重复的金融套利。

## 同一项目，四张不许混写的现金表

先取确定性、无税/费用、无违约、可同率借贷的环境。项目在0支付100给供应商，在1从客户收132；这两个经营/投资金额不因融资变化。机会成本 $r=1/10$，故0期资产价值 $132/(1+r)=120$，与投入100之差20。项目收益权在投资后值120，不等于发起者在0必须实际投入120。

借款本金 $L=50$，1期偿还 $H=(1+r)L=55$。现金从各权利人视角记正负：

| 对象 | 0期现金 | 1期现金 | 本表在问什么 |
|---|---:|---:|---|
| 融资前项目 | −100 | +132 | 经营机会的增量价值 |
| 债权人 | −50 | +55 | 放出与收回融资 |
| 股东 | −50 | +77 | 补足投资后拿剩余 |
| 公司内融资收付 | +50 | −55 | 资金来源/偿还，不是项目收入 |

0期股东50与债权人50共同交给供应商100；1期客户132拆成债权人55、股东77。每个日期都对上，才可谈估值。债权人的NPV为 $-50+55/1.1=0$；股东为 $-50+77/1.1=20$。末期77的股权市场价是70，实际出资50，差额20仍来自项目机会；按出资算77/50−1=54%，并不是市场资本成本。这里股东现金也确定，所以可用相同10%；不能据此把不确定股权的要求回报永远固定10%。

若在0另付融资服务费 $F=2$，股东要投入52，末期仍收77，股东NPV降为18。服务商在0收到2；从项目及出资者这个评价边界看是新增成本，而不是凭空消失的金额。若要评价社会资源损失，须另查服务商实际消耗、外部影响与福利权重。

一般地，在同样的确定性公平融资条件下，股东0期投入 $I+F-L$、1期取得 $X-H$，从**每期守恒**与 $L=H/(1+r)$ 得

$$NPV_E=-(I+F-L)+\frac{X-H}{1+r}
=\underbrace{-I+\frac X{1+r}}_{NPV_{project}}-F.\tag{1}$$

这不是借三遍相同NPV公式自证融资无关：关键独立前提是合同公平价、经营支付不变和逐期 $X=H+(X-H)$。若债券售价与所给支付不匹配、经营选择因负债变化或需要违约成本，抵销便不成立。利息也不是“一律不可计”：融资前项目现金不扣利息，再用匹配的经营资本成本；股权现金则扣债务收付，再配股权成本。混搭才会重复。

## 从工作流到增量税后现金：完整两年例

[[社会科学/20-经济流动与宏观/15-资源受限科技创业与单位经济#可靠工作流的单位贡献：降模型价格可能只改变一小项|单位贡献]]只覆盖定义内的直接成本，尚不含设备、税、回款与营运资金。现在另建一个确定性两年项目，不改变原页已有任务/质量分母，也不借原案例的真实经营数据。

每年容量 $q=200$ 个合格任务，售出率 $(u_1,u_2)=(1/2,11/20)$，每付费任务价格1、付现变动成本 $1/5$，每年固定付现成本20，故收费任务 $(100,110)$、收入 $(100,110)$、付现成本 $(40,42)$。上述固定20也是采用才新增的付款；与采用无关、两方案都发生的原公司维护费用不因分摊就变为增量。容量乘利用率一次；若输入已是实际收费任务，就不再乘第二次。

0期设备付100，税务折旧各年50，期末税务账面0；0期投入经营净营运资金10，1期末增至15，2期清算释放到0。还要占用自有场地：不做项目可在0取得税后两年租约款20，做项目会放弃它；场地2期剩余价值两方案相同，差额为0。以前已花的研究费5不可收回。2期设备卖20。

本例是**教学税制**：正EBIT当年末缴25%，亏损不退税/不结转；设备出售正收益缴25%，出售损失无抵税。未建立利息抵税/融资税盾。经营净营运资金NWC只含本例应收/存货等经营占款净额，不含现金、借款及其他融资。令现金经营成本为 $O_t$、税务折旧 $D_t$，定义

$$EBIT_t=R_t-O_t-D_t,\quad T_t=\tau\max(EBIT_t,0),$$
$$FCF_t=EBIT_t-T_t+D_t-CAPX_t-\Delta NWC_t+S_t^{net},\quad
S_T^{net}=S_T-\tau\max(S_T-B_T,0).\tag{2}$$

这里 $B_T$ 是税务账面值，$\Delta NWC=NWC_t-NWC_{t-1}$；0期单列设备、营运资金与税后机会成本。只有税额确为 $\tau EBIT$ 时，才可把前半式写成 $EBIT(1-\tau)+D$；亏损无抵税时照抄会虚构退税。实际税法还可能改变抵扣、结转和时点，不能由本表代替某法域规则。

| 项目/单位 | 0期 | 1期末 | 2期末 |
|---|---:|---:|---:|
| 收费任务/个 | — | 100 | 110 |
| 收入 | 0 | 100 | 110 |
| 付现经营成本 | 0 | 40 | 42 |
| 税务折旧（不等于当期付款） | 0 | 50 | 50 |
| EBIT | 0 | 10 | 18 |
| 经营税 | 0 | 5/2 | 9/2 |
| 经营现金 $EBIT-T+D$ | 0 | 115/2 | 127/2 |
| 设备购买/追加CAPX | −100 | 0 | 0 |
| 营运资金现金 $-\Delta NWC$ | −10 | −5 | +15 |
| 设备净出售现金 | 0 | 0 | +15 |
| 放弃税后场地租约机会 | −20 | 0 | 0 |
| **增量融资前现金** | **−130** | **105/2** | **187/2** |

按10%机会成本，$NPV=-130+(105/2)/1.1+(187/2)/1.1^2=-5$。不计场地机会会误得15；再扣已付研究费又会把历史支出计入新决策。设备在0已付款，折旧只影响税，不再次付50；出售20缴5只加净15。营运资金的15释放与设备残值是不同项目，均已在末期现金中，不能再另加一份“终值”。

不用利润调节也能核：1期直接收100、付40、付税2.5、再投营运资金5，留下52.5；2期收110、付42、付税4.5、收回营运资金15、卖设备净收15，留下93.5。0期实际新增打款110，但相对“不做而收租”的比较还少了20。**开工现金可行与NPV正是两个问题**；机会成本不一定是一张需要再付款的发票。

## 回款晚一年，不能只盯贡献利润

若1期应计收入中10延至2期收、税仍按上述应计额当期缴，1期末应收增加10进入 $NWC$，末期收回。经营现金相对原表变成 $(52.5-10,93.5+10)$；总收款没变，现值却减少 $10/1.1-10/1.1^2=100/121$。不能既在直接收款减10，又在已经以应计收入为起点的同一表中再通过 $\Delta NWC$ 减一次10；两种路线是替代核对。

不同问题要分开：收款延迟不是收入必假，正NPV不是每月现金不短缺，借到钱不是项目需求增加。到 [[社会科学/30-金融市场与风险/09-AI投资现金流与需求口径校注#收款、确认收入和融资要能分列|现金流审计]] 返回时，仍带同一订单、交付、确认与收款时点。[[社会科学/30-金融市场与风险/50-公司金融/80-实践/01-项目预算与融资分离/迁移题#二：税后利润、回款与可用现金|题二]]同时改利用率和应收，要求重建两条核算路线，而非只把最后NPV调一下。

## 返回原AI例：只改利用率，别顺便改分母

带原现金流校注的固定情景A返回：参考容量Q100，闭环比例(1/2,7/10)，售价2、实际任务付现成本1、固定付款10/年、初始100、末期实际净残值49；无税/营运资金，r10%。原售出率u=4/5时收费任务(40,56)，现金(30,46)，NPV700/121。仅将u改3/5，收费任务变(30,42)，现金(20,32)，NPV变−1800/121。两年技术闭环比例、价格、成本口径、残值和时点均未改变；容量没有再乘两次u，也没把固定成本另扣一遍。

这是对原应用的一个完整条件改变：利润贡献下降通过两期现金进入NPV，融资来源没有被当成更多客户需求。它与上节**另建的税后项目**分开；不能把其25%教学税率或场地机会款无声塞回原无税情景。该旧A与新u变式在本实践小程序按固定输入复算，不声称重跑旧源码全套或得到真实AI项目收益。

## IRR什么时候能答，什么时候换了问题

对现金序列 $(-I,C_1,\ldots,C_T)$，$I>0$，IRR是满足 $-I+\sum C_t/(1+\rho)^t=0$ 的 $\rho>-1$。若以后各 $C_t\ge0$ 且至少一个严格正，函数连续且导数 $-\sum tC_t/(1+\rho)^{t+1}<0$，两端极限分别为正无穷与 $-I$，所以唯一IRR存在；对这个**单独常规项目**、平坦机会成本 $r>-1$，NPV正当且仅当 $\rho>r$。

这没有证明可以按IRR排列互斥项目。例A $(-100,150)$，B $(-200,280)$，同为一年确定性、无税、机会成本10%。A的IRR50%，B40%；但 $NPV_A=400/11$，$NPV_B=600/11$。互斥且资金充足时选B，因为增量B−A $(-100,+130)$ 也超过10%机会成本。高百分比不能代替较大的现值增量。若0期现金上限150，B不可行，此时选A；这是约束变了，不是B价值算错。

若现金序列 $(-100,230,-132)$，令 $z=1+\rho$，零现值方程化为

$$-100z^2+230z-132=-(10z-11)(10z-12)=0.\tag{3}$$

两个IRR分别10%、20%；NPV仅在机会成本介于二者之间时严格正。未来又有支出时，单调性前提已经失效；“取较高那个IRR”不会修复它。若按给定10%折现，NPV恰0，不支持一个严格增值的采用结论；若项目风险、时点不同，需要匹配的新机会成本，而非从根中挑一个喜欢的。

## 硬预算和不可分割，为什么要看组合

若多个项目相互独立、可任意组合且资源不限，以增加净市场价值为目标可接受所有正NPV项目。若0期现金上限 $B$、项目不可分割，选择就变成

$$\max_{z_j\in\{0,1\}}\sum_j z_jNPV_j,\qquad
\sum_j z_j I_j^{cash}\le B.\tag{4}$$

约束中是需要付款的现金 $I^{cash}$，不一定等于含自有资源机会成本的NPV首项；项目间互斥、互补和后续融资限制也要另加，不能把它们假装独立。

三个项目K/L/M，0期投入分别6/5/5，未来现金现值分别12/9/9（按10%年利率，末期实际现金13.2/9.9/9.9）。NPV分别6/4/4，$PV/I$ 分别2/1.8/1.8。预算10时，先装最高比率K只剩4，无法装L或M，总NPV6；选L+M花10、NPV8更好。枚举全部8个组合即可完整验最优，不靠贪心规则自称正确。预算11则K+L或K+M花11、NPV10。可分割、独立且只有这一线性预算时才可使用连续背包的比率方法；现实项目可否分割是经济条件。

这是有限选择问题，资本约束**外生给定**。它没有解释企业为何拿不到更多钱；信息不对称、治理、抵押与融资供给要另建。直接给一个预算上限不能据此宣布某企业被信贷歧视，也不能从“资金便宜”推出该上限消失。

## 相同经营支付，股权的风险和资本成本会改变

只用确定例容易产生错觉：无论借多少，股权都用原10%贴现。现在复用 [[社会科学/30-金融市场与风险/40-金融理论/01-有限状态支付空间与定价#从状态价到m与Q：同一价格的三种表示|一期状态价主解释]]，不重新证明定价定理。两个年末状态，实际概率 $P=(1/2,1/2)$；市场给定正状态价 $\pi=(3/5,3/10)$，银行支付1的价格为 $9/10$，所以 $r_f=1/9$。状态价不是实际概率，两者都明确给定而非拿项目NPV倒校准。

项目机会在0耗100，经营支付 $X=(100,200)$，市场价值 $V=\pi\cdot X=120$，融资前NPV20。无税/费用/困境损失，合同仅在项目内按债务先付、股权拿剩余；这是合成支付约定，不是任何现行破产顺位。借50且无违约，承诺末期 $H=500/9$，逐状态分拆为

| 状态 | 项目X | 债券d | 股权X−d |
|---|---:|---:|---:|
| 低 | 100 | 500/9 | 400/9 |
| 高 | 200 | 500/9 | 1300/9 |
| 0期市场价 | 120 | 50 | 70 |
| 0期实际项目出资 | 100 | 50 | 50 |

市场价行来自**同一个**线性定价，实际出资行来自投资成本；差额20是机会的净价值，不能把股权70当成股东已经打款70。分别计算各状态和市场价的加法，再比较出资，才有融资分离。借款换了实际出资与权益风险暴露，项目总支付未变。

用实际概率求市场价格上的预期回报：

$$r_A=\frac{E_PX}{V}-1=\frac14,\quad r_D=\frac19,\quad
r_E=\frac{E_P(X-H)}{70}-1=\frac{22}{63}.\tag{5}$$

股权的价值为 $E_P(X-H)/(1+r_E)=70$。若照用经营资产25%去折股权，误得 $680/9\approx75.56$。项目与股权的风险成本必须匹配；支付总量相同，不意味着各层证券的要求回报相同。这里的预期回报分母是市场价格，**不是初始项目出资**，后者还包含正NPV机会的价值。

在 $V>0,E>0$ 下，一般无违约且债券按银行价公平发行时，$D+E=V$、$E_PH=(1+r_D)D$。代入 $E_PX=(1+r_A)V$ 得

$$r_E=r_A+\frac DE(r_A-r_D).\tag{6}$$

本例 $r_A>r_D$，杠杆使股权预期回报上升；一般方向仍看利差。股权支付绝对方差因减常数而与X相同，但**市场价值归一化的回报方差**由 $\operatorname{Var}_P(X)/V^2$ 变成 $\operatorname{Var}_P(X)/E^2$，借债后增大。若股权市场价E为0，支付仍可核算，但不能除E定义股权收益率；没有股权的边界不套(5)–(6)或上述方差比。别把“风险转移”说成项目经营风险被魔术消灭。

![[社会科学/30-金融市场与风险/50-公司金融/80-实践/01-项目预算与融资分离/choice-and-risk.svg]]

左面板是另一组确定性互斥项目的NPV/IRR比较；右面板只对本有限状态经济改变无违约债务D，显示市场价格上的预期回报，二者不是同一风险模型。代码只在 $D\le90$ 内沿用银行利率，因为低状态100最多偿还 $100/(10/9)=90$ 的本金；超过后，若仍只用项目资产，债务支付/售价或担保假设必须重判。

对一般已给定的可计价经营支付X及债权d，沿用196的线性价算子 $\Pi$，若公平取得 $L=\Pi(d)$，经营不变、总费用F在0期另付，则股权净值为

$$\Pi(X-d)-(I+F-L)=\Pi(X)-I-F.\tag{7}$$

若不完备使项目价值不唯一，就应保留允许的价集合而不是随意挑π；若投资/清算/违约/税改变X，(7)的“同一个X”已被撤去。无税融资基准是一把检查哪里真正改变的尺，不是现实资本结构永远无关的宣言。一般复制条件、税盾/困境与债务政策在[[社会科学/30-金融市场与风险/50-公司金融/02-资本结构复制税盾与融资政策估值|02]]接续：用全部股债支付PV核APV与逐期WACC，改变政策时重新求债务额和税盾；本页有限拆分仍是其前提，不代完整证明。

## 权利、目标与现实证据还要带什么回来

股权是剩余支付不等于所有控制权都已规定。投票、董事席位、债务契约、担保、再融资权、追加投资与违约处置需要自己的可执行安排；不同规则会改变经营选择，届时不能继续固定X。回 [[社会科学/30-金融市场与风险/03-股票所有权现金流与估值#2. 从企业价值桥到每股权利|价值桥]] 时，还要给同一情景的股份数、现金及其他优先索取权，才可谈每股。理论支付表不是实际法律授权，真实规则须按 [[社会科学/63-法学/02-主体事实解释与证据程序#谁在请求什么，向谁请求|主体、请求与证据]] 查询法域和时点，不用软件批准记录替代。

NPV增加的当前评价边界是项目/索取权人。若员工承担风险、客户利益或外部环境变化没有进入现金，不能把(4)叫社会最优。[[计算机知识/75-软件工程与人机交互/05-职业伦理利益相关者与责任判断#同一个预约服务，谁受影响|利益相关者与责任]]要求另外列受影响者、权利和责任；不靠把一个外部成本改名为“战略价值”来补表。[[社会科学/30-金融市场与风险/50-公司金融/03-融资信息治理激励与实物期权|03]]再改变经营决策和管理目标：风险替换/悬置、努力可实施的融资上限、发行后验与分派分别核总现金和各方效用，仍保留本页的福利/权利边界。
