# 复合动力学与有限基区：先预测，再核收支

同一个体寿命能否同时代表高注入衰减、有限基区储存和接触关断？本实践用一组公开教学系数生成全部速率、剖面和图，再用另一条数值路线检查。它不读取厂商参数卡，也不进行真实光学/Hall/恢复测量。

主解释在 [[物理/50-半导体物理/05-准Fermi陷阱占据与产生复合#一个陷阱为何需要四种过程|四过程占据]] 和 [[物理/50-半导体物理/06-有限基区通量接触与存储时间#先解有限吸收端，再逐项核守恒|有限基区守恒]]。先写三个预测：增大注入是否一定仍为同一指数？右端反射是否还必须零浓度？短基区的 $Q_s/I_{inj}$ 是否一定等于体 τ？完成后回读各自的假设而非只看通过标志。

## 输入、单位与同一模型

[recombination_lab.py](recombination_lab.py) 是数值真源，[build_figures.py](build_figures.py) 只消费它的 [results.json](assets/results.json)，未另设曲线参数。运行只用 Python 标准库；源码没有在正文维护重复镜像。固定系数是教学输入，没有从第 3 课的材料卡推导出陷阱/辐射/Auger 参数。

| 输入 | 数值与单位 | 用途与条件 |
| --- | --- | --- |
| $T,n_i,p_0$ | 300 K，$10^{16},10^{22}\,\mathrm{m^{-3}}$ | $n_0=n_i^2/p_0=10^{10}\,\mathrm{m^{-3}}$，p 型背景 |
| $N_c=N_v$ | $10^{26}\,\mathrm{m^{-3}}$ | 与 $n_i$ 在 MB 内对应 $E_g=1.19053$ eV，另一个教学统计卡 |
| $N_t,E_t-E_i$ | $10^{19}\,\mathrm{m^{-3}},0$ eV | 单能级、两态权重比 1；$n_1=p_1=n_i$ |
| $\tau_{n0},\tau_{p0}$ | 1、2 μs | $c_n=10^{-13},c_p=5\times10^{-14}\,\mathrm{m^3s^{-1}}$，不是 Auger 系数 |
| $B,C_n,C_p$ | $10^{-16}\,\mathrm{m^3s^{-1}},10^{-40},10^{-40}\,\mathrm{m^6s^{-1}}$ | 独立有效通道，等温固定系数，无真实材料认证 |
| $D_n,u_0$ | $0.003\,\mathrm{m^2s^{-1}},10^{18}\,\mathrm{m^{-3}}$ | 低注入有限 p 型基区；只忽略少子漂移 |
| 体 $\tau,L_n,L$ | $\tau_{lin}=497.513180$ ns，$L_n=38.633399$ μm，$L=L_n$ | τ由前述三个通道的同状态线性化求得，L由其与D共同生成 |
| 右边界 | 理想吸收、$\beta=0,1,10$ | $\beta=SL_n/D$；面/接触通量独立于体积分 |

$p_0$ 是平衡多数载流子输入，固定背景需与平衡陷阱电荷相容；本实践没有另解掺杂电离/Poisson。注入时 $n=n_0+\delta,p=p_0+\delta$ 近似忽略较小的陷阱占据电荷差额；默认低注入例中约 0.2%。更密的陷阱或超快变化须把陷阱状态和电荷加入方程。高注入例 $\delta=10^{24}$ 相对所设 $N_c,N_v$ 约0.01；数值 API 允许更高输入不等于 MB 物理适用性已认证。

## 速率和时间检查

在此目录运行；Python 3.10+，不要求科学包：

```bash
python3 -B recombination_lab.py
python3 -B build_figures.py
python3 -B -m unittest -v test_recombination_lab.py
```

`rate_state(delta, Rates())` 将 $np-n_i^2$ 写成 $\delta(n_0+p_0+\delta)$，避免极小注入下两大数相减；它计算三个净通道、陷阱稳态与响应时间、准 Fermi 分离以及割线/微分寿命。`trap_state(n,p)` 从四过程另外算电子和空穴的净俘获，再与 SRH 闭式比较，允许净产生检查。准 Fermi 的 MB 指数参数输出为 `eta_n_mb,eta_p_mb`，用来检验允许计算的密度是否仍远低于 DOS 有效密度。

[回归源码](test_recombination_lab.py) 的独立对象包括：

- 从四事件重新求 $U_n,U_p$，验证稳态相等，匮乏 $n,p$ 时为净产生；规定 $n,p$ 下陷阱的仿射 ODE 直接有闭式 $f(t)=f^*+(f(0)-f^*)e^{-t/t_t}$。
- 在 $\delta\to0$ 比较总线性系数；微分寿命用独立中心差分核导数；仅 SRH 且高注入时比较 $\tau_{n0}+\tau_{p0}$。
- 非线性 RK4 熄光与独立辐射闭式比较：本征背景时 $\dot\delta=-a\delta-b\delta^2$，$a=2Bn_i,b=B$，解 $\delta(t)=\delta_0e^{-at}/[1+(b\delta_0/a)(1-e^{-at})]$。该基准令陷阱时间很大而非声称物理上完全删除，影响小于测试容差。
- 默认高注入 RK4 的 20 ps/10 ps 两档步长在相同时间点比较；最大相对差约 $5.13\times10^{-12}$。这不是误差定理或物理参数误差，只是本有限轨道的步长变化检查。

![[物理/80-实践/05-复合动力学与有限基区/assets/injection-decay.svg]]

`uniform_decay` 只计算外加产生关闭后的均匀模型；初态假定已完成局部热化及陷阱准备。20 ns 内过剩浓度由 $10^{24}$ 降至 $2.13284\times10^{23}\,\mathrm{m^{-3}}$，$\tau_{sec}$ 从 3.28574 ns 增到约 30.8454 ns。它没有解泵浦期间的光吸收或超快陷阱电荷动力学。

## 边值问题和守恒检查

`base_point`/`base_summary` 使用正文双曲函数的完整边界解，传统电子电流取 `Jn_A_m2=-q*Fn_m2_s`。每一个 $x$ 保存浓度、通量和累积体复合，不只存左右端。吸收端与 Robin 端都验证 $F_n(0)-F_n(L)=\int u/\tau\,dx$、$F_n(L)=Su(L)$、长/短基区与反射极限。

![[物理/80-实践/05-复合动力学与有限基区/assets/base-conservation.svg]]

独立离散路线不调用双曲函数生成解：令 $z=x/L_n$，在 $[0,1]$ 的 80/160 等分网格求三对角方程 $(2+h^2)u_i-u_{i-1}-u_{i+1}=0$，左边为1、右边为0。Thomas 消元得到剖面，再比较解析解；误差约按4倍降低，细档最大归一误差小于 $3\times10^{-7}$。离散流入−流出与内部控制体积复合和独立检查：界面共用通量使内部边抵消。离散端通量位于第一/最后节点间的边，与解析物理端导数位置不同；本测试不会把端点一阶斜率误差藏作完全相同的端口值。

`mode_point` 另外计算两端零浓度、非负二正弦制备态的精确模态。核对 PDE 与整体收支，图在 $L/4$ 观察两种时间，而积分第二模态为零。这是一个明确的观测权重反例，未冒充前面的注入稳态关断轨道。

![[物理/80-实践/05-复合动力学与有限基区/assets/spatial-decay.svg]]

## 数值 API 与未验层

参数须有限，温度/密度/俘获时间为正，辐射/Auger系数非负；陷阱能量约束 $|(E_t-E_i)/(k_BT)|\le40$。`rate_state` 的过剩域是 $0\le\delta\le10^{25}\,\mathrm{m^{-3}}$；`trap_state` 的规定 $n,p$ 域同样为0至 $10^{25}\,\mathrm{m^{-3}}$。后者可以数学检查匮乏载流子的净产生，不保证其空间电荷背景。

有限基区 API 为 $D,\tau,L,u_0>0$、$0\le x\le L$、$0.001\le L/L_n\le20$，有限 $0\le\beta\le10^8$ 或 `None` 表示吸收极限。这是双曲函数有限数值区间，不是物理长度定理。极短例的累积复合会有大数相减，不能把浮点“恰好守恒”当任意精度证明。RK4 至多100000步，终点须为步长的整数倍，正性失败须缩小步长，不能裁掉负数继续报成功。

七项回归和图/数据只支持本机有限模型。原始来源本轮实际读到 MIT L4/L5/L10/L11 对应 PDF 与 TU Wien SRH 正文；没有从来源中的实验图提取真实参数。没有进行商业 TCAD、DD–Poisson 自洽、Schottky/Ohmic 标定、真实寿命/光学/恢复测量、工艺或硬件验证，Obsidian 客户端与真人理解也未运行。到 [[电子电路/22-半导体与真实元件/04-结电容存储恢复与温度#反向恢复：条件写全才有时间|反向恢复模型]] 时，应带回抽取电流、终止判据与空间边界，不能拿一个体 τ 直接预报手册 $t_{rr}$。
