# 测量争论与识别边界：同一个问题为什么得到相反方向

## 争论不只是“电话调查不可信”

1994研究的就业数来自对门店经理或助理经理的电话/现场访问。工资单批评不是一个从1995到2000固定不变的“同一数据集”：1995年3月初稿只有Berman/EPI提供的71个门店观测；1995年8月NBER Working Paper 5224扩到230家并报告NJ相对PA就业约下降4.6%，同时指出原电话数据的就业变化离散程度更大。

Card 与 Krueger 的再分析（1998工作论文，后发表于AER 2000回复）使用BLS ES-202行政工资单数据，报告NJ相对宾州东部就业增长相近或稍快。2000 Reply表5重新整理的合并BNW工资单样本为235家，其中标作NW子样本的为154家，原始Berman样本为71家；这些数字不等于1995年NBER摘要的230家。Reply还指出周、双周、月报送口径的变化不同；“控制报送周期后接近零且不显著”是Reply对其235家合并样本的重分析结论，不是Neumark–Wascher正式评论自行报告的结论。

| 文稿/分析版本 | 文中样本标签与规模 | 本组怎样使用 |
| --- | --- | --- |
| 1995年3月初稿 | original Berman/EPI，71 | 只说明最初批评的数据范围 |
| 1995年8月NBER WP 5224 | 扩展工资单样本，230 | 对应摘要中的-4.6%结果 |
| 2000 Card–Krueger Reply重分析 | pooled BNW 235；NW subset 154；original Berman 71 | 对应Table 5的版本拆分和报送周期控制 |

这些样本数的差异可能来自版本扩充与Reply重构；不能把230、235和154当成同一个固定总体的别名。

这三项结果不能压成“工资单一定正确”或“原论文已经永远胜出”。至少要分开：

| 层次 | 要问的问题 |
| --- | --- |
| 测量 | 经理口述的全职/兼职人数，与工资单总工时/35，分别测到什么？误差是否随州和波次变化？ |
| 样本 | 410家电话调查店、230家自愿提供工资单的店、行政记录覆盖的单位是否代表同一总体？ |
| 口径 | FTE人数、总工时、工资单报告周期、永久/临时关闭如何处理？ |
| 识别 | 即使测量准确，NJ未处理趋势是否等于PA？是否有差异同期冲击或溢出？ |
| 外推 | 快餐既有门店8个月的结果是否适用于全行业、长期、别的工资增幅？ |

## 为什么经典两期DID不能检验平行趋势

原数据只有一个处理前波次。政策前无法画两州多期趋势，因此不能用这份数据检查“政策前趋势是否已经分叉”。政策前就业**水平**不同不是直接反证；缺少多期前趋势却使核心假设更多依赖制度与比较组论证。

政策在1990年已经立法，1992年才生效。企业可能提前改工资、招聘、人员构成或开店计划；若处理前调查已经含预期反应，简单DID的“前”不再是完全未处理状态。原文也记载生效前曾发生推迟/分阶段实施的政治争论。

## 六个具体威胁

1. **差异测量误差**：若NJ经理在涨薪后改变全职/兼职报告方式，而PA没有，DID也会变。
2. **回归均值**：两轮口述就业噪声大，极端第一轮值可能机械回落；按初始工资暴露分组时还需担心初始测量误差。
3. **样本选择**：愿意交工资单的连锁或加盟商可能不是随机样本；行政数据覆盖更广也可能行业编码不完全相同。
4. **组成变化**：既有门店内就业增加可与新店进入减少、员工总工时下降同时发生。
5. **同期差异冲击**：NJ与PA即便相邻，也可能遭遇不同景气、连锁扩张、税收、交通或地方需求变化。
6. **溢出与一般均衡**：跨州通勤、顾客转移、竞争门店退出会让PA也受NJ政策影响；此时对照不是“未处理”。

## 原论文做了哪些有用但有限的检查

- 把NJ中政策前已付5美元以上的高工资店作为替代对照；其就业变化与PA接近。
- 改变兼职权重、临时停业处理、排除海岸门店、控制连锁/所有权和地区。
- 比较菜单价格、招聘奖金、福利和工资结构等可能机制。
- 追踪第一轮样本的关闭状态，避免只看幸存店。

这些稳健性检查会攻击特定替代解释，却不能证明所有未处理趋势、测量或溢出假设成立。特别是“某一规格显著”与“设计识别成立”仍是两件事。

## 读相反证据的四步法

1. **统一目标量**：店均FTE、总工时、员工人数、全行业就业是否相同？
2. **对齐样本**：相同门店、相同州域、相同日期和相同关闭规则吗？
3. **审计数据生成**：谁报告、按什么周期、缺失如何形成？
4. **再谈符号**：只有前三步对齐后，正负差异才主要是估计或模型差异。

> [!example] 会推翻“约2.75是政策效应”的反例
> 假设1992年NJ某连锁独立扩张，使样本店平均多招3个FTE，而PA没有。即使最低工资真实效应是 $-0.25$，观察DID仍约 $+2.75$。数据表和算术完全正确，因果解释仍错误，因为同期冲击破坏平行趋势。

## 结论该怎样写

合格句子是：**在Card作者官网的固定公开归档和其FTE/缺失规则下，NJ相对PA的两期DID约为+2.75 FTE/既有门店（AER正文报告2.76）；把它解释为1992年上调的短期因果效应，需要平行趋势、无差异测量误差、无重要溢出和样本口径稳定等条件。后续工资单与行政数据研究对测量和样本提出相反证据，不能由原表本身裁决。**
