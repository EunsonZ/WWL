# CLIP、图文对齐、连接器与 VLM 训练

“图文能互相检索”和“模型能根据图像生成正确回答”是两种能力，训练目标也不同。CLIP 类双塔学可比较的表示；生成式 VLM 把视觉证据接入语言生成过程。

![图文双塔形成配对矩阵](../90-资源/图示/clip.png)

## 对比学习怎样对齐两种模态

先用一个人工构造的两对图文 batch 看清两个方向。以下分数是教学用的缩放 logits $s_{ij}$，不是实测图文数据；行是图像，列是文本，对角线 $(i_1,t_1)$ 与 $(i_2,t_2)$ 是本例指定的配对：

$$
S=\begin{array}{c|cc}
 & t_1 & t_2 \\ \hline
i_1 & 2 & 0 \\
i_2 & 1 & 0
\end{array}.
$$

行 softmax 固定图像、沿候选文本归一化。$i_1$ 的概率为 $(0.8808,0.1192)$，正确配对 $t_1$ 的交叉熵为 $-\log 0.8808=0.1269$；$i_2$ 的概率为 $(0.7311,0.2689)$，正确配对 $t_2$ 的损失为 $-\log 0.2689=1.3133$。因此本例 $L_{I\to T}=(0.1269+1.3133)/2=0.7201$。

列 softmax 固定文本、沿候选图像归一化。$t_1$ 在 $i_1,i_2$ 间的概率为 $(0.7311,0.2689)$，目标是 $i_1$，损失 $0.3133$；$t_2$ 的概率为 $(0.5,0.5)$，目标是 $i_2$，损失 $0.6931$。因此 $L_{T\to I}=(0.3133+0.6931)/2=0.5032$，用未舍入概率算两向平均得 $L_{CLIP}=0.61165$，约为 $0.6116$。同一对角线配对在两个方向各自承担一次目标，但每次 softmax 的候选轴和分母都不同。

这些有限 batch 的非对角项是训练时构造的候选负样本；它们只表示该次 softmax 中“不作为当前目标的候选”，不证明图文语义互斥。分数、softmax 概率和交叉熵都是无量纲相对量，CLIP 分数不是世界命题为真的概率。

设一个 batch 中有 $N$ 对图文，图像向量 $u_i$ 与文本向量 $v_j$ 已做 L2 归一化。相似度 logits 为 $s_{ij}=u_i^Tv_j/\tau$，图到文损失为：

$$
L_{I\to T}=-\frac1N\sum_i\log\frac{\exp(s_{ii})}{\sum_j\exp(s_{ij})}.
$$

对应的文本到图像项把每一列当候选图像：

$$
L_{T\to I}=-\frac1N\sum_j\log\frac{\exp(s_{jj})}{\sum_i\exp(s_{ij})}.
$$

CLIP 的双向目标可写成 $L_{CLIP}=(L_{I\to T}+L_{T\to I})/2$。每行固定一张图、在文本候选间选择；每列固定一段文本、在图像候选间选择。$\tau$ 控制分布锐度；归一化防止只靠放大向量长度提高相似度。[1]

即使在实际训练中，另一张内容相同的图片也可能落在非对角位置，成为假负样本；近重复与粗糙 caption 也会污染配对标签。

## 生成式 VLM 怎么连接

![视觉特征投影进入语言上下文](../90-资源/图示/vlm.png)

视觉编码器输出 `[B,N,D_v]`，线性层或 MLP projector 将其变为 `[B,N,D_l]`，然后作为视觉前缀/插入 token，或供 cross-attention 读取。此处 $N$ 表示每张图的视觉 token 数，CLIP 损失中的 $N$ 表示 batch 图文配对数，两处口径不同。若压缩器把很多 patch 变成少量 token，就在用细节换上下文预算。

**先做：单条件变化。** 只把单视图输入从 $448\times448$ 改为 $384\times384$ 像素，patch 仍为互不重叠的 $16\times16$；假设 $B$ 不变，视觉宽度 $D_v=1024$、语言宽度 $D_l=4096$，并使用逐 token 共享、无偏置的线性 projector；忽略特殊 token、多裁剪和压缩器。写出 patch 网格、视觉特征 shape、投影后 shape，并说明哪些量改变、哪些量不变。

<details>
<summary>参考解：分辨率改动</summary>

网格由 $28\times28$（每图 $N=784$）变成 $24\times24$（每图 $N=576$），因此 $[B,784,1024]$ 变为 $[B,576,1024]$。变化的是单视图分辨率与 patch 数；每 token 的视觉宽度仍是 $D_v=1024$。投影后 shape 为 $[B,576,4096]$，其中 token 数为 576，语言向量宽度 $D_l=4096$。不含偏置的逐 token 共享线性投影有 $1024\times4096=4,194,304$ 个权重，$B$ 或 $N$ 改变都不增加这层参数；若加 bias，再有 4096 个参数，总数为 4,198,400。

</details>


一种常见训练路线先对齐连接器，再以图像与指令/回答数据进行监督微调。哪些模块冻结、哪些可训练、loss 是否只覆盖回答 token，都要显式说明。LLaVA 的视觉指令微调提供了代表性范式，不代表所有 VLM 共享相同架构和配方。[2]

**换个表面再做：视觉前缀的消费端。** 设一个合成的 batch 有 2 张 $384\times384$ 图；每张用互不重叠的 $16\times16$ patch，不加特殊 token、裁剪或压缩器。每个 patch 已编码成 1024 维向量，逐 patch 共用一个无偏置投影映到语言模型的 4096 维宽度，并假定每个投影向量都作为一个视觉前缀 token。写出投影输入/输出 shape、每条样本的前缀 token 数、整个 batch 的 patch 向量数，以及 projector 参数数。

<details>
<summary>参考解：视觉前缀 shape 与参数</summary>

每张图是 $24\times24=576$ 个 patch，输入为 $[2,576,1024]$。投影后的 shape 是 $[2,576,4096]$，每条样本有 576 个视觉前缀 token；batch 中共 1152 个 patch 向量，但它们仍分属两条长度为 576 的序列。相同线性层逐 token 复用，参数数为 $1024\times4096=4,194,304$（不含偏置）；不能把 4096 维误读成 token 数，也不能按 1152 个向量重复计算投影权重。

</details>

## 可靠性的关键对照

相同问题分别输入正确图片、无关图片、空白图片和遮挡图片；若回答几乎不变，可能主要依赖语言先验。再测 OCR、计数、定位、空间关系和跨图对比，避免用一个平均分掩盖失败。

数据切分按文档、视频、网页或实体，而不是按切出来的小图随机切。生成回答中的引用应能回到实际区域或页码。低质量图文对齐、语言答案泄漏和重复图片是不同故障，不能都用更多 SFT 样本解决。
