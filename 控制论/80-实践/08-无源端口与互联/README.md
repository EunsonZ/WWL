# 无源端口与互联：有限能量账与条件变化

先读 [[控制论/10-系统课程/17-无源系统耗散与反馈互联#负反馈先消去内部供给，再讨论稳定|一般端口消项]]，自己预测：保持质量/弹簧两边无源，删去阻尼、翻转质量端的受力方向、附加端口看不见的振子，分别改变哪一步稳定论证？正文给一般证明；这里把同一 SI 方程的有限轨迹、累计能量、反例与解析核对接起来。

## 输入口、真源与运行

[input.json](input.json) 给单位明确的机械、电路与隐藏振子参数；[passivity_lab.py](passivity_lab.py) 是标准库真源，[[控制论/80-实践/08-无源端口与互联/code-sync/passivity_lab|源码阅读镜像]] 与之逐字相同。Python3.10以上可运行，不需科学计算依赖。在本实践目录执行，输出使用**尚不存在**的目录：

```sh
python3 -B passivity_lab.py --input input.json --output-dir /private/tmp/wwl-passivity-my-run
```

作者本次实际使用 `python3 -B /private/tmp/numerical_guard.py --threads 1 --timeout 60 --lock-timeout 60 -- python3 -B passivity_lab.py --input input.json --output-dir /private/tmp/wwl-passivity-author-default-20261012`。运行记录在 [run-output.txt](run-output.txt)，默认6输出保留在 [results/summary.json](results/summary.json) 同目录。Python3.14.7/macOS27.0.1 arm64，作者进程约0.089s、观测峰值RSS26968064bytes；这只描述本次轻量CPU执行，不是未来参数的资源上限或硬件实时证书。

程序先读并验证全部参数，再计算，最后创建新输出目录。拒绝重复JSON键、字段缺失/多余、非有限数/布尔值、非正储能元件、负损耗、未对齐网格、过长有限时域、超过200000个请求子步或已存在输出目录；这些是实验输入条件。它不把“输入拒绝”改称数学上不可稳定。反接无源组件的主动连接有意作为独立失败模型，不允许把负电阻混入名义被动组件。

## 端口和五组有限轨迹

机械名义满足 $\dot q=v,\ 2\dot v=-2v-8q$，单位 m、m/s、kg、N·s/m、N/m。初值 $(q,v)=(0.1,0)$，无外力。电例在原生 SI 坐标独立积分 $2\dot i=-2i-v_C,\ 0.125\dot v_C=i$，初值 $(v_C,i)=(0.8,0)$ V、A。两者分别保存，不把电压与位移当一种单位。

| 入口 | 改变的条件 | 六秒末的有限结果 |
| --- | --- | --- |
| nominal | 原损耗与负反馈 | $q\approx0.00186275537$ m，$v\approx0.00834968483$ m/s，$H\approx8.35966670\times10^{-5}$ J。 |
| lossless | $b=0$，接线保持 | $H\approx0.04$ J，解析周期 $\pi$ s，不趋0。 |
| reversed | 质量端 $u_1=+kq$，弹簧端 $u_2=v$ | $q\approx728.318719$ m，$H\approx3415262.444$ J；合成无限线性模型的增长，不是普通被动弹簧实物预测。 |
| hidden | 名义可见运动再附独立无损振子 | 隐藏储能约0.01 J恒定，联合储能约0.01008359667 J；可见输出衰减不消去隐藏运动。 |
| circuit | 正R串联电感与电容负反馈 | $v_C\approx0.01490204295$ V，$i\approx0.00834968483$ A，储能/损耗同名义机械例。 |

[mechanical.csv](results/mechanical.csv) 共1204数据行，每个入口301行，0到6s包含端点，导出间隔0.02s。列 `mass_supply_W` 与 `spring_supply_W` 为流入两子系统的端口供给；负反馈时逐点和为0，反接时和为 $2kqv$。`connection_supply_integral_J` 用增广ODE积分这个和；`loss_integral_J` 积分 $bv^2$。总账余差为

$$H(t)+E_b(t)-E_{\rm connection}(t)-H(0).$$

隐藏例 $H$ 包含 $H_h$，初值0.05 J；其他机械例初值0.04 J。`storage_dot_W` 由完整供给减耗散计算，不能把两个端口各取绝对值再相加。[electrical.csv](results/electrical.csv) 另给301行，能量账为 $H+E_R-H(0)$。两CSV共1505行，均显式保存闭式状态列；闭式不由CSV拟合。CSV使用LF行尾。

## 从数值复现到可独立计算的基准

正文给名义解，源码 `exact` 用二阶矩阵指数恒等式 $(A+\alpha I)^2=(\alpha^2-\sigma k/m)I$；$\sigma=+1$ 是原负反馈，$-1$ 是反接。它按负/零/正判别式分别用三角函数、临界极限、双曲函数；与RK4路线不同，但仍是作者给出的解析实现，不能叫非作者oracle。

独立手算名义例 $\omega=\sqrt{15}/2$ s⁻¹，$t_*=\pi/\omega\approx1.62231147039$ s，得到 $v(t_*)=0$、$q(t_*)\approx-0.04443442251$ m、$H(t_*)\approx0.007897671615$ J，累计耗散约0.03210232839 J。这个特殊时刻不恰好位于CSV网格；自行代闭式算，不拿相邻导出点冒充它。原点收敛来自正文零耗散不变集证明，六秒末残余能量小本身不能证明一般渐近性。

[step-errors.csv](results/step-errors.csv) 有四种机械入口×四个步长0.02/0.01/0.005/0.0025，共16行，共用0.02s导出网格。默认交付使用0.005s子步。

| 默认0.005s比较 | 最大观测余差 |
| --- | --- |
| 名义 $q/v$ 对闭式 | $1.27\times10^{-11}$ m / $2.45\times10^{-11}$ m/s。 |
| 无损 $q/v$ 对闭式 | $9.21\times10^{-11}$ m / $1.68\times10^{-10}$ m/s。 |
| 名义/隐藏能量账 | 不超过 $1.03\times10^{-11}$ J。 |
| 无损能量账 | $6.67\times10^{-13}$ J；这个漂移不叫真实耗散。 |
| 反接 $q/v$ 对闭式 | $2.10\times10^{-7}$ m / $3.28\times10^{-7}$ m/s。 |
| 反接能量账 | $2.64\times10^{-4}$ J，比较的是约 $4.24\times10^6$ J 供给，尺度与名义不同。 |
| 原生电坐标对闭式 | 电压 $1.02\times10^{-10}$ V、电流 $2.45\times10^{-11}$ A。 |

缩半步后各默认入口闭式误差下降；反接能量余差降到约 $1.65\times10^{-5}$ J。程序的PASS只表示输入与当前导出步长的有限能量账检查完成，不认证任意变参、连续稳定定理、任意算法或硬件实现。电/机械换算完全吻合也只支持明确参数的两原生RHS一致，不替代其他参数的推导。

非作者核查可不导入本源码：自行对机械/电原式写自适应高阶积分器，或用精确二阶闭式/高精度矩阵指数核每个导出点；独立积分阻尼与反接供给，核隐藏解、根和特殊时刻，再检查总账。重新运行本脚本是复现，不能独立签收它自身的预期值。
