# 动态辨识与自适应：先固定目标，再比较更新

基础入口从 [[信号与系统/40-状态控制与辨识/03-动态回归持续激励与LMS-RLS#两抽头先说明未知对象|两行冲激]] 带未知h=(.5,−.25)及零初史；快进入口带 [[信号与系统/40-状态控制与辨识/03-动态回归持续激励与LMS-RLS#RLS保存的是哪个目标的逆信息|初始信息/加权目标]] 与噪声路径。返回主课交同一目标的独立核、真实训练/验证/测试结果及修改条件的判断。

## 固定输入和时间切分

本实验把电压数值除1 V，各回归分量与输出无量纲、增益无量纲；恢复物理时数据乘1 V、MSE乘1 V²。

1. FIR数据seed180000，4096拍±1输入，过去u[−1]=0，y=.5u[k]−.25u[k−1]+e，e独立Gaussian标准差.05。训练k∈[3,1024)、验证[1024,2048)、测试[2048,4096)，候选1/2/3抽头，R₀=10⁻⁶I、θ₀=0、λ=1。验证选择阶次、冻结训练参数后只报告测试MSE；不在测试挑阶次，也不把理论二抽头强制成每次实际选择结果。
2. 同一动态物理记录seed180100：x[k]=.5x[k−1]+.25u[k−1]+w[k]，u±1外生，w标准差√.75，初态0；理想y=x和同x叠加独立v标准差.5，分别形成两观察。弃k∈[0,256)，训练[256,2304)，测试[2304,6400)，均用过去y,u的二参数ARX。一步预测用实际上一拍，自由运行仅用训练末实际y初始化后递推自身预测。有效误差按**真参数**另算，以避免用拟合后的训练正交性自证原噪声外生。
3. 漂移seed180200，2048拍，h₀前1024拍=.5，后1024拍线性到.8，h₁=−.25、噪声.05。比较RLS λ=1/.98（R₀=.01I、θ₀=0）和LMS μ=.02；记录全过程参数轨迹。最终参数冻结，seed180300另生成1024拍、h=(.8,−.25)验证，比较后续预测误差。不同λ对应不同目标，不先宣称哪个实跑一定获胜。

`fir.csv`、`ar.csv`、`drift.csv`、`later_validation.csv`保留全部固定数据；JSON记录分段、候选/选择、原始目标矩阵、残差lag0…8、一步/自由运行以及轨迹。FIR与AR的输入—残差lag都按物理同拍对齐：lag ℓ使用u[k−ℓ]与e[k]，各自全测试窗均值、分母N，边界仅配窗内两时刻。AR预测器使用u[k−1]，它在这份相关报告中是lag1；lag0仍为u[k]。不存在硬件输入、未自动施加实际激励或接反馈控制。

## 解析oracle与有限模型预期

| 检验 | 独立可算参照 | 边界 |
| --- | --- | --- |
| 两抽头输入 | 稳态常值只给和1/4；零过去冲激两行恢复(.5,−.25) | 一次冲激不等于长期PE |
| RLS λ=1 | 三行目标R=[[3,1],[1,3]]、b=(3/4,0)，解(9/32,−3/32) | R₀=I仍正则，非无先验OLS |
| RLS λ=1/2 | 同行加权目标解(31/79,−13/79) | 先验也随λ³衰减 |
| 回归噪声相关 | 理想创新矩0；白测量噪声矩−1/8 V² | 解析一般公式−aVarv，样本相关会波动 |
| 无输入AR观测噪声 | 人工模型总体aOLS=2/5，真a=1/2 | 实验含b=.25输入，不能套这一特例 |
| 本含输入AR观测噪声 | Vars=(.75+.25²)/(1−.5²)=13/12，R对角(4/3,1)，总体aOLS=13/32、bOLS=.25 | 初态0已弃256；有限fit不严格等总体 |
| 闭环四格 | g=.5,κ=1,r/e=±1，OLS=−.25、参考IV=.5 | 同期可解环1+κg≠0，不是所有闭环都有偏 |
| LMS有限独立φ | μ=1.5时均值乘−.5、均方乘2.5 | 不能移给共享时间回归量 |

测试独立Fraction两维行列式逐前缀比较批量和RLS，中心还用非零(1/3,−2/5)避免只验零先验；有限分布分别枚举测量噪声矩、同期闭环和LMS均方反例；不把源码自己的批量例当唯一oracle。新增相关测试先用三行精确分数固定均值/lag/分母，再从完整AR原始物理时刻、冻结拟合参数重算两模型全部lag0…8，捕捉调用处移一拍的错误。时间保留、自由运行和坐标目标的测试实际检查不同历史与惩罚对应；普通测试PASS不认证所有步长、真实噪声或控制稳定。

## 返回主课的撤提示任务

只保留稳态常值后仍报告两参数时，给出核方向；改变R₀或λ时写实际目标；用同x的两噪声观察指出OLS变成何种预测系数；对漂移比较最后独立验证和参数波动；若由估计h去调控制器，指出尚缺真实输入符号、模型误差、饱和/延迟和闭环证书。可以合法回答数据不足并给新观测/模型，不靠模型名称填空。

真实采集、设备加载/时戳、客户端显示与真人迁移各自未验。普通教材不以这些未验层统一阻塞可独立的解析/数值主线，也不因此宣称整个控制或自适应控制方向完成。
