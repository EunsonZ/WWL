# 5 分钟运行与测试模板

这页解决一个最实际的问题：**正则写好后，怎样在真实语言里运行，并知道结果确实正确？** Python 与 JavaScript 二选一即可，不必同时学习。

> [!tip] 第一次只做这一件事
> 复制一段完整代码运行。看到“全部通过”后，再改一个样本或模式，观察断言怎样暴露错误。这里不需要第三方库、在线账号或插件。

## 先分清三层

| 层次 | 例子 | 谁来解释 |
| --- | --- | --- |
| 正则本体 | `ERR-[0-9]{3}` | 正则引擎 |
| 宿主写法 | Python `r"ERR-[0-9]{3}"`、JavaScript `/ERR-[0-9]{3}/g` | Python 或 JavaScript |
| 调用方式 | 搜索、完整匹配、全部查找、替换 | 语言 API |

同一个正则本体，因为宿主字符串、标志（flags）和 API 不同，结果可能不同。实验记录至少写明：语言与版本、正则引擎、标志、调用方式。

## 路线 A · Python 3 标准库

先确认版本：

```bash
python3 --version
```

把下面代码保存为临时 `.py` 文件，或粘贴到 Python 环境中运行：

```python
import re

text = "ERR-404 request missing\nWARN-404 cache stale\nERR-500 timeout"
pattern = re.compile(r"ERR-[0-9]{3}")

# 全部查找
assert pattern.findall(text) == ["ERR-404", "ERR-500"]

# 完整匹配：整个输入都必须符合
identifier = re.compile(r"[A-Za-z][A-Za-z0-9_]{2,11}")
assert identifier.fullmatch("dev_01") is not None
assert identifier.fullmatch("1dev") is None

# 捕获组
date = re.compile(r"([0-9]{4})-([0-9]{2})-([0-9]{2})")
match = date.fullmatch("2026-08-31")
assert match is not None
assert match.groups() == ("2026", "08", "31")

# 替换
assert date.sub(r"\g<3>/\g<2>/\g<1>", "2026-08-31") == "31/08/2026"

print("Python 正则模板：全部通过")
```

这里用 `fullmatch` 表达严格的完整匹配，避免自行猜测 `$` 对最终换行的处理。Python 的 `re` 就是当前路线的引擎；不用再另选测试器。

## 路线 B · 现代 JavaScript / Node.js

先确认版本：

```bash
node --version
```

把下面代码保存为临时 `.js` 文件，或粘贴到 Node.js 环境中运行：

```javascript
const assert = require("node:assert/strict");

const text = "ERR-404 request missing\nWARN-404 cache stale\nERR-500 timeout";

// 全部查找：g 表示继续查找全部不重叠结果
const codes = [...text.matchAll(/ERR-[0-9]{3}/g)].map((match) => match[0]);
assert.deepEqual(codes, ["ERR-404", "ERR-500"]);

// 完整匹配：不使用 m，且模式约束输入两端
const identifier = /^[A-Za-z][A-Za-z0-9_]{2,11}$/;
assert.equal(identifier.test("dev_01"), true);
assert.equal(identifier.test("1dev"), false);

// 捕获组
const match = "2026-08-31".match(/^([0-9]{4})-([0-9]{2})-([0-9]{2})$/);
assert.deepEqual(match?.slice(1), ["2026", "08", "31"]);

// 替换
assert.equal(
  "2026-08-31".replace(/^([0-9]{4})-([0-9]{2})-([0-9]{2})$/, "$3/$2/$1"),
  "31/08/2026",
);

console.log("JavaScript 正则模板：全部通过");
```

> [!warning] `test()` 与 `g` / `y`
> JavaScript 中，复用带 `g` 或 `y` 的同一个 `RegExp` 对象调用 `test()` 时，对象会更新 `lastIndex`，连续测试同一输入可能得到不同结果。单值校验不要带 `g` / `y`；全部提取优先使用 `matchAll` 等返回形状明确的 API。

## 把样本变成可回归的断言

一次人工高亮只能说明“这次看起来成功”。断言则能在修改模式后自动指出哪条约束被破坏。每组工程测试至少覆盖：

1. 一个应成功的正例；
2. 一个很相似但应失败的反例；
3. 一个空值、长度上下界、换行或 Unicode 边界例；
4. 需要捕获时，检查每一组的实际内容；
5. 需要替换时，检查完整输出，而不只检查是否命中。

推荐记录：

```text
目标语言或工具：
版本：
正则引擎：
标志（flags）：
调用方式（搜索 / 完整匹配 / 全部查找 / 替换）：
输入：
预期：
实际：
```

## 10 分钟扩展：验证你实际用到的引擎差异

上一节的两个模板证明了基础 API 能跑通；下面两份同目录文件专门把容易被“看起来一样”的语义变成断言。它们不下载依赖、不读取真实日志，运行后会打印解释器版本和成功信息。

- Python：[[编程知识/30-实践/01-正则表达式实验区/05-Python差异断言.py|05-Python差异断言.py]]，运行 `python3 05-Python差异断言.py`；
- Node.js：[[编程知识/30-实践/01-正则表达式实验区/06-JavaScript差异断言.js|06-JavaScript差异断言.js]]，运行 `node 06-JavaScript差异断言.js`。

两份脚本比较：Unicode `\\w` / `\\d`、emoji 的点号匹配、预组合与分解重音字符、命名组和替换，以及 JavaScript `g` 标志的 `lastIndex`。它们对应 [[编程知识/10-基础/01-正则表达式/07-Unicode与引擎差异|Unicode 与引擎差异]]；“通过”只说明本机当前版本通过该组明确样本，不能把结果推广给其他引擎。

Python 源文件是下方代码块的规范来源。若要改变预期，先修改源文件，再让此代码块与它逐字同步：

<!-- code-sync: ./05-Python差异断言.py -->
```python
import re
import sys
import unicodedata


def fullmatch(pattern: str, text: str) -> bool:
    return re.fullmatch(pattern, text) is not None


assert fullmatch(r"\w+", "中文")
assert fullmatch(r"\d+", "１２３")
assert not fullmatch(r"[A-Za-z0-9_]+", "中文")
assert fullmatch(r".", "🙂")
assert not fullmatch(r".", "e\u0301")
assert unicodedata.normalize("NFC", "é") == unicodedata.normalize("NFC", "e\u0301")

date = re.compile(r"(?P<year>[0-9]{4})-(?P<month>[0-9]{2})-(?P<day>[0-9]{2})")
match = date.fullmatch("2026-08-31")
assert match is not None
assert match.groupdict() == {"year": "2026", "month": "08", "day": "31"}
assert date.sub(r"\g<day>/\g<month>/\g<year>", "2026-08-31") == "31/08/2026"

print(f"Python {sys.version.split()[0]} regex difference assertions: passed")
```

JavaScript 源文件同样是下方代码块的规范来源：

<!-- code-sync: ./06-JavaScript差异断言.js -->
```javascript
const assert = require("node:assert/strict");

assert.equal(/^\w+$/.test("中文"), false);
assert.equal(/^\d+$/.test("１２３"), false);
assert.equal(/^[A-Za-z0-9_]+$/.test("中文"), false);
assert.equal(/^.$/.test("🙂"), false);
assert.equal(/^.$/u.test("🙂"), true);
assert.equal(/^.$/u.test("e\u0301"), false);
assert.equal("é".normalize("NFC"), "e\u0301".normalize("NFC"));

const date = /^(?<year>[0-9]{4})-(?<month>[0-9]{2})-(?<day>[0-9]{2})$/;
const match = date.exec("2026-08-31");
assert.notEqual(match, null);
assert.deepEqual({ ...match.groups }, { year: "2026", month: "08", day: "31" });
assert.equal("2026-08-31".replace(date, "$<day>/$<month>/$<year>"), "31/08/2026");

const stateful = /ERR-[0-9]{3}/g;
assert.equal(stateful.test("ERR-404"), true);
assert.equal(stateful.test("ERR-404"), false);
stateful.lastIndex = 0;
assert.equal(stateful.test("ERR-404"), true);

console.log(`Node ${process.version} regex difference assertions: passed`);
```
