# 局部有效政策与累积优势的判断

> [!abstract] 读者问题
> 一项政策对一群人有效，是否说明应把它扩大给所有人？如果改善会随时间累积，结论会不会更强？本页把描述、机制、识别、分配与价值分开。初读者先在现实事实回顾里给材料分类；本科读者可从“把阈值和人口同时改变时”提出比较对象，再回补同一张主张卡。两路最后都交第一次材料分类、范围缺口和暂时结论。

![[社会科学/40-公共政策与社会学/assets/08-局部有效与累积优势.svg]]

图画的是提问顺序，不是“越早干预一定越好”的因果箭头。累积优势可以是政策机制，也可以是选择、资源差异或测量的表象；每条线都要有相应证据。

## 一个完整而受限的真实案例：Moving to Opportunity（MTO）

本页只保留作政策判断所需的现实回顾：MTO 在历史上的美国五城项目中随机**提供住房券方案**给符合条件、报名的家庭；实际搬迁仍有选择。较小年龄儿童与青少年结果不同，说明人群和结果窗口会改变结论。随机邀请的 ITT 与实际使用支持的效应不同；后者还依赖工具变量的附加条件。地区、时期、制度版本也限制外推。以上是经济页的摘录回顾；项目样本、基线年龄定义、效应解释及原始文档定位由 [[社会科学/20-经济流动与宏观/04-教育住房地域与累积优势#怎样把“住在哪里”变成可识别问题|“住在哪里”怎样可识别]] 负责维护。

带着“随机了什么、年龄是哪一时点、实际搬迁需哪些假设”去读该段及“一个手算的 ITT 与服从率边界”；回来填下面“因果与比较”栏，再判断新提案究竟沿用了什么。这里不复制 MTO 数字和论文页码，离线回顾仍足以说出随机邀请、ITT 及不可普遍外推三项边界。

### 用同一张主张卡进入扩容选择

这里采用 [[社会科学/10-共同工具/01-事实模型与价值判断#一张主张卡：让同一论证带着范围跨页|共同工具的主张卡]]，只展示政策应用所需内容。历史项目事实和新政策推断要写在不同句子里，机制和价值各带自己的理由。

| 卡的栏位 | 已有证据怎样进入选择 | 还缺什么 |
| --- | --- | --- |
| 对象与范围 | MTO 的报名家庭、儿童年龄与历史项目版本由经济页定义 | 新资格人群、城市、实施时点和处理包是否相同 |
| 测量与描述 | 指定年龄/窗口中的长期结果；随机的是家庭方案提供 | 新项目哪些单位可进入记录，未获支持者是否被追踪 |
| 机制与竞争解释 | 环境暴露可以累积；搬迁扰动与家庭/地点选择仍需区分 | 学校、同伴、安全等过程资料；不能把年龄梯度当单一机制证明 |
| 因果与比较 | ITT 比较被邀请与对照；实际使用支持的效应另需工具变量条件 | 邀请、资格、实际使用和整个扩容各是哪一种目标量 |
| 分配与规范桥 | 可给儿童长期机会较高权重，或给居住自主/权利底线优先 | 明示理由、预算机会成本，以及等候/原社区家庭的代价 |
| 结论强度 | 局部项目结果使新提案值得研究 | 新人群、制度、容量与权衡未清时，总体效果或“应扩容”暂无法裁决 |

> [!example] 初读入口：交出第一次材料分类
> 把“该项目邀请改善某些儿童长期结果”标为经验因果，把“更久暴露累积改善”标为候选机制，把“新城市仍同样有效”标为外推，把“应全面扩容”标为规范判断。先交四类句子、未知范围与一个可说结论：**历史项目邀请证据可支持局部判断；新政策是否有效、是否值得扩容，需要补人群、制度与分配资料。** 未知项可以保留。


## 累积优势不是自动外推许可

“越早搬迁，累计暴露越久，成年收入越高”可以提出动态机制：更长的学校、同伴、信息或安全暴露期，也许逐步改变后续机会。但同一模式还可能混入搬迁时机、家庭选择、地点质量、干扰或后续政策差异。MTO 的随机分配使“优惠券邀请”的比较强于一般观察相关性；它并没有把每一年的环境暴露随机化，也没有把某一具体机制单独随机化。

因此，累积优势的实证任务是追踪链条而不是给它贴标签：何时获得何种资源？资源怎样改变下一期选择？哪些组无法进入？一个看似平均有效的项目是否把稀缺学校席位、住房或社会关系从其他家庭挤出？这些问题将“效果”变成分配与容量问题。

### 局部支持、外推与改变条件的失败面板

![[社会科学/40-公共政策与社会学/assets/08-政策范围与失败面板.svg|425]]

这是一张**非数据的二维示意**，没有效应轴、数值大小或真实 MTO 支持域；方框面积不代表样本比例，箭头不是已识别 DAG。左栏沿用一个假想项目的证据范围，右栏只展示从同一基线出发改变条件会怎样失去原结论的许可。A/B/C 是阅读动作的标签：

- **A，证据到局部句子**：在声明的人群、方案和窗口内，用相应比较支持局部主张；这条实线不增加未测机制或价值结论。
- **B，局部句子到新提案**：虚线仅是外推请求。要返回主张卡检查年龄/家庭构成、地方住房与学校规则、执行年代、容量和未获邀者；相似名称不保证相同处理。
- **C，条件改变到失效点**：右栏虚线表示反例提问。只改变人群时，旧效应仍属于旧人群；只改变制度时，旧项目包不再是新包；两者都变时两项缺口并存。这些是许可失效，不证明新政策一定有害。

例如，只把受益对象改为青少年，旧“较小年龄儿童”句子就不能直接套用；如果同一批家庭另获学区优先，处理包改变，即使人数不变也需重问方案效果。如果人群不变、规则不变，却大幅扩容，租金或学校拥挤可能改变未获券家庭的结果；原局部 ITT 也不能单独给出总体净福利。选择“当前信息不足”时，应指出缺的是哪条箭头的条件，而不是笼统拒绝研究。

## 把阈值和人口同时改变时：RD 不能自动借来

有时项目按分数、收入或年龄阈值分配资格。若阈值两侧的单位在除资格外的潜在结果上连续，且没人能精确操纵运行变量，RD 可以识别阈值附近的局部效应。[[社会科学/40-公共政策与社会学/30-断点设计与制度阈值/02-真实众议院数据的局部线性复算|Lee 众议院案例]]中四个手定带宽的正向跳跃，只是同一数据和一阶局部线性规格下有限的敏感性描述；它不认证所有规格，更不认证所有政策。

当阈值变化还同时改变人口或制度环境时，原来的比较对象已经换了。例如，将“低于收入线者获得券”改为更高收入线，可能同时改变资格者的家庭结构、可租住房供给、地方等候名单和房东选择；这不是仅把 RD 的 cutoff 从 0 移到 1。此时要重选证据：

1. **重新定义处理和人群**：是获资格、获券、实际搬迁，还是获得某种社区位置？新旧人群怎样不同？
2. **重新检查同阈值规则**：收入线是否同时触发其他补贴、学校资格、税务或行政审查？若有，跳跃不能只归给住房支持；若这些规则已完整记录，可把预先定义的组合政策包资格作为目标，但仍不能从同一个跳跃分离各组件效果。
3. **重新检查可操纵性与组成**：申请、申报、等待名单、家庭规模和迁移选择会不会在阈值附近改变？
4. **重新给出容量与溢出证据**：增加名额会否改变租金、接收社区、学校资源或原有受益者的机会？
5. **重新陈述外推**：即使新阈值附近识别可信，也只回答新的临界群体，而不是旧群体或全体家庭。

> [!question] 本科基础快进
> 设一个城市把住房券收入阈值从 30% 中位收入提高到 50%，并同时新增学区优先资格。可否把原阈值的 RD 效应当作新政策的效果？
>
> [!answer]- 参考答案
> 不可直接当作。运行变量阈值变了，临界家庭变了；新增学区资格又让处理版本改变。需先识别两个规则各自何时生效，再在新阈值附近检查密度、协变量、其他同步政策和住房容量。即使得到可信跳跃，它也是新制度下新临界群体的局部效应，不回答扩容后的总体福利或分配。

### 联合迁移：在新规则下重新选证据

某市把家庭支持的收入线从中位收入的 30% 提高到 50%，新入选家庭同时可优先申请若干学区，且市政府计划在两年内新增 800 套可租住房。已知旧项目有随机发放的邀请记录；新规则第一年出现排队，周边租金上升，但没有现成的结果数据。

请独立决定还需要知道什么，再提出证据策略和暂时可作或不可作的政策判断。先写你想回答的问题，给出比较对象、关键假设、容量或溢出、以及多久后才可能观察到什么结果。题干不指定方法，也不保证已有记录足以裁决。

> [!answer]- 完整参考答案
> 一种合法路线是把新项目仍随机发出的邀请与未获邀请家庭比较，先估计“被邀请”的意向处理效应；这要求随机分配在新规则下确实执行，且记录家庭是否收到、使用和迁入何处。比较对象是新资格人群中被邀请与未被邀请者。800 套供给、学区优先和租金上升意味着干扰与一般均衡效应可能存在：即使被邀请家庭改善，也不能把结果当作“不影响其他家庭”的总扩容福利。短期可预注册搬迁、租金、学校进入与家庭压力等过程结果；收入、教育或长期积累效果需要足够长的随访窗口。
>
> 另一条合法路线是在新的 50% 收入线附近比较，先把目标定义为“住房支持与学区优先组成的政策包资格”的局部意向处理效应。资格本来就应在阈值处改变；在申报收入无法被精确操纵、未获该资格时的潜在结果连续、资格包之外没有未纳入的同步跳变等条件下，结果跳跃可支持该组合资格的局部效果，即使实际使用并非人人相同。它不能从同一个跳跃分离住房支持与学区优先的各自效应。
>
> 排队需要另查阈值两侧申请者/记录的组成、执行规则和实际处理概率是否出现非零跳跃。若进一步用结果跳跃除以实际处理率跳跃来估计 fuzzy RD，须先定义实际处理，并补充相应排除限制、单调性等条件；若实际处理仅指住房支持，而资格还通过学区优先直接影响结果，就不能把该比率解释为住房支持的单独效应。分期建设的 800 套住房可在有可信未处理趋势、没有选择性提前建设和可观测溢出时提供另一种比较；排队次序若带有可审计的随机或准随机成分也可提供机会。单纯观察已搬迁者和未搬迁者只能描述差异，除非补足家庭选择和地点选择的证据。
>
> 因此目前最强的暂时判断可以是：新政策改变了人群、处理版本和容量，旧项目结果不能直接外推；先保存邀请、排队、房源、租金、学区、实际迁入和随访记录，再决定哪种比较可行。若邀请并未随机、阈值同步规则不清、分期由高需求地区优先且溢出无法量化，则“暂无法裁决总体效果”是正确结论。价值判断仍另问：新增住房和学区名额应怎样在当前家庭、等候家庭和原社区之间分配。

### 迁移题怎样评分：替代路线与未知都可合格

初读者用文字写比较，本科读者可加 estimand 与假设；两路使用同一标准。每项 0—2 分：0 为缺失或偷换对象，1 为指出问题但未落实范围，2 为写清具体范围和证据缺口。满分 12 不要求选某种方法，也不要求得出正向效果。

| 项目 | 得 2 分的表现 |
| --- | --- |
| 对象与时点 | 区分旧/新资格家庭、家庭分配与儿童结果，写清实施和随访窗口 |
| 处理与比较 | 区分邀请、实际使用、学区优先和住房供给；比较回答指定目标量 |
| 假设与失败 | 给策略所需条件及一个具体失效观察；没有现成设计时不虚构随机性 |
| 容量与分配 | 包含等候/未受益家庭、租金/学校或供给的溢出，不只看受益者均值 |
| 规范理由 | 用明确目标/权利/公平理由连接“应”，并写预算或替代方案权衡 |
| 结论与更新 | 限定当前可说、不可说，并写下一项可能改变判断的资料 |

两种有条件成立的替代策略都可得同分。“缺随机执行记录/同步政策日期/可比对照，所以暂无法裁决”也可在说明缺口及下一步时得满分；只写“不知道”没有完成卡。反之，即使方法名正确，若把获邀 ITT 写成所有搬迁者的效应，或直接推出扩容公平，相关项计 0，须回补后再提交。

## 给决策者的结论强度

| 证据状态 | 可以说 | 不能说 |
| --- | --- | --- |
| MTO 的随机邀请比较 | 特定项目、城市和目标家庭中，某些年龄组的长期结果有有力证据。 | “搬到好社区必定提高每个人收入”。 |
| 一项 RD 在阈值附近通过诊断 | 在明确规则和临界人群下，可讨论局部处理效应。 | “把门槛推开就会以同一幅度改善全体”。 |
| 四个带宽方向相同 | 对该预先列出的有限规格可报告方向一致。 | “模型无关地稳健”或“机制已证实”。 |
| 累积模式加上过程资料 | 可把时长作为候选机制，继续收集中介、容量与分配资料。 | 仅凭年龄梯度就断定单一机制或价值结论。 |

## 自检任务

为一项“给低收入家庭更早搬迁支持”的提案写一段四句备忘：

1. 写清处理版本、目标人群和一个结果；
2. 写出最接近的识别来源及其比较对象；
3. 写一个会改变效果或使旧证据失效的容量/制度条件；
4. 写一个不由因果估计本身回答的分配或价值问题。

若四句中有一句把相关、机制、识别或价值混为一谈，回到上表修改。完成这一步，才有资格讨论“局部有效”是否值得扩容。
