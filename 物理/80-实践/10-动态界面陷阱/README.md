# 动态界面陷阱：从四过程到电荷反馈

## 同一卡怎样从静态根走到时间轨迹

先读 [[物理/50-半导体物理/13-动态界面陷阱与电荷反馈#输入控制与准静态 Poisson 怎样真正闭合|输入控制]]，写下阶跃两侧有哪些量连续、哪些量可在未解析的快层改变。再用 [[物理/50-半导体物理/13-动态界面陷阱与电荷反馈#同一时间步怎样检查事件与总电荷|四通道积分账]] 预测：电子净损失大于空穴净损失时，受主界面态的片电荷应往哪边变。

[dynamic_trap_lab.py](dynamic_trap_lab.py) 是数值真源，[inputs.json](inputs.json) 是固定陷阱／控制协议输入，[build_figures.py](build_figures.py) 读取结果 CSV 与同次参数快照，绘制两幅 SVG。本目录直接导入相邻实践 08 的材料卡和常数／三对角求解，以及实践 09 的冻结占据 Poisson 接口；不复制旧求解器。[实践 08](../08-异质结与Poisson自洽/README.md) 拥有材料带阶与同一卡静电统计，[实践 09](../09-界面态与平衡电荷/README.md) 拥有两态电荷和冻结片电荷边值。移动本目录时应同时携带 08／09，或用 `--base-dir` 指向实际拥有它们的实践父目录。

唯一新体统计是明确的均匀 `Fn_eV`／`Fp_eV` 外控 MB 律，以解出的势决定局部载流子；代码通过模块代理把它送入 09 的求解器，原 08／09 源码和输入均只读。陷阱从 A 侧池交换，位于共同禁带内；没有 B 侧捕获、跨界面输运、局部连续式或左右端电流求解。主协议取共同 F，从 −0.50 到 −0.45 eV，150 nm/侧，两端势固定初始中性值，300 K，全电离杂质。08 卡原有的 `sheet_number_m-2` 不进入本次源项；固定参考片电荷改由本目录的 `fixed_sheet_C_m-2=0` 控制，再加动态占据电荷，避免重复记入旧片电荷。分裂协议另将 `Fp_eV` 保持 −0.50 eV；它是分布式理想外控储库的非平衡输入，不是已求两个偏置接触的 DD。

## 运行与独立比较

Python 3 标准库即可，不安装求解依赖。正式结果已经随本单元保留，脚本为保护原字节拒绝写入非空目录；复算必须给一个新输出目录。下面两条命令从库根运行，第二条使用同一个输出目录，目录名可换为自己的新路径：

```bash
python3 -B '物理/80-实践/10-动态界面陷阱/dynamic_trap_lab.py' --out /private/tmp/wwl-dynamic-trap-new-run
python3 -B '物理/80-实践/10-动态界面陷阱/build_figures.py' --results /private/tmp/wwl-dynamic-trap-new-run
```

候选单独运行时，第一条增加 `--base-dir /实际主库/物理/80-实践`。默认输入每侧 120 格、0.1 μs、50 μs；程序同时算半步／四分之一步、240 格、倍密度、0.2／5 倍四率、三离散能级与分裂储库共九例。先在有限 CPU 预算下预跑；通常复算无需多线程。任一旧输出、非法概率、负捕获系数、非正时间步、非有限输入或超出预算会失败，不裁概率、不覆盖旧结果。两 SVG 已存在时绘图也拒绝覆盖。

本单元的数值正式结果由非作者在独立目录实际运行，不将作者 syntax 检查当实验。另用连续两材料 `solve_bvp` 与 `DOP853` 占据 ODE 作独立比较；它们没有复用生产三对角矩阵或指数 Euler 步进。独立工具依赖只装在该运行者的临时环境，生产程序仍仅用标准库。结果支持这里声明的有限模型：

## 每份输出回答什么问题

`step-time.csv` 从 $0^+$ 开始，记录同一步的占据、瞬时相容稳态 $f^*$、固定场 $1/\lambda$、界面势、片／体／电极电荷、$U_n,U_p$、MB 尾部和 Gauss／Newton 残差。动态轨迹一般 $f\ne f^*$，这是状态方程的作用。`half_dt-time.csv`、`quarter_dt-time.csv` 用同一初态和协议，按公共时刻比较；只看终态不能检验早期滞后。

`step-balance.csv` 保存各步四个非负事件积分、$\Delta\sigma_s$、片电荷恒等式残差、外控电子／空穴净供给数和供给电荷恒等式残差。供给量由全局数账反求，不给左右端分流或局部空间供给。`before-profile.csv`、`0plus-profile.csv`、`end-profile.csv` 另存快层前后和终态完整空间量；界面 A／B 两行同势但不同统计，各有半格权重。

`frozen-analytic.csv` 是**固定 $0^+$ 电势**下的精确指数，生产 `exponential_step` 在同一固定率极限实际回到它；该解析曲线是独立公式对照，代码内自查由同一作者实现，不能自行成为独立审阅。完整反馈轨迹由新占据重解 Poisson，与这条冻结场指数的差是模型差，而非自动归为时间误差。

`density-time.csv` 从倍密度自身的共同费米平衡初态开始；`slow-time.csv`／`fast-time.csv` 同倍所有匹配四率，静态根应不变；`finite_dos-time.csv` 是三个等面积位置数的离散谱，总量保持 $8\times10^{14}$ m⁻²，不声称已验证连续 DOS 的能量收敛。`split-time.csv` 输入 $F_n=-0.45,F_p=-0.50$ eV，保留两个池的独立物理意义。

[dynamics.svg](results/dynamics.svg) 回答滞后、反馈、时钟和多能级问题；[charge-balance.svg](results/charge-balance.svg) 回答动态储电时为什么两净通道不相等，以及四事件和电极怎样入账。图只消费这些输出 CSV，图例读取同次 `results.json` 中保存的密度／率倍数和能级；当前四图布局要求恰有三个能级，其他数量可由 solver 求解但绘图明确拒绝，需另选布局。横轴 μs，能级使用共同参考 eV，电荷每面积而非总 C。

## 改条件时先写预测

**半引导。** 把 `capture_factors` 从 0.2／5 改为 0.1／10，50 μs 都可叫长期终点吗？如果四率同倍，何种对照比“终点相近”更有力？

> [!question]- 解释性答案
> 慢例可能更远离平衡，要看 $f-f^*$、共同 F 静态根与观察时间；不能保证固定 50 μs 对所有系数都够长。固定输入后的理论轨迹应按系数倍数缩放时间，比较重叠时间窗并控制两份时间步误差，比只比较终点更能检验时钟。保存更长观察窗时也需遵守有限步数预算。

**撤提示。** 若某次输出概率合法、四事件和 Gauss 都通过，但相邻两时间步轨迹明显不同，可以接受那条快动态曲线吗？若实际样品随扫描方向出现迟滞，本例已识别真实陷阱参数了吗？

> [!question]- 解释性答案
> 不可接受为精确动态结果：保界、代数守恒和空间根只分别支持其对应层，冻结率时间积分仍需收敛。有限占据记忆可以产生速率依赖，却不能仅凭相似迟滞判定具体缺陷；仪器、空间输运、热、极化和多态机制均可影响观测。要识别真实 $D_{it}$／截面还需匹配测量协议、额外温度／频率／谱观测和模型误差证据。
