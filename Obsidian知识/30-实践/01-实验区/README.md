## 安全恢复小抄

- **先比较版本**：早期导入批次曾按未初始化 Git 的副本说明恢复；当前副本是否受 Git 管理须由读者在自己的目录检查。日常编辑先保留副本，再比较改动；确认已有 Git 时才使用 `git diff -- 目标文件`。
- **用 File Recovery**：在 Obsidian 中打开命令面板，搜索 **File recovery: View**，选择文件和时间点，预览历史版本后再恢复需要的内容。
- **撤销与恢复**：编辑时用 `Cmd/Ctrl+Z` 撤销，误撤销可用 `Cmd/Ctrl+Shift+Z`（或编辑器菜单中的重做）。

恢复前先保存当前仍想保留的内容，并逐段检查差异。本页只说明恢复方法，不执行删除操作；任何删除或批量改动都请先确认范围并保留可回退版本。
