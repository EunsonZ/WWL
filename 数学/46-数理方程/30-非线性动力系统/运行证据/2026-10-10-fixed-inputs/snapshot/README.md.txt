# 非线性动力系统有限复算

这里的程序帮助复算阻尼摆、径向极限环、Euler 伪周期、固定金融反馈、非正规瞬态与一个二值 iid 乘法例。Python 3.10+ 标准库即可；无第三方依赖、网络请求或导入时执行。使用单进程，不创建额外线程。

可以把整个目录复制到另一台机器，再在任意工作目录运行源码的绝对路径。默认输入按源码所在目录寻找，不依赖当前工作目录，也没有旧临时目录引用。

```bash
python3 -B "/绝对路径/30-非线性动力系统/dynamics_lab.py"
python3 -B "/绝对路径/30-非线性动力系统/dynamics_lab.py" --output-dir /tmp/wwl-dynamics-your-new-run
```

默认只将 JSON 打印到标准输出。指定输出目录时，必须是尚不存在、位于课程和带 AGENTS.md 的工作区外部的路径；创建该目录后写入 `report.json` 和 `pendulum-phase.svg`。保留 stdout、stderr、退出码与原始输出，可以辨认实现失败、数值域拒绝和数学模型失效。不要覆盖失败的第一轮记录。

`fixed-inputs.json` 是默认配置；`--inputs /绝对路径/你的输入.json` 可指定同一 profile 的新配置。`expected.json` 独立列出正文代数推导出的固定预期，不由程序输出生成；执行者另写 Fraction/解析 oracle 对照它。修改输入时先写出新预期与适用条件，固定预期不自动认证改过的配置。程序的有限断言只覆盖相应轨迹、精确有理数和默认容差。

最小预跑就是上述固定配置：三种步长的短轨迹和至多20轮二项计数枚举，没有随机蒙特卡洛或大量样本。执行者先以60秒上限预跑；完整运行也限制在5分钟内。教学接口对单条 RK4 轨迹最多100000步、乘法枚举最多100轮。任务组织者控制全局最多两组数值实验并发；本目录不会自行调度其他任务。

径向接口只接受有限参数、$10^{-6}\le\mu\le100$、$|\alpha|\le100$、$r_0=0$ 或 $10^{-6}\le r_0\le10$、$0\le t\le100$、$\mu t\le100$。`expm1` 保留小时间下 $1-e^{-2\mu t}$ 的差值精度；近零分母另有保守取消误差护栏。非正或未分辨分母均拒绝认证有限半径，错误文本不独自证明物理爆破；域外拒绝也没有关于一般 ODE 稳定性的结论。

课程主解释见 `00-非线性动力系统-MOC.md` 至 `04-确定衰减与随机乘法增长.md`。实验逐项解释和完整源码镜像在 `80-动力系统有限复算.md`。有限执行、来源核对、一般证明、Obsidian 显示与真人学习是不同证据层。
