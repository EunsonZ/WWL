## 问题与验证对象

解释浅复制和闭包绑定；用非有限数和嵌套 bool 推翻错误验证；说明 TaskGroup 的任务所有权与取消清理。

实际脚本检验：直接读取两个已修正文档代码块回归；浅复制；TaskGroup 清理。3.11+ 示例与后续 free-threaded CPython 分开；科学计算生态是入口，不替代每个库的专门课程。

## 执行方式

在 Vault 根目录执行。先阅读源码；不要启用 Python `-O` 或 C/C++ `NDEBUG`，否则断言可能被删除。

```bash
python 计算机知识/_labs/round3/PY/test_python.py
```

统一运行器只使用系统已有工具，不下载依赖；编译产物写在临时目录并清理，每次运行的结果写入 `Logs/运行/round3-labs/<运行时间戳>/计算机知识/round3_lab_results.json`。缺少工具明确 SKIP，不伪造通过。Python 要求 3.11+；C/C++ 编译器需支持 C17/C++20 与所用消毒器；TypeScript 需本机 tsc 和 Node。

- [test_python.py](test_python.py)
