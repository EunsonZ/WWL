# U1：同一 RC 跨层复算

这是一份 CPU 解析模型实验。先用 [[电子电路/10-电路基础/04-同一RC从物理到离散实现|RC 六层正文]] 解释模型和索引，再运行下面的小实验。目标是能够把每个异常对应到一个具体条件：初值、源负载、容差、输入保持、离散步长、块状态或舍入。实验不包含 SPICE、实体测量、ADC、目标设备调度或真人学习效果。

高中补桥先预测 1 ms 的电压，用 $\tau=RC$ 和指数手算，再查 `assets/results.json`。本科快进先核对 `RC` 的 K 与 τ、输入区间语义，随后跑测试和联合迁移题。两条入口共享源码，不另维护一份简化模型。

## 先给可检查的规格

所有 API 数值采用 SI：电阻 Ω，电容 F，时间 s，频率 Hz，电压 V。名义参数 R=1000、C=1e−6、Rs=0、RL=正无穷；输入为 1 V 阶跃，v0=0。有限源/负载配置用 Rs=200、RL=10000。`RC` 只接受正 R/C、非负有限 Rs、正 RL（允许正无穷），派生时间常数也必须可表示。

`step(times, level, v0)` 返回所给非负、不降时间点上的常输入闭式值。`frequency(hz)` 返回零状态稳态复电压比。`simulate(inputs, ts, v0, method)` 的一维输入长 n，表示 n 个保持区间；返回长 n+1 的状态数组，含初值。`method="exact"` 精确解同一 ZOH 输入；`method="euler"` 用起点斜率。不存在默认状态缓存，调用者明确传递上一块末值。

QFormat 是参考有限字长仿真：16 位有符号、14 小数位，四舍六入五成双、饱和；输入/初值/系数分别量化，每步乘加在 float64 计算后舍入一次。它没有整数 DSP 乘法器的中间溢出语义。整数硬件、每次乘法单独舍入或环绕溢出，需要另立实现规格。

## 十项验证各自证明什么

手算值核对 τ=1 ms、$v(\tau)=0.6321205588$ V、截止频率 159.154943 Hz、截止处 −45°。有限负载测试先由直流电流余额算终值；闭式初值测试独立从 $C\dot v=U/R_t-(1/R_t+1/R_L)v$ 解出衰减率。分段输入用 Duhamel 积分逐段求末值，再检查块拼接。零输入能量测试检查 $E(t)+\int p_Rdt=E(0)$。Euler 测试用步长减半后的误差比接近 2 验证一阶收敛，并核对 2.5 ms 反例的独立数列。精确保持的凸包测试检查被动一阶状态不会越过初值与保持平衡值的范围。

Q 测试核对 tie、饱和、量子，并使用含系数缺陷的误差界。小步长测试用正小增量检查 `expm1` 未把结果相消为零。无效参数测试涵盖零/负/非有限、二维输入、逆序时间、非法方法与派生溢出。测试不是物理测量，也没有证明模型已包含所有非理想因素。

RLC 图使用三种阻尼闭式，额外把电压、导数和电流代回 KVL，以及 $\dot E=ui-Ri^2$；此处没有使用 RC 递推替代 RLC 证明。完整推导与初值在 [[电子电路/10-电路基础/05-RLC二阶响应与能量|RLC 二阶正文]]。

## 自己改坏一次

先把 `RC(rs=200, rl=10000)` 的终值与时间常数写在纸上，再比较原模型：应为 K=0.892857、τ=1.071429 ms。把 v0 改为 0.4 V，应只新增零输入衰减项；把 ts 改为 2.5 ms，exact ZOH 稳定而 Euler 失稳。把输入分成两块，应传递边界状态；每块从零开始则是有意引入错误。

改变 R±5%、C±20% 时，1 ms 输出边界 [0.547809,0.731738] V 是容差矩形的最坏组合，未给概率。不要把 `frequency` 用来求非零初值的全部瞬态；不要把 exact ZOH 用于真实斜坡并叫它精确连续解。绘图线把采样点连起来，并不表示点间电路轨迹。

## 联合迁移与答案边界

将源电阻改为 200 Ω、负载改为 10 kΩ、v0 改为 0.2 V，软件周期 0.5 ms，并把输入改为 0 到 1 ms 的真实连续斜坡。先独立提交方程、1 ms 预测和模型选择，随后对照 [[电子电路/10-电路基础/04-同一RC从物理到离散实现#联合迁移题与等价答案|正文完整答案]]。正确连续解约 0.391060 V；本 API 的输入保持假设不能直接代表斜坡。采用足够小步长并报告收敛估计，或另写分段线性精确更新均可，不能为了通过而把斜坡的真实定义偷偷改成阶梯。

若拟合只有电压轨迹，只能识别 RC 的组合或加载参数组合，未必分别识别 R/C。完整实机任务要记录源波形、探头/仪器输入、元件容差、接线与原始数据，并比较模型残差；没有这些证据时允许“尚不能区分”作为诚实结论。
