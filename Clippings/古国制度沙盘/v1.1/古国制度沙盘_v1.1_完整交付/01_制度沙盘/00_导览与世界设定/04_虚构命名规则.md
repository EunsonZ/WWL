# 古国虚构命名规则

## 一、适用范围

本规则约束除现实资料目录外的全部古国文件，适用于国家、地域、机构、职位、法源、公共项目、企业、政治团体、社会组织、信息系统和指标。目的不是追求生僻，而是同时做到原创、可读、可检索和职责可辨。

## 二、命名四原则

1. **原创隔离**：不得使用现实国家、机关、法律、公共企业或商业企业专名，也不得只替换其中一个字造成明显影射。
2. **一名一物**：同一正式名称只指一个主体；同一主体只有一个正式全称和一个登记简称。
3. **职责先于气势**：公权机构名称至少包含一个功能词，如“帑、选、数、劳、能、居、约”；不得使用“总管一切”式名称。
4. **稳定可追溯**：改名不改变制度编号；旧名永久保留为历史别名，不得转配给新主体。

## 三、词形结构

### 1. 公权机构

正式名称采用“原创功能词根＋组织尾称”，一般为四至七个字：

- `台`：仅用于守护共同宪章连续性、典礼或程序确认，不拥有日常执行链；
- `坛／庭`：用于公开议事、代表审议或特定独立审查；议事庭不作个案行政决定；
- `府`：用于综合执行或卫备指挥，必须受预算、审计和裁判约束；
- `院`：用于独立裁理、专业守护、研究或公共服务保障，名称必须写明功能；
- `署`：用于规则执行、监管、登记或专业行政，不得兼任被监管企业的所有者；
- `会`：用于多人共同决定、所有权受托或跨机构协调，必须另列成员来源和回避规则。

尾称不单独决定权力，权力只来自有效制度编号。任何新机构必须在词典中登记“可以做、不得做、首席职位、任用制衡”后方可进入正文。

### 2. 职位

职位采用“机构专属功能词＋角色尾称”，例如“总筹官、总托护、首席裁理”。不得使用能让一名职位同时支配立规、执行、裁判、审计或统计的称呼。代理职位写作“署理＋正式职位”，最长不得连续署理一百八十日。

### 3. 企业

企业采用“高区分度意象品牌＋业务词＋法定形态”，例如“曜脊输能网社”。公共企业必须用“网社、基社、供给社、工社”等业务形态，不得仅凭品牌隐去公共属性；商业企业统一使用“股份社、合伙社、协作社”等法定形态。

企业名称不得含有监管、裁判、审计、选务或法源意味的词根。企业无论所有权为何，都不得以名称暗示拥有公权力。

### 4. 地域和项目

- 一级地方单元统一称“衡域”，二级称“协区”，基层服务单元称“坊社”。
- 地名采用自然地貌或虚构复合词，不用现实行政区名；示例地名不得自动成为正式单位。
- 公共项目采用“目标＋期限／批次”，禁止使用领导者姓名、企业品牌或永续性口号命名。

## 四、法源与文件标题

古国法源只有以下四类，名称格式固定：

1. 共同宪章：唯一最高法源，正式题名《共衡宪章》；
2. 公共规则：题名格式《事项＋公共规则》；
3. 实施规程：题名格式《事项＋实施规程》；
4. 地方规约：题名格式《衡域名＋事项＋地方规约》。

“办法、条例、法、令、决定”等词不得被用作新的法源层级。机构内部的工作指引、操作手册和技术规范必须在标题中明确其非对外法源性质。

## 五、保留词根与排他含义

| 词根 | 保留含义 | 使用限制 |
|---|---|---|
| 守章 | 共同宪章连续性与程序确认 | 仅守章台及其职位使用 |
| 共议／民席／域席 | 全国议事及两类代表基础 | 不用于行政、企业或社会组织 |
| 裁理／终裁 | 宪章与普通司法裁判 | 不用于行政复核和商业仲裁品牌 |
| 追诉 | 公共检控 | 不用于警务侦查或私人索赔 |
| 帑核 | 公共财政审计 | 被审计单位不得自称帑核 |
| 选信 | 选务登记、投票可信性 | 不用于政团或候选组织 |
| 国况 | 独立统计测量 | 政策机构不得以“国况”发布自我绩效结论 |
| 数权 | 个人数据权利与公共数据边界 | 不表示数据所有权归机构 |
| 帑筹／币值／融业 | 财政、货币、金融监管三项分立功能 | 三个词根不得集中于同一机构 |
| 市序 | 竞争与市场公平 | 不含行业许可或企业所有权 |
| 公业持衡 | 全民信托资产的所有者职能 | 不含行业监管、采购或企业经营 |
| 安序／追诉／裁理 | 警务、检控、司法三条分立链 | 人员和个案指令不得互相隶属 |
| 秘权鉴察 | 对秘密权力的外部监督 | 不从事情报采集或行动 |

## 六、简称、别名与编号

1. 正式简称须在词典登记，通常取两个功能字加组织尾称；不得用容易与另一机构混淆的首字母串。
2. 制度文件第一次出现主体时写全称，随后可用登记简称；文学作品可有民间绰号，但须标明非正式。
3. 机构编号采用 `GG-ORG-三位序号`，企业编号采用 `GG-ENT-三位序号`；编号一经分配永久冻结。
4. 合并、拆分或改名须同时登记旧名、继受主体、生效阶段和存量文件处理；禁止静默替换全文。

## 七、新名称登记程序

提出者先提交候选全称、简称、词义、职责、排他边界和三个替代名。总督依次完成：

1. 与虚构机构、职位和企业词典做精确与近似重复检查；
2. 与现实专名禁用表做人工和自动隔离检查；
3. 检查词根是否暗示未获授权的权力；
4. 检查监管者、所有者、经营者、统计者、审计者是否被混同；
5. 登记编号、正式简称、历史别名和首用文件。

未完成登记的名称只能以“候选名”出现在审议记录，不得进入生效制度、预算、合同或数据字段。

## 八、自动与人工检查

- 自动检查：完全重复、包含关系、同音近似、编号重复、禁用专名、简称冲突和企业／机构词根串用。
- 人工检查：是否形成现实影射、是否过度生僻、是否误导权限、是否对某地域或群体带贬义。
- 发现冲突时，以较早登记者保留名称；后登记者改名。若较早名称本身违反现实隔离或权力边界，则整体更名并保留修订记录。
