# 高等代数课程地图

## 本科系统课程

高等代数研究“哪些改变坐标不会改变本质”。从多项式整除出发，逐步构造算子不变量和标准形，再将同态、商结构与扩张统一起来。

**先修：**线性代数中的基、线性映射、行列式、特征值与内积。01–02 多项式内容可以提前学习。

### 从结构语言到存在、计数与分解

11的陪集与群作用之后，读 [[数学/25-高等代数/15-有限群Cauchy与Sylow计数|Cauchy与Sylow]]，理解素数阶元素、Sylow子群存在性、共轭与计数怎样排除群结构；01和12之后，读 [[数学/25-高等代数/16-整环Euclid域PID与唯一分解|整环分解链]]，核对Euclidean→PID→UFD的条件与逆箭头反例。两支可并行，再结合13读 [[数学/25-高等代数/17-群环域结构综合题与反例|结构综合题]]。

先手算S3、D4和Gaussian整数，再用 [[数学/25-高等代数/81-有限群与因子分解复算|有限枚举实验]] 检查指定例；有限枚举不能证明一般定理。一般有限 Galois 对应可继续沿 [[数学/25-高等代数/30-Galois理论/00-Galois理论-MOC|Galois 证明链]] 阅读：嵌入延拓→正规可分→Artin 固定域→双向对应与正规商群，再用双二次域和 $S_3$ 对照全部中间域。根式判别单列所用条件与外部依赖；PID 但非 Euclidean 的严格反例沿 [[数学/25-高等代数/40-PID与非欧几里得反例/00-PID与非欧几里得反例-MOC|负十九二次整数环课程]] 阅读：整数环与理想类 → Minkowski 界 → PID → 排除任意 Euclidean 函数。

### 一般模与有限群表示

已有 F[t] 算子分类进一步推广为 [[数学/25-高等代数/50-模与有限群表示/00-模与有限群表示-MOC|模与有限群表示课程]]：一般模/正合列 → PID 有限生成结构 → 整数核像商 → Maschke/Schur → 特征标分解。用 S3 贯穿群作用、置换矩阵和二维不可约块；循环群支线导出有限 Fourier 与周期卷积，同时标明同调和模型等变的不同作用对象。

### 学习验收

1. 由核维数序列重建 Jordan 块，而不是仅凭特征值猜标准形。
2. 说明有理标准形与 Jordan 形各需要什么底域条件。
3. 计算商环、有限域和简单 Galois 对应，并说明“子群”与“正规子群”的区别。
