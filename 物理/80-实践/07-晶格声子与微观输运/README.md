# 晶格、声子与微观输运复算

## 晶格与能带的有限检查

对应 [[物理/50-半导体物理/09-三维晶格倒格子与紧束缚#倒格子是相位的对偶，一区是距离的分区|倒格子几何]] 和 [[物理/50-半导体物理/09-三维晶格倒格子与紧束缚#以局域轨道为基，带宽来自相邻格点的耦合|紧束缚基]]。先预测：改变胞数只会改变允许波矢间距，还是也会改变余弦带宽？把 hopping 减半时，带底质量与速度怎样改变？

规范源码 [lattice_transport.py](lattice_transport.py) 只用 Python 标准库；有限卡 [inputs.json](inputs.json) 给六角几何、简单立方电子、单原子链、三维长波 LA 形变势及无量纲屏蔽比较，卡之间不声称来自同一真实材料。代码内部电子/声子散射能量用 J；输入 eV 乘 $q$，输入 nm 乘 $10^{-9}$。这里没有经验迁移率拟合参数。

```bash
python3 lattice_transport.py --inputs inputs.json --out /tmp/wwl-lattice-run
```

命令产生 `results.json`、`band.csv`、`phonon.csv` 与 `assets/*.svg`；`--out` 指定新输出目录，读者可与本页同版保留的输出逐项比较。它不运行既有实践 03–06，不安装依赖，不调用材料数据库或第一原理软件。运行结果认证的是这些教学方程的有限计算。

几何与电子的可检查量：$\mathbf a_i\cdot\mathbf b_j=2\pi\delta_{ij}$，$N=960$、两自旋态数 1920；有限 16 格环的 Bloch 和正交残差；简单立方带宽 3 eV、带底质量约 $0.6096m_0$、$ka=\pi/2$ 速度约 $3.7982\times10^5$ m/s。独立检查应另构造 16×16 最近邻环矩阵或逐点作用于 Bloch 向量，核 $Hc=Ec$，不能仅调用源码同一色散函数作为 oracle。图中只有一条 $\Gamma-X$ 路径；不把它的点数误称整个三维 BZ 的态数。

## 声子到电流的独立检查

对应 [[物理/50-半导体物理/10-声子微观散射Boltzmann与Hall因子#一条链的动力学完整求到谱|谐链]]、[[物理/50-半导体物理/10-声子微观散射Boltzmann与Hall因子#一种机制真正算出速率：LA 形变势|微观速率]] 和 [[物理/50-半导体物理/10-声子微观散射Boltzmann与Hall因子#从能量依赖寿命推迁移率与 Hall 因子|能量权重]]。

单原子链卡独立核 $N=32$ 的差分力矩阵：每行和为零，质量加权矩阵作用于 $e^{i2\pi jl/N}$ 应给非负本征值 $\omega_j^2$；零模是自由质心，只有 31 个非零频率正常坐标。全链每模一个坐标，不能给每模再乘电子自旋。长波斜率应趋 $10^4$ m/s，区边角频率 $4\times10^{13}$ rad/s。

LA 卡应从离散终态的归一、每自旋 DOS、$D_A^2k_BT/(\rho Vc_s^2)$ 的 V 抵消独立重建系数，再核 $\tau\propto T^{-1}\varepsilon^{-1/2}$、$\mu\propto T^{-3/2}$。电流权重的三个积分可用 $u=t^2$ 换元后另外求积（平滑被积函数），比直接调用本源码 `moments()` 更独立。闭式 $r_H=3\pi/8$，相应 $n_H/n=8/(3\pi)$。源码的有限 $u\le40$、4000 区间 Simpson 值可有离散误差，尤其二阶矩在 u=0 附近有平方根；将区间数加倍或换元比较时须报告实际误差，而不以“曲线看着一致”判通过。

## 实验与材料的输入边界

真实样品需要原始平移矢量、原子基/轨道/重叠矩阵、材料与温度、声子分支及耦合张量、有效质量/谷、掺杂和屏蔽条件；实验还需要几何、接触、温度、磁场/电流符号及原始测量。此卡没有这些现实输入。第一原理与硬件测量在需要时消费这些接口；本实践并不等待它们才能检查教学理论。

输出未认证 Obsidian 显示、真实材料预测或真人掌握。重要结论与数值须由非作者独立核查后整合；独立核查的实际结果由交付记录承接。

同版保留的 JSON/CSV/SVG 来自作者本机有限运行，以及倒格图缩放和独立 runner 指出横轴标签重叠后的两次重生成（标准库，三次均使用 guard 请求 1 线程、60 s，退出 0；三次 JSON 字节一致）；没有重跑实践 03–06。第三次只增加通用图底部留白，刻度基线由 335 移至 315，轴标签仍在 342、图例在 368。这些作者运行用于产物生成与自查，独立核查的最终字节及渲染结果由交付记录承接。有限 Simpson 的 Hall 值约 1.17798926，闭式约 1.17809725，相对差约 $9.17\times10^{-5}$；图用闭式迁移率/Hall 因子，JSON 同时保留求积值与其实际步数，避免把两种精度混作一条证据。
