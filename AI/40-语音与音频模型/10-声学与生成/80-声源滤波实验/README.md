# 声源—滤波有限实验

先读[[AI/40-语音与音频模型/10-声学与生成/01-声源滤波与音高共振峰|主解释]]。这是合成脉冲声源，不是录音、真实音素或文本到波形模型；不需要麦克风、外部数据、权重或远程计算。

## 输入、样本与代码真源

[[AI/40-语音与音频模型/10-声学与生成/80-声源滤波实验/inputs.json|固定参数]]保存三受控case：fs=16000、保留1秒、预热.25秒；f0=125/250/125；两极点角频率500/1500、500/1500、500/2200 Hz，B=80/120 Hz。g由DC增益1约定确定。浮点波形全部以共同增益α=2.023810329075194缩放，三case中最大峰值.8，不逐文件归一化。

[[AI/40-语音与音频模型/10-声学与生成/80-声源滤波实验/source_filter_lab.py|源码]]和[[AI/40-语音与音频模型/10-声学与生成/80-声源滤波实验/test_source_filter_lab.py|六项行为检查]]只实现当前有限模型；数学STFT既有帧起点/对称Hann/FFT零填充规范在[[数学/70-信号处理与多模态数学/02-采样定理波形STFT与Mel频谱#4. STFT：局部时间片上的 DFT|已有主解释]]，没有重造Mel或相位重建理论。镜像见[[AI/40-语音与音频模型/10-声学与生成/80-声源滤波实验/code-sync/源码与测试镜像|源码与测试镜像]]。

[[AI/40-语音与音频模型/10-声学与生成/80-声源滤波实验/results/results.json|结果JSON]]保留每节系数/半径、周期、峰/RMS、稳态与周期误差、PCM量化误差、98帧中心与频率网格。`results/samples.npz`是用NumPy无pickle读取的全部实际数组：

| 字段 | shape/意义 |
| --- | --- |
| `base/pitch/filter_source` | (16000,)，按全局脉冲源裁剪，幅度0或1 |
| `*_raw` | (16000,)，串联滤波输出、未乘共同α |
| `*_samples` | (16000,)，α×raw，float64，图/分析的实际输入 |
| `*_pcm16` | (16000,)，round(32768×samples)，小端int16，WAV原始帧字节 |
| `*_stft` | (98,257)，complex128，对称Hann400/hop160/FFT512 |
| `*_spectrum_amplitude` | (8001,)，单边幅度：abs(rfft)/N，内部正频率乘2、DC/Nyquist不乘2 |
| `frame_starts/frame_centers_s` | (98,)，0..15520样本/对应中心秒 |
| `spectrum_freq_hz/stft_freq_hz` | (8001,)/(257,)，1 Hz /31.25 Hz网格 |

JSON中局部包络峰是65537点频率网格在每个F±250 Hz窗中取最大，本固定输入确有内部峰；它们不是连续求导得到的精确极值。若更改宽带B或让两个窗重叠，必须按实际曲线判断，不能把窗内最大点一律解释成独立共振峰。

三个`results/*.wav`是16 kHz、16 bit、单声道、恰16000帧；图使用量化前float，实际WAV解码q/32768误差≤1/65536。可配置peak上限为32767/32768，拒绝像.999999这种会让正峰round到32768并int16溢出的值；不以wraparound冒充音频。默认PCM误差base/pitch/filter约1.49950e−5/1.52349e−5/1.51052e−5，均在界内。

## 必要实验的重要性与失败判据

| 对象/断言 | 重要性与理由 | 独立预期、容差/失败 | 实际结果/边界 |
| --- | --- | --- | --- |
| 两极点、递推与串联 | 高；若符号/增益错，源滤波主机制即错 | 独立解析h_j并线性卷积三个源，不调用递推；raw逐样本绝对差≤1e−10。极点模均<1，DCgain1，B由−lnr fs/π还原 | 正式r=.984414763/.976713470；一般稳定性用正文绝对可和证明，不由有限运行代替 |
| 周期/裁剪相位/谐波 | 高；最强谱线误当f0会误解音高 | 独立周期DFT或级数含4000裁剪相位，预测全复DFT绝对差≤2e−8（未除N，对幅度系数≤1.25e−12）；P128/64，首脉冲96/32；base/filter激励完全一致 | 三DFT误差约1.1e−11、周期重复误差≤1.86e−15；最强谱线均500 Hz，源f0确不同 |
| 98×257 STFT与图轴 | 高；样本/帧率/bin混淆破坏后续音频token解释 | 直接复指数求和核至少首/中/末帧全257bin，复数绝对差≤1e−9；帧中心.01246875到.98246875，末80样本未覆盖；图栅格从同数组量化，坐标≤1e−3px | 默认shape/轴精确符合；STFT不承担真实音素/听者识别 |
| 共同缩放与PCM文件 | 高；独立归一化或int16溢出会换实验 | α全case同一值；每WAV元数据16k/16bit/1ch/16000帧，帧字节等`*_pcm16`，解码误差≤1/65536；.999999 peak必须拒绝 | 最大峰.8且三量化误差在界内；文件没播放，边界保持原样无fade |
| 受控变式与图/重建 | 中；错图或旧标签会给错误解释 | 改f0而节系数不变；改F2而源不变；默认JSON/NPZ/3WAV/2SVG共7产物同环境byteexact；两asset逐字同结果SVG；变输入图仍读同次数组 | 波形/谱包络/STFT同源；非人类质量检验 |
| codec负载账本 | 中；易把不同时间轴当同一个token率 | 5s恰250帧×8×10=20000bit；PCM3840000bit；比192，4码本时10000bit/比384，整数精确 | 只完成指定算术，不是运行codec或质量评测 |
| 人类听测 | 高；数字机制不能替代听感、可懂度和自然度 | 见下一节的固定材料、分配/播放/答案记录；只有实际记录才给听感结论，现状态not_performed | 没有招募/播放/作答；仍有独立价值，不以合成图豁免 |

以上容差限定本默认浮点/FFT输入域。任一波形、元数据、相位或索引偏差超界先定位原因；不通过放宽到“图看着差不多”签收。源码测试含小规模解析卷积；关键独核需另一路实现，不能只把作者函数互相调用当证据。

## 听测接口与不代填记录

固定材料是base.wav、pitch.wav、filter.wav（全为本课程自生成、没有说话人或版权录音），不添加自然元音标签。记录模板在[[AI/40-语音与音频模型/10-声学与生成/80-声源滤波实验/听测记录模板.csv|空CSV]]；目前只有字段名，不能读成已经听过。建议一次具体的自愿听测：

1. 在实际播放器固定无音效处理、音量与播放设备，记录设备/播放链与是否使用文件原切边；任何响度匹配必须另存变换参数和材料版本，不能冒充本共同增益版本。
2. 保持每位听者内的配对随机顺序且先不给参数标签；先比较base/pitch，再比较base/filter，允许“不确定/无差异”；记录随机分配和每次原始回答，不用模型代答。
3. 分别询问感知周期性/音高差、音色差与切边影响；本材料没有真实文字，**不适合据此计算文本可懂度或真实语音自然度**。这些原要求应在下一条真实文本到波形链用合法样本与明确任务另测。
4. 记录实际听者数/试次/缺失与条件，先保留原始观察再选择汇总口径；没有事先功效设计或足够人数就不声称推广到人群。无需为本候选批准而虚构听测。

这个接口没有自动触发真人实验，也未播放系统音频。可听材料存在、波形结构正确、听者感知到预期差异是三层证据，分别报告。
