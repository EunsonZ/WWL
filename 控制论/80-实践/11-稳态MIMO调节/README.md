## 在独立复制目录复算

把本文件所在整个目录复制到你自己的临时工作目录，从复制目录运行。依赖安装限定那份新虚拟环境，数值过程经复用护栏运行；正式结果目录保持作为对照。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
python3 -B numerical_guard.py --threads 1 --timeout 60 --lock-timeout 60 -- .venv/bin/python -B regulation_lab.py --inputs inputs.json --out reproduced
python3 -B build_figures.py --results reproduced
```

第一个数值调用就是全部9个有限案例的60秒预跑；失败则先读错误与依赖，不重复增加并发。常规任务仍限定1线程、最多300秒，护栏只允许两个同用户共享数值槽之一；同次课程任务并发合计不得超过2。护栏逐字节复用实践10，控制子进程线程环境与超时，不是内存硬上限或硬件实时期限。`--timeout` 合法范围1–300，默认命令已足够本模型。绘图脚本仅标准库，不启动额外数值任务。

本次真实独立复算使用已存在的隔离Python 3.14.7、NumPy 2.5.4、SciPy 1.18.1，仅只读复用该环境，未改系统或旧环境；上面的新 `.venv` 安装是复建接口，本次没有据此声称已做新环境安装。精确版本在 [requirements-lock.txt](requirements-lock.txt)；矩阵指数来自SciPy，运行与图源不调用外部服务。

`--out` 拒绝非空目录。程序先完成输入验证与所有计算，在旁边新临时目录生成全部CSV/JSON，再发布完整结果；失败不覆盖旧结果。绘图拒绝任一同名SVG已存在的结果目录，先准备两个完整文档再独占创建；改参数后使用新的输出目录，不覆写既有证据。

## 输入输出与实际闭环

时间轴 $\tau=t/t_0$，默认 $t_0=1\,s$，九分支都是连续对象和即时控制器；`dt_tau=1/50` 是保存结果的间距，饱和分支也是RK4步距，**不是数字控制采样周期**。所有数值参数允许有限数值或有理字符串。实际积分状态顺序 `(x1,x2,x3,hatx1,hatx2,hatx3,eta1,eta2)`。

固定卡明确列出 $A=-\operatorname{diag}(1,2,3)$、$B$、$C=B^T$ 与反例 $C_b$（$D=0$、过程入口 $E=I$）。基础衰减率与端口数组必须保持这份固定模型，否则真实拒绝，不把默认原点零点与 $q$ 恒等式套到任意新矩阵。参数迁移通过 `matched_third_decay` 分支改变真实和观测器的第三衰减率；可修改参考、恒扰动、偏置、$k,\kappa,\ell$、慢/快积分因子、限幅及时间卡。它是指定对象的课程接口，一般 $D\ne0$ 与任意MIMO设计仍按正文的矩阵合同重新建实现。

`horizon_tau<=120`、`dt_tau<=.1`、步数不超过50000；切换时刻严格在区间内，终点/切换必须与步距对齐。衰减率、$\kappa$、缩放因子、限幅与时间尺度须正，$k,\ell\ge0$。非有限量、布尔数值、重复JSON键、错误shape、越界或不稳定的实际线性主分支会被拒绝。给未知字段不产生新物理端口。

| 案例 | 变化及可核结论 |
| --- | --- |
| `nominal` | $r=(1,-1/2)$，无扰动/偏置；全部8状态稳定，到合法平衡。 |
| `disturbance` | $\tau=10$ 后 $d=(1/5,-1/10,3/10)$，普通观测器不知道它；$y\to r$，$e\to(9/125,-13/250,7/125)$。 |
| `slow_integral`、`fast_integral` | 同一扰动，$\kappa$ 默认乘1/4、4；证明仍稳定，有限终点收敛程度与动作量各自检查。 |
| `matched_parameter` | 默认 $A_{33}=-4$，观测器同步；新平衡需重算，保留端口能量证明。 |
| `sensor_bias` | 无过程扰动，$b=(1/5,-1/10)$；测量到参考，真实 $y\to(4/5,-2/5)$。 |
| `no_integral` | 先用合法无扰动前馈校准，再加同一未知扰动；通常留下输出偏差。只有6个活动状态，额外两列eta冻结为0不作为稳定设计状态。 |
| `dc_zero` | 固定 $C_b,r=(1,0),d=0$；原对象可控可观，原点秩缺1，$q=q_0+\tau$ 精确增长，不能稳定全输出积分。 |
| `saturation` | 无扰动，实际逐动作限±1/2，同时送给对象与观测器；默认所需 $u_*=(1,-1)$ 超限，目标不可行且未加防windup。 |

线性八状态分支与六状态前馈对照用分段仿射矩阵指数；在每段把常值强迫加到第9个齐次坐标。扰动阶跃时状态连续，保存的 `d` 按右连续定义，阶跃后的下一步使用新强迫。饱和分支从对象/观测器/积分原方程做RK4，限幅作用于每个子步的动作；观测器收到的是实际动作。

每个案例一个CSV，列含规范化/秒时间、全部8个保存状态、真实/测量输出、两误差、命令/实际动作、三扰动与默认反例的 `q_bad`。`q_bad` 仅在固定 `dc_zero` 中有本页断言的解析意义。`summary.json` 保存实际输入快照、精确有理可控/可观/Rosenbrock/DC秩、实际增益/矩阵/极点、最终误差与线性平衡。`no_integral` 的极点只查6活动状态；`dc_zero` 不解不存在的目标平衡；饱和分支另记未限幅平衡是否超界，以及代回实际限幅方程的残差；默认超界的线性平衡不是实际非线性平衡。

## 结果怎样支持与限制解释

[summary.json](results/summary.json) 与九CSV是本次真实固定输入的输出；图 [tracking.svg](results/tracking.svg) 解释积分与前馈/增益的差别，图 [boundaries.svg](results/boundaries.svg) 解释原点零点、偏置和饱和。每条线由CSV投影，图例同时用颜色与不同线型区分；参数标签消费同次summary而不硬写默认参考/增益。图中的有限终点残差不代替渐近证明。

独立数值核查用未导入生产函数的完整8状态原式DOP853，与生产矩阵指数对照；另用Fraction非零子式rank、特征多项式Hurwitz条件、精确平衡与状态坐标变换核对理论对象。默认饱和RK4 `.02` 与独立解的最大状态差约 $2.79\times10^{-6}$，缩到 `.01` 后约 $3.16\times10^{-7}$；它仅认证指定有限轨迹的数值一致性，不证明一般限幅系统稳定。一个组合参考/扰动/匹配参数改卡与一次饱和步距减半实际重算；错误卡、旧结果拒写也实际触发。

原对象可控/可观rank均3，默认 $\mathcal R_0$ rank5、$G(0)$ rank2；坏端口仍可观rank3，但原点rank4、DCrank1。未知扰动的非零估计误差平衡与正文一致。真实设备、真实采样/延迟、任意模型不确定性和真人掌握度未验证。

## 带回正文的迁移

复制输入卡改 `matched_third_decay` 为5、`reference` 为 `["4/5","-1/5"]`、`disturbance` 为 `["1/10","1/5","-1/10"]`，在新目录运行。先用实际 $G(0)$ 预测合法平衡，再比对两个输出、估计偏差、积分记忆和动作峰值。仅看极点并不能说明目标是否超出限幅。

随后把参考减小到限幅内，图标题会依据本次未限幅平衡是否超界改变；这只是必要平衡检查，实际饱和初始瞬态仍须另查。若想换成任意新端口或非零 $D$，程序会拒绝固定矩阵改卡，应从正文(3)/(7)/(11)重建，而不是删掉守护沿用默认 `q` 或分离结论。
