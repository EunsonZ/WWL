# 土地、住房与城市更新（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：土地所有与用途管制、征收和建设用地、国有与集体建设用地接口、不动产登记、商品住房、租赁、保障性住房、住房公积金和城市更新。
- 房地产金融、物业管理、建筑质量和地方限购限售政策仅在必要处提示，未作全国逐项汇编。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 土地 | 2019年修正、2020年施行的土地管理法及2021年修订的实施条例为主干，继续实行土地公有、国土空间规划、用途管制和耕地保护。 |
| 登记 | 不动产登记暂行条例经2024年修改后现行有效，土地、房屋等不动产权利由统一登记机构依申请登记并提供依法查询接口。 |
| 租赁 | 《住房租赁条例》作为行政法规已于2025-09-15施行，直接适用于**城镇国有土地上**的住房租赁；集体土地上的住房租赁由省、自治区、直辖市人民政府另定管理办法。条例覆盖房源条件、实名合同、备案、押金、经纪机构、转租经营企业和网络平台。 |
| 保障 | 公共租赁住房、保障性租赁住房、配售型保障性住房等由国家政策框架与地方实施规则共同构成，准入、轮候、租售价格和退出条件地域差异较大。 |
| 城市更新 | 2025年中央层面关于持续推进城市更新行动的意见处于实施期；它是政策纲领，**尚无一部统一的全国城市更新基本法律**。 |

## 现行结构摘要

1. **城乡土地所有权二元。** 城市土地原则上国家所有，农村和城市郊区土地原则上由农民集体所有；单位和个人取得的是不同期限、用途和条件下的用益或承包等权利。
2. **规划与用途管制决定开发。** 农用地转建设用地、建设占用耕地、永久基本农田保护、年度计划和项目用地审批相互连接；违法改变用途会触发行政和恢复责任。
3. **征收与市场配置并存。** 为公共利益依法征收集体土地需履行公告、调查、补偿安置等程序；符合规划和用途条件的集体经营性建设用地可依法出让、出租并进入市场。
4. **国有建设用地通过出让或划拨供给。** 住宅、商业等通常有偿出让并设置用途和期限，公共项目可依法划拨；土地价款进入政府性基金预算，形成土地、财政和建设的强连接。
5. **住房供给是市场与保障双轨。** 商品住房主要通过开发、预售或现售交易；保障性住房由政府投资、政策支持或多主体建设，针对不同收入、户籍、居住和人才群体。
6. **城镇国有土地上的租赁进入行政法规层级。** 房源安全、合同备案、押金返还、经纪收费、租赁企业资金和平台核验形成全国底线，具体租金、登记和执法仍由地方细化；集体土地住房租赁另由省级政府制定管理办法。
7. **更新由项目化政策推动。** 老旧小区、危旧住房、城中村、低效用地、基础设施和历史文化保护等纳入更新行动，资金、征收搬迁、居民同意和增值分配依不同项目及地方法规处理。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 土地规划—住房供给 | 国土空间规划、年度供地和用地性质决定可建设的住房数量、区位和类型。 |
| 土地出让—地方财政 | 出让收入及相关税费支持城市建设，又使地方财力与土地和房地产周期相连。 |
| 征收—安置救济 | 公共利益认定、补偿标准、社会保障、住房安置和行政司法救济共同决定被征收人处境。 |
| 预售—工程交付 | 预售许可、合同网签、预售资金监管、工程施工、竣工验收和产权登记跨越多个部门与主体。 |
| 租赁—公共服务 | 租赁备案、居住登记、子女教育和住房保障资格相互影响，但不同城市的材料和条件不统一。 |
| 更新—产权共同决定 | 多产权人建筑和街区更新涉及业主表决、公共利益、规划增容、搬迁补偿、历史保护与公共投资。 |
| 公积金—劳动关系 | 单位和职工缴存形成低息住房金融来源，覆盖程度与正规就业关系密切，灵活就业人员接入仍由地方探索。 |

## 可观察约束与信息缺口

- 土地出让、房地产税费、基础设施支出和地方债之间相互影响，但缺少可逐宗、逐项目衔接的公共资产负债数据。
- 征收公共利益的具体论证、估价假设、协商记录和补偿分布公开程度因地区与项目而异。
- 集体经营性建设用地入市具备法律通道，但全国交易数量、收益分配、抵押融资和后续监管数据仍有限。
- 商品房预售资金监管以地方规则为主，专户拨付、银行责任、资金缺口和项目失败后的购房人顺位不完全一致。
- 保障性住房类型较多，资格、轮候、租售价格、产权限制、违规退出和实际受益数据缺少统一全国口径。
- 租赁条例设定底线后，押金托管、租金监管、维修责任和租赁企业失败处置仍依执法与地方配套落地。
- 城市更新的居民同意门槛、租户参与、临时安置、价值增益分享、历史保护和长期社区影响缺乏统一规则。

## 古国改革需回答的问题

1. 土地所有权、开发权、使用权和公共规划权如何分离，住宅用地到期续期怎样形成可预期规则？
2. 征收的公共利益由谁证明，是否必须比较替代方案；补偿按原用途、市场价值还是重置生活成本计算？
3. 城乡不同土地权利是否统一进入市场，集体成员和长期居住者如何分享增值并保护选择权？
4. 土地收入是否全部纳入统一预算，怎样削弱地方服务对卖地和房价上涨的依赖？
5. 商品房预售是否保留；若保留，资金托管、交付保险、购房人优先权和失败接管如何设计？
6. 租户的期限稳定、涨租、押金、维修、隐私、提前解约和争议裁决有哪些最低权利？
7. 住房保障采用公共房源、租金补贴还是混合模式，轮候和退出如何透明且避免贫困陷阱？
8. 城市更新需要何种业主与租户同意、搬迁补偿、独立评估、历史保护和增值回馈社区机制？
