# 需求与补偿：用同一输入复算金额与图

返回 [[社会科学/20-经济流动与宏观/30-微观经济学/01-价格变化普通需求与补偿需求|正文的三种固定对象]]。本实验只使用 Python 标准库 `fractions`、`math`、`json` 等；不调用优化器。源码 [demand_compensation.py](demand_compensation.py) 是真源，Obsidian 可读的 [源码镜像](code-sync/demand_compensation.md) 与其逐字同步。

## 先预测，再执行

输入全在 [inputs.json](inputs.json)，数值使用字符串以保留有理数，量纲为份、元／份和元。主例旧价 $(1,1)$、预算10、新价 $(4,1)$、偏好 $xy$；迁移例预算12、新价 $(9,1)$；角点例偏好 $2x+y$。从本库根执行：

```bash
python3 -B 社会科学/20-经济流动与宏观/30-微观经济学/80-实践/01-需求与补偿/demand_compensation.py
```

默认在源码旁的 `results/` 输出精确 [JSON](results/exact-results.json) 和 [SVG](results/demand-compensation.svg)，并将同一结果打印到终端。SVG用公式绘曲线、用该次精确结果定位点，只有画布坐标转成浮点；不以离散采样认证全局最优。SVG自带 `title`、`desc`、轴单位、文字和不同线型。

运行前应从正文的不等式得到下面的**独立预期**，而不是先读程序输出再写预期：

| 要检查的断言 | 重要性及理由 | 由模型独立推出的预期 |
| --- | --- | --- |
| 固定收入与固定效用不同 | 高：决定回答的反事实，不能靠同一个“补偿”词代换 | 主例普通束 $(5/4,5)$、支出10、效用 $25/4$；Hicks束 $(5/2,10)$、支出20、效用25 |
| 20元是最低支出 | 高：仅代回能证可行，不能证最省 | 任意 $xy\ge25$ 有 $4x+y\ge4\sqrt{xy}\ge20$，等号在 $(5/2,10)$ |
| 原篮子成本补偿 | 高：常把25误填成Hicks支出，或把15补款误作总预算 | 原篮子新成本25，补15；再优化到 $(25/8,25/2)$，效用 $625/16$ |
| 价格和预算改变后的迁移 | 中：排除只背主例数字 | 旧效用36；固定12元束 $(2/3,6)$；Hicks束 $(2,18)$、总支出36、补24；原篮子新成本60 |
| 线性偏好的角点与并列解 | 高：决定是否可用内点切线和单值需求 | 新价 $(4,1)$ 时固定10元选 $(0,10)$；恢复目标20选 $(0,20)$、支出20；旧篮子新成本40；价格 $(2,1)$ 时整段 $2x+y=10$ 都最优 |

以上重要性是对本课结论影响的判断，不是现实损失估计。2026-10-16在本机用标准库实际运行，固定输入结果与表中预期一致；其后用既有 CairoSVG 将本次SVG渲染成预览图，作者检查了轴、点、线型与标签。精确结果文件可直接读分数，不把 $5/4$ 四舍五入后再回代。一般全局论证仍由正文承担；独立核查由未参与作者推导者另行进行，作者运行本程序不算独立证明。

## 改一个条件，观察固定对象是否被偷换

复制 `inputs.json` 为自己的文件后，可改 `new_prices`、预算或线性权重。为避免固定图的标题、范围和案例标签被误用，参数改变后使用 `--no-figure`，输出到新的目录：

```bash
python3 -B 社会科学/20-经济流动与宏观/30-微观经济学/80-实践/01-需求与补偿/demand_compensation.py --input /绝对路径/自己的输入.json --output-dir /绝对路径/新结果目录 --no-figure
```

程序精确处理的 Hicks 根式要求开方结果仍为有理数；例如新 $p_x$ 可用4或9。非平方有理数根式明确报错，这只是该轻量复算器的边界，不是数学模型失效；正文根式公式仍成立。脚本限定正价格、正预算、正线性权重与唯一角点基线；改变成零价或基线并列选择时，应另写问题并明确选定的旧篮子，不能让程序暗自挑一个参照。可独立改变 `tie_prices`，观察 `kind` 从 `unique` 变成 `segment`；不要把后者当程序漏报数量。

主例图固定于正文的旧价 $(1,1)$、新价 $(4,1)$、预算10及线性权重 $(2,1)$；改变这些值而不加 `--no-figure` 会停止。只有固定案例才生成图。改参数前，先预测支出下界、角点所在轴与并列条件；执行后若不同，先查固定了什么，再查算术。

## 现实数据与政策识别接口

这里没有导入或估计真实家庭数据，也没有实施补贴。要研究现实对象，先记录地区、时期和样本单位，商品质量与价格基准、可支配预算、消费束、补贴用途约束、交易成本和配给。再提出能区分价格变化、收入变化及偏好变化的研究设计；旧篮子成本可由匹配价格数量算账，Hicks所需支出还需要对偏好／替代行为作有根据的识别，不能由两期账单直接读出。

尚未验证的层包括现实偏好估计、价格或政策的因果识别、政府筹资和分配后果、Obsidian目标客户端显示以及真人能否在撤去提示后迁移。此处本机执行与静态图预览不代替这些证据。
