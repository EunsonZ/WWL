# 谐振读出与合成判别

## 运行与有限合同

本实践的两个标签只是两个条件谐振频率。源码模拟经典有阻尼微波端口、指定对称化噪声预算与放大后经典Gaussian观察。没有量子器件主方程、状态准备/跃迁/反作用、真实低温器件或量子保真度。

用已有Python环境在本目录运行：

```bash
python -B -m unittest discover -s . -v
python -B generate.py --output /private/tmp/f07-new-output
python -B -m unittest discover -s code-sync -v
```

`--output`必填，只接受不存在的库外新目录；主库、候选及已有目录前置拒绝。源码纯导入不读argv、不生成、不导入NumPy/Matplotlib/CairoSVG，不写缓存；生成时才加载依赖，使用Figure/rc_context，无pyplot或全局rcParams改变。caller可设MPLCONFIGDIR到自有库外目录。`models.py`/`test_models.py`/`generate.py`为真源，`code-sync/`三镜像逐字节相同，必须作为一个变更单元维护。

## 测试和可复算数据

13项源码测试（镜像同13项）覆盖：原端口能量守恒/无损/临界耦合、两个实状态ODE的独立2000步RK4、长衰减保持可表示初值、短时启动和状态接续、Boltzmann几何概率和Bose占据、经典/零温极限、各级原能量记账、前置损耗代价、独立矩阵求解、原Gaussian密度积分、投影分类、三点轴校准、超大int/无效及有效端点。Gaussian/ODE对照不是量子器件实验。

生成器固定：6GHz、κ/2π5MHz、外比例.8、条件δ=±κ/4、输入1e−17W；100MHz采样，1024段，600段驱动，窗[50,550)。前置η=.5，源/损耗浴20mK，G1=100,N1=.5,G2=1000,N2=20，R0=50Ω。I/Q映射[[1,.08],[.02,.9]]，偏置[2,−3]μV。逐样本噪声等效各坐标48.8405μV，500点平均2.184214μV；平均点直接抽样该Gaussian分布，不伪称存了带噪波形。

每类80训练与200留出平均点，局部Random(seed7)可复现。result.json记录参数、三点校准估计、质心、理论1.91363%与本次留出17/400=4.25%；保留差异，不挑种子拟合理论。data.json保存无噪声完整脉冲，以及留出点的“校正I/Q、测量I/Q”四列和完整参数。没有ADC量化/限幅模型；正文的2mV/12位例仅单独条件预算。
