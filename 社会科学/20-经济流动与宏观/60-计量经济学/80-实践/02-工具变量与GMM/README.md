## 四题参考答案与最近错解

### 一、组合相关与因果机制

VarX=4+1+1=6，Cov(X,ε)=2，故总体OLS=3+2/6=10/3；Γ=(2,1)′，q=(6,3)′，两矩解3。组合Z*=Z₁−2Z₂的Cov(Z*,X)=2−2=0；虽然两个原工具分别相关，线性组合可抵消。不能把“工具个数足够”当秩。

代入X方程，任意θ都有Yθ=3X+2V+U，完整观察分布相同；干预X每单位效应是θ，模型族允许[0,3]。统计矩在系数3处同时为零。只有另加并辩护工具不经其他路径影响结果及相应外生结构限制，才能从矩解到因果斜率3；θ0世界虽工具随机仍有直接路径。近错解“Γ满秩，所以真实因果值必3”把给定矩模型的唯一系数换成未经验证的结构机制。给出族内效应集合正确，但不能宣称脱离此构造所有可能机制只落[0,3]。

### 二、权重、单位与残差

修改后的q=(7/2,9/2)′、Γ=(1,2)′、Qzz=I。OLS8/3；单位权重/2SLS=(7/2+9)/5=5/2。W=diag(1,4)时为(7/2+36)/17=79/34。2SLS结构残差(1,−2,1,2)′给Ŝ=(5/2)I，二步W=(2/5)I，仅改统一尺度，点估计仍5/2；g=(1,−1/2)′，nQ=2。近错解“二步一定换系数”忽略了两个权重可能成比例；“J=2已经证明工具有效”忽略了极限和因果对象。

Z₂×10而W=I的解(7/2+900)/(1+400)=1807/802；调整权重diag(1,1/100)恢复5/2。第一阶段X̂=Z(1,2)′=(−3,1,−1,3)′，软件第二阶段残差(7/2,−9/2,−3/2,9/2)′，给错误的S=[55/4,5/2;5/2,55/4]。它含额外的(X−X̂)β，不是结构ε。估计系数相同不保证每一个软件随附统计量都回答原模型问题。

### 三、分母与两种失败

误差=(aₙ+bₙ)/(κ+aₙ)。κ0时总体E[ZX]=0，所有β同矩；固定κ1/2时一致且√n误差极限N(0,8)。κₙ=2/√n时误差趋于(A+B)/(2+A)，非退化；每个n满秩也不恢复通常正态近似。不能把c1基线的数字直接当c2答案。

n4κ1，分母零等价所有ZV=−1，概率(1/2)^4=1/16；b计数再怎么变化也不能让这个分母有定义，总权重必须保留。直接项γ=1/100时总体比率2+γ/κ：κ1/10得21/10，κ1/100得3。后一组是矩有效性被破坏；前述局部序列没有直接项，仍有效，只是识别强度随n改变。近错解“误差变大就证明工具无效”混淆两条逻辑。

### 四、零Wald不等于没人受益

第一阶段2/5−1/5=1/5；简约式(2/5)×1−(1/5)×2=0；Wald=0。总体ATE=(2/5)×1+(1/5)×2=4/5；顺从者效应1。反向者贡献的符号把两个正效应抵消；Wald为零不是所有人效应为零。

随机性、排除、一致性/无干扰在题中给定，失败的是把该带符号比率解释成顺从者LATE的单调性；这不使潜在处理单调性变成所有线性矩模型的前提。在现实数据看不到双潜在D，不能按单次观察“识别反向者并删掉”，那会另造选择。可改设计、给可辩护限制或报告较弱目标/界，必须说明变更后总体和所需证据。

评分按对象、关键等式和限制给分，接受等价代数/枚举路线；只报近似小数不掩盖分母零、把不拒绝说成认证、或未声明便删样本，都不算对应识别题完成。此评分是材料核验标准，没有真人答题、学习效果或评分者一致性数据。

## 外部真实识别接口与未验层

真实因果结论重要性高：一条未被测量的工具直接路径即可改变目标量而保留良好拟合。接续时先提交协议：研究问题/总体、处理和工具版本、时间零点、可能直接通路与负对照、外生变化制度依据、各预先协变量用途；输入保留来源版本和授权、原单位ID/簇/日期、Z/X/Y与测量机制、选择及缺失原因。没有合法数据/相应授权不导入个体材料，不擅自联系受试者或发放干预。

分配/暴露应区分真正随机邀请、自然制度变化和自行选择；记录谁被分到什么、谁实际暴露、谁接受处理及何时发生结果，禁止以处理后参加筛选替换原分配总体。相关秩与第一阶段按预定控制/总体报告，不为达到阈值搜索工具；结果、工具、模型和全部失败样本同时留存。依赖单位决定S/有效独立信息；若多工具、弱秩或拟合/稳定性失败，停止使用本课常规正态/J校准，转为适合原设计的弱识别稳健或部分识别方案并重新说明保证，不凭模板拼一个窄区间。

观察层可核分布、时点、相关、缺失、工具矩相容及设计的可观察含义；排除与潜在反事实不由J检验认证。预先列能推翻排除的制度/直接结果证据，分开“不拒绝”“功效不足”“与竞争机制同观察”；若变化是政策同时包，应修改结构/目标而非隐藏通路。报告估计、分母/奇异、模型敏感性、外部效度和失败，不能只交显著一栏。
