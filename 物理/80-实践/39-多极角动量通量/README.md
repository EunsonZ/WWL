# 多极角动量通量：有限球的内源与外场两面核算

先在 [[物理/30-电动力学/12-多极辐射角动量通量#应力的次阶项怎样留下角动量|正文的应力推导]]预测：同一个圆偏振电源加线偏振磁源，完整场在近区和远区应给相同的整球角通量；只保留 $1/r$ 辐射场会给零。这次实验让两个预测分别运行，再用球内与球面真正的电荷、电流积分检查守恒。

固定输入的源是球内均匀极化和磁化，$f=100$ MHz、$p_0=10^{-12}$ C·m、$ka=0.2$、$\eta=b=1,\delta=0$。所有相量采用 $e^{-i\omega t}$ 的峰值约定，平均双线性量有 $1/2$。$\mathbf p_b$ 是实际球的电偶极矩，$\mathbf q_b=\mathbf m_b/c$；外场矩乘同一有限尺寸因子 $F(ka)$。本例没有入射自由场，也没有从点偶极奇点积分自力。

源码为 [multipole_flux.py](multipole_flux.py)，输入为 [inputs.json](inputs.json)，随附实际结果为 [results.json](output/results.json)。源码是真源；本文没有重复的活动 `code-sync` 代码块。需要 Python 3 与已有 NumPy；使用已有库环境即可，不需要新安装或运行维护检查器测试。由本库根执行：

```bash
.venv/bin/python -B 物理/80-实践/39-多极角动量通量/multipole_flux.py --inputs 物理/80-实践/39-多极角动量通量/inputs.json --output /tmp/wwl-multipole-new-run
```

输出路径必须尚不存在；程序拒绝覆盖。单进程，NumPy 的 BLAS/OpenMP 线程被限制为1；默认作者运行不到1秒，输入限制也使网格和距离扫描有界。若没有 NumPy，应报告运行缺层，不把旧输出冒充本机新运行。

## 三个独立对象如何比较

**一、外部完整场应力。** 用 Gauss–Legendre 积分 $\mu=\cos\theta\in[-1,1]$，周期梯形积分 $\phi$。各点先计算完整 $\mathbf E,c\mathbf B$，再计算整个应力张量牵引，最后积分功率、三分量线动量和三分量角动量；不是先套总功率或总力矩公式。测试 $kr=0.3,0.5,1,2,10,100$，均在源球外。原点平移检验将同一采样点力臂改为 $\mathbf r-\mathbf a_O$，表面法线和场不动。

**二、源处 Lorentz 交换。** 从正文标量卷积的球内表达构造 Hessian，体电流的功与磁力另做径向 Gauss 积分；球面电荷和闭合磁化电流的交换使用两侧平均场。保留球内 $c\mathbf B$ 的额外磁化项。所有源力矩由位置叉乘实际力密度得到。源码 `source_exchange` 不调用外场通量或解析总量函数，也不拿守恒余额代填输入。这两条数值路线共享给定 Maxwell 模型，但被积对象与积分区域不同。

**三、解析整球答案。** 用正文的 $\int n_in_jd\Omega$ 与奇偶性推出

$$\mathcal P=K(1+\eta^2+b^2),\quad
\Phi_{P,z}=Kb\cos\delta/c,\quad
\Phi_{L,O,z}=2\eta K/\omega,$$

其中 $K=ck^4p_0^2F(ka)^2/(12\pi\epsilon_0)$。解析函数还保留一般复矢量叉积写法用于各分量对比。这是手算答案；两种网格对同一公式的重复求值不能冒充独立证明，后续非作者核查应从正文或源卷积重新推导，并采用不同球面积分方案。

程序对前两条路线都做粗、细两级积分，默认角网格 $16\times48\to32\times96$，径向节点 $16\to32$。球外平均通量应不随半径变化；源交换的负值与外向通量对应。源数据在 JSON 里明确标记 `outward_equivalent_SI`，意味着**负的场给物质交换**，不是物质受力符号本身。

## 输出、误差与图读法

- [surface.csv](output/surface.csv)：每个网格和半径的 W、N、N·m 结果，包括改变原点后的三分量角通量以及错误截断的 $z$ 通量。`Jx/Jy/Jz` 列表示角动量**流率**，单位 N·m。
- [angular.csv](output/angular.csv)：$\phi=0$ 的远区角功率，保留相干总场与人为删除干涉两列，单位 W/sr；[angular.svg](output/angular.svg)以 μW/sr 显示这些同源数据。它不是积分网格，不能把切面曲线直接当全角总量。
- [radius.csv](output/radius.csv)：51个对数距离点，含完整场和错误截断的 $\omega\Phi_{L,z}/\mathcal P$；[radius.svg](output/radius.svg)画相同两列。另存 $\theta=\pi/4,\phi=0$ 的局部电场误差除以正的辐射尺度 $E_{\rm ref}=p_0k^3|F|\sqrt{1+\eta^2+b^2}/(4\pi\epsilon_0kr)$（`local_E_error_over_radiation_scale`）；尺度不取该方向的场，避免方向零点处除零。它提醒“全角平均通量半径无关”不等于“各点近场与远场相同”。
- [results.json](output/results.json)：参数、采用的 SI 数值常数、源积分、解析答案、最大误差和运行环境。`elapsed_s` 是本次观测时间，重跑无需字节相等。

误差在无量纲量上评估。设 $E_0=p_0k^3/(4\pi\epsilon_0)$，$P_s=\epsilon_0cE_0^2/(2k^2)$；功率除 $P_s$，力除 $P_s/c$，力矩除 $P_s/(ck)$。各分量的绝对差再统一除解析功率的无量纲值，零分量也有明示尺度，不对零除。成功门为所有源积分和外场完整通量的此项误差 $<2\times10^{-7}$。默认作者实跑最大值 $4.89\times10^{-13}$；细网格误差可能稍大，因为本源角多项式很低阶，粗网格已足够，之后主要是浮点抵消。

错误截断给出的角通量零不作为成功答案；它是一个刻意保留的失败模型，CSV 中不超过 $10^{-29}$ N·m 的数是浮点零。半径增大时该模型不会趋近正确角通量。JSON 的 `pass` 只证明程序定义的比较通过，不是整个课程、客户端或真实源实现的验收。

## 先预测，再用新参数复算

复制输入到新文件，各次输出到新目录：

1. `magnetic_ratio=0`：功率从 $3K$ 变 $2K$，线反冲为零，球心角通量保持；原点修正也归零。
2. `ellipticity=-1`：功率和默认的角功率图不变，球心 $z$ 角通量反号。只有强度信息的程序会漏掉这个改变。
3. `magnetic_phase_rad` 改为 $\pi$ 或 $\pi/2$：功率、球心角通量不变，线反冲和横向原点修正分别翻号或为零。不要误称它把反冲旋到 $xy$ 平面。
4. 同时令 `ellipticity=0,magnetic_ratio=0`：线性电偶极正辐射功率，零净力矩。
5. `ellipticity=0,magnetic_ratio=-0.7071067811865476,magnetic_phase_rad=0`：固定局部探头方向的领先辐射电场为零；全角功率仍为正。辅助场误差使用正的全局尺度，不能除以这个方向的零场。
6. 为保持实际源半径而将频率加倍，必须同时把 `frequency_Hz` 和 `ka` 加倍；观察面若也保持实际半径，则各 `kr` 同样加倍。原点若保持同一实际位移，`origin_shift_dimensionless` 也要加倍。这一字段存的是 $k\mathbf a_O$ 的无量纲三分量，不是位移的米数。

程序接受 $0.05\le ka\le1$，$|\eta|,|b|\le2$，正 $f,p_0$，2到32个递增且位于球外的 $kr\le1000$，以及有界角／径向网格。超出上述范围、非有限输入或会使 SI 归一尺度溢出／下溢的输入在创建输出目录前拒绝；已有输出目录也拒绝。范围是这个轻量实践的实现合同，不宣称 Maxwell 模型只在这些数字内有效。纯零频率的静态问题没有本实验的周期平均/辐射定义，应回到静场课程。
