# 微积分与优化 MOC

微积分回答“一个量趋近、稍微变化或持续累计时，另一个量怎样变化”，优化则把局部变化变成训练参数的更新规则。本单元从高中函数和向量出发，经极限、连续、积分与 Taylor 近似的桥梁，最终走到 Transformer 训练中的反向传播、AdamW 与稳定性设计。

## 这条路线怎样读

每课都有两条并行轨道：

- **直觉轨**：先用坡度、等高线、水流和记账理解“为什么”。第一次阅读可以只走这条轨道。
- **推导轨**：写明变量形状、假设和等号由来，得到可以迁移到代码与论文的结论。

推荐顺序：

1. **基础桥接**：[[数学/40-微积分与优化/07-极限连续积分与Taylor近似|极限、连续、积分与 Taylor 近似]]：先理解趋近、连续累计和局部近似；文件编号 `07` 表示后补的结构桥，不表示应最后学习。
2. [[数学/40-微积分与优化/01-导数偏导数与链式法则|导数、偏导与链式法则]]：从一条曲线走到多变量复合函数。
3. [[数学/40-微积分与优化/02-梯度方向导数与Jacobian|梯度、方向导数与 Jacobian]]：区分梯度、Jacobian、JVP 和 VJP。
4. [[数学/40-微积分与优化/03-计算图反向传播与自动微分|计算图、反向传播与自动微分]]：理解梯度为何能在线性时间内反传。
5. [[数学/40-微积分与优化/04-SGD-Momentum-Adam与AdamW|SGD、Momentum、Adam 与 AdamW]]：把梯度变成带状态的参数更新。
6. [[数学/40-微积分与优化/05-初始化归一化与训练稳定性|初始化、归一化与训练稳定性]]：解释为什么“公式正确”仍可能训练失败。

8. **约束优化分支**：[[数学/40-微积分与优化/08-凸优化对偶与最优性证书|凸优化、对偶与最优性证书]]：从“乘子表示什么”到可行性、强对偶、灵敏度和停止误差；已能使用梯度与基本 KKT 后进入，不作为初学反向传播的前置。

## 开始前自测

不要求先学完大学高数。若能完成以下三项，就可以从基础桥接课开始：

- 能展开 $(a+b)^2$，并知道函数 $y=f(x)$ 把输入映射到输出；
- 能把向量看成一列数，知道矩阵乘法是“加权求和”；
- 能读懂 Python 的列表、循环、函数与 `assert`。

若还不能稳定区分“对所有”“存在一个”“若……则……”以及单向推出与等价，先读 [[数学/10-数学语言与基础/03-集合映射命题与合法推理|集合、映射、命题与合法推理]]。

暂时不会矩阵乘法时，可先回到 [[数学/20-线性代数与几何/00-线性代数与几何-MOC|线性代数与几何 MOC]]；符号含义见 [[数学/03-数学符号表|数学符号表]]。

## 全单元统一约定

| 对象 | 形状 | 含义 |
| --- | --- | --- |
| 单个样本 $x$ | $\mathbb{R}^{d}$，默认列向量 | $d$ 个输入特征 |
| 参数 $\theta$ | $\mathbb{R}^{p}$ | 展平后的全部可训练参数 |
| 标量损失 $L(\theta)$ | $\mathbb{R}$ | 越小通常越好 |
| 梯度 $\nabla_\theta L$ | $\mathbb{R}^{p}$，与 $\theta$ 同形 | 每个参数的一阶敏感度 |
| 向量函数 $f:\mathbb{R}^{n}\to\mathbb{R}^{m}$ 的 Jacobian | $\mathbb{R}^{m\times n}$ | 第 $i$ 个输出对第 $j$ 个输入的偏导 |

本单元默认梯度是列向量；代码中的数组会保留参数本来的张量形状。论文或框架可能采用不同排布，只要维度自洽就不矛盾。

## 学完应能回答

- 极限为什么可以存在于函数未定义的点？连续、可导之间是什么关系？
- 为什么积分近似必须包含采样步长，离散期望与连续期望怎样统一？
- Taylor 近似在什么邻域、光滑性和余项条件下才可信？
- 为什么负梯度是局部最陡下降方向，而不是“保证到达全局最优”的方向？
- 为什么反向传播主要计算的是 vector–Jacobian product，而不显式生成巨大 Jacobian？
- Momentum 和 Adam 分别保存哪些状态，状态形状是什么？
- 为什么 Adam 中的 L2 正则通常不等价于 AdamW 的解耦 weight decay？
- 初始化、LayerNorm、残差、梯度裁剪和混合精度各自解决哪一层问题？
- 为什么二次函数的最大曲率会限制稳定学习率，而梯度为 0 又不足以证明已到最优点？
