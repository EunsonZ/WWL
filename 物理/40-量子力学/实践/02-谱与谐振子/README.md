# 谱与谐振子的复算

这一段把连续动量区间、离散振子谱、有限矩阵截断和占据统计分开核对。先做正文的手算，再用单线程、低内存的 Python 标准库脚本核几项具体风险；程序不证明一般自伴或谱定理。

## 先固定手算预测

| 问题 | 手算答案与单位 |
| --- | --- |
| 首段 Gaussian 的 $\kappa=ks$ 分布 | 均值一、标准差 $1/2$；$P(k<0)=0.0227501319481792$ |
| $0\le E\le\hbar^2/(2ms^2)$ 的能量窗 | 对应两个波数分支合成 $\kappa\in[-1,1]$；概率 $0.499968328758167$ |
| 振子前三项 | $\phi_0,\phi_1,\phi_2$ 归一正交；无量纲能量为 $1/2,3/2,5/2$，不是连续位置坐标本身 |
| $6\times6$ 截断升降矩阵 | 对易子对角为 $(1,1,1,1,1,-5)$，迹零；不等于 $I_6$ |
| $|1\rangle$、$|\alpha=1\rangle$、$q=1/2$ 热态 | 均值占据均一，方差分别 $0,1,2$；$\langle a\rangle$ 分别为 $0,1,0$ |

## 运行与输出

从本目录执行：

```bash
python3 -B spectrum_oscillator.py
```

[spectrum_oscillator.py](spectrum_oscillator.py) 是本段源码真源，只使用 `math`、`cmath`、`json` 和 `pathlib`；不派线程、不安装依赖、不构造大网格 Hamiltonian。输出 [checks.json](assets/checks.json) 与 [occupation.svg](assets/occupation.svg)，再次执行会重新生成两项。

连续例使用解析 Gaussian Fourier 密度，积分变量 $\kappa=ks$ 无量纲。归一窗为 $[-5,7]$、4000段梯形法；概率窗为 $[-5,0]$ 与 $[-1,1]$、8000段。均值一、标准差 $1/2$ 使有限尾截断在本例可忽略；改变漂移/宽度须重新核截断范围。概率比较容差 $5\times10^{-8}$，梯形误差为主要来源；这不是 FFT 或时间步进求解器。

谐振子用 $\xi=x/\ell$，函数 $u_n(\xi)=\sqrt\ell\phi_n(x)$ 无量纲。仅检查 $n=0,1,2,3$ 的归一与交叉内积，范围 $[-10,10]$、4000段、绝对误差阈值 $10^{-11}$。另在指定五个空间点，以 $\delta\xi=10^{-4}$ 中心差分核

$$\tfrac12(-u_n''+\xi^2u_n)=(n+1/2)u_n,\qquad
\tfrac1{\sqrt2}(\xi u_n+u_n')=\sqrt n\,u_{n-1}.$$

差分残差阈值为 $10^{-7}$ 的无量纲绝对值；有限空间窗、差分截断和浮点相减均有误差。完备性与本质自伴性依正文给出的标准定理，不能由四个函数的有限检查认证。

占据计算保留 $n=0\ldots63$，相干态以递推生成复振幅，不把截断后结果强制重归一化。热态的未含概率为 $2^{-64}$，未含平均占据为 $65\times2^{-64}$；相干 $|\alpha|=1$ 尾更小。范数、均值、方差和含时幅比较阈值 $10^{-12}$。若把 $|\alpha|$ 或温度增大，这个截断不能自动沿用，需检查占据尾与矩尾。

截断对易关系另外实际构造 $6\times6$ 降算符矩阵并相乘，核完整对易矩阵；占据向量的64项截断仅用于所问低占据态的矩近似。对顶态 $|63\rangle$，该截断的 $[a,a^\dagger]$ 期望为 $-63$，不满足无限振子的一；不能用64项列表本身当作无限维算符。
