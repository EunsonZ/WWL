# Python 练习答案与解释

先独立完成练习，再使用本页比较思路。答案不是唯一写法，评价重点是输入边界、错误信息、文件编码和可测试性。

## 语法与文件练习参考

```python
from __future__ import annotations

import json
from collections.abc import Iterable, Mapping
from pathlib import Path


def summarize(records: Iterable[Mapping[str, object]]) -> dict[str, float]:
    totals: dict[str, float] = {}

    for index, record in enumerate(records):
        if not isinstance(record, Mapping):
            raise ValueError(f"record {index}: record must be a mapping")

        category = record.get("category")
        amount = record.get("amount")

        if not isinstance(category, str) or not category:
            raise ValueError(f"record {index}: category must be a non-empty string")
        if isinstance(amount, bool) or not isinstance(amount, (int, float)):
            raise ValueError(f"record {index}: amount must be a number")

        totals[category] = totals.get(category, 0.0) + float(amount)

    return totals


def save_summary(path: Path, summary: Mapping[str, float]) -> None:
    text = json.dumps(summary, ensure_ascii=False, indent=2, sort_keys=True)
    path.write_text(text + "\n", encoding="utf-8")


def main() -> None:
    records = [
        {"category": "book", "amount": 88.0},
        {"category": "food", "amount": 26.5},
        {"category": "book", "amount": 42.0},
        {"category": "travel", "amount": 15.5},
    ]
    output = Path("summary.json")
    summary = summarize(records)
    save_summary(output, summary)
    assert json.loads(output.read_text(encoding="utf-8")) == summary
    print(summary)


if __name__ == "__main__":
    main()
```

为什么显式排除 `bool`？因为 `bool` 是 `int` 的子类，单纯的 `isinstance(True, int)` 会得到 `True`，但把 `True` 当金额通常不是我们想要的业务约定。

最小边界测试还应包含一条“记录不是映射”的情况：

```python
try:
    summarize(["not-a-record"])
except ValueError as exc:
    assert "record 0" in str(exc)
else:
    raise AssertionError("非法记录没有被拒绝")
```

## 开放式自评的答案思路

第 13 课的 CSV 工具和第 14 课的字符串价格练习没有唯一实现；可用下列问题检查自己的答案，而不是照抄一份“标准项目”：

- CSV 工具应在 `groupby` 前检查所需列，并在测试中分别覆盖正常文件、缺列文件和生成 PNG 的可观察结果；删除环境后，应按已审查的依赖/锁定流程重建再运行测试。
- 字符串价格工具应先确定空列表的返回或异常契约；将每个价格转换为数值时，对转换失败的 `ValueError` 用 `raise ... from exc` 保留原因；测试至少覆盖正常字符串、空输入和非法字符串。
- 两题都应把文件路径放进 `tmp_path`/临时目录，删除调试断点，并以成功标准而不是“代码看起来像答案”作为完成依据。

## 环境实验应得到的结论

- venv 复用创建它的基础 Python，但有独立前缀和 site-packages；
- 激活脚本把环境的可执行目录放到当前 shell 的 PATH 前面；
- `.venv/bin/python` 或 Windows 对应解释器可在不激活时直接运行；
- `python -m pip` 将 pip 绑定到该次执行的 Python；
- uv project 可以同时维护项目元数据、锁文件和可重建环境；
- Conda 环境可以管理 Python 以及渠道中提供的非 Python 依赖；
- 三者都不是安全沙箱，运行不可信代码仍有风险。

## 自我复盘

- 如果你的答案更短：它是否仍验证了类型和空值？
- 如果你的答案更复杂：复杂度是否真的来自需求，而不是为了展示语法？
- 如果测试依赖当前目录：换一个目录运行会怎样？
- 如果环境损坏：能否只根据项目文件重建，而不是复制 `.venv`？
