## 先修与学习方式

了解变量、函数、对象与基本 JavaScript。

把运行时值、编译时关系和宿主 API 分开，完成可验证的异步程序。

版本与范围：严格类型检查；运行时语义属于 JavaScript，宿主 API 另行区分。
