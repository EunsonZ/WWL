语音与音频模型处理随时间变化的声音：语音识别把波形转成文本，语音合成从文本生成可听信号，说话人、事件和音乐任务则分别关注身份、环境或结构。音频并不等同于语言；文字转写也不等同于知道谁说的、为什么说、现场发生了什么。录音可能包含旁人、住址、健康、口音、情绪或版权材料，因此“可被模型读取”不等于“可被收集或推断”。

本轮已补齐下列两篇核心课程，含直觉解释、主要公式、小例、图示与一手资料。原有地图保留为进阶学习和实验设计；不能把完整主题目录理解为全部研究深度、真实模型运行或 GPU 性能均已验收。

## 领域问题与边界

- **输入与任务边界**：同一段波形可用于 ASR、关键词检测、说话人验证、音频事件识别、翻译、TTS 或音乐生成，但标签、误差代价和授权条件不同。先写“输入、输出、允许的错误、禁止的推断”，再挑模型。
- **信号边界**：采样率、响度、信噪比、麦克风、压缩和声道影响输入。频谱图是对波形的表示，不是客观原声；预处理可抹掉语义线索，也可在不知不觉中泄漏录制设备或人群信息。
- **交互边界**：实时听写、会议摘要和合成语音涉及持续采集、显示、保存、分享和删除。课程实验默认离线、最小数据、可撤销，绝不暗中录音或打开系统麦克风。

## 与 LLM 共用和不同的部分

| 层次 | 与 LLM 共用 | 语音与音频的新问题 |
| --- | --- | --- |
| 表示 | 序列、embedding、位置、注意力、encoder/decoder | 连续波形、帧、频带、相位、声道、采样率与时长 |
| 训练 | 目标函数、优化、微调、数据切分、复现 | 对齐方式（CTC/seq2seq）、噪声/混响、说话人和录制条件分布 |
| 推理 | prompt/条件、解码、缓存、批处理、服务监控 | 流式窗口、端点检测、实时性、时长变化和声学前端 |
| 评测 | 基准、置信区间、错误分析、回归集 | WER/CER、DER、PESQ 类质量指标、主观听感和不同口音/环境的分项误差 |

## 进阶课程结构与持续学习方向

| 模块 | 计划课程 | 要回答的问题 | 可观察完成标志 |
| --- | --- | --- | --- |
| 1. 声音与采样 | 波形、采样率、量化、声道、响度与裁剪 | 文件的数字样本表示什么？ | 能检查时长、采样率、声道和削波 |
| 2. 时频表示 | DFT、STFT、Mel、窗口、hop 与频谱增强 | 一帧特征覆盖多长时间、丢了什么？ | 能计算帧数/频率 bin 并解释权衡 |
| 3. 识别架构 | HMM 史、CTC、seq2seq、Conformer 与自监督表征 | 波形如何对齐到文字或标签？ | 能区分对齐、语言建模与解码责任 |
| 4. 生成架构 | 声学模型、vocoder、codec token 与条件控制 | 文本如何变成连续可听信号？ | 能画出文本、韵律、声码器的数据流 |
| 5. 数据与训练 | 转写、对齐、切分、增强、微调与复现 | 为什么随机切分会高估成绩？ | 能按说话人/录制会话隔离数据 |
| 6. 流式推理 | VAD、分块、缓存、端点、延迟与重写 | 实时输出为何会变？ | 能记录首字/最终结果延迟和修改率 |
| 7. 评测与偏差 | WER/CER、错误分类、说话人/环境分层、听测 | 总体平均掩盖了谁的错误？ | 能给出分层报告和样例审听协议 |
| 8. 隐私与治理 | 同意、保留期、声纹、冒充、版权与披露 | 哪些收集/合成行为不可默认执行？ | 能写出最小化数据流和人工退出点 |

## 推荐阅读顺序

1. 概念路线：ML 基础 → LLM 的序列/Transformer 章节 → 数学 70/02 → 模块 1、2、3、4。
2. 数据与评测路线：模块 5 → 模块 7 → 模块 8。先理解转写真值与人群覆盖，再解释 WER 或主观分数。
3. 工程路线：CUDA MOC → 模块 6 → 小型离线实验。实时服务不应作为首次实验，也不应用真实会议或个人录音做测试。

## 进阶实验设计与硬件路线

| 层级 | 设计 | 成功标准 | 明确限制 |
| --- | --- | --- | --- |
| CPU 信号实验 | 合成正弦波/短噪声片段，查看采样、STFT 与 Mel 的形状变化 | 可由公式和固定样本复算时间/频率轴 | 不证明对真实语音鲁棒 |
| 受许可离线 ASR 评测 | 少量公开且许可明确的短片段，固定转写与按说话人切分 | WER/CER 计算、归一化规则和错误例可复查 | 不外推到所有语言、口音或会议环境 |
| GPU 推理/生成剖析 | 只用许可模型和非个人样本，比较 batch、片段长度和精度 | 记录硬件、驱动、模型版本、实时系数、显存和预热 | 不做身份验证、情绪诊断或冒充演示 |

硬件按风险而非显卡大小分层：CPU 足以完成表示和指标练习；8–16 GB 显存优先做小模型或量化离线推理；24 GB 以上也只在数据许可、显存估算和检查点空间清楚后讨论小规模微调。长音频的长度、采样率和 batch 会线性或超线性地推高内存与延迟；实时任务还要测端点、缓冲和网络，而不只是每秒处理速度。以上是预算变量和实验次序，不是特定模型或硬件的兼容性承诺；使用统一 [[AI/90-资源/03-GPU显存与资源预算表|GPU 预算表]]，并在实际模型实验前按 [[AI/90-资源/05-官方资料与版本核验记录|一手来源核验规则]] 记录实际工具与版本。

## 数据许可、隐私与评测边界

- 录音之前应有可理解、可撤回的同意；说明用途、处理者、保存位置、保留期、分享范围和删除途径。旁人的声音、背景谈话和元数据也可能是个人数据。
- 不将声纹识别、情绪/人格推断、疾病判断、未授权模仿、克隆特定真人声音或隐蔽录音设为默认实验。合成语音应标注为合成，并避免被误认成真实发言。
- 核对音频、转写、歌词和模型权重的许可证；“可在线播放”或“公开可下载”不是训练、再分发或商业使用许可。
- 评测需保留原始度量、文本正规化规则、切分单位、人工听测样本和失败类型；WER 低不证明专名、否定词、数字、口音、公平性或隐私风险都已解决。
