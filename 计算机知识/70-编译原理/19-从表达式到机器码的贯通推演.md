# 编译原理深化：从一条表达式贯通全部阶段

> 阅读定位：语言语义、前端、IR、优化、后端、运行时与验证。返回 [[计算机知识/00-开始/课程地图/12-编译原理-课程地图|编译原理 · 课程地图]]；全域入口 [[计算机知识/00-开始/全局导航/00-总学习地图|计算机知识库 · 总学习地图]]。

## 一个小程序经过不同表示

主路线直接使用现有实验的 `DEMO_SOURCE`：

```text
let x: int = 2 + 3 * 4;
let hot: bool = x > 10;
if (hot) {
  return x + 1;
} else {
  return 0;
}
```

实际终点是 **Python 实现的栈式字节码 VM**，返回15。[[计算机知识/80-实践/08-编译原理/09-MiniLang端到端编译器/README|MiniLang实验]]给出唯一源码、文法、运行命令与镜像；本页追踪同一程序。词法分析把字符分为关键字、标识符、整数和符号，并保存源位置；语法分析按优先级形成 `Add(2,Mul(3,4))`，不是 `Mul(Add(2,3),4)`。CST 保留更多语法细节，AST 突出语义结构。

名称解析把 x 的使用连到它的定义，作用域规则决定同名绑定遮蔽。类型检查确认乘法、加法、比较、bool 分支条件和 return 合法；“语法能解析”不意味着类型与变量都正确。对动态语言，部分检查移到运行时，也不意味着完全没有编译阶段。

## IR 使不同变换有统一对象

未优化 IR 顺序为 t0=const 2、t1=const 3、t2=const 4、t3=mul t1 t2、t4=add t0 t3、x=move t4；随后 t5=const 10、t6=gt x t5、hot=move t6 与 branch hot then0 else1。then0 中 t7=const 1、t8=add x t7、return t8；else1 中 t9=const 0、return t9。优化后为 `jump then0 / label then0 / return 15`。

MiniLang 的整数加减乘在折叠与VM两处均作有符号 i32 模回绕；这些运算纯且不会因整数溢出陷阱。常量 x=14、hot=true 可传播，未选分支不可达，再经活跃性删除无用纯定义。若加入I/O、重载或溢出陷阱，须重新证明这些优化；实数代数不能代替语言语义。

| 表示 | 一个 x 的连续追踪 |
| --- | --- |
| 字符/token | 声明 x 在第1行第5列；比较中的 x 在第2行第17列 |
| AST/绑定 | `Let.name_span` 指向1:5；`Name` use_span 2:17 的 Binding.declaration_span 指回1:5 |
| 类型 | symbol_types 中 x:int，hot:bool；`>` 的两边是int，结果bool |
| 未优化IR | `move x t4` 定义x，`gt t6 (x,t5)`使用它 |
| 未优化bytecode | emit_bytecode 按目标首次出现排slot：t0,t1,t2,t3,t4,x，因此 x是slot5；STORE 5保存，比较时LOAD 5取回 |
| 优化bytecode/VM | x经传播消失，不需要slot；跳转进入then0，压入常量15，RETURN弹出15 |

上述编号依当前源码手推，后续版本应按新产物重核；这轮没有执行编译器或测试。`return missing;` 的名称诊断预期 `name:1:8`，`let x: int = true;` 的类型诊断预期 `type:1:1`。关闭 `optimize_ir` 后 IR/bytecode会变长，但返回值仍应为15，这一预期有现有回归入口，当前状态notrun。

有分支时建立控制流图。SSA 让每个名字只定义一次，汇合点用 phi 表达根据前驱边选择哪个定义。phi 不是在运行时同时执行所有分支，也不等同于普通函数。移除 SSA 时需要在边上安排合适复制，处理并行复制冲突。

## 从当前 VM 终点继续到原生后端

当前 `emit_bytecode/run_vm` 不分配物理寄存器、不使用原生调用约定，也不输出可链接目标文件。后续若走ISA分支，需要新增目标指令选择、寄存器分配、ABI/栈布局、编码/重定位和链接层，再以交叉编译与目标执行分别验收；不能把VM返回15登记为机器码或ABI通过。

## 后端不只是把 IR 名字换成寄存器

指令选择把操作映射为目标 ISA 支持的形式，寄存器分配在有限寄存器之间分配活跃值，溢出值 spill 到栈产生额外访存，指令调度在依赖和资源约束下安排执行。ABI 规定参数、返回值、保存约定、栈和外部交互，链接再解析符号与重定位。

同一个源表达式可能被常量折叠，也可能由于外部可见语义保留运算，不能预先承诺对应几条机器指令。调试信息负责把优化后代码尽量映射回源位置，这种对应并不总是一对一。

## 词法和语法的覆盖地图

正规语言、正则表达式、NFA、DFA 适合许多词法问题；上下文无关文法用于递归结构；LL、递归下降、Pratt、LR/LALR 等采用不同决策和状态模型。左递归、左因子、优先级、结合性与歧义各自需要处理。错误恢复还要保证推进，避免在同一坏 token 上无限报错。

属性文法、语法制导翻译、类型推断、约束统一、模式匹配编译、泛型实例化、闭包转换、异常降低、运行时检查和模块系统补齐前端到运行时的链路。练习为上述程序保留每一阶段的表示，再故意引入未定义名字与类型错误，确认错误发生在哪一阶段并给出源区间。
