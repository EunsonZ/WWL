# 基准质量与投资经理选择：先校准尺，再评价人

经理选择不是把三年回报排序。合理流程先把任务写清楚，再选能代表任务的 benchmark，随后评价过程、人员、组合、业绩、费用、运营与合同；最后仍要持续监控。若尺子不匹配，精确归因只会更精确地回答错问题。

## 一个有效 benchmark 要通过什么检查

常用质量要求可组织为：

- **明确**：成分与权重事前可知，不能在结果出来后换尺；
- **适当**：代表经理的投资风格、风险和可投资集合；
- **可衡量**：能按一致时点和口径计算；
- **可投资**：至少存在可行的被动替代或复制意义，否则机会成本含混；
- **反映当前观点/责任**：经理知道相对它的主动决策是什么，并对差异负责；
- **归属清楚**：资产所有者、overlay 与底层经理各有与授权相符的 benchmark。

liability-based benchmark 适合衡量履约任务，例如负债现金流复制或负债回报加 spread；market index 更适合明确资产类别授权；custom security-based benchmark 可贴近经理风格，但维护成本高且可能被操纵；peer universe 容易受幸存者偏差、风格混杂和排名噪声影响。

对另类资产，滞后估值、非交易资产、不同 vintage、杠杆和现金流会让公开指数比较困难。不能因缺少完美 benchmark 就用不相干股票指数制造 alpha，也不能因无法精确比较而免除披露限制。

## 经理选择是一条证据链

1. **定义授权与成功。** 风格、风险预算、流动性、ESG/法律限制、费用和期限必须与 IPS 对齐。
2. **建立候选池。** 核对完整历史、产品与团队关系，防止只看存续赢家；披露搜索顾问或转介利益冲突。
3. **定量筛查。** 回报、风险、capture、drawdown、风格暴露、持仓和交易成本用于提出问题，不是自动录取分数。
4. **定性与运营尽调。** 投资哲学如何转成决策？谁有权改变仓位？团队离职、数据、估值、合规、托管、网络安全和业务连续性如何控制？
5. **组合层面检验。** 单个好经理可能与现有经理重复；要看合并后因子、流动性、容量和费用。
6. **合同与实施。** separate account 控制和透明度高但门槛/运营成本可能高；pooled vehicle 便捷但定制与穿透有限。基准、终止、关键人、流动性和绩效费条款需与任务一致。
7. **监控与退出规则。** 人员、流程、风险、容量或授权漂移可触发重审；短期落后本身不是自动解聘。

## Type I / Type II：招聘判断的两种代价

把“有可持续技能”当真实状态：

| 决策 | 经理无技能 | 经理有技能 |
|---|---|---|
| 雇用/保留 | Type I：误聘/误留 | 正确保留 |
| 拒绝/解聘 | 正确拒绝 | Type II：错杀 |

严格阈值能减少误聘，却可能错杀新策略或短历史经理；宽松阈值相反。选择阈值要看代价：更换经理的税/交易/转换成本、集中风险、治理能力和可替代性。统计显著不自动等于经济上值得，经济上吸引也不免除样本不确定性。

## 把定量结果放回过程

若经理六期 appraisal ratio 为正，先问主动回报来自稳定选择、风格暴露、一次事件还是 benchmark 错配。returns-based style analysis 可估计总体暴露但掩盖期内变化；holdings-based analysis 能看实际持仓，却依赖及时完整数据。二者冲突时应调查流程和交易记录，而不是挑支持既有偏好的结果。

团队决策还会受权威、确认、过度自信和群体一致压力影响。可使用事前 thesis/失效条件、独立反方、决定与结果分离的复盘、轮换发言和明确升级机制。形式化会议不保证独立判断；若薪酬只奖励短期相对排名，制度本身会推动拥挤风险。

## 费用必须与可控价值对齐

管理费降低所有状态下的净回报；绩效费可能对齐激励，也可能鼓励尾部风险。审查 hurdle、high-water mark、对称性、计算频率、benchmark 与终止时结算。费用表必须逐现金流/估值期复算，本组未覆盖官方全部三类绩效费和样本费表，不能据这一段称完整 LOS。

## 一个完整判断示例

候选经理 A 三年超额回报高、团队刚更换、容量接近上限；B 超额回报较低但流程稳定、与现有组合相关性低、费用低。不能只因 A 排名第一就选 A。若青岚的主要缺口是分散现有拥挤因子，B 可能给组合带来更高净价值；若 B 的“低相关”来自平滑非流动估值，则优势又可能是假象。结论须写成“任务—证据—不确定性—条件化动作”。

职业责任贯穿搜索：不能只展示赢家历史，不能隐瞒顾问费用，不能把预测写成保证，也不能因客户想追逐冠军就放弃适当性。细节回到[[社会科学/50-CFA课程/01-职业伦理准则标准与判断程序|伦理判断程序]]和[[社会科学/50-CFA课程/03-GIPS业绩呈现范围与误导识别|GIPS呈现边界]]。

## 反例：解聘落后经理反而锁定风格循环

价值经理在成长占优的两年落后，委员会改聘近期冠军成长经理，随后风格反转。问题不是“永远不解聘”，而是委员会没有区分授权内风格结果与流程失效。若原经理仍按明确流程、风险与容量执行，短期落后可属于预期状态；若出现风格漂移、关键人离开或风险控制失灵，即便近期跑赢也应重审。

## 迁移题与原创短答

**题目。** 一个低波动绝对收益经理用股票大盘指数作 benchmark，报告高 appraisal ratio。给出两个不能直接接受该结论的理由。

**短答。** 第一，股票指数可能不代表其可投资集合、风险目标和授权，主动回报分母与分子都被错配；应先建立与绝对收益/现金加点或风险目标相符的 benchmark。第二，低波动可能来自非交易资产的估值平滑或卖出尾部保险；应检查持仓、流动性、极端损失和多状态表现。

**再问。** 定量合格、运营控制失败的经理能否用更高预期 alpha 补偿？通常不能把不可接受的资产保管、估值或欺诈风险只折成一个期望收益调整；应修复控制或拒绝授权。
