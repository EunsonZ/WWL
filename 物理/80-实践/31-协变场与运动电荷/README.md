# 协变场与运动电荷复算

本实践把三种路线分开实现：四维矩阵和三维场变换；通用推迟求根和匀速闭式；对推迟势作数值微分和直接场公式。它们针对不同错误，不是只换函数名重复代入同一结果。源码是 [covariant_charge.py](covariant_charge.py)，仅使用 Python 标准库、单进程单线程，本次运行约 0.070 秒，包含解释器的 macOS 峰值常驻内存约 22.34 MiB（23,429,120 字节）。

## 独立对照分别检查什么

| --- | --- | --- |

| 混合电磁场的两个不变量 | 矩阵并非只对纯电场偶然正确 | 最大数值差约 $2.34\times10^{-15}$ |

| 通用二分根与匀速代数根 | 光锥约束、选择过去根 | 横向例 $t_r/(b/c)=-1.25$；三个额外空间/时间点最大差约 $8.89\times10^{-16}$ |
| 推迟速度场与静止系 Coulomb 场的逆 boost | 势的 Jacobian 和场方向 | $E_y\approx1.248271$ V/m、$B_z\approx2.498270$ nT，两条路线一致 |

| 无效输入 | 错误不能用数值输出掩盖 | 拒绝光速 boost、光速脉冲峰值和落在点源世界线上的观察事件 |

表中“独立对照”指不同计算入口；这是作者自查，不能替代未参与写作的独立语义审阅。

场与求根核心先使用无量纲 $c=T=1$，电场单位为 $q/(4\pi\epsilon_0L^2)$，空间单位为 $L=cT$；SI 输出最后恢复量纲。场张量运算把 $cB$ 与 $E$ 放在同一归一单位，代码里的矩阵对应正文的 $cF$，不是把磁场的 T 直接当作 V/m。所有场、数值差分和误差单位见正文约定。

## 有限运动脉冲的关键反例

源峰值速度 $b=0.2$，长度 $L=3$ m，源时间 $u=1/4$ 映射到探头时刻 $t/T\approx1.250041263$。此时源当前已经停止，但场的推迟事件还在运动段。结果为

$$E_x^{\rm vel}/E_*\approx-0.107690628,\quad
E_x^{\rm acc}/E_*\approx-0.626531757,\quad
E_x/E_*\approx-0.734222386.$$

源时间 $u=1/2$ 则速度最大、加速度为零，$E_x^{\rm acc}$ 在舍入误差内为零。这个对照专门检验“取当前状态”与“把高速本身当作辐射”的两种错误。

代码还把探头距离从 $10L$ 增至 $300L$，只积分加速度项的有限距离诊断量，检查其趋近渐近 $+y$ 方向能量：相对差从约 −0.2574% 降至 −0.00834%。这个量没有包含完整近区交叉项，**不是有限距离总 Poynting 通量或总辐射能量**。真正的渐近单方向结果来自正文的 $1/r$ 极限与时间积分；全立体角总量尚待课程展开。
