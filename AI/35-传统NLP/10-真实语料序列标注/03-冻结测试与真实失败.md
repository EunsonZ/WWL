# 冻结测试：总体准确率之外，模型在哪里失效

本页的数字来自固定 test 子集 492 句、7,181 token；模型在 dev 选出 α=0.01 后没有用 test 重新选参。token accuracy 的分母是全部 7,181 个整数 token；sentence accuracy 的分母是 492 句，只有整句标签全对才算对。

![[./figures/ud-ewt-test-baselines.svg]]

| 冻结 test 模型 | token accuracy | sentence accuracy |
| --- | ---: | ---: |
| unigram | 0.1589 | 0.0122 |
| word-frequency tag | 0.8082 | 0.1931 |
| 监督 HMM + Viterbi | **0.8351** | **0.2744** |

HMM 超过词频基线只说明此固定子集上标签链与平滑的组合增加了 token 正确数；不是与全量 EWT、神经模型或不同 tokenization 的可比排名。

## 两个“难词”分母必须分开

**真正 OOV** 是字符串从未在 train 的 `FORM` 集出现；本 test 有 1,216 个，HMM accuracy 为 **0.4679**。**已见稀有词** 是 train 中出现 1 次、因训练规则映射为 `<UNK>` 的原字符串；本 test 有 396 个，HMM accuracy 为 **0.4672**。它们都走 `<UNK>` 发射，前者检验新字符串，后者检验故意合并低频类型；若把二者混成一个“unknown accuracy”，读者看不到分母差异。

![[./figures/ud-ewt-hmm-slices.svg]]

按 gold 标签和句长的完整切片在 `results.json`，避免只挑一个好看的类别。最高频真实混淆包括 `PROPN→NOUN` 222 次、`NOUN→PROPN` 77 次、`VERB→NOUN` 62 次、`NOUN→VERB` 56 次。它们符合一个只看词形与一阶标签链的模型在专名、普通名词和动词歧义处容易失手的机制，但不能从这些计数推出标注错因或语言学唯一解释；需逐句检查。

文档隔离没有消除所有重叠：按完整有序 `FORM` tuple 的精确比较，固定子集中 train–dev 有 **5** 个、train–test 有 **7** 个、dev–test 有 **3** 个跨 split 重复句文本。实验如实保留它们、报告它们，未按预测或标签删除，也没有为了提升分数改切分。作为**不参与选参**的敏感性分析，移除 test 中完整 `FORM` tuple 已见于 train 的全部 12 个句实例后，剩余 480 句、7,164 token；HMM 是 5,980/7,164 = **0.8347** token accuracy，123/480 = **0.2563** sentence accuracy。这个分析不把原 test 主结果替换成新分数；它只说明 test 并非独立文本来源的强保证，0.8351 的外推范围应限于这个冻结子集协议。

### 反例与答案

若 HMM 的 token accuracy 上升，但 OOV accuracy 降低，能说模型“更好”吗？**答案：** 只能说它在全 token 这个加权分母上更高；是否可接受取决于任务对未知词的目标。必须同时报告两个明确分母，不能由一个总体数字替代。

若把发现的重复句从 test 删除并重新报更高分？**答案：** 那改变了冻结评测对象，除非预先定义并重新建立一套版本化协议；本实验只把重复作为限制报告。
