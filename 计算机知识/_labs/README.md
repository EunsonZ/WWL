## 实际包含什么

`integration/` 保留上一包实际存在的教学程序，本轮重新运行，不沿用旧报告结论。包含二分、排序、并查集、最短路、背包、页面/缓存模型、调度与安全序列、增量分帧、SQL、解释器/栈机和异步失败路径等受控测试，以及 C 动态向量、C++ RAII、Rust 标准库测试和 TypeScript 输入验证示例。

这些是组件教学模型，不是完整网络协议栈、真实内核调度器或生产数据库。原库 `计算机知识/80-实践/` 的全部文件也保留，其中更深入的编译、媒体、CUDA 和系统实验仍按原说明使用。

## 运行

```sh
python3 计算机知识/_labs/integration/run_all.py
```

从 Vault 根目录运行上述命令。程序只使用本地工具，编译产物写入临时目录，不自动安装依赖，不修改分区、驱动或服务；每次运行的默认报告写入 `Logs/运行/integration-labs/<运行时间戳>/计算机知识/integration_test_results.json`。需要 Python 3.11+；C、C++、Rust、TypeScript 的测试根据工具是否存在分别执行或跳过。

[[计算机知识/90-资源/维护/导入-com/_meta/04-实验验证记录|历史输入包运行记录]]只给出当时的通过、失败和跳过；缺少 Rust 编译器时只能记为 SKIP，不能从源代码存在推断“Rust 已验证”。

## 怎样学习而不只看 PASS

先写预测，再运行，检查断言覆盖了哪条合同。改变一个边界或故意移除必要条件，观察哪条测试失败。随机差分覆盖有限样例，不能代替证明；设备写回、网络故障和并发隔离还需要独立的受控真实实验。返回 [[计算机知识/00-开始/全局导航/00-总学习地图|计算机知识库 · 总学习地图]]。
