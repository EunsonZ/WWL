# 资本预算、增量现金流与项目选择

澄河制造年底现金113，董事会要不要建设新生产线？现金余额告诉它是否需要融资，项目NPV回答投入是否创造价值。先建立“不做项目”与“做项目”两条未来路径，再把两者现金差拿来贴现。利润、总收入和已花的钱都不能直接替代增量现金流。

本课预测在**2026年底决策时点 $t=0$**发生，$t=1,2,3$分别为2027–2029年末；所有现金流万元、名义税后、年度有效率。同一家澄河制造，但这些是**另行构造的新增项目预测**，没有写入10课2026已发生账本。初始支出超过历史现金113，需要融资/预算安排；本课先评价经济性，融资方案另在21课讨论。固定折现率10%是题设适用的项目风险要求回报，不由历史净利率或贷款票息推得。

## 1. 增量先把取舍放进账本

| 输入 | 数值与时点 | 怎样进入决策 |
|---|---|---|
| 已完成市场调研 | 决策前付8 | 沉没成本，无论现在选什么都不能收回；不进增量CF |
| 新设备安装后资本支出 | $t=0$付120 | 增量投资支出－120 |
| 自有空地 | 现在可卖、税后净得20 | 若被项目占用，放弃出售＝机会成本－20；不是必须另付20现金 |
| 期初增量经营NWC | $t=0$占用15 | －15；$t=3$全部收回＋15 |
| 新线销售 | 每年130 | 增量毛销售，不是最终净增收入 |
| 挤掉旧线销售 | 每年10，旧线成本变化为0 | 蚕食损失－10，净增收入120 |
| 增量付现经营成本 | 每年55 | 扣工资、材料等；无未列入的额外固定成本 |
| 会计与税折旧 | 每年40，共三年 | 设备120、零残值；25%税率，本题即时充分利用扣除 |
| 项目结束设备 | 账面/税基/售价均0 | 处置CF0；有售价时另算出售税效应 |
| 空地结束可卖 | $t=3$税后净20 | 假设使用无损耗、题内无土地售价变动；＋20 |

历史财报只记自己土地的历史成本，项目预算记20机会成本，两者对象不同。设备融资借款、还本、利息与股利先不入本课融资前项目CF；它们的成本在风险匹配的折现率或单独融资估值中反映。若一边扣利息一边又用融资前WACC，容易重复计融资成本。

## 2. 从经营利润到融资前增量现金

每年EBIT $=130-10-55-40=25$，税6.25，税后经营利润18.75；加回折旧40，经营现金58.75。折旧未付现却影响税，省税 $40\times25\%=10$ 已在计算中一次反映：

$$OCF=(Revenue-CashCost-Dep)(1-T)+Dep
=(120-55)(1-0.25)+40\times0.25=58.75.$$

年度内NWC恒15，$t=0$投入与$t=3$收回，没有每年重复扣15。若销售增长需要额外NWC，应在对应年度扣 $\Delta NWC_t$；终期只能收回实际可收的部分。设备出售税后金额通常须依据售价、税基和适用税制计算；本题为0，不因此推广为“终期忽略税”。

| 时点 | 经营CF | 设备 | 土地机会成本/收回 | NWC | 总CF |
|---|---:|---:|---:|---:|---:|
| $t=0$ | 0 | －120 | －20 | －15 | **－155** |
| $t=1$ | 58.75 | 0 | 0 | 0 | **58.75** |
| $t=2$ | 58.75 | 0 | 0 | 0 | **58.75** |
| $t=3$ | 58.75 | 0 | ＋20 | ＋15 | **93.75** |

$$NPV(10\%)=-155+\frac{58.75}{1.1}+\frac{58.75}{1.1^2}+\frac{93.75}{1.1^3}
=17.3986\text{万元}.$$

在给定预测与风险折现条件下，正NPV表示比同风险要求回报多创造17.3986的决策时点价值；不保证利润或现金预测会兑现。忽略蚕食每年多算税后7.5，NPV就多算 $7.5\times(1/1.1+1/1.1^2+1/1.1^3)=18.6514$；反而错误扣沉没8会把NPV降为9.3986。预算差错不能靠更精确贴现修好。

## 3. IRR好看，为什么仍可能选另一个项目

内部报酬率IRR满足 $NPV(r)=0$。对初始负支出、其后非负并至少一笔正现金的项目，在 $r>-1$ 上NPV严格递减，若存在根则唯一；这只是特定现金符号条件。NPV按指定机会成本衡量价值金额，IRR以百分比描述临界折现率，两个排序目标不同。

**规模冲突：** 董事会可在同风险的一年项目A和B中选一个，资本足够1000，两者不可拆分、不可克隆。A投入100、年末130；B投入1000、年末1250。

| 项目 | NPV，$r=10\%$ | IRR |
|---|---:|---:|
| A：－100，130 | 18.1818 | 30% |
| B：－1000，1250 | 136.3636 | 25% |
| B－A：－900，1120 | 118.1818 | 24.4444% |

B绝对创造价值更多；追加900能取得24.4444%临界回报，高于10%，因此可负担且互斥时选B。若资本上限只有100，B不可行；资本预算受约束时要找可行组合，而不是盲选最大单项NPV或IRR，也不能假定能买十个独立A。

**时间冲突：** C为－100、0、150，D为－100、125、0。IRR C $=\sqrt{1.5}-1=22.4745\%$，D＝25%；10%时NPV C＝23.9669、D＝13.6364，仍选C。增量C－D为0、－125、150，其交点 $150/(1+r)=125$，$r=20\%$；低于20%晚到的大现金占优，高于20%早收现金占优。在25%时D NPV0、C NPV－4，应连同“不投资”的0比较，不能被互斥措辞强迫选负NPV。

**多根与不存在根：** 现金－100、230、－132，令 $x=1+r$，根满足 $-100x^2+230x-132=0$，得 $x=1.1,1.2$，IRR10%和20%。15%时NPV0.1890，NPV并非单调。软件只返回一个根也不能说明另一个不存在。现金全正时本来没有投资初始负项，通常没有有限IRR；不用随意给出“无穷收益”比较。直接按经济合理风险率算NPV，或明确经过修改的收益指标及再投资假设。

## 4. 资本分配还需要机会、约束和敏感性

简单回收期看未折现累计收回，本项目在第三年回收：第二年累计117.5，尚缺37.5；若第三年58.75经营现金均匀流入，回收期约 $2+37.5/58.75=2.6383$年。但本课正式CF按年末给定，严格离散回收发生在$t=3$，不能把均匀流入近似写成精确日期。回收期省略时间价值和回收后的现金，不能替NPV排序。ROIC是经营利润对投入资本的会计回报，亦非IRR。

敏感性先改单变量：若净增收入每年少10、其他条件不变，OCF少7.5，NPV变为－1.2528；销量与价格、材料成本可能同时变，单变量并非联合风险。情景树要注明条件概率和状态现金，风险调整不能在悲观现金与高折现率里随意重复。

等待、分期扩建、停产、放弃是实物选择权。假设一年后观察需求：等一年则可高需求时投资、低需求时放弃；应把所有状态和等待损失放进决策树，固定计划NPV不能自动给等待权价值。此课说明选择权对象，未给无套利实物期权估值或完整资本配给优化课。[CFA Institute 2026 Capital Investments and Capital Allocation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/capital-investments-and-capital-allocation)公开介绍提供资本分配、NPV/IRR与相关陷阱的课程定位。

## 5. 练习与答案

**题1：** 项目需要自有土地，财务人员说“不用付钱就不算成本”。**解：** 无项目可卖得20，使用就放弃该替代现金流，计－20机会成本。本题终期还可卖20，计＋20但贴现更晚；土地净现值成本 $20-20/1.1^3=4.9737$。历史购买价或账面土地值不能替代当前税后机会成本。

**题2：** 公司拿10%贷款融资，是否在每年项目CF扣贷款利息后继续用10%贴现？**解：** 10%题设是融资前项目风险回报，贷款票息偶然也10%不改变对象。若评价债股共同项目现金就不扣融资；若改为股东现金，要列借款、还本、利息税效应并用股权风险成本。不能因为数字一样就混口径。

**题3：** A的IRR30%高于B25%，B投入大，董事会该选谁？**解：** 输入为互斥、同风险且足以投入1000时选B；先比NPV，再复核增量NPV118.1818。若只有100预算，A是可行选择，不能说B的高NPV自动取得融资。

**题4：** 多根项目的资金成本15%，只查IRR10%判拒绝是否充分？**解：** 不充分；另一根20%存在，NPV15%为＋0.1890。用现金时间表与NPV直接判断，另外核对末期负支出的法律/环保等实质。
