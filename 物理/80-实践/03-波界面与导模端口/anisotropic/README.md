# 倾斜单轴平板的四分量求解

本实验只解 [[物理/20-电磁学/11-倾斜单轴平板的矢量混合模|11 的模型]]：同06/09的无穷平板、850 nm与半厚，芯层换成合成实对称正定单轴张量，光轴在xy平面转动。求两个相互隔离的传播根，恢复同一个根下的全部E/H，在同一100 µW下积分完整包层功率和有限段能量。原 `solve_waves.py`、`tm/solve_tm.py`及其结果没有被本扩展改写或重跑。

`solve_anisotropic.py` 是规范真源，`inputs.json` 是固定卡；程序需要NumPy和SciPy，实际环境版本在生成的 `values.json` 内。源码不安装依赖、不联网，Markdown没有复制实现的 `code-sync` 块。计算完成才写七个结果，既有同名结果会被拒绝，改参数必须选新目录。

## 先预测，后执行

先在正文完成三项预测：45°为何必须混合；0°为何仍分离；将45°改−45°，哪些可观测量不变、哪些分量相对符号反转。然后在本目录、已有所需依赖的Python环境运行：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 MKL_NUM_THREADS=1 \
python3 -I -B solve_anisotropic.py --input inputs.json --output-dir /private/tmp/wwl-anisotropic-my-first-run
```

示例输出目录必须此前没有本程序的七个结果；需要重算时换一个新路径。运行只用CPU，建议单线程、单进程、外部60秒超时；脚本自身没有创建子进程。不要把运行时间和退出0当作物理模型正确的证据，还需下述边界与特限核对。

| 输入 | 默认值与用途 |
| --- | --- |
| `n_ordinary`,`n_extraordinary`,`n_clad` | 1.50、1.53、1.45；芯层张量为 $n_o^2I+(n_e^2-n_o^2)aa^T$，包层 $n_s^2I$ |
| `wavelength0_m`,`reference_V` | 850 nm、1；用 $d=V/[k_0\sqrt{n_o^2-n_s^2}]$ 固定半厚，与06/09相同 |
| `axis_angle_deg` | 45°；$a=(\sin\theta,\cos\theta,0)$，从+y向+x量 |
| `periodic_width_m`,`control_length_m` | 1 mm、2 mm；宽为周期单元，没有实际侧缘；长只定义能量观察段 |
| `power_W` | 每支分别100 µW；不是两支叠加的共同输入功率，也不指定实际耦合效率 |

程序只接受上述键、有限实数且拒绝bool、重复JSON键与未知键。数值域限定 $1<n_s<n_o\le n_e\le1.6$、$0\le n_e-n_o\le0.04$，真空波长400 nm–2 µm，参考V为0.75–1.2，$V\sqrt{(n_e^2-n_s^2)/(n_o^2-n_s^2)}<1.5$，角度−60°至60°。宽和长各1 µm–0.1 m、功率 $10^{-12}$–1 W。它们限定有限教学卡，不是各向异性导模存在定理；即使合法参数仍须通过根数、孤立性与重叠检查，才输出本两分支结果。

## 数值步骤和可以审计的输出

以 $\xi=k_0x$、$b=\beta/k_0$ 写实状态 $g=(E_y,-iE_z,Z_0H_y,-iZ_0H_z)^T$。全空间采用峰值 $e^{i\omega t-i\beta z}$。程序构造正文C、左右衰减基L/R，解 $M=[\exp(2k_0dC)L,-R]$。各列除自己的正范数后扫描 $n_s+10^{-8}<b<n_e-10^{-8}$ 的1001点，以异号相邻点括区求根。这个内缩区间刻意不算截止，有限网格可能漏根，没有一般全谱证明。

找到恰好两根后，还要求根间距大于 $2\times10^{-5}$；M的最小/最大奇异值比小于 $2\times10^{-10}$、次小/最大比大于 $10^{-5}$，转移矩阵条件数小于 $10^4$。从0°纯模式起以最多5°一步追踪；在固定 $x/d\in[-4,4]$ 的101点六分量复内积上，最优配对的每支相邻重叠必须大于0.85。此重叠只是有限网格诊断。出现简并、多分支、极窄根间隔、快速场变化或很厚层时，应重建求解，不能绕过guard继续贴旧标签。

规范输出共七个：

| 文件 | 内容及读法 |
| --- | --- |
| `values.json` | 完整卡、近似常数/环境、半厚/张量、两支结果、0°反例、各向同性恢复、负角迁移及逐角数据；含括区、奇异值、T条件数、边界相对残差和积分改变 |
| `branch-1-fields.csv`,`branch-2-fields.csv` | 每支363行：左包层81、芯层201、右包层81；所有E/H的实虚部，SI峰值、平均 $S_z$、电/磁平均能量密度、法向 $D_x,B_x$ |
| `angle-scan.csv` | 同一转轴扫描的 $b,\eta_y$、包层功率、U、能量速度、残差与相邻场重叠，标签表示从纯模式连续延伸 |
| `root-scan.csv` | 默认目标角1001个b及列归一化匹配行列式，可独立看异号括区；插值图形不替代根残差 |
| `mixed-fields.svg` | 用两CSV的 $\operatorname{Re}E_x,\operatorname{Re}E_y,\operatorname{Im}E_z$ 画同功率场，界面保存两侧值 |
| `axis-branches.svg` | 从同一angle-scan画两根和 $\eta_y$ 随光轴角变化，$\eta_y$明确为场平方比例 |

`branch-1` 是从0°TE0延伸的分支，`branch-2`从0°TM0延伸；在混合区它们不是严格TE/TM。角度为0°时只保留该角度的两支数据，图用圆点显示，横轴±1°只是留白，不表示额外计算。SVD向量整体符号无物理意义，源码以核心中心最大状态分量的符号定规；跨条件比相对分量时先对齐整体相位，不按绝对正负认定模式换支。

CSV的x单位m，E单位V/m、H单位A/m、$S_z$单位W/m²、u单位J/m³、$D_x$单位C/m²、$B_x$单位T。每个界面各有一条芯层记录及一条包层记录，它们x相同但介质不同；四切向场、$D_x,B_x$应连续，$E_x$可跳跃。若先删重复x再插值，会把正要核的边界藏掉。

图只画各侧6个振幅衰减长度。实际积分以96点Gauss算芯层，再加左右各自 $F(\pm d)/(2\kappa)$ 的无限尾；128点复算的相对改变作为芯层积分检查。归一用

$$P=W_y\int\tfrac12\operatorname{Re}(\mathbf E\times\mathbf H^*)_zdx,$$
$$U=\frac{W_y\ell}{4}\int(\varepsilon_0E^\dagger\varepsilon_rE+\mu_0H^\dagger H)dx.$$

矩阵中h已乘Z0，但CSV磁场已经除回Z0，不能再将h直接当A/m。不得把 $|E_y|^2$ 比例当功率，或用标量平均介电常数算电能；交叉项必须保留。输出的 `energy_velocity_m_per_s` 为 $P/(U/\ell)$，没有额外宣称已经独立做过群速度频差。

## 固定卡结果和独立证据

本次由非作者在独立临时环境实际运行，Python 3.14.7、NumPy 2.5.4、SciPy 1.18.1；源码仅使用这些库与标准库。作者只做语法及文本自查，下面数值来自独立执行。近似常数延续06/09：$c_0=299792458$ m/s、$\mu_0\approx4\pi10^{-7}$ H/m、$\varepsilon_0=1/(\mu_0c_0^2)$，现代SI中$\mu_0$不是精确定义值。

45°两支$n_{\rm eff}$为1.4940151691796386和1.4723676408146462，$\eta_y$为0.5371589611和0.4618861790；各100 µW时总能量为$1.0201184679011251\times10^{-15}$ J和$9.97118321822514\times10^{-16}$ J。具体量、包层份额和迁移答案见[[物理/20-电磁学/11-倾斜单轴平板的矢量混合模#完整例与转轴连续追踪|正文完整例]]及本页JSON。

独立核查没有导入候选函数作为答案：从原复旋度方程建立层内本征场，以八个界面幅度拼接BVP，再用自适应芯层积分和解析无限尾复算。20个角度/分支根最大差约$1.34\times10^{-15}$，U相对差小于$7.8\times10^{-16}$。两支共726条完整六分量场记录与独立场相对差小于$2.7\times10^{-15}$，分段六阶差分原旋度残差小于$2.5\times10^{-14}$；界面四切向场最大相对跳量小于$2.2\times10^{-15}$。各向同性/主轴标量根、正负光轴镜像与追踪重叠也被分别复核。该一致性没有证明任意材料或任意扫描的完整谱。

最终同版默认运行用时约1.105秒，退出0；七产物已从独立运行逐字节复制。两张默认SVG已实际Cairo渲染并目验，0°单点显示缺陷修后另行渲染确认。18个坏卡均清楚退出2且无新结果，既有七目标拒绝覆盖并保留原字节；这些行为不依赖Python的assert优化开关。

结果中的平均$S_x$由实际场网格计算为0，与本实g相位结构的解析预测一致。$U_E,U_H$的相对差约$10^{-16}$量级；这个检查与正储能来自同一无损非频散合同，不适用于未加入正确材料储能的频散模型。

## 变条件练习与反例

在当前目录执行下列标准库脚本只写新的输入卡，不运行求解；若目标已存在则拒绝覆盖。先预测，再把新卡交给同一真源，输出到另一个新目录：

```sh
python3 - <<'PY'
import json
from pathlib import Path
p=json.loads(Path('inputs.json').read_text())
p['axis_angle_deg']=30.0
with Path('axis30-input.json').open('x') as f:
    json.dump(p,f,indent=2)
    f.write('\n')
PY
```

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 MKL_NUM_THREADS=1 \
python3 -I -B solve_anisotropic.py --input axis30-input.json --output-dir /private/tmp/wwl-anisotropic-axis30
```

半引导30°的张量与解题入口见正文。撤提示将角度改−45°时，$\varepsilon_{xy}$反号、对角不变；经整体相位对齐后 $E_x,E_z,H_y$反号，$E_y,H_x,H_z$保持，两根、衰减长度和U相同。默认求解会从0°独立追踪到正角和负角，`mirror_axis_modes`保存负角的实际重算；不是将原结果复制到答案栏。

默认也独立解 $n_e=n_o$ 的各向同性特限，应恢复06的TE0与09的TM0；它们在本V=1卡本来不简并。0°各向异性反例只有TM0与旧09相同；TE看到1.53，不能误当“转回主轴就变回各向同性”。实际xz光轴不在该代码输入合同内，正文的一般Maxwell四式已证明该方向仍可分离；不要借角度参数给它改名后运行。

可核拒绝：将功率改0、角度改90°、$n_s\ge n_o$、$n_e<n_o$、引入未声明键或超大整数；这些应退出2，并不产生七个结果。已存在任一目标、符号链接输出也应拒绝，原结果保留。合法范围外的拒绝只表示超出本卡，并不表示该物理问题不存在解。截止 $b=n_s$ 的非衰减尾不能归一；泄漏/辐射态需要新边界，不能把扫描下端调到包层光线下方就继续用L/R。
