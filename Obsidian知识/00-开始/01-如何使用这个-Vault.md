# 如何使用这个 Vault

这个 Vault 同时是指南、示例知识库和安全实验场。最有效的学习方式是：**先观察一个现成示例，再在实验区亲手改一次，最后从反向链接或视图中验证结果。**

## 先认识四种入口

1. **文件列表**：按目录浏览课程和样例。
2. **内部链接**：点击 `[[笔记名]]` 在知识网络中移动。
3. **快速切换器**：按 `Cmd/Ctrl + O`，输入部分标题直接打开。
4. **命令面板**：按 `Cmd/Ctrl + P`，搜索“图谱”“模板”“日记”等动作。

> [!practice] 现在试一下
> 不使用左侧文件列表，依次用快速切换器打开 [[Obsidian知识/00-开始/00-Playground-首页|00-Playground-首页]]、[[Obsidian知识/10-基础/02-链接与知识网络/00-链接与知识网络-MOC|00-链接与知识网络-MOC]] 和 [[Obsidian知识/30-实践/03-示例项目/周末读书会/00-周末读书会项目主页|00-周末读书会项目主页]]。

## 阅读、编辑和源码

Obsidian 的 Markdown 文件始终是纯文本，但你可以用不同方式查看：

- **阅读视图**：看到最终渲染结果，适合阅读。
- **实时预览**：边写边看格式，是默认学习方式。
- **源码模式**：完整看到 `[[链接]]`、frontmatter 和嵌入语法，适合排错。

在 [[Obsidian知识/30-实践/01-实验区/Markdown/01-自由草稿纸|自由草稿纸]] 中输入 `**粗体**`，切换三种状态，观察同一份文本如何显示。

## 用四种结构各做一件事

不要让文件夹、标签、属性和链接反复登记同一个分类。它们回答的问题不同：

| 结构 | 应回答的问题 | 例子 |
| --- | --- | --- |
| 文件夹 | 这份文件属于哪个稳定区域或课程？ | `Obsidian知识/10-基础/` |
| 属性 | 哪些短事实需要筛选、排序或显示？ | `type`、`stage`、`topics` |
| 链接 | 它与另一份知识的关系是什么？ | “这个例子应用了 [[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/双向链接\|双向链接]]” |
| 正文 | 为什么这个关系成立、证据与限制是什么？ | 解释、例子、反例和判断 |

例如，一份阅读材料可以放在资源区，用属性记录来源和状态；正文写自己的理解与局限；再用带说明的链接连接它支持或质疑的概念。不要只因它是“来源”就同时给文件夹、文件名前缀、标签和 `type` 重复贴上同一层分类。

> [!tip] 先少后多
> 本 Vault 已有课程与知识域的目录结构。学习本课不要求把它改造成另一套统一目录；只有某个字段、标签或文件夹确实解决了稳定问题，才值得长期维护。

## 课程页怎么读

每篇课程都采用相似结构：

- 开头告诉你将学到什么。
- 中间给出一个可复制的小例子。
- `练习` Callout 要求你真的操作。
- `成功标准` 让你自行检查。
- 页面末尾连接相关概念和下一站。

frontmatter 中的公共属性也有意义：

| 属性 | 用途 |
| --- | --- |
| `type` | 这是 hub、lesson、workflow 还是 challenge |
| `stage` | 所属学习阶段 |
| `status` | `ready`、`doing` 或 `done` |
| `difficulty` | 入门、进阶或挑战 |
| `estimated_minutes` | 建议练习时间 |
| `topics` | 供 Search、Bases 和 Dataview 使用的主题 |

这些课程属性描述教材，不记录你的掌握程度。把一页从 `ready` 改成其他值也不能证明自己已经学会；真正的尝试、错误和问题应留在自己的练习或学习记录中。

## 在哪里动手

自由编辑 [[Obsidian知识/30-实践/01-实验区/Markdown/00-Markdown实验室|10-实验区]] 中的内容。课程之外的示例项目放在 [[Obsidian知识/30-实践/03-示例项目/周末读书会/00-周末读书会项目主页|周末读书会]]；它负责展示人物、会议、书目、概念、决定和日记怎样形成网络。

> [!warning] 不要把试验扩散到整个 Vault
> 初学 Linter、Importer、批量属性修改和自动化时，只选择课程指定的样例文件。插件命令可能一次影响许多文件，操作前先读 [[Obsidian知识/00-开始/04-安全实验与重置|04-安全实验与重置]]。

## 怎样返回和继续

- 页面顶部的当前标签页可返回历史。
- 右侧 Backlinks 显示“谁链接到了这里”。
- 页面底部通常有上一站和下一站。
- 所有主线都能回到 [[Obsidian知识/00-开始/00-Playground-首页|00-Playground-首页]]。

> [!success] 完成标准
> 你能够用快速切换器打开一篇笔记，切换编辑/阅读状态，并从一个内部链接进入另一篇笔记后通过反向链接返回。
