# 能量整形与输入界：同一受控摆的复算

[[控制论/10-系统课程/15-非线性控制能量整形与输入界|第15课]] 的式(1)是物理真源，式(7)–(17)给一般局部证明。本实践用同一方程核五条有限轨迹、严格函数导数的实现和缩步误差。先读 [input.json](input.json)，再读规范源码 [pendulum_iss_lab.py](pendulum_iss_lab.py) 或 [[控制论/80-实践/06-能量整形与输入界/code-sync/pendulum_iss_lab|同版代码镜像]]；输入中 `certified` 只是指定哪组例必须满足正文条件，运行时逐一验证这些参数，并不充当独立理论签收。

## 怎样复建和改变输入

标准库Python3即可执行；没有安装数值库、设备程序或服务。输出目录必须不存在，已有目录即拒绝运行，复核请换全新名字。在本目录执行：

```sh
python3 -I -B pendulum_iss_lab.py --output-dir /private/tmp/wwl-pendulum-iss-rerun
```

`--input /个人副本/input.json` 可指定修改后的输入。脚本从与自身同目录的输入文件默认读取，当前工作目录不改变默认输入位置；输出只写指定的新目录。先完成输入和证书检查，再创建输出。若输入不满足证书，不能删掉检查后仍把该例标为 `certified: true`。

- `physical` 的 $m,l,g$ 给SI尺度，`design` 的 $\gamma,\kappa,k_d,\epsilon,r,h,a_{\max},d_{\max}$ 给课程证书；由 $b=\gamma ml^2\sqrt{g/l}$ 恢复物理阻尼，改变 $l,g$ 而保留 $\gamma$ 相当于相应改变 $b$。
- `initial` 为共同 $(e,v)=(0.3,0)$，$e=\theta-\pi$，$v=\dot\theta/\omega_0$；每个case从同一初值重新开始。
- `integration` 的 `end_tau=20`、`base_step_tau=0.02` 给终点与导出网格；四路RK4每格分别取1/2/4/8子步，图/CSV使用4子步路线，即实际积分步长0.005个 $\tau$。8子步路线是误差参考，仍是数值解。
- 换向负载每2个 $\tau$ 翻转。输入switch和终点必须对齐导出网格；在每个网格区间用同一个负载，跨换向边界状态连续，导出端点的 $d$ 和导数用右侧值。这样不会在RK4末级把下一段负载错误混入上一段积分。
- 控制是连续反馈：RK4各级按自己的状态计算命令并实施饱和。积分网格不是控制器采样周期。减少计算步长不能认证真实数字控制闭环。

改变外扭矩界时应同时改 `design.d_max` 与constant/square case的幅度；改变电机极限时相应修改主设计和三个 `certified` case的限幅。保留失败case作为明确条件变化。脚本检查局部域、所有域内点的扭矩充分界、严格输入阈值及共同初值；拒绝状态/输入阈值不合法的声明。其绘图入口特意限制为五个具名对照；要研究其他轨迹，应在个人副本明确修改图和输入的对应关系。
