# 阵列节点与LIF事件实践

## 先挑一个读者问题

如果问“为什么把存的电导乘上输入电压能求和”，读第一章的“理想条件下的KCL”，在四支路与八节点之间比较。问“校准一次为何不能把所有输入都修好”，读第二章的两个基向量反例。问“漏电和复位是不是普通线性滤波”，读第三章的事件顺序。返回代码时检查这些条件如何成为输入合同；看完图不能把框内端口当已实现芯片。

## 源码与输入合同

真源为同目录 `array_model.py`、`test_array_model.py`、`generate_figures.py`；[[电子电路/80-实践/41-阵列节点与LIF事件/源码镜像|源码镜像]] 是受code-sync核对的阅读副本，修改先改真源并同时更新三块。生成函数不在导入时运行；数值源和测试只依赖标准库，Matplotlib/CairoSVG只在显式生成时导入。

所有数值为SI有限实数，拒bool、complex、NaN、inf、无法转成有限float的大整数。固定2×2，G在0..1 mS，输入−0.2..0.2 V；线阻0用理想专门式，有限线阻允许1 Ω..1 MΩ，0与1 Ω之间明确拒绝，避免声称任意逼近都具有浮点精度保证。`solve`是固定内部矩阵求解器，不是面向任意病态矩阵的通用API；公开教学网络都按上述拓扑组装。

`differential`权重−4..4、输入−2..2，电导尺度1e−8..1e−4 S，基线0..1e−5 S、输入尺度0.0001..0.1 V。两阵列都按各自电导重新求解；不能把有线阻的正负阵列独立误差假定抵消。`quantize_current`单极电流范围含端点、过载显式拒，位数整数1..16。`drift`仅t≥t0的合成保持曲线，t0≥1 ms、t≤1e9 s、ν在0..1；不预测真实寿命。

`lif`固定R=10 MΩ、C=1 nF、阈值.01 V，初值−.1 V至严格小于.01 V；恒定电流−10..10 nA、观察0..1 s、hold0..100 ms。只能按恒定输入求事件，不接受时变刺激或把数组偷偷当标量。终点触发先记录然后返回复位右极限；有限事件预算10000和可表示时间推进保护。固定参数的有限实验不证明全部输入轨迹或真实生物机制。

能量函数分别接功率W、驻留s、每次J和整数次数，校准摊销次数须≥1。每项非负且有限；缺少通信/空闲成本时只可用明确假设0的合成例，不能替真实系统填写0。

## 从库根运行，输出用新的库外目录

下面命令以WWL根为工作目录，Python路径需用已有环境；没有依赖就记录未运行，不安装。

```bash
.venv/bin/python -B -m unittest discover -s '电子电路/80-实践/41-阵列节点与LIF事件' -v
.venv/bin/python -B '电子电路/80-实践/41-阵列节点与LIF事件/generate_figures.py' --output /private/tmp/f06-teaching-new-output
```

第二条要求路径不存在或空目录，重复非空目录拒绝，防止覆盖发布资产；省略`--output`参数解析退出2且不生成。输出24项：7原创SVG、14张360/425 PNG、1 CSV、2 JSON。临时字体缓存放在显式输出目录内并清除；环境与rc_context在成功/异常退出后恢复。渲染异常可能留下部分输出，须另用新目录重跑，部分文件不是完整生成结果。不启动服务、不运行SPICE/硬件、不改库。

11组作者测试包括：理想数值与转置方向、单单元串联解析、八节点邻居迭代独立算法、负输入与零电导极限、差分共同项能耗、量化端点、漂移与基向量校准反例、能量摊销、LIF解析事件/阈值极限/终点顺序、小步Euler及电荷、无效类型/shape。算法对照和浮点容差是有限CPU证据，非任意精度证明；正确解析、另一收敛求解器或受控步长的数值答案都可接受。

## 图与数据如何读

`array-nodes.svg`是真实八节点拓扑，行输入源与列夹持共享0；`ideal-ports.svg`、`differential-ports.svg`明确理想驱动/读出责任；`calibration.svg`比较两基向量的第一列电流；`energy-ledger.svg`是合成同MVM账；`lif-node.svg`是有单位的RC/阈值规则；`lif-events.svg`表示节点电压而非动作电位形状。CSV记录线阻与两电流及功率，JSON分别记录SI输入参数与完整默认节点/事件/账。图由这些真源和数值生成，可编辑SVG，未复制论文图。

V43合同还包含生物前端隔离/保护/信号链。本组只贡献阵列求和及非理想部分；不依赖未签F05，不宣称整个V43完成。F06三主题与实践41教学CPU范围需独立普通与承重审阅，源码运行不替代主题、源文和图义核验。真实PDK、编程/漂移实测、神经网络训练任务、端到端能量测量、SPICE、真实客户端与人阅读结果均未运行。
