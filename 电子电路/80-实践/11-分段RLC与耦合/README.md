# 分段、RLC与耦合：状态和能量的独立复算

本实践回答三个相连的问题：开关改变后如何携带原状态；振铃与能量如何同属于一组RLC方程；第二绕组的参考方向怎样进入能量交叉项。先读[[电子电路/10-电路基础/15-分段开关如何传递状态|分段状态]]，再进入[[电子电路/10-电路基础/16-串并联RLC的能量与相轨迹|RLC状态与能量]]和[[电子电路/10-电路基础/17-互感同名端与变压器的边界|互感边界]]。基础路线先预测方向再复算；快进入口先列状态矩阵，最后共同解释一个失败结果。

`storage_models.py`是唯一数值真源，本页没有平行复制实现。所有参数使用SI：秒、伏、安、欧姆、亨、法；输出能量为焦耳，磁链为V·s。图的毫秒、毫安、µJ由生成器显示时转换，CSV保留SI并在表头注明单位。

## 输入输出合同

|API|输入与输出|条件与失败|
|---|---|---|
|`rc_interval`|初值、区间秒、源电压、Rs、C和可选RL；返回末值、终值、τ|RL=`None`表示没有负载；持续时间可为0；Rs/C及给定RL正值；相对时间指数保留初值和源两权重|
|`piecewise_rc`|非空有限区间列表；返回端点时间、电压|n区间→n+1端点，首项是实物初值，每段时间正；所有区间先验证，空列表或缺字段拒绝|
|`rlc_state`|时间、R/L/C、v₀/i₀、串或并联、常值source；返回v、i|串联源单位V、R可0；并联源单位A、R须正；固定线性集总模型，三阻尼类及非零初值都有解析解|
|`storage_energy`|v、i、L、C；返回½Cv²+½Li²|参考方向不改变平方项；强制电源供能须另加功率账本|
|`mutual_energy`|两个流入点电流、L₁/L₂、有符号k；返回E/λ₁/λ₂/M|L均正、abs(k)≤1；k=±1允许半正定但不可通用求逆；abs(k)>1拒绝|

数值接口在转换前拒绝bool、complex（即使虚部为零）、数组/嵌套、非有限及超出binary64的输入。该合同面向实物时间域标量；频域复数不是因此错误，需在相应复数接口计算。导出的极端量若溢出或基本尺度下溢失效，会明确失败；没有任意宽动态范围保证。模型无无限迭代，循环次数由有限区间或固定采样数量决定。

RLC求值直接保留初始状态与源的各自贡献，避免“大平衡值减去再加回”抹去初值。若`max(αt,ω₀t)≤0.1`，采用`z=(v,i√(L/C))`的原ODE增量级数，两坐标单位都是V，固定计算32项；此区间矩阵的无穷范数不超过0.3，截断余项远小于binary64舍入尺度。其余区间使用三阻尼类指数系数；源权重用`expm1`和半角形式减小消减。测试包含`1e16 V`源、`1e-30 s`时刻下保留`0.4 V`初值，以及零初值极短阶跃的正二阶响应。给定加载RC的`Rs/RL`若超出binary64，明确拒绝；不把溢出的比值当成零终值，亦不承诺支持该极端区间。

## 从原方程而不是答案验证

测试用独立RK4推进原KCL/KVL，与三阻尼闭式解比较；用端口功率积分核对能量差，以中心差商核对瞬时功率。互感用配平方、坐标反接和k=1零方向检查。改变初值、负载、拓扑和步长，不能只对默认图形比对像素。

1. 保持L=10 mH、C=1 µF、串联R=50 Ω，将v₀=1 V、i₀=0的自然响应代回两式。先预测i的初始方向，再查看相轨迹。
2. 将源改为0.8 V、初值改为0.4 V/−3 mA，对比E(t)−E(0)与∫(ui−Ri²)dt；并联使用电流源及∫(vI−v²/R)dt。不能用串联功率式套并联。
3. 将Euler步长改成25/50/100 µs。50 µs是严格稳定边界，100 µs的能量增长属于数值模型。源码数据逐步保留状态，图用不同线型。
4. 改k至1，观察能量的零方向。用求逆失败识别代数约束；不靠随意小对角数掩盖模型。

L03的解、相轨迹、s平面与Euler对照由本单元提供；谐振输出/品质因数继续读[[电子电路/12-交流与变换域/04-串并联谐振品质因数与输出|已存在的谐振主解释]]，把观察对象与源/负载保持一致。内容与CPU层可验收，真实RLC/绕组测量尚未运行，不制造硬件日志。
