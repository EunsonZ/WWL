# 同一有源双端口：复波、功率、稳定与噪声

承重原文与自行推导的界线见[SOURCE-NOTES.md](SOURCE-NOTES.md)。主解释在[[电子电路/46-电磁射频与高速/08-有源稳定与噪声匹配|有源稳定与噪声匹配]]。这是给定教学 S 与正定噪声波协方差的有限计算，无随机采样、无 SPICE/PDK、无仪器连接。一般圆盘覆盖、全局增益最大及指定动态扩展的稳定/失稳由正文证明，有限矩阵不代替一般结论。

## 固定输入与同一物理对象

[fixed-inputs.json](fixed-inputs.json)使用 SI；复量都是[实部,虚部]。R0=50 Ω、f0=1 GHz、Q=1、T0=290 K、Pav=1 μW。默认 S0=[[.5,.1],[2,.4]]；条件稳定反例 Sc=[[.5,.3],[3,.4]]。源/负载 Γ 是从器件端看外部的值，a/b单位√W，V/I为 RMS，电流入 DUT。每方案保持同一可用源功率，器件面 Thevenin Vs 可改变。

噪声 C/(kBT0)=N 的精确教学目标为 N11=53/740、N22=164/185、N12=(21+20j)/185、N21=N12*；JSON保存其 binary64近似，不把小数写成额外测量有效位。严格正定 det=36/925，输出 Cholesky可重建 N。c是 outgoing器件噪声波，C是单边交叉PSD[W/Hz]；窄常谱带宽Bw内随机波幅c_B[√W]满足E[c_B c_Bᴴ]≈CBw，F中带宽消掉，普通幅度协方差不直接当PSD。给定源热噪声与c独立，读出负载不额外加噪；真实负载、匹配损耗、仪器返回噪声没有偷偷设为全硬件物理零，它们在外部合同另列。

默认4个 Γ 值(0,.2+j.2,−.3+j.1,.65−j.15)作16种源负载组合；只用于实现核查。旧负载100+j50 Ω另算一行。三种设计为参考阻抗直连、同时共轭最大增益、Γopt最低噪声加输出共轭；每种实际综合两侧“器件面并联C、串联L到R0”的无损 L 节，再用同一元件在 .8/1/1.2 GHz重算 Γ 和 GT。不是把目标Γ直接回填频率表。

信号动态扩展明确为 S(s)=H(s)M，H(s)=((ω0/Q)s)/(s²+(ω0/Q)s+ω0²)。H的稳定性/范数从解析式证明，使用频域矩阵范数全频sup的H∞代数/L2小增益，并非时域L∞诱导范数；默认 S0 加权v=(1,4)界.9，给特定实现与稳定被动终端的小增益证明。Sc用ΓS=ΓL=.9时的极点另算。噪声N仅定义在f0，不把它外推到另外两个频点。

[active_match.py](active_match.py)为规范源码，[test_active_match.py](test_active_match.py)为必要回归，[plot_active.py](plot_active.py)只读保存JSON画图。正文直接链接源码，不新抄一份程序；此新实验没有另一个活动 code-sync镜像。旧03/04的已有实验不改、不重跑。

## 有限预算与真命令

只需Python标准库，无新依赖或系统组件。R0在1..1000Ω，f0在1MHz..100GHz，Q在.2..20，T在1..1000K，Pav在1pW..1mW；这些是教学计算预算，不是器件额定/安全值。所有数拒绝bool和非有限；矩阵2×2且各元素模≤10；噪声严格Hermitian/正定且主子式留数值间隔。主S要求两端对整个被动圆盘严格收缩<.999，逆向环非零；本脚本不承担所有可能退化网络。

probe Γ最多8个、模≤.95，频率比最多16个且.1..10，噪声圆最多8个且不低于该卡计算Fmin；Sc终端Γ在(0,.99)，旧负载实部正。L综合限所选并联在器件侧拓扑的可实现支；不合条件时拒绝，换拓扑须另推。更接近奇点/零主子式的病态模型未获统一浮点精度保证。主文一般条件的定义域比这个脚本预算更大。

输出目录必须不存在，普通路径与坏symlink均保护；计算和allow_nan=False序列化在mkdir前完成；非法卡exit2且不留下新输出目录。I/O错误exit2，已存在文件不覆盖；实际存储故障不承诺事务式全文件回滚。

真实环境 Python3.14.7/macOS27.0.1 arm64；标准库有限矩阵，无线程并行、无蒙特卡洛、无旧套件重跑。共享两槽runner取一、限180s且强制线程1/禁bytecode；独立命令仍显式-B。以下从本实验目录执行，是最终实际命令：

    python3 -B /private/tmp/wwl-next-context/run_local.py --timeout 180 -- '/Users/ysz/Misc/Obsidian/Valults/WLM/WWL/.venv/bin/python' -B active_match.py --input fixed-inputs.json --out results > author-run.txt 2>&1
    python3 -B /private/tmp/wwl-next-context/run_local.py --timeout 60 -- '/Users/ysz/Misc/Obsidian/Valults/WLM/WWL/.venv/bin/python' -B -m unittest -v test_active_match.py > author-tests.txt 2>&1

首次数值预跑后仅补JSON root/序列化/路径保护、参考匹配label，再执行以上正式结果；数值算法与输入未漂移。前两次过程目录只在作者临时区，不进入读者实验。最终日志：[运行](author-run.txt)、[7回归](author-tests.txt)。共享runner只在本机协作时存在；发布后可用任何符合预算的标准库Python在新目录重建：
