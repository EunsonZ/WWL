# 表格练习场

> [!todo] 挑战目标
> 先手工完成三个小实验，理解源码结构；再用 [[Obsidian知识/20-功能/02-社区插件实验室/06-Advanced-Tables-Editing-Toolbar与Linter|Advanced Tables]] 比较插件带来的编辑体验。

## 实验 1：增加一行

把“嵌入”添加为第四行，并给熟练度填 `1`。

| 能力 | 我能解释 | 熟练度（0–3） |
| :--- | :---: | ---: |
| 内部链接 | 是 | 2 |
| 反向链接 | 否 | 1 |
| Callout | 是 | 2 |
|  |  |  |

## 实验 2：修复对齐

下面源码故意不整齐，但依然可能正常渲染。让竖线在编辑视图中对齐，体会“内容正确”与“源码易读”的区别。

```markdown
|项目|状态|下一步|
|---|:---:|---:|
|课程笔记|进行中|完成练习|
|插件实验|未开始|打开课程|
```

在这里粘贴并修复；删除外层代码围栏即可看到表格：

```markdown
|项目|状态|下一步|
|---|:---:|---:|
|课程笔记|进行中|完成练习|
|插件实验|未开始|打开课程|
```

## 实验 3：任务矩阵

在单元格内写任务时，用 `<br>` 换行：

| 主题 | 今日动作 | 完成 |
| --- | --- | :---: |
| Markdown | 复习表格<br>补一个链接 | [ ] |
| 数学 | 写一个分数<br>写一个矩阵 | [ ] |

> [!warning] 表格里的任务框
> `[ ]` 在表格单元格中通常只是文本，不一定成为可点击任务。若需要被任务系统可靠检索，优先使用表格外的标准 `- [ ]` 任务列表。

## 实验 4：竖线转义

在表格单元格中，内部链接别名的竖线需要写成 `\|`，否则会被当成分列符。

**源码：**

```markdown
| 课程 | 说明 |
| --- | --- |
| [[02-列表任务与表格\|返回课程]] | 竖线已转义 |
```

**渲染效果：**

| 课程 | 说明 |
| --- | --- |
| [[Obsidian知识/10-基础/01-Markdown基础/02-列表任务与表格\|返回课程]] | 竖线已转义 |

## 插件对照

完成手写后进入 [[Obsidian知识/20-功能/02-社区插件实验室/06-Advanced-Tables-Editing-Toolbar与Linter|Advanced Tables 与 Linter]]，重点观察：

- Tab / Shift+Tab 在单元格间移动。
- 输入时自动扩列或整理对齐。
- 格式化前后的 Git diff 是否只包含预期变化。
- Linter 的规则会不会与 Advanced Tables 的表格格式互相改写。
