# 校准辨识与不确定度

## 两个入口

基础入口：先用四次参考测量手算斜率和截距，再看残差不能告诉什么。快进入口：检查温漂设计矩阵的秩、协方差假设和外推反例。两路校准同一个 12 bit ADC，code 无量纲计数，参考读数单位 V，温度差用 K（与摄氏度差相同）。

![[电子电路/80-实践/30-采集DMA与闭环/assets/06-calibration.svg]]

## 拟合参数必须有足够不同观测

先设 v_i=b+a c_i+e_i，将 code 当确定且无误差的解释变量。X 每行 [1,c_i]，β=[b,a]ᵀ；目标最小化 ||Xβ−v||²。若 X 两列独立，最优条件为 Xᵀ(Xβ−v)=0。不是任何数据都能同时估 b 和 a：全是同一码时，观测只约束 b+a c0，沿 (δb,δa)=(-c0δa,δa) 无法区分。

读 [[数学/20-线性代数与几何/14-最小二乘伪逆与正则化#无精确解时应最小化什么]]，把列空间解释用于本页 X，返回识别残差正交与唯一性。伪逆可以选一个最小范数解，但它不凭空让原来无法辨识的物理参数变唯一。实现将 code/4096 缩放以改善列尺度，用 SVD 判断条件，lstsq 求解；拒绝 scaled design condition≥1e10 的设计。它没有使用正规方程直接求 β。

## 四点完整算例

c=[0,1000,2000,3000]，参考电压 v=[.010,.811,1.612,2.409] V。均值 c̄=1500，v̄=1.2105 V，Scc=Σ(c−c̄)²=5,000,000 count²。斜率

\[
a=\frac{\sum(c_i-\bar c)(v_i-\bar v)}{S_{cc}}
=0.0007998\ \mathrm{V/count},\quad b=\bar v-a\bar c=0.0108\ \mathrm V.
\]

预测 [.0108,.8106,1.6104,2.4102] V，残差 v−预测=[−.0008,.0004,.0016,−.0012] V。残差和为零，Σc_i e_i=0，SSE=4.8×10⁻⁶ V²；这两条正交性是可检查的拟合结果。n−p=2，因此估计 σ²=SSE/2=2.4×10⁻⁶ V²，σ≈1.54919 mV。

若误差独立、零均值、同方差，且 X 确定，则 Cov(βhat)=σ²(XᵀX)⁻¹；用残差 σhat²估计它得到

\[
\begin{bmatrix}1.68\times10^{-6}&-7.2\times10^{-10}\\-7.2\times10^{-10}&4.8\times10^{-13}\end{bmatrix}.
\]

左上单位 V²，右下是 V²/count²，交叉项是 V²/count。负协方差不是负方差；截距和斜率的联合不确定性相互补偿。已知 code c 的拟合均值方差为 gᵀCov g，g=[1,c]ᵀ；本例可化成 σhat²[1/4+(c−1500)²/5,000,000]。在1500码，标准误0.7746 mV；在4000码约1.8974 mV，并且后者已经外推训练范围。新一次参考电压观测的预测方差还加 σ²，不要把均值标准误当单次观测误差。

这个小样本没有直接宣称某个百分比置信区间。若还要 Student-t 区间，需正态误差假设、自由度2以及指定覆盖概率；共享参考源的系统偏差与温漂不满足这里 iid 模型，不能通过多采几点使它们按1/√n消失。code 本身有随机误差或量化误差时，误差变量问题会使 OLS 假设失效；只把 σ 写小不能修复。

## 温漂需要新方向的实验

扩展为 v=b+a c+d(T−25°C)+e，d 单位 V/K。X 三列 [1,c,T−25]。若全在25°C测量，第三列为零，d 不可辨识。若温度恰为25+c/100，则第二和第三列相关，只有组合 a+d/100 可辨识。应该独立改变 code 与温度：例如 c=[0,1000,0,1000]，T=[25,25,45,45]°C，v=[.010,.810,.012,.812]V，得到 b=.010V,a=.0008V/count,d=.0001V/K，四点分别约束偏置、斜率与温漂。这是精确构造例，不是实测的温漂数据。

读 [[数学/70-数学建模/03-敏感性可辨识性与模型边界#结构可辨识与数值稳定是两回事]]，把其“新观测打破非唯一性”映射为本页独立温度变化。再读 [[电子电路/10-电路基础/04-同一RC从物理到离散实现#工程层：参数不确定与需要新证据的结论]]：只观察RC电压轨迹通常只确定τ=RC。用多温度打破本页共线性与用新电流/已知R打破RC乘积模糊属于相同实验设计原则，具体方程与可辨识变量不同。这是对接口X15的局部教学贡献，并非完成其全部 Bayes/灵敏度课程。

## 残差、范围与版本

画残差随 code、T、时间的变化，系统弯曲可能提示非线性，相关时间结构可能提示漂移；小残差也可能只是训练范围很窄。完全相同的系统偏移加在全部参考电压上，截距照样拟合，残差完全不变。因此需另外追踪参考源不确定度、加载、热平衡与设备范围。任何校准必须保存训练范围、配置、误差模型和 calibration_id；不在换 ADC 分辨率、参考电压或前端增益后默默继续使用旧a,b。

## 四题与理由

1. 三次同一码的平均值很稳定，能校准斜率吗？答：不能，X秩不足，只约束该码下b+ac0，重复减少随机误差而不提供新方向。
2. 四点残差正交是否证明ADC线性？答：不能，这是所选线性OLS最优解的代数性质；训练范围外、温度外及其他输入条件仍可能非线性。
3. 温度随码严格同增会怎样？答：a与d混在同一列方向，无法分开；必须改变实验设计，不能单靠更精细数值求解。
4. 参考源整体偏高1 mV，残差会显著增加吗？答：不会，偏移被b吸收；这正说明残差估计不包含共享参考偏差。
