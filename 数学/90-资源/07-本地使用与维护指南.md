# 本地使用与维护指南

## 安全导入

先备份你原知识库中的 `数学/` 文件夹。压缩包顶层只有 `数学/`，将它放回知识库中原来的同级位置，再合并或替换对应文件。不要把顶层文件夹放进现有 `数学/`，否则会形成 `数学/数学/`。

本次保留原有57个路径，并保留原始130次库外引用的目标。若你在上传后又修改了同名文件，应先用差异工具合并，直接覆盖会丢失你的后续修改。压缩包不是整个知识库，其他目录、Obsidian 设置、主题、插件与历史记录没有随包提供，也没有被改写。

从 `00-数学-首页.md` 开始。六科地图负责系统学习，原有应用文件继续可用，跨科目录提供综合题、反例、证明方法与可执行实验。

## 图片、公式与折叠答案

图片使用本地 SVG 和相对路径，存放于 `assets/figures/`。请连同整个 assets 目录导入，不能只复制 Markdown。SVG 中字形已转换成路径，不需要读者另装绘图时的字体，也没有附带字体文件。

正文使用 `$...$`、`$$...$$` 与标准 TeX 环境，不要求自定义宏。折叠解答使用原生 `[!question]-` Callout；单击标题可展开。表格内双链的别名分隔符写作 `\|`，避免 Markdown 将它误判为新列。

本次做了文件级链接、公式解析与本地图示检查，但没有在你的实际 Obsidian、主题和插件组合中打开全部页面。若个别主题改变表格或公式的视觉样式，先切换默认主题确认，不要马上改坏数学源代码。

## 库外链接为何可能暂时显示为未创建

带 `AI/`、`计算机知识/` 等前缀的目标属于原知识库的其他目录。它们不在本次上传子目录中，不能据此认定失效，也没有创建空白文件去“消除红链”。另有原始短链接需要在完整库中解析，详见 [[数学/90-资源/08-库外链接保留清单|保留清单]]。

库内双链采用原有 `数学/` 根路径约定；图片采用相对路径。若以后整体改名或迁移目录，请在 Obsidian 中进行，并检查是否启用内部链接自动更新；跨库复制仍应重新审计，不能假设软件能找到未导入的目标。

## 运行数学实验

阅读正文不需要 Python。运行实验建议建立独立环境，在 `数学/` 内执行：

```bash
python -m venv .venv
# 激活环境后执行；不同操作系统的激活命令不同。
python -m pip install numpy scipy sympy matplotlib pyyaml
python "80-跨学科专题与综合练习/六科综合实验.py"
python "90-资源/维护/审计知识库.py"
python "90-资源/维护/运行原始实验.py"
```

综合实验生成或更新 `90-资源/维护/综合实验验收.json`，原始实验检查生成单独报告。失败会用非零退出码提示，而不是静默跳过。不要用 `python -O` 运行以依赖断言为验证手段的原始演示脚本。

重绘所有图片可执行：

```bash
python "90-资源/维护/生成教学图示.py"
```

重绘需要本机可用的中文字体；现有 SVG 阅读不需要。绘图脚本不下载字体、不访问远程图片。输出参数见 `assets/figures/图示参数清单.json`。

公式验收另外需要 Node.js 与 `mathjax-full`。建议在库外临时工作目录安装依赖，避免把 `node_modules` 混入知识库：

```bash
npm install mathjax-full
# 让 Node 能解析该临时目录中的依赖后，执行维护目录的 .cjs 脚本。
node "/你的知识库/数学/90-资源/维护/公式渲染验收.cjs"
```

可通过 `NODE_PATH` 指向临时工作目录的 `node_modules`，或将验收脚本复制到该目录并传入数学根目录参数。维护脚本说明包含具体参数。报告记录实际环境版本，不等于保证未来所有依赖版本行为完全一致。

## 后续维护规则

新增页面先接入一张课程地图，再添加具体先修与后续链接；不要只靠全局图谱识别知识依赖。新增定理写清对象、假设、结论与证明层级，新增算例至少保留一条独立核验。修改 Python 后同步对应正文中的完整代码片段，并重跑检查。

本库的 SHA-256 清单用于核对交付文件是否改变，不证明数学正确性。静态审计、数值实验、精确算例和人工复核分别承担不同任务，详见 [[数学/90-资源/09-修订说明与验收报告|验收报告]]。
