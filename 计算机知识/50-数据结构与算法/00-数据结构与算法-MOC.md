# 数据结构与基本算法 · MOC

<!-- ROUND3 NAV END -->


数据结构不是一份要背诵的容器清单，算法也不是“记住模板”。这门课训练的是一条可迁移的推理链：**先说清问题和允许的操作，再选择表示、写出不变量、证明操作为何正确，最后分析它在什么成本模型和输入边界下可用。**

> [!abstract] 学完后的能力
> 你将能根据访问、更新、排序、搜索、连通和优化需求选择数据结构；能用不变量解释算法而不只复述代码；能区分最坏、平均与摊还复杂度；能把渐近分析与缓存、内存、并发、持久化和真实输入分布联系起来。

## 入门诊断与补桥

开始前不需要学过离散数学或刷题。你只需能手工追踪变量、`for`/`while`、函数返回值和列表下标，并能计算小规模的 `1+2+...+n`。若“每轮减半”“下标从 0 开始”或“循环执行多少次”还不熟，先用 [[计算机知识/10-编程语言/01-Python/00-Python基础-MOC|Python 基础 MOC]] 补齐变量、条件、循环与列表；读到公式时先代入 `n=1,2,4,8`，不要为了继续阅读而硬背符号。

> [!tip] 首读方式
> 首次系统学习请以本页的“第一次系统学习”路线为准，而不是机械地跟随每页页尾链接：`06`、`13`、`14` 是有明确项目需要时再进入的专题。每一课先完成一个手算例子和一题练习，再进入下一课。

## 先区分四层

| 层次 | 回答的问题 | 例子 |
| --- | --- | --- |
| 抽象数据类型（ADT） | 使用者可以做什么？ | 栈提供 push/pop，映射提供按键查找 |
| 表示 | 数据在内存或存储中怎样组织？ | 连续数组、链式节点、开放寻址、邻接表 |
| 算法 | 操作怎样一步步完成？ | 二分查找、堆化、BFS、动态规划 |
| 成本与证据 | 在什么模型、输入和机器上值得？ | 比较次数、额外空间、缓存未命中、基准和测试 |

同一种 ADT 可以有多种表示；同一种算法也可能因为数据布局、哈希函数、并发协议或输入分布而表现不同。因此，课程里的 $O(1)$、$O(\log n)$ 和 $O(n)$ 都必须带着操作、成本模型与前提阅读。

## 每道题都使用同一张分析卡

1. **输入与目标：** 输入规模是什么，输出要满足什么？
2. **允许操作：** 读、写、插入、删除、比较、随机访问或顺序扫描？
3. **表示：** 数据怎样放置；是否允许重复、空值、环或并发修改？
4. **不变量：** 每一步前后都必须保持什么？
5. **正确性：** 初始化为什么成立，步骤为何保持，结束为何推出目标？
6. **成本：** 时间、额外空间、I/O、缓存、通信和预处理分别是多少？
7. **边界：** 空输入、重复值、极端深度、溢出、恶意输入和规模上限怎样处理？
8. **证据：** 哪些由证明保证，哪些由测试、基准或生产观测支持？

## 结课成功标准

- [ ] 面对一个新问题，我会先写操作集合和不变量，而不是先套代码模板。
- [ ] 我能区分抽象数据类型、具体表示和操作算法。
- [ ] 我能说明复杂度结论依赖的输入规模、成本模型和假设。
- [ ] 我能为数组、链表、哈希表、堆、搜索树和图结构各给出适用与不适用场景。
- [ ] 我能用循环或递归不变量解释二分、遍历、贪心或动态规划为何正确。
- [ ] 我会把空输入、重复值、溢出、恶意输入、内存限制和测量噪声纳入测试。
- [ ] 我能说明磁盘页、概率误差和近似召回率改变了什么成本模型，也能明确它们没有保证什么。
