# 02 · 语法、类型与函数

## 本课目标

读懂声明、初始化、`const`、按值传参和只读借用；把函数写成输入、输出和不变量清楚的小单元。C++ 的类型不仅是“数据形状”，还携带生命周期、可变性和所有权约束的线索。

<!-- code-sync: ./types_functions.cpp -->
```cpp
#include <iostream>
#include <string_view>

int twice(int value) {
    return value * 2;
}

void greet(std::string_view name) {
    std::cout << "Hello, " << name << "\n";
}

int main() {
    const int answer = twice(21);
    greet("C++");
    std::cout << answer << "\n";
}
```

`value` 按值复制，函数拥有自己的 `int`；`std::string_view` 是一段非拥有的字符范围，调用者必须保证原字符数据在 `greet` 使用期间仍活着。不要把返回的 `string_view` 指向临时 `std::string`。

## 阅读声明的次序

- `const int answer`：对象本身被定义为 const，不能通过其他别名合法修改；这不同于“用 const 引用/指针观察一个原本可变对象”，后者只限制该访问路径。
- `int twice(int value)`：返回一个 `int` 值；小标量按值清晰且通常廉价。
- `void greet(std::string_view name)`：无返回值，读取一个借用范围；它不能延长底层字符串生命期。
- `{}` 列表初始化优先于容易发生窄化的初始化；编译器拒绝可疑转换是帮助而非障碍。

## 练习与成功标准

新增 `int square(int)`，在 `main` 中调用 `square(7)`，用 `const int` 保存并输出结果。成功标准：`cmake --build build --target types_functions` 后输出包含 `Hello, C++`、原有的 `42` 和新增的 `49`；能指出哪一行调用证明新函数真的被执行，并说明为何 `string_view` 不是字符串的所有者。
