# 收入、存货、长期资产与报表调整

两家公司的现金收付一样，利润为什么不同？收入要看履约，存货要分配成本，长期资产要估计消耗和可收回金额；税法确认时间又可能不同。分析师要先识别差异来自经济活动、政策还是估计，再决定是否做可比调整。调整表是**分析工作底稿**，不能冒充公司依法应重新出具的报表。

本课承接[[社会科学/50-CFA课程/10-三张财务报表权责发生与现金勾稽|澄河制造2026完整账本]]：收入500、NI48.75、CFO63、现金113、存货80、固定资产220、税款应付4.25、负债244.25、权益228.75，总资产473。下列各情景**分别从这个基线开始**；没有说明就不叠加。全部金额为万元。税规则是教学假设，适用地未指定，不当作实际税务建议。

## 1. 收到钱与挣得收入之间隔着履约

IFRS 15的主线是识别合同、履约义务、交易价格，按相对独立售价分摊，再在义务履行、客户取得控制时确认收入。[IFRS 15官方About](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-15-revenue-from-contracts-with-customers/)支持这五步；它不替代复杂合同的具体判断。

澄河在基线交易之外，2026年12月另收设备预付款30；合同可执行、不可退，设备要到2027年2月才交付；不含其他服务，控制权也未转移，没有重大融资成分。税法在本题同样等交付才征税。2026借记现金30、贷记合同负债30，收入为0。到2027交付，借记合同负债30、贷记收入30，同时另结转实际销售成本。成本金额未给定，不能凭30收入算出下一年的净利润。

| 2026预收情景 | 基线 | 正确叠加预收30后 |
|---|---:|---:|
| 现金／总资产 | 113／473 | 143／503 |
| 合同负债／总负债 | 0／244.25 | 30／274.25 |
| NI／权益 | 48.75／228.75 | 48.75／228.75 |
| CFO／CFI／CFF | 63／－60／10 | 93／－60／10 |

两边仍平衡，钱收到却尚未赚得。若直接把30记收入，便把未来履约义务藏掉；先查发货、验收、退货权、附带服务与合同条款，不能只凭发票日期判定控制权。多义务、可变对价、主代理、长期履约条件及合同资产减值都需进一步原文核查，本例不覆盖它们。

## 2. 同一批货：FIFO与期间加权平均如何改利润

基线的存货数量补充如下：期初60件，每件1万元；先买100件×1万元，再买100件×2万元；两次采购后销售220件，无损耗。可互换货物的总可用数量260、成本360，期末40件。仓库实物移动与账面成本流转是不同问题。

FIFO先分配旧成本：$COGS=60\times1+100\times1+60\times2=280$，期末40×2＝80。期间加权平均单位成本 $360/260=18/13$：销售成本 $220\times18/13=3960/13\approx304.6154$；期末成本 $40\times18/13=720/13\approx55.3846$。两种方法各自满足“期初＋采购－销售成本＝期末”。[IAS 2，2021 issued，§§23–27](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ias-2-inventories.pdf)定位可互换存货FIFO或平均成本与不通常可互换项目个别辨认；这里采用期间平均，并非逐次移动平均。

| 改为期间加权平均的独立情景 | 结果 |
|---|---:|
| 收入／销售成本／税前利润 | 500／304.6154／40.3846 |
| 所得税总费用／NI | 10.0962／30.2885 |
| 存货／递延所得税资产 DTA | 55.3846／6.1538 |
| 现金／总资产 | 113／454.5385 |
| 总负债／权益 | 244.25／210.2885 |
| CFO／CFI／CFF | 63／－60／10 |

这张调整表指定：**税法仍按FIFO、当前应税利润65、当前税16.25、已付税12不变，未来扣除可利用且税率恒25%**。账面存货比税基低 $320/13$，可抵扣暂时性差异形成DTA $80/13$。递延税收益降低总税费，并不在2026返还现金。若实际税法随会计方法改变，当前税与现金税可能也变，此表不能照搬。税率为0时，NI差应是全额320/13，不能依旧使用75%差额。

本例成本上涨且期末有库存，FIFO利润高于平均法；若价格下降、销售穿透旧成本层或存在减值，方向与大小会改变。不能把高利润等同高经营效率。

**限定的IFRS/US GAAP对照：** IAS 2上述可互换货物成本方法不含LIFO；FASB [ASU 2015-11，Summary及ASC 330-10-35-1A–1C](https://storage.fasb.org/ASU_2015-11.pdf)把美国存货后续计量分为两组：FIFO/平均法等用成本与NRV孰低，LIFO/零售法继续用成本与market孰低。因此“US GAAP存货一律成本与market孰低”不准确。本课仅核对这一区分，未展开US GAAP LIFO转换、清算、market上/下界或减值转回规则，不能据此做全体系报表转换。

## 3. 减值要同时追资产、利润、税和现金

**存货独立情景：** FIFO期末账面80，可变现净值NRV70。NRV指预计售价减完工和销售所需成本；它不是折现后的使用价值。按IAS 2 §§9、28–34确认损失10，存货降至70。指定税法出售时才准扣、未来应税利润很可能足够，则DTA2.5、递延税收益2.5、总税费13.75、NI41.25；当期税款及现金未变。[IAS 12官方介绍](https://www.ifrs.org/issued-standards/list-of-standards/ias-12-income-taxes/)支持账面与税基暂时性差异机制，DTA可利用性是本例明确条件。

期末资产 $113+60+70+220+2.5=465.5$；负债244.25、权益 $228.75-7.5=221.25$，两边相等。CFO仍63。用**未含减值的经营存货增加20**，间接法为 $41.25+40+10-20-20+10+4.25-2.5=63$；其中加10非现金减值，减2.5 DTA增加。若用报表存货增加10，则不再单独加减值10：$41.25+40-20-10+10+4.25-2.5=63$。两种途径任选一种；一起用会夸大CFO10。

次年若货仍在手且NRV恢复至85，IAS 2 §33允许转回限于原减值10，账面最高恢复到原成本80，不能增加到85。税差随账面恢复相应减少。这里的IFRS转回规则不用于美国准则或所有长期资产。

**固定资产独立情景：** 基线净额220，其中一组资产有减值迹象、可独立估计现金流，使用价值190、公允价值减处置成本180；可收回金额取二者较高190，损失30。假设成本模式、无重估储备且未来税扣除可利用，税基未改，DTA7.5，NI26.25，总资产450.5、负债244.25、权益206.25，现金与CFO仍113与63。[IAS 36官方About](https://www.ifrs.org/issued-standards/list-of-standards/ias-36-impairment-of-assets/)支持可收回金额的双路比较；不是任意选择更悲观数180。本例排除商誉、金融资产等另有计量规则对象，未示范现金产生单元分配与商誉减值。

## 4. 资本化、折旧与税差不能混成一项

购置60若满足固定资产确认条件，先记资产，后按受益期间消耗；若是普通日常维护，通常没有额外未来经济利益，不能只因“想提高利润”就资本化。基线折旧40为已给事实。另有一台假设设备成本120、残值0、达到可用状态，受益期3年且消耗均匀，则直线折旧40/年。改为6年会把每年费用降至20、抬高近期利润，却不改变购置当日现金120；必须有使用寿命依据。[IAS 16，2021 issued，§§7、15–22、50–61](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ias-16-property-plant-and-equipment.pdf)定位确认、成本与折旧；残值和寿命至少年末重看、达到可用状态开始折旧。此独立设备说明不是更改基线60购置。

**基线税折旧变为60的独立情景：** 账面折旧仍40，假设税法本期多扣20、以后少扣20；应税利润45，当前税11.25；已付税仍12，所以期末应收所得税0.75，取代基线应付4.25。固定资产账面220、税基200，产生DTL5。总税费 $11.25+5=16.25$、NI48.75不变。期末资产473.75＝负债245＋权益228.75；现金113不变。间接CFO把净利润、折旧及经营营运资本接回，再加DTL5、减当前税资产0.75，结果仍63。

递延所得税负债DTL5表示未来扣除变少可能导致以后交更多税，绝不是本期又付款5。永久差异不会仅因利润与应税收入不同就产生递延税；例如题设某罚款永不准扣，应先修有效税率调节表。本组不展开实际税法、亏损抵扣限制、Pillar Two、税率变动或全部确认例外。

## 5. 租赁：增加使用权与债务，也改现金分类

**独立叠加一笔租赁：** 2026年初澄河取得一台可识别设备的两年控制使用权，非短期/低价值豁免，无初始直接费用、预付款、激励、购买权或残值保证；年末付款60、55，适用年利率10%。初始租赁负债 $60/1.1+55/1.1^2=100$，使用权资产ROU同为100；直线折旧50/年。2026利息10、付款60中本金50，期末负债50、ROU50。初始100对100不涉及现金，需单独披露，不能塞进投资付现100。[IFRS 16，2021 issued，§§22–36、50](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ifrs-16-leases.pdf)支持此普通承租人模型与本金融资分类。

指定教学税法按同额折旧50和利息10扣除，本例不产生额外递延税；现金税仍12（超缴留作应收，未退款）。利息10仍选经营分类，租赁本金50融资分类。

| 2026租赁叠加情景 | 完整结果 |
|---|---:|
| EBIT／利息／税前利润 | 30／25／5 |
| 总税费／NI／期末RE | 1.25／3.75／23.75 |
| CFO／CFI／CFF／期末现金 | 53／－60／－40／53 |
| 现金／应收／存货／PPE／ROU／当前税资产 | 53／60／80／220／50／10.75 |
| 总资产 | 473.75 |
| 应付／有息债／租赁债／股本／RE | 60／180／50／160／23.75 |
| 总负债＋权益 | 290＋183.75＝473.75 |

间接CFO $3.75+90-20-20+10-10.75=53$，90是原折旧40＋ROU折旧50。2027租赁利息5、本金50、ROU再折旧50；只就租赁自身，两年付現115＝成本摊销100＋利息15。租赁会让债务与折旧增加；不能只因CFO分类变高就认定合同经济成本下降。此表未覆盖出租人、经营租赁US GAAP双模型、修改、售后回租、变动支付或IFRS18生效后的利息分类。

## 6. 原创情景题与解答

**题1：** 收到设备预收30后，财务主管认为现金变多所以收入也应多30。哪份证据最有判断力？**解：** 合同履约与控制权事实，包括交付/验收与剩余义务；银行流水只证明收款。2026资产和负债各加30，利润不变。错误选项“看是否开票”只锁定法律/税务记录的一部分。

**题2：** FIFO存货减值10后，分析师用存货增加10又加回减值10，CFO得到73。怎么改？**解：** 用报表增量10就不加回10；或先恢复经营增量20再加回减值10。还须减DTA增加2.5。本例正确63。机械地“所有非现金费用都加回”忽略资产差额已包含该费用。

**题3：** 税折旧比会计折旧多20，现金税已付12。NI是否增加5？**解：** 没有，当前税少5、递延税费多5，总税费未变；当前税应收0.75与DTL5一并出现。只有当前现金收付变化才改变今年现金。

**题4：** 租赁首年付款60都算经营费用是否能得到同样NI？**解：** 本特定两年合同比较的首年50折旧＋10利息恰为60，但资产、租赁负债和现金分类仍错误；第二年费用50＋5＝55。金额偶合不能证明方法正确。

到[[社会科学/50-CFA课程/12-现金流比率盈利质量与分析边界|比率与盈利质量]]，检查这些调整如何改变比率分子分母；到[[社会科学/50-CFA课程/80-三表与资本预算复算|复算实验]]看不平衡反例与完整资产负债测试。
