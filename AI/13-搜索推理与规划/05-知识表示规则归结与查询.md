# 知识表示：事实、规则、统一、归结与查询

“已知Ada是Ben的家长，Ben是Cora的家长，能否推出Ada是Cora的祖先？”这是显式事实与规则的推理问题。我们要知道哪些对象被谈论、谓词是什么意思、规则承诺什么，以及查询结果由哪些前提推出。文本向量相似可以帮检索相关片段，但相似度本身不定义逻辑蕴含，也不替代这个知识库。

先回顾[[数学/10-数学语言与基础/03-集合映射命题与合法推理|谓词、量词、充分条件]]，然后在这里建立一个小而完整的符号系统。本页选择经典逻辑与有限、无函数的正向规则子集；它不把缺失事实自动当现实世界中的否定。

## 语法与语义先分开

命题逻辑中，原子p、q取真或假，用¬、∧、∨、⇒组成句子。一阶逻辑增加对象、变量、常量、函数与谓词。项是变量x、常量Ada，或函数项f(x)；谓词`Parent(x,y)`形成原子句。变量要受量词绑定才成为闭句，例如 $\forall x\forall y(Parent(x,y)\Rightarrow Anc(x,y))$。

一个**模型**给出非空论域及常量、函数、谓词的解释；公式在该解释下具有真值。知识库KB是一组闭句。$KB\models q$（蕴含）表示每个使KB全真的模型都使q真；$KB\vdash q$ 表示某推理过程写出了q的形式证明。**可靠性（soundness）**要求推得的都被蕴含，**完备性（completeness）**要求被蕴含的能被推得；两者不同。可满足表示至少一个模型使所有句子真。若KB本身矛盾，在经典逻辑中没有满足模型，因而蕴含任意句子；它不能作为可靠业务答案的依据。

开放世界下，“未证明Anc(Cora,Ada)”不等于证明其否定。有限数据库或规划器可显式约定闭世界，把未列出原子当假；这是一项额外模型约定。唯一名称（Ada、Ben、Cora互不同）、论域只含这三名人物，也不是一般一阶逻辑自动给出的事实；有限实验会明确采用这些数据库约定。

## 一个事实和规则知识库

事实与规则如下。规则变量均隐含全称量词，每次应用前可以改名成新的局部变量。

```text
F1: Parent(Ada,Ben)
F2: Parent(Ben,Cora)
R1: Parent(x,y) -> Anc(x,y)
R2: Parent(x,y) AND Anc(y,z) -> Anc(x,z)
```

这里Anc定义“由至少一条Parent边连接的祖先关系”；不把自己作为零步祖先。Parent是我们给定的关系名称；规则只编码传递推导，不认证事实是否来自可信记录。R1为确定Horn规则：多个正原子前提推出一个正原子结论；R2同样如此。

| 正向轮次 | 使用的前提与替换 | 本轮新增 |
| --- | --- | --- |
| 初始 | F1，F2 | 两个Parent事实 |
| 第1轮 | R1，{x↦Ada,y↦Ben}及{x↦Ben,y↦Cora} | Anc(Ada,Ben)，Anc(Ben,Cora) |
| 第2轮 | R2，{x↦Ada,y↦Ben,z↦Cora} | Anc(Ada,Cora) |
| 第3轮 | 没有能产生新原子的规则实例 | 停在不动点 |

查询 `Anc(Ada,Cora)` 为可推得；查询 `Anc(Ada,Who)` 返回Who=Ben、Cora。反向链也可复算：要证Anc(Ada,Cora)，选R2，把x=Ada,z=Cora，剩子目标Parent(Ada,y)与Anc(y,Cora)；F1统一y=Ben，再由R1及F2证Anc(Ben,Cora)。反向搜索可能选错规则或循环，逻辑规则可靠不等于搜索策略必然终止。

有限常量、无函数、只含确定Horn规则时，可能的基原子有限，正向链单调增加原子，终止于最小模型（最小不动点）。可靠性可按轮次归纳：事实被KB蕴含；某轮前提均被蕴含，规则在每个模型真，故新结论也被蕴含。对这个有限ground Horn子集，正向闭包给出所有被蕴含的正原子；不是在解决完整一阶逻辑。加函数f后可有 `P(a) -> P(f(a)) -> P(f(f(a))) ...`，有限终止理由失效。一般一阶逻辑蕴含只有半判定性质，证明不存在未必会停。[AIMA 作者第9章讲义，PDF第8、24–28、43–46页](https://aima.cs.berkeley.edu/slides-pdf/chapter09.pdf)用于定位这项边界与推理路线。

## 统一是保持同一变量含义的替换

统一（unification）找替换 $\sigma$ 使两个项或原子应用替换后完全相同。最一般统一者MGU尽量不额外限定未被要求的变量；它不是按字面字符串相似度匹配。来自不同规则的变量先标准化分离，避免同名局部变量被意外绑定。

手算 `P(x,f(y))` 与 `P(Ada,f(Ada))`：谓词名称和元数一致；首参数要求x↦Ada；次参数函数名称f一致，再要求y↦Ada，得到 $\sigma=\{x\mapsto Ada,y\mapsto Ada\}$。代入两边均为 `P(Ada,f(Ada))`。

`P(x,x)` 与 `P(Ada,Ben)`不能统一：第一位迫使x=Ada，第二位还要求Ada=Ben，在本实验不同常量项的语法体系中失败。若忽略“同一变量每次出现必须一致”而分别匹配，会错误成功。一阶理论中的等式推理则是额外机制，本实验并未实现它。

**Occurs check** 禁止把变量绑定到包含自身的有限项。试图统一x与f(x)，会要求有限项t=f(t)；右侧高度比左侧大1，不存在有限语法树解。较隐蔽的链 `P(x,f(x))` 与 `P(f(y),y)` 先有x=f(y)，随后要求y=f(f(y))，仍必须拒绝。检查要在已有替换解引用后进行，不能只在原字符串中查变量。[Stanford Logic Programming，Unification（变量改名与occur check段）](https://logical.stanford.edu/logicprogramming/miscellaneous/unification.html)明确给出变量绑定、发生检查与局部变量改名的算法条件。某些语言允许循环的rational tree，那已是不同项语义，不能假称为本文的有限一阶项。

## 归结如何可靠地消去一个互补文字

文字是原子或其否定，子句是文字的析取。命题归结规则为

$$
\frac{P\lor A\qquad \neg P\lor B}{A\lor B}.
$$

其可靠性逐模型证明很短：若模型使P假，为让首前提真就必须使A真；若P真，为让第二前提真就必须使B真；无论哪种，A∨B真。A或B可以是空析取，空子句恒假。一次只消去一对互补文字；不能从 `{p,q}` 与 `{¬p,¬q}` 同时消去两对而得空子句，因为赋值p=true,q=false使两前提都真，它们并不矛盾。正确的一次归结得到q∨¬q或p∨¬p这种永真子句。

一阶版本先统一互补原子并把同一个替换用于**两子句余下全部文字**：从 `¬Parent(x,y)∨Anc(x,y)` 和 `Parent(Ada,Ben)`，MGU为{x↦Ada,y↦Ben}，归结得Anc(Ada,Ben)。变量必须先标准化分离；要处理完整一阶归结完备性还涉及因子化、公平策略与正确的子句转换，本实验不声称实现完整定理证明器。

要证明 $KB\models q$，可把 $KB\land\neg q$ 化为子句并反驳。上例查询Anc(Ada,Cora)的完整链为：

```text
C1 Parent(Ada,Ben)
C2 Parent(Ben,Cora)
C3 ¬Parent(x,y) ∨ Anc(x,y)
C4 ¬Parent(u,v) ∨ ¬Anc(v,w) ∨ Anc(u,w)
C5 ¬Anc(Ada,Cora)             # 取查询的否定
C6 Anc(Ben,Cora)             # C2,C3，x=Ben,y=Cora
C7 ¬Anc(Ben,w) ∨ Anc(Ada,w)  # C1,C4，u=Ada,v=Ben
C8 Anc(Ada,Cora)             # C6,C7，w=Cora
C9 空子句                    # C5,C8
```

空子句说明KB与查询否定不可同时为真。命题逻辑有限饱和归结的反驳完备性见 [Stanford Introduction to Logic，第6章6.3–6.4，Resolution](https://logical.stanford.edu/intrologic/chapters/chapter_06.html)。本文给了这条查询的全部证据，但没有把归结完备性大定理的完整证明伪装成本页已有推导。

一般一阶转子句还要消蕴含、否定内移、变量改名、Skolem化及分配。Skolem化保可满足性，通常不与原句在原签名下逻辑等价；例如“∀x∃y喜欢(x,y)”需新函数y=f(x)，不能用一个固定常量充当所有x的见证。等号需要等号公理或专门推理；缺它的纯归结系统不能自行证明所有带等式结论。

## 独立oracle、边界与练习

实验将三人物的规则有限ground化，固定Parent扩展只有两条边，所有可能Anc原子9个。对两个固定事实加9个Anc原子共11个命题枚举2048赋值，保留满足所有ground规则与事实的模型，再交集求每个模型都真的正原子；与正向链闭包比较。未从原Parent表产生的新Parent不在该实验签名里，因此这是明确有限数据库对照，不能把2048赋值说成穷尽所有一阶论域。

`resolve`只做一次ground命题归结；实验逐个赋值检查前提都真时归结式必真。`unify`处理有限项含occurs check；它不自动完成从一阶式到子句转换。算法范围与正文声明相符。

**题1：** KB只有P⇒Q和Q，能推出P吗？不能。P=false,Q=true满足KB，是反模型。反向链不是把蕴含箭头任意反过来。

**题2：** 未推得Anc(Cora,Ada)，能回答“否”吗？在原开放一阶知识下只能说“不被当前正向闭包证明”，没有推出¬Anc(Cora,Ada)。在显式有限最小数据库约定下可以回答该关系不在结果表中，但需保留这个约定。

**题3：** 把C4中u,v与另一规则的x,y直接复用可不可以？规则各自量词作用域局部，调用前应换新变量；同名字并不授予跨规则相等关系。先改名再做统一，才能避免意外捕获。
