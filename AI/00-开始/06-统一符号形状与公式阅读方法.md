# 统一符号、形状与公式阅读方法

公式的困难经常不是某个高级定理，而是同一个字母在相邻章节换了含义。本页给出默认约定；单篇显式声明的局部约定优先。把符号当成带类型的对象，能在运行代码之前发现很多错误。

第一次读下面的 $B,T,V$，先在 [[AI/20-LLM/10-原理/02-自回归建模Logits损失与困惑度#先把五次预测放进一个有限数组|NLL 原理 02 的有限数组]] 看一份已经能数清的输入、右移目标、词表轴与有效计分位置，再回到本节，将具体数字换成批量、位置和候选数。那里完整例不依赖本页；已经能重建它的读者可直接继续默认约定，无须往返借读。

## 默认形状与方向

深度学习实现默认 batch 在前。批量序列表示为 $X\in\mathbb R^{B\times T\times d}$，其中 $B$ 是批量大小，$T$ 是序列长度，$d$ 是特征维度。线性层的单样本数学推导可能使用列向量 $y=Wx$；PyTorch 的批量输入通常按行储存，实际写成 $Y=XW^\top+b$。二者并不矛盾，但不能把一个约定的梯度式直接抄到另一个约定。

注意力常拆成 $Q\in\mathbb R^{B\times H_q\times T_q\times d_h}$，$K,V$ 的 head 数可能为 $H_{kv}$。单头推导省略 batch/head 维后，$QK^\top$ 的形状是 $T_q\times T_k$；只有特征轴被收缩。GQA 还需说明 query head 到 KV head 的分组对应，不能靠不明含义的广播糊过去。

语言模型 logits 常为 $B\times T\times V$，标签为 $B\times T$；类别维是词表 $V$。图像卷积常用 $N,C,H,W$；CTC 的 log-probabilities 接口常用 $T,N,C$。这些都是语义轴，不只是几个恰巧相乘相等的数字。实际接口依据[[AI/12-PyTorch/06-梯度诊断数值验证与自定义算子|梯度诊断]]与[[AI/40-语音与音频模型/03-CTC路径求和流式延迟与语音评测|CTC]]中的固定版本来源。

## 用七个问题读一条公式

先确定对象是标量、向量、矩阵还是概率分布；写出形状和单位。接着标出固定条件与随机变量，再指出求和或期望覆盖哪些对象。然后检查目标的优化方向、分母、适用条件以及退化情况。最后构造一个能手算的小例，并找一个边界反例。这个顺序比先背公式名称更可靠。

例如 $L=\sum_i\ell_i/N$ 中，$N$ 可能是序列数、有效 token 数或权重和。这三种定义不是排版差异，而是三个不同的经验目标。见[[AI/12-PyTorch/05-变长批处理Packing与有效Token归一化|损失分母]]。又如 $\mathbb E[f(X)\mid C]$ 仍对条件分布中的随机性平均，不等于任意一个样本上的 $f(x)$。

## 梯度、微分与有限变化不要混用

标量目标对向量的梯度默认与该向量同形；矩阵梯度按 Frobenius 内积定义：

$$
dL=\langle\nabla_W L,dW\rangle_F
=\operatorname{tr}((\nabla_W L)^\top dW).
$$

$dW$ 是无穷小变化，$\Delta W$ 是有限更新；一阶近似不保证大步长仍准确。$\partial L/\partial W$ 要说明其余量如何保持或依赖于 $W$。共享参数有多条路径时，所有路径都贡献梯度。[[AI/11-数学与统计桥梁/02-矩阵微积分VJP与反向传播|VJP]]解释为什么不必构造完整 Jacobian。

向量的平方误差分解使用**协方差的迹**而不是直接加协方差矩阵：

$$
\mathbb E[\|Y-f(X)\|^2\mid X]
=\operatorname{tr}\operatorname{Cov}(Y\mid X)
+\|\mathbb E[Y\mid X]-f(X)\|^2.
$$

左边是标量，右边也必须是标量。这个检查连接[[AI/50-扩散模型/03-Score去噪FlowMatching与CFG的联系|条件期望与去噪]]和[[AI/20-LLM/60-模型格式与量化/08-量化误差传播校准目标与端到端评测|二阶矩加权的量化误差]]。

## “归一化”不是一个单一操作

向量单位化除以长度，改变的是尺度而保留方向；Softmax 把分数变成给定支持集上的概率，且同一行加常数不变；LayerNorm/RMSNorm 对激活做特定统计变换；损失归一化定义经验目标的单位；优势标准化则改变策略梯度估计的尺度和可能的偏差。它们只有名字相近，没有可随意交换的代数关系。

尤其注意 $\mathbb E[X X^\top]$ 与 $\operatorname{Cov}(X)$：前者是未中心化二阶矩，后者减去了均值外积。输入均值非零时，用协方差替代二阶矩会改变[[AI/20-LLM/60-模型格式与量化/08-量化误差传播校准目标与端到端评测|输出误差]]分析。

## 概率与对数的约定

本库公式默认自然对数 $\ln$，除非显式写 $\log_2$。NLL 单位因此通常是 nat；bits 指以 2 为底。连续分布的密度值可以大于 1，不能当成某个点的概率。离散 token 概率的连乘可转为对数求和，但不能随意改成逐 token 均值后声称仍是同一序列概率。

$p$ 常表示目标或数据分布，$q$ 表示近似/提议分布，$\pi$ 表示策略；实际语义由单篇定义。$\beta$ 在 DPO、扩散、Adam 中分别可能表示 KL 强度、噪声日程和指数平均系数；它们不是跨章节共享的物理常数。

## 掩码、位置与支持集

布尔掩码的 True 含义由接口决定。SDPA 的 True 表示允许参与，其他接口可能用 True 表示忽略。因果条件是 key 的实际位置不晚于 query，而不是无条件取一个矩阵的左下三角。带缓存、滑窗、packing 或跨模态前缀时，先定义位置与可见性。见[[AI/20-LLM/20-架构/11-RoPE相对位置缓存偏移与长度外推|偏移掩码]]。

概率公式出现 $\log q$、$p/q$ 或条件期望时，检查零概率支持集。实现里添加 epsilon 是数值或建模选择，可能改变目标，不能只因“避免报错”就省略说明。[[AI/20-LLM/40-推理/08-投机解码接受拒绝与分布不变性|投机采样]]给出了 $q=0$ 仍可严格处理的例子。
