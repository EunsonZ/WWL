# 基础理论学习路线

这不是一份按周计的课程表，也不要求先读完所有前置。它把学习与计算、状态与执行、证据与解释连接成可回退的阅读路线。每一步都以一个具体问题为入口；卡住时只回到直接缺失的对象、假设或证据，不把整条路线重来。想先看关系再决定从哪里开始，可以打开 [[00-工作台/基础理论总览.canvas|基础理论总览 Canvas]]，双击文件节点进入对应正文；边的文字说明的是先修、应用或比较关系，不是现实世界的因果箭头。

从 [[00-工作台/README|工作台]] 返回日常入口；需要按学科改选时回到 [[../README|知识库总入口]]。若问题转向社会后果、政策或制度，使用 [[社会科学/00-开始/00-社会科学-首页|社会科学首页]]，并把技术指标、经验事实和价值判断分开记录。

## 两种起点，同一份深入解释

**基础补桥**：高中数学或编程新手先进入下面案例的直观层，看术语和一个可手算、可观察的对象；交出一次预测和一句不能外推的结论即可停下。代码是可选的复算入口。卡在某个符号、概率或索引时，只回补直接需要的先修。

**本科基础快进**：已有线性代数、概率、微积分或基础编程的读者，直接进入同一案例的机制层，核对假设和推导，再独立做迁移题。人文与社会问题从材料、论证和识别入手，不把技术课程列成共同先修。

| 层次 | 当前应能做什么 | 可检查产物 |
| --- | --- | --- |
| 直观 | 指出对象、可见信息与输入输出，预测一次变化 | 一张对象图/时间线、预测、一个限制 |
| 机制 | 核对条件，完成推导、论证或实现，并解释反例 | 计算过程、论证比较或可复算输出 |
| 迁移 | 在两个条件共同改变时重新选择方法和证据 | 缺信息清单、方案、接受或暂不能判断的理由 |

三级可以往返，不要求首次阅读完成所有证明。解释、推导、实现和迁移各有出口；跟随答案跑通一次只说明该次复现。

## 三条贯穿路线与六个案例

下表每例只选一条主路线。箭头和跳转表达阅读、信息或论证关系，不自动构成现实因果。

| 主路线 | 追踪对象 | 先进入的案例与可停点 |
| --- | --- | --- |
| 学习与计算 | 任务、表示、目标、变换、输出 | [[AI/80-实践/09-从一句话到学习与生成/01-一句话的目标更新与生成\|一句话的学习与生成]]：画移位表，算一个概率和更新；随后解释共享梯度与错误分母 |
| 状态与执行 | 状态的持有者、更新时间、恢复和失效 | [[计算机知识/40-并行与异构计算/80-张量跨层执行/01-同一张量从数值到线程\|同一张量从数值到线程]]：追踪一个元素，改变 stride 后重算地址；[[AI/45-机器人与具身智能/20-状态估计与LQG/05-从不完整读数到条件不确定性\|不完整读数与条件不确定性]]：预测一次读数如何改变状态估计 |
| 证据、解释与选择 | 主张、可见材料、竞争解释、判断或行动 | [[哲学与文化/10-主题/01-文化政治与组织结构/09-科举命题的证据与竞争解释\|科举命题的证据与竞争解释]]：分时期比较材料；[[AI/80-实践/05-RAG评测与私有服务/02-有引用的回答与可交付行动\|有引用的回答与可交付行动]]：检查证据与执行状态；[[社会科学/40-公共政策与社会学/08-局部有效政策与累积优势的判断\|局部政策与累积优势]]：区分识别、外推和价值目标 |

选当前问题最接近的一例。基础入口先做一张表或一次预测；快进入口先核对形式对象和假设；两者都回到相同答案与深入页。每次只带一个问题跳转：去读哪一节、为什么需要、回来应补上什么。

### 反向追问与关键比较

模型答错时，沿“输出→可见前缀→目标与分母→计算图”追问；程序结果不同时，沿“输出→执行顺序→地址/stride→数值表示”追问；历史解释过强时，沿“结论→反例→竞争解释→材料身份与时期”追问。返回目标变化时，重新选择保存什么状态、读取什么材料。

低秩问题回到[[数学/20-线性代数与几何/16-SVD的推导最优低秩与PCA|SVD]]和[[AI/20-LLM/30-训练/15-LoRA低秩几何QLoRA与蒸馏边界|LoRA比较]]，分别说清权重近似、数据变化、参数更新和缓存状态。结果经过校正或回退时，使用[[AI/80-实践/10-提案证书与完整成本/01-提案校正回退与最终结果|提案、证书与完整成本]]，将提案质量、最终结果和全过程成本分别核对。

这些案例是一组已选教学切片，不代替完整学科课程。[[00-工作台/AItextbook参照与采用边界|参照与采用边界]]记录教学方法来源、接口差异和已披露问题。内容验收、程序复算、客户端呈现和真人学习效果分别从实际结果记录判断。

### 条件更新之后，何时需要换一种证据？

先问你准备主张什么。模型内的条件更新能说明“在这些假设下怎样利用观测”，现实因果、历史比较和规范选择各有另外的义务。去相邻学科时，带回比较对象、关键条件、一个反例和不能推出的结论；资料不足可以停止判断。

| 你要主张什么 | 去哪里、带着什么问题 | 回来补上的一步 |
| --- | --- | --- |
| 模型内怎样预测或更新 | [[AI/45-机器人与具身智能/20-状态估计与LQG/05-从不完整读数到条件不确定性\|条件更新]]：读机制层，噪声、动力学、时点假设是什么？ | 说明更新的是模型内估计，尚不能证明现实干预效果 |
| 改变行动会造成什么 | [[社会科学/10-共同工具/03-因果图反事实与识别\|因果识别]]：先固定目标总体、处理与比较，再读识别假设 | 说明为何观察相关或正确区间不能单独给出干预结论 |
| 某历史解释何以可信 | [[哲学与文化/10-主题/01-文化政治与组织结构/09-科举命题的证据与竞争解释\|历史材料比较]]：读分期、来源和竞争解释 | 收紧到材料支持的时期与群体；保留无法区分的解释 |
| 结果改善是否值得采用 | [[社会科学/10-共同工具/01-事实模型与价值判断\|事实与价值]]：读规范判断，谁得失、用何目标与理由？ | 写出不能由技术指标或因果效果直接推出的价值前提 |

图与公式也需要这些边界。可以沿 [[数学/40-微积分与优化/81-二维参数与三维目标图像|二维参数与三维目标图像]] 做一个完整小例：先预测更新，分别用二维等高线、三维函数高度和迭代曲线核对，再解释稳定、数值与任务效果为何不能互推。返回时带回两个放大因子和一个被特殊初值掩盖的反例。

### 从一段 C 程序返回系统各层

沿“状态与执行”继续时，进入 [[计算机知识/30-计算机系统/20-CSAPP阅读路线/00-CSAPP程序员视角路线|CS:APP 程序员视角路线]]：基础入口先画数组、函数、目标文件、进程、FD 与响应的身份，快进入口直接核对类型/ABI/平台和资源合同。它将十二章主题对应到已有课程，并用四个原创单元补构建、优化、信号/I/O 和并发交接；每次跳转带回一个地址、符号、字节数或状态证据。教材主题地图不表示全文取得、官方实验认证或个人掌握。

## 先修：先能说清对象与问题

先写下一个可检查的问题：输入是什么、输出是什么、你看到的失败或差异是什么。随后从三门课各取最短的必要页：

- 模型、数据、参数和目标分别是什么：[[AI/10-机器学习与深度学习基础/01-AI机器学习深度学习与生成模型的边界|AI、机器学习、深度学习与生成模型的边界]] → [[AI/10-机器学习与深度学习基础/02-模型特征参数目标与泛化|模型、特征、参数、目标与泛化]]；
- 程序的数据如何表示、地址如何解释：[[计算机知识/30-计算机系统/01-数据表示字节序与对齐|数据表示、字节序与对齐]] → [[计算机知识/30-计算机系统/02-进程虚拟地址空间与内存映射|虚拟地址空间与内存映射]]；
- 算法承诺的资源界限是什么：[[计算机知识/50-数据结构与算法/01-复杂度模型渐近分析与摊还分析|复杂度模型与摊还分析]] → [[计算机知识/50-数据结构与算法/02-数组动态数组链表与内存布局|数组、动态数组、链表与内存布局]]。

**检查点：** 你能区分数据、模型参数和目标；能说明一个值在内存中怎样被表示；也能说明复杂度是输入增长的模型，而不是某台机器上的秒数。

## 核心机制：沿一条因果链读下去

选择你当前问题最贴近的一条主线，再把相邻两条当作解释边界。

| 当前问题 | 主线 | 相邻边界 |
| --- | --- | --- |
| 为什么训练分数好，换一批数据却变差？ | [[AI/10-机器学习与深度学习基础/00-机器学习与深度学习基础-MOC\|机器学习与深度学习基础 MOC]]，再读 [[AI/10-机器学习与深度学习基础/05-数据集拆分清洗与泄漏\|数据集拆分、清洗与泄漏]] 与 [[AI/10-机器学习与深度学习基础/06-损失函数优化与训练循环\|损失、优化与训练循环]] | 数据划分不是系统资源；但 I/O、内存和批处理会影响可观察的训练行为 |
| 为什么同一程序会慢、占内存或表现不稳定？ | [[计算机知识/30-计算机系统/00-计算机系统-MOC\|计算机系统 MOC]]，再读 [[计算机知识/30-计算机系统/04-缓存局部性带宽与延迟\|缓存、局部性、带宽与延迟]] | 先测量再归因；算法复杂度、数据布局和运行时开销各自解释不同部分 |

## 聚焦路线：共享计算图如何变成注意力梯度

**问题：** 前向能写出 Attention，为什么反向时不知道某个参数、token 或 score 的梯度从哪里来？

1. 先读 [[数学/40-微积分与优化/03-计算图反向传播与自动微分#推导轨一：手算一张图|计算图的手算例]]：确认上游梯度、局部导数，以及共享节点的多条贡献为何用 `+=` 合并。
2. 再读 [[AI/11-数学与统计桥梁/02-矩阵微积分VJP与反向传播#用一个局部线性近似理解导数|矩阵微积分与 VJP]]：把标量图中的局部乘法推广为 $J^Tg$，逐项核对输入、权重和 bias 梯度的形状。
3. 最后读 [[AI/20-LLM/20-架构/10-注意力反向传播与Softmax竞争#逆着信息流逐步求导|注意力反向传播]]：按 $O=PV$、行 Softmax、$QK^T/\sqrt d$ 的逆序追踪梯度，检查每行至少一个合法 key、mask 位置零梯度和缩放的适用条件。

**退出点：** 能解释共享分支为何相加、VJP 的输入输出形状、Softmax 为什么使可见 key 彼此竞争后，转到 [[AI/80-实践/08-深层机制数值实验/00-数值实验导航与验收|深层机制数值实验]]核对解析梯度、mask 和有限差分。若卡在 Jacobian、行列约定或某条局部导数，回到前两页对应段落；缓存偏移、dropout 或训练目标归一化则进入各自专题。这条路线也在总览 Canvas 下方以三张正文卡表示，边只说明先修与应用关系。

## 可复算练习：让一个小例子反驳或支持理解

练习不需要下载模型、开服务或使用真实敏感数据。选一项已有的可运行材料，保留输入、预期性质、实际输出和不能说明的事：

1. 用 [[AI/80-实践/07-PyTorch与核心公式CPU实验/00-CPU实验与使用说明|PyTorch 与核心公式 CPU 实验]] 检查张量、损失或梯度的小性质；它只验证该例的计算路径。
2. 用 [[计算机知识/80-实践/05-数据结构与算法/01-线性结构与摊还/README|线性结构与摊还练习]] 写出操作序列、势能/总成本或不变量；再改变一个边界输入。
3. 用 [[计算机知识/80-实践/06-计算机系统/03-缓存局部性benchmark/README|缓存局部性 benchmark 练习]] 固定输入规模、计时口径和机器条件，区分一个观察值与一般性能结论。

**检查点：** 练习记录必须能回答“输入是什么、预期性质是什么、实际看到什么、哪个条件一变就不能外推”。若没有保存这些信息，只能说读过或运行过，不能说已经验证机制。

- 需要模型选择、泛化、评估或分布偏移时，从 [[AI/10-机器学习与深度学习基础/11-经典机器学习基线与模型选择|经典机器学习基线与模型选择]]、[[AI/10-机器学习与深度学习基础/12-统计学习泛化与实验设计|统计学习泛化与实验设计]] 继续；
- 需要并发、持久化、ABI、网络或系统测量时，回到 [[计算机知识/30-计算机系统/00-计算机系统-MOC|计算机系统 MOC]] 选对应机制；
- 需要图、动态规划、随机/近似或证明边界时，回到 [[计算机知识/50-数据结构与算法/00-数据结构与算法-MOC|数据结构与算法 MOC]]，并用 [[计算机知识/50-数据结构与算法/23-正确性证明反例与复杂度边界|正确性、反例与复杂度边界]] 复查条件；
- 需要从技术问题讨论社会影响时，使用 [[社会科学/00-开始/00-社会科学-首页|社会科学首页]]；技术指标、经验事实和价值判断仍须分开说明。

具体应用可选择 [[计算机知识/62-图形学/00-图形学-MOC|图形学]]，用坐标变换、裁剪和插值把矩阵与几何接到像素；或选择 [[计算机知识/63-Web平台开发/00-Web平台开发-MOC|Web平台开发]]，用状态与请求代号把异步顺序接到交互结果。先手算一例、再检查实验层证据；软件模型和接口执行仍不能代替真实客户端与人的使用。

语言任务需要结构化输出时，用 [[AI/35-传统NLP/00-传统NLP-MOC|传统NLP]] 比较隐藏路径、标签区间和句法树；行动任务需要从读数纠偏时，用 [[AI/45-机器人与具身智能/00-机器人与具身智能-MOC|机器人闭环]] 比较状态估计、路线与反馈。二者都先固定对象和评分/仿真边界，再运行各自的小例。

## 从共同案例返回学科自己的问题

若当前障碍是“方向正确为何仍发散”，去 [[数学/40-微积分与优化/81-二维参数与三维目标图像#为什么这两个步长不同？|二次目标的步长解释]]，携带你选择的曲率和初值，读两个放大因子的条件；回来先补一次更新预测和失稳条件，再选择ODE或浮点主解释。二维参数和三维高度仍是同一函数，图本身不证明收敛。

若当前障碍是“已有提升定理是否给出了全部覆盖”，去 [[数学/36-拓扑学/10-覆盖空间与van-Kampen/02-同伦提升与映射提升判别#三个边界与反例|提升的三个边界]]，携带底空间、已有覆盖及基点，分开给定覆盖、一般映射提升和覆盖存在；回来收紧你的定理主张。再问普适覆盖或分类时，沿数学覆盖矩阵确认尚未定位的范围，不把有限实验作一般分类证明。
