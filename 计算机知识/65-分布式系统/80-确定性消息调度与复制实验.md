# 确定性消息调度与复制实验

本实验让一个初始 x=0 的三副本寄存器遇到消息丢失、重复、乱序、分区、crash-stop 与内存模型 reboot，随后核对“提交前不应用”“重复身份不增票”“旧任期多数不直接提交”等局部不变量。标准库即可运行；没有真实网络、磁盘、多进程、时钟或生产服务，不依赖随机种子。

共识模拟将一次请求处理和对应确认合在 `deliver()` 内；它可以丢弃整次投递，但没有单独的应答队列、时钟推进和响应丢失阶段。`replicate()` 发整个日志，选举由调用者显式触发并直接收票。`reboot()` 的“持久字段”是仍在内存的 term/vote/log，不能据此声称进行了刷盘或 crash recovery 实验。N=1 的多数集合代数已检查；RaftCore 的示例执行仅针对N=3或N=5，不提供单节点自动推进协议。

## 故障注入的完整 trace

`demo()` 先以A/B两票选A为term1主；A提议put7，阻断A→B和A→C，两个消息投递均丢失。恢复后向B发送同一个RPC，第一次保留在队列以制造重复；随后送C和传播commitIndex。

实际输出前八行：

```text
DROP 0->1
DROP 0->2
isolated leader commit=0, state=0
RPC 0->1 (1, True, 1); commit=1
RPC 0->1 (1, True, 1); commit=1
RPC 0->2 (1, True, 1); commit=1
RPC 0->1 (1, True, 1); commit=1
RPC 0->2 (1, True, 1); commit=1
```

节点0/1/2对应A/B/C。应答三元组是 `(term,success,matchedIndex)`；每行commit显示A的提交索引。分区时A虽有日志，state仍0。第一条B的请求携带发送时的leaderCommit=0，所以B只存日志、暂不应用；A收确认后提交并应用7。重复B消息不能把同一身份数成两份。后续发送更新的leaderCommit，B/C才按前缀应用7；测试断言最终三节点state=[7,7,7]。

## 先预测，再运行：完整解答

1. **把网络一直分区会发生什么？** A的log长度为1，commit与state仍0。消息队列变空不代表系统完成，缺少后续可达消息时没有活性保证。模型不自动循环重试。
2. **重复B的投票十次能选出五节点主吗？** A自票+B的集合只有2个身份，仍candidate；用消息计数1+10会错误选主。测试同时展示这两种算式，便于复现错误实现。
3. **term4主有term2条目三份，为什么不能直接确认？** 多数数量本身不排除更高旧日志任期的另一个候选人；[[计算机知识/65-分布式系统/03-共识领导者日志与多数派交集#为何旧任期条目在多数派上仍不能直接提交|五节点完整手算]] 给出可覆盖过程。局部代码以三节点断言term2条目多数时commit0，追加term4条目并多数后连同前缀commit2。
4. **H1 stale读到底通过哪种判定？** demo末尾输出 `stale read sequential= (1, 0) linearizable= None`。索引1是B读0，索引0是A写7；这个顺序合法但违背真实时间。把B改为A，同客户端顺序也不允许这个排列，顺序一致检查同样失败。
5. **2PC超时能让Aabort吗？** demo最后输出的两个世界，A都是 `('prepared','timeout')`；W0的B为prepared，W1的B为committed。若A在W1abort，两边最终决定分歧；须取得合法决定或保留等待。

扩展练习：添加4条不同日志命令、交错两任期选举，并用独立“已确认前缀不可改变”规格寻找最短违例。在完成完整消息应答队列、响应任期绑定、重启恢复与测试前，不应宣称这个扩展自动安全。对真实多进程、端口、进程kill或磁盘故障的实验需另设可恢复环境与实际授权，本组没有开展。

```python
"""Deterministic, finite teaching models; no sockets, clocks or disk durability.

RaftCore implements selected guards only. It is NOT a complete Raft protocol.
Histories contain completed single-key operations, with one outstanding call/client.
"""
from dataclasses import dataclass, field
from itertools import combinations, permutations


class ClockTrace:
    """Explicit local/send/receive events plus an independent causal DAG."""
    def __init__(self, size):
        if not isinstance(size, int) or size <= 0:
            raise ValueError("positive process count required")
        self.size = size
        self.scalar = [0] * size
        self.vector = [[0] * size for _ in range(size)]
        self.events = []
        self.last = {}
        self.edges = set()

    def event(self, process, receive=None):
        if not isinstance(process, int) or not 0 <= process < self.size:
            raise ValueError("invalid process")
        if receive is not None and not 0 <= receive < len(self.events):
            raise ValueError("receive must name an existing send event")
        index = len(self.events)
        if receive is not None:
            _, scalar, vector = self.events[receive]
            self.scalar[process] = max(self.scalar[process], scalar)
            self.vector[process] = [max(a, b) for a, b in
                                    zip(self.vector[process], vector)]
            self.edges.add((receive, index))
        self.scalar[process] += 1
        self.vector[process][process] += 1
        if process in self.last:
            self.edges.add((self.last[process], index))
        self.last[process] = index
        self.events.append((process, self.scalar[process],
                            tuple(self.vector[process])))
        return index

    def reachability(self):
        # Oracle uses graph traversal, not timestamp comparisons.
        result = set()
        for start in range(len(self.events)):
            todo = [b for a, b in self.edges if a == start]
            while todo:
                dest = todo.pop()
                if (start, dest) in result:
                    continue
                result.add((start, dest))
                todo.extend(b for a, b in self.edges if a == dest)
        return result


def vector_before(a, b):
    if len(a) != len(b) or not a:
        raise ValueError("nonempty equal dimensions required")
    return all(x <= y for x, y in zip(a, b)) and any(x < y for x, y in zip(a, b))


@dataclass(frozen=True)
class Operation:
    client: str
    kind: str
    value: int
    start: int
    end: int


def serial_witness(history, real_time=True):
    """Return a legal permutation, or None. Exponential; tiny histories only."""
    if len(history) > 8:
        raise ValueError("bounded checker accepts at most 8 operations")
    endpoints = [t for op in history for t in (op.start, op.end)]
    if len(set(endpoints)) != len(endpoints):
        raise ValueError("event endpoints must be distinct order numbers")
    for op in history:
        if (op.kind not in {"put", "get"} or type(op.value) is not int
                or type(op.start) is not int or type(op.end) is not int
                or op.start >= op.end):
            raise ValueError("invalid completed operation")
    for a, b in combinations(history, 2):
        if a.client == b.client and max(a.start, b.start) < min(a.end, b.end):
            raise ValueError("one outstanding call per client required")
    constraints = {(i, j) for i, a in enumerate(history)
                   for j, b in enumerate(history) if a.end < b.start
                   and (real_time or a.client == b.client)}
    for order in permutations(range(len(history))):
        position = {item: i for i, item in enumerate(order)}
        if any(position[a] >= position[b] for a, b in constraints):
            continue
        state = 0
        legal = True
        for index in order:
            op = history[index]
            if op.kind == "put":
                state = op.value
            elif op.value != state:
                legal = False
                break
        if legal:
            return order
    return None


def majority_sets(n):
    if not isinstance(n, int) or n <= 0:
        raise ValueError("positive member count required")
    return [frozenset(c) for c in combinations(range(n), n // 2 + 1)]


@dataclass(frozen=True)
class Entry:
    term: int
    value: int


@dataclass
class RaftCore:
    """Fixed membership, manually driven elections/replication, memory persistence.

    Missing: timers, RPC retries/backtracking, snapshots, membership changes,
    crash-safe writes, read protocol, client deduplication and full safety proof.
    """
    node: int
    members: int = 3
    term: int = 0
    voted_for: int | None = None
    log: list = field(default_factory=list)
    role: str = "follower"
    commit: int = 0
    applied: int = 0
    state: int = 0
    match: dict = field(default_factory=dict)
    votes: set = field(default_factory=set)

    def __post_init__(self):
        if self.members <= 0 or not 0 <= self.node < self.members:
            raise ValueError("invalid membership")

    def observe_term(self, term):
        if term > self.term:
            self.term, self.voted_for, self.role = term, None, "follower"
            self.votes.clear()

    def last(self):
        return (self.log[-1].term, len(self.log)) if self.log else (0, 0)

    def election(self):
        self.term += 1
        self.role = "candidate"
        self.voted_for = self.node
        self.votes = {self.node}
        self.match = {}
        return self.term, self.node, self.last()

    def vote(self, term, candidate, last):
        if not 0 <= candidate < self.members:
            raise ValueError("candidate outside membership")
        self.observe_term(term)
        grant = (term == self.term and last >= self.last()
                 and self.voted_for in (None, candidate))
        if grant:
            self.voted_for = candidate
        return self.term, grant

    def record_vote(self, peer, term, granted):
        if not 0 <= peer < self.members:
            raise ValueError("peer outside membership")
        self.observe_term(term)
        if self.role == "candidate" and term == self.term and granted:
            self.votes.add(peer)
            if len(self.votes) > self.members // 2:
                self.role = "leader"
                self.match = {self.node: len(self.log)}

    def propose(self, value):
        if self.role != "leader":
            raise ValueError("only leader can propose")
        self.log.append(Entry(self.term, value))
        self.match[self.node] = len(self.log)

    def append(self, term, prev_index, prev_term, entries, leader_commit):
        self.observe_term(term)
        if term != self.term:
            return self.term, False, 0
        self.role = "follower"
        if prev_index < 0 or prev_index > len(self.log):
            return self.term, False, 0
        actual = self.log[prev_index - 1].term if prev_index else 0
        if actual != prev_term:
            return self.term, False, 0
        entries = list(entries)
        if any(e.term > term or e.term <= 0 for e in entries):
            raise ValueError("entry term outside RPC term")
        for offset, entry in enumerate(entries):
            index = prev_index + offset
            if index < len(self.log) and self.log[index] != entry:
                if index < self.commit:
                    raise AssertionError("attempt to overwrite committed prefix")
                self.log = self.log[:index]
            if index == len(self.log):
                self.log.append(entry)
        matched = prev_index + len(entries)
        # Empty/short RPC must not commit an unrelated trailing suffix.
        self.commit = max(self.commit, min(leader_commit, matched))
        self.apply()
        return self.term, True, matched

    def acknowledge(self, peer, term, success, matched):
        if not 0 <= peer < self.members:
            raise ValueError("peer outside membership")
        self.observe_term(term)
        if self.role != "leader" or term != self.term or not success:
            return
        if not 0 <= matched <= len(self.log):
            raise ValueError("invalid matched index")
        self.match[peer] = max(self.match.get(peer, 0), matched)
        for index in range(len(self.log), self.commit, -1):
            copies = sum(m >= index for m in self.match.values())
            if copies > self.members // 2 and self.log[index - 1].term == self.term:
                self.commit = index
                break
        self.apply()

    def apply(self):
        while self.applied < self.commit:
            self.state = self.log[self.applied].value
            self.applied += 1

    def reboot(self):
        # Persistent *model* fields term/vote/log survive; no disk IO is tested.
        self.role, self.commit, self.applied, self.state = "follower", 0, 0, 0
        self.match, self.votes = {}, set()


class Scheduler:
    """Manual delivery, reordering, duplication, loss, partitions and crash-stop."""
    def __init__(self, nodes):
        self.nodes = nodes
        self.queue = []
        self.blocked = set()
        self.down = set()
        self.trace = []

    def send(self, source, dest, payload):
        self.queue.append((source, dest, payload))

    def deliver(self, index=0, duplicate=False):
        source, dest, payload = self.queue[index]
        if not duplicate:
            self.queue.pop(index)
        if source in self.down or dest in self.down or (source, dest) in self.blocked:
            self.trace.append(f"DROP {source}->{dest}")
            return
        result = self.nodes[dest].append(*payload)
        self.nodes[source].acknowledge(dest, *result)
        self.trace.append(f"RPC {source}->{dest} {result}; commit={self.nodes[source].commit}")

    def replicate(self, source, dest):
        leader = self.nodes[source]
        # Whole-log RPC from index 0: deliberate simplification, no nextIndex.
        self.send(source, dest, (leader.term, 0, 0, tuple(leader.log), leader.commit))


def elect(nodes, candidate, voters):
    request = nodes[candidate].election()
    for peer in voters:
        term, granted = nodes[peer].vote(*request)
        nodes[candidate].record_vote(peer, term, granted)


def two_pc_unknown(commit_reached_b):
    """A sees the same prepared/timeout trace in two different global worlds."""
    states = {"A": "prepared", "B": "prepared"}
    decision = None
    if commit_reached_b:
        decision, states["B"] = "commit", "committed"
    return {"A_observation": ("prepared", "timeout"),
            "coordinator_decision": decision, "states": states}


def demo():
    nodes = [RaftCore(i) for i in range(3)]
    elect(nodes, 0, [1])
    scheduler = Scheduler(nodes)
    scheduler.blocked.update({(0, 1), (0, 2)})
    nodes[0].propose(7)
    for peer in [1, 2]:
        scheduler.replicate(0, peer)
        scheduler.deliver()
```

```python
class ClockTests(unittest.TestCase):
    def test_vector_matches_dag_for_all_short_traces(self):
        # At step i: process 0/1 and either local or receive any older event.
        checked = 0
        def visit(plan):
            nonlocal checked
            trace = ClockTrace(2)
            for process, receive in plan:
                trace.event(process, receive)
            reachable = trace.reachability()
            for a in range(len(plan)):
                for b in range(len(plan)):
                    self.assertEqual((a, b) in reachable,
                                     vector_before(trace.events[a][2], trace.events[b][2]))
                    if (a, b) in reachable:
                        self.assertLess(trace.events[a][1], trace.events[b][1])
            checked += 1
            if len(plan) < 4:
                for process in range(2):
                    for receive in [None] + list(range(len(plan))):
                        visit(plan + [(process, receive)])
        visit([])
        self.assertEqual(checked, 443)

    def test_scalar_order_is_not_causality(self):
        t = ClockTrace(2)
        a = t.event(0)
        t.event(1)
        b = t.event(1)
        self.assertLess(t.events[a][1], t.events[b][1])
        self.assertNotIn((a, b), t.reachability())
        self.assertFalse(vector_before(t.events[a][2], t.events[b][2]))

    def test_invalid_clock_inputs(self):
        for n in [0, -1]:
            with self.assertRaises(ValueError):
                ClockTrace(n)
        with self.assertRaises(ValueError):
            vector_before((1,), (1, 2))


class HistoryTests(unittest.TestCase):

                     for i, (k, v) in enumerate(zip(kinds, values))]
                expected, state = True, 0
                for k, v in zip(kinds, values):
                    if k == 'put':
                        state = v
                    elif v != state:

                checked += 1

class RaftGuardTests(unittest.TestCase):
    def test_each_term_has_one_vote_and_fresh_log_check(self):
        voter = RaftCore(0, log=[Entry(2, 7)], term=2)
        self.assertEqual(voter.vote(3, 1, (1, 99)), (3, False))
        self.assertEqual(voter.vote(3, 1, (2, 1)), (3, True))
        self.assertEqual(voter.vote(3, 2, (3, 5)), (3, False))
        voter.reboot()
        self.assertEqual(voter.vote(3, 2, (3, 5)), (3, False))

    def test_stale_term_and_prefix_mismatch_rejected(self):
        follower = RaftCore(1, term=3, log=[Entry(2, 7)])
        self.assertEqual(follower.append(2, 0, 0, [Entry(2, 9)], 1), (3, False, 0))
        self.assertEqual(follower.append(3, 1, 1, [], 1), (3, False, 0))
        self.assertEqual(follower.log, [Entry(2, 7)])

    def test_old_term_majority_does_not_directly_commit(self):
        leader = RaftCore(0, term=4, role='leader', log=[Entry(2, 7)])
        leader.match = {0: 1}
        leader.acknowledge(1, 4, True, 1)
        self.assertEqual(leader.commit, 0)
        leader.propose(9)
        leader.acknowledge(1, 4, True, 2)
        self.assertEqual((leader.commit, leader.applied, leader.state), (2, 2, 9))

        f = RaftCore(1, term=3, log=[Entry(1, 7), Entry(2, 8)], commit=1)
        f.append(3, 1, 1, [Entry(3, 9)], 2)
        self.assertEqual(f.log, [Entry(1, 7), Entry(3, 9)])
        self.assertEqual(f.state, 9)
        with self.assertRaises(AssertionError):
            f.append(4, 0, 0, [Entry(4, 99)], 1)

    def test_short_heartbeat_does_not_commit_unmatched_suffix(self):
        f = RaftCore(1, term=3, log=[Entry(1, 7), Entry(2, 8)])
        f.append(3, 1, 1, [], 2)
        self.assertEqual((f.commit, f.state), (1, 7))

    def test_partition_then_heal_and_duplicate(self):
        nodes = [RaftCore(i) for i in range(3)]
        elect(nodes, 0, [1])
        s = Scheduler(nodes)
        nodes[0].propose(7)
        s.blocked = {(0, 1), (0, 2)}
        for peer in [1, 2]:
            s.replicate(0, peer)
            s.deliver()
        self.assertEqual((nodes[0].commit, nodes[0].state), (0, 0))
        s.blocked.clear()
        s.replicate(0, 1)
        s.deliver(duplicate=True)
        s.deliver()
        self.assertEqual((nodes[0].commit, nodes[0].state), (1, 7))
        for peer in [1, 2]:
            s.replicate(0, peer)
            s.deliver()
        self.assertEqual([n.state for n in nodes], [7, 7, 7])

    def test_all_single_entry_delivery_orders_and_losses(self):
        # Four queued RPCs: duplicated to each follower. 24 orders x 16 loss masks.
        checked = 0
        for order in permutations(range(4)):
            for losses in product([False, True], repeat=4):
                nodes = [RaftCore(i) for i in range(3)]
                elect(nodes, 0, [1])
                nodes[0].propose(7)
                targets = [1, 1, 2, 2]
                seen = set()
                for packet in order:
                    peer = targets[packet]
                    if not losses[packet]:
                        result = nodes[peer].append(1, 0, 0, [Entry(1, 7)], 0)
                        nodes[0].acknowledge(peer, *result)
                        seen.add(peer)
                    # Independent oracle: at least one distinct follower got entry.
                    self.assertEqual(nodes[0].commit == 1, bool(seen))
                    for node in nodes:
                        self.assertLessEqual(node.applied, node.commit)
                        self.assertLessEqual(node.commit, len(node.log))
                    self.assertEqual(nodes[0].state, 7 if seen else 0)
                checked += 1
        self.assertEqual(checked, 384)

    def test_crash_stop_and_memory_reboot(self):
        nodes = [RaftCore(i) for i in range(3)]
        elect(nodes, 0, [1])
        nodes[0].propose(7)
        s = Scheduler(nodes)

        s.deliver()

        s.replicate(0, 1)
        s.deliver()
        self.assertEqual(nodes[1].state, 7)
```
