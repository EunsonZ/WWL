# 控制论：从调节问题到闭环设计

一间保温盒温度太低，为什么“再加一点功率”有时管用，有时反复振荡？先问目标、可见信息、允许动作和时间，再问控制公式。这里从一个有限调节表开始，把同一个热对象走到连续反馈、数字采样、积分和失效条件。

零基础从 [[控制论/10-系统课程/01-调节目标信息与行动#先做一个无需微积分的诊断|三行调节诊断]] 进入，再依次读热模型和采样实现。已有 ODE、状态空间经验的读者可直达 [[控制论/10-系统课程/02-热模型从物理到连续反馈#先固定对象和每个端口|带单位模型]]，核对模型、初值与噪声端口后直接推闭环极点。两条路线使用相同主解释、相同例题。

按现有课号分五段读；停点是可以自行说明或复算的结果，重新进入时从该段首课继续，并用下面的原课程列表定位具体任务。需要回补或核完整建设范围，返回 [[控制论/00-开始/01-控制课程路线与覆盖边界|课程路线与覆盖边界]]。

- [[控制论/10-系统课程/03-采样保持积分调节与实现边界|数字反馈、积分与实现边界]]：保持积分、一拍时序、恒定扰动和传感偏置。
- [[控制论/10-系统课程/04-耦合热对象状态与端口能力|两状态与端口能力]]：从同一热对象扩到耦合节点，区分可控、可观、退化和长期目标。
- [[控制论/10-系统课程/05-状态反馈观测器与平衡目标|状态反馈与观测器设计]]：完整二维增益手算、四状态闭环与偏置边界。
- [[控制论/10-系统课程/06-多变量互联矩阵顺序与实现条件|多变量互联与实现]]：两路输入输出、矩阵顺序、可解代数环、归一化和采样极点。
- [[控制论/10-系统课程/07-有限时域最优控制Hamiltonian与终点条件|有限时域最优与终点条件]]：连续协态、全局最优性、可达界和限幅重求解。
- [[控制论/10-系统课程/08-约束预测控制从有限QP到终端保证|两步约束QP与终端保证]]：完整分数KKT证书、收紧名义界和滚动移位。
- [[控制论/10-系统课程/09-有界扰动不变管与模型误差|扰动管与辨识误差接口]]：真实状态/动作保证、持久扰动偏差、参数包围界和失效例。
- [[控制论/10-系统课程/10-闭环辨识从激励到控制条件|闭环辨识与控制条件]]：回归秩、测量噪声偏差、工具变量和错误模型的真实闭环反例。
- [[控制论/10-系统课程/11-直接MRAC有界跟踪与参数收敛|直接MRAC的证明与激励]]：标量匹配、有界/跟踪、PE参数收敛与无激励不变量。
- [[控制论/10-系统课程/12-扰动下的σ修正与数字实现边界|扰动修正与数字实现]]：解析漂移反例、固定泄漏残差界和采样保持的局部Schur条件。
- [[控制论/10-系统课程/13-混杂事件切换与驻留保证|混杂事件、切换与驻留]]：滞回flow/jump、guard/reset、不变带、Zeno反例与共同/多Lyapunov证书。
- [[控制论/10-系统课程/14-网络采样时延与允许更新序列|网络采样、时延与更新序列]]：新鲜成功间隔的全序列收缩、旧功率增广、时龄/乱序/时钟与有限反例。
- [[控制论/80-实践/05-混杂与网络/README|混杂与网络复算]]：热事件定位、切换/驻留、固定分数时延和允许更新序列。
- [[控制论/80-实践/04-辨识与MRAC/README|辨识与MRAC复算]]：条件矩、有限OLS/IV、连续解析核对和数字雅可比。
- [[控制论/80-实践/03-最优与约束热调节/README|最优与约束热调节复算]]：连续解析/RK4、精确QP、扰动序列与同式曲线。
- [[控制论/80-实践/02-耦合热状态/README|耦合热状态复算]]：二维/四维轻量CPU对照与撤提示任务。
- [[控制论/80-实践/01-热调节/README|热调节复算]]：标准库程序、解析对照、缩步检查、同方程曲线和撤提示任务。

入口段采用理想集中参数教学模型。它提供可复算的数学设计与 CPU 执行；真实设备参数、热损耗变化、时限和安全条件需要实测。这也只是独立控制课程的起步段，07–09增加连续最优、标量约束与鲁棒管，10–12继续闭环辨识和标量直接MRAC的条件/证明；更广多变量、非线性、鲁棒综合、完整最优与辨识、自适应推广沿课程路线继续建设；13–14落实指定混杂/切换与标量网络链，一般非线性混杂、多变量时变时延及实际事件/设备实现仍待完成。
