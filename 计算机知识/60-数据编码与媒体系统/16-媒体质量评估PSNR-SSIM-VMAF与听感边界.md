# 媒体质量评估：PSNR、SSIM、VMAF 与听感边界

## 本课目标

学完后，你能：

1. 先问清“与哪个参考、在什么观看/收听条件下、要做什么决策”，再选择指标；
2. 区分全参考（full-reference，FR）与无参考（no-reference，NR）评测；
3. 说明 PSNR、SSIM、VMAF 的输入、对齐前提、能回答的问题和不能回答的问题；
4. 用 ABX 与 MUSHRA 的直觉设计可解释的听感评测；
5. 把客观分数、主观样本、失败切片和不确定性写成一个可审计结论，而不是用一个数字代替质量。

> [!important] 质量不是文件属性
> “这个文件质量是 92”没有足够的信息。它至少缺少参考版本、显示/播放设备、观看距离或音量、内容类型、指标版本、对齐方法和聚合规则。质量是某个任务与条件下的证据，不是编码器吐出的永久标签。

## 1. 先决定你要回答哪一个问题

| 问题 | 合理证据 | 不应偷换成 |
| --- | --- | --- |
| 转码是否忠实于已知母版？ | FR 指标 + 对齐检查 + 抽样主观复核 | “看起来清楚” |
| 用户收到的流是否有明显劣化？ | 设备/网络切片、NR 伪影检测、回传与主观样本 | 与不存在的原始母版逐像素比较 |
| 两个编码方案谁更适合发布？ | FR/NR 指标、码率与卡顿、主观偏好、关键内容切片 | 平均 VMAF 更高就一定胜出 |
| 音频 A、B 是否听得出不同？ | 盲化 ABX | “频谱更接近” |
| 音频 A、B 哪个更好、差多少？ | 盲化听评（例如 MUSHRA）+ 任务问题 | ABX 的可分辨性 |

### FR 与 NR：缺失的参考决定了上限

**FR** 同时拥有“参考”与“待测”信号；它能估计后者偏离前者的方式。**NR** 只看待测信号，通常检测与训练分布相似的伪影、模糊、噪声、卡顿或响度问题。NR 很适合真实播放监测，却无法证明“完全保留了原片的细节”：它没有原片可比。

降码率、调色、裁切、升帧、插帧、去噪、锐化、缩放或改音轨会改变“相同内容”的含义。先在实验计划中声明参考是：创作母版、同一发行版的无损中间件、还是某一已发布交付物；不要把不同调色/不同剪辑版本硬当失真。

## 2. 全参考评测的第一道门：可比且对齐

在计算任何 FR 分数前，写下并检查下列契约：

| 维度 | 必须一致或显式转换 | 典型假阳性/假阴性 |
| --- | --- | --- |
| 内容与时间 | 同一剪辑、相同起点、帧率与帧对应；记录丢帧/重复帧 | 整体错一帧会让每一帧都“很差” |
| 几何 | 宽高、像素纵横比、裁切、旋转、letterbox/pillarbox 规则 | 把黑边或一次缩放误当编码损失 |
| 像素解释 | 像素格式、位深、色彩矩阵、range、transfer、primaries、HDR/SDR 映射 | 同一画面因范围或色调映射不同而被惩罚 |
| 音频时基 | 采样率、声道布局、响度/增益处理、起点与延迟 | 静音填充或时钟漂移淹没真正的编码差异 |
| 评测实现 | 指标/模型版本、预处理、子采样、池化方法 | 两次“同名 VMAF”不可直接比较 |

对齐不是为了把分数“调高”。若发布目标本来就包含缩放或 HDR→SDR，评测管线可以做**有记录的共同规范化**；报告必须同时保留原交付差异和规范化规则。不能可靠对齐时，FR 分数应标为无效，而不是继续排行。

## 3. PSNR：均方误差的对数量尺

对 $N$ 个已对齐样本，均方误差为：

$$
\operatorname{MSE}=\frac{1}{N}\sum_{i=1}^{N}(x_i-y_i)^2.
$$

若样本最大可表示值为 $MAX$，则：

$$
\operatorname{PSNR}=10\log_{10}\frac{MAX^2}{\operatorname{MSE}}\ \mathrm{dB}.
$$

MSE 为零时 PSNR 是无穷大；这是“这些数值完全相同”，不是“人类体验无穷好”。PSNR 是全参考、逐样本误差的单调变换；**同一位深、同一平面、同一对齐和同一聚合方式内，较高通常表示数值误差更小**。

它不理解物体、运动、纹理是否重要，也不保证人眼/人耳觉得更好。一个轻微平移、可察觉的结构损坏和不太可察觉的噪声，可能得到反直觉排序。不要跨不同 bit depth、色彩分量权重、HDR 处理或剪辑直接比较 dB；也不要把 luma PSNR 偷换成“整段视听质量”。

### 同一两像素例：先池化MSE，还是先取dB？

参考是当次真实的两像素图，数值范围 $[0,1]$，左右像素已对齐，取 $MAX=1$；恢复器只得到两像素平均值 $X=1/2$。完整有限表、允许的信息和平方最优性见 [[数学/30-概率与统计/11-条件期望与最小均方估计#两像素逆问题：均值最优，为什么仍不是真图？|条件均值主解释]]。带回两层平均：每幅图先平均两个像素的平方误差，再平均真图与独立恢复随机数。

| 恢复器 | 对当次参考的每图 MSE | 总体池化 MSE | 由总体池化 MSE 算 PSNR |
| --- | --- | ---: | ---: |
| 条件均值 $(1/2,1/2)$ | 两种真图都为 $1/4$ | $1/4$ | $10\log_{10}(1/(1/4))\approx6.0206$ dB |
| 独立准确后验抽样 | 以 $1/2$ 概率为0，$1/2$ 为1 | $1/2$ | $10\log_{10}(1/(1/2))\approx3.0103$ dB |

这里的“总体池化”按精确配对概率加权；各图都有两个像素，所以按图加权与按像素加权一致。一般不同像素数的媒体应声明权重。有限批 $B$ 幅图若有 $k$ 次错配，抽样器池化 MSE 是 $k/B$，PSNR 是 $10\log_{10}(B/k)$（$k>0$），不保证该批恰好一半匹配。

**先取 dB 再平均是另一种报告。** 抽样器完全匹配时 MSE=0、PSNR=$+\infty$；错配时 MSE=1、PSNR=0 dB。因此其理论逐图 PSNR 的扩展实数期望为 $+\infty$，不等于3.0103 dB。有限批只要含一次匹配，直接平均含 $+\infty$ 的 dB 也为 $+\infty$；全错批则为0 dB。均值恢复器每图都是6.0206 dB，所以两种聚合恰在它上面相同。对数的非线性已足以使两种报告不同，不要把它们都称为“平均PSNR”。

本有限实验的**零误差政策**：数值语义为 $+\infty$；JSON 用字符串 `"+infinity"` 表示，CSV 用 `+infinity`，不写非法 JSON Infinity，也不静默剔除零误差例。实际平台若加 $\varepsilon$、截顶或排除零误差，必须另列规则、阈值、排除数与原因，那已经改变报告对象。[[计算机知识/80-实践/07-媒体编码与FFmpeg/05-条件均值与分布恢复/README#从一张有限表重建结果与图|精确枚举及灰度图]] 可直接重建这组数字；没有运行媒体编码或真实观众实验。

此例保留了两种黑白候选的输出分布，却增加逐参考 MSE；均值图则相反。去 [[AI/50-扩散模型/03-Score去噪FlowMatching与CFG的联系#局部条件均值为什么没有把全部生成变成灰图|扩散页]] 看“拟合局部均值”如何成为采样器的一部分，再从那里返回本段核对比较的是参考误差、候选分布还是完整过程。

[Blau 与 Michaeli 的 perception–distortion 论文](https://arxiv.org/html/1711.06077v4) 第III节把平均逐参考失真与输出分布距离分为两种目标，III-A讨论后验均值；本页的两像素例是独立有限构造。论文的分布距离式“感知”定义不等于所有人的体验。本例的支持集差异没有证明更锐利就更受喜爱，也不推出任意两个模型之间都有相反排名。作品解释与审美价值还需作品细节、语境和可争论的理由，见 [#190 的美学与作品评价范围](https://github.com/EunsonZ/WWL/issues/190)；该课程的拟建作品主文当前不能当成已交付阅读位置。PSNR、输出分布匹配和艺术评价分别回答不同问题。

## 4. SSIM：局部亮度、对比度与结构的比较

SSIM 仍是 FR 指标，但不只逐像素相减。对局部窗口的均值 $\mu$、标准差 $\sigma$ 与协方差 $\sigma_{xy}$，常见形式为：

$$
\operatorname{SSIM}(x,y)=
\frac{(2\mu_x\mu_y+C_1)(2\sigma_{xy}+C_2)}
{(\mu_x^2+\mu_y^2+C_1)(\sigma_x^2+\sigma_y^2+C_2)}.
$$

它的直觉是分别看局部亮度、对比度和结构相关性，再汇总窗口/帧/片段。因此 SSIM 有时比 PSNR 更贴近某些结构性失真；它仍依赖对齐、窗口、色彩平面、尺度和池化选择，不能证明感知等价，也不自动覆盖闪烁、卡顿、音画同步或审美偏好。多尺度 SSIM（MS-SSIM）改变了观察尺度，不会解除这些前提。

## 5. VMAF：面向特定观看条件的全参考感知模型

Netflix 的 `libvmaf` 文档把 VMAF 定义为从**失真视频与其全质量参考视频**抽取质量特征、再以非线性回归融合的感知质量评估方法；其命令行工具也要求 `reference` 与 `distorted` 两路输入。[项目文档](https://github.com/Netflix/vmaf/blob/master/libvmaf/tools/README.md)（核验：2026-09-03）

所以 VMAF 是 FR，不是“只给一个 MP4 就能测”的万能分数。选择模型时还必须匹配显示分辨率、观看距离、动态范围与内容/失真条件。例如项目当前 v1 文档明确区分标准 1080p、手机与不同观看距离的 4K 模型，并有不同分数范围；模型版本变化时不能把旧阈值直接移植。[VMAF 模型说明](https://github.com/Netflix/vmaf/blob/master/resource/doc/models_v1.md)（核验：2026-09-03）

> [!warning] VMAF 不是发布批准章
> 它可能看不到你的业务禁区：字幕缺字、片尾音画不同步、某类人脸被过度平滑、暗场 banding、首帧黑屏、码率尖峰导致卡顿，或特定设备上的 HDR 映射问题。应保留每帧/每段分数、最差片段和按内容/设备的切片；均值能掩盖短而严重的故障。

### NR 指标如何进入同一张报告

NR 指标可补充“原始参考不可得的线上分发”场景，例如检测 banding、模糊、噪声、冻结、黑帧或播放卡顿。它的输出应写成“在此模型/阈值下观察到某类伪影风险”，并以抽样人工复核校准误报与漏报。Netflix 的 CAMBI 文档甚至区分默认的无参考 banding 分数与可选的 full-reference 模式，说明“同一算法名”也可能有不同证据边界。[CAMBI 文档](https://github.com/Netflix/vmaf/blob/master/resource/doc/cambi.md)（核验：2026-09-03）

## 6. 音频：波形接近、能否听出与主观偏好是三件事

音频的逐样本 MSE/PSNR、SNR 或频谱距离同样需要精确的采样率、声道、增益和时间对齐。它们适合诊断编码误差或回归，不等于音乐、语音清晰度、空间感和疲劳感。频谱如何由波形得到、窗口带来的取舍见 [[数学/70-信号处理与多模态数学/02-采样定理波形STFT与Mel频谱|采样定理、波形、STFT 与 Mel 频谱]]。

到 [[AI/40-语音与音频模型/02-语音生成音频Token与实时交互#两类主要接口|语音生成的波形/特征接口]] 时，先选择被比较对象：同一参考波形的采样误差、同一预处理下的声学特征误差，还是候选语音分布/可懂度/自然度。波形比较须锁定采样率、声道、增益与时延；特征比较还须锁定 STFT/Mel 等变换和权重。两像素例只提示“逐参考误差与候选分布是不同目标”，它的1/4、1/2与dB不构成音质实测。回到本节时带回具体参考、特征定义和听评问题；不能从图像支持集或训练MSE代推出听者偏好。

| 方法 | 参与者实际做什么 | 能回答 | 不能回答 |
| --- | --- | --- | --- |
| 客观 FR/NR 音频指标 | 工具比较波形/特征，或只观察输出 | 回归、候选筛查、疑似伪影定位 | 人是否偏好、是否适合任务 |
| **ABX** | 盲化地听 A、B，再判断未知 X 属于哪一个 | 在该材料、设备、听者与重复次数下能否可靠区分 A/B | 哪个更好、差异有多大 |
| **MUSHRA** | 多刺激、隐藏参考与锚点，听者在连续量表评分 | 中等质量区间中候选的相对主观质量 | 对未代表内容/人群的一般保证 |

MUSHRA 是 *Multi Stimulus test with Hidden Reference and Anchor*。ITU-R BS.1534-3 将它规定为中等音频质量的主观评估方法；其目的、材料、听音条件、受试者和统计报告都是方法的一部分，不是只在网页上放一个 0–100 滑条。[ITU-R BS.1534-3](https://www.itu.int/rec/R-REC-BS.1534-3-201510-I/en)（核验：2026-09-03）

ABX 若能显著地区分，只说明可分辨；听者仍可能偏好 A、偏好 B 或认为差异不重要。反过来，少量、未训练听者没有区分出，也不是“绝对透明”的证明。盲化、随机顺序、音量匹配、熟悉试次、预先定义的排除规则和代表性片段，往往比把样本数从 3 增加到 30 更先决定结论是否可信。

## 7. 不用单指标替代主观质量：最小证据包

一次可发布的比较至少记录：

1. **对象与参考**：媒体版本、哈希、时长、颜色/音频解释、对齐/规范化规则；
2. **客观证据**：PSNR/SSIM/VMAF 或 NR 指标的版本、逐帧/逐段分布、均值以外的分位数与最差片段；
3. **体验证据**：设备、观看距离/耳机或音箱、音量、网络条件、盲评设计与原始匿名评分；
4. **关键切片**：暗场、粒子、字幕、快速运动、动画、音乐瞬态、语音、弱网和目标设备；
5. **决策与不确定性**：预先定义的业务禁区、失败样本、样本来源和区间/重采样方法。

同一片段上的两个候选应使用配对差异和相应的置信区间，而非把两个均值独立相减；统计区间不覆盖内容选择偏差、听者群体偏差或指标失配。详见 [[数学/30-概率与统计/05-统计估计置信度与模型评测|统计估计、置信度与模型评测]] 与 [[AI/20-LLM/70-工程应用与工具链/04-评测回归与可观测性|评测、回归与可观测性]]。

## 可观察练习：把“更高分”变成可检验主张

某团队说：“候选 B 的 VMAF 平均值比 A 高 1.2，所以 B 质量更好。”请先不计算任何文件，写一张评测卡：

1. 参考版本、帧对应、像素格式/色彩/HDR 规范化和 VMAF 模型版本；
2. 至少四个内容切片（例如暗场、快速运动、字幕、纹理）及每个切片的最差片段；
3. 哪些问题用 NR/播放遥测补充，为什么不能用 VMAF 证明；
4. 一个视频盲评问题和一个音频 ABX 或 MUSHRA 问题，明确各自的结论边界；
5. 一条发布禁区，例如“任意目标语言字幕缺字”或“目标网络下首播卡顿超过阈值”，并说明它为何不能被平均分抵消。

### 成功标准

- [ ] 我没有在未对齐、不同颜色解释或不同剪辑上报告 FR 排名。
- [ ] 我能正确说出 PSNR/SSIM/VMAF 都需要参考，VMAF 还依赖所选模型与观看条件。
- [ ] 我能举出一个高平均分仍应拒绝的短时/切片失败。
- [ ] 我能区分 ABX 的“可分辨”与 MUSHRA 的“主观质量评分”。
- [ ] 我的结论同时说明了测到的事实、未测到的体验，以及样本边界。
