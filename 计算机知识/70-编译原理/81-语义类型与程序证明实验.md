# 语义、类型与程序证明实验

本实验回答三个可复算问题：函数实参何时求值；良类型项执行一步后有没有改型或卡住；循环头不变量与终止度量在实际轨迹中是否对应。一般证明在 [[计算机知识/70-编译原理/14-类型安全替换引理与进展保持|类型安全]] 和 [[计算机知识/70-编译原理/15-Hoare逻辑循环不变量与终止|Hoare逻辑]]；枚举、断言、超时都不替代它们。

在此目录执行，Python 3.10以上，仅标准库：

```bash
python3 -B semantics_lab.py
python3 -B -m unittest -v test_semantics_lab.py
```

实验直接用元组AST，没有词法或语法解析。`('bool', True)` 对应true，`('var','x')` 对应x，`('lam','x','Bool',body)` 对应λx:Bool.body，`('app',f,a)` 对应f a，`('if',c,a,b)` 对应条件式；类型箭头为`('arrow',S,T)`。开项用于替换测试，但安全枚举只检查空环境良类型项。`type_of` 缺省拒绝fix，只有`allow_fix=True`明确进入递归扩展；运行器可运行未类型化项，用于展示卡住和保持不能反向使用。

| 入口 | 输入/输出与边界 |
| --- | --- |
| subst(t,x,s) | 避捕获替换；新名避开自由与绑定的全部名字，内层同名遮蔽处停止 |
| type_of(t,env) | Bool/箭头类型，或TypeError；畸形AST与非法注解ValueError |
| step(t,strategy) | 下一个项，或None；None可能是值也可能卡住 |
| run(t,strategy,fuel) | 状态value/stuck/fuel与包含初态的完整轨迹；fuel不表示已证发散 |
| terms(size,scope) | 精确节点数有限枚举，注解仅Bool与Bool→Bool，无fix |
| imp_step(c,state) | 下一命令与复制状态，skip给None；未初始化/非整数/非法语法拒绝 |
| countdown(N) | N≥0，返回最终状态、循环头和语义小步数；输入状态不被原位修改 |

## 1. 按手算核对轨迹

把not构造为`('lam','x',B,('if',('var','x'),FALSE,TRUE))`，应用false。预期三项依次为原调用、`if false then false else true`、true。`test_hand_trace`把这条预期轨迹写死，并未用解释器生成期待值。

令δ=`('fix',('lam','z',B,('var','z')))`，调用`(λx:Bool.true) δ`。CBV每步保留相同调用，在4步预算后返回fuel，轨迹有5项；数学发散证据是δ→δ的规则自环。CBN一步返回true，轨迹有2项。`test_strategy_trace`还在无递归核心用a=`(λy:Bool.y) false`核对CBV两步与CBN一步。

| 检查对象 | 独立预期 | 实验意义 |
| --- | --- | --- |
| `(λy:Bool.x)[x:=y]` | `λy_:Bool.y`，FV={y} | 避捕获不能仅靠类型正确性判断 |
| Γ={x:Bool}中的x | 有类型但运行卡住 | 进展需闭项 |
| `(λx:Bool.true)(λy:Bool.y)` | 源类型拒绝，一步为true | 保持不能反向推出源有类型 |
| `fix(λz:Bool.z)` | 扩展中Bool且一步自环 | 安全不推出终止 |

## 2. 有限搜索与循环独立oracle

枚举节点数1至5、参数注解集合{Bool,Bool→Bool}、无fix、按词法作用域生成变量。共有616个闭语法项，其中272个可在空环境类型化；CBV完整轨迹共有39次转换。每个良类型项在50步预算内返回值，并且每个轨迹项都保留初始类型。有限计数由测试打印；它覆盖此有限语法全集，未覆盖节点>5、其他注解或递归，更不能证明一般定理。

命令式实验使用数学整数、加减与`>`，对应第15课。N=3返回`{'x':0,'s':3}`，循环头依次(0,3)、(1,2)、(2,1)、(3,0)，实际转换16步=5×3+1。测试对N=0至30，以公式第k头(s,x)=(k,N−k)作为独立oracle；检查最终s=N、每个头s+x=N、x非负。该oracle不调用解释器求预期。

反例测试故意省略`s:=s+1`，用N=1证不变量不保持；`while 1>0 do skip`运行12步仍非skip，对应规则的循环自环结构，不能借12步观察单独证明不终止。未初始化变量、bool伪装整数、除法语法、负N、非法策略与畸形项均有拒绝测试。

## 3. 修改练习与答案

1. 暂时把`subst`遇到λ的分支改成直接递归，会有哪些测试暴露问题？答：捕获、遮蔽、新鲜名字三类；只有闭程序轨迹测试可能看不见开项捕获，所以必须保留绑定测试。
2. 若`step`在CBV遇到λ就直接代实参，哪项揭示策略错误？答：固定策略轨迹与fix差异。只检查最终true不足以发现有限例子的求值顺序变化。
3. 把计数程序中`x-1`改成`x-2`。答：N=1最终x=−1、s=1，头部非负失效；N=2最终s=1≠2。不应删除失败测试或把规格改成只比较“会停止”。

```python
"""Named Bool STLC + optional fix; separate integer Imp. Python 3.10+.
Tuples are ASTs, never source strings. No general proof is claimed by enumeration.
"""
from functools import lru_cache

B = 'Bool'
TRUE, FALSE = ('bool', True), ('bool', False)


def valid_type(t):
    if t == B:
        return
    if isinstance(t, tuple) and len(t) == 3 and t[0] == 'arrow':
        valid_type(t[1]); valid_type(t[2]); return
    raise ValueError('invalid type')


def valid_term(t):
    if not isinstance(t, tuple) or not t:
        raise ValueError('AST must be a nonempty tuple')
    tag = t[0]
    if not isinstance(tag, str):
        raise ValueError('term tag must be a string')
    if tag == 'bool' and len(t) == 2 and type(t[1]) is bool:
        return
    if tag == 'var' and len(t) == 2 and isinstance(t[1], str) and t[1]:
        return
    if tag == 'lam' and len(t) == 4 and isinstance(t[1], str) and t[1]:
        valid_type(t[2]); valid_term(t[3]); return
    arity = {'app': 3, 'if': 4, 'fix': 2}.get(tag)
    if arity == len(t):
        for child in t[1:]:
            valid_term(child)
        return
    raise ValueError('malformed term')


def fv(t):
    valid_term(t)
    if t[0] == 'var':
        return {t[1]}
    if t[0] == 'bool':
        return set()
    if t[0] == 'lam':
        return fv(t[3]) - {t[1]}
    return set().union(*(fv(c) for c in t[1:]))


def names(t):
    if t[0] == 'lam':
        return {t[1]} | names(t[3])
    if t[0] == 'var':
        return {t[1]}
    if t[0] == 'bool':
        return set()
    return set().union(*(names(c) for c in t[1:]))


def subst(t, x, s):
    """Capture avoiding; fresh name absent from all names, including shadowed ones."""
    valid_term(t); valid_term(s)
    if not isinstance(x, str) or not x:
        raise ValueError('invalid substitution name')
    if t[0] == 'var':
        return s if t[1] == x else t
    if t[0] == 'bool':
        return t
    if t[0] == 'lam':
        y, ty, body = t[1:]
        if y == x or x not in fv(body):
            return t
        if y in fv(s):
            used = names(body) | names(s) | {x, y}
            z = y + '_'
            while z in used:
                z += '_'
            body = subst(body, y, ('var', z))  # stops at inner binders named y
            y = z
        return ('lam', y, ty, subst(body, x, s))
    return (t[0], *(subst(c, x, s) for c in t[1:]))


def type_of(t, env=None, *, allow_fix=False):
    valid_term(t)
    env = {} if env is None else dict(env)
    for ty in env.values():
        valid_type(ty)
    tag = t[0]
    if tag == 'bool':
        return B
    if tag == 'var':
        if t[1] not in env:
            raise TypeError('unbound variable: ' + t[1])
        return env[t[1]]
    if tag == 'lam':
        env[t[1]] = t[2]
        return ('arrow', t[2], type_of(t[3], env, allow_fix=allow_fix))
    ts = [type_of(c, env, allow_fix=allow_fix) for c in t[1:]]
    if tag == 'app' and isinstance(ts[0], tuple) and ts[0][0] == 'arrow' and ts[0][1] == ts[1]:
        return ts[0][2]
    if tag == 'if' and ts[0] == B and ts[1] == ts[2]:
        return ts[1]
    if tag == 'fix' and allow_fix and isinstance(ts[0], tuple) and ts[0][1] == ts[0][2]:
        return ts[0][1]
    raise TypeError('typing rule does not apply: ' + tag)


def value(t):
    valid_term(t)
    return t[0] in {'bool', 'lam'}


def step(t, strategy='cbv'):
    """Return next AST or None (value OR stuck); caller distinguishes them."""
    valid_term(t)
    if strategy not in {'cbv', 'cbn'}:
        raise ValueError('strategy must be cbv or cbn')
    tag = t[0]
    if tag == 'app':
        f, a = t[1:]
        if not value(f):
            r = step(f, strategy)
            return None if r is None else ('app', r, a)
        if strategy == 'cbv' and not value(a):
            r = step(a, strategy)
            return None if r is None else ('app', f, r)
        if f[0] == 'lam':
            return subst(f[3], f[1], a)
    if tag == 'if':
        c, a, b = t[1:]
        if c[0] == 'bool':
            return a if c[1] else b
        r = step(c, strategy)
        return None if r is None else ('if', r, a, b)
    if tag == 'fix':
        f = t[1]
        if f[0] == 'lam':
            return subst(f[3], f[1], t)
        r = step(f, strategy)
        return None if r is None else ('fix', r)
    return None


def run(t, strategy='cbv', fuel=100):
    if type(fuel) is not int or fuel < 0:
        raise ValueError('fuel must be a nonnegative integer')
    valid_term(t)
    if strategy not in {'cbv', 'cbn'}:
        raise ValueError('invalid strategy')
    trace = [t]
    for _ in range(fuel):
        if value(t):
            return 'value', trace
        r = step(t, strategy)
        if r is None:
            return 'stuck', trace
        t = r; trace.append(t)
    if value(t):
        return 'value', trace
    if step(t, strategy) is None:
        return 'stuck', trace
    return 'fuel', trace


@lru_cache(None)
def terms(size, scope=()):
    """Exact node size, binder annotations restricted to Bool / Bool->Bool, no fix."""
    if type(size) is not int or size < 1:
        raise ValueError('positive node size required')
    if size == 1:
        return (TRUE, FALSE, *(('var', x) for x in scope))
    out = []
    x = 'x' + str(len(scope))
    for ty in (B, ('arrow', B, B)):
        out += [('lam', x, ty, b) for b in terms(size-1, scope+(x,))]
    for i in range(1, size-1):
        out += [('app', f, a) for f in terms(i, scope) for a in terms(size-1-i, scope)]
    for i in range(1, size-2):
        for j in range(1, size-1-i):
            k = size-1-i-j
            out += [('if', c, a, b) for c in terms(i, scope) for a in terms(j, scope) for b in terms(k, scope)]
    return tuple(out)


# Imp uses unbounded signed integers, total +/-, > guard; no lambda terms.
def aeval(a, state):
    if type(a) is int:
        return a
    if isinstance(a, str) and a:
        if a not in state:
            raise ValueError('uninitialized variable: ' + a)
        if type(state[a]) is not int:
            raise ValueError('state contains non-integer')
        return state[a]
    if isinstance(a, tuple) and len(a) == 3 and a[0] in {'+', '-'}:
        x, y = aeval(a[1], state), aeval(a[2], state)
        return x+y if a[0] == '+' else x-y
    raise ValueError('invalid arithmetic expression')


def guard(b, state):
    if isinstance(b, tuple) and len(b) == 3 and b[0] == '>':
        return aeval(b[1], state) > aeval(b[2], state)
    raise ValueError('invalid guard')


def valid_command(c):
    if c == ('skip',):
        return
    if not isinstance(c, tuple) or len(c) != 3:
        raise ValueError('malformed command')
    if c[0] == 'set' and isinstance(c[1], str) and c[1]:
        # Validate expression syntax separately from state-dependent initialization.
        def check(a):
            if type(a) is int or isinstance(a, str) and a:
                return
            if isinstance(a, tuple) and len(a) == 3 and a[0] in {'+', '-'}:
                check(a[1]); check(a[2]); return
            raise ValueError('invalid arithmetic expression')
        check(c[2]); return
    if c[0] == 'seq':
        valid_command(c[1]); valid_command(c[2]); return
    if c[0] == 'while' and isinstance(c[1], tuple) and len(c[1]) == 3 and c[1][0] == '>':
        valid_command(('set', '_check', c[1][1])); valid_command(('set', '_check', c[1][2]))
        valid_command(c[2]); return
    raise ValueError('invalid command')


def imp_step(c, state):
    valid_command(c)
    if any(not isinstance(k, str) or not k or type(v) is not int for k, v in state.items()):
        raise ValueError('state must map names to integers')
    state = dict(state)
    if c[0] == 'skip':
        return None
    if c[0] == 'set':
        state[c[1]] = aeval(c[2], state)
        return ('skip',), state
    if c[0] == 'seq':
        if c[1] == ('skip',):
            return c[2], state
        first, state = imp_step(c[1], state)
        return ('seq', first, c[2]), state
    return (('seq', c[2], c) if guard(c[1], state) else ('skip',)), state


def countdown(n):
    if type(n) is not int or n < 0:
        raise ValueError('countdown input must be nonnegative integer')
    c = ('while', ('>', 'x', 0), ('seq', ('set', 's', ('+', 's', 1)), ('set', 'x', ('-', 'x', 1))))
    state = {'x': n, 's': 0}
    heads = [dict(state)]
    steps = 0
    while c != ('skip',):
        c, state = imp_step(c, state); steps += 1
        if c[0] == 'while':
            heads.append(dict(state))
    return state, heads, steps


if __name__ == '__main__':
    ident = ('lam', 'x', B, ('var', 'x'))
    print('identity:', run(('app', ident, FALSE)))
    loop = ('fix', ident)
    for strategy in ('cbv', 'cbn'):
        print(strategy, run(('app', ('lam', 'x', B, TRUE), loop), strategy, 4))
    print('countdown:', countdown(3))
```

```python
import unittest
from semantics_lab import B, TRUE, FALSE, fv, subst, type_of, step, run, terms, countdown, imp_step, aeval

V = lambda x: ('var', x)
L = lambda x, body: ('lam', x, B, body)
A = lambda f, a: ('app', f, a)


class SemanticsTests(unittest.TestCase):
    def test_hand_trace(self):
        t = A(L('x', ('if', V('x'), FALSE, TRUE)), FALSE)
        self.assertEqual(run(t), ('value', [t, ('if', FALSE, FALSE, TRUE), TRUE]))

    def test_strategy_trace(self):
        arg = A(L('y', V('y')), FALSE)
        t = A(L('x', TRUE), arg)
        self.assertEqual(run(t, 'cbv')[1], [t, A(L('x', TRUE), FALSE), TRUE])
        self.assertEqual(run(t, 'cbn')[1], [t, TRUE])

    def test_capture(self):
        r = subst(L('y', V('x')), 'x', V('y'))
        self.assertEqual(r, L('y_', V('y')))
        self.assertEqual(fv(r), {'y'})

    def test_shadow_and_fresh(self):
        t = L('y', A(V('x'), L('y_', V('y'))))
        self.assertEqual(subst(t, 'x', V('y')), L('y__', A(V('y'), L('y_', V('y__')))))
        self.assertEqual(subst(L('x', V('x')), 'x', TRUE), L('x', V('x')))

    def test_substitution_typing_open(self):
        t = L('y', V('x'))
        self.assertEqual(type_of(t, {'x': B}), ('arrow', B, B))
        self.assertEqual(type_of(subst(t, 'x', V('y')), {'y': B}), ('arrow', B, B))

    def test_closed_requirement(self):
        self.assertEqual(type_of(V('x'), {'x': B}), B)
        self.assertEqual(run(V('x'))[0], 'stuck')

    def test_reverse_preservation_false(self):
        t = A(L('x', TRUE), L('y', V('y')))
        with self.assertRaises(TypeError):
            type_of(t)
        self.assertEqual(step(t), TRUE)
        self.assertEqual(type_of(TRUE), B)

    def test_fix_divergence(self):
        loop = ('fix', L('x', V('x')))
        self.assertEqual(type_of(loop, allow_fix=True), B)
        with self.assertRaises(TypeError):
            type_of(loop)
        self.assertEqual(step(loop), loop)
        t = A(L('x', TRUE), loop)
        self.assertEqual(run(t, 'cbv', 8)[0], 'fuel')
        self.assertEqual(run(t, 'cbn', 1), ('value', [t, TRUE]))

    def test_stuck_and_function_value(self):
        self.assertEqual(run(A(TRUE, FALSE))[0], 'stuck')
        self.assertEqual(run(L('x', A(TRUE, FALSE)))[0], 'value')
        with self.assertRaises(TypeError):
            type_of(L('x', A(TRUE, FALSE)))

    def test_invalid_inputs(self):
        for t in [(), ('bool', 1), ('var', ''), ('app', TRUE), ('lam', 'x', 'Int', TRUE), ([],)]:
            with self.assertRaises(ValueError):
                run(t)
        for fuel in [-1, True, 0.5]:
            with self.assertRaises(ValueError):
                run(TRUE, fuel=fuel)
        with self.assertRaises(ValueError):
            run(TRUE, 'lazy')
        with self.assertRaises(TypeError):
            type_of(('if', TRUE, TRUE, L('x', V('x'))))

    def test_finite_safety_search(self):
        total = good = checked_steps = 0
        for n in range(1, 6):
            for t in terms(n):
                total += 1
                try:
                    ty = type_of(t)
                except TypeError:
                    continue
                good += 1
                status, trace = run(t, fuel=50)
                self.assertEqual(status, 'value')
                for r in trace:
                    self.assertEqual(type_of(r), ty)
                checked_steps += len(trace)-1
        self.assertGreater(good, 100)
        print(f'FINITE nodes<=5 total={total} well_typed={good} transitions={checked_steps}')

    def test_countdown_oracle(self):
        for n in range(31):
            state, heads, steps = countdown(n)
            self.assertEqual(steps, 5*n+1)
            self.assertEqual(state, {'x': 0, 's': n})
            # Independent arithmetic oracle for every loop head, not evaluator vs itself.
            self.assertEqual(heads, [{'x': n-k, 's': k} for k in range(n+1)])
            self.assertTrue(all(h['s'] + h['x'] == n for h in heads))

    def test_imp_assignment_and_bad_state(self):
        state = {'x': 2}
        self.assertEqual(imp_step(('set', 'x', ('+', 'x', 1)), state), (('skip',), {'x': 3}))
        self.assertEqual(state, {'x': 2})
        for c, s in [(('set', 'x', 'z'), {}), (('set', 'x', 1), {'x': True}), (('while', ('>', 1, 0), ('oops',)), {})]:
            with self.assertRaises(ValueError):
                imp_step(c, s)
        with self.assertRaises(ValueError):
            aeval(('/', 1, 0), {})
        with self.assertRaises(ValueError):
            countdown(-1)

    def test_false_invariant_and_nontermination(self):
        body = ('set', 'x', ('-', 'x', 1))
        _, state = imp_step(body, {'x': 1, 's': 0})
        self.assertNotEqual(state['s'] + state['x'], 1)
        c = ('while', ('>', 1, 0), ('skip',))
        s = {}
        for _ in range(12):
            c, s = imp_step(c, s)
        self.assertNotEqual(c, ('skip',))


if __name__ == '__main__':
    unittest.main()
```
