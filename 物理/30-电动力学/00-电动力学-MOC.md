# 电动力学：从守恒源到因果场

如果给定一团电荷和电流怎样随时间变化，远处探头究竟何时测到什么？Maxwell 方程约束场的局部变化；想实际求解，还要给守恒源、初始场和边界。势和规范使求解更方便，推迟 Green 函数把传播时间写进积分，辐射功率则把求出的场接回能量账本。

本课已经给出连续的**理论与复算路线**：检查源守恒 → 从 Maxwell 推出势方程 → 选择 Lorenz 规范和推迟条件 → 求有限源偶极场及平均功率 → 在同一 SI 约定下变换四流、场和粒子力 → 求运动点电荷的推迟事件、外部场与有限运动脉冲 → 核对场动量、应力和镜面受力 → 从守恒源展开磁偶极与四极并积分全角功率 → 对齐发射/接收时钟计算点电荷全角辐射 → 求受驱振子散射并核对反作用的慢变近似。它没有完成整门经典电动力学；物理域导航和电磁学课程分别负责总路线与静场、介质、模式，这里不复制静电边值课程。

## 进入前先核对三件事

- 会用散度、旋度和乘积求导；在 [[电子电路/46-电磁射频与高速/01-从集中参数到电磁场#场与边界如何约束电路|Maxwell 与连续性]] 中确认 SI 量纲。本课取真空，源符号表示纳入模型的**总**电荷、电流，不把介质的自由源方程不加说明搬过来。
- 在 [[数学/46-数理方程/15-Green函数基本解与边界响应#Green 函数是满足边界的点源响应|Green 主解释]] 中分清算子的基本解、边界条件和齐次解。回来把空间 Poisson 算子换成时空波动算子。
- 在 [[数学/46-数理方程/10-多维波动方程球面平均与传播#有限传播与尾部不是同一概念|波动支撑]] 中分清三维光锥面与二维内部尾部。这里用三维均匀真空，不能把支撑结论原封不动用于色散材料。
