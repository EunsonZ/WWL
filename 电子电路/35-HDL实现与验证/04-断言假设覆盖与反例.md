# “没有反例”究竟跨过了多少拍和多少前提

读者问题：写一条 assert 并获得绿色状态，就证明数据最终送达了吗？基础入口把“模块必须做”“环境答应做”“想看到发生过”分成三句话。快入口写采样时钟、reset取消、前件与后件，再区分有限展开与归纳。这里用单槽缓冲检验安全；永远阻塞时不会丢数，也可能永远不交付。

## assert、assume、cover分别改变什么

assert 要在允许的轨迹上成立，例如“有有效输出时，值等于历史队列头”。assume 缩小允许环境，例如“上游尚未被接收时保持valid和data，除非复位取消”。cover 寻找一个允许轨迹使指定事件发生，例如“旧满并同沿出入”。把待证明的 head equality 写成 assume 会排掉错误轨迹，绿色只反映循环前提；把下游 ready 常1会隐藏阻塞场景。

性质必须区分采样和取消。教学 SVA 形式：

```systemverilog
assert property (@(posedge clk) disable iff(!rst_n)
  (m_valid && !m_ready) |=> (m_valid && $stable(m_data)));
```

在某有效采样沿发现有效而阻塞，下一采样沿仍有效、数据与上一次采样一致。`|=>` 是非重叠蕴含，后件在下一采样检查；`$stable` 比较采样值，不是连续时间电压永不毛刺。复位可取消该义务；不能把取消算作一次输出。实现真源为了基本 Yosys 前端兼容，使用 clocked immediate assert 与带 past_valid 的 `$past`，不声称上述完整 SVA 语法已经被当前工具编译。

[IEEE 1800-2017 §16.9.3（395—397页）、§16.12及16.12.7（420、423、425—426页）](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf) 对应采样变化函数、非重叠蕴含及取消条件；§16.15（473—474页）规定默认disable条件的作用域。`disable iff` 使用当前值而非普通采样值，取消的attempt既不成功也不失败；所以不得把复位取消记作PASS样本。此处实际交付 harness 抽象成离散有效采样，并显式 guard 当前/前次 rst_n，不能冒充模拟所有亚周期脉冲。

## 完整算例和最小反例

沿1空格接A1；沿2旧满、mr=0，上游B2未接入。若fault宏用sv写数据，沿2后数据变B2。历史assert的前件并非没有发生：队列[A1]仍非空，故沿后 head equality 立刻失败。stall性质下一采样沿也会发现旧A1变B2；两种性质的观察位置不同、定位同一错误。把rst_n一直0就能让有效采样guard永不进入，此时安全断言真空成立，所以还需cover正常接入、阻塞、替换与非空复位。

## 归纳如何证明任意长度的安全

令 P为本复位区间接受序列，O为已交付序列，Q为未交付队列。归纳不变量：\(P=O\Vert Q\)，\(|Q|=q\in\{0,1\}\)，q=1时data_q=Q头。复位建立空基例。对一个无复位沿，先由旧q决定pop：若发生，移唯一头；再由ready保证push时已空或刚移除，因此追加新字不越容量。数据只在push写新尾，否则保留。四组(push,pop)=(0,0),(1,0),(0,1),(1,1)都保住不变量，于是归纳覆盖任意有限长度。

这是依据明确转移函数的数学归纳，尚须把真实RTL映射到该函数才构成RTL证明。自动k归纳另要求工具检验基例并从足够强的不变量关闭归纳步；“12拍没有错”不能替代这个闭合步骤。`slot.sby`分 bmc深度12、prove归纳任务、cover见证、mutant有意失败，状态必须分别记录。当前四任务未运行。

[SBY Quickstart 的 First properties、Writing a basic SBY configuration、Finding a failing property](https://yosyshq.readthedocs.io/projects/sby/en/latest/quickstart.html) 展示过去值初始化guard、有限BMC与prove/cover的区别。本文的队列不变量、反例和harness是自行设计的实例；工具介绍中的FIFO通过不意味着本缓冲已通过。

## 安全不蕴含活性，公平不等于超时

安全是“坏事不发生”，例如不凭空输出。活性是“好事最终发生”，例如接受后终于输出。在无限mr=0且不复位的轨迹中，A1可以永久保存，所有上述安全性质仍成立。要最终交付，需要下游在该项等待期间终于有一个有效采样mr=1且不复位；要最多B拍交付，还要明确最大阻塞B拍的更强有界环境保证。有限深度cover一次输出只是见证存在，不证明每条轨迹都最终输出。

两位图枚举8状态/256转移支持本有限CPU语义；不同位宽、四值、异步复位亚周期行为和综合网表仍须另论。回到 [[电子电路/30-数字电路与实现/02-RTL性质复位与跨时钟边界#性质是可以被反例推翻的句子|原性质与反例]]，检查每句话的环境责任，避免把“形式”二字当能力证明。

## 四题与理由

1. assume(m_ready)后通过阻塞保持assert，有说服力吗？答很弱，阻塞前件永不出现；cover(valid&&!ready)会不可达，应去掉无依据假设。
2. BMC12拍PASS能推第13拍吗？答不能，计数到13才触发的错误是反例。可用数学归纳或成功闭合的工具证明，并检查基例/假设。
3. cover(push&&pop)成功证明所有数据不丢吗？答只证明存在一次替换；安全需要对所有允许轨迹的assert。
4. 复位取消A1后，下游稍后ready，A1必须送出吗？答不用，已取消epoch；若应用需要复位后恢复事务，需要上层重试或持久状态新合同，不能偷偷保留旧队列。
