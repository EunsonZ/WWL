# 缓存到期了，选课记录也该消失吗？

S1在T1选了C10、C20。页面缓存可以过期重建，选课身份却不能因此重新变成“从未创建”。两位老师同时改成绩时，一个GET、一个SET都成功，也不代表两人的修改都保存了。再问“昨天这名学生改过哪些课”，按当前选课键点查又不能自动得到时间范围答案。

本课接 [[计算机知识/55-数据库/10-系统课程/13-键值文档与图模型#三种表示回答同一个查询|关系、嵌入与引用的同一课表]]，用同一学生/学期/课程/教师数据完成两种访问：**键值记录保存当前状态，按学生与时间分区的宽列式布局保存接受的变更点**。读完带着键、条件写、保留与范围查询的代价回 [[计算机知识/55-数据库/10-系统课程/08-数据库工程安全与扩展专题#迁移要允许新旧版本短期共存|迁移项目]]。图路径问题仍由 [[计算机知识/55-数据库/10-系统课程/20-图模型路径语义与访问代价|第20讲]] 解释，不重新用键值代码冒充图查询。

实际证据分三层：标准库教学模型给20个前缀的当前值/墓碑、缓存与三种分区布局；独立批量历史与SQLite查询复算全部分页；本机**由官方源码编译的Redis 8.10.2**实际执行14个CAS裁决快照及NX、TTL、受控两客户端交错和错误/重启探针。宽列布局是本地有序分区模型，**没有运行Cassandra**；CQL接口按官方5.0文档核规则，未作为引擎执行记录。输入、原始RESP字节与复建在 [[计算机知识/_labs/round3/DB/kv_partition_timeseries/README|实践入口]]。

## 先让键指向业务对象

一条当前选课的身份是 `(student_id,term,course_id)`，不是姓名、课名或到达时间。S1/T1/C10和S1/T2/C10不同；没有分班、重修或共同授课。若增加班次或同学期重修，键必须增加offering/attempt，不能因为底层“无schema”就把两次选课覆盖成一条。课程13已经给出这些业务依赖与模型前提，本课只沿用固定世界。

| 记录 | 逻辑键／值 | 供什么查询 |
| --- | --- | --- |
| 当前选课 | 三元身份 → version、deleted、完整value | 已知学生/学期/课程，点查或条件更新 |
| 学生课表索引roster | 学生/学期 → 当前有效course_id集合 | 已知学生/学期，先找课程再点查 |
| 教师当前资料 | teacher_id → 当前电话 | 给课表取得教师的当前号码 |
| 课表缓存 | 学生/学期 → 某次投影结果和到期时间 | 允许有限陈旧的重复读取 |
| 变更审计点 | 学生/时间桶/分片 + event_ms/event_id → 接受的新版本 | 学生在时间范围内的接受变更 |

value含teacher_id、grade、phone_at_enrollment。教师当前电话由教师键取得；最后一项是选课时的历史事实，教师改号不改它。键值库不会自动把其中的teacher_id变成外键；本输入都引用T7，模型遇到未知教师时当前电话为null，不能据此证明引用约束存在。Redis存的是封套JSON字符串；可解析和“只存一份值”都不授予业务schema校验。

不能简单将字段用冒号连接。二元组 `['a:b','c']` 与 `['a','b:c']` 都变成 `a:b:c`，原本不同的身份相撞。本课把紧凑UTF8 JSON数组编码成无padding的base64url：先序列化再编码，不做大小写折叠或Unicode规范化。因此同形但不同码点的标识仍不同；是否应合并是上游业务决定。例：

```text
tag = base64url(UTF8(["S1","T1"])) = WyJTMSIsIlQxIl0
选课键 = enrol:{WyJTMSIsIlQxIl0}:WyJDMTAiXQ
索引键 = roster:{WyJTMSIsIlQxIl0}
```

花括号内是Redis Cluster hash tag的设计接口：同学生/学期的选课与索引可落同slot，方便需要多键的操作满足同槽条件；本次实际只跑单节点。Redis[集群规范](https://redis.io/docs/latest/operate/oss_and_stack/reference/cluster-spec/)定义hash tag与多键限制，不能从本地两个键名字相近推断已验分片事务。若只用 `{T1}`，整个学期都可能集中；按学生分组也不能拆掉一个超热学生的所有写。同槽减少协调范围，同时集中负载。

## 一次读课表需要哪些访问

要读S1/T1当前课表，先取roster得到C10、C20，按确定键取得两份选课，再按去重后的teacher_id取T7当前电话。初始结果与第13讲关系JOIN/文档查询相同：C10/A和C20/B，当前与历史电话均555-0100。改教师键为555-0199后，两条当前电话变新，历史快照仍旧；缓存若未失效则可能还旧。

若有效课程数为k、不同教师数为u，完整读取至少取得一个索引集合、k个选课值与u个教师值，以及相应结果字节。管线化、批量命令可以减少网络往返，不能把数据工作量变成“一次O(1)”。Redis Cluster跨slot时又有不同命令限制。若只有已知三元键的点查，不需要先扫全库；若问“所有成绩为A的学生”，这些键不直接支持它，须扫数据或维护另一个按成绩组织的索引及其更新协议。

上述多次roster/选课/教师读取也不因单次Lua写原子就自动取得同版快照；本课顺序输入的课表结果没有认证并发读取快照。roster是维护出来的副本，不是键值系统自动知道的关系。如果权威选课已创建、roster漏添，课表查询会漏课；roster保留已删除课程，读取时又可能遇到墓碑。改用每学生/学期一份大JSON可以让这份课表内更新更集中，却增加整值读写、文档增长和热点竞争；关系表索引及JOIN也可能更合适。选择取决于实际查询形状和维护边界，不由“NoSQL更快”决定。

## 版本条件写，和两个都成功的裸SET

教学权威状态是 `version,deleted,value`。未有记录视为version0；合法条件写携带expected_version和完整after，要求它等于当前版本，成功后版本恰增1。after为null时登记有版本的墓碑并从roster移除；非null写入完整值并添回roster。删除不存在的键若expected0，也可按本教学合同登记version1墓碑；它不是SQL DELETE的受影响行数语义。

单纯“先GET、检查、再SET”不能把这三个动作变成一个条件写。本机两个持久Redis连接按明确屏障交错：A、B都先读到version1；A裸写version2/value A，B再裸写version2/value B，两个SET成功而最终只剩B。不是Redis忘了A，而是协议明确允许B覆盖它。SET NX只允许键不存在时创建，第二个创建返回RESP null；它不检查整个选课系统的任意唯一性，也不能在键已经有值时比较版本。[SET的NX与PX规则](https://redis.io/docs/latest/commands/set/)是具体引擎合同。

本次用原样执行的 `cas.lua` 在脚本内检查版本、写值并维护roster。实跑两客户端都持有expected1时，A得到accepted2，B得到version_conflict2，最终保留A。这两个隔离probe使用简短A/B值，并未作为主日志的选课payload；主日志仍按完整封套逐项核对。处理先后在本例明确；有限受控交错不等于所有并发调度的证明。Lua脚本执行期间不会与其他客户端命令交错，是[Redis脚本原子执行](https://redis.io/docs/latest/develop/programmability/eval-intro/)的保证；命令执行成功后的持久性是另一件事。

固定日志的关键裁决如下。request_id只是这份有限输入的唯一命令标签与审计点身份，**不是已实现的持久意图去重协议**。

| 请求 | S1/T1操作及expected | 裁决与状态 |
| --- | --- | --- |
| R01、R02 | C10、C20各expected0创建 | 各version1 |
| R08 | C10 expected1改成绩B | accepted2 |
| R09、R10 | C10仍expected1、或expected0创建 | 都conflict，观察版本2 |
| R12、R13 | C20 expected1删，再expected2重新创建 | 墓碑2，再有效3 |
| R14 | C10 expected2改C，业务时点50ms晚到 | accepted3；event_ms旧不表示expected旧 |
| R15、R16、R17 | C10 expected3删；expected2改；expected4重新创建 | 墓碑4；conflict4；有效5 |
| R19 | C30缺grade | invalid_payload，不创建状态 |

R11另创建S2/T1/C10，R18创建S1/T2/C10，各version1。最后S1/T1的C10为A/version5、C20为C/version3；两者新选课快照为555-0199。S2的历史快照仍555-0100，当前电话为555-0199。Redis实际保存的14次裁决与完整选课/roster快照逐项对应模型；完整课表投影、逻辑缓存和时序布局属于本地模型层，不把它们都写成已执行Redis查询。

为什么保留墓碑？删除后若把版本键也过期，旧expected0的创建可能再次成功，或旧写者不能分清“从未存在”和“曾删到version4”。本课权威键与墓碑不设TTL，随身份数增长，没有有界总内存保证；合法复活必须读到墓碑版本再CAS。若以后回收，要定义旧写者失效、版本代数或保留期限，不能只加一条EXPIRE。

CAS防止本例覆盖，不会给超时请求恢复原结果。某请求成功到version2但回复丢失，重发expected1只收到conflict2：可能自己已成功，也可能另一个请求先成功；不能据此认定本请求被拒。稳定业务意图、指纹和原裁决的恢复复用 [[计算机知识/75-软件工程与人机交互/82-v2意图恢复与演进实验#唯一业务合同：移动端与流处理共用|SE82既有合同]]，本课不另造兼容协议。

## 原子执行为什么还会留下半截写

故意的错误Lua先 `SET probe:partial written-before-error`，再向一个string键执行LPUSH；真实Redis返回WRONGTYPE，随后GET却仍读到 `written-before-error`。脚本执行不被其他命令穿插，**不等于执行错误会回滚之前的命令**。MULTI/EXEC也不能凭SQL事务直觉推回滚，具体排队错误与执行错误规则应按[Redis事务说明](https://redis.io/docs/latest/develop/using-commands/transactions/)核对。

本课CAS先检查权威键是none/string、roster是none/set，已知类型错误在写之前返回invalid_type；真实探针确认此时权威键仍不存在。但这只缩小一个已知错误路径，不保证OOM、未来加代码后的错误或绕开可信包装器的输入都会自动回滚。完整nextJSON与schema在调用前按教学前提构造；实际Redis运行包装器只为这份固定输入作必要检查，不是公开的任意payload安全服务。

本地模型把一次合法操作的权威、roster与审计点一起产生，便于核不变量；Redis实跑只维护权威/roster，**没有同时把审计点提交到Cassandra或另一个资源**。如果真实工程要求状态和审计一起可恢复，应采用已验证的同资源outbox/恢复协议，回 [[计算机知识/55-数据库/10-系统课程/18-源位置状态快照与目标恢复|第18讲]] 检查提交边界。一次EVAL成功不证明跨资源exactly-once。

## TTL清理的是缓存，不是业务历史

模型使用显式处理时钟clock_ms，单调不减；缓存填充时到期点为 `clock_ms+ttl_ms`，当 `clock_ms>=expires_at_ms` 即miss。R03在10ms填缓存，TTL50，到60ms过期；R04在20ms教师改号，此时命中缓存仍得旧号；R05到60ms缓存已消失，权威选课、版本和教师资料仍在。TTL控制多久可能继续读旧投影，不能单独保证始终读最新。

R06重新填TTL50的缓存，R07紧接着用普通无TTL的SET语义覆盖，过期点清成无期限。到逻辑1000ms，它仍留着C20成绩B，而当前C20已经是C。给缓存设过一次TTL，不代表未来覆盖永远保持TTL。[SET文档](https://redis.io/docs/latest/commands/set/)说明成功覆写会丢弃原TTL，需按需求显式设置或保留。

Redis真实TTL探针使用服务器实际时间，与上述逻辑钟分开：PX50后观察PTTL为 `50,39,26,15,4,-2`，缓存GET为nil，权威GET仍有值、PTTL=-1；另一个PX10000键普通SET后PTTL从10000变-1。[-2表示键不存在、-1表示无过期](https://redis.io/docs/latest/commands/pttl/)。轮询与调度会改变中间毫秒值，本次只据此证明这个有限过期/覆盖观察；不要求别人的运行复现每个中间数，也不把业务event_ms当服务器时钟。缓存失效与数据库驱逐也不同，本次maxmemory采用noeviction，没有测试内存压力驱逐。

本次Redis配置save空、AOF关闭。正常SHUTDOWN NOSAVE并重新启动后，authority与probe键都为nil；这是实际运行的内存型配置在**正常停起**下丢失的观察。没有进程kill、断电、复制切换或备份恢复试验，不能据此评价启用RDB/AOF后的保证；“权威键没有TTL”也不等于它已持久。

## 宽列式时序：先设计分区，再写范围查询

现在换问题：不是“C10当前成绩”，而是“S1在某个业务时间范围内接受了哪些更改”。一行是一条接受的变更点，含event_id、event_ms、三元选课身份、新版本与after/墓碑。拒绝的尝试不进入这张接受审计；如果要安全审计全部拒绝，要另定义记录对象与保留。20个动作接受10条，S1占9条，S2占1条。删除点仍是业务审计事实，不是要求底层立即删除历史行。

采用宽列式布局：分区键 `(student_id,bucket)`，其中 `bucket=floor(event_ms/D)`，D=86400000毫秒、按UTC epoch的固定日桶；分区内按 `(event_ms,event_id)` 聚簇升序。单位是整数毫秒，不按本地夏令时“每天若干小时”换桶；模型只接受非负时间。event_id解决同毫秒并列。它与第19讲分析用的**列式投影布局**不同：这里围绕一个分区的多行及聚簇键范围访问，不是把全表每列分开存就得到宽列模型。

[Apache Cassandra逻辑建模](https://cassandra.apache.org/doc/latest/cassandra/developing/data-modeling/data-modeling_logical.html)强调从查询确定partition/clustering keys。对应的Cassandra5.0风格结构接口为：

```cql
CREATE TABLE enrollment_audit_by_student_day (
  student_id text, bucket bigint, event_ms bigint, event_id text,
  term text, course_id text, version int, deleted boolean, grade text,
  PRIMARY KEY ((student_id,bucket),event_ms,event_id)
) WITH CLUSTERING ORDER BY (event_ms ASC,event_id ASC);
```

两层键各做一件事：student与bucket定位分区；时间与id决定分区内唯一行和顺序。若只用event_ms作行键，R12删除与R13重新创建都发生在D，可能覆盖成同一行。若按 `(student,term,course)` 作行键，则只保留当前对象而不是完整变更序列。CQL主键/聚簇含义以[官方DDL](https://cassandra.apache.org/doc/latest/cassandra/developing/cql/ddl.html)为准；Cassandra内部写时间、冲突合并和业务version不是同一个字段，本模型没有实现其副本/LWW/repair/compaction。

![[计算机知识/_labs/round3/DB/kv_partition_timeseries/partition-order.svg]]

图由同一actual.json生成。R14处理位置14晚于R08的位置8，但event_ms=50早于100，所以插入日0旧位置；它不是“过期版本”，CAS读取的expected2仍合法。这是输入当前前缀下的有限排序，不复制第17讲watermark或窗口final政策。

## 半开范围、并列游标与迟到插入

查询 `S1,[lo,hi)`：先枚举覆盖的日桶，再在每个分区取 `event_ms>=lo AND event_ms<hi`，最后按完整 `(event_ms,event_id)` 合并。例如 `[D-1,D+1)` 跨日边界，结果恰为R02、R12、R13，不含D+1的R15；`[50,100)` 仅R14，不含100的R08。

本地模型对每分区有序行二分定位、每页取至多 `page_size+1` 个候选，合并后返回前page_size项；多取一项用于判断是否还有后页。游标含最后输出的**时间和事件id**，后页严格取tuple更大者。仅存时间会在同毫秒时漏掉剩余行；只写“大于等于”又会重复上一条。相同输入前缀的完整S1输出为：

```text
(R01,R14) → (R08,R02) → (R12,R13) → (R15,R17) → (R18)
```

括号是一页，page_size=2；R12/R13同时间按id排序。CQL代表查询固定完整分区键后再给时间范围，见实践 `cassandra_interface.cql`；跨桶与跨分片的合并由应用负责。按[官方DML规则](https://cassandra.apache.org/doc/latest/cassandra/developing/cql/dml.html)检查所选条件能否定位分区和连续聚簇范围，不能把任意SQL过滤直接改写成CQL，再靠ALLOW FILTERING保证低代价。

游标也不制造快照。例如前缀13的第一页是R01/R08，游标为(100,R08)；前缀14才接受R14，时点50插在两者之间，继续严格大于这个游标就漏R14。每个前缀的分页全量正确，不等于跨前缀分页不漏。需要固定查询数据版本、允许重扫与去重，或另约定补发；这些工程协议没有在此实装。相对地，offset分页在前面插入行后还会移动位置，本课不以keyset取代所有一致性需求。

## 桶、分片与热点：同答案怎样换成本

三种布局在同一日志上都返回相同查询结果：日桶、半日桶、日桶加两片（shard=CRC32(event_id) mod 2）。哈希只用于本地确定性分片示范，不是Cassandra的partitioner或Redis Cluster算法。查询须知道全部片号并合并，否则只是漏读半份数据。

| 最终S1全范围首分页，size2 | 探测分区数 | 拷入候选行数 | 所有实际分区最大行数 |
| --- | ---: | ---: | ---: |
| 日桶 | 3 | 7 | 4 |
| 半日桶 | 5 | 8 | 4 |
| 日桶两片 | 6 | 8 | 4 |

探测含空分区；每个分区独立预取至size+1，因此候选行数可高于全局size+1。后页可能重新读上页的lookahead，不能将9个最终结果当总读取工作。模型计数只记分区探测与**实际拷入候选列表的行**，不含二分键比较、排序/合并、建分区与存储字节；不是Cassandra RPC、SSTable读取、物理页I/O或实测速率。

这里细桶和两片都没降低最大分区行数：日0的四个事件恰好在两片布局落同片。小样本分片不会自动均衡。一般若单学生事件率λ、桶长B，均匀假设下每桶约λB行，查跨度W约触及 `ceil(W/B)+1` 个桶（边界上界）再乘片数s；B变小限制桶内增长，却增加范围查询fanout、元数据与晚到旧桶维护。λ会突发、哈希也会倾斜，不能把λB当最坏界。一个超热学生/课程或全班同秒写仍可能形成热点；追加随机片有写分散机会，但查询多读多合并；这里拆的是审计分区，不能分散同一student/term hash tag中的权威CAS热点。

如果需求改成“所有学生中C10昨天的更改”，现分区键没有course维度。需要读许多学生桶，或另建按课程/日组织的查询表；那会复制审计点，带来写放大、不同查询表的更新/恢复一致性和回填成本。关系索引更灵活不代表免费，宽列按查询建表也不意味着查询永远便宜。整段范围本次在本地模型与独立SQLite查询上实际复算，Cassandra源码/单节点服务本次没有启动；可运行的CQL接口与待验断言保留，不能将未做写成外部不可验。

## 哪些不变量已经兑现

在固定可信顺序输入、无执行中故障的模型合同下：每个三元身份只有一个当前封套；版本从0起只在匹配expected时加1；roster恰等于同学生/学期未deleted的课程集合；审计恰含每次接受的变更点；每点在每种布局恰有一个分区和完整顺序位置。

可按输入前缀归纳。初始集合为空；无效/冲突CAS不改变当前值、roster或审计。接受写只替换这一身份的封套，并按deleted增删同一个集合成员、追加唯一event_id点；因而版本和roster关系保持。teacher操作只改当前资料，不改历史字段；cache操作只换派生缓存，不改权威。分区函数对每个点给唯一桶/片，按全序排序不改变点集合。查询枚举所有覆盖桶/片、半开过滤与严格游标，固定前缀每点不漏不重。少枚举一个片、只用时间游标、或把墓碑版本过期，分别破坏其中一个前提。

独立批量oracle从原始历史重建每个前缀，再用新SQLite全量范围排序分页；不import模型。另有非作者从全历史选择合法版本后继、全量filter-sort的不同路线，核固定与变式；真实Redis原始RESP独立解码后逐CAS全状态对应。模型归纳证明不外推脚本所有错误、真实服务并发、跨资源审计或持久恢复。

"""Finite teaching model: versioned KV, derived roster, logical TTL, ordered partitions."""
import argparse
import base64
import bisect
import copy
import json
from pathlib import Path
import zlib


def token(parts):
    return base64.urlsafe_b64encode(json.dumps(parts,ensure_ascii=False,separators=(',',':')).encode('utf-8')).decode().rstrip('=')


def keys(key):
    tag=token(key[:2])
    return 'enrol:{'+tag+'}:'+token(key[2:]),'roster:{'+tag+'}'


def payload_valid(value):
    return value is None or (isinstance(value,dict) and set(value)=={'teacher_id','grade','phone_at_enrollment'} and all(isinstance(v,str) and v for v in value.values()))


def project(current, roster, teachers, student, term):
    result=[]
    for course in sorted(roster.get((student,term),set())):
        value=current[(student,term,course)]['value']
        result.append({'course_id':course,'grade':value['grade'],'current_phone':teachers.get(value['teacher_id']),
                       'phone_at_enrollment':value['phone_at_enrollment']})
    return result


def partitioned(audit, layout):
    result={}
    for point in audit:
        key=(point['key'][0],point['event_ms']//layout['bucket_ms'],zlib.crc32(point['event_id'].encode())%layout['shards'])
        result.setdefault(key,[]).append(point)
    for values in result.values(): values.sort(key=lambda p:(p['event_ms'],p['event_id']))
    return result


def query(partitions, layout, q, cursor=None):
    lo,hi=q['lo_ms'],q['hi_ms']; limit=q['page_size']
    candidates=[]; probes=0
    for bucket in range(lo//layout['bucket_ms'],(hi-1)//layout['bucket_ms']+1):
        for shard in range(layout['shards']):
            probes+=1
            rows=partitions.get((q['student'],bucket,shard),[])
            order=lambda p:(p['event_ms'],p['event_id'])
            start=bisect.bisect_left(rows,(lo,''),key=order)
            if cursor is not None: start=max(start,bisect.bisect_right(rows,tuple(cursor),key=order))
            stop=bisect.bisect_left(rows,(hi,''),key=order)
            # One lookahead from each touched partition, then merge by full order.
            candidates.extend(rows[start:min(stop,start+limit+1)])
    candidates.sort(key=lambda p:(p['event_ms'],p['event_id']))
    answer=candidates[:limit]; more=len(candidates)>limit
    return {'rows':answer,'next_cursor':[answer[-1]['event_ms'],answer[-1]['event_id']] if more else None,
            'cost':{'partition_probes':probes,'candidate_rows_read':len(candidates)}}


def query_all(partitions,layout,q):
    pages=[]; cursor=None
    while True:
        page=query(partitions,layout,q,cursor);pages.append(page)
        cursor=page['next_cursor']
        if cursor is None:break
    return pages


def run(spec):
    actions=spec['actions']
    if len(actions)>100 or len(spec['queries'])>10 or len(spec['layouts'])>4:raise ValueError('fixture_limit')
    if len({a['request_id'] for a in actions})!=len(actions):raise ValueError('command_labels_must_be_unique')
    for q in spec['queries']:
        if not 0<=q['lo_ms']<q['hi_ms'] or not 1<=q['page_size']<=20:raise ValueError('query_bounds')
        if q['hi_ms']-q['lo_ms']>100*spec['day_ms']:raise ValueError('range_limit')
    total_probe_bound=0
    cas_count=sum(a['op']=='cas' for a in actions)
    for layout in spec['layouts']:
        if type(layout['bucket_ms']) is not int or type(layout['shards']) is not int or not 1<=layout['bucket_ms'] or not 1<=layout['shards']<=4:raise ValueError('layout_limit')
        for q in spec['queries']:
            probes=((q['hi_ms']-1)//layout['bucket_ms']-q['lo_ms']//layout['bucket_ms']+1)*layout['shards']
            if probes>1000:raise ValueError('partition_probe_limit: each query/page must touch at most 1000 partitions')
            max_pages=max(1,(cas_count+q['page_size']-1)//q['page_size'])
            total_probe_bound+=len(actions)*max_pages*probes
    if total_probe_bound>1000000:raise ValueError('total_probe_limit: worst-case prefix/page partition probes exceed 1000000')
    current={};roster={};teachers=copy.deepcopy(spec['initial_teachers']);cache={};audit=[];prefixes=[];clock=-1
    for position,a in enumerate(actions,1):
        if type(a['clock_ms']) is not int or a['clock_ms']<clock:raise ValueError('clock_must_not_regress')
        clock=a['clock_ms']
        cache={k:v for k,v in cache.items() if v['expires_at_ms'] is None or clock<v['expires_at_ms']}
        result={'status':'accepted'}
        if a['op']=='cas':
            key=tuple(a['key']); old=current.get(key);version=old['version'] if old else 0
            if not payload_valid(a['after']):result={'status':'invalid_payload'}
            elif type(a['expected_version']) is not int or a['expected_version']<0:result={'status':'invalid_expected_version'}
            elif type(a['event_ms']) is not int or a['event_ms']<0:result={'status':'invalid_event_time'}
            elif version!=a['expected_version']:result={'status':'version_conflict','observed_version':version}
            else:
                value={'version':version+1,'deleted':a['after'] is None,'value':copy.deepcopy(a['after'])}
                current[key]=value
                members=roster.setdefault(key[:2],set())
                if value['deleted']:members.discard(key[2])
                else:members.add(key[2])
                point={'event_id':a['request_id'],'event_ms':a['event_ms'],'key':list(key),**copy.deepcopy(value)}
                audit.append(point);result={'status':'accepted','version':version+1}
        elif a['op']=='teacher':teachers[a['teacher_id']]=a['phone']
        elif a['op']=='cache_fill':
            ttl=a['ttl_ms']
            if ttl is not None and (type(ttl) is not int or ttl<=0):raise ValueError('ttl')
            cache[(a['student'],a['term'])]={'value':project(current,roster,teachers,a['student'],a['term']),
                  'expires_at_ms':None if ttl is None else clock+ttl}
        elif a['op']!='clock':raise ValueError('unsupported_operation')
        layouts=[]
        for layout in spec['layouts']:
            partitions=partitioned(audit,layout)
            layouts.append({'id':layout['id'],'partitions':[{'key':list(k),'rows':v} for k,v in sorted(partitions.items())],
                            'max_partition_rows':max(map(len,partitions.values()),default=0),
                            'queries':[{'query_id':q['id'],'pages':query_all(partitions,layout,q)} for q in spec['queries']]})
        prefixes.append({'position':position,'request_id':a['request_id'],'clock_ms':clock,'result':result,
                         'current':[{'key':list(k),'storage_key':keys(list(k))[0],**v} for k,v in sorted(current.items())],
                         'roster':[{'key':list(k),'storage_key':keys([*k,''])[1],'courses':sorted(v)} for k,v in sorted(roster.items())],
                         'teachers':copy.deepcopy(teachers),
                         'schedules':[{'key':[s,t],'rows':project(current,roster,teachers,s,t)} for s,t in [('S1','T1'),('S1','T2'),('S2','T1')]],
                         'cache':[{'key':list(k),'pttl_model_ms':None if v['expires_at_ms'] is None else v['expires_at_ms']-clock,**copy.deepcopy(v)} for k,v in sorted(cache.items())],
                         'audit':copy.deepcopy(audit),'layouts':layouts})
    collision={'naive':[':'.join(p) for p in spec['key_collision_pairs']], 'encoded':[token(p) for p in spec['key_collision_pairs']]}
    return {'input_version':spec['input_version'],'layer':'finite local model, not Redis/Cassandra','key_collision':collision,'prefixes':prefixes}


def main():
    p=argparse.ArgumentParser();p.add_argument('--spec',type=Path,required=True);p.add_argument('--out',type=Path,required=True)
    a=p.parse_args();r=run(json.loads(a.spec.read_text()));a.out.write_text(json.dumps(r,ensure_ascii=True,indent=2)+'\n')
    print(json.dumps({'prefixes':len(r['prefixes']),'accepted_audit_points':len(r['prefixes'][-1]['audit'])}))
if __name__=='__main__':main()
