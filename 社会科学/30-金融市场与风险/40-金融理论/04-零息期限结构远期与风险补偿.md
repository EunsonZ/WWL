# 零息期限结构、远期与风险补偿

本课**另换一个有限随机短率经济**，不是把上一课常数r的GBM偷偷改成随机r，却保留原call公式。连续复制课说明风险溢价为何不直接进入可复制期权方程；这里问反向问题：观察一条零息价格曲线，能不能据此读出真实短率预测和风险补偿？先从可交易现金流推远期，再用同价反例检验识别。

## 零息价格是某日期支付1的当前金额

记 $D(t,T)>0$ 为一份无违约、无中间息票、T日支付1单位同币种货币的零息债在t的每份价格。$D(T,T)=1$；与某个到期收益率、银行账户累计价值、真实短率都不是同一对象。不同币种、信用、税收、日计数、交割与流动性条款不同的债，不能先当成同一组D再解释差异。

先以日期0及整数年n计，年度复利即期率和连续复利即期率分别定义为

$$z_n=D(0,n)^{-1/n}-1,\qquad y_n=-\frac{\ln D(0,n)}n.\tag{1}$$

前者每年有效率，后者连续复利年率，$e^{y_n}=1+z_n$。正价格只保证 $z_n>-1$；负利率时D可以大于1，不可把“所有D必须随期限下降”当无条件定理。若合同现金流确定、可交易的这些零息债可双向组合，息票债价格为 $\sum_n CF_nD(0,n)$：按现金流复制，而非把各期限曲线硬压为同一个YTM。

复用 [[社会科学/30-金融市场与风险/02-债券价格利率期限结构与信用利差#1. 先固定合约现金流|债券02的正确分母解释]]：在**单一收益率摘要**、有限个确定非负现金流固定（到期N年）且y>−1时

$$P(y)=\sum_{n=1}^N CF_n(1+y)^{-n},\quad
P'(y)=-\sum_{n=1}^N\frac{nCF_n}{(1+y)^{n+1}}<0,$$

最后严格号要求至少一项CF>0。收益率升高使分母增大、因子减小；该页已正确，本课只核条件不重修术语。零息曲线非平行改变、有嵌入期权或现金流变化时，要按各自对象重新定价，不能拿这一个导数替代。

## 远期先是一组零成本的日期现金流

在0承诺“日期s借出1，日期T收回F”，s<T；假设零息债可买卖/卖空、同币种无摩擦，构造：买 $F=D(0,s)/D(0,T)$ 份T到期债，同时卖空1份s到期债。

| 日期 | 组合现金流 |
| --- | ---: |
| 0 | $FD(0,T)-D(0,s)=0$ |
| s | −1 |
| T | +F |

所以s到T锁定的年化有效远期率为

$$f_{s,T}=\left(\frac{D(0,s)}{D(0,T)}\right)^{1/(T-s)}-1.\tag{2}$$

这是给定融资/交割条件的无套利价格比。若对方给不同F，可对做两份相反贷款，s日相抵，T日留确定差额。远期组合自身并非全日期非负：s日仍必须拿出1，不能把0日零成本当免费收益；到s借钱融资后，最终净收益是 $F-R_{s,T}$，通常有风险。

只有利率未来确定，或再加特定预期/风险结构时，远期才等于某种真实短率预期。正态连续股票课的“把r提出期望”不适用于随机银行终值；正确的共同结构是

$$D(t,T)=B_tE_Q[1/B_T\mid\mathcal F_t].\tag{3}$$

这里Q须与该经济中银行及债券的交易价格一致，使其贴现价格为真鞅；有限完备树由前课逐节点证明这个表示。在连续随机利率模型中还需相应测度、可积性与可交易/复制条件，本课不由(3)自行宣布一般市场完备。[Lawler §5.5，印刷166–167、PDF172–173](https://www.math.uchicago.edu/~lawler/finbook.pdf)给条件银行比率留在期望中的形式。

## 同一组价格建立一棵完整的随机短率树

日期0、1、2各隔一年。银行 $B_0=1$，0到1毛收益 $R_0=21/20$；到1才揭示L/H，之后1到2毛收益为 $R_1(L)=1,R_1(H)=6/5$，在1已知；1以后没有新不确定性。两态在真实P下都正概率。无违约、费用、借贷价差或持仓限制，允许在1重配。

0日可交易银行账户一份价1、1日值21/20；另有2到期零息债Z，2日付1，1日价值 $D(1,2)=1/R_1$，即L为1、H为5/6，0日价55/63。按**1日价值**列支付矩阵，银行在第一列：

$$A=\begin{pmatrix}21/20&1\\21/20&5/6\end{pmatrix},\quad
q=\begin{pmatrix}1\\55/63\end{pmatrix}.\tag{4}$$

$\det A\ne0$，两态支付完备，状态价由 $A^\top\pi=q$ 解出 $\pi_L=\pi_H=10/21>0$。因此0到1的条件Q均为1/2；1到2只有一个确定子态，仍可用当地银行复制任意已知金额。注意银行列是账户**下一日21/20的值**，不是改成支付1又忘改今天价格。

从银行可推出1到期支付1的零息价 $D(0,1)=20/21$。同一组曲线是

$$D(0,0)=1,\quad D(0,1)=20/21,\quad D(0,2)=55/63.$$

按(1)/(2)，

$$z_1=1/20=5\%,\quad z_2=\sqrt{63/55}-1,\quad
1+f_{1,2}=\frac{12}{11},\ f_{1,2}=1/11\approx9.0909\%.$$

持两年收到1的债，若1日卖出，售价随L/H为1或5/6；“到期支付确定”没有让中途持有回报确定。

日期2状态价格也可独立核：银行累计值L为21/20、H为63/50，故 $\pi_{0,2}=Q/B_2=(10/21,25/63)$，相加正好55/63。它们与日期1状态价不同，因为日期/支付单位不同；Q均为1/2不意味着两态日期2状态价相等。

## 改P而不改任何已列价格，风险解释会怎样

0日价格与树形固定，另构造两个都合法的真实经济：A世界 $P_H=1/4$，B世界 $P_H=3/4$。这不是在一套真实数据里随意选择P来优化收益；它是证明“观察价格尚不足识别P”的两个可行机制。

一步SDF $m_s=\pi_s/P_s$ 给

| 对象 | A：$P_H=1/4$ | B：$P_H=3/4$ |
| --- | ---: | ---: |
| $(m_L,m_H)$ | $(40/63,40/21)$ | $(40/21,40/63)$ |
| $E_P[R_1]$ | $21/20$ | $23/20$ |
| $E_P$未来净短率 | $1/20$ | $3/20$ |
| Z从0到1的 $E_P[R^Z]$ | $483/440$ | $441/440$ |
| Z的持有期超额毛回报 $E_P[R^Z]-R_0$ | $21/440$ | $-21/440$ |

因为 $R^Z=D(1,2)/D(0,2)$，其L/H毛回报分别为 $63/55,21/22$。两世界都有 $E_Pm=20/21$、$E_P[mR^Z]=1$，但 $\operatorname{Cov}_P(m,R^Z)$ 为 $-1/22,+1/22$；一期协方差恒等式再次给出表中的正/负补偿。长债在A的高m态H价格低，因而承担坏态风险而要求正补偿；这个“坏态”的边际价值解释若落到真实消费，仍须额外偏好/禀赋证据，而非仅凭H这个字母。

所以同一零息曲线兼容未来短率均值5%和15%，也兼容长债正或负的物理预期超额持有回报。无套利和定价Q没有替你选出真实机制；更多到期日价格可约束更多定价对象，却不凭空提供物理短率概率。

## 远期减预期，不全是风险补偿

这里有三个经常混叫“期限溢价”的不同量：远期报价减物理短率预期、债券某持有期间的物理超额回报、某结构模型参数。必须先定义一个再算，不能把三者互相作答案。

本树从(3)得到

$$D(0,2)=\frac1{R_0}E_Q[1/R_1],\qquad
1+f_{1,2}=\frac1{E_Q[1/R_1]}=12/11.\tag{5}$$

这在货币市场计价Q下是R1的调和均值，不是 $E_QR_1=11/10$。精确分解

$$\underbrace{f_{1,2}-E_P(R_1-1)}_{\text{远期—预测差}}
=\underbrace{\left\{\frac1{E_Q(1/R_1)}-E_QR_1\right\}}_{\text{非线性/凸性项}}
+\underbrace{\{E_QR_1-E_PR_1\}}_{\text{测度/风险定价差}}.\tag{6}$$

两个常数−1已经抵消。R1>0时Jensen给第一项≤0，本树为−1/110；第二项A为1/20，B为−1/20，所以A/B的远期—预测差分别 $9/220,-13/220$，与持有期补偿 $\pm21/440$ 不相等。把两种定义的百分点混用并不能反推出一个“市场害怕未来多少”的参数。

更尖锐的反例是第三世界 **P=Q**，即 $P_H=1/2$。此时m常数20/21，长债 $E_PR^Z=R_0$，持有期风险补偿0；但真实未来净短率均值1/10仍高于远期1/11，差−1/110来自非线性，不能叫正/负风险厌恶补偿。这里没有需要通过增大样本数消除的采样误差，算的都是精确模型期望。

## 从曲线回到头寸，再问什么证据会改变结论

同一树中新支付X在1日L付0、H付1；由(4)可用银行账户 $40/7$ 份、Z债−6份复制：L支付6−6=0，H支付6−5=1，0日成本 $40/7-6(55/63)=10/21$。真实P_H从1/4变3/4会改X的真实期望/风险补偿，却不改这些逐态等式，和上一课改变μ但call复制价不变相接。

若新增未被可交易支付张成的风险，复制价未必唯一，不能用“真实概率已知”补齐状态价格。[[社会科学/30-金融市场与风险/40-金融理论/80-实践/03-连续定价与期限综合/迁移题|三道综合题]]把连续漂移/错密度、这份X的矩阵头寸和硬币未张成支付串起来；[[社会科学/30-金融市场与风险/40-金融理论/80-实践/03-连续定价与期限综合/README#综合题完整答案|完整答案]]要求说明在哪个前提改变后失去唯一性，以及何种新报价或偏好/消费信息能缩小范围，不只运行函数。

现实若要分出预期与补偿，须另提供同日期/币种/日计数的无套利价格输入、真实短率历史或调查、P动态/测量误差模型、风险价格识别约束，并做事前窗口与样本外检验；预期误差、模型误设和流动性不能自动归成一个剩余溢价。结果是依赖这些约束的估计，不是曲线本身的直接读数。本课只留具体研究接口，没有获取实时曲线、运行真实资产研究或作投资建议。
