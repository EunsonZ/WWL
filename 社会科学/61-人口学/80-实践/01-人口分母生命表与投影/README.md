# 人口分母、生命表与投影：固定教学情景复算

这里支持[[社会科学/61-人口学/00-人口学-MOC|三篇人口主解释]]与[[社会科学/61-人口学/80-实践/01-人口分母生命表与投影/迁移题|撤提示新表题]]。全部输入是明确合成情景；没有拉取真实人口数据，没有参数拟合，没有随机个体或置信区间，更没有从精确分数推出真实医疗、婚育和迁移因果。

[inputs.json](inputs.json)固定期初与事件账、四个人暴露轨迹、两年龄组率、三组生命表和四年龄组投影。[demography.py](demography.py)是唯一程序真源，[[社会科学/61-人口学/80-实践/01-人口分母生命表与投影/code-sync/demography|源码镜像]]供笔记中读取。输出[results/results.json](results/results.json)逐项存精确有理数字符串；[results/life-years.svg](results/life-years.svg)只将同一组L/l0贡献画成条形图，图形坐标浮点不影响数值真源。改条件与答案独立核查应先自行推导，不能只让同一函数再跑一遍给自己盖章。

## 环境与复建

标准库Python 3.10+即可，无第三方安装。实际作者本机运行环境为CPython 3.14.7；独立核查者的结果另附原issue。本任务不升级系统、不下载依赖。整合到正式库后，从库根运行：

```bash
python3 社会科学/61-人口学/80-实践/01-人口分母生命表与投影/demography.py --out /private/tmp/population-rebuilt
```

默认输入为源码同目录inputs.json；可用`--input /你的合成输入.json`，原输入和已发布结果应保留。生命表比较接口限定两段连续有限年龄区间加一段开放末组，多一段或少一段会明确拒绝；支持在此结构内改变合法m/a/n和基数。`changed_tail`把当前输入的末组m乘2，`changed_early_timing`把第一段a设为当前n/4；图的年龄、贡献、总和及描述全部来自实际结果，显示标签取四位有效数字，精确值保留于JSON及SVG描述。实验只有20个步长的程序上限，是为避免误操作长跑，不代表真实人口预测最多400年。每步必须20年，因为四组年龄宽度固定。

本阶段共享数值资源的实际作者命令（2026-10-17，本机）为：

```bash
python3 /private/tmp/wwl-next-context/run_local.py --timeout 300 -- python3 /private/tmp/wwl-next-199/files/社会科学/61-人口学/80-实践/01-人口分母生命表与投影/demography.py --out /private/tmp/wwl-next-199/files/社会科学/61-人口学/80-实践/01-人口分母生命表与投影/results
```

这是当次候选运行路径；复建不依赖临时runner，可直接执行前一个命令。runner持有两个共享槽之一并设置单线程；源码本身无并行数值库。

## 外部未验接口

真实人口估计需要死亡登记和人口暴露按年龄/性别/地区对齐，处理漏报、删失、年龄误报、修订与迁移选择；若从生命表导入投影，还需年龄组内分布、出生时间与存活比转换。真实生育需女性人年、全部/女婴出生的口径和年龄率；这里的b/r不替TFR估计。公开方法已读，不表示真实原表已经复算。

未来运行这些接口，应固定数据取得日期、原表、代码与单位，先核守恒和覆盖，再给不确定性；当前没有输入的材料不能代填。此实验未认证真实迁移/医疗/婚育原因、未来概率分布、硬件、客户端/跨设备显示或真人学习效果。剩余完整人口课程见[[社会科学/61-人口学/00-人口学-MOC|课程入口的范围说明]]。
