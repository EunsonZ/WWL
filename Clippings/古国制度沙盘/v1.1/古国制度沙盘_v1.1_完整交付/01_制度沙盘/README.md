# 古国制度沙盘

这是一套用于政治文学与制度推演的虚构国家规则库。古国拥有与大型工业化大陆国家相近的人口、地区差异和公共治理复杂度，但古国的机关、部门、职位、法律、公共企业、商业企业、行政层级与项目名称全部原创。

## 使用边界

- `01_reality/` 保存截至 2026-08-18 核对的现实制度基线摘要及官方来源，只用于说明改革参照，不收录整部制度原文。
- 其余目录只讨论古国怎样改变和建立规则，不复制现实制度表述，也不使用现实机构、企业或法律专名。
- 每项古国制度分别说明改革理由、规则、可行性、过渡、公平性、收益、风险、救济、备选方案、失败处置和压力测试。
- 方案是可争辩的制度设计，不把预测写成事实；审议记录保留不同部门的质疑、答辩、总督裁决和少数意见。

## 推荐阅读顺序

先读 `00_导览与世界设定/`，再按兴趣进入制度目录；若要进行政策推演，先读 `12_transition_改革过渡与评估/`；若要写政治文学，再结合 `13_literary_toolkit_政治文学工具箱/` 的场景卡和案卷。
