## 环境与运行

在已安装 PyTorch 的独立 Python 环境中，进入本页所在目录。依赖只有 PyTorch 与 Python 标准库。安装方式按 [PyTorch 官方安装页面](https://pytorch.org/get-started/locally/) 选择适合操作系统的 CPU 版本，不要照搬不匹配的 CUDA 安装命令。本轮实际环境与测试结果见 [[AI/90-资源/06-修订与验收报告]]，不把文档网站的版本号当成运行版本。

```bash
python -m unittest discover -s . -p 'test_*.py' -v
python train_cnn.py --epochs 10
```

默认 CNN 模型文件写入临时目录，结束后清理。要保留结果，可显式指定知识库以外的目录：

```bash
python train_cnn.py --epochs 10 --output /你自己的实验目录/cnn-lines
```

输出为 `metrics.json`、训练/验证损失曲线 `history.svg`、带预测的像素样本图 `samples.svg` 与本次自己生成的 `model.pt`。不要用本实验加载来历不明的 checkpoint。脚本以 `weights_only=True` 读取自己保存的权重，但这不构成对任意恶意文件的安全承诺。

## 固定算例与当前回归入口

`test_core.py` 原有20个核心测试方法，新增CNN数据配置/重复种子、shape/参数/字节账及图报告接口回归；当前方法数量只是AST定义数，不能作为新运行次数。原有方法覆盖：张量广播与视图、标量反向传播与数值梯度、模块注册、卷积互相关及形状/参数量、感受野与残差导数、在线 softmax 的分块等价性与数值稳定性、缓存偏移因果掩码、MLA 内容分支的矩阵吸收、全局 token 加权、CTC 折叠次序、扩散代数重建、配对 flow 路径，以及 logits 与交叉熵。

这些测试检查特定数学条件下的小例与实现一致，不是对所有输入、所有 dtype、所有硬件的证明。在线 attention 实现没有 padding 或因果 mask；实际缓存例另用显式掩码的 SDPA 验证。MLA 测试不包含 RoPE 分支，也没有真实模型参数。DDP 例检查归一化代数，不启动多进程通信。扩散实验使用已知噪声重建输入，不代表已经学会去噪。

阅读 [[AI/20-LLM/40-推理/06-FlashAttention在线Softmax与SDPA掩码]] 时先看测试怎样比较完整与分块结果；阅读 [[AI/20-LLM/20-架构/08-MLA低秩缓存与位置解耦]] 时先确认每个矩阵的维度，再调换计算次序。

## CNN 为什么先用横线和竖线

输入是带噪声的单通道 $16\times16$ 图像，标签为横线或竖线。训练、验证、测试分别用独立随机种子生成，样本数为 256、128、128。模型用两层卷积提取方向特征，经全局平均池化和线性层分类。训练时交叉熵直接接收 logits。

验证集只用于选择最低验证损失的 epoch；测试集只在训练与选择完成后用于最终指标、样本预测和检查点往返核对。保存最佳参数使用深拷贝，防止后续优化悄悄覆盖“最佳模型”。再次加载后，程序逐元素检查同一输入的输出与保存前完全一致。

跑通后改变噪声强度、线宽、缺口、旋转角度或位置范围，观察分布变化的影响。原始标签只定义水平/垂直，任意角度旋转后的标签未必仍有意义。不要把近乎完美的合成测试准确率误当作真实视觉能力。

## 对同一 CNN 改输入，并读清资源账

公开入口为 `--noise`（标准差，有限且非负）、`--position-min/--position-max`（0..15的闭区间，min<=max）、`--seed`。默认.15、3..12、2026保持原分布；split种子为seed-2015/seed-2004/seed-1993，shuffle为seed-1982，默认即11/22/33/44，故seed须在[2015,2**63)。线长固定12，在另一维覆盖索引2..13；位置0/15允许边缘线。样本像素有正负噪声，不能假定已夹到[0,1]。

选模后报告config、所有test预测与错误索引、前8张test样本及至多8张错误样本（像素/标签/logits/预测）、history、torch版本与参数数。无错误时error_samples是空列表，不能编造错误示例。样本图显示时把像素映射夹到[0,1]灰阶；metrics.json保留原始未截断值。图只可视化报告，loss曲线按训练/验证角色分开，test不参与epoch选择。

| 层 | batch1 shape | 参数 | FP32裸张量字节 |
| --- | --- | ---: | ---: |
| 输入 | [1,1,16,16] | 0 | 1024 |
| conv1 1→8，3×3，s1,p1 | [1,8,16,16] | 8×(1×9+1)=80 | 8192 |
| conv2 8→16，3×3，s1,p1 | [1,16,16,16] | 16×(8×9+1)=1168 | 16384 |
| GAP | [1,16,1,1] | 0 | 64 |
| Linear | [1,2] | 2×(16+1)=34 | 8 |

总参数1282；ReLU不增加参数且不改shape。字节按元素×4，只数单个裸张量，不相加冒充峰值，不含训练图/梯度/AdamW状态、allocator、workspace或checkpoint。

沿单轴从r=1,j=1开始，`r_new=r+(k-1)j`、`j_new=js`：conv1得到r=3,j=1，conv2得到r=5,j=1。内部conv2像素(p,q)覆盖输入[p-2,p+2]×[q-2,q+2]的5×5；例如中心(8,8)覆盖行列6..10，平移到(8,9)覆盖行6..10、列7..11。边缘需裁到0..15，越界位置是padding零值。GAP聚合所有空间位置，其后logits可依赖整张有效输入，不可说整图分类器只有5×5感受野。原模型全程stride1，没有stride>1下采样相位；有关混叠的迁移解释见 [[AI/15-卷积神经网络/05-采样混叠感受野与平移鲁棒性|采样、感受野与平移边界]]，shape/共享参数推导见 [[AI/15-卷积神经网络/01-卷积互相关形状与参数共享|卷积shape与参数共享]]。

以下是留下的运行接口，本次未执行CNN、模型或测试：

```bash
# A：默认分布，重新训练并按valid选择
python train_cnn.py --epochs 10 --seed 2026 --output /你自己的实验目录/cnn-A
# B：在更高噪声、边缘位置分布重新训练；与A比较的是整个训练情景
python train_cnn.py --epochs 10 --seed 2026 --noise .30 --position-min 0 --position-max 15 --output /你自己的实验目录/cnn-B
# C：训练/valid仍用默认分布，只在最终test改变分布
python train_cnn.py --epochs 10 --seed 2026 --test-noise .30 --test-position-min 0 --test-position-max 15 --output /你自己的实验目录/cnn-C
python -m unittest -v test_core.py
```

A/B不回答“固定模型分布偏移”的问题；A/C有相同训练、验证与shuffle种子，后者的test配置不影响选模。实际版本、曲线、预测与准确率须由未来运行报告填写，目前状态notrun；不预报数值收益，不外推GPU、真实图像或跨设备逐位一致性。

## 练习与解释要求

把目标张量从 `[B]` 改成 `[B,1]`，先预测哪里应当报错、哪里可能发生意外广播，再运行。把缓存掩码换成未经偏移的上左三角形，观察它与完整因果注意力的结果为何不同。将在线注意力的块归一化后直接平均，构造两个分数尺度不同的块，解释输出为何不再相等。

自检不是“命令返回 0”就结束：每个通过或失败的断言，都应能回到张量形状、概率归一化或数学假设上解释。
