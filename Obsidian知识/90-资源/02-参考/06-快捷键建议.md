# 快捷键建议

> [!abstract] 先学命令，再记快捷键
> 按 `Cmd/Ctrl + P` 打开 Command Palette，模糊搜索任何命令；只有一周内反复执行的 3–5 个动作才值得分配快捷键。最终状态以 **Settings → Hotkeys** 为准。

## 四个入口先分清

| 入口 | 默认/常用键 | 回答的问题 |
| --- | --- | --- |
| Command Palette | `Cmd/Ctrl + P` | “我要执行什么动作？” |
| Quick Switcher | `Cmd/Ctrl + O` | “我要打开或创建哪篇笔记？” |
| Search | `Cmd/Ctrl + Shift + F` | “哪些文件包含这段内容或满足条件？” |
| Hotkeys 设置 | Command Palette 搜索 `Hotkeys` | “我要把哪个命令固定到某组按键？” |

`Cmd` 指 macOS；`Ctrl` 指 Windows/Linux。非美式键盘布局下，Settings 中显示的符号可能按美式布局标注，但 Obsidian 仍按实际按键工作。

## 推荐先掌握

| 动作 | 常见默认键/入口 | 为什么高价值 | 移动端替代 |
| --- | --- | --- | --- |
| 打开 Command Palette | `Cmd/Ctrl + P` | 不必记菜单位置；可发现插件命令 | 从顶部下拉 Quick Action（默认）或 Open menu |
| 打开 Quick Switcher | `Cmd/Ctrl + O` | 快速打开、创建和切换笔记 | 未编辑时点底部中央加号 |
| 全 Vault 搜索 | `Cmd/Ctrl + Shift + F` | 找正文、路径、标签、任务和属性 | 左侧栏 Search 或 Command Palette |
| 切换编辑/阅读视图 | `Cmd/Ctrl + E`（以本机 Hotkeys 为准） | 观察 Markdown 源码和渲染结果 | More options/视图命令，可加入移动工具栏 |
| 添加文件属性 | `Cmd/Ctrl + ;` | 快速进入 Properties | 笔记 More options → Add file property |
| 打开内部链接到新标签 | `Cmd/Ctrl` + 点击/Enter（视上下文） | 保留当前位置作对照 | 长按链接后选择打开方式 |
| 关闭对话框/取消选择 | `Esc` | 离开编辑状态、关闭面板、取消 Canvas 选择 | 点返回/面板外部；不同视图略有不同 |

> [!note] 自动保存
> Obsidian 会持续把本地笔记写入文件；`Cmd/Ctrl + S` 不应被当成备份。独立备份、File Recovery、Git 和 Sync 是不同层次。

## 系统编辑快捷键

这些通常由操作系统或 Obsidian 底层框架提供，不一定能在 Settings → Hotkeys 中改。

| 动作 | Windows/Linux | macOS |
| --- | --- | --- |
| 复制 / 剪切 / 粘贴 | `Ctrl+C / X / V` | `Cmd+C / X / V` |
| 无格式粘贴 | `Ctrl+Shift+V` | `Cmd+Shift+V` |
| 撤销 / 重做 | `Ctrl+Z / Ctrl+Shift+Z`（部分系统也用 `Ctrl+Y`） | `Cmd+Z / Cmd+Shift+Z` |
| 全选 | `Ctrl+A` | `Cmd+A` |
| 粗体 / 斜体 | `Ctrl+B / Ctrl+I` | `Cmd+B / Cmd+I` |
| 删除前一个词 | `Ctrl+Backspace` | `Option+Backspace` |
| 到行首/行尾 | `Home / End` | `Cmd+← / Cmd+→` |
| 到笔记首/尾 | `Ctrl+Home / Ctrl+End` | `Cmd+↑ / Cmd+↓` |

### 编辑器内通用动作

| 动作 | 键 | 备注 |
| --- | --- | --- |
| 新段落/列表下一项 | `Enter` | Markdown 渲染的段落还需要空行 |
| 同段换行/列表项内换行 | `Shift+Enter` | 不创建新的列表编号 |
| 增加/减少列表缩进 | `Tab / Shift+Tab` | 先把光标放在列表项中 |
| 复制整段 | 未选择文字时 `Cmd/Ctrl+C` | Obsidian 编辑器的便利行为 |
| 剪切整段 | 未选择文字时 `Cmd/Ctrl+X` | 先确认光标所在段落 |
| 删除当前行 | `Cmd/Ctrl+Shift+K` | 无选区时；先在练习页验证 |

## 建议的自定义层

以下只是**示例组合**，本 Vault 不应替用户强行预配置。添加前在 Settings → Hotkeys 搜索冲突，并在当前键盘布局试按。

| 优先级 | 命令 | 示例组合 | 适用人群 |
| ---: | --- | --- | --- |
| 1 | Daily notes: Open today's daily note | `Cmd/Ctrl + Alt + D` | 每天用日记捕获 |
| 2 | Templates: Insert template | `Cmd/Ctrl + Alt + T` | 高频创建结构化笔记 |
| 3 | Graph view: Open local graph | `Cmd/Ctrl + Alt + G` | 链接整理与局部探索 |
| 4 | Backlinks: Open backlinks for current note | `Cmd/Ctrl + Alt + B` | 研究/写作时固定上下文 |
| 5 | QuickAdd: Run QuickAdd | `Cmd/Ctrl + Alt + Q` | 已完成 QuickAdd 安全配置后 |
| 6 | Tasks: Create or edit | `Cmd/Ctrl + Alt + Enter` | 使用 Tasks 的用户 |

### 为什么用两个修饰键的三键组合作为示例

- 与操作系统/编辑器的常用两键组合冲突较少。
- 不会把单个字母或普通输入动作抢走。
- 缺点是较难按；真正高频后可换成更短组合。

不要照抄别人的快捷键表：输入法、窗口管理器、浏览器式标签页、IDE/Vim 模式和辅助功能软件都会改变冲突情况。

## 按工作流选择，不按插件数量选择

### 收集

- 打开今天的日记
- 插入模板
- QuickAdd 单一 Capture

### 整理

- Quick Switcher
- Move current file to another folder（按需自定义）
- Add internal link
- Extract current selection（Note composer）

### 检索

- Search
- Backlinks
- Local Graph
- Bookmark current item

### 回顾

- Open today's daily note
- Open weekly review（若由模板/插件提供）
- Random note（轻量偶遇，不能替代计划复习）

## 移动端：用动作面板代替背键

移动端的重点不是复制桌面快捷键，而是把 4–8 个关键动作放到拇指可达位置。

| 桌面习惯 | 移动端实现 |
| --- | --- |
| `Cmd/Ctrl + P` | 顶部下拉 Quick Action；默认 Command Palette |
| `Cmd/Ctrl + O` | 未编辑时点底部中央加号；或把 Quick Switcher 加入工具栏 |
| 格式化快捷键 | Customize mobile toolbar，加入粗体、链接、任务等 |
| 插件命令 | Settings → Mobile → Manage toolbar options → Add global command |
| 右键菜单 | 长按文件、链接、标签页或列表项 |
| 左右侧栏 | 导航栏/Open menu 中打开隐藏侧栏，再用下拉切换视图 |

### 建议的移动工具栏顺序

1. Toggle keyboard
2. Undo / Redo
3. Add internal link
4. Toggle checkbox status
5. Indent / Unindent list
6. Command palette
7. Open today's daily note
8. 一个确实高频的插件命令

工具栏可以横向滑动。数量过多会让真正高频动作更难找到。

## 设置快捷键的安全流程

1. 在 Command Palette 找到命令，先执行几次确认名称和效果。
2. Settings → Hotkeys 搜索该命令。
3. 点击 `+`，按下组合；检查冲突提示。
4. 在 Source、Live Preview、Reading view 和不同焦点位置测试。
5. 插件命令还要在插件禁用后观察：不要让关键工作流只剩一个失效快捷键。
6. 桌面与移动、Windows 与 macOS 分别验证；不要假设配置和键位完全等价。

## 常见问题

| 症状 | 原因/处理 |
| --- | --- |
| 按键无反应 | 焦点可能在属性、搜索、Canvas 或模态框；先按 `Esc`，再试 |
| 输入文字却触发命令 | 自定义键过短或与输入法/Vim 冲突；移除并换双修饰键的三键组合 |
| 快捷键显示符号不对 | 非美式键盘显示差异；按实际键重新录入 |
| 插件升级后命令消失 | 插件禁用/改名/不兼容；从 Command Palette 重新确认命令 |
| 移动端找不到 Ribbon | 移动端没有桌面 Ribbon；用 Open menu 和移动工具栏 |
| 快捷键越来越多记不住 | 删除低频键；Command Palette 才是长期通用入口 |
