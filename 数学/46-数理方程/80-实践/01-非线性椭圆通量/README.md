# 非线性椭圆通量：解析剖面与小网格

[[数学/46-数理方程/30-正则性与非线性演化/04-单调算子与非线性椭圆弱解|正文]]先证明一般纯 $p$-Laplace 弱解存在唯一，再从常源一维模型导出帽函数通量平衡。本实验实际求这个有限维非线性方程；解析公式只作对照。要回答的不是“残差是否接近零”一个问题，而是：相邻单元怎样守恒，整条折线距弱解多远，改变 $p$ 后梯度误差为什么与函数误差不同。

规范源码为 [elliptic_flux_lab.py](elliptic_flux_lab.py)，输入为 [inputs.json](inputs.json)，[build_figures.py](build_figures.py) 读取同次结果CSV与summary参数快照，生成SVG。完整同版镜像为 [[数学/46-数理方程/80-实践/01-非线性椭圆通量/code-sync/elliptic_flux_lab|求解源码]]、[[数学/46-数理方程/80-实践/01-非线性椭圆通量/code-sync/build_figures|图源]]、[[数学/46-数理方程/80-实践/01-非线性椭圆通量/code-sync/numerical_guard|数值运行护栏]]。源码是代码真源。

## 输入对象与允许改变的范围

所有量无量纲。`length=L`，`source=F`，`boundary=zero_dirichlet`；不接受任意边界函数或非恒源卡。数学定理覆盖全部 $1<p<\infty$，可执行卡为有限预算窗口 `1.25<=p<=6`，不能把程序窗口当成理论限制。

| 项 | 默认值与边界 |
| --- | --- |
| `p_values` | `[1.5,2,3,4]`，至多8个不同有限数 |
| `cells` | `[8,16,32,64]`，每个整数2–256，允许奇数；总组合至多32 |
| `length`, `source` | 1、1；$0.1\le L\le4$，$|F|\le8$，允许零源和负源 |
| `profile_points` | 601；整数33–2001，只控制保存的曲线采样，不控制求解网格 |
| `quadrature_abs_tol` | $10^{-10}$；范围 $10^{-12}$ 至 $10^{-6}$，作用于误差积分诊断 |
| `resonance_amplitudes` | `[0,1,2]`，至多8个不同有限数，绝对值至多8 |

重复JSON键、未知字段、布尔数值、非有限数、错误类型、重复项与超出上述预算的卡会被拒绝。零通量的前向/逆通量直接返回0，避免 $p<2$ 时先求零的负次幂。

生产算法把帽函数平衡写成 $q_j=c-F(j+1/2)h$，对 $h\sum_j\operatorname{sgn}q_j|q_j|^{1/(p-1)}=0$ 二分射击。浮点停止后还比较相邻候选与各单元的精确零通量候选，以实际右端残差择优；这避免奇数网格的零点附近将一ulp放大成可见边界误差。程序不强行把末节点改成0：端点残差超过 $10^{-11}\max(1,L\max|s_j|)$，或能量恒等残差超过 $10^{-10}\max(1,\text{左右能量绝对值})$，就明确失败。这是有限模型的数值验收，不能代替存在唯一证明。

## 输出中每一种误差回答什么

| 文件 | 实际列与用途 |
| --- | --- |
| [nodes.csv](results/nodes.csv) | `p,cells,node,x,u_h,u_exact,error`，节点比较 |
| [edges.csv](results/edges.csv) | 单元左右端、斜率、常通量、解析中点通量、本构残差 |
| [profiles.csv](results/profiles.csv) | `p,cells,x,u_h,u_exact,gradient_h,gradient_exact,q_h,q_exact`，分片函数/梯度/通量比较；单元端点按右侧单元保存，末端取最后一单元 |
| [resonance.csv](results/resonance.csv) | `amplitude,x,u,analytic_residual`，另一个算子在固定区间$0,1$上的 $A\sin\pi x$，不随本模型L改变 |
| [summary.json](results/summary.json) | 实际卡快照、射击常数、端点/通量/本构/能量残差、节点与曲线误差、积分估计及深度受限计数 |

函数误差为 $(\int|u_h-u|^2)^{1/2}$，梯度误差为 $(\int|u_h'-u'|^p)^{1/p}$。求解器在每单元积分，含中点的单元再拆成两段；自适应Simpson局部差值之和不是严格误差界，`quadrature_is_rigorous_error_bound` 明确为false。容差作用于误差的积分值，开方或开p次方后的范数不享有同一绝对容差。深度受限计数非零时应另核积分，不能只把容差写小就认证更多数字。

$p=2$ 另保存严格公式 `p2_exact_l2_error=|F|sqrt(L)h²/sqrt(120)`、`p2_exact_gradient_l2_error=|F|sqrt(L)h/sqrt(12)`。节点恰好一致时这两项仍非零；零源时所有解与误差才同时为零。`profile_sampled_max_error` 只指保存网格的最大值，不能替代连续上确界。

## 图怎样阅读与重建

[profiles.svg](results/profiles.svg) 的四幅图分别问：改变p怎样改变解析曲线、粗细网格距曲线多远、帽测试怎样平衡单元通量、改算子后共振怎样产生不同解。[convergence.svg](results/convergence.svg) 将函数和梯度误差分开；横轴log2N，非零误差用log10轴，零源安全退回线性误差轴。单网格卡用带编号标记的点，图例编号一致；所有标签从同次卡快照读取，线条同时用颜色和不同线型。

默认图中的共振算子是 $-u''-\pi^2u$，不是纯p-Laplace。其任意振幅都满足齐次问题，反映强制性与严格单调条件的缺失。图不能凭零残差认证唯一，也不能凭近似曲线认证一般正则性或一般有限元收敛阶。

## 先预测再迁移

复制卡，把 `length` 改2、`source` 改4，并取 `p_values=[3]`；先由正文公式预测峰值放大 $4\sqrt2$、端点通量放大8倍、梯度积分能量放大 $32\sqrt2$，再运行新目录。把源改成−4，应只使函数、梯度和通量反号。

再把网格改 `[15,30,60]`：中间单元通量为零时，真实梯度仍只在中点为零，必须比较整条梯度而非一个点。最后取零源，预测所有p的解、离散斜率与真实误差为零；共振图的非零振幅仍存在，因为它来自另一个算子。
