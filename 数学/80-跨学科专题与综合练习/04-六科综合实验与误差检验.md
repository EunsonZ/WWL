# 六科综合实验与误差检验

## 实验不是把结果打印出来就算完成

同一个结论可以得到三种不同证据：符号运算验证某个精确恒等式，数值计算检查给定输入，数学证明覆盖满足条件的全部对象。它们不能互相冒充。这里用27组公开输入的实验，将六科里的关键算例交叉核验；结果记录在 `90-资源/维护/综合实验验收.json`。

伴随源代码：[六科综合实验.py](六科综合实验.py)。它使用 NumPy、SciPy 和 SymPy，不访问网络，不读取私人数据。可从数学目录运行：

```bash
python "80-跨学科专题与综合练习/六科综合实验.py"
```

程序逐组记录通过或失败，失败时以非零退出码结束；不通过不应靠放宽容差掩盖，应先判断是定理、算例、离散化还是实现出了问题。环境与依赖版本写入报告，便于以后复现。

## 第一组主线：误差需要预测，不只是观察

对 $\int_0^1e^x\,dx=e-1$，使用 $n=8,16,32,64$ 的均匀分割。复合梯形在足够光滑时误差是 $O(h^2)$，Simpson 为 $O(h^4)$；所以步长减半，截断误差的比值应分别接近4和16。程序检查这一预测，而不是仅看曲线“下降”。继续细分会遇到舍入平台，不能用平台否认截断误差理论，也不能把理论阶数延伸到任意小步长。

条件数实验用 $A=\operatorname{diag}(1,10^{-6})$，$b=(1,0)^T$，扰动 $\delta b=(0,10^{-6})^T$。原解为 $(1,0)^T$，扰动后为 $(1,1)^T$，数据只改变百万分之一，解却改变1。这里不是算法粗心，而是问题把第二方向的信息压缩了百万倍。

## 第二组主线：同一个最优化词语对应不同问题

SVD 检查用 $A=\operatorname{diag}(4,2,1)$。秩一截断的 Frobenius 误差是 $\sqrt5$，二范数误差是2。矩阵 $B=\operatorname{diag}(b,0,0)$ 对所有 $2\le b\le6$ 都有二范数误差2，因此二范数最优解不唯一；这与 Frobenius 范数中存在奇异值间隙时的唯一性并不冲突。

投影实验先将 $x^2$ 投影到 $\operatorname{span}(1,x)$ 的 $L^2$ 内积，得到 $x-1/6$ 和误差平方 $1/180$。再用 $\int uv+\int u'v'$ 内积投影 $x^3$，得到 $-16/65+(129/130)x$。程序验证精确有理数，但为什么要解 Gram 方程、为何残差正交，需要回到 [[数学/80-跨学科专题与综合练习/01-投影从最小二乘到Fourier与有限元|投影专题]] 的推导。

## 第三组主线：先构造结构，再验证表达式

代数实验不仅计算特征值，还构造 $A=\begin{pmatrix}1&1&0\\0&1&0\\0&0&2\end{pmatrix}$ 的谱投影、循环基和矩阵指数。验证 $P^2=P$、投影相乘为零、$E'(t)=AE(t)$ 与 $E(0)=I$，比单独计算若干时刻的矩阵更有信息。

Smith 实验验证 $\begin{pmatrix}t&1\\0&t\end{pmatrix}$ 的非单位因子为 $t^2$。软件可能输出相伴元 $-t^2$；这是单位因子归一化的差别，不是不同的模分类。程序因此比较相伴关系，并在正文中统一首一约定。

复变实验分别精确求留数、以离散围道积分核验零点计数，并数值检查 Poisson 核质量。离散围道可能漏掉贴近边界的尖峰；本例零点数的严格依据仍是 Rouché 定理，不是“计算结果接近整数”。

## 第四组主线：数理方程必须检查数据和能量

对热方程，验证函数满足 PDE、零边界和指定的非齐次项；对波方程，验证残差与能量守恒。Green 函数检验连续性和导数跳跃 $-1$，以确认它对应 $-d^2/dx^2$ 而不是相反符号。Robin 实验的负特征值还要检查边界残差，而不只找到一个代数根。

有限元例子是 $-u''=1$、$u(0)=u(1)=0$，真解为 $u=x(1-x)/2$。均匀分段线性有限元在本例恰好给出真解节点值，但单元内部仍有误差。因此“节点误差接近零”不能代表函数整体误差为零。

在一个单元上用局部变量 $s\in[0,h]$，真解与线性插值之差为 $s(h-s)/2$，导数差为 $h/2-s$。直接积分并累加 $1/h$ 个单元得
$$\|u-u_h\|_{L^2}=\frac{h^2}{\sqrt{120}},\qquad \|u'-u_h'\|_{L^2}=\frac{h}{\sqrt{12}}.$$
程序解线性系统，再用 Gauss 积分独立核验这两条误差公式，不直接把公式数值当成测量结果。

## 实验覆盖与限制

27组检查涵盖 Taylor、积分阶数、Jacobian、法向与通量、投影、收敛尖峰、Fubini 反例、含参积分、QR、SVD、条件数、Schur、Jordan、Smith、模逆、留数、围道、Poisson、Fourier、热波、Green、Robin、曲率与挠率、变分、有限元和显式格式稳定性。完整参数、实际误差与环境见机器可读报告。

另外，原有七个应用实验由 `90-资源/维护/运行原始实验.py` 独立执行，检查正文代码同步和部分非法输入。教学程序不是经过生产认证的数值库；极端范围、超大规模和未声明的输入类型需要单独测试。

## 自测与扩展

把有限元真解改成 $u=\sin(\pi x)$，右端也必须相应改成 $\pi^2\sin(\pi x)$。预测能量误差与 $L^2$ 误差的阶数，然后改变网格。不要只替换真解而忘记右端，制造一个“程序不收敛”的假问题。

> [!question]- 解答与检验路线
> 在线性单元、足够光滑解和此规则一维问题下，应观察能量误差一阶、$L^2$ 误差二阶。载荷积分需要足够精度；节点不再依赖本例二次多项式的特殊积分结构来判断整体误差。连续减半网格，比较误差比值接近2与4，再区分舍入平台和渐近区间。
