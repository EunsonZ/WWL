# 控制流、函数与作用域

程序不是从第一行机械地走到最后一行：**控制流**决定“走哪条路、重复几次、何时停止”；**函数**把一件有名字的工作封装起来；**作用域**决定某个名字在何处可见、赋值又会改到哪里。本课用 Python 3.10+ 的语法示例说明这些边界。

> [!abstract] 本课目标
> 完成本课后，你能：
>
> - 用 `if`、循环和函数写出可读的处理流程；
> - 判断何时适合（或不适合）使用 `match`；
> - 正确解释循环的 `break`、`continue` 和 `else`；
> - 设计清楚的函数参数与返回值，并避开可变默认参数；
> - 按 LEGB 顺序定位变量，谨慎使用 `global` 与 `nonlocal`。

## 1. 用条件表达业务分支

`if` 的条件为真时执行其代码块；`elif` 依次检查后续条件；`else` 处理前面都不成立的情形。一个链中可以没有 `elif`，`else` 也可省略；一旦某个分支执行，后面的分支不会再检查。

```python
score = 86

if score < 0 or score > 100:
    grade = "输入无效"
elif score >= 90:
    grade = "A"
elif score >= 60:
    grade = "及格"
else:
    grade = "需要补考"

print(grade)  # 及格
```

把条件从“异常或无效”写到“普通情形”，并让每个分支互斥，读者更容易验证覆盖范围。多个独立规则同时适用时，用多个 `if`，不要误写成 `elif`。

### `match`：适合描述形状，不是 `if` 的普遍替代

Python 3.10 新增的 `match` 是**结构化模式匹配**：从上到下尝试 `case`，仅执行第一个成功的模式，还可以把匹配到的组成部分绑定到名字。它很适合有限命令、不同数据形状、元组/字典的解包；若只是比较范围、组合复杂布尔条件或条件本身有副作用，`if` 通常更直接。

```python
def describe_command(command: object) -> str:
    match command:
        case ["open", filename]:
            return f"打开：{filename}"
        case ["quit"]:
            return "退出"
        case ["help", *topics]:
            return f"帮助主题：{', '.join(topics) or '总览'}"
        case _:
            return "无法识别的命令"


print(describe_command(["open", "notes.txt"]))  # 打开：notes.txt
```

> [!warning] 容易误解的捕获名字
> 在 `case name:` 中，裸名字通常是“捕获并赋值”，而不是与已有变量比较；它会匹配几乎任何值。常量应使用字面量、枚举成员等限定形式，例如 `case Color.RED:`。`case _:` 是明确的通配分支。

## 2. 重复：`for`、`while` 与 `range()`

`for` 逐项遍历可迭代对象（如字符串、列表、字典）；它不是 C 风格的计数器循环。需要数值序列时使用 `range()`：终点不包含在内，`range(start, stop, step)` 的 `step` 也可以是负数。

```python
names = ["Ada", "Guido", "Lin"]

for index, name in enumerate(names, start=1):
    print(index, name)

for number in range(5, 0, -1):
    print(number, end=" ")
print("开始！")
```

预期输出的前几行是 `1 Ada`、`2 Guido`、`3 Lin`，倒计时是 `5 4 3 2 1 开始！`。`range(5)` 产生 `0` 到 `4`；它是节省空间的可迭代对象，不会先创建整张数字列表。

`while` 在条件为真时重复，更适合“不知道次数、知道停止条件”的任务。循环必须让条件最终可能变为假，或在适当位置退出。

```python
attempts_left = 3
while attempts_left > 0:
    print(f"还可尝试 {attempts_left} 次")
    attempts_left -= 1
```

不要在遍历某个列表或字典时直接删改同一对象；先遍历副本，或建立新的结果集合。这样不会跳过元素或让逻辑难以推断。

### `break`、`continue` 与循环 `else`

- `break`：立即离开**最内层**的 `for` 或 `while`；
- `continue`：跳过当前轮剩余代码，开始下一轮；
- 循环的 `else`：仅当循环自然结束、从未执行 `break` 时运行。`return` 或异常提前离开也不会运行它。

这使得“查找成功就停止，否则报告未找到”可以紧凑而准确地表达：

```python
def find_first_even(values: list[int]) -> int | None:
    """返回第一个偶数；若没有则返回 None。"""
    for value in values:
        if value % 2 == 0:
            break
    else:
        return None  # 循环结束而没有 break
    return value


assert find_first_even([-3, -4, 8, 10]) == -4
assert find_first_even([1, 3, 5]) is None
```

循环 `else` 与“循环最后一轮的 `if ... else`”无关。若团队成员普遍不熟悉它，使用 `found = False` 或提取函数也可以换取更直白的可读性。

## 3. 定义函数：输入、工作与输出

`def` 后跟函数名和参数列表，缩进的代码块是函数体。调用函数会创建新的局部命名空间。`return expression` 立刻结束函数并把值交给调用方；没有写 `return`、或只写 `return`，结果都是 `None`。

```python
def total_price(unit_price: float, quantity: int, *, discount: float = 0.0) -> float:
    """计算折扣后的价格；discount 必须是 0 到 1 之间的小数。"""
    if unit_price < 0 or quantity < 0:
        raise ValueError("价格和数量不能为负数")
    if not 0 <= discount <= 1:
        raise ValueError("折扣必须在 0 到 1 之间")
    return unit_price * quantity * (1 - discount)


assert total_price(12.5, 4, discount=0.2) == 40.0
```

类型标注（如 `float`、`-> float`）是给读者、编辑器和类型检查工具的元数据；Python 默认不会因为标注而自动转换或检查实参类型。异常处理会在 [[计算机知识/10-编程语言/01-Python/05-异常文件IO与上下文管理|异常、文件 I/O 与上下文管理]] 中继续讨论。

### 参数种类与调用边界

```python
def configure(source, /, mode="safe", *items, timeout, **options):
    return source, mode, items, timeout, options


result = configure("config.toml", "fast", "a", "b", timeout=3, retry=2)
```

| 语法 | 名称 | 调用规则 | 适用场景 |
| --- | --- | --- | --- |
| `source, /` | 仅位置参数 | 不能写 `source=...` | 参数名不应成为公开 API，或与 `**options` 避免重名 |
| `mode` | 位置或关键字参数 | 可按位置或写 `mode="fast"` | 大多数普通参数 |
| `mode="safe"` | 默认参数 | 可以省略 | 稳定且无副作用的默认行为 |
| `*items` | 可变位置参数 | 收集额外位置实参为元组 | 接受不定数量的同类输入 |
| `*, timeout` | 仅关键字参数 | 必须写 `timeout=...` | 提高配置型参数调用的可读性 |
| `**options` | 可变关键字参数 | 收集额外具名实参为字典 | 转发受控选项；不要用它掩盖拼写错误 |

显式写出的普通位置实参必须在关键字实参之前；但 `*iterable` 可以写在关键字实参后，展开后仍先参与位置绑定。例如 `f(b=1, *(2,))` 合法，而 `f(a=1, *(2,))` 因 `a` 得到两个值而失败。同一个参数不能得到两个值。公开函数应优先选少量、名字清楚的参数；`*args`/`**kwargs` 只在“数量或选项确实开放”的边界使用。

### 默认参数的可变对象陷阱

默认值在**定义函数时**求值一次，而不是每次调用都重新建立。列表、字典等可变对象会被后续调用共享：

```python
def wrong_add(item: str, bucket: list[str] = []):
    bucket.append(item)
    return bucket


print(wrong_add("第一项"))  # ['第一项']
print(wrong_add("第二项"))  # ['第一项', '第二项']，通常不是想要的结果
```

用 `None` 表示“调用者没有提供容器”，再在函数内部创建新对象：

```python
def add(item: str, bucket: list[str] | None = None) -> list[str]:
    """把 item 加入本次调用的列表，除非调用者传入已有列表。"""
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket


assert add("第一项") == ["第一项"]
assert add("第二项") == ["第二项"]
```

## 4. LEGB：名字到哪里去找

读取一个未在当前块赋值的名字时，Python 按 **L → E → G → B** 查找：

1. **L（Local）**：当前函数的局部变量和参数；
2. **E（Enclosing）**：嵌套函数外层函数的局部变量；
3. **G（Global）**：模块顶层定义的名字；
4. **B（Built-in）**：内置名字，例如 `len`、`print`。

函数内只要对某名字赋值，Python 默认把它认作局部变量；即使全局已有同名变量也是如此。因此，下面的 `count += 1` 会在读取局部 `count` 前失败。

```python
count = 0

def broken_increment():
    count += 1  # UnboundLocalError：count 被认定为局部变量
```

通常更好的设计是把值作为参数传入、把新值作为返回值交出：

```python
def increment(current: int) -> int:
    return current + 1


count = increment(count)
assert count == 1
```

### `global` 与 `nonlocal`：明确、少量地改外层绑定

`global name` 声明后，赋值改的是模块全局绑定；`nonlocal name` 声明后，赋值改的是最近一层已有该名字的外层函数绑定。它们必须在函数中相应名字被使用或赋值之前出现；`nonlocal` 找不到外层绑定会报错。

```python
def make_counter():
    total = 0

    def next_number() -> int:
        nonlocal total
        total += 1
        return total

    return next_number


counter = make_counter()
assert (counter(), counter()) == (1, 2)
```

闭包的私有计数器是 `nonlocal` 的合理小范围用法。`global` 会让任意调用点共享并改变模块状态，难测试也难并发推理；除初始化、受控缓存等少数情形外，优先传参和返回值。也不要把变量命名为 `list`、`id`、`len` 等内置名，否则会遮蔽 B 层名字。

## 5. `lambda` 和文档字符串

`lambda` 创建一个匿名函数，但函数体在语法上只能是**一个表达式**。它适合在需要函数对象的地方写很短、显而易见的转换或排序键：

```python
people = [("Ada", 36), ("Lin", 28), ("Guido", 69)]
by_age = sorted(people, key=lambda person: person[1])
assert by_age[0] == ("Lin", 28)
```

一旦需要分支、局部变量、异常说明、可复用测试或清晰名字，就写 `def`。不要为了“一行”把业务逻辑塞进嵌套 `lambda`；普通函数可读、可调试，也可写文档字符串。

文档字符串（docstring）是函数、类或模块体中的第一个字符串字面量，可通过 `对象.__doc__` 取得，并供 `help()`、IDE 和文档工具使用。为公开或会复用的函数写一句“做什么”的概述；需要补充参数、返回值、副作用和异常时，用空行隔开后续说明。

```python
def normalize_name(name: str) -> str:
    """规范化显示名称。

    删除首尾空白，并把每个单词转换为首字母大写。
    空字符串会返回空字符串。
    """
    return name.strip().title()


assert normalize_name("  ada lovelace ") == "Ada Lovelace"
assert "规范化" in normalize_name.__doc__
```

## 6. 一次可运行的综合练习

把下列代码保存为 `control_flow.py`，在终端运行 `python3 control_flow.py`。它把分支、`match`、`for`/`continue`、函数返回值和 docstring 放在同一个小程序中。

```python
def classify_readings(readings: list[object]) -> tuple[int, int]:
    """返回有效读数的总和和数量；未知格式会被忽略。"""
    total = 0
    valid_count = 0

    for reading in readings:
        match reading:
            case bool():
                continue  # bool 是 int 的子类，但本读数模型不把布尔值视为整数读数
            case int(value) if value >= 0:
                pass  # value 已经可用
            case {"value": int(value)} if not isinstance(value, bool) and value >= 0:
                pass
            case _:
                continue

        total += value
        valid_count += 1

    return total, valid_count


total, count = classify_readings([3, {"value": 5}, True, -1, "未知", {"value": -2}])
assert (total, count) == (8, 2)
assert classify_readings([{"value": True}, {"value": False}]) == (0, 0)
assert classify_readings([{"value": 0}, 2]) == (2, 2)
print(f"有效读数 {count} 个，总和 {total}")
```

### 动手练习

1. 为 `classify_readings` 增加对 `{"value": 0}` 的测试，确认它仍被计入。
2. 增加规则：`{"skip": True}` 应被忽略。用 `case {"skip": True}:` 写在通用字典模式之前，并用 `assert` 验证。
3. 写 `find_name(names, target)`：用 `for ... else` 返回第一次出现的下标；找不到时返回 `None`。为“首项命中”“末项命中”“不存在”各写一个断言。
4. 将一个使用 `global` 的计数示例重构为“传入旧值、返回新值”的函数，并说明为什么后者更易测试。

### 成功标准

- [ ] 我能区分“循环结束”和“执行过 `break` 后结束”，并预测循环 `else` 是否运行。
- [ ] 我不会把 `case name:` 当作普通常量比较。
- [ ] 我能根据调用方式区分位置、关键字、仅位置、仅关键字、`*args` 和 `**kwargs`。

## 7. 常见错误诊断

| 现象 | 常见原因 | 检查与修复 |
| --- | --- | --- |
| `SyntaxError: invalid syntax` 指向 `match` | 解释器低于 Python 3.10 | 运行 `python3 --version`；升级解释器，或临时改用 `if`/字典分派 |
| `TypeError: ... got multiple values for argument` | 同一参数既按位置又按关键字传入 | 只保留一种传法；检查可变参数之前的普通参数 |
| 第二次调用函数时列表里有旧内容 | 可变默认参数只创建了一次 | 默认值改为 `None`，函数内部再创建列表/字典 |
| `UnboundLocalError` | 函数内赋值使名字成为局部变量，却先尝试读取它 | 传入并返回值；必要时明确 `global` 或 `nonlocal` |
| 循环 `else` 没有执行 | 执行了 `break`，或通过 `return`/异常提前离开 | 确认 `else` 与循环同级缩进，追踪每条提前退出路径 |
| `while` 永不停止 | 循环条件相关状态没有改变，或改变方向错误 | 在循环中打印/断言状态；优先改成有明确上界的 `for range(...)` |
| `case RED:` 行为反常 | `RED` 是捕获变量而非常量 | 使用字面量、`EnumMember` 的限定名或 guard；不要用裸名字表示常量 |
