# 社保、医疗、教育、养老与社会救助：现实制度基线

## 核对范围与日期

- 核对截止日：**2026年8月18日**。
- 范围包括基本社会保险、退休、基本医疗卫生与医疗保障、教育、养老服务、长期护理、社会救助，以及户籍和居住证对公共服务取得的交叉影响。
- 本文核对全国法律、行政法规和中央政策；具体缴费率、待遇、招生条件、救助标准和服务清单大量由省市确定，未用单一地方规则代替全国基线。
- 对2026年新施行的社会救助法、正在全国建立但分期落地的长期护理保险，均单列时间状态。

## 制度状态

| 领域与文件 | 截止日状态 | 基线意义 |
|---|---|---|

| 《社会保险经办条例》 | **已于2023年12月1日施行** | 统一经办、关系转移、信息查询、基金安全和便民服务要求 |
| 企业职工养老保险全国统筹 | **自2022年起实施的制度安排** | 加强全国调剂和统筹，但不表示所有地方参数和经办完全一致 |

| 《教育法》《义务教育法》《职业教育法》 | **现行法律** | 构成教育、九年义务教育和职业教育基本结构 |
| 《学前教育法》 | **已于2025年6月1日施行** | 学前教育首次形成专门全国法律 |

| 国家基本养老服务清单 | **2023年起实施的政策清单** | 确定面向特定老年群体的国家基本服务项目，不等同于全民统一充分待遇 |

| 《社会救助法》 | **已于2026年7月1日施行** | 成为社会救助领域的基础性法律，扩大对象并统一基本程序 |
| 《社会救助暂行办法》 | **既有行政法规和操作基线** | 配套规则需依新法继续清理、修订；与新法不一致处以法律为准 |
| 《户口登记条例》 | **1958年由全国人大常委会通过的现行法律性文件**，并非国务院行政法规 | 户籍登记仍影响部分公共服务的申请地和地方财政责任 |
| 《居住证暂行条例》 | **国务院行政法规**，自2016年1月1日起施行 | 常住地登记连接部分基本公共服务与办事便利 |
| 2024年新型城镇化五年行动计划 | **政策规划** | 要求放开放宽多数城市落户并推进按常住地提供基本公共服务，不是直接赋权法律 |

## 现行结构摘要

### 1. 社会保险与退休

基本社会保险由用人单位、个人和财政按不同险种共同筹资。职工通常参加职工养老和职工医保，用人单位同时承担工伤、失业、生育等法定义务；城乡居民可参加居民养老和居民医保。企业职工基本养老保险已实行全国统筹，城乡居民养老和多项待遇仍有地方差异。

渐进式延迟退休自2025年启动：男职工法定退休年龄在过渡期内由60岁逐步延至63岁，原50岁和55岁退休的女职工分别逐步延至55岁和58岁；2030年起领取基本养老金最低缴费年限由15年逐步提高至20年。符合条件者可在规定范围内弹性提前或延后退休。

### 2. 医疗卫生与医疗保障

医疗卫生法确立政府发展公共卫生和基本医疗服务、建设医疗服务体系及保护健康权的基本责任。医疗费用保障主要由职工基本医保、城乡居民基本医保、大病保险、医疗救助和补充保障组成。职工医保建立门诊共济，并逐步扩大个人账户家庭共济；跨地区就医直接结算持续推进，但筹资、起付线、封顶线和目录执行仍由统筹地区具体确定。

### 3. 教育

国家实行九年义务教育，义务教育以县级政府管理和财政保障为重要基础。学前教育、高中阶段、职业教育和高等教育分别由法律政策调整。城乡义务教育经费保障机制已统一，“双减”政策限制义务教育阶段过重作业和学科类校外培训。随迁子女在居住地接受义务教育的渠道持续扩大，但人口高度流入地区仍可依据承载能力设置具体条件。

### 4. 养老服务与长期护理

老年保障由家庭赡养、基本养老保险、医疗保障、基本养老服务和市场、社会服务共同承担。国家基本养老服务清单主要保障特定困难、高龄、失能等群体。2026年长期护理保险进入全国建制阶段，参保、筹资、失能评估、待遇、服务机构和支付规则由各省分步制定，因此现实中仍处于地区制度并行和过渡状态。

### 5. 社会救助

2026年社会救助法把特困人员、最低生活保障家庭、低保边缘家庭、刚性支出困难家庭、受灾人员、急难人员等纳入分层分类体系，救助包括基本生活、医疗、教育、住房、就业、灾害、临时和疾病应急等类型。县级政府应建立一门受理、协同办理，民政等部门通过家庭经济状况核对进行资格确认，并承担个人信息保护责任。

### 6. 户籍、居住证与公共服务

户口登记由公安机关管理，居住证用于证明常住人口身份、获取规定的基本公共服务并申请落户。国家政策已要求城区常住人口300万以下城市取消落户限制、300万至500万城市全面放宽、500万以上超大特大城市优化积分落户，并逐步按常住地提供服务。但教育、住房保障、救助和部分待遇的申请条件仍需查看地方细则。

## 关键制度接口

| 接口 | 现实运行要点 | 关键可核验材料或指标 |
|---|---|---|
| 劳动关系—社会保险 | 是否建立劳动关系影响职工险种、缴费责任和追缴路径 | 合同、工资、参保缴费、用工控制、补缴情形 |
| 地区流动—保险接续 | 跨地区就业、退休和就医需要关系转移及信息互认 | 缴费年限、个人账户、统筹地、转入转出时长 |
| 退休—就业 | 达到退休年龄、最低缴费年限和继续工作安排相互作用 | 出生和岗位信息、累计缴费、弹性退休协议、劳动关系状态 |
| 基本医保—医疗救助 | 基本医保报销后个人负担可能进入大病保险或医疗救助 | 合规费用、目录内外支出、起付线、封顶线、家庭经济状况 |
| 医保支付—医疗质量 | 医保支付方式影响医院收治、检查、住院时长和成本 | 病组支付、再入院、并发症、拒收转院、患者自付 |
| 户籍居住—教育 | 常住地、居住证、住房和社保材料可能影响入学和升学 | 招生方案、学位供给、申请材料、分流和申诉数据 |
| 教育—就业与社保 | 职业教育、高校毕业和就业质量影响长期缴费和流动 | 学分互认、就业去向、起薪、参保率和地区流动 |
| 养老保险—养老服务 | 现金养老金与照护服务是不同制度，不能相互替代 | 养老金水平、服务可得性、照护费用、家庭负担 |
| 医保—长期护理保险 | 医疗治疗与长期生活照料需要明确支付边界 | 失能评估、护理项目、医疗必要性、重复支付审查 |
| 长护险—家庭照护 | 制度可支付机构、上门服务或家庭照护支持 | 评估等级、照护计划、照护者补贴、复评和申诉 |
| 社会救助—其他福利 | 救助资格可能联动医疗、教育、住房和就业支持 | 家庭收入财产、刚性支出、共享认定、退出和缓退规则 |
| 户籍—社会救助 | 多类救助原则上由户籍地受理，急难救助更强调发生地 | 申请地、居住证、跨地核查、转介时间和拒绝理由 |

## 可观察约束与信息缺口

1. 职工与居民两类养老、医疗制度的筹资和待遇差异明显；全国统筹并不意味着所有地区缴费参数、报销待遇和经办规则完全一致。
2. 灵活就业、平台就业、间断就业人员可能在职工保险缴费负担、连续性和职业伤害保障上面临缺口，公开覆盖率不能直接说明待遇充分性。
3. 养老基金公开信息以年度收支为主，长期精算假设、代际负担、地区调剂和管理费用缺少统一、易比较的长期报告。
4. 职工医保和居民医保待遇差异、统筹地区差异、目录外费用及异地手续会共同影响实际自付；公开口径较难完整呈现家庭灾难性卫生支出。
5. 医保支付改革强调控费和效率，但拒收高风险患者、过早出院、转院和照护质量需要独立结果指标配套观察。
6. 教育经费主要按地区和学校管理，学校质量仍与地方财政、住房区位和师资配置相关。全国平均覆盖率不能替代流入人口集中城市的真实入学门槛。
7. “双减”能够压缩显性校外培训，但隐性家教、家庭辅导能力和优质学位竞争不易从官方常规统计中观察。
8. 养老服务清单主要面向特定对象，居家、社区和机构服务的等待时间、价格、护理员工资、人员流失与事故数据尚无统一全国公开格式。
9. 长期护理保险在2026年由试点转向全国建制，各省未来约三年逐步实施；截止日不能以先行地区待遇代表全国。
10. 社会救助法刚施行，地方标准、部门信息系统和既有行政法规的配套清理处于过渡期。家庭经济状况核对还同时带来隐私、错误匹配和复核需求。
11. 低保及低收入认定主要以家庭为单位，法定扶养关系与实际可获得支持可能不一致；个人遭受家庭控制或暴力时的单独认定情况不易观察。
12. 公共服务逐步向常住人口覆盖，但超大城市积分落户、流入地财政压力、农村土地权益和地方服务承载力仍使户籍与福利未完全脱钩。

## 古国改革需回答的问题

1. 社会保险是否以个人为唯一账户并全国统一，中央与地方如何分担筹资、待遇和风险调剂？
2. 对平台、零工、照护和间断就业者，缴费责任如何分摊，最低保障能否不以标准劳动合同为前提？
3. 养老金待遇如何兼顾最低生活、缴费贡献、照护劳动、地区物价和代际可持续性？精算报告由谁独立出具？
4. 退休年龄是否按健康、职业风险和个人选择设计，而不是仅按性别或身份分类？弹性选择如何避免被雇主强迫？
5. 基本医疗应覆盖到什么范围；起付线、封顶线、目录和异地结算能否全国统一并由公开程序调整？
6. 医保支付如何同时控制成本和保护质量，患者拒收、再入院、并发症和自付负担由谁监测？
7. 基层医疗、公共卫生、医院和长期照护如何转介，个人是否拥有完整健康记录及访问、更正和授权权？
8. 是否把学前和高中阶段逐步纳入免费公共教育；教育经费如何随学生流动并缩小地区、学校差距？
9. 随迁儿童能否只凭实际居住入学和参加升学考试，学位不足时采用何种公开、公平的分配规则？
10. 职业教育与普通教育如何互转、学分互认，避免一次分流决定终身机会？
11. 长期护理保险是全民统一制度还是分层制度，失能评估由谁独立实施，拒绝待遇怎样申诉？
12. 家庭照护者是否获得现金支持、休息服务、社会保险和职业培训，怎样避免把照护成本固定转嫁给女性？
13. 社会救助以个人还是家庭为单位；收入、财产和刚性支出如何核对，如何处理家庭成员实际不提供支持的情形？
14. 救助待遇如何设置缓退期，避免收入略增便丧失医疗、住房和教育支持的“福利悬崖”？
15. 公共服务是否与户籍彻底脱钩并按常住地供给；人口流入地获得怎样的自动财政补偿？
16. 社保、医疗、教育、救助数据库共享的目的、最小范围、保存期限、访问日志和个人更正权如何规定？
