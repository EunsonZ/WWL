# 基础理论学习路线

这不是一份按周计的课程表，也不要求先读完所有前置。它用于把“模型为什么这样训练”“程序为什么这样运行”“算法为什么这样选”分成可回退的四步。每一步都以一个具体问题为入口；卡住时只回到直接缺失的对象、假设或证据，不把整条路线重来。想先看关系再决定从哪里开始，可以打开 [[00-工作台/基础理论总览.canvas|基础理论总览 Canvas]]，双击文件节点进入对应正文；边的文字说明的是先修、应用或比较关系，不是现实世界的因果箭头。

从 [[00-工作台/README|工作台]] 返回日常入口；需要按学科改选时回到 [[../README|知识库总入口]]。若问题转向社会后果、政策或制度，使用 [[社会科学/00-开始/00-社会科学-首页|社会科学首页]]，并把技术指标、经验事实和价值判断分开记录。

## 先修：先能说清对象与问题

先写下一个可检查的问题：输入是什么、输出是什么、你看到的失败或差异是什么。随后从三门课各取最短的必要页：

- 模型、数据、参数和目标分别是什么：[[AI/10-机器学习与深度学习基础/01-AI机器学习深度学习与生成模型的边界|AI、机器学习、深度学习与生成模型的边界]] → [[AI/10-机器学习与深度学习基础/02-模型特征参数目标与泛化|模型、特征、参数、目标与泛化]]；
- 程序的数据如何表示、地址如何解释：[[计算机知识/30-计算机系统/01-数据表示字节序与对齐|数据表示、字节序与对齐]] → [[计算机知识/30-计算机系统/02-进程虚拟地址空间与内存映射|虚拟地址空间与内存映射]]；
- 算法承诺的资源界限是什么：[[计算机知识/50-数据结构与算法/01-复杂度模型渐近分析与摊还分析|复杂度模型与摊还分析]] → [[计算机知识/50-数据结构与算法/02-数组动态数组链表与内存布局|数组、动态数组、链表与内存布局]]。

**检查点：** 你能区分数据、模型参数和目标；能说明一个值在内存中怎样被表示；也能说明复杂度是输入增长的模型，而不是某台机器上的秒数。

## 核心机制：沿一条因果链读下去

选择你当前问题最贴近的一条主线，再把相邻两条当作解释边界。

| 当前问题 | 主线 | 相邻边界 |
| --- | --- | --- |
| 为什么训练分数好，换一批数据却变差？ | [[AI/10-机器学习与深度学习基础/00-机器学习与深度学习基础-MOC|机器学习与深度学习基础 MOC]]，再读 [[AI/10-机器学习与深度学习基础/05-数据集拆分清洗与泄漏|数据集拆分、清洗与泄漏]] 与 [[AI/10-机器学习与深度学习基础/06-损失函数优化与训练循环|损失、优化与训练循环]] | 数据划分不是系统资源；但 I/O、内存和批处理会影响可观察的训练行为 |
| 为什么同一程序会慢、占内存或表现不稳定？ | [[计算机知识/30-计算机系统/00-计算机系统-MOC|计算机系统 MOC]]，再读 [[计算机知识/30-计算机系统/04-缓存局部性带宽与延迟|缓存、局部性、带宽与延迟]] | 先测量再归因；算法复杂度、数据布局和运行时开销各自解释不同部分 |
| 为什么这个数据结构或算法能用，又会在什么条件下失效？ | [[计算机知识/50-数据结构与算法/00-数据结构与算法-MOC|数据结构与算法 MOC]]，再读 [[计算机知识/50-数据结构与算法/07-图的表示BFS-DFS与拓扑排序|图的表示、BFS、DFS 与拓扑排序]] 或 [[计算机知识/50-数据结构与算法/10-贪心算法与正确性证明|贪心算法与正确性证明]] | 正确性依赖问题规格与不变量；快慢还需结合输入分布、缓存和 I/O |

## 可复算练习：让一个小例子反驳或支持理解

练习不需要下载模型、开服务或使用真实敏感数据。选一项已有的可运行材料，保留输入、预期性质、实际输出和不能说明的事：

1. 用 [[AI/80-实践/07-PyTorch与核心公式CPU实验/00-CPU实验与使用说明|PyTorch 与核心公式 CPU 实验]] 检查张量、损失或梯度的小性质；它只验证该例的计算路径。
2. 用 [[计算机知识/80-实践/05-数据结构与算法/01-线性结构与摊还/README|线性结构与摊还练习]] 写出操作序列、势能/总成本或不变量；再改变一个边界输入。
3. 用 [[计算机知识/80-实践/06-计算机系统/03-缓存局部性benchmark/README|缓存局部性 benchmark 练习]] 固定输入规模、计时口径和机器条件，区分一个观察值与一般性能结论。

**检查点：** 练习记录必须能回答“输入是什么、预期性质是什么、实际看到什么、哪个条件一变就不能外推”。若没有保存这些信息，只能说读过或运行过，不能说已经验证机制。

## 进阶：按障碍进入完整课程，而不是把路径无限拉长

- 需要模型选择、泛化、评估或分布偏移时，从 [[AI/10-机器学习与深度学习基础/11-经典机器学习基线与模型选择|经典机器学习基线与模型选择]]、[[AI/10-机器学习与深度学习基础/12-统计学习泛化与实验设计|统计学习泛化与实验设计]] 继续；
- 需要并发、持久化、ABI、网络或系统测量时，回到 [[计算机知识/30-计算机系统/00-计算机系统-MOC|计算机系统 MOC]] 选对应机制；
- 需要图、动态规划、随机/近似或证明边界时，回到 [[计算机知识/50-数据结构与算法/00-数据结构与算法-MOC|数据结构与算法 MOC]]，并用 [[计算机知识/50-数据结构与算法/23-正确性证明反例与复杂度边界|正确性、反例与复杂度边界]] 复查条件；
- 需要从技术问题讨论社会影响时，使用 [[社会科学/00-开始/00-社会科学-首页|社会科学首页]]；技术指标、经验事实和价值判断仍须分开说明。

返回 [[00-工作台/按问题找知识|按问题找知识]]；每次只选一条主线，下一次阅读由你当前的具体障碍决定。
