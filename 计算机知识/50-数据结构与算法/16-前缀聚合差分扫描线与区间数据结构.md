# 16 · 前缀聚合、差分、扫描线与区间数据结构

## 本课目标

学完后，你能把“重复查一段”改写为前缀聚合，把“先收集所有区间更新、最后只读一次”改写为差分，用扫描线管理按坐标发生的事件；当更新和查询交错时，能根据代数性质、空间和操作类型选择 Fenwick 树或线段树，并明确复杂度结论的前提。

## 1. 直觉：别在每个问题上重新走同一段路

数组 `a[0:n]` 上的区间和 `sum(a[left:right])` 若每次现算，一次需要扫描 `right-left` 个元素。若数组不变却有很多查询，这些扫描大量重叠。前缀和把从起点到每个边界的结果先缓存：

```text
P[0] = 0
P[i + 1] = P[i] + a[i]
sum(a[left:right]) = P[right] - P[left]
```

本课统一使用左闭右开 `[left, right)`。空区间是 `[k,k)`，长度是 `right-left`，数组末边界可以正好写成 `n`。这个约定使相邻区间可以无重叠地拼接，也减少 `+1/-1` 错误。

## 2. 前缀聚合：不只是加法

设有一个结合的二元运算 `⊕`，且有单位元 `e`，则可定义 `P[i+1]=P[i]⊕a[i]`。“结合”保证括号重排不改变结果，所以可用分段聚合。但要从两个前缀结果恢复中间区间，还需要可逆或特定的取消规则：

| 聚合 | 前缀能否 `O(1)` 得到任意区间 | 原因 |
| --- | --- | --- |
| 整数加法 | 能 | `P[r]-P[l]` 取消左前缀 |
| XOR | 能 | 一个值 XOR 两次被取消 |
| 计数向量 | 能，但每维都要算 | 分量相减 |
| 最小值 | 一般不能 | 不知道最小值来自被取消部分还是保留部分 |

不变量是：对每个 `i`，`P[i]` 恰好聚合 `a[0:i]`，既不遗漏也不重复。构造用 `Θ(n)` 次聚合，区间和查询在 RAM 模型、固定字长加减为常数时是 `Θ(1)`；大整数或向量聚合不能被暗中算成固定代价。

## 3. 差分：记录“从这里开始变化”

若一批操作都是给 `[left,right)` 每个位置加 `delta`，可在差分数组上只写两个边界：

```text
D[left]  += delta       # 影响从 left 开始
D[right] -= delta       # 影响在 right 之前结束
```

最后从左到右累加 `D`，得到每个位置应用的总增量。对长度 6 的零数组执行 `[1,5)+=3` 和 `[2,4)+=-1`：

```text
D 的有效变化：D[1]+=3, D[5]-=3, D[2]-=1, D[4]+=1
扫描结果：      [0, 3, 2, 2, 3, 0]
```

每次更新两次边界写入，`q` 次更新后一次 `Θ(n)` 扫描，总代价 `Θ(q+n)`。关键前提是可以离线：扫描完之前不需回答中间查询。如果更新和查询交错，只保存边界就不够。

## 4. 扫描线：把空间问题改成事件顺序

扫描线先把二维或区间问题改写为“在坐标 `x` 发生什么事件”，排序后从小到大处理，同时维护活跃集合。例如区间覆盖长度：

```text
[left,right) 生成 (left,+1) 与 (right,-1)
按坐标分组：先把同坐标的 delta 全部合并
从 previous_x 到 x 若 active > 0，加入 x-previous_x
再用当前坐标的总 delta 更新 active
```

必须明确同坐标事件的语义。在左闭右开区间中，长度按两个相邻不同坐标之间统计，同坐标的开始/结束可先合并；但若问题要计算端点接触、报告交点或在事件之间查询，同坐标的处理次序就是正确性的一部分。

若事件数为 `k`，排序通常是 `O(k log k)`，每个事件对活跃结构的操作再加上相应代价。坐标压缩只保留顺序与相等关系；若要求几何长度，还必须保留原坐标差，不能把压缩后的下标差当真实长度。

## 5. Fenwick 树：用二进制块维护动态前缀和

Fenwick 树（Binary Indexed Tree）用 1-based 内部下标。`tree[i]` 保存以 `i` 结尾、长度为 `lowbit(i)=i&-i` 的一段聚合。这是核心表示不变量。

- 查前缀：累加 `tree[i]`，再令 `i -= lowbit(i)`，每次删掉最低位的 1；
- 点更新：修改 `tree[i]`，再令 `i += lowbit(i)`，走向下一个覆盖该位置的块。

每条路径至多与下标二进制位数同阶，所以点加和前缀查询是 `O(log n)`，区间和用两次前缀查询。这个结论依赖数组随机访问及聚合为常数代价。Fenwick 树紧凑，但不适合直接维护“区间最小值且任意增减更新”这类无法用逆运算取消前缀的问题。

## 6. 线段树：把区间分解成少量规范块

线段树的每个节点代表一个区间，根代表全部，子节点把父区间分成两段。不变量是：节点的聚合值恰好等于它表示的全区间聚合；内部节点值由两个孩子按同一结合运算得到。

任意连续查询可分解为 `O(log n)` 个规范节点，点更新只修复一条根路径，因此都是 `O(log n)`。若要整段更新，懒标记表示“这个更新已对本节点的聚合生效，但尚未下传到孩子”。标记的组合、它对聚合值的作用，必须闭合且顺序正确；区间赋值和区间加法不能无规则地混在一个 `lazy += delta` 里。

| 工作负载 | 首选候选 | 必须确认 |
| --- | --- | --- |
| 数组不变，大量区间和 | 前缀和 | 聚合能否用前缀取消 |
| 所有区间加在前，最后读取 | 差分 | 中间无在线查询 |
| 按坐标增删活跃对象 | 扫描线 + 活跃结构 | 同坐标顺序与坐标压缩语义 |
| 点加 + 前缀/区间和 | Fenwick 树 | 需要可取消的前缀聚合 |
| 多种区间聚合或懒更新 | 线段树 | 标记与聚合的代数规则、更大常数和空间 |

## 7. 完整例子：从离线排班到在线修正

有 8 个时间槽，初始需求为零。批次导入两条“`[1,5)` 加 3、`[2,4)` 减 1”时，差分用 4 次有效边界写入和 8 次扫描得到最终值。若之后用户可以随时将某个时间槽修正 `delta`，并立即询问任意区间总需求，则把已实体化的数组建成 Fenwick 树：修正和查询各触及对数个树槽。这不是“Fenwick 总比差分快”，而是工作负载已从离线改成在线。

## 练习

1. 对 `[2,7)+=4`、`[0,3)+=1`、`[5,5)+=99` 手算差分边界和最终长度 8 的数组，解释空区间为何不影响结果。
2. 为“静态区间最小值”说明为何不能用 `min(P[r],P[l])` 或相减；列出一种可用结构和其不变量。
3. 设计扫描线计算区间并集长度，用 `[1,3)` 与 `[3,5)` 检查同坐标事件。
