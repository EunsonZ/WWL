# 课程与班级证据：运行、改变条件与真实观察接口

先读 [[社会科学/68-教育学/04-评价效度班级研究与实施证据|评价与班级研究]] 的四班表，再做 [任务纸](迁移任务纸.md)；答案在 [[社会科学/68-教育学/05-课程修订迁移与完整答案|课程修订完整答案]]。与原 [分母单元教师页](../01-分母教学与迁移/教师答案与实施说明.md) 分工：原页维护I/II/D/N、初答和帮助；此处维护四课实施与班级计数。

## 本机可复算的层次

[inputs.json](inputs.json) 明确为合成计数，包含完整四班记录和**另一组**缺失情景，不把两表拼成同一批学生。源码 [education_counts.py](education_counts.py) 使用Python标准库 `Fraction`，不拟合学习模型、读取真人资料或调用外部服务；[代码镜像](code-sync/education_counts.md) 只为阅读。

在本目录可运行：

```bash
python3 education_counts.py --input inputs.json --out results
```

实际作者执行使用了本机共享限流入口 `run_local.py --timeout 300 -- command`，退出0，生成以下三产物；这是计算层运行，不是教学实验。无需安装依赖。输出目录可另选，避免覆盖自己要保留的变式结果。

- [exact-results.json](results/exact-results.json)：学生率A3/5、B7/10，班均A7/10、B3/5；六种分配与精确双侧概率2/3；缺失组差界−1/8至7/40。分数保存为精确字符串，百分号显示才转小数。
- [randomization.csv](results/randomization.csv)：A班组合与统计量，每种概率1/6；其解释要求四班二选二等概率、无干扰及锐零假设，不能当真实研究p值。
- [class-weights.svg](results/class-weights.svg)：同一输入与计算结果生成，纵轴比例0–100%、条旁保留公式／计数，含title/desc；没有虚构学习曲线。

输入验证要求恰四班、每方案两班，唯一非空ID，正人数和合法成功计数；缺失情景满足成功≤已测≤原分配，拒绝未知字段、布尔计数和缺失来源说明。没有被测者时观察率输出null，但原分配名单的逻辑界仍可计算；不能把null填0。

## 改变条件前先预测

1. **仅改班级人数并保持班率。** 把四班人数全改为10，成功改为9、5、8、4，预测学生率与班均都为A70%、B60%；运行时用另存输入及新输出目录。反转消失说明权重有作用，不是教学机制已识别。
2. **改变分配机制。** 若学校只允许班1、3之一获A、班2、4之一获A，合法集合不再是全部六种；本脚本不接受这项设计修改，应先重写枚举及概率，再算随机化检验。不能改标题后复用2/3。
3. **改变缺失。** 把A、B全部40人测齐，写明确成功数，逻辑界收缩为点；仍保留随机分配和总体外推问题。若未知结果不再是二元，当前0/1界也须改，不把原界当万能公式。
4. **改变目标。** 若目标是“当前设备下完成”，访问失败可成为服务结果的一部分；若目标是“理解记录口径”，设备访问失败是未测。两个目标应分别记录，不能为了好看的结论事后换名。

这些是材料迁移，不给读者登记掌握度。运行变式和拒绝输入只验证相关程序合同，不认证所有输入范围或现实效果。

## 四次课真正发什么

02的第一课用01完整示例；第二课用渐撤后摘发I/II；第三课用04合成班级／缺失表。第四课如安排在约一周后，可依原教师页**先D后N**单独摘发，期间不反馈会泄露N的答案；仅当学习者此前没看过D/N才记未暴露。实际日期、与第二课间隔及期间复习／讨论另记；D、N不等值，不能用分差估遗忘。若第四课提前或读者已见题，换另编且事先核同目标的新材料并记录版本，不能将已讲I/II重标陌生。

D/N之后可做任务E讨论目的和制度；A–F是整课修订练习，其部分内容已在正文示范，不据此自称盲测或真人首次迁移。独立核查者先答后核也属于材料层，不是未经暴露招募的学习者。

## 真人和课堂层：高重要性，当前未运行

下列接口不启动招募、收集或课堂实验；当前没有成绩、实际教学日期、同意记录、评分者一致率或因果结果。真实保持／迁移的重要性高，因为它是本课目标的直接观察；年龄／语言访问的重要性高，因为可能改变分数含义与机会；班级效果的重要性高（若宣称方案有效），因为材料正确不代表教学造成提高；客户端显示的重要性中，因为阅读能否正确到达材料仍需实际环境。
