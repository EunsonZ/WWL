# 多导体静电与电容矩阵复算

本实践接 [[物理/20-电磁学/08-多导体静电与电容矩阵#完整求解：两段势，四份表面电荷|三导体完整边值解]]。给三块导体分别施加单位电位并积分其净电荷，得到每米 Maxwell 电容矩阵；同时比较解析对数解、径向保守离散解、场能积分与端口二次型。它解的是有厚度中间筒、有限长度端面 Neumann、无外部场的两圆环问题，没有求任意三维多导体结构。

## 输入和运行

[inputs.json](inputs.json) 给 SI 参数：$a=0.001$ m、$b_-=0.002$ m、$b_+=0.0025$ m、$c=0.005$ m、$\ell=0.1$ m；内/外间隙 $\epsilon_r=(2,4)$，导体电位 $(1,0.25,0)$ V、电位变化率 $(10^6,0,0)$ V/s。迁移输入在同一文件的 `layered_transfer`：内间隙于0.0015 m处分层，$\epsilon_r=(3,6)$；迁移题自身取 $v_1=1$ V、中间中性浮置、外参考零。

[solve_capacitance.py](solve_capacitance.py) 是规范源码，只使用 Python 3 标准库。常数沿用 E01：$\mu_0\approx4\pi10^{-7}$ H/m、$c_0=299792458$ m/s、$\epsilon_0=1/(\mu_0c_0^2)$。材料是理想教学常数，这个 $\mu_0$ 近似不冒充 SI 精确定义。没有安装新依赖，也没有启动服务。

在本目录运行；指定目录内的同名文件会被覆盖，保留原结果时换一个新的输出目录：

```bash
python3 -I -B solve_capacitance.py --input inputs.json --output-dir results > results/stdout.json
```

[stdout.json](results/stdout.json) 是摘要；[values.json](results/values.json) 保存 SI 数据、单位激励列、四面电荷密度、能量、端口及各网格检查。[fields.csv](results/fields.csv) 与 [sweep.csv](results/sweep.csv) 是定量图的同数据来源；CSV按LF写出，没有把它们转成另一套公式。三个 `assets/` 图与 `results/` 的同名SVG逐字相同。改变输入后先核对正文条件再接收新图，不能留下旧数值配新几何。

## 三种检查分别承担什么

解析解在每个常介质圆环使用对数势；积分每米导体自由电荷用 $2\pi r\sigma_f$，中间导体两面相加。解析 $A,B$ 给完整三电位矩阵与固定外参考的 $2\times2$ 矩阵；它是独立可手算的目标答案。

径向离散求解不把解析 $C'$ 填回矩阵。每个材料区均匀分成 $n$ 个径向边；从 $D_r=-\epsilon\phi_r$ 的中点通量建立

$$g_e=\frac{2\pi\epsilon_e r_{e,\mathrm{mid}}}{h_e},\qquad [g_e]=\mathrm{F/m},\qquad
q'_e=g_e(\phi_{e,L}-\phi_{e,R}).$$

这里 $g_e$ 是离散电容系数，未表示真实漏电电导。内部节点无自由电荷，所以相邻边的 $q'_e$ 相等；解这个径向保守网络得到 $q'=\Delta V/(\sum_e1/g_e)$ 和逐节点电位。这个求解路径不使用对数电容公式。对三次单位电位激励分别求两间隙，再积分三块导体电荷，所得三列组成离散矩阵；只在比较误差时读取解析解。它并未运行有限元或一般二维/三维网格。

每层1024个正偶数区间的 Simpson 积分独立累计 $\pi\epsilon rE_r^2$，与 $\tfrac12\sum_iU_iQ'_i$ 比较；另用512区间核积分变化。离散能量 $\tfrac12\sum_eg_e(\Delta\phi_e)^2$ 与离散端口二次型的近零差，是离散模型自身的结构核验；它与解析能量的网格误差才检查这套离散几何近似。对称残差为零也有保守离散结构原因，不能单凭这个数值证明任意材料互易。
