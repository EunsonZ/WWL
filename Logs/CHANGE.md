## 8. R1-01：修复 Softmax／LogSumExp／交叉熵的组合不稳定

目标：`数学/50-信息论/softmax_stability.py`；同步 `数学/50-信息论/02-指数对数Softmax与LogSumExp.md`、`数学/50-信息论/80-Softmax数值稳定性实验.md` 及实际镜像。

原行为：`[1e16, 1e16]` 经 `exp(z - logsumexp(z))` 得到 `[1, 1]`，概率和为 2；真实标签交叉熵可能为 0，而应为 `log(2)`。根源是先将微小修正加回巨大公共偏移，再相减时修正丢失。

必须改成始终在中心化坐标中计算：令 `m=max(z)`、`a=(z-m)/T`、`S=sum(exp(a))`，分别形成概率、log-prob 与交叉熵，不将巨大偏移重新引回消去路径。应明确支持的输入、dtype、温度和无穷／掩码语义。

不要用上一轮辅助函数文件整体覆盖原实验：保留熵、KL、演示、主程序等真实功能，按函数合入并同步镜像。中心化也不保证所有极端中间运算均可表示，仍需测试支持域。

验收：相等巨大 logits、公共偏移、常规输入、零／非法温度、空输入、极端概率、概率和及梯度有限差分；有反例证明旧实现失败、新实现通过。说明代数恒等与浮点算法的区别，不只写“用了减最大值”。

## 11. R2-02：修正 Adam 首步偏差修正解释

目标：`数学/40-微积分与优化/04-SGD-Momentum-Adam与AdamW.md`，原第 144–153 行。

已有例子：`g1=2`、`β1=.9`、`β2=.999`、初始矩为零。此时 `m1=.2`、`v1=.004`，偏差修正后 `m_hat=2`、`v_hat=4`。

原说明称第一步否则会缩小约十倍，这只看了一阶矩，忽略分母也被偏置。忽略 epsilon 便于比较：

`未修正方向 = m1/sqrt(v1) = 3.162277660...`；
`修正方向 = m_hat/sqrt(v_hat) = 1`。

应推导通式 `(1-β1)/sqrt(1-β2) * sign(g1)`，并说明 epsilon 有限时的实际公式。不要把移动平均启动偏差与“当前非平稳梯度分布的无偏估计”混为一谈。

验收：保留原参数的完整手算、独立数值检查和解释题。问题应问“为什么两个矩都偏小，却可能使归一化更新偏大”，不是让读者背修正公式。

## 12. R2-03／R2-04：纠正 Fourier 叙述，明确谱的约定

目标：`数学/70-信号处理与多模态数学/02-采样定理波形STFT与Mel频谱.md` 和 `数学/70-信号处理与多模态数学/80-多模态数学最小实验.py` 及其镜像。

### R2-03：完整 DFT 不等于丢失时间位置

原“只对整段做一次 DFT 会丢失什么时候出现”过强。完整复数 DFT 可逆；全局频谱不直接展示局部时频演化；只保留幅度／功率时才丢掉相位信息。

加入长度 4 的位置脉冲对照：`x=[1,0,0,0]` 与 `y=[0,1,0,0]`。两者幅度谱相同，复数谱相位不同，逆变换能恢复不同的位置。用它引出 STFT 为局部表示付出的时间／频率分辨率权衡，而非声称 STFT 神奇恢复了 DFT 已经永久丢掉的信息。

验收：复数谱、幅度谱和逆变换的区别可手算／运行验证；保持已有关于零填充和对数可逆性的正确限定。

### R2-04：原始谱特征、能量与 PSD 分开

`one_sided_power_spectrum` 当前返回单边 `|DFT|²`，不包含采样率／窗归一化，也未作保能量单边加倍。这可以是合法的谱特征约定，不能直接判定全部 Mel 计算错误。

修复重点是名称、单位和解释一致。明确本实验使用原始单边平方幅度；若声称 Parseval 能量或 PSD，则使用对应归一化，并说明 DC／Nyquist 不应像内部正频率一样加倍。不要为“修好能量”盲目改变所有 Mel 特征值。

对照案例：N=8、矩形窗、单位正弦，时域平方和约 4，全双边原始平方幅度和约 32，单边原始和约 16。解释三个数字的来源以及窗／采样率的作用。

验收：公式、函数命名、输出标签和单位相符；明确这是语义与归一化合同完善，不把未归一化特征一概判错。

## 13. R2-05／R2-06／R2-07：RAG 评测必须测到真实失败

目标：`AI/80-实践/05-RAG评测与私有服务/rag_service.py`、`test_rag_service.py`、`00-RAG评测与私有服务.md`、`01-完整源码与测试附录.md`。

### R2-05：Hit@K 与 Recall@K

`evaluate_retrieval` 原按“至少命中一个 gold”计数，却返回 `recall_at_k`。两个 gold 只找回一个时输出 1，真正的该查询 recall 为 1/2；当前 gold 为单例的测试掩盖了区别。

保留旧逻辑时应显式命名 `hit_at_k`；真正 recall 按每查询相关项覆盖计算并明确 macro／micro。给空评测集、空 gold、重复返回、k 超过候选数规定政策。若 gold 表示“多个替代的充分证据”或“必须联合满足的证据组”，先定义任务语义，不能以普通集合 recall 冒充充分性评价。

更新所有消费该字段的正文、测试、JSON 示例与视图，不能悄悄改变同名指标的历史含义。

验收：至少一个多 gold 例子清楚区分 Hit@K、Recall@K、MRR@K；按真实分母聚合，不只用两个正常问题获得全 1。

### R2-06：格式失败不能在计算失败率之前终止评测

`answer()` 在返回前调用 `validate_answer()`，而 `evaluate_generation()` 的 `try` 在 `answer()` 之后。生成器返回 `{}` 时整个评测先抛出异常，无法记录 `schema_valid_rate=0`；顺利返回的结果又被重复验证。

改成按请求保留 raw／validated／failure 的明确信息流；验证失败要计入相应分母，基础设施失败与模型格式失败分别报告。捕获可预期的验证错误，不用宽泛 `except Exception` 静默吞掉编程错误；也不把失败样本从分母中剔除。

验收：非法 JSON、缺键、多键、错误 citations、非法 confidence、合法结构但无事实支持都进入各自正确的结果；整个小评测不被一个坏响应无说明终止。指标能同时出现合法结构和事实失败，不能把合法引用 ID 等同于证据支持。

### R2-07：索引算法版本与内容快照分离

删除文档重建后，原 `revision='demo-index-v1'` 不变，但 chunk 集合已改变。若这是算法版本，应改名或说明；另增能够区分内容快照的标识，包含被允许用于复现的数据版本、分块参数和权限版本等必要信息。

不要为了可复现把全部私密正文／ACL／查询写入公共日志。快照摘要和敏感派生值也要受保护。文档 ID＋序号不应被误作跨版本永恒内容标识。

验收：内容更新／删除或相关配置变更后能辨别新快照；不变输入可重复；相同算法版本不会掩盖不同数据。现有权限先于排序、禁止请求自报权限、删除后不再召回、仅 loopback 等安全测试继续通过，且不自动启动服务。

## 14. R2-08／R2-09：Decoder 位置合同与采样数值边界

目标：`AI/20-LLM/50-实现/tiny_decoder.py`、`tiny_train_generate.py`、`tiny_tokenizer_embedding.py` 与同目录 01／02／03 三篇实现笔记及实际镜像。

### R2-08：无缓存但非零 start_pos 的因果泄漏

原 `CausalSelfAttention.forward()` 的 query positions 从 `start_pos` 起，而无缓存 key positions 仍从 0 起。长度 3、`start_pos=5` 时第一 token 会看到所有三个 key。固定种子探针中改变第三 token，第一位置输出最大变化约 0.7727；它不是正常浮点微扰。

本轮采用最小正确合同：如果实现只支持从零开始的前缀缓存，就明确拒绝 `cache is None and start_pos != 0`，也拒绝负位置；或者完整一致地支持偏移并测试 key／query 的绝对位置。不要趁机新增滑动窗口缓存、分页缓存或新的推理特性。

检查缓存长度、batch／head／维度和适用 dtype；不依赖广播侥幸工作。顺便明确 tokenizer／embedding ID 的合法范围，负索引不能静默代表词表末尾，除非明确设计且正文说明。

验收：修改未来 token 不影响先前输出；不支持的偏移在计算前明确报错；原从零 prefill 与逐 token cache 等价测试继续通过；错误缓存与非法 token ID 有边界测试。

### R2-09：温度除法发生在中心化之前

`sample_from_logits()` 原先做 `logits/temperature` 再减最大值。有限输入 `[1000,999]`、正有限温度 `1e-308` 会溢出为 inf，继而产生 NaN 概率；该例可用先中心化处理。

检查一维、非空、有限输入和有限正温度，明确 top-k 和并列值政策。在声明的支持域内稳定计算，不能将“温度大于 0”误当成足够的数值合同。与 Softmax 修复共享测试思路，但不要机械共用不同 mask／axis／dtype 语义的函数。

验收：普通采样固定种子可重复；巨大公共偏移和该微温度例输出合法；空数组、NaN／inf 温度有明确诊断；极端异号导致中心化本身不可表示时也有明确政策，不输出 NaN 后才让 `choice` 报错。

## 15. R2-10／R2-15：检索实验的数值与键语义

目标：`计算机知识/80-实践/05-数据结构与算法/11-概率结构与检索评测/retrieval_lab.py`、同目录测试；关联 `计算机知识/50-数据结构与算法/19-概率型数据结构流式摘要与误差合同.md`、`20-倒排索引精确近邻与近似向量检索.md` 和 `数学/20-线性代数与几何/03-点积范数距离与余弦相似度.md`。

### R2-10：大／小有限向量的余弦错误

原平方和直接计算范数：平行向量 `[1e200,1e200]` 得 NaN，`[1e-200,0]` 被误判零向量，数学上二者与自身的 cosine 均为 1。

采用分量缩放及合适累加计算，显式拒绝非有限输入和真零向量。仅在符合误差分析时处理微小越界，不将 NaN 夹成 0，不通过任意增大 epsilon 改写方向关系。明确 `exact` 是穷举候选而非任意精度数值。

同步数学页：`max(norm_product, epsilon)` 只是零分母保护，不自动解决平方、点积和范数乘积的溢出／下溢。给正缩放不变性、正交、反向、极端尺度和 NaN 输入测试，确保排序不含不可比较值。

### R2-15：repr 不是任意对象的稳定键编码

原 `_stable_hash()` 接受 `object` 并散列 `repr`；Bloom 接受不可哈希对象。字典 `{'a':1,'b':2}` 和逆插入顺序字典 Python 相等，但表示不同；加入前者后查询后者，当前探针返回 False。

这不是 Bloom filter 概率定理被推翻，而是接口没有说清“同一个键”。最小修复优先限制为稳定的 `str`／`bytes` 及明确编码与类型域；需要结构化键时才实现经过测试的规范编码。不要启动通用序列化框架项目。默认 object repr 可能含地址，不能宣称其跨进程稳定。

验收：键相等的定义、不可变性、类型差异、编码版本和支持范围写清；不支持对象明确拒绝；支持键跨进程相同编码／位置。对已有字符串用例保持无假阴性；同时复核 Count-Min 等共享哈希调用点。

## 16. R2-11：最短路可达与浮点溢出不能混为一谈
