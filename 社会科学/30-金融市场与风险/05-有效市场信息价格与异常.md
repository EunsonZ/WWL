# 有效市场、信息、价格与异常

“价格吸收信息”不是“价格永远正确”。它是一组关于**给定信息集、给定预期收益模型，价格调整后是否还留下可利用预测误差**的假设。要检验它，必须先说信息是什么、正常回报怎么算、成本怎样扣。

## 1. 三个信息集，三种不同强度

经典分类可写成：

- 弱式：信息集只含过去价格与成交等市场历史；
- 半强式：加入公开信息，如公告与公开宏观数据；
- 强式：再包含私有信息。

Fama 1991 建议把它们更操作化地表述为“回报可预测性检验、事件研究、私有信息检验”。这避免把“效率”当一个单开关。某市场对公开公告反应很快，不代表内部人没有信息优势；过去回报有统计预测力，也不必然产生扣成本后的利润。

## 2. 信息进入价格是一条带摩擦的时间线

```mermaid
flowchart LR
  X[事件实际发生] --> O[部分参与者观察]
  O --> B[更新信念与下单]
  B --> P[价格与成交变化]
  P --> L[流动性提供者和他人继续学习]
  L --> N[新信息到来]
```

箭头表示信息处理和交易过程，不证明每一步即时、无偏或无成本。时间戳也有多种：事件发生、首次披露、机器可读发布、交易所收到订单、成交。事件研究必须事先选择事件时点和窗口。

## 3. 异常回报依赖“正常回报”模型

资产 $i$ 在时点 $t$ 的异常回报常写为

$$AR_{i,t}=R_{i,t}-E[R_{i,t}\mid\mathcal I_{t-1};M],$$

其中 $\mathcal I_{t-1}$ 是信息集，$M$ 是预期收益模型。固定事件窗、简单收益口径和同一条基准路径后，三种常被混用的对象应分开命名：

$$CAR=\sum_t AR_t,\qquad BHAR=\prod_t(1+R_t)-\prod_t(1+R_t^{bench}).$$

另一个 $\prod_t(1+AR_t)-1$ 是“直接复合异常回报”，通常既不是 CAR 也不是上式 BHAR。比如两期资产收益各为 10%、可投资基准各为 5% 时，CAR 为 $0.05+0.05=0.10$，直接复合 AR 为 $1.05^2-1=0.1025$，而 BHAR 比较两条财富路径，等于 $1.10^2-1.05^2=0.1075$。这只是固定路径的算术例，不把随机复合收益的期望误当作边际期望的乘积。

若观察回报高于 CAPM 预测，至少可能是：市场错价、CAPM/市场代理错、beta 随时间变化、样本偶然、数据处理错误。Fama 1991 明确把这种无法单独检验市场效率的问题称为联合假设问题。

教学构造：公告日实际回报 3.0%，基准模型预测 0.8%，则单日异常回报 2.2%。若换成能解释行业共同冲击的模型，预测变为 2.1%，异常仅 0.9%。观察价格没有变，结论随基准改变。

## 4. 信息有成本，完全效率会产生悖论

Grossman 与 Stiglitz 1980 的核心机制是：若价格无成本地完全揭示所有信息，付费搜集信息者没有补偿，于是没人愿意搜集；但没有信息搜集，价格又不能完全有信息。因此有成本信息的市场更像一个均衡：价格相当有信息，但保留足以补偿信息活动的噪声或收益。

这不是“市场一定无效”的交易信号。信息成本、交易成本、风险和资本约束决定偏差是否值得利用；当别人发现同一规则，价格和竞争也会改变。

## 5. 泡沫、超额波动与效率并非一句话能裁决

Shiller 1981 将实际价格波动与一个事后按未来股息构造的基准比较，质疑简单常折现率现值模型能否解释价格波动。这个结果推动了超额波动研究，但解释仍依赖股息过程、终值与折现率是否随时间变化。Fama 1991 指出，若期望收益随经济状态变化，波动检验仍会遇到联合假设。

所以“价格比股息动得多”值得解释，却不能仅凭一张图在“理性风险溢价”和“非理性泡沫”间唯一判决。泡沫也不是看到价格上涨后的同义标签；要给出相对于哪个基本面模型、何种可证伪预测。

## 6. 从统计异常到可交易结果的六道门

| 门 | 要问什么 | 典型失败 |
| --- | --- | --- |
| 数据时间 | 当时真的可获得吗？ | 回看偏差、公告时间错位 |
| 样本 | 失败和退市资产是否保留？ | 幸存者偏差 |
| 规则 | 是否先看数据再挑窗口/变量？ | 多重检验、数据挖掘 |
| 基准 | 风险和共同冲击怎样调整？ | 错模型制造 alpha |
| 实施 | 点差、冲击、借券、税费是多少？ | 纸面异常不可交易 |
| 复现 | 样本外、其他市场、制度改变后怎样？ | 一次性样本偶然 |

Fama 1991 本身也要求对预测结果保持怀疑并寻找样本外确认。异常经过这些门仍存在，才是更强证据；仍不能称作无风险套利。

## 边界、练习与链接

- 统计显著不等于经济上足以覆盖交易成本；平均盈利不等于没有尾部风险。
- 价格快速反应不说明信息公平分布；效率命题与市场权力、披露权利是不同问题。
- 练习：把“某月平均回报较高”写成一个可检验命题，列出信息可得时点、基准、成本和样本外检验。
- 练习：解释为什么同一组回报数据既可能拒绝 CAPM，也可能被误读为拒绝市场效率。
- 继续 [[社会科学/30-金融市场与风险/06-远期衍生品无套利与期权|无套利与期权]]，看比“平均回报预测”更强的同状态复制关系；需要系统检查研究偏差时，转 [[社会科学/10-共同工具/04-比较研究偏差与证据审计|比较研究与证据审计]]。
