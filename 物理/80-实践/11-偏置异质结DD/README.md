# 偏置异质结 DD：从完整空间解到三本收支账

## 运行同一完整模型

先读 [[物理/50-半导体物理/14-偏置异质结两载流子DD-Poisson与电流收支#偏置先改变接触的电化学势|接触合同]]，写出本记法中正向偏压的符号；再读 [[物理/50-半导体物理/14-偏置异质结两载流子DD-Poisson与电流收支#先选择界面，再求电流|零界面阻力的限定]]，预测界面哪些场连续、哪些量应跳跃。这里是固定片电荷、理想 Ohmic 两储库、理想 CQFL 界面下的完整有限稳态两载流子问题。

[biased_dd_lab.py](biased_dd_lab.py) 是真源，[inputs.json](inputs.json) 只拥有合成迁移率、寿命、偏压、网格和求解预算。A/B 带阶、态密度、掺杂、介电常数、300 K、600 nm/侧、共同参考及正片电荷来自相邻 [[物理/80-实践/08-异质结与Poisson自洽/README#同一参数卡的运行与输出|实践 08]] 的实际源码与材料卡，程序导入它的常数、中性接触和零偏初始化；不复制或改写 08。移动本目录时需同时携带 08，或给 `--base-dir /实际实践父目录`。09/10 的动态界面状态没有被暗中加入。

求解需要 Python 3.12 及以上、NumPy、SciPy；绘图仅标准库。[requirements.txt](requirements.txt) 固定作者实际使用的 NumPy 2.5.2/SciPy 1.18.1；本次在 Python 3.14 临时环境安装，未升级系统环境。已有兼容环境可以直接运行；否则自行创建独立环境并按 requirements 安装，不要把虚拟环境放进正式 vault。

从库根运行，`/你自己的环境/bin/python` 替换为拥有依赖的解释器，输出目录必须是新目录或空目录。两个命令按顺序运行，求解失败时不要继续绘图：

```bash
/你自己的环境/bin/python -B '物理/80-实践/11-偏置异质结DD/biased_dd_lab.py' --out /private/tmp/wwl-biased-dd-new-run
```

上条成功后再执行：

```bash
python3 -B '物理/80-实践/11-偏置异质结DD/build_figures.py' --results /private/tmp/wwl-biased-dd-new-run
```

候选尚未接入同级 08 时，求解命令增加 `--base-dir /主库/物理/80-实践`。`--prototype` 只算 60 格/侧的零偏与主偏压，供短预跑；默认完整入口算九例、三级网格、精确极限和失败分支。输出保护不允许覆写非空目录，图源拒绝已存在的两幅图。

同一轮完整结果全部算完才写 CSV/JSON；输入出域、未知键、重复 JSON 键、非有限数、非整数网格、Newton/回溯预算用尽均 clean 非零退出，不把部分案例写成成功报告。未知 `Et`、界面律或动态陷阱字段会被拒绝，不能往输入里加字段却以为它生效。文件系统写入失败仍可能留下未完成文件，应保留错误并换新目录重试。

`half_cells` 要给三个按整数倍递增的整数，每侧 8–1000 格；默认 60/120/240，即 10/5/2.5 nm。`bias` 数值许可为 ±0.1 V，延拓步不得小于 1 mV，40 次 Newton/24 回溯，势步 ≤0.05 V、对数步 ≤1，体/准费米指数绝对值 ≤100。数值许可域不是物理适用域。默认本机有限单线程预跑低于 60 秒；时长不是跨机器保证，未认证硬内存上限。外部专业工具、硬件与服务不参与运行。

正文不复制源码片段，因此没有另一个需同步的 Python `code-sync` 镜像；方程、输入与链接消费这份唯一源码。[build_figures.py](build_figures.py) 只读本次结果快照，不偷偷重求方程。

## 零偏恢复与非零偏置分别验什么

`equilibrium-profile.csv` 是完整混合模型对实践 08 同网格正片电荷平衡解的检查：共同 $F_n=F_p=F_0$、两支流准确零，电势逐点同版。240 格/侧界面势 0.2522338250 V；与 08 默认 480 格/侧的 0.25223631 V 区别是网格，不是换材料。

主偏压 `forward_n240` 为右端 −20 mV。接触 $F_n=F_p=F_0-V=-0.480$ eV、静电势 $\phi_R^0+V$，相容统计保持端点中性浓度；内部两准费米分开，$np$ 不再强制为 $n_i^2$。当前主解如下：

| 位置或量 | 电子 $J_n$（A/m²） | 空穴 $J_p$（A/m²） |
| --- | --- | --- |
| 左接触 | $2.149246061\times10^{-4}$ | $4.622516581\times10^{-5}$ |
| A 侧界面（半格修正后） | $2.611182329\times10^{-4}$ | $3.153906901\times10^{-8}$ |
| B 侧界面（半格修正后） | $2.611182329\times10^{-4}$ | $3.153906901\times10^{-8}$ |
| 右接触 | $2.611188793\times10^{-4}$ | $3.089263362\times10^{-8}$ |

总流 $2.611497719\times10^{-4}$ A/m² 逐边相同；电子流沿路增加对应电子粒子反向流在向左旅途中的复合损失。正向净 SRH 的积分在 A 为 $2.883179405\times10^{14}$、在 B 为 $4.034732336\times10^9$ m⁻²s⁻¹。分别乘 $q$ 后才与上述两端支流差比较；两材料贡献相差很多，不能因 B 在同一线性图贴近零就把它删掉。

CSV 的每个界面保留 A/B 两行，同 $x,\phi,F_n,F_p$、不同 $n,p,E_c,E_v,U$，并存各自 `quadrature_weight_m`。边 CSV 存真正独立求出的 $J_n,J_p,D,E$。界面浓度比为 $n_B/n_A=0.00604144607,p_B/p_A=0.21683442275$；这些是当前理想合同的分配，不是普适热发射数据。

## 电流、Gauss、误差三本账

正式 JSON 保存每次偏压延拓的 Newton 残差/阻尼/回溯、全材料与运输输入、各解和失败例。默认主例缩放残差 $3.27\times10^{-12}$；电荷尺度 $1.922611961\times10^{-3}$ C/m²、电流尺度 $3.830287165\times10^{-3}$ A/m²。缩放后的边关系、节点行和接触行都参加停止判断；不是只检查 Poisson。

- **支流与总流：** 各材料/全域分别核 $\Delta J_n-q\int Udx$、$\Delta J_p+q\int Udx$；主例最大约 $3.0\times10^{-19}$ A/m²。界面两个中点流之差含半格体复合，修正后各支界面跳约 $5.42\times10^{-20},6.62\times10^{-24}$ A/m²。逐边总流 spread 约 $1.08\times10^{-19}$，接触总流差为零。
- **静电：** 主例 $D(0^-)=-3.897677097\times10^{-4}$、$D(0^+)=-3.577241771\times10^{-4}$ C/m²；修正后的片电荷跳跃误差约 $1.91\times10^{-18}$ C/m²，全体加端点半格的 Gauss 差约 $2.78\times10^{-19}$ C/m²。电极电荷账与传导电流账分别核。
- **统计与物理：** 最小 $n,p>0$，最大 $n/N_c$ 或 $p/N_v\simeq0.001$，通过 $\eta\le-3$ MB 尾部检查。主例最大场约 $4.378\times10^6$ V/m，相对输入教学场窗 $10^7$ V/m 为 0.438；场窗是指定检查尺度，不能认证真实材料低场或否定速度饱和。完全电离、等温、局部热化、微小缺陷储电与零界面阻力仍是模型前提。
- **空间误差：** 60→120→240 格/侧同节点势差 51.159→14.116 μV，准费米差 $F_n$ 为 3.577→0.888 μeV、$F_p$ 为 4.912→1.240 μeV；总流差 $7.109\times10^{-8}\to1.832\times10^{-8}$ A/m²。守恒残差比误差小很多，它们不是同一量。
- **不同求解路线：** 独立分区连续边值模型给主例 $\phi_0=0.2376580339$ V、总流 $2.61143678\times10^{-4}$ A/m²；细网格势低约 4.834 μV、总流高约 $6.09\times10^{-9}$ A/m²。它不导入生产求解函数，另核接触、CQFL 与片电荷条件；比较支持当前有限方程，没有证明一般有偏 DD 唯一性。

多数区的准费米差非常小，CSV 中 eV 能量舍入后再套普通 SG 会有浮点抵消；应核原混合边关系或显式估计舍入界，不能把格式化 CSV 的相减当高精度电流 oracle。总流相等也不支持抹掉 $J_n,J_p$ 的空间变化。

## 变化、极限与明确失败

完整入口还实际重解以下条件，原输入保留在报告中；不是换输出目录名称就改变材料。

| 案例 | 新输入与需重求的对象 | 左总流（A/m²，约） |
| --- | --- | --- |
| 主正向 | $V=-20$ mV，240 格/侧 | $2.61149772\times10^{-4}$ |
| 半偏压 | $V=-10$ mV | $1.08629306\times10^{-4}$ |
| 反向 | $V=+20$ mV，内部净产生 | $-1.35515516\times10^{-4}$ |
| 带阶变化 | B 的 $E_{c0}$ 加 0.025 eV、$E_g$ 不变；重算 B 中性边界与两分配比 | $2.63545484\times10^{-4}$ |
| A 电子迁移率减半 | 只改 $\mu_{n,A}$，重解准费米、反应与电荷 | $1.53686393\times10^{-4}$ |
| 关闭体反应 | $U=0$，各支独立常流 | $2.14957650\times10^{-4}$ |

迁移率减半的总流没有减半，因为空穴/SRH等路径仍在；界面势在本卡中变化很小，不是所有参数都只影响电场。带阶例同时改变 $E_c,E_v$ 的材料基准，不能只画一条额外势垒却不改统计与边界。

`exact_intrinsic` 把两侧变成同一种未掺杂材料、零片电荷、零偏，给精确常势/零流；`equilibrium08_phi_error_V=0` 检查实际旧材料平衡恢复。`no_recombination` 不依靠旧 SRH 解，重新求两支常流。非法负迁移率、偏压超过数值域、分数网格和零 Newton 预算会明确失败；失败并不证明对应一般物理方程无解，而是输入或当前求解预算的合同未满足。

**撤提示复算。** 只把 A 的迁移率改掉，然后重新调整寿命，使一个端口总流恢复原数值。能够因此宣称参数已被辨识、空间解也相同吗？

> [!question]- 解释性答案
> 一个总端流可由多个输运/反应参数组合得到；同端口数值不保证 $J_n,J_p,U,\phi$ 或温度依赖相同。应保留变化输入、求解与观察映射，增加有辨识力的空间/频率/温度或独立材料观测，并核模型适用窗；沿 [[物理/50-半导体物理/04-弛豫时间Hall符号与可辨识测量#相同电导怎样用 Hall 拆开|Hall 观测]] 返回的只是具名条件下拆分 $n\mu$ 的方法，不能保证本异质结多参数问题唯一。
