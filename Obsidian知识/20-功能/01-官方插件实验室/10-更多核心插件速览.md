# 10 · 更多核心插件速览

> [!abstract] 最后一课
> 不需要一次掌握所有插件。本页给剩余核心插件建立“用途 → 最小实验 → 风险”的索引，并再次校正核心插件、官方维护社区插件和付费服务的边界。

## 目标

- 快速定位尚未单独开课的核心插件。
- 为每个插件选择一个低风险的最小实验。
- 识别全 Vault 操作、附件删除和公开发布等风险。
- 准确分类 Maps、Importer、Sync 与 Publish。

## 动手

### 1. 挑三个最小实验

从下表任选三个，不必全部执行：

| 核心插件 | 它做什么 | 最小实验与边界 |
| --- | --- | --- |
| Backlinks | 查看指向当前笔记的链接和未链接提及 | 在另一篇笔记链接本页，再回来观察 Linked mentions |
| Outgoing links | 查看当前笔记发出的链接和潜在链接 | 比较本页链接列表与未链接提及 |
| Search | 用运算符搜索正文、任务、属性和路径 | 搜索 `tag:#playground` 与 `[status:ready]` |
| Graph view | 把内部链接显示为节点与边 | 打开 Local Graph；记住它不是语义相似图 |
| Quick switcher | 用键盘按名称或 alias 打开笔记 | 按 `Cmd/Ctrl+O`，空查询时切换最近笔记 |
| Properties view | 查看全 Vault 属性和当前文件属性 | 找出 `status`、`difficulty`、`stage` |
| Tags view | 浏览并统计标签 | 展开 `playground/...` 的嵌套层级 |
| Slash commands | 在编辑器里用 `/` 搜命令 | 在空白处输入 `/`，搜索插入 Callout |
| Footnotes view | 汇总当前笔记脚注 | 在实验笔记加入脚注后打开该视图 |
| Audio recorder | 录音、保存附件并嵌入当前笔记 | 录五秒测试音频；删除 embed 不会删除实体附件 |
| Random note | 从当前 Vault 打开随机笔记 | 连续抽三篇并补充链接；核心插件没有按标签过滤选项 |
| Slides | 从 Markdown 笔记演示幻灯片 | 只在无敏感内容的测试笔记中练习 |
| Unique note creator | 用时间编码标题创建唯一笔记 | 新建一篇临时想法，再链接回 MOC |
| Format converter | 把外部 Markdown 或旧 Properties 格式转换为当前格式 | **只阅读设置**；它会作用于整个 Vault，运行前必须独立备份 |

### 2. 做一次分类练习

把下面四项填入正确类别：

| 项目 | 正确类别 |
| --- | --- |
| Canvas | 第一方核心插件 |
| Maps | Obsidian 团队维护、需另装的社区插件 |
| Importer | Obsidian 团队维护、需另装的社区插件 |
| Obsidian Publish | 内置 Publish 入口对应的可选付费托管服务 |

### 3. 理解 Publish 的边界

Publish 出现在核心插件列表中，但真正的 Obsidian Publish 是付费云端托管服务。本实验室不会启用或上传。

未来若订阅，只应先用一篇不含隐私的 `Publish Sandbox`：

1. 只选择这一篇测试页。
2. 发布后检查内部链接、Graph 和 Search。
3. 检查站点级密码与公开范围。
4. 完成后取消发布。

社区插件依赖运行时代码渲染的内容通常不会直接在 Publish 工作；嵌入式 `query` 搜索也不受支持。Canvas 与 Bases 的发布支持应以最新 Roadmap 和 Publish limitations 为准。

## 成功标准

- [ ] 我完成了至少三个低风险的核心插件小实验
- [ ] 我能把 Canvas、Maps、Importer、Publish 放进正确类别
- [ ] 我知道 Format converter 为什么不能在没有备份时试运行
- [ ] 我知道删除 Audio embed 不等于删除附件
- [ ] 我知道 Publish 核心插件入口不等于免费或已公开

## 限制与边界

- 官方核心插件清单会随 Obsidian 更新；以实时 Core plugins 页面为准。
- Format converter 会按设置转换整个 Vault，不是当前笔记级实验。
- Audio recorder 不包含官方承诺的剪辑、自动转录或 AI 摘要。
- Random note 的官方核心功能只说明从当前 Vault 随机打开笔记，没有按文件夹、标签或属性过滤。
- Graph 只显示内部链接结构，不判断内容语义。
- Maps 和 Importer 虽由 Obsidian 团队维护，仍是社区插件，需要单独安装并遵守社区插件安全模型。
- Publish 和 Sync 都是可选付费服务；不要在未审查隐私、附件和链接范围时上传。
