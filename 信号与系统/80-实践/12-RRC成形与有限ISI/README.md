# 有限RRC：从同一码字核零点、能量、延时与噪声

这个实验回答：理想的RC零ISI条件，落成有限RRC发收FIR以后还剩什么误差？先读[[信号与系统/50-通信与反演/03-RC与RRC脉冲成形零ISI与采样|RC/RRC主解释]]，把实双边 $N_0/2$、Hz Fourier变换、单位能量与“零点属于合成响应”的合同带来。上一[[信号与系统/80-实践/11-BPSK波形与判决/README|矩形BPSK实验]]的MC结果继续按其原模型使用，本实验不重复它，也不把有限ISI后的错误当同一个 $Q(2)$ 模型。

## 固定输入与两个模型层次

[fixed-inputs.json](fixed-inputs.json) 给唯一实际运行卡：$T=0.001$ s、$E_b=10^{-6}$ J、$N_0=5\times10^{-7}$ J、位串1101001（位1→+，位0→−），序列外符号为0。每个配置都保留完整7位、完整线性卷积和滤波尾部。四个rolloff $\beta=0,0.25,0.5,1$ 检查sinc端点、两种带宽/尾部取舍及可去奇点；span $S=6,12$ 检查截断；每符号样点 $L=8,16$ 检查采样/归一化，而非多采样买额外能量。16个配置全部报告，不从中搜索最漂亮的图。时偏固定 $T/4$，恰为两个网格的整数样点，不插入未知插值器。

理想连续模型是 $G_\beta(f)=T R_\beta(fT)$、$P=\sqrt G$、$p(t)=r_\beta(t/T)/\sqrt T$，$p$ 单位能量、无限支撑。规范源码 [pulse_lab.py](pulse_lab.py) 用闭式计算RC/RRC含 $\beta=0$ 及可去奇点，另从频谱平段/滚降段用4096格复合Simpson积分核时间值、$\int R=1$ 与 $\int R^2=1-\beta/4$。后一条防止把RC峰值1误作能量1。这是作者提供的异路径自查，不是非作者独核。

实际有限运行是**独立定义的数字FIR近似**：

$$u_i=\frac{r_\beta((i-D)/L)}{\sqrt{\sum_{j=0}^{SL}r_\beta((j-D)/L)^2}},\quad D=SL/2,\quad i=0,\ldots,SL.$$

$u$ 无量纲且 $\sum u_i^2=1$；它等价于先对物理采样 $p_i$ 用 $\Delta t=T/L$ 记能量再换到 $\sqrt{\Delta t}$ 坐标。两 $L$ 保持同一单脉冲能量、匹配中心增益及完整支持输出噪声方差，但截断与求积会改变具体旁瓣/样值；不是首包矩形cell-average两网格的逐次恒等关系。若将每tap嵌入宽 $\Delta t$ 的常值小格，它有精确离散能量，但只是近似RRC，且不严格带限。实验只报告tap时间坐标；$SL+1$ 个坐标的首末间隔 $ST$ 不冒称特定DAC保持波形的完整支撑时长。

发送坐标 $x=(A\sum_k a_k\delta[n-kL])*u$，$A=\sqrt{E_b}$；近似物理幅值为 $x/\sqrt{\Delta t}$。接收 $y=x*u_{\rm rev}$，中心延时 $SL$ 个样点；在 $SL+kL$ 取全部7个判决。规范源码不会用循环卷积、从输出0强行对齐、只取中间有利位或丢掉尾部。

## 运行前预期、重要性与失败判据

以下四条是**高重要性**，因为任一归一化、卷积或噪声因子错误都会改变判决与能量结论；通过漂亮的波形图无法抵消它们。

| 具体承重断言 | 不依赖本次观测的预期与有限容差 |
| --- | --- |
| 理想RC符号零点与RRC奇点 | $g(0)=1,g(kT)=0$；$\beta=1$时 $g(T/2)=1/2,r(T/4)=1$，$r(0)=4/\pi$。闭式对频域积分在所列点的绝对差≤$2\times10^{-9}$；回归零点/谱折叠误差≤$10^{-13}$。谱折叠检查是本例有限样点，任意位置的结论仍来自正文互补谱证明。 |
| 能量与有限完整卷积 | $\sum u^2=1$、匹配中心增益1，绝对差≤$2\times10^{-13}$。发送完整数组能量应等于Gram二次型，差≤$2\times10^{-12}\max(E_{\rm frame},E_b)$。不预设每个有限码字都等于 $7E_b$，也不预设有限旁瓣为0。完整链对逐符号叠加的差≤$2\times10^{-12}A$。 |
| 同一噪声/能量合同 | 能量坐标输入噪声方差 $v=N_0/2$，幅值小格平均噪声方差 $v/\Delta t$。完整支持输出方差 $v$、相邻符号协方差 $v g_d[SL+L]$；有限二阶枚举与这些解析值的差≤$2\times10^{-12}v$。不能用启动零填充后的小方差宣称降噪。 |
| 延时与符号/波形目标 | $S=6,L=16$的单滤波器48、合计96样点延时，判决96至192每16个取一次；发送/接收数组长度193/289。$\beta=.5$理想 $B=.75/T$；400/600 Hz在1000 sample/s相同，16点最大差≤$10^{-12}$。零ISI不认证任意带限波形抗混叠。 |

时偏和rolloff有限对照也有明确目标：同一数组、同一误差分母，报告全部7位的无噪声幅值与偏差，不要求人为制造至少一个翻位，不把0次翻位报成一般BER为0。span6→12的比较是本输入上的截断观察，不预设所有指标/参数单调改进。波形和谱图是这些数据的解释图，不增加装饰性的随机或参数扫描。

这些阈值在正式运行前由模型和数值尺度确定。若失败，保留失败目录与stdout，先查闭式奇点、dt权、卷积索引、滤波支持和单位；不放宽到通过或更换输入隐藏错误。[test_pulse_lab.py](test_pulse_lab.py) 是作者回归，包括字面小数组卷积、手算噪声权、奇点和反例，并明确拒绝非法输入；非作者需另用自己的推导和实现核对。

## 二阶有限枚举不等于Gaussian误码仿真

噪声分布的理论接口是实白噪声/正交坐标 Gaussian，沿用主文协方差公式。数值核对只需验证线性映射的二阶矩，不需要重跑几十万随机符号。

选择包含3个输出全部滤波支持的 $N$ 维输入窗口，构造等概率的 $2N$ 个向量 $w=\pm\sqrt{Nv}\,e_j$，$j=0,\ldots,N-1$。它们均值0、协方差恰为 $vI$；把每个向量投到3个接收权向量后，平均 $zz^\mathsf T$ 应得 $vHH^\mathsf T$。本例报告输出下标 $SL,SL+L,SL+L/4$，输入窗口长 $N=SL+L+1$，每个报告输出都能使用全部tap。基准 $S=6,L=16$ 是113维、226个向量。

这个有限分布**不是Gaussian**，也不声称其各坐标独立；只因协方差与指定输入坐标相同，才能用于线性系统二阶验证。没有用它估计Gaussian尾概率、BER、帧错误或CRC漏检。启动反例另故意将输入窗口之前的噪声补0，在输出0只剩首tap，展示方差分母/支持改变；不能把这个边缘结果混入完整支持统计。

输出目录和图不覆盖已有结果。正式16配置计算耗时0.155秒，8项作者回归通过；这只是本次观察，不是一般性能保证。记录见 [author-tests.txt](author-tests.txt)、[author-run.txt](author-run.txt)。输入显式限制正有限物理量、1至32位串、1至4个不同 $\beta\in[0,1]$、1至2个不同偶数span(2至16)与sps(4至32)、能落到所有采样网格的时偏 $[0,.5]T$、偶数Simpson格数256至8192；bool不当计数，NaN/非法串/不相容网格拒绝。这些是有限算例预算，不缩小正文定理的定义域。闭式/积分比较点为0、1/4、1/2、1、2、3及落在 $|t|/T\le8$ 内的可去奇点；频率/时间输出范围是有限的，未声称覆盖任意细微rolloff的所有尾部误差。

有限数据文件：

- [results.json](results/results.json)：实际输入/环境、16配置、理论对照、Gram能量、判决数组、完整3×3协方差与启动反例。
- [pulse.csv](results/pulse.csv)：每个tap的索引、中心时间 $t/T$、无量纲 $u$ 及近似物理脉冲幅值 $u/\sqrt{\Delta t}$，单位 $\mathrm{s}^{-1/2}$。

- [spectrum.csv](results/spectrum.csv)：$\nu=fT$，理想 $G/T$ 与有限DTFT的 $|\sum_nu_ne^{-j2\pi\nu(n-D)/L}|^2/L$。后者周期为 $L$，只输出0至1.5的一段，不是一个严格带限的连续频谱证明。

## 改条件之前先给预测

把 $S$ 缩到2、$\beta$ 改0.1，先预测尾截得更重、但不预设所有指标单调；写哪些量仍应被归一化合同固定。换8位01101001时，先写新的完整卷积长度、判决下标和Gram项，再运行到新目录；CRC代数接口仍回网络原页，本实验没有改生成式。要试别的时偏，先选能落到所有网格的值；真正分数时延需要声明插值/重采样器及其误差，不靠强行取整冒称同一条件。

作者回归、频域异路径和实际执行已完成。非作者另从连续谱用Gauss–Legendre积分生成脉冲，以直接重叠内积核有限相关、Gram能量与噪声协方差，不导入作者函数；已核16个正式配置、另改物理量/位串/rolloff/span/网格/时偏的8个配置及7/8位有限符号枚举的ISI界。两正式SVG在已有CairoSVG中渲染并实际目视，标题/图例、中文、坐标与符号清楚，无截断重叠；这是该渲染器的图像检查，未推定原生Obsidian验收。独立材料和最后逐项结论随本批接收记录。对该批新增重要断言，需要分别核原频谱/奇点/能量、不同实现的有限相关/Gram/噪声协方差、参数改变及图像，而不是重跑旧矩形MC或检查器自身全套测试。

| 外部验证输入/记录 | 要核的断言与失败条件 |
| --- | --- |
