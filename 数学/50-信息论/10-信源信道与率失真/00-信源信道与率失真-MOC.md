# 信源、信道与率失真

知道一个符号的熵，还不能回答一个文件能压多小、经过噪声后能否恢复、允许失真后又能省多少。本组课把这三个问题连起来，并在每一步说明随机对象、计量单位和允许的误差。

熵、交叉熵、KL 与互信息的基本定义统一使用 [[数学/50-信息论/01-熵交叉熵KL散度与互信息|原有定义页]]。本组默认**有限字母表、以 2 为底的对数**；信息量单位是 bit。连续变量、无限字母表、非平稳源和带记忆信道需要另外的条件，不靠改一个符号直接套用这里的定理。

顺序是 1 → 2 → 3 → 4。需要联合/条件概率、期望和方差、有限和、独立性以及极限的基本含义。用到的集中估计、随机码本存在性和覆盖估计均在正文展开，无需先等待一门新课程。

```mermaid
flowchart LR
  X[源符号：k 个] --> S[信源编码：约 kR bit]
  S --> C[信道编码：n 次信道使用]
  C --> W[条件转移律 W]
  W --> D[译码与重建：k 个符号]
```

图里的两个比率不可混用：源编码率是 bit/源符号，信道码率是 bit/信道使用；连接它们的是 $b=n/k$。每秒有几次信道使用，还需要物理层时间模型。

## 用同一条链迁移，而不是积累链接

- **文件与 NLL**：先在 [[计算机知识/60-数据编码与媒体系统/04-压缩原理熵编码字典编码与有损压缩#同一串消息：概率、载荷与文件开销|八符号消息]] 上对照 14 bit 与 16 bit 载荷，再回到第二课区分有限码、模型开销与渐近界。

- **通信与检测**：第三课先固定输入、输出和转移概率。一个检测器的虚警率不是自动得到的 BSC 翻转概率；带宽、同步、调制、均衡与实测 BER 是建立实际信道模型的后续工作。
- **媒体与生成模型**：第四课把理论 $R(D)$ 接到 [[计算机知识/60-数据编码与媒体系统/09-视频编码预测变换量化熵编码与GOP#7. 率失真与码率控制|编码器的 $J=D+\lambda R$]] 和 [[AI/10-机器学习与深度学习基础/22-生成建模自回归VAE流GAN与扩散#VAE：为不可算后验学习一个近似入口|VAE 的重建项与 KL]]；改变失真定义，优化问题随之改变。

## 完成标准与证据边界

每课有可手算例子、条件变化题和答案。能够重写关键估计并解释失败反例，才构成本组的学习目标。文中数字是可复算的教学目标值；具体代码运行、真实编码文件大小、设备吞吐量或真人学习成效，需要各自独立的证据。

有限数值例的独立复算脚本为 [information_finite_oracle.py](../80-运行证据/information_finite_oracle.py)。从知识库根目录运行：

```bash
python3 -B 数学/50-信息论/80-运行证据/information_finite_oracle.py
```

它检查八符号消息的编码/解码、随机相位枚举、条件 NLL、二元串联信道与率失真表；[2026-10-09 运行记录](../80-运行证据/2026-10-09-information-finite-oracle.json) 保存输入、环境和输出。这些有限计算已通过，不能代替一般编码定理的证明，也没有测量真实容器、无线信道或媒体质量。

完整信息论课程还可继续研究连续/高斯模型、多用户网络、反馈、普适编码、有限码长与密码学；这些是明确的后续边界，不作为本组有限离散定理成立的隐含前提。
