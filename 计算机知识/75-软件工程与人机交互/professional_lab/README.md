[[计算机知识/75-软件工程与人机交互/09-专业沟通许可与软件可持续性|09主解释]]给完整机制、许可情境、历史与六题答案；先做[无答案题纸](QUESTIONS.md)。[COMMUNICATION.md](COMMUNICATION.md)是可直接复用结构的模拟工程交接、预约者说明V1/V2、复盘与决策材料，逐句标事实/推断/承诺及责任角色。没有实际客户、外发消息、真人反馈或团队签收；模拟反馈不能改名为可用性结果。

## 什么实际执行，什么需要查原文与现实接口

数值只执行教学卡[energy.json](energy.json)，协议professional-energy-v1；[energy.py](energy.py)用标准库Fraction算精确J/kWh/g，输出精确分数与浮点显示，不采样设备功率。[energy-results.json](energy-results.json)为实际固定7卡结果，与[run/energy-results.json](run/energy-results.json)复建逐值相同。A/B同负载隔离效率；B_double改变总量；B_retries加入内部失败尝试；寿命/碳强度变式是敏感性；B_bad_quality不达Q1，拒绝同功能单位强度。

N是正确完成数。correct_rate/p99是固定功能验收样本的教学质量声明，failed_attempts是最终完成前内部尝试失败，不是同一二项正确率分母；没有把失败请求计入成功数。卡没有模拟真实排队/重试过程或测得延迟，只对给定质量声明作门槛判断。真实评估还需独立需求oracle/负载trace与正确性、延迟、失败/重试观测。

许可条文不由代码裁判。主文逐项定位MIT、Apache2.0、GPLv3-only、AGPLv3-only；精确组件是教学构造，实际项目必须核对包/源码头/NOTICE、修改与组合/网络事实、地区与权利人权限。不同对象的法律分类、未知权利、作品关系、User Product与安装信息不由扫描或本算术脚本签“合规”。CERN历史来源也不授权本课全部代码/内容，未向主库添加整体LICENSE。

## 隔离复建

Python3.10+标准库即可，正式3.14.7；无服务、外部连接、数据库、GPU、额外依赖。操作数为≤24位非负十进制字符串；计数为0..10⁹且拒bool，成功分母正；1..32卡，资源份额(0,1]、0<窗口≤寿命、设施系数≥1。质量正确率0..1、门槛(0,1]；内存与时间不随请求数迭代，只作有限分数算术。卡是明确有限教学域，不是任意JSON碳核算系统。

从本目录运行，输出目录必须新建：

```sh
python3 -B /private/tmp/wwl-next-context/run_local.py --timeout 60 -- /opt/homebrew/opt/python@3.14/bin/python3.14 -B run_checks.py --out /private/tmp/professional-rebuild-176
```

脱离本工作台可用本机解释器直接运行run_checks并提供同等超时。它顺序运行energy CLI与3单测，保留每阶段原stdout/stderr，子进程10秒超时；新输出目录在运行中失败时可能留部分材料，须看退出码/两阶段完整记录。energy CLI也拒已有输出文件，但目标父目录须存在；不能覆盖旧结果后声称重复运行相同。独立只算新卡：

```sh
python3 -B energy.py --input /private/tmp/my-energy-176.json --out /private/tmp/my-energy-result-176.json
python3 -B plot_energy.py --results /private/tmp/my-energy-result-176.json --out /private/tmp/my-energy-176.svg
```

图程序从同一results.input取N/e/T/EL/I标签，并随保存结果调整总量条长；不再用固定标签假装支持变卡。它写入指定SVG，可覆盖该文件，应选自己的新路径；至少一张通过质量门的卡才可画。图为保存分摊结果的展示，不是第二个独立oracle。正式[SVG](energy.svg)和[1600px PNG](energy.png)已实际目视：总量/强度单位、质量拒绝、标签均可读；未在Obsidian客户端预览。PNG用既有隔离resvg_py0.5.0与macOS PingFang字体生成，字体/栅格器改变可改像素。可选显示复建例，不是数值依赖：

```python
from pathlib import Path
import resvg_py
p = Path('/private/tmp/my-energy-176.svg')
p.with_suffix('.png').write_bytes(resvg_py.svg_to_bytes(
    svg_string=p.read_text(), width=1600,
    font_files=['/System/Library/Fonts/PingFang.ttc']))
```

## 现实接口：重要而不能伪造

- **沟通/恢复（高）**：指定客户端/服务部署身份、脱敏对象与同一时区原始事件、实际恢复/通知状态、支持更新负责人；由获授权团队使用材料，真人按任务复述下一动作。错误判据是承诺超证据、状态含糊导致错误再申请或受影响者不能采取动作。本课没有外发或招募真实反馈。
- **许可/权利（高）**：真实组件的精确包/源码/NOTICE及权利来源、修改/连接/复制交付/网络交互与地区/合同；由有责任与权限者审查未知关系。条款无法同时满足、来源缺失或组合事实未知时，应由项目负责人决定排除、替换、补授权或等待；本页不是司法裁定，也未对真实项目审计。
- **可持续性（高）**：同质量工作负载及正确成功数、失败/重试/延迟，校准电量采集端口/采样区间/闲置基线、预留资源/设施边界、网络终端/监测备份、设备LCA/寿命/维修与时空电网因子。单位/J→kWh错、漏重大项、制造重复分摊、质量不同或分母漂移均应拒比较。无功率计/云遥测/采购LCA或生产碳强度实测；代码执行不能填成设备完成。

这些接口是将来真实决策需要的证据，不为本课额外制造一个平台或要求穷尽所有法域/硬件。当前原课程的沟通、条款应用、有限工作负载/敏感性与有来源历史可独立学习；真人、项目法律结论与实际排放成效仍各守边界。
