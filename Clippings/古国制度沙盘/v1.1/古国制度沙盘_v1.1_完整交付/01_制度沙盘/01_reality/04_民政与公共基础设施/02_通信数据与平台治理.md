# 通信、数据与平台治理（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：电信许可与普遍服务、无线电频谱、网络安全、数据安全、个人信息、数据跨境、算法推荐、网络交易平台及直播电商。
- 内容治理、国家秘密、密码、地图和新闻出版等另有专门制度，本文件不作穷尽列举。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 电信 | 《电信条例》现行文本最后一次行政法规层面修改在2016年；基础与增值电信业务实行分类许可，通信资源、互联互通、服务质量和用户权益受行业监管。 |
| 网络与数据 | 2025年修订的网络安全法已于**2026-01-01**施行；数据安全法、个人信息保护法和2025年起施行的网络数据安全管理条例共同构成主干。 |
| 数据跨境 | 2024年规定对安全评估、个人信息标准合同和认证的适用范围作了调整，重要数据和达到数量门槛的个人信息仍受专门程序约束。 |
| 平台 | 算法推荐、网络交易、价格行为和直播电商分别受网信、市场监管及相关行业规则约束；《网络交易平台规则监督管理办法》与《直播电商监督管理办法》均为2025年发布、自2026-02-01施行的部门规章。 |
| 临近生效规则 | 网络数据安全风险评估办法将于**2026-08-20**施行，小型个人信息处理者规定将于**2026-09-01**施行；二者在核对日尚未生效，只作时点提示。大型网络数据处理者相关规定仍处征求意见阶段。 |

## 现行结构摘要

1. **通信网络实行许可与资源管制。** 工业和信息化主管部门及省级通信管理机构负责电信业务许可、码号、互联互通、服务质量和网络运行；频谱属于国家所有并按规划、许可或指配使用。
2. **普遍服务通过财政项目补足。** 中央财政安排电信普遍服务补助，支持农村、边疆等地区网络建设和运行；年度预算持续存在，绩效由财政与行业主管部门管理。
3. **网络安全按运营者和设施分层。** 网络运营者负有等级保护等义务，关键信息基础设施运营者承担更高安全要求；违法责任和监管机关权限分布在网信、公安、通信及行业部门。
4. **数据按风险分类治理。** 数据处理者承担安全管理、事件处置和重要数据义务；个人信息处理还须具备法定处理基础、履行告知并保障查阅、更正、删除等权利。
5. **平台兼具市场与规则制定者属性。** 平台需核验经营者、保存交易信息、治理违法内容和商品服务，并对价格、算法、直播营销、收费和退出规则承担特定义务。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 网络接入—市场竞争 | 基础网络具有高固定成本和资源稀缺性，牌照、互联结算、设施共建共享及批发接入决定下游竞争条件。 |
| 普遍服务—财政绩效 | 补贴把覆盖目标转为建设项目，但覆盖率、可负担价格、实际速率和长期运维需分别衡量。 |
| 网安—数据—个人信息 | 同一处理活动可能同时触发网络运行安全、重要数据和个人权利规则，主管机关和评估程序可能交叉。 |
| 数据跨境—国际业务 | 数据类型、是否属于重要数据、个人信息数量和接收方安排共同决定豁免、合同、认证或安全评估路径。 |
| 算法—内容—竞争 | 推荐算法既涉及内容生态与用户选择，也可能影响商户排序、差别定价和自营优待，需要多机关协同。 |
| 平台处分—程序救济 | 删除内容、下架商品、限流、封号和终止服务通常先依平台规则执行，用户、劳动者或商户的说明和申诉权由不同规则分别保障。 |

## 可观察约束与信息缺口

- 通信、网信、公安、市场监管及行业部门的管辖边界重叠，个人或企业难以判断一个复合争议的最终责任机关。
- 电信批发价格、互联结算成本、网络拥塞和普遍服务项目实际质量缺少稳定、细颗粒度公共数据。
- “重要数据”目录由地区和部门推进，企业在跨行业、跨地区识别时仍可能面临口径不一致。
- 算法备案证明完成行政备案，不等同于外部可验证的公平、安全、可解释审计；核心参数和训练数据通常不公开。
- 数据出境便利化与安全评估并存，全球业务需要持续判断数据分类、数量门槛和多法域义务。
- 平台掌握流量、交易、申诉和风控证据，监管者、商户、劳动者和消费者在取证上处于不对称地位。
- 即将生效或仍在征求意见的规则会快速改变合规边界，任何时点档案都需要保留生效日期而非只记录发布日期。

## 古国改革需回答的问题

1. 基础网络是否进行结构分离、开放接入或价格监管，互联争议由谁快速裁决？
2. 普遍服务要保障覆盖、速度、可靠性还是可负担价格，补贴如何公开招标并按结果支付？
3. 是否设置独立数据保护机关；网安、执法取证、行业监管和个人权利之间怎样划界？
4. 个人信息处理基础、敏感信息、自动决策、访问删除、群体诉讼和损害赔偿如何设计？
5. 公共数据、企业数据和个人数据的授权、收益、开放与撤回机制分别是什么？
6. 算法应公开到什么程度，谁有权进行保密审计、测试歧视和要求人工复核？
7. 平台收费、排序、自营优待、封禁和规则变更需提前多久通知，申诉是否暂停处分？
8. 数据跨境、网络中断或服务关闭需满足何种法定条件、期限、补偿和司法审查？
