# 信号处理与多模态数学 MOC

图像、声音和扩散过程看起来属于不同领域，数学上却可以先用同一句话理解：**对象被表示成带坐标的数值信号，模型对这些数值做局部变换、频率分解或随机演化。**

本专题只建设第一阶段需要的数学桥梁，不讲具体的 VLM、语音模型或扩散模型架构。完整模型课程留在对应的 planned MOC 中。

## 先修边界

### 第一阶段共同最低先修

开始前，只需能够：

1. 把一串数或一个像素网格看成向量、矩阵或张量；
2. 理解函数、正弦波、求和符号和坐标；
3. 知道均值、方差和高斯分布表达“中心附近多、远处少”；
4. 把导数理解为瞬时变化率，把梯度理解为“增长最快的方向”。

## 共同概念地图

```text
现实对象
  ├─ 图像：空间坐标 (x, y) → 像素值
  ├─ 声音：时间坐标 t → 空气压力的数字近似
  └─ 数据分布：状态 x + 噪声时间 t → 概率密度
          ↓
离散表示：像素 / 样本 / 有限维向量
          ↓
局部或尺度变换：Patch、卷积、窗口、加噪
          ↓
另一种观察坐标：空间频率、时频平面、score 场
```

三类变换都在回答两个问题：

- 哪些信息被保留、压缩或丢弃？
- 结论依赖哪些假设、边界条件和尺度？
