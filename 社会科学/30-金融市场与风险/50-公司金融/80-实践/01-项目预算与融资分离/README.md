## 现实融资与治理的未验接口

真实资本预算的重要输入：决策日期与被冻结版本、主体/币种/名义实际/期间、已签订单及交付/开票/回款、付费任务与利用率分母、增量人工/返工和共享成本、资本支出与维护、经营NWC、残值与退出义务。逐项附原始凭证或披露定位，明确与“不采用”的现金差；沉没成本不能只凭名称决定，若停做可退则并非沉没。机会成本须有真实可行替代用途与相关税现金，不能取公司内部任意分摊价。

税需选真实法域/日期/纳税主体和一手规则，核折旧、亏损抵扣与结转、利息限制、销售税/出售利得、缴纳时间及其他业务合并；本课max税函数不替代这些。终值要说明清算/继续经营、税、关闭成本及是否已经包含在末期现金，不因项目负NPV就补一个无依据“战略正值”。资本成本需有可比风险、期限和可交易证据或允许价格区间；实际融资报价还包含担保、违约、服务费和选择，不能直接拿历史借款利率贴所有经营项目。

融资/治理目标必须先固定，例如某额度/契约的改变对同类合格企业投资或现金短缺的作用；记录申请、资格、要约、接受、实际提款、经营用途和权利执行，保留拒绝、未回应、缺失与提前行为。随机额度/政策阈值或合适对照仍需分配/遵从、排除限制、操纵与市场溢出条件。项目质量影响融资，又影响收益；用已融资公司与未融资公司的平均回报差，不能分离资金、选择与控制权。复用计量主解释的反事实与独立单位，按企业/融资批次/地区冲击确定依赖结构，不把同企业多张账单当很多独立治理实验。

权利证据还需股类、投票/否决、董事/经理目标、可变更经营政策、追加融资、担保与违约程序及相应法源。若负债改变投资风险、员工/客户承担下行或执行失败，固定经营X与本页福利边界就可能失效。代理冲突与信息/选择的完整有限模型接[[社会科学/30-金融市场与风险/50-公司金融/03-融资信息治理激励与实物期权|03]]；税盾/困境及政策一致估值接02。支付表闭合仍不证明实际契约有效或实现治理改善。
