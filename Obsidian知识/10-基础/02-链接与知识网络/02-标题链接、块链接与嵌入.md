# 标题链接、块链接与嵌入

普通链接带你到一篇文件；标题链接和块链接把目标缩小到文件里的一个位置；在它们前面加 `!`，就能把源内容显示在当前笔记中。

## 1. 链到标题

输入 `[[文件名#` 后继续搜索标题。这个真实链接会直接跳到一个小节：

[[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/渐进式总结#三层摘要|查看“三层摘要”小节]]

语法形状：

```text
[[目标笔记#标题]]
[[目标笔记#标题|更自然的显示文字]]
```

标题链接适合引用稳定的小节。若标题经常变化，重命名后应检查引用是否仍符合语义。

## 2. 链到块

“块”通常是一个段落、列表项、引用或其他可单独定位的内容。在链接建议中输入 `^` 可以搜索块；也可以在源段落末尾给它一个稳定 ID。

[[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/渐进式总结#^progressive-core|跳到一条核心结论]]

对应语法：

```text
[[目标笔记#^block-id]]
```

> [!tip] 什么时候使用固定块 ID
> 需要长期引用的关键定义可以使用可读的固定 ID。临时引用也可让 Obsidian 自动生成 ID。不要给每一段都编号，否则维护成本会超过收益。

## 3. 嵌入，不复制

下面不是复制进来的文字，而是对源标题的嵌入：

![[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/渐进式总结#三层摘要]]

下面只嵌入一个块：

![[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/渐进式总结#^progressive-core]]

修改源笔记后，所有嵌入位置都会显示新内容。这使“一个事实只有一个权威来源”成为可能，也避免复制产生多个漂移版本。

## 轮到你做

1. 在 Source mode 查看上面两个嵌入，注意开头的 `!`。
2. 打开源笔记 [[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/渐进式总结|渐进式总结]]。
3. 在“三层摘要”末尾加一句自己的话。
4. 返回本页，观察嵌入是否同步变化。
5. 悬停块链接，确认 Page preview 能直接预览目标段落。

## 检查结果

- 链接会导航，嵌入会在当前位置渲染源内容。
- 标题链接的目标是小节，块链接的目标更细。
- 嵌入也会计入源笔记的 Backlinks，因为当前笔记确实引用了它。

## 挑战与复原

挑战：把自己刚写的句子单独做成一个块，再从实验区嵌入它。

复原：撤销源笔记里的练习改动和实验区嵌入；保留 `^progressive-core`，其他课程依赖这个固定样例。
