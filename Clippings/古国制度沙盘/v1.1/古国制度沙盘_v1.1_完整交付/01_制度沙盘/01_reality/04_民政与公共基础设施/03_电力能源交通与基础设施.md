# 电力、能源、交通与基础设施（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：能源与电力治理、电力市场和输配电价、综合交通规划，以及政府投资、企业投资和基础设施特许经营的建设融资接口。
- 水利、市政供水、燃气、邮政和单一交通方式的全部技术规章不在本文穷尽列举之内。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 能源 | 《能源法》自2025-01-01施行，确立能源规划、开发利用、市场体系、储备应急、科技和监督等总框架。 |
| 电力 | 现行电力法为2018年修正文本；2024年电力市场运行基本规则、供电营业和供电监管规则已经施行。 |
| 全国电力市场 | 2026年2月进一步提出全国统一电力市场建设实施安排；它属于推进市场建设的政策文件，不替代电力法和部门规章。第四监管周期省级电网输配电价自2026-08-01执行。 |
| 综合交通 | 2035年国家综合立体交通网规划纲要仍是长期规划主干；2026年综合交通运输体制机制改革意见和2026—2030年多式联运行动方案处于实施期。 |
| 投资建设 | 政府投资适用2019年行政法规，企业投资实行核准目录与备案，基础设施和公用事业特许经营适用2024年施行的部门规章。 |

## 现行结构摘要

1. **能源统筹与分行业实施并行。** 能源主管部门负责战略、规划和政策，电力、煤炭、油气、新能源等仍有各自许可、项目管理、价格与安全规则；生态环境、自然资源和应急管理等共同介入。
2. **电网自然垄断与竞争性环节并存。** 输电、配电网络由受监管企业经营并执行核定输配电价；发电、售电、电力用户和储能等通过中长期、现货、辅助服务等市场交易逐步形成价格。
3. **供电区域和普遍服务受监管。** 供电企业在批准区域提供服务，承担可靠供电、报装接电、计量收费和用户权益义务；居民、农业和不直接参与市场的用户仍通过代理购电等机制连接市场。
4. **交通按方式管理、向综合协同推进。** 铁路、公路、水运、民航、邮政等存在不同管理和运营体系，国家规划通过综合通道、枢纽和多式联运连接，2026年改革继续推动标准、数据和运输组织衔接。
5. **基础设施资金来源多元。** 中央预算内投资、地方财政和政府债券、政策性开发性金融、国有企业和社会资本共同参与；项目性质决定采用政府投资审批、企业核准备案或特许经营。
6. **特许经营不是无条件财政担保。** 政府应通过竞争方式选择经营者并约定建设运营、价格、服务和风险；规则禁止以保底收益、回购等方式变相新增地方政府隐性债务。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 电力市场—电网监管 | 发售电交易价格与受监管的输配电价叠加，调度、阻塞、损耗和辅助服务规则决定实际结算。 |
| 能源安全—低碳转型 | 保供、储备、可再生能源消纳、煤电调节和碳排放目标共同影响项目许可、调度和成本分担。 |
| 中央规划—地方项目 | 国家网络规划、地方空间规划和具体项目审批相互约束，跨省通道还涉及受益与成本的地区分配。 |
| 建设—运营维护 | 项目立项强调建设必要性和资金来源，长期维护、更新、灾害韧性和退役成本需在预算或经营合同中持续落实。 |
| 特许经营—价格监管 | 社会资本回报依赖使用者付费、可行性缺口补助或其他依法约定收入，收费调整和服务标准需要兼顾可负担性。 |
| 交通方式—统一服务 | 多式联运需要统一单证、责任、数据接口、枢纽换装和收费结算，但各方式法规和运营主体仍不同。 |

## 可观察约束与信息缺口

- 电力市场跨省交易扩大，但地方保供责任、既有合同、容量保障和省间利益分配仍可能形成市场分割。
- 输配电成本监审和核价结果有公开文件，电网分区成本、投资效率、阻塞收益和服务质量数据仍不够细。
- 新能源并网、调度、限电补偿、储能收益和煤电容量成本处在持续调整中，投资者与用户承担风险的边界不稳定。
- 大型交通与基础设施项目前期评估、替代方案、全生命周期成本和后评价材料并非总能以统一格式公开。
- 建设融资与运营现金流跨越多年，特许经营重谈、最低需求偏差、国企融资和地方财政支持的真实风险需穿透识别。
- 各交通方式的客货流、价格、延误、事故、碳排和无障碍服务指标口径分散，难以进行综合绩效比较。

## 古国改革需回答的问题

1. 能源规划、市场监管、安全监管和国有能源资产所有者是否组织分离，独立监管者向谁负责？
2. 输配电价如何核定并公开成本，发电与零售市场怎样保护小用户免受价格冲击？
3. 电网接入、调度、弃电、容量和辅助服务的权利义务及争议裁决如何设计？
4. 能源贫困、偏远地区供能和减排成本由一般财政、全体用户还是排放者负担？
5. 基础设施立项是否必须公开需求预测、替代方案、生态社会影响和全生命周期财政承诺？
6. 特许经营的招标、调价、超额收益分享、重谈、提前终止和接管怎样预先约定并公开？
7. 综合交通由单一机关统筹还是保持分业；票务、货运单证、数据和事故责任如何跨方式衔接？
8. 可达性、可靠性、韧性、无障碍和碳排放怎样成为与建设里程同等重要的绩效指标？
