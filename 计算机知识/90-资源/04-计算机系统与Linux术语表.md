# 计算机系统与 Linux 术语表

这是一张按系统分层和排错主题组织的速查表，不是字母表。遇到陌生术语时，先判断它属于硬件、启动、内核、用户空间、存储、命令行、软件包还是网络，再跟随“课程”列进入上下文。

> [!tip] 一条排错规则
> 先说出对象所在层，再选工具：内核版本、服务状态、文件权限、软件包与 DNS 结果分别回答不同问题，不能互相代替。

## 1. 硬件与启动链

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **硬件（hardware）** | CPU、RAM、存储器和外设等实际执行计算、保存状态或完成 I/O 的物理部件，虚拟机中则可由虚拟硬件接口模拟。 | 不是 `/dev` 中的设备节点，也不是驱动程序。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |
| **CPU** | CPU 是取指令、执行运算并提供特权级、中断和内存管理配合机制的处理器。 | 不是进程；进程是被内核调度到 CPU 上执行的运行环境。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |
| **内存（RAM）** | RAM 是保存当前活跃代码和数据的易失性存储，内核通过虚拟内存机制将它分配给进程使用。 | 不是进程看到的整个虚拟地址空间，也不是 SSD 等持久存储。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |
| **固件（firmware）** | 固件是在主板或设备上提供低层初始化与控制逻辑的软件，部分设备固件会由内核驱动在运行时加载。 | 不是驱动：固件通常在设备一侧运行，驱动在主机内核一侧控制设备。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]]、[[计算机知识/20-操作系统/01-Linux/09-设备驱动内核模块与udev\|设备驱动、内核模块与 udev]] |
| **UEFI** | UEFI 是现代平台固件接口与启动环境，它依据启动项执行 EFI 程序并把链条交给下一阶段。 | 不是 Linux 内核，也不必然就是 bootloader 本身。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]] |
| **引导程序（bootloader）** | bootloader 是选择并装载内核与可选 initramfs、传递启动参数后将控制权交给内核的程序。 | 不是 init 或 systemd，因为后两者在内核已运行后才进入用户空间启动。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]] |
| **initramfs** | initramfs 是内核启动早期解包到内存中的临时根文件系统，用于加载必需模块并找到真正根文件系统。 | 不是最终根文件系统，也不是 bootloader 或 kernel image。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]] |
| **Linux 内核（kernel）** | kernel 是在特权态管理 CPU、内存、进程、文件系统、网络和设备，并向用户空间提供系统调用的核心软件。 | 不是整个发行版，也不是 shell、systemd 或 GNU 命令集。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |

## 2. 内核与用户空间的执行边界

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **用户空间（user space / userland）** | 用户空间是应用、库、shell 和大多数服务在受限 CPU 特权下运行的软件与执行环境。 | 不是“非 root 用户的空间”，root 进程也主要在用户态执行。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |
| **系统调用（system call / syscall）** | syscall 是用户空间程序请求 Linux 内核完成受保护操作的基本接口。 | 不是任意函数调用或 shell 命令，库函数也可以完全不发起 syscall。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |
| **进程（process）** | 进程是带有 PID、凭据、虚拟地址空间、文件描述符和调度状态的运行中执行环境。 | 不是磁盘上的静态程序文件，同一程序可有多个进程。 | [[计算机知识/20-操作系统/01-Linux/06-用户权限进程与作业控制\|用户、权限、进程与作业控制]] |
| **线程（thread）** | 线程是进程内可被调度的执行流，同一进程的多个线程通常共享地址空间和打开资源。 | 不是完整隔离的进程，也不与 CPU 核数一一对应。 | [[计算机知识/20-操作系统/01-Linux/06-用户权限进程与作业控制\|用户、权限、进程与作业控制]] |
| **PID** | PID 是内核在某个 PID namespace 中用来标识进程的数字。 | 不是程序名或全球永久身份，进程退出后 PID 可被复用。 | [[计算机知识/20-操作系统/01-Linux/06-用户权限进程与作业控制\|用户、权限、进程与作业控制]] |
| **文件描述符（file descriptor / FD）** | FD 是某个进程内引用已打开文件、管道、socket 或终端等 I/O 对象的非负整数句柄。 | 不是路径或 inode 号，也不在不同进程间具有全局相同含义。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |
| **虚拟内存（virtual memory）** | 虚拟内存是内核与 CPU 把进程地址空间映射到物理页、文件或其他后备存储的机制。 | 不是“假 RAM”的别名，虚拟映射总量也不等于进程独占物理内存。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |

## 3. 存储、文件系统与命名

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **设备（device）** | 设备是内核可识别并管理的硬件或虚拟 I/O 对象。 | 不是必然存储数据的磁盘，也不等于用户空间看到的 `/dev` 设备节点。 | [[计算机知识/20-操作系统/01-Linux/09-设备驱动内核模块与udev\|设备驱动、内核模块与 udev]] |
| **块设备（block device）** | 块设备是以可寻址数据块提供 I/O 的设备接口，常见于磁盘、SSD 和逻辑卷。 | 不是文件系统，一个块设备可以未分区、未格式化或作为其他层的容器。 | [[计算机知识/20-操作系统/01-Linux/03-目录结构挂载与文件系统\|目录结构、挂载与文件系统]] |
| **分区（partition）** | 分区是块设备上由分区表描述的一段逻辑范围。 | 不是文件系统或挂载点，分区中可以存放文件系统、swap、LVM 或其他数据。 | [[计算机知识/20-操作系统/01-Linux/03-目录结构挂载与文件系统\|目录结构、挂载与文件系统]] |
| **文件系统（filesystem）** | 文件系统是组织文件、目录、元数据与空间分配的格式和语义，也可以是 procfs 这类无块设备后端的虚拟接口。 | 不是分区或目录树的同义词，文件系统需经挂载才接入某个 mount namespace。 | [[计算机知识/20-操作系统/01-Linux/03-目录结构挂载与文件系统\|目录结构、挂载与文件系统]] |
| **挂载（mount）** | 挂载是把一个文件系统的根接到当前 mount namespace 中某个目录位置的操作。 | 不是复制数据、格式化分区或“让磁盘通电”。 | [[计算机知识/20-操作系统/01-Linux/03-目录结构挂载与文件系统\|目录结构、挂载与文件系统]] |
| **挂载点（mount point）** | 挂载点是目录树中承接某个已挂载文件系统的目录位置。 | 不是分区或设备本身，卸载后该目录仍可存在。 | [[计算机知识/20-操作系统/01-Linux/03-目录结构挂载与文件系统\|目录结构、挂载与文件系统]] |
| **inode** | inode 是某个文件系统内记录文件类型、权限、所有者、时间和数据位置等元数据的对象。 | 不是文件名、完整路径或 FD，目录项把名称映射到 inode。 | [[计算机知识/20-操作系统/01-Linux/03-目录结构挂载与文件系统\|目录结构、挂载与文件系统]] |
| **路径（path）** | 路径是从根目录或当前目录出发、由名称分量组成的文件系统查找表达式。 | 不是文件对象的永久身份，同一 inode 可因硬链接拥有多个路径。 | [[计算机知识/20-操作系统/01-Linux/05-文件目录与文本处理命令\|文件、目录与文本处理命令]] |

## 4. init、服务与设备管理

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **init** | init 是内核启动的用户空间起点，在完整主机上通常为 PID 1 并负责组织其他服务和进程。 | 不是 kernel 或 bootloader，容器中的 PID 1 也可以是其他程序。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]] |
| **systemd** | systemd 是一套用户空间系统与服务管理组件，其 systemd 管理器在许多发行版中作为 init。 | 不是 Linux 内核，也不代表所有以 Linux 为内核的系统都必须使用它。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]] |
| **服务（service）** | 服务是为其他程序或用户长期提供网络、日志、时间或其他功能的受管理进程或工作单元。 | 不是内核功能的同义词，`systemctl` 状态也不等于服务端到端功能已经验证。 | [[计算机知识/20-操作系统/01-Linux/02-启动链Kernel与systemd\|启动链、Kernel 与 systemd]]、[[计算机知识/20-操作系统/01-Linux/10-网络存储日志与故障排查\|网络、存储、日志与故障排查]] |
| **驱动程序（driver）** | driver 是在内核一侧理解特定设备协议并将其能力接入内核子系统的代码。 | 不是设备固件、`/dev` 节点或 udev 规则。 | [[计算机知识/20-操作系统/01-Linux/09-设备驱动内核模块与udev\|设备驱动、内核模块与 udev]] |
| **内核模块（kernel module）** | kernel module 是可在运行时加入或移出内核的代码单元，许多驱动以此形式提供。 | 不是 Python module，也不是所有驱动的必然形式，因为驱动也可内建进 kernel image。 | [[计算机知识/20-操作系统/01-Linux/09-设备驱动内核模块与udev\|设备驱动、内核模块与 udev]]、[[计算机知识/10-编程语言/01-Python/07-模块包导入与项目结构\|Python 模块、包、导入与项目结构]] |
| **设备节点（device node）** | 设备节点是 `/dev` 中带有主、次设备号的特殊文件系统对象，它为用户空间提供访问对应内核设备接口的名称。 | 不是物理设备本身，删除节点也不等于拔掉硬件。 | [[计算机知识/20-操作系统/01-Linux/09-设备驱动内核模块与udev\|设备驱动、内核模块与 udev]] |
| **udev** | udev 是在用户空间处理内核设备事件、管理设备节点并应用命名与权限规则的设备管理机制。 | 不是驱动或固件，udev 能看到设备事件不代表设备已完成功能验证。 | [[计算机知识/20-操作系统/01-Linux/09-设备驱动内核模块与udev\|设备驱动、内核模块与 udev]] |

## 5. Shell、环境与命令定位

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **终端（terminal）** | 终端或终端模拟器是承载字符输入输出的界面与应用，shell 通常运行在其中。 | 不是 shell、命令或 kernel，关闭终端窗口也可能通过会话与信号机制影响其中作业。 | [[计算机知识/20-操作系统/01-Linux/04-Shell命令行与帮助系统\|Shell、命令行与帮助系统]] |
| **Shell** | Shell 是解析引用、展开、管道和重定向，执行内建命令或启动外部程序的用户空间命令解释器。 | 不是终端或 Linux 内核，也不是每条命令都会创建外部进程。 | [[计算机知识/20-操作系统/01-Linux/04-Shell命令行与帮助系统\|Shell、命令行与帮助系统]] |
| **Shell 变量** | Shell 变量是当前 shell 自身维护的名称与值，只有被导出后才通常进入后续子进程的环境。 | 不是自动全局可见的环境变量，也不会因赋值就反向改变父进程。 | [[计算机知识/20-操作系统/01-Linux/07-环境变量Shell启动与PATH\|环境变量、Shell 启动与 PATH]] |
| **环境／环境变量（environment / `env`）** | 进程环境是创建新程序时传递的字符串键值集合，`env` 命令可查看环境或在修改后执行程序。 | 不是整台系统共享的唯一全局字典，也不是 Python venv。 | [[计算机知识/20-操作系统/01-Linux/07-环境变量Shell启动与PATH\|环境变量、Shell 启动与 PATH]] |
| **`PATH`** | `PATH` 是以冒号分隔的目录列表，shell 在命令名不含斜杠时按顺序用它定位可执行文件。 | 不是某一个文件的 path，也不是 Python 导入搜索使用的 `sys.path`。 | [[计算机知识/20-操作系统/01-Linux/07-环境变量Shell启动与PATH\|环境变量、Shell 启动与 PATH]]、[[计算机知识/10-编程语言/01-Python/07-模块包导入与项目结构\|Python 模块、包、导入与项目结构]] |

## 6. 发行版、仓库与软件包

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **发行版（distribution）** | 发行版是将 Linux 内核、用户空间工具、软件库、默认配置、包管理与更新策略组装成可维护系统的项目。 | 不是 Linux 内核的同义词，同一内核世系可被不同发行版以不同策略组装。 | [[计算机知识/20-操作系统/01-Linux/01-计算机系统与Linux分层\|计算机系统与 Linux 分层]] |

| **系统软件包（package）** | 系统软件包是发行版包管理器用来追踪文件、版本、依赖、安装脚本与签名状态的分发单元。 | 不是正在运行的进程，也不是 Python 的导入包或 PyPI 分发包。 | [[计算机知识/20-操作系统/01-Linux/08-pacman-apt-dnf与yum包管理\|pacman、apt、dnf 与 yum 包管理]]、[[计算机知识/10-编程语言/01-Python/08-pip与PyPI依赖管理\|pip、PyPI 与依赖管理]] |
| **包管理器（package manager）** | 包管理器是解析仓库元数据与依赖、验证来源并以事务方式安装、升级或移除软件包的工具。 | 不是所有生态的通用名称，`pacman`、`apt`、`dnf`、`pip` 和 `uv` 的管理边界不同。 | [[计算机知识/20-操作系统/01-Linux/08-pacman-apt-dnf与yum包管理\|pacman、apt、dnf 与 yum 包管理]]、[[计算机知识/10-编程语言/01-Python/12-包管理器选择锁定与迁移\|Python 包管理器选择、锁定与迁移]] |
| **依赖（dependency）** | 依赖是某个软件包或项目在构建、安装或运行时需要的其他组件与版本条件。 | 不是“仓库中最新版就一定兼容”，声明范围、当前安装快照与锁定结果也是不同对象。 | [[计算机知识/20-操作系统/01-Linux/08-pacman-apt-dnf与yum包管理\|pacman、apt、dnf 与 yum 包管理]]、[[计算机知识/10-编程语言/01-Python/08-pip与PyPI依赖管理\|pip、PyPI 与依赖管理]] |

## 7. 网络定位、选路与连接

| 术语 | 一句定义 | 不要混淆 | 课程 |
| --- | --- | --- | --- |
| **网络接口（interface）** | 网络接口是内核用于收发网络包的逻辑端点，它可对应物理网卡、虚拟设备或 loopback。 | 不是 IP 地址，一个接口可有多个地址，一个地址也有自己的作用域。 | [[计算机知识/20-操作系统/01-Linux/10-网络存储日志与故障排查\|网络、存储、日志与故障排查]] |
| **IP 地址** | IP 地址是在特定网络与作用域中用来定位接口并参与分组交付的第三层逻辑地址。 | 不是 DNS 名称、MAC 地址或端口号，有 IP 也不等于到目标已有可用路由。 | [[计算机知识/20-操作系统/01-Linux/10-网络存储日志与故障排查\|网络、存储、日志与故障排查]] |
| **路由（route）** | 路由是内核根据目标前缀选择下一跳、输出接口与其他参数的转发规则。 | 不是 DNS 解析或应用连接，默认路由存在也不证明远端服务可达。 | [[计算机知识/20-操作系统/01-Linux/10-网络存储日志与故障排查\|网络、存储、日志与故障排查]] |
| **网关（gateway）** | 网关是路由规则中代为本机把分组继续转发到其他网络的下一跳设备地址。 | 不是 DNS 服务器或“互联网”本身，同一主机也可有多条选路规则。 | [[计算机知识/20-操作系统/01-Linux/10-网络存储日志与故障排查\|网络、存储、日志与故障排查]] |
| **DNS** | DNS 是将域名等名称查询为 IP 地址或其他记录的分布式命名系统。 | 不是 TCP 连接、路由或应用服务，解析成功不代表目标端口可达。 | [[计算机知识/20-操作系统/01-Linux/10-网络存储日志与故障排查\|网络、存储、日志与故障排查]] |

## 最短对照链

| 遇到的现象 | 先分清这条链 |
| --- | --- |
| 开机后找不到系统 | `UEFI 启动项 → bootloader → kernel/initramfs → 根文件系统 → init` |
| 程序无法读写文件 | `path → mount point → filesystem → inode/权限 → 当前进程凭据 → FD` |
| 设备没有正常工作 | `device → driver/module → firmware → udev/device node → 用户空间应用` |
| 命令“不存在” | `shell 解析 → PATH 搜索 → 可执行文件 → 动态库/解释器 → process` |
| 域名能解析但服务不通 | `DNS 结果 → IP 与 route → socket/端口 → 远端服务 → 应用协议` |
| `pip` 安装后仍无法导入 | `PATH 中的 Python 解释器 → venv/sys.prefix → pip 安装目标 → distribution → import package` |
