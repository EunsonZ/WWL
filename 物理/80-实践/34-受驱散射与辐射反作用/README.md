# 受驱散射与反作用：三个有限核算

唯一计算和图源是 [scattering.py](scattering.py)，全部输入在 [inputs.json](inputs.json)，原始结果在 [output/results.json](output/results.json)。Python 3标准库，单进程单线程，不安装、不联网。进入本目录，用一个尚不存在的目录保存新结果：

```bash
python3 -B scattering.py --inputs inputs.json --output /tmp/wwl-scattering-new-run
```

输出目录已存在则拒绝执行，保护旧输出。修改输入时先复制，完成预测后再运行；表中数值只对应随附输入。

## 三个有限核算分别说明什么

**单色振子。** 输入电子质量/电荷、真空常数、共振频率 $f_0=10^{14}$ Hz、电场峰值1 V/m，以及 $\Gamma_{\rm nr}/(\tau\omega_0^2)=1$。这里是经典教学模型，非实际原子的谱线参数。复位移来自完整单色分母，平均驱動做功取 $qE_0\omega\operatorname{Im}X/2$，散射功率由加速度平方的 Larmor 式求得，吸收功率独立由非辐射阻尼求得。

| 默认物理量 | 作者运行值 |
|---|---:|
| $\tau$ | $6.26642476\times10^{-24}$ s |
| $\tau\omega_0$ | $3.93731080\times10^{-9}$ |
| $\Gamma_{\rm nr}$ | $2.47388534\times10^6$ s⁻¹ |
| 位移峰值 | $5.65759646\times10^{-11}$ m |
| 速度峰值 / $c$ | $1.18574454\times10^{-4}$ |
| 平均入射强度 | $1.32720936\times10^{-3}$ W/m² |
| 平均散射功率、平均吸收功率（各） | $1.42384344\times10^{-15}$ W |
| 平均驱动做功 | $2.84768688\times10^{-15}$ W |
| 散射截面 | $1.07280997\times10^{-12}$ m² |
| 输入－散射－吸收，相对输入 | $-1.39\times10^{-16}$ |

大截面没有使总能量凭空增加：驱动相位和振幅一起决定移走的入射功率。稳态必须等待瞬态衰减；该表不提供突然开光的瞬态结果。[spectrum.csv](output/spectrum.csv) 扫 $\omega/\omega_0=10^{-2}\ldots10^2$；[resonance.csv](output/resonance.csv) 用真实窄线宽尺度细分共振附近。广域等对数采样不足以分辨窄线宽，不能从广域图的单个尖峰读半高宽。[scattering.svg](output/assets/scattering.svg) 的窄图因此用独立密集频率数组，但仍是同一组参数和方程。

**Gaussian 慢变误差。** 写 $x=t/T,\delta=\tau/T$。对照的形式非逃逸解为 $\int_0^\infty e^{-u-(x+\delta u)^2/2}du$，局部约化解为 $e^{-x^2/2}(1-\delta x)$。在401个 $x\in[-4,4]$ 样点比较；未来积分截到40，尾项不超过 $e^{-40}$，用1600子区间 Simpson。最小 $\delta$ 的 $x=0$ 再加倍积分网格，变化约 $2.03\times10^{-9}$，远小于理论截断误差；这是指定点的数值核对，不是所有输入的统一数值误差定理。

| $\delta$ | 最大绝对差（加速度除以 $a_0$） | Taylor 上界 $\delta^2$ |
|---|---:|---:|
| 0.05 | 0.002490352 | 0.0025 |
| 0.025 | 0.0006243901 | 0.000625 |
| 0.0125 | 0.0001561980 | 0.00015625 |

[gaussian.csv](output/gaussian.csv) 保存全部样点。它验证有限阶慢变展开与形式未来边界解的接近，**不验证未来积分是因果物理规律**；逃逸、预加速和阶跃输入的解释见 [[物理/30-电动力学/10-受驱散射与辐射反作用#消掉逃逸解却出现预加速|正文病态解]]。

**有初值的因果约化振子。** 此例使用独立的无量纲教学参数，不把 $\delta=0.02$ 冒称前表电子的 $\tau\omega_0$。令 $u=\omega_0t$、$y=\omega_0x/c$、$A=qE_{\rm scale}/(mc\omega_0)=10^{-4}$，给

$$g(u)=\begin{cases}\sin^4(\pi u/U)\cos u,&0<u<U,\\0,&\text{其他},\end{cases}\qquad U=40,$$

$$y''+\delta y'+y=A(g+\delta g'),\qquad y(0)=y'(0)=0.$$

$g$及前三阶导数在连接处连续；场开启前的零初值和本地方程使这里无需未来力数据。选 $\delta=0.04,0.02,0.01$，积分至 $u=120$，尚有少量机械能，不能假设结束时所有输入功都已辐射。RK4用步长0.02、0.01分别积分位移、速度、驱动功和辐射能。定义

$$e=(y'^2+y^2)/2,\quad e_S=-\delta y'y'',\quad p_{\rm rad}=\delta(y'')^2,\quad p_{\rm in}=Ag y'.$$

这些分别以 $mc^2$ 和 $mc^2\omega_0$ 为单位。约化方程只保留到 $O(\delta)$；把这些量精确代入它，不应要求守恒余项为机器零。直接求导得到可独立核对的恒等式

$$r=p_{\rm in}-e'-e_S'-p_{\rm rad}
=\delta^2y'(Ag''-y'').$$

脚本一边通过能量导数构造左边，一边由运动方程算右边。默认三例的两边差除以 $A^2$ 小于 $2.6\times10^{-15}$；$r$自身的最大值除以 $A^2$ 则分别约0.03008、0.00904、0.00252。它们不是同一轨迹，不能要求比例严格等于4；误差阶以明确的 $\delta^2$恒等式和有界轨迹为依据。

在 $\delta=0.02$ 的细网格，输入功除 $mc^2$ 为 $2.64654952\times10^{-7}$，辐射能为 $2.26204925\times10^{-7}$；机械能与Schott项补上大部分差额，剩余 $W_{\rm in}-e-e_S-W_{\rm rad}\approx-1.16311\times10^{-10}$ 是截断阶账本残差。步长减半时残差变化除以 $A^2$ 约 $2.20\times10^{-8}$，这才是数值网格的观察；不要把它与模型截断余项混报。[pulse.csv](output/pulse.csv) 保存默认中间 $\delta$ 的全程抽样；[reduction.svg](output/assets/reduction.svg) 直接画同批的曲线。采样速度最大约 $6.55\times10^{-4}c$，支持该有限例的非相对论尺度，未证明任意驱动都满足它。

## 改条件的可执行任务

将输入非辐射阻尼比改为0，检查共振散射增至4倍而消光增至2倍；入射强度不变，但外场移走的功率随响应改变。将Gaussian三组 $\delta$减半，先预测 $O(\delta^2)$差的比例；再检查数值积分误差没有盖过模型误差。将有限脉冲幅值$A$加倍，在线性方程中位移/速度加倍，功和各储能项乘4；重新检查速度与小振幅条件，而非只看程序成功退出。
