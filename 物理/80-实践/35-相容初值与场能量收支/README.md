# 相容初值与场能量收支：同一片源的三组初场

给同一静态电荷层和同一有限时长片电流，改变自由波初值的带符号幅度 $\alpha=0,1,2$；比较总储能、交叉能流、源功与物质冲量。进入前先在 [[物理/30-电动力学/11-相容初值自由场与有源叠加#同一源的两组相容初场|正文的场与源定义]]核对 $F,H,\rho,K$，并预测 $\alpha=1$ 的右侧总场和 $\alpha=2$ 的源功。

这是 SI 真空、无限平面对称的指定源模型。控制层为 $-2cT<z<2cT$，$T=2$ ns；所有广延量按单位面积给出，不报无限横截面的全空间有限总能。也可在横向周期单元计算，其侧面通量两两抵消。体电荷和片电流由外部约束维持；它们收到的功/冲量可核，但没有计算维持装置的材料动力学或机械储能。

唯一源码是 [initial_fields.py](initial_fields.py)，固定输入在 [inputs.json](inputs.json)，原运行结果在 [output/results.json](output/results.json)。Python 3 标准库，单进程，不安装依赖。进入本目录，将输出指向一个**尚不存在**的目录：

```bash
python3 -B initial_fields.py --inputs inputs.json --output /tmp/wwl-ed-initial-new-run
```

输出目录已存在则拒绝运行，以便保留每次结果。实验会生成三份逐时 CSV、JSON 和两张 SVG；新结果从同一方程和输入重建图，图中实时间尺度也从输入读取。不同网格及修改后的输入应分别输出到新目录，不把新结果覆盖随附结果。

## 两条独立数值核算与错误条件

**场、源与局部方程。** 程序从正文给定场函数独立取空间/时间中心差分，在片面以外的12个事件检查 Faraday、Ampère、Gauss 和无源区局部 Poynting 余额。片面不能用普通中心差分替代分布源：另外核两侧磁场跳跃 $-\Delta(cB_y/E_0)=2F$。静电场随 $H$ 给出 $\rho$；程序同时记录指定总 $E_0=0$ 时的非零 Gauss 余额及源光锥到达前的源扰动零值。

随附输入的局部步长为 $10^{-4}$，$\zeta\in\{-0.31,0.17,0.67\}$、$\tau\in\{0.25,0.6,1.3,2.4\}$、$\alpha=1$。归一化 Maxwell 残差最大 $1.318\times10^{-7}$，Poynting 残差最大 $1.39\times10^{-13}$，片面跳跃余额为零。Gauss 反例在 $\zeta=1/4$ 为 $1.6875$，其归一化是散度除以 $E_0/(cT)$；这里 $E_0$ 指输入的波场尺度，不是被错误置零的总初场。此处 $\rho=-2.49196428\times10^{-8}$ C/m³。局部采样和残差不证明任意 Maxwell 求解器都正确；本程序评估的是已明示的解析场。

**控制体储存、边界与源。** 空间积分用 Simpson，片面的两侧分别积分；一侧 $B_y$ 值在 $z=0$ 的端点取相应单侧极限。若把片面平均磁场塞进普通全层能量积分，会人为少掉一个网格点的磁能。平均磁场只用于片源受力。电功由 $-K E_x(0,t)$ 计算，片源力由 $K(B_{y,+}+B_{y,-})/2$ 计算；体电荷力由 $\rho\mathbf E$ 空间积分。边界能流和应力由两端总场计算。程序不把余额定义成储存项。

空间积分得到 $U_V,P_z,P_x$ 后，再用五点时间差分独立计算变化率，分别核

$$\frac{dU_V}{dt}+\Phi_{\rm out}=\mathcal P_{s\to f},\quad
\frac{dP_z}{dt}-\mathcal T_z+F_z=0,\quad
\frac{dP_x}{dt}-\mathcal T_x+F_x=0.$$

$\mathcal T$ 是向外法线下的应力牵引差，动量向外通量是其相反数。所有式子已经除以面积。细网格每个半层200子区间、时间1000子区间；粗网格为100/500，两者都实际计算。在 $\alpha=2$ 下，能量和纵向动量变化率最大归一化残差分别由 $1.958\times10^{-5}\to1.199\times10^{-6}$、$3.916\times10^{-5}\to2.398\times10^{-6}$；横向由 $1.422\times10^{-5}\to6.143\times10^{-7}$。这是空间积分与时间差分的共同加密，不据此把某一个独立离散算子认证为四阶。

原 CSV 的时间是 $\tau=t/T$，其余列名给出归一化：储能除以 $\epsilon_0E_0^2cT$，动量除以 $\epsilon_0E_0^2T$，能流/功率除以 $\epsilon_0cE_0^2$，应力/力除以 $\epsilon_0E_0^2$。JSON 同时保存输入、SI 结果、解析整段积分和粗细误差，不把归一化残差当成 SI 误差。

程序对新结果执行的成功门为：归一化整段余额不超过 $2\times10^{-5}$、逐时余额不超过 $10^{-4}$、源功与解析值之差除以 $w$ 不超过 $2\times10^{-8}$、局部 Maxwell/Poynting 残差不超过 $2\times10^{-5}$。失败会返回非零退出码并留下结果供检查，不将失败输出自动清理。随附结果是作者在本机真实轻量运行；独立核查与客户端显示由后续验收分别确认。

## 先预测再改输入

复制输入文件后把 $\alpha$ 改为 −1，预期出射 $5w$、源给场 $4w$、源冲量 $-2w/c$。把 $E_q$ 加倍，程序会由同一参数自动重构 $\rho$ 和相容静电场，预期背景能量变为四倍而横波净纵向收支不变。若只在理论中把 $\rho$ 改倍却保持原静电场，则是 Gauss 反例，不能称“输入已改且解仍相容”。自由幅度变化不改变电流输入，改动 $E_0$ 则会同时改变片电流幅度；这两种实验也要分开。

当前 CLI 限定起时 $\tau=-1$、对称控制层半长至少 $2cT$ 和完整脉冲离开后的终时。[[物理/30-电动力学/11-相容初值自由场与有源叠加#改变条件后重新求解|正文的非对称控制面迁移题]]有独立解析答案，CLI 不支持该几何；不能把对称参数简单改成1后继续套随附表，也不提供导体壁/材料自洽求解。
