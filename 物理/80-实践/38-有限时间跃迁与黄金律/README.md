# 有限时间跃迁与黄金律复算

先预测“哪两条曲线先分离”，再运行同一个有限卡。由 [[物理/40-量子力学/17-含时微扰与黄金律的时间窗口#同一有限卡分别检验四种失效|主解释的有限宽带模型]] 进入；这里的完整有限Hamiltonian是闭合酉模型，一阶连续带积分是一项近似的另一个对象。没有硬件、随机碰撞、环境重置或拟合率。

## 输入和三个可比较对象

`inputs.json` 使用 μs 与 rad/μs；radian视为无量纲。`B`是对称带的**半宽**，`N`为出态数，`gamma`为指定的连续平带领先Γ，`t_max`为开关时长的扫描上限。g不是自由追加参数，而由 $d=2B/N$、$J=\Gamma/(2\pi)$、$g=\sqrt{Jd}$ 得出。改变N时保持同一连续耦合密度J；改变gamma时才改变总耦合。

有序基 $(|i\rangle,|1\rangle,\ldots,|N\rangle)$ 中，初态是第一单位列，$H/\hbar$ 为实对称 $(N+1)\times(N+1)$ 矩阵；对角为 $0,\delta_1,\ldots,\delta_N$，第一行/列出态耦合为g，其余非对角元零。关断后测原 $H_0$，输出 $1-|\psi_i|^2$。N+1不是未声明的无限空间截断；本实践把它直接定义为有限模型。

四条曲线有明确比较顺序：

| 曲线 | 计算 | 先比较什么 |
| --- | --- | --- |
| exact finite | Hermitian对角化后精确矩阵指数的生存投影 | 与离散一阶相比，检验所选有限模型的微扰截断 |
| 1st discrete | $g^2t^2\sum_j\operatorname{sinc}^2(\delta_jt/2)$ | 与连续带相比，检验终态采样/重新聚相 |
| 1st continuum | $Jt^2\int_{-B}^B\operatorname{sinc}^2(\delta t/2)d\delta$ | 与Γt相比，检验有限带宽和长时核 |
| Gamma t | Γt | 只有前面的条件同时适用且耗尽很低，才是窗口内领先率 |

`two_state`另定义 $H/\hbar=[[0,g],[g,\delta]]$，同样初态第一列；此处g是独立二态参数，与宽带g不用同值。默认g=0.1 rad/μs、δ=0或1 rad/μs、0–40 μs，完整概率用矩阵平方得到的解析式计算，不调用宽带对角化。

## 运行和输出

需要Python 3.10+和NumPy 2.x（使用`numpy.trapezoid`）。在**自己可写的副本**运行，默认输出在该副本源码旁的assets；不要直接覆盖已交付数据。也可用`--output`指向自己的新目录：

```bash
python3 -B finite_transition.py --inputs inputs.json --output /private/tmp/wwl-fgr-my-run
```

同机多人运行遵守当前数值资源约定，单线程调用示例：

```bash
python3 -B /private/tmp/numerical_guard.py --threads 1 --timeout 60 --lock-timeout 60 -- python3 -B finite_transition.py --inputs inputs.json --output /private/tmp/wwl-fgr-my-run
```

这个guard是当前机器的调度入口，非课程可移植依赖；其他机器若没有它，按当地资源约定单线程运行。不要自动安装/修改系统或他人的虚拟环境。资源输入有界：N=2–400，曲线采样21–1001，连续积分网格1001–64001且为奇数，最多8张卡；非法数值/单位在生成前拒绝。连续求积依网格收敛，允许范围本身不保证任何输入都达到某指定容差。

输出七文件：

- `band.csv`/`band.svg`：五默认卡的同源四曲线，CSV列含case和μs坐标；图图注动态读取B/N/Γ，不硬编码默认数值。
- `two-state.csv`/`two-state.svg`：两态准确式与一阶式，按δ分组。
- `kernel.csv`/`kernel.svg`：同一归一角频率核的三时长曲线；有限显示域不承担全域归一检验。
- `results.json`：完整输入、d/J/g/自由相位聚集尺度、各误差与末时值；不是独立核查收据。

全部SVG有title/desc、坐标、单位和文本图例，虚线型辅助区分颜色。没有对曲线平滑、拟合或把越界近似压回[0,1]。源码通过 `--inputs` 接受JSON副本，通过 `--output` 指向新目录；主库历史输出不随别的工作目录变化而被悄悄写入。

## 默认卡先写预测，再看数据

window：B=10 rad/μs，N=200，Γ=0.01 μs$^{-1}$，扫描到8 μs。第一零点宽度、自由重新聚相尺度和Γt分别控制不同判断；前述中间窗是有限尺度筛选，未承诺任意精度。

在同卡上逐项改变：

1. B降为0.2而保持N/J/T：预测初期系数 $2BJt^2$ 下降，带宽近似先失败；微扰截断未必同时失败。
2. N降为8而保持B/J/T：d增大，g按$\sqrt d$变大以保持谱密度；离散与连续带先分離，自由相位聚集尺度从约62.83降到2.513 μs。
3. 只将扫描延至160 μs：Γt到1.6，且跨过自由相位聚集尺度，耗尽与离散重聚都存在；这张卡不单独区分两者。
4. 只将Γ升至0.5：8 μs已给Γt=4，尚未跨过62.83 μs的自由相位尺度，单独暴露低转移条件失败。

读CSV/图后携带“哪一项比较失效”回 [[物理/40-量子力学/17-含时微扰与黄金律的时间窗口#长时间是相对于相关时间，短时间是相对于耗尽和复现|一般时间窗]]。完整有限解接近某项近似，只支持该卡和该窗口，不证明一般不可逆性。

## 数值误差和模型误差分别检查

精确有限时间曲线用谱分解，不离散时间方程；`results.json`报告特征残差、Q正交残差，以及t=0/半末时/末时的完整态范数残差。它们检验浮点矩阵计算，不独立确认Hamiltonian写对了；独立复核应直接构造原矩阵或用 [[物理/80-实践/38-有限时间跃迁与黄金律/ANSWERS#不靠同一对角化的一条复算接口|消元后的根与权重]] 检查。

连续带积分用梯形求积，默认32001点，另以16001点重算最大差。默认作者生成的五卡最大差约$2.54\times10^{-9}$；这不是严格误差上界，更不是Γt的近似误差。独立解析式的Si积分见 [[物理/80-实践/38-有限时间跃迁与黄金律/ANSWERS#有限带的解析领先答案|有限带答案]]，应从公式或另一算法复核，再对照作者数据。

首轮作者生成的最大特征残差约$8.9\times10^{-15}$ rad/μs。理论推导、独立数值/变参运行与SVG渲染由非作者分别核对；这里不把作者的收敛或默认输出称作独立认证。真实量子实验、Obsidian客户端/同步与真人撤提示能力未由本程序验证。
