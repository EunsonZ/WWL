# 两体态与接触散射复算

先检查 [[物理/40-量子力学/10-张量积纠缠偏迹与交换对称#先说明两个子系统是什么|两体态的子系统与基顺序]]，再进入 [[物理/40-量子力学/11-相对坐标接触势与一维散射#单侧入射先算振幅再比通量|连续散射匹配]]。本实践用标准库复矩阵、显式偏迹与同方程的散射解；源码 [two_body_contact.py](two_body_contact.py) 同时生成 [checks.json](assets/checks.json) 和两张 SVG。有限矩阵酉性与连续模型的自伴域是两项不同证据。

## 手算答案先于运行

脚本单线程，仅 Python 标准库，矩阵最大 $4\times4$，积分流式求和，不需要安装。下列相对命令必须从**包含 `物理/` 的课程根目录**执行。本候选根为 `/private/tmp/wwl-qm-manybody-candidate-20261011/`；整合后可从 vault 根运行同一相对命令。输出位置按源码路径确定。

```sh
python3 '物理/40-量子力学/实践/05-两体态与接触散射/two_body_contact.py'
```

运行会写本实践的 `assets/checks.json`、`joint-probability.svg`、`contact-scattering.svg`。冻结验收时在自己的临时副本运行，保持候选只读。先给出可独立解析的答案：

- $\Phi_\theta=(|00\rangle+e^{i\theta}|11\rangle)/\sqrt2$ 的局部态均为 $I/2$，全局纯度 1；经典混态 $(|00\rangle\langle00|+|11\rangle\langle11|)/2$ 局部态相同、全局纯度 $1/2$。纯态的 $x,x$ 联合概率按 `(++,+−,−+,−−)` 为 $((1+\cos\theta)/4,(1-\cos\theta)/4,(1-\cos\theta)/4,(1+\cos\theta)/4)$，$X\otimes Y$ 期望为 $\sin\theta$。
- 非对称复数态 $(1,2i,-1,1+i)^T/\sqrt8$ 按 `00,01,10,11` 编号，$\rho_A=[[5,1+2i],[1-2i,3]]/8$，$\rho_B=[[2,-1-i],[-1+i,6]]/8$。这个例子暴露 Bell 态的对称性可能掩盖的偏迹索引错误。
- 交换 singlet 的本征值为 $-1$，对称 triplet 为 $+1$。非正交 $u=(1,0)$、$v=(1,i)/\sqrt2$ 有 $|\langle u|v\rangle|^2=1/2$，两交换态须用 $\sqrt{2(1\pm1/2)}$ 归一。
- 接触势 $g=\hbar^2/(\mu\ell)>0$，$q=k\ell=1$ 给 $r=(-1-i)/2,t=(1-i)/2$，率 $\mathcal R=\mathcal T=1/2$；$q=2$ 给 $\mathcal T=4/5$。偶通道相位 $-\arctan(1/q)$，奇通道相位 0；奇**端口**本征值 $-1$ 是自由端口排序的符号，不是相互作用相移。
- 相同绝对值的吸引势 $-g$ 给无量纲束缚态 $U_b(\xi)=e^{-|\xi|}$，$\xi=x/\ell$，范数 1，相对能量 $-\hbar^2/(2\mu\ell^2)$。中心运动仍是自由连续谱。

## 计算接口与核查方式

两体列向量按 `2*i+j` 展开，$A$ 索引较慢、$B$ 较快；张量积矩阵也采用这个顺序。所有 dagger 均作复共轭转置。偏迹直接求 $\sum_j\rho_{ij,kj}$ 或 $\sum_i\rho_{ij,il}$，输出分别为 $2\times2$。用五个相位 $0,\pi/2,\pi,3\pi/2,2\pi$ 检查联合概率、归一、局部 $I/2$、纯度及 $X\otimes Y$ 的虚相位；再用上述非对称复数态独立核两种偏迹。对 $B$ 局部酉 $\operatorname{diag}(1,e^{0.37i})$ 检查未选择结果的 $A$ 态不变。容差均为无量纲 $10^{-13}$。

交换矩阵显式交换中间两基矢，检查 $\mathsf P^2=I$ 和 singlet/triplet 的有号本征关系；非正交归一例另核。这里不是相同粒子模式纠缠的完整认证，也没有计算多体 Fock 占据统计。

散射采用实 $g$、$\mu=10^{-30}$ kg、$\ell=10^{-9}$ m。原点匹配在 $\xi=x/\ell$ 下为 $\phi'(0+)-\phi'(0-)=2\phi(0)$，此处导数对 $\xi$，不是 m。五个 $q=0.1,0.5,1,2,4$ 分别检查连续性、导数跳跃、端口 $S^\dagger S=I$、偶/奇本征值及 $\mathcal R+\mathcal T=1$。直接将解析波函数和导数代入 $\operatorname{Im}(\phi^*\partial_\xi\phi)/q$，在 $\xi=-2.3,-0.7,0.4,1.8$ 核净流与 $\mathcal T$ 相等；干涉项不能凭“两个概率相加”省略。这些无量纲残差容差 $10^{-13}$。

物理尺度另报 $g$（J·m）、$E_{q=1}$（J）、$A=\ell^{-1/2}$（$\mathrm{m^{-1/2}}$）及 $j_{\rm in}$（$\mathrm{s^{-1}}$）。$h=6.62607015\times10^{-34}$ J·s 是 SI 定义的精确常数；$\mu,\ell$ 都是教学选择。正、负 $g$ 的同能量率一致而幅相不同，也作独立比较。

吸引束缚态的范数在正半轴 $[0,20]$ 积分后乘二，使用 Simpson 2000/4000 面板，避免跨原点尖点误用光滑函数的误差估计；精确概率尾为 $e^{-40}$。声明范数绝对误差及粗细差 $10^{-8}$，不重归一。另用无量纲步长 $10^{-5}$ 的单侧差分检查原点跳跃（容差 $3\times10^{-5}$），用中心差分在 $\xi=\pm0.4,\pm2$ 检查 $-U_b''=-U_b$（容差 $3\times10^{-6}$）。这是局部方程和已知解析函数的复算，不是用网格证明整个算子的自伴性。

## 两图与同一模型的对应

[联合概率图](assets/joint-probability.svg) 的纯态曲线由实际 $4\times4$ Born 运算生成，横轴相位 rad，纵轴联合概率；混态横线也由同一测量投影求得。它说明保持局部态不变仍可改变联合数据。[接触散射图](assets/contact-scattering.svg) 从同一匹配振幅生成反射/透射率，再画对应奇偶相位。采样 $0.05\le q\le4$，纵轴上窗为通量比、下窗为 rad，图内注明阈值 $q=0$ 只作极限。
