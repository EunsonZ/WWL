## 速查表

| 想要 | 写法 |
| --- | --- |
| 粗体 | `**文字**` |
| 高亮 | `==文字==` |
| 内部链接 | `[[笔记名]]` |
| 显示别名 | `[[笔记名\|显示文字]]` |
| 嵌入 | `![[笔记名]]` |
| 任务 | `- [ ] 事情` |
| Callout | `> [!tip] 标题` |
| 脚注 | `内容[^1]` 与 `[^1]: 说明` |
