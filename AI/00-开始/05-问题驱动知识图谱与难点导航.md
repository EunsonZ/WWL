# 问题驱动知识图谱与难点导航

不要把知识图谱理解成“每个名词都多连几条线”。有用的链接应说明关系：这是**先修工具**、**同一机制的另一种实现**、**可推翻过强结论的反例**，还是**检验当前解释的实验**。下列路线按真实疑问组织，而不是按模型发布时间排队。

![[AI/90-资源/图示/深化研究/course_graph.png]]

## 读公式总是卡住：先恢复对象，再追踪操作

从[[AI/00-开始/06-统一符号形状与公式阅读方法|统一符号与形状]]进入[[AI/11-数学与统计桥梁/01-向量空间投影SVD与低秩|线性代数]]和[[AI/11-数学与统计桥梁/02-矩阵微积分VJP与反向传播|矩阵微积分]]。每看到一个式子，先问输入输出的形状、哪个索引被求和、哪个量保持不变。再读[[AI/20-LLM/20-架构/10-注意力反向传播与Softmax竞争|注意力反向传播]]，检查转置和上游梯度。停下来手算一个两行小例，比跳过一页公式更有效。

## loss 正常下降，训练却不对：目标是否被悄悄改了

读[[AI/20-LLM/10-原理/07-语言模型目标分词粒度与评测可比性|语言模型目标]]确定标签偏移和条件分布，再读[[AI/12-PyTorch/05-变长批处理Packing与有效Token归一化|有效 token 分母]]与[[AI/12-PyTorch/08-DDP全局目标通信与分片边界|DDP 全局目标]]。9 个低损失 token 加 1 个高损失 token 的反例能直接揭示“微批均值再平均”的问题。最后用[[AI/12-PyTorch/06-梯度诊断数值验证与自定义算子|梯度诊断]]判断实现错误，用[[AI/10-机器学习与深度学习基础/18-嵌套验证配对实验与指标陷阱|严格验证]]判断是否只是过拟合。

## 已经设置随机种子，为什么恢复后不一样

读[[AI/12-PyTorch/07-完整训练状态恢复与可复现实验|完整训练状态]]，把参数、优化器动量、随机数状态和数据位置分开。再读[[AI/12-PyTorch/09-性能剖析编译动态形状与内存账本|执行环境与性能]]，区分随机性、非确定算子、不同精度与不同系统配置。进入[[AI/80-实践/08-深层机制数值实验/00-数值实验导航与验收|CPU 恢复实验]]重现同一个下一步；不要把单机成功外推成所有硬件逐位一致。

## 卷积为何有效，转置卷积又在“转置”什么

从[[AI/15-卷积神经网络/04-卷积反向传播与转置卷积|卷积的线性算子与伴随]]理解权重共享、散射回传和信息丢失，再读[[AI/15-卷积神经网络/05-采样混叠感受野与平移鲁棒性|采样混叠]]区分局部等变性与实际平移鲁棒性。随后用[[AI/15-卷积神经网络/07-残差网络轻量卷积与训练配方|架构配方]]和[[AI/15-卷积神经网络/06-检测分割匹配损失与评估协议|视觉任务评测]]把算子选择与任务需求连接。

## 低秩、稀疏、量化、缓存压缩是不是同一种省资源方法

不是。[[AI/11-数学与统计桥梁/01-向量空间投影SVD与低秩|SVD]]在给定范数下近似矩阵；[[AI/20-LLM/30-训练/15-LoRA低秩几何QLoRA与蒸馏边界|LoRA]]约束训练更新；[[AI/20-LLM/20-架构/12-MLA线性注意力与状态空间的记忆取舍|MLA]]通过架构共享潜变量并重排计算；[[AI/20-LLM/20-架构/13-MoE路由梯度负载均衡与通信成本|MoE]]稀疏选择计算路径；[[AI/20-LLM/60-模型格式与量化/08-量化误差传播校准目标与端到端评测|量化]]改变数值表示。判断它们是否近似、丢了什么，应从目标函数和可恢复信息入手，而不是只看参数量或 bit 数。

## 上下文加长了，为什么模型仍然找不到信息

先读[[AI/20-LLM/20-架构/11-RoPE相对位置缓存偏移与长度外推|RoPE、位置偏移与外推]]排除坐标和缓存错误，再读[[AI/20-LLM/20-架构/12-MLA线性注意力与状态空间的记忆取舍|可寻址记忆与递归状态]]理解信息组织方式。最后从[[AI/20-LLM/40-推理/10-测试时计算验证器误差与预算公平性|测试时计算]]和[[AI/20-LLM/70-工程应用与工具链/10-LLM评测污染裁判偏差与统计检验|长上下文评测协议]]检查有效证据密度、干扰、延迟和预算。标称窗口能容纳多少 token，不等于可以可靠利用多少信息。

## 模型没有更新参数，为什么还像“学会了”任务

读[[AI/20-LLM/10-原理/08-上下文学习机制假说与可证伪实验|上下文学习的不同机制假说]]，区分条件推断、隐式算法与训练时学会的模式。再读[[AI/20-LLM/80-研究拓展/01-机制可解释性Probe干预与稀疏特征|可解释性与干预]]：能从隐藏状态读出某变量，不证明输出依赖它。用随机标签、提示置换和机制干预构建竞争解释，不把一个漂亮可视化当成完整机制。

## DPO、PPO、GRPO 的公式怎么连起来

从[[AI/10-机器学习与深度学习基础/19-强化学习MDP价值函数与策略梯度|策略梯度与基线]]建立期望梯度，再分别走[[AI/20-LLM/30-训练/12-从KL约束到DPO的逐步推导|KL 约束与偏好建模]]、[[AI/20-LLM/30-训练/13-GRPO重要性比率归一化与奖励偏差|组内奖励与重要性比率]]。它们解决的问题与估计方式不同，不能仅因都使用“好回答/坏回答”就视作同一损失。奖励是否可信、长度如何计权、采样分布是否匹配，是比缩写更重要的检查点。

## 投机解码何时真的“不改变分布”

读[[AI/20-LLM/40-推理/08-投机解码接受拒绝与分布不变性|接受拒绝的概率证明]]，用两个类别枚举输出概率。然后回到[[AI/20-LLM/40-推理/09-KV缓存分页滑窗与前缀复用|缓存与系统状态]]和[[AI/20-LLM/40-推理/10-测试时计算验证器误差与预算公平性|预算公平性]]：概率分布相同不等于相同随机种子生成逐 token 相同结果，更不等于任何批量与硬件上都提速。

## RAG 能检索到文档，为什么答案还是错

按[[AI/20-LLM/70-工程应用与工具链/08-混合检索重排RAG误差分解与证据|检索、证据使用与引用分解]]构造无检索、真实检索、理想证据、干扰证据四组对照。再用[[AI/10-机器学习与深度学习基础/17-概率校准保形预测与分布偏移|校准与分布偏移]]区分自信分数和正确率，用[[AI/20-LLM/70-工程应用与工具链/10-LLM评测污染裁判偏差与统计检验|LLM 评测]]检查引用是否支持具体主张。把[[AI/20-LLM/70-工程应用与工具链/09-Agent状态机幂等执行与提示注入边界|授权与提示注入]]纳入系统边界，检索内容不是工具执行许可。

## 多模态方法为何仍共享同一套数学

[[AI/30-VLM/03-视觉语言对齐信息瓶颈与反事实评测|图文对比学习]]连接分类、表示与负样本；[[AI/40-语音与音频模型/03-CTC路径求和流式延迟与语音评测|CTC]]连接潜在对齐路径求和与动态规划；[[AI/50-扩散模型/03-Score去噪FlowMatching与CFG的联系|去噪、Score 与 Flow Matching]]连接条件期望和生成路径；[[AI/20-LLM/80-研究拓展/02-离散扩散语言模型与自回归对照|离散扩散语言模型]]进一步提示连续与离散状态的区别。共同点是目标、条件信息和估计，不能因此忽略模态自己的边界。

## 无限模型类为什么可学，训练最优又离未来最优多远

从 [[AI/10-机器学习与深度学习基础/30-统计学习理论/01-PAC一致收敛与近似ERM#从好事件逐项推出近似ERM界|一致好事件与近似ERM]] 推 $2\epsilon+\eta$，再到 [[AI/10-机器学习与深度学习基础/30-统计学习理论/02-增长函数VC与不可学习#交换每一对样本：现在才可以使用有限联合界|增长函数与随机交换]] 看无限类怎样获得有限保证。带着SVM的优化证书返回01核目标换算，再到 [[AI/10-机器学习与深度学习基础/30-统计学习理论/03-正则化稳定性与范数复杂度#正则强度为什么有两面|稳定性与正则取舍]]，最后用 [[AI/10-机器学习与深度学习基础/30-统计学习理论/80-有限分布复算与条件破坏#两个条件破坏：复制行与部署偏移|复制行与部署偏移]] 指出独立性或分布条件失效在哪一步。

## 论文声称有效，我该相信到哪一层
