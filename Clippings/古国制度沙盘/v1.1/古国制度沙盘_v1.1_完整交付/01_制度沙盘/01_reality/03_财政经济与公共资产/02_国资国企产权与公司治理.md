# 国资国企产权与公司治理（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：经营性国有资产的所有权代表、履行出资人职责、企业法人财产权、公司治理、负责人考核、产权交易和信息公开。
- 不展开行政事业性资产、金融国有资产和自然资源资产的全部专门规则，只标注其与企业国资并非同一监管体系。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 上位法 | 现行主干仍为2008年《企业国有资产法》和经2019年修改的《企业国有资产监督管理暂行条例》。 |
| 公司治理 | 企业同时适用现行公司法及国资专门规则；中央企业章程、董事会、经理层授权、重大事项前置研究、考核和合规制度由多份规范性文件细化。 |
| 产权流转 | 增资、转让、资产交易原则上经过决策、审计评估、信息披露和产权交易机构公开交易，另有依法适用的非公开协议等例外。 |
| 修法状态 | 企业国有资产法修订草案已于2026年4月提请首次审议，**截至核对日尚未成为法律**；不得把草案中的资产范围、监管方式或责任条款当作现行规则。 |

## 现行结构摘要

1. **国家所有、分级代表。** 国家对国有资产享有所有权，国务院和地方政府依法代表国家履行出资人职责；国资监管机构以及经政府授权的其他部门、机构对所出资企业行使股东权利。
2. **企业拥有法人财产权。** 出资人的股权或权益与企业实际控制、使用和处分的法人财产相区分。国企以公司等市场主体形式经营，原则上自负盈亏，同时可能承担公共服务、产业安全或政策任务。
3. **公司机关与出资人权力并行。** 股东会或履行出资人职责机构、董事会、经理层、监督机制按公司法和章程分工；负责人任免、薪酬考核、重大投资、重组、产权转让及担保等还受国资规则约束。
4. **党的领导嵌入治理。** 中央企业实践将党的领导写入章程，对重大经营管理事项设置前置研究讨论接口，但企业董事会和经理层仍需依法承担相应决策与执行责任。
5. **监管以资本和责任为纽带。** 国资监管覆盖企业战略、资本布局、产权、财务监督、考核分配、风险和违规责任追究；部分行业国企则由其他履行出资人职责机构管理。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 所有权代表—公共权力 | 政府既制定公共政策，又可能通过授权机构行使股东权利，所有者职能与行业监管、社会管理之间需要区分。 |
| 出资人—董事会 | 出资人决定章程、资本、负责人和特定重大事项；董事会承担企业经营决策，授权边界由法律、章程和授权清单共同界定。 |
| 党组织—公司机关 | 前置研究与法定公司决策在程序上衔接，但意见形成、责任归属和记录公开主要属于内部治理。 |
| 商业目标—公共任务 | 政策任务可通过规划、考核、补贴、资本金或专营权实现；若成本补偿不透明，商业绩效与公共绩效难以区分。 |
| 产权交易—市场竞争 | 交易规则要求评估和公开竞价以防流失，但审批、战略投资者选择及协议交易例外会影响竞争程度。 |
| 母公司—多层子企业 | 股权链、实际控制、担保和关联交易跨越多级企业，穿透监管依赖统一产权、财务和风险数据。 |

## 可观察约束与信息缺口

- 中央和地方、金融与非金融、经营性与行政事业性国有资产分别统计，公众难以获得边界一致的全国合并资产负债表。
- 政府的所有者角色、行业监管角色和政策购买者角色可能重合，竞争中性和责任追究容易出现目标冲突。
- 公共服务义务、战略储备或保供任务的成本补偿及绩效结果缺少统一的合同化、项目化公开标准。
- 多级子企业的关联交易、交叉补贴、担保、资金归集和实控关系对外披露颗粒度不一。
- 董事会获得授权后，行政审批减少与国有资产保值责任加重并存；失败投资、正常商业风险和违规决策的边界并不总是清晰。
- 产权交易公开平台能呈现挂牌信息，但从前期决策、估值假设到交割后承诺履行的全链条数据有限。

## 古国改革需回答的问题

1. 公共资产由谁代表全民持有，所有者、行业监管者和公共服务采购者是否必须组织分离？
2. 哪些企业保留公共所有，依据是自然垄断、公共服务、战略安全还是财政投资回报？由谁定期复核？
3. 公益任务如何通过可计量合同和预算补偿，避免与商业盈亏混在一起？
4. 董事、经理和公共股东各自的授权、忠实义务、免责和追责标准如何可预期？
5. 党派或其他政治组织是否进入企业治理；若进入，其决定如何留痕、审查并承担法律责任？
6. 国有企业应公开哪些合并财务、补贴、担保、关联交易、薪酬、公共绩效和重大风险数据？
7. 产权交易的估值、竞价例外、职工安置和利益冲突怎样接受独立复核？
