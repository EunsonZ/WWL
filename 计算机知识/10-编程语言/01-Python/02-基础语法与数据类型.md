# Python 基础语法与数据类型

## 本课目标

学完本课，你应该能够：

- 用缩进组织代码，用 `#` 写注释，并读懂名称、赋值和表达式；
- 区分数字、布尔值、`None`、文本 `str` 与二进制 `bytes`；
- 用“名称指向对象”的模型解释赋值、可变性和 `is`/`==` 的差异，而不是把变量想成固定的盒子；
- 读懂比较、真值、`input()`、`print()`、f-string，并做基本类型转换。

适用场景：这是从能运行 Python 到能独立读写小脚本的桥梁。示例均可粘贴到 Python 解释器或保存为 `.py` 文件运行。

## 1. 心智模型：名称指向对象

Python 程序运行时，值以对象存在；对象有类型、值和身份。名称只是一个可重新绑定的标记，它指向某个对象。下面的 `score` 先指向整数对象，之后又指向另一个整数对象：

```python
score = 80
score = score + 5
print(score)       # 85
print(type(score)) # <class 'int'>
```

因此不要说“把 80 放进 score 盒子后在盒子里加 5”。更准确的说法是：先计算 `score + 5` 得到新对象，再让名称 `score` 指向结果。对象能否原地改变，取决于它的类型是否可变；名称本身总可以重新绑定。

多个名称可以指向同一个对象：

```python
first = ["待办"]
second = first
second.append("学习")
print(first)  # ['待办', '学习']
print(first is second)  # True：是同一个列表对象
```

`is` 检查是否为同一对象，`==` 检查值是否相等。日常值比较通常用 `==`；`is` 最常见的用途是检查单例 `None`：`result is None`。

## 2. 缩进、注释、名称与赋值

### 缩进是语法

冒号 `:` 后开始一个代码块，后续语句必须统一缩进。推荐每层 4 个空格；同一个文件不要混用 Tab 和空格。

```python
temperature = 22

if temperature > 20:
    print("适合散步")
    print("记得带水")
else:
    print("可以加一件外套")
```

缩进不只是排版：缩进错位会产生 `IndentationError` 或 `TabError`。同一代码块内的语句必须处在同一缩进层级。控制流和函数会在[[计算机知识/10-编程语言/01-Python/03-控制流函数与作用域|下一课]]展开。

### 注释不会执行

`#` 从当前位置开始到物理行末都是注释；字符串里的 `#` 仍是字符串内容。

```python
# 这是给读代码的人看的说明
message = "价格是 #1"  # 行末注释
print(message)
```

注释应说明“为什么”或约束条件，而不是重复显而易见的代码。不要用注释代替实际的可执行逻辑。

### 名称与赋值

名称区分大小写，通常用小写加下划线（`user_name`）。不能用关键字（如 `if`、`class`）作为名称，也不要遮蔽重要内置名称（如 `str`、`list`、`print`）。赋值语句使用 `=`，它不是数学等式，而是绑定操作：

```python
left = 3
right = left + 4  # 先读取 left，计算 7，再绑定 right
left = 99         # 不会改变 right 已经指向的整数对象
print(left, right)  # 99 7
```

可以同时赋值和交换名称的指向：

```python
low, high = 2, 9
low, high = high, low
print(low, high)  # 9 2
```

## 3. 表达式：产生值的代码

表达式会被求值并产生一个对象。算术运算遵循优先级；不确定时用括号明确意图：

```python
subtotal = 3 * 10 + 2       # 32
average = (3 + 5) / 2       # 4.0
quotient = 17 // 5          # 3，整除
remainder = 17 % 5          # 2，余数
power = 2 ** 3              # 8
```

表达式也可以组合比较、布尔运算和函数调用：

```python
age = 20
has_ticket = True
allowed = age >= 18 and has_ticket
print(allowed)  # True
```

`and` 与 `or` 会短路，并返回参与判断的最后一个操作数，不保证返回布尔值：`"" or "默认"` 的结果是字符串 `"默认"`。`not` 始终返回 `True` 或 `False`。

## 4. 常见内置数据类型

用 `type(value)` 查看类型，用 `repr(value)` 在调试时查看更接近 Python 表示的形式。

### 数字：`int`、`float`、`complex`

```python
count = 12          # int，整数
ratio = 0.75        # float，浮点数
z = 2 + 3j          # complex，复数
print(type(count), type(ratio), type(z))
```

除法 `/` 返回浮点数；`//` 是整除，负数时结果向负无穷取整。浮点数是近似表示，金额等精确需求不要直接依赖普通浮点数相等比较。

### `bool`、`None`

`bool` 只有 `True` 和 `False`，可参与布尔上下文与比较。`None` 是表示“没有值/尚未提供结果”的单例对象，不等于 `0`、`False` 或空字符串：

```python
finished = False
result = None
print(finished == 0)  # True：数值比较中 bool 与整数有特殊关系
print(result is None) # True：推荐这样检查 None
```

`None` 通常表示函数没有有意义的返回结果，或可选数据尚未存在；使用前先明确它的含义。

### `str`：Unicode 文本

字符串可以用单引号或双引号；反斜杠转义特殊字符，三引号可写多行文本。字符串是不可变的，索引从 0 开始：

```python
name = "Ada"
greeting = "你好，" + name
print(greeting[0])  # 你
print(len(greeting))
print("第一行\n第二行")
```

不能直接修改字符串中的某个位置；要构造新字符串：

```python
word = "cat"
# word[0] = "b"  # TypeError
word = "b" + word[1:]
print(word)  # bat
```

### `bytes`：不可变的字节序列

`str` 表示已解码的文本，`bytes` 表示 0 到 255 的字节序列，适合文件、网络协议等二进制数据。文本和字节之间必须明确编码：

```python
text = "你好"
data = text.encode("utf-8")
print(data)                 # b'\xe4\xbd\xa0\xe5\xa5\xbd'
print(data.decode("utf-8")) # 你好
```

`bytes` 也不可变；要可变字节序列可使用 `bytearray`。不要把 `bytes` 和 `str` 直接用 `+` 拼接，也不要猜测编码：读写双方应约定编码（UTF-8 是常见选择）。

### 可变与不可变

不可变对象创建后，其自身内容不能原地改变，例如 `int`、`float`、`bool`、`NoneType`、`str`、`bytes` 和 `tuple`。元组始终是不可变序列：不能替换、增加或删除它保存的元素引用；但元组元素可以指向列表等可变对象，那个内部对象仍可原地改变。因此，“元组不可变”不等于“元组内部可观察到的所有状态都不会变化”，也不等于“所有元组都可哈希”。可变对象可以原地修改，例如 `list`、`dict`、`set` 和 `bytearray`：

```python
items = ["a"]
alias = items
items.append("b")       # 修改同一个列表对象
print(alias)             # ['a', 'b']

number = 10
other = number
number += 1              # 重新绑定 number，不修改整数 10
print(other)             # 10
```

函数参数传递的是对象引用的值；因此函数可能通过可变对象观察到原地修改，但重新绑定形参不会改掉调用者的名称。后续学习函数时，要同时关注“改对象”与“换绑定”。

## 5. 比较与真值

常用比较运算符是 `<`、`<=`、`>`、`>=`、`==`、`!=`。比较结果通常是布尔值，也可以链式比较：

```python
score = 86
print(0 <= score <= 100)  # True
print("a" < "b")          # True，字符串按序比较
```

在 `if`、`while`、`and`、`or` 等布尔上下文中，Python 会把对象解释为真或假。一般来说，`False`、`None`、数值 0、空字符串以及空容器为假；其他多数对象为真：

```python
answer = ""
if not answer:
    print("尚未填写")

values = [1, 2]
if values:
    print("列表非空")
```

“为空”与“值为 `None`”不是一回事。若业务要求区分二者，写 `value is None`，不要用 `if not value` 把 0、空字符串和 `None` 混为一谈。

## 6. 输入、输出与 f-string

`input(prompt)` 显示提示并返回用户输入的字符串；即使用户输入数字，返回值也仍是 `str`。`print()` 把对象输出到标准输出，默认以空格分隔参数并换行：

```python
raw_age = input("年龄：")
age = int(raw_age)
print("明年：", age + 1)
```

实际程序应考虑用户输入为空或不是整数的情况；`int()` 转换失败会抛出 `ValueError`，异常处理将在后续课程涉及。

f-string 在字符串前加 `f`，用 `{表达式}` 插入值；冒号后可以写格式说明：

```python
item = "咖啡"
price = 18.5
quantity = 2
print(f"{item} × {quantity} = {price * quantity:.2f} 元")
# 咖啡 × 2 = 37.00 元
```

调试时可用 `f"{price=}"` 看名称和值：

```python
print(f"{quantity=}, {price=}")
```

## 7. 类型转换：明确、可验证

常用构造器包括 `int()`、`float()`、`str()`、`bool()`、`bytes()`；它们不是“给对象贴标签”，而是尝试产生目标类型的值：

```python
print(int("42"))        # 42
print(float("3.5"))     # 3.5
print(str(42))           # '42'
print(bool(""))         # False
print(bool("0"))        # True：非空字符串为真
```

注意 `bool("False")` 是 `True`，因为字符串非空；不要用它解析用户输入的真假文字。应写明确规则，例如 `answer.strip().lower() in {"y", "yes"}`。转换前确认输入格式，转换后用 `type()` 或测试值验证假设。

## 常见坑

| 现象 | 原因 | 更稳妥的做法 |
| --- | --- | --- |
| `if x = 1` 报语法错误 | `=` 是赋值，不是比较 | 条件比较使用 `==` |
| `input()` 得到的值不能直接加数字 | `input()` 返回 `str` | 先用 `int()`/`float()` 转换并处理失败 |
| `bool("False")` 为真 | 非空字符串为真 | 自己定义允许的真假文本 |
| `a is b` 的结果出乎意料 | `is` 比较对象身份，不是值 | 值比较使用 `==`；`None` 用 `is None` |
| 修改一个列表后另一个名称也变了 | 两个名称指向同一个可变对象 | 需要副本时显式复制，如 `items.copy()` |
| 中文文本变成乱码或 `str`/`bytes` 无法拼接 | 文本与字节、编码边界未明确 | 用同一编码 `encode()`/`decode()` |
| `IndentationError`/`TabError` | 代码块缩进不一致或混用 Tab/空格 | 编辑器统一为 4 个空格，并观察代码块层级 |
| `0`、`""` 被当成“没有值” | 真值判断覆盖了多个不同状态 | 需要区分时使用 `is None` 或显式比较 |

## 练习：做一个可检查的费用小票

请新建一个临时 `practice.py`，完成以下任务：

1. 用 `input()` 读取商品名、单价和数量；
2. 把单价转为 `float`，数量转为 `int`；
3. 用表达式计算总价，用 f-string 保留两位小数输出；
4. 增加一个 `None` 初始的优惠码变量，并用 `is None` 判断“没有优惠码”；
5. 创建一个列表并让第二个名称指向它，演示 `append()` 后两个名称看到同样内容；
6. 创建一段中文 `str`，编码为 UTF-8 的 `bytes`，再解码回 `str`，打印 `type()` 和结果。

先故意把 `input()` 的结果直接与数字相加，观察错误；再修正并说明错误来自哪一层类型不匹配。练习结束后可删除临时文件，不会修改本课笔记。

## 跨域路标：代码负责表示，数学负责定义

本课中的 `float`、比较和布尔条件让程序能够运行，但它们不自动给出数学上的精度、误差或概率含义。例如，`0.1 + 0.2` 的二进制浮点近似不适合作为“金额一定相等”的判据；实际金额规则应在业务边界中明确，必要时改用 `decimal` 或最小货币单位的整数表示。想理解数值近似、误差与可复现计算，应进入 [[数学/60-数值计算与量化/00-数值计算与量化-MOC|数值计算与量化 MOC]]；机器学习中数组、随机性和特征数值的应用入口在 [[AI/00-开始/00-AI-首页|AI 首页]]。
