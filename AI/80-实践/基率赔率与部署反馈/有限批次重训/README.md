# 有限批次重训：从精确原子表复算波动

主解释在[[AI/65-可信AI与真实数据实践/04-区间代价分组失败与发布漂移#有限批次重训为何留下平稳波动|部署课的新加性模型]]。这里保留它的唯一计算源码、固定输入、精确结果和同数据图；不运行真实训练或部署。旧[总体异方差实验](../DEPLOYMENT.md)仍使用原模型。

## 运行与输入

[batch_retrain.py](./batch_retrain.py)只需 Python 3.10+ 标准库。从本实验目录运行，选一个尚不存在的输出目录：

```bash
python3 -B batch_retrain.py --input input.json --output /tmp/wwl-batch-retrain-new-run
```

程序拒绝覆盖已有输出目录；为再次运行换一个新路径。省略参数会读源码同目录的 [input.json](./input.json)，尝试写同目录 `results/`；已随正文保留结果时该目录存在，因此默认会拒绝写入。运行不改输入、源码或别的实验。

| 输入 | 本次固定值 | 允许的变化及含义 |
| --- | --- | --- |
| `theta0` | `"0"` | $[0,1]$ 内的有理数文本，分母至多1024；确定性初值 |
| `steps` | 8 | 整数1至8；已完成更新次数 |
| `snapshot_steps` | `[1,2,4,8]` | 1至steps中递增、无重复的轮次，至多4个；保留其完整 $m=1$ 原子表和图 |
| `fixed_batch_sizes` | `[1,4]` | 1至8内递增、无重复且含1；固定新批、重用位、冻结旧观测均计算 |
| `threshold` | `"1/10"` | $(0,1/2)$ 内的有理数文本；尾事件严格取 $|\theta_t-1/2|>\epsilon$ |
| `growth_first_batch` | 1 | 整数1至4；第 $t$ 个采样轮 $m_t=\text{该值}\times2^t$，从0开始 |

这些小范围用于可完全枚举的教学输入，不是一般训练程序的容量声明。JSON未知/重复字段、非法类型和边界会被拒绝；参数值改变后应先独立预测新结论，再看输出。

## 输出怎样与图共用分布

每个新批的成功数 $K_t$ 有 $P(K_t=k)=\binom{m_t}{k}/2^{m_t}$。程序用整数质量计数推进 $\theta_{t+1}=\theta_t/2+K_t/(2m_t)$，碰到同一有理数位置就合并。最后用 `Fraction` 归一化，不用浮点抽样逼近概率。重复位与冻结观测则枚举一次初始批的所有成功数。

- [atoms.csv](./results/atoms.csv)保留 $m=1$ 所选四轮的全部原子，共278行；每行包含轮次、参数位置、精确概率。
- [moments.csv](./results/moments.csv)有63行，从0至8轮，覆盖7个情形。均值、方差、到 $1/2$ 的均方误差、严格尾概率来自各自完整原子表；新鲜部署风险再对独立 $B=0,1$ 各半概率直接求和。
- [metrics.json](./results/metrics.json)保留同样的精确分数、输入与计算方法。它是有限量的计算结果，不是验证者签收或真实平台观测。
- [batch-retrain.svg](./results/batch-retrain.svg)只消费枚举出的 $m=1$ 原子与矩。上排纵轴为单点质量，各面板独立标出自己的量级；下排把均值与方差分开。均值连线不表示随机路径，方差曲线不表示均值置信区间。SVG有文字替代说明和虚线标记，颜色不是唯一提示。

默认输入已在2026-10-12按受限数值调用实际计算这些文件。程序给出的精确数值支持该输入的有限计算；弱极限、连续不变分布、TV恒1及条件变化的数学结论依赖主正文的证明，不能靠8轮结果认证无限时刻。

## 改条件，先给预测再复算

遮住主课迁移答案，把 `growth_first_batch` 改为2：第一步均值应为1/4、方差1/32、到1/2均方误差3/32；仍然需要每轮新独立抽样。把固定批量改为4，长期方差由证明给1/48、平均风险13/192，但8轮输出只是有限值，不能直接当极限。改 `theta0` 为 `"1/3"`，初始偏差项也要跟着改，原子网格会平移；不能把初值0的 $k/2^t$ 完整分布原样套用。

同一输入下比较 `new_fixed_m1`、`reused_bits_m1`、`frozen_observations_m1`：前者每轮抽新位；第二种每轮响应随部署变化但重复同一初始位；第三种永远拟合第0轮的观测 $Z_{0,j}=\theta_0/2+B_j/2$。报告 `new_draws_this_update` 为0的后续行没有新增独立样本。三者不同，不能只把脚本里的批量字段改大就当独立性恢复。
