# 最短路、最小生成树与并查集

## 本课目标

- 按边权条件选择 BFS、Dijkstra 或 Bellman–Ford，并能解释负权边的边界；
- 区分“从一个源到各点的最短路”和“连通全图的最小总边权”；
- 用 cut property 理解 Kruskal/Prim 的安全边，而不把“最小边”当作普适规则；
- 说清并查集的森林不变量、路径压缩、按秩/大小合并及其近似复杂度。

> [!tip] 首读核心闭环与按需选读
> **首读核心闭环**是：先按边权条件区分 BFS、Dijkstra 与 Bellman–Ford（第 2–5 节）→ 用一条负边反例知道 Dijkstra 的前提（第 3 节）→ 能为一个源点选择正确算法。完成这条闭环后，先回到主线总结选择依据即可。
>
> **按需选读**：当任务是“用最小总边权连通全部顶点”时读 MST、割性质与 Kruskal/Prim（第 6 节）；当需要反复合并和查询连通块时再读 DSU 与路径压缩（第 7 节）。这两类目标都不是单源最短路的换名。

## 1. 先分清三个不同目标

| 问题 | 要求 | 输出 | 不能混同为 |
| --- | --- | --- | --- |
| 单源最短路 | 从源点 $s$ 到每个点的路径成本最小 | `dist[v]` 与可选前驱 | 一棵总边权最小的树 |
| 最小生成树（MST） | 无向连通图中连通全部顶点且总边权最小 | $\lvert V\rvert-1$ 条边 | 从固定源出发的最短路径树 |
| 连通性查询 | 两点是否在同一连通块 | 是/否，或集合数 | 两点之间的最短距离 |

一棵最短路径树未必是 MST：它偏向让源点到各点近；MST 只关心全体所选边之和，可能让某个顶点绕远路。MST 的边权可以为负；“负权危险”是某些最短路算法的条件，不是 MST 的禁令。

## 2. BFS：每条边代价相同

在无权图，或每条边权都等于同一个正单位时，BFS 按层扩展。第一次访问顶点时，走过的边数就是最少边数：队列中节点的距离非递减，任何更短路径的前驱本应在更早一层入队。

```text
BFS(graph, source):
    set dist[*] = infinity; dist[source] = 0
    enqueue source
    while queue is not empty:
        u = dequeue
        for each neighbor v of u:
            if dist[v] is infinity:
                dist[v] = dist[u] + 1
                parent[v] = u
                enqueue v
```

邻接表表示下，BFS 时间为 $O(V+E)$、额外空间为 $O(V)$。它不适用于“边数少但代价昂贵”的一般加权图；此时按层不再等于按距离。

## 3. Dijkstra：要求所有可达边权非负

Dijkstra 维护从源到各点的暂定距离，每次取出暂定距离最小的**未确定**顶点 $u$，把它标记为 `settled`，再松弛它的出边：若 `dist[u] + w(u,v)` 更小，就更新 `dist[v]`。下列是“确定后不再重开”的标准版本；负边反例正是针对这条 settled 不变量。

```text
Dijkstra(graph, source):
    set dist[*] = infinity; dist[source] = 0
    set settled[*] = false
    push (0, source) into min-priority-queue
    while queue is not empty:
        (d, u) = pop minimum
        if settled[u]: continue     // lazy heap 的过期条目
        settled[u] = true
        for each edge (u, v, weight):
            if not settled[v] and d + weight < dist[v]:
                dist[v] = d + weight
                parent[v] = u
                push (dist[v], v)
```

当所有边权 $w\ge0$ 时，弹出的最小距离已不可能被未来路径降低：任何经过尚未弹出顶点的替代路径，已知前缀至少不小于 `dist[u]`，再加非负边不会更小。这就是“确定”操作的贪心选择性质。上面使用重复入堆的 lazy 二叉堆，初始化 `dist`/`settled` 要 `O(V)`，队列至多有 $E+1$ 个条目，时间为 $O(V+E\log(E+1))$。对简单图有 $E=O(V^2)$，故可写为 $O(V+E\log V)$。若实现提供 decrease-key 并维持 $O(V)$ 个堆项，常见界为 $O((V+E)\log V)$；不要在未说明实现和图模型时把 `\log E` 无条件改写成 `\log V`。

### 负权反例

边为 $s\to a:2$、$s\to b:5$、$b\to a:-4$。Dijkstra 会先确定 $a$ 的距离为 2；但真实最短路径是 $s\to b\to a$，成本 $5-4=1$。负边允许一个“以后才见到”的顶点回头降低已确定结果，因此上述证明断裂。

## 4. Bellman–Ford：允许负边，也要报告负环

Bellman–Ford 不急于确定某一点。它重复对所有边做松弛。它的逐轮不变量是：完成第 `k` 轮全边松弛后，`dist[v]` 不大于任意一条从源到 `v`、至多含 `k` 条边的路径成本；若每轮只读上一轮快照，它恰是这类路径的最小成本。下面的原地松弛可能按边枚举顺序在一轮传播多条边，只会更早得到改进，不会破坏 $V-1$ 轮上界。

这个不变量可按 `k` 归纳：第 0 轮只有源的空路径为 0；一条至多 `k` 条边的非空路径，可以拆成至多 `k-1` 条边的前缀再接最后一条边，本轮松弛会考虑这个候选。在没有可达负环时，最短游走可删去重复顶点之间的非负环而化为简单路径，至多有 $V-1$ 条边；因此 $V-1$ 轮后所有有限最短距离已传播完。

```text
Bellman_Ford(vertices, edges, source):
    set dist[*] = infinity; dist[source] = 0
    repeat at most V - 1 times:
        changed = false
        for each edge (u, v, weight):
            if dist[u] is finite and dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight
                parent[v] = u
                changed = true
        if not changed: break
    if one more reachable edge relaxation is possible:
        report reachable negative cycle
```

时间上界为 $O(VE)$，空间通常为 $O(V)$（不含图本身）。若从源可达一个负环，则能绕环任意多次降低成本；到受该环影响的目标不存在有限的“最短”值。一个额外松弛只说明存在**从源可达**的负环；若问题只问某个目标，还要判断该负环能否继续到达该目标。额外松弛可从被改进的顶点向前传播“负无穷影响”；在此之前，`parent` 链可能进入环，路径重建必须限制步数或拒绝受影响的目标，不能盲目回溯。

## 5. 手算：选择哪一个最短路算法

从 $s$ 出发的三张图：

| 图 | 边权情况 | 正确选择 | 原因 |
| --- | --- | --- | --- |
| $s-a, s-b, a-t, b-t$ 都为 1 | 单位边权 | BFS | 层数就是距离 |
| $s\to a:2, s\to b:1, b\to a:1, a\to t:2$ | 全部非负 | Dijkstra | $dist[b]=1$，再得 $dist[a]=2$、$dist[t]=4$ |
| $s\to a:2, s\to b:5, b\to a:-4$ | 有负边、无负环 | Bellman–Ford | $a$ 可由 2 改进为 1 |

这张表不是说 Bellman–Ford 在前两图不正确；它仍正确，只是通常做了更多不必要的工作。算法选择同时取决于正确性条件和规模。

## 6. MST：Kruskal 与 Prim 的安全边

对无向连通加权图，生成树连接全部顶点且没有环。Kruskal 从全局最小边开始，若加入不会成环就保留；Prim 从某个起点开始，每次加入当前树到树外的最轻边。两者都依赖**割性质**：对任意把顶点分成两侧的割，跨越该割的最轻边中至少有一条属于某棵 MST。但当算法已有部分选边集 `A` 时，要声称新边对 `A` **安全**，还必须选择一个尊重 `A` 的割：`A` 中没有边跨越该割。此时一条最轻跨割边才能安全地把 `A` 扩展为某棵 MST 的子集。

### 手算一条割

设割左侧为 `{A,B}`，右侧为 `{C,D}`；跨割边为 `A-C:4`、`B-C:2`、`B-D:5`、`A-D:6`。跨割最轻的是 `B-C:2`，所以割性质允许某棵 MST 选它。若当前部分森林的已选边全在割的某一侧内，这个割尊重已选集，`B-C:2` 才还是对当前部分解的安全扩展。这里不是说“任取一个割的最轻边都能随便加入当前树”：Kruskal 以当前连通块形成尊重森林的割，并用 `find(u) != find(v)` 排除会成环的边；Prim 始终使用“已入树顶点/树外顶点”的割。

```text
Kruskal(vertices, edges):
    sort edges by nondecreasing weight
    make one singleton set for each vertex
    tree = empty
    for each edge (u, v, weight):
        if find(u) != find(v):
            add edge to tree
            union(u, v)
    return tree
```

```text
Prim(graph, start):
    mark start in_tree
    push all edges from start into min-priority-queue
    while queue is not empty and tree has fewer than V - 1 edges:
        pop lightest stored edge (u, v)
        if both ends are in_tree: continue  // lazy 队列中的 stale edge
        // 维护“只从刚加入顶点压入其 incident edges”时，不会出现两端都在树外
        add edge to tree; mark outside endpoint in_tree
        push all incident edges of that newly entered endpoint
    return tree if all vertices entered; otherwise report disconnected graph
```

这里 `continue` 不是“跳过一条当前跨割边”，而是跳过入队后两端都已进入树的 stale edge；因此堆顶剩余的第一条跨割边才是安全候选。Kruskal 先为 $V$ 个顶点建立单元素集合，再排序边；其时间为 $O(V+E\log(E+1))$，并查集部分为 $O((V+E)\alpha(V))$。上面的 Prim 从 `start` 只探索它所在的可达分量；若该分量有 $V_s$ 个顶点、$E_s$ 条边，lazy 二叉堆版本为 $O(V_s+E_s\log(E_s+1))$，简单图中可写作 $O(V_s+E_s\log V_s)$。若要在不连通图中得到完整最小生成森林，需对每个尚未进入的顶点重启 Prim，总界为 $O(V+E\log(E+1))$；若图连通，这正是单次 Prim 的 $V,E$ 界。带 decrease-key 的二叉堆可写为 $O(E\log V)$。图不连通时，Kruskal 自然得到**最小生成森林**，而单次 Prim 会报告起点以外仍有顶点；调用方必须决定是否接受森林或执行外层重启。

## 7. DSU：用一片森林维护连通块

并查集（Disjoint Set Union，DSU/Union-Find）维护一个不相交集合族。每个元素有一个父指针；根节点指向自己，`find(x)` 返回集合代表元，`union(a,b)` 只在两代表元不同的时候把两棵树合并。

不变量是：

1. 每个父指针最终到达且只到达一个根，不形成父指针环；
2. 两元素属于同一集合，当且仅当它们的 `find` 结果相同；
3. `union` 只连接两个不同根，因此集合数恰好减一，不会把已有连通块误拆或重复合并。

路径压缩使一次 `find` 走过的节点直接或接近直接指向根；按秩或按大小合并把较浅/较小的树挂到较深/较大的根下。两者组合后，$m$ 次操作的均摊时间为 $O(m\alpha(V))$，其中反 Ackermann 函数 $\alpha$ 在任何现实规模都极小，工程上常近似为常数；这不是严格的单次 $O(1)$ 最坏情况声明。

> [!note] 关于 $\alpha(V)$ 的诚实口径
> 这里不要求手算 Ackermann 函数。对实践的可用结论是：路径压缩加按秩/大小合并的**整段操作总成本**几乎线性；不能由“现实中很小”推出每一次 `find` 都有形式化的最坏 `O(1)` 保证，也不能省略两项优化后直接套用这个界。

Kruskal 中“若两个端点已同集合则跳过”正是环检测：当前选边已构成森林，两个端点若已连通，再加这条边就会形成环。

## 8. 常见误用与失败检查

- 对一般正权加权图用 BFS：它最小化边数，不最小化权重和；
- 对含负边图用 Dijkstra：已确定的距离可能被回头改善；
- 把 MST 当最短路树：两者优化的目标函数不同；
- 在 Kruskal 中不检查 `find(u) != find(v)`：会加入环，结果不再是树；
- 对有向图直接谈普通 MST：经典 MST 定义针对无向图；有向分支结构是另一类问题；
- 报告负环时忘记可达性：与源无关的负环不影响该源的距离结果。

## 练习

1. 对边 $s-a:1$、$s-b:4$、$a-b:2$、$a-t:6$、$b-t:3$，手算 Dijkstra 每次弹出的顶点及最终 `dist[t]`。
2. 给图 $s\to a:1$、$a\to b:-2$、$b\to a:-2$、$b\to t:1$，解释 Bellman–Ford 的额外一轮为何仍可松弛，以及为何 $t$ 没有有限最短路。
3. 在无向图边 $(A,B,1)$、$(B,C,2)$、$(A,C,3)$、$(C,D,4)$ 中执行 Kruskal。每条跳过的边写明两个端点的 `find` 结果与“成环”理由。
4. 说明一个 DSU 若只做任意合并、不做路径压缩或按大小合并，正确性是否受影响；再说明性能为什么可能变差。

## 成功标准

- 你能根据“单位边权 / 非负边权 / 允许负边”分别选择 BFS、Dijkstra、Bellman–Ford，并陈述对应前提；
- 你能用 $s\to a:2,s\to b:5,b\to a:-4$ 解释 Dijkstra 的负边反例；
- 你能说出 MST 与最短路径树的目标差异，以及 Kruskal/Prim 的安全性来自割性质；
- 你能陈述 DSU 的三条森林不变量，并把 $O(m\alpha(V))$ 解释为均摊近似而非魔法常数。
