# 资源受限科技创业与单位经济：怎样在现金耗尽前学到值得行动的东西

一个工程师能把询价文件变成报价草稿，却没有大额资金和投资人关系。下一步是多写功能、找客户、找合作方，还是筹资？先问当前卡在哪一环。技术演示、客户使用、买方付款、可靠交付、创业者留下贡献和现金，是六个不同结果。看成功公司的共同点，不能替这个工程师回答自己的约束。

本课用报价工作流贯穿验证、单位经济和组织选择。历史案例用于提出竞争解释，教学金额用于检查条件；二者都不是个人创业成功率或当前赛道排行榜。来源核读截止2026-10-09，动态经营数据只对应注明的历史时期。

## 从损失到可重复的现金，中间会在哪里断裂

客户每周处理几十份询价，确实有痛点，但使用者可能没有预算；老板有预算，却担心报价错误和数据外流。现有供应商较慢，却能承担责任。因此“能省时间”只证明一部分价值，未证明存在可经营的机会。

```mermaid
flowchart LR
  A[某类客户的实际任务损失] --> B[技术与交付能改善]
  B --> C[受益者与预算买方]
  C --> D[采购信任与责任安排]
  D --> E[可靠交付和持续使用]
  E --> F[收费覆盖完整增量成本]
  F --> G[回款支持下一次选择]
```

图是待检查的条件链，每个箭头都可能不成立。客户省下100元，并不保证供应商能收100元；竞争、采购权、替代品与互补投入决定价值获取。[[社会科学/20-经济流动与宏观/13-生产率技术扩散与制度变迁|技术采用主解释]]说明设备、流程、技能和需求为什么要一起检查。此处把它用于新供应商进入客户组织，不复制电气化、管理实验和NPV的完整论证。

资源也要拆开：自由现金、工资与生活缓冲、行业经验、设备与知识产权、供应商账期、客户信任、渠道和可调用帮助。注册资本低，只说明一个法律或现金起点。没有富人关系不等于没有行业联系；公开作品能够形成可检查信誉，但是否能动员资源仍需观察。联系、桥接位置与社会资本的定义见[[社会科学/40-公共政策与社会学/05-网络社会资本制度与文化|网络与可动员资源]]。

机会为何尚未被大公司解决，也要保留不同解释：市场碎片化、现有销售成本太高、新技术刚降低成本、兼容或利益冲突，或者根本没有足够可支付收益。最后一种会推翻“被忽略就值得做”的直觉。

## 第一批反馈可能使产品朝错误方向变好

朋友、技术社区和首发网站容易接触，但其工作流、预算与责任未必像目标客户。某功能在程序员中获好评，却使采购负责人更难审计；你可能优化了错误对象的体验。

Cao、Koning、Nanda的《Sampling Bias in Entrepreneurial Experiments》在此采用HBS Working Paper 21-059、2022-07-29版本，核读§2、§4.5及附录F：它研究2016—2018年Product Hunt产品，利用历史产品简报引起的当日用户构成变化考察抽样偏差。结果量包含后续网站访问；不能把访问增长当利润。简报冲击影响多种参与渠道，作者明确不将其简单当“票数”的标准工具变量。该历史平台机制不能直接外推中国B2B；姓名推断性别和平台入选也有测量与选择边界。[工作论文原文](https://www.hbs.edu/ris/Publication%20Files/21-059_96e01ed1-06e4-4219-b06d-a9798be1618a.pdf)。2024正式发表版本与工作论文不能不加说明地混用效果数字，本课不引用百分比效果。

报价项目可以建立如下研究接口，当前未实施：固定客户单位为“有重复询价流程且有采购预算的一类企业”，分别记录使用者、预算人、数据负责人。沿两个来源不同的渠道，保留接触、未回应、合格、报价、购买、真实使用、续购和拒绝原因的分母。同范围同价格是比较前提，客户类型或报价同时改变时，不能把结果全归给渠道。

| 竞争解释 | 能区分的观察 | 应更新哪种选择 |
| --- | --- | --- |
| H1：识别质量不够 | 冻结真实代表性样本，错误集中于某类输入，修订后在独立样本改善 | 针对输入与错误修技术；未测试预算/信任 |
| H2：使用者喜欢但没有购买权 | 工作流实际有价值，预算人却不承担相同收益或没有可用预算 | 改买方与收益安排；不能只加功能 |
| H3：预算存在但不信任数据处理和责任 | 相同质量价格下，客户对可审计部署/边界责任方案明显更能接受 | 检查交付和信任；不能默认降价解决 |
| H4：购买的是定制人工服务 | 首次实施愿付款，但自主使用、跨客户复用或续订弱 | 将服务作为可能终点，收窄通用产品命题 |

这些是可区分预测，不是已经得到的客户证据。少量客户时报告人数与分母，保留失败和未回应者；如不能随机化，渠道构成、时机和自选择仍是竞争解释。旧稿1—5分加权及70/55分行动线未说明归一化、权重依据和外部效度，只能保留为提问清单，不能当成功率预测器或据分数自动作投入决定。某个风险上限还可能构成硬约束，不能靠其他高分抵消。

Camuffo等2024年的四项研究包含759家企业；两组都受训，处理组多了科学式决策训练。核读论文§5、§6及表2—5，其研究内结果支持更多、更早终止项目，并呈现转向方式差异；不是“受训/无人支持”的比较，也不保证普遍收入提高。自愿申请的企业与全部创业者不是同一总体。[正式论文机构入口](https://openaccess.city.ac.uk/id/eprint/32437/)。本课将其转为设计原则：行动前写清解释、替代解释、区分观察、预算上限和信息到达时间；停止不合算想法可以保护下一次选择，但高终止率本身也不是目的。未复现研究数据。

## 可靠工作流的单位贡献：降模型价格可能只改变一小项

固定一种收费任务和质量门槛，以元/任务核算收入与成本。模型调用、重试、集成、人工审核、异常返工和退款必须在同一边界内；失败但没有收费的任务，其成本也要分摊到相应收费任务。定义简化的期望贡献：

$$m=P-c_{model}-c_{other}-wh-\pi L.$$

$P$为每收费任务收入；两个$c$为相应平均直接成本；$w$为复核每小时成本，$h$为每任务复核小时；$\pi\in[0,1]$为复核后某一残余错误发生概率，$L\ge0$为该错误发生时的平均损失。若有多类错误，应分开条件概率与损失，防止重叠事件重复计入。返工、退款若已进入$c$，不能再次计入$L$。固定成本、税费、融资和资本支出尚未进入$m$。

以下全部是教学构造，没有真实报价客户数据：$P=100,c_{model}=2,c_{other}=3,w=150,h=0.2,\pi=0.01,L=1000$。

| 情景 | 代入过程，元/任务 | 期望贡献 |
| --- | --- | ---: |
| 基准 | $100-2-3-150\times0.2-0.01\times1000$ | 55 |
| 只把模型成本降为1 | $100-1-3-30-10$ | 56 |
| 审核时间降为0.1小时，假设错误率不变 | $100-2-3-15-10$ | 70 |
| 取消审核，假设错误率升至0.08 | $100-2-3-0-80$ | 15 |

第三行的错误率不变必须取得证据，第四行的0.08同样是假设。降成本带来价格竞争时，$P$也可能下降；计算只改$c_{model}$不能预测真实利润变化。平均损失还不能保护一个小团队免于低概率巨额赔付，必须另设不可承受事件、授权与人工批准的约束。

“可靠完成一次”的记录至少要对应任务与版本、独立判分、人工介入、所有重试成本、失败/拒绝、延迟分布和风险类别。离线冻结样本只能检查其覆盖的任务；真实工作流、续用和买方受益需要另取证。具体评测真源见[[AI/20-LLM/70-工程应用与工具链/04-评测回归与可观测性|分层评测、版本与回滚]]，统计边界见[[AI/20-LLM/70-工程应用与工具链/10-LLM评测污染裁判偏差与统计检验|裁判偏差和统计检验]]。

### 免费版：同一个用户分母才能算得上

在同一期间、同一活跃用户总体中，$N>0$为人数，$q\in[0,1]$为付费比例，$P$为每付费用户该期收入，$c_p,c_f$为付费、免费用户平均直接成本，$F$为该期固定成本。简化经营余额为

$$\Pi=N[q(P-c_p)-(1-q)c_f]-F.$$

令$D=P-c_p+c_f>0$，则非亏损条件是

$$q\ge\frac{c_f+F/N}{D};$$

严格盈利改为$>$。阈值大于1时，该参数下即使全部付费也无法非亏损；$D\le0$时不能沿用除法方向，应回原式分析。教学参数$N=10000,P=100,c_p=10,c_f=1,F=20000$给阈值$3/91\approx3.2967\%$；$q=1\%$时$\Pi=-20900$，$q=5\%$时$\Pi=15500$元/期。均未运行程序。

累计注册者不能充当活跃$N$，某一渠道升级率不能充当总体$q$。获客、流失、年付递延和未单列风险成本还要按目的加入；因此这不叫完整净利润模型。Tally自报的累计用户和ARR也不能直接塞入本式。

## 现金时序与资本：钱的来源改变了谁承担什么风险

账面贡献为正，客户半年后付款仍可能使企业先断现金。预付款可能附退款义务，应收款还未到账；云额度有用途和资格限制，不能当工资现金。收入、现金、利润、估值和ARR的类型与期间回[[社会科学/10-共同工具/02-指标分布与存量流量核算|核算真源]]；条件承诺与实际付款的区别回[[社会科学/30-金融市场与风险/10-科技公司融资与AI资本循环校注|融资校注]]。

教学跑道令$C$为实际可动用现金，$R$为不得投入项目的生活/应急保留额，$E$为一次性试验支出，$b>0$为之后恒定每月净现金消耗。要求$C-R-E\ge0$：

$$T=\frac{C-R-E}{b}.$$

$C=60000,R=20000,E=8000,b=6000$元/月时，$T=16/3\approx5.33$个月。负分子意味着当前计划已经不可行，不能叫负跑道；$b=0$不能使用此式；分期支出、回款波动和退出成本要用逐月现金账。旧稿资金比例上限相加为120%，不能作为完整预算；这里也不是建议任何人投入相同比例。

| 资金/合作方式 | 可以承担的约束 | 新增代价或边界 |
| --- | --- | --- |
| 工资、服务收入 | 保生活与渐进开发 | 时间有限，定制交付可能锁住团队 |
| 客户预付/联合开发 | 证明预算并提前现金 | 履约、退款、专属需求和权利约束 |
| 研究资助与产业合作 | 在首单前取得技术证据 | 资格、里程碑、成果归属与期限 |
| 股权资本 | 较长期研发与扩张 | 所有权、治理、增长/退出目标改变 |
| 借款和供应商账期 | 有预测现金流的周转 | 到期偿付；未知需求风险未消失 |

这是条件比较，没有普适融资次序。深研发可能先筹资取得第一份可行性证据；窄服务业务可能无需资本扩张。选哪个终点，还要把收入、时间、健康、控制权、员工和客户责任分开。

## 服务何时积累产品，何时积累更多人工工作

首个客户可以买创始人的个人能力，下一家却要另一套字段和审批。代码越来越多，但每客户支持时间同比增加，不能由“有代码”宣布产品已经形成。

把项目分解成共享流程、配置、真正复用的模块、客户特定实施和持续支持；记录每客户交付/变更/支持工时、数据权利、自主使用程度与创始人亲自销售时间。如果共同模块变多，但创始人工时不降，要竞争性检查数据质量、组织责任、客户异质性与产品界面。原“60%共同流程”没有校准，不能当自动转型门槛。标准化专业服务也可能是可控且有价值的终点。

分发也有资产和成本：内容、合作方、平台集成、自助购买与企业销售解决不同信任门槛。一次曝光不等于重复渠道；平台算法、API、账号权限改变可能损害业务。规模经济是固定成本分摊，学习效应是经验改善流程，网络效应是用户增加改变他人使用价值，切换成本是迁移代价；四者不能统一叫飞轮，更不能把有害锁定当客户价值。

## 用成功、慢增长、收缩与终止共同检查解释

下面五组有本次实际核读的公司/创始人原始记录，全部仍属自报或回忆，不等于审计，也不是互相匹配的因果对照组。

- **Plausible，2018—2022**：开发者自用问题起步，2019年5月收费，324天达到400美元MRR；2020年增加市场合伙人，内容与隐私定位参与分发，2022年自报100万美元ARR、4人。达到可持续时此前还消耗了两人个人储蓄，说明自筹增长也有安全垫成本。慢增长反驳统一90天停止线，却不证明任何项目坚持就有效。[2022回顾](https://plausible.io/blog/open-source-saas)。
- **Tally，2020—2026年9月**：免费表单入口和传播、付费升级并行；2026-09-22自报600万美元ARR、250万用户、10人。它同时披露8月第三方工具安全事件，账号邮箱和哈希密码被提取；表单未被访问是公司声明，年底认证是计划。产品小团队并不免除运维、依赖治理和信任责任。[公司回顾](https://blog.tally.so/6-years-in-6-million-far/)。
- **Gumroad，2011—2019回顾**：创作者销售链接起步，获外部资本；增长不足以支持下一轮路径，团队由20缩到5，2016年6月披露较小成本结构下盈利。行业位置和资金不能省略；存续与创始人后来选择更自由，也不能抵消裁员和投资损失。不能由回忆识别唯一失败原因。[创始人复盘](https://sahillavingia.com/reflecting)。
- **RethinkDB，2016—2017**：2016-10-05经营关闭公告确认无法建立可持续业务，工程团队转入Stripe；2017-02-06公告记载CNCF购买代码权利并贡献给Linux Foundation。企业终止与公共项目存续是不同结果，不能以开源代码可用证明原商业模式成功。[关闭公告](https://rethinkdb.com/blog/rethinkdb-shutdown/)、[治理转接公告](https://rethinkdb.com/blog/rethinkdb-joins-linux-foundation/)。
- **Balsamiq，2024结果、2025发布**：2025-02-04公司回顾自报2024收入658万美元、比2023下降6%，同时聚焦云与Atlassian集成。产品线调整、收入下降与长期存续可以并存；不从某一年下降判全部失败，也不以“三周盈利”故事认证完整成本。[年度回顾](https://balsamiq.com/blog/looking-back-2024/)。

| Salesforce，1999起 | 大型软件经验；在线CRM企业买方 | 外部资金及企业销售；各阶段金额未知 | 订阅→多业务→平台；远程交付没有消除迁移与实施责任 |
| Basecamp，1999服务/2004产品 | 设计咨询现金与内部协作问题 | 自助/公开写作；2006少数投资安排待核 | 减定制、发展订阅；内部需求能否外部复用要另验证 |
| Mailchimp，2001起 | 代理业务与小企业邮件需求 | 代理现金、自助/免费版；所有权历程待核 | 工具→营销业务；长尾客单与销售成本匹配，不把交易估值当收入 |
| Atlassian，2002起 | 技术与支持需求；Jira团队用户 | 网站试用/透明购买；信用额度故事遗漏资源待核 | 部门采用→产品组合/云/企业；早期自助不等于永远不用销售 |
| Shopify，2004自用/2006平台 | 自建Snowdevil商店软件 | 商家订阅与伙伴生态；各期融资待核 | 工具→支付/POS/生态；未证明原商店失败，GMV与收入分开 |
| DJI，2006起 | 学校飞控研究、导师和深圳供应链 | 组件/整机渠道；前置资本及研发支持待核 | 飞控→完整航拍→专业用途；工业化须计库存、认证、质量与售后 |
| Balsamiq，2008起 | 线框工具与设计开发团队需求 | 早收费与平台集成；完整初期成本待核 | 桌面→云与聚焦；2024收缩局部已核，早期盈利成本边界仍未知 |
| Zapier，2011起 | 兼职开发与跨SaaS集成需求 | 论坛需求/早期付费与伙伴；融资细节待核 | 手工接触→连接目录/开发平台；API变化和恢复维护是持续成本 |
| Canva，2007校刊/2013产品 | 设计教学、窄校刊客户及生活支持 | 早期借款线索、后种子资本/资助；模板自助 | 校刊→大众/团队；狭窄学习能否迁移需查客户与技术差异 |
| Figma，2012研发/2015beta | 浏览器图形技术与协作研发 | 前置资本、自下而上传播、后企业销售 | 设计→协作/开发工作流；多年研发的成功不能认证所有长期坚持 |
| Cursor，2022起 | 开发者与编辑器工作流、模型浪潮 | 自助下载与风险资本；当前成本利润未知 | 编辑器→agent/企业；异常高增长不能作普通团队预算前提 |

与新增Tally、Plausible、Gumroad、RethinkDB共19个不同对象。它们跨年代、资本强度和客户组织，不能直接比较增长率，更不能估某路径的因果成功率。真正可比研究应固定决策当时信息，匹配行业、时期、起点现金/经验、可触达买方与技术资本强度，纳入未上市、缩编、终止与仍未观察到结局的企业。找不到匹配对照，就保留不可识别。

## 怎样检验自己已经学会选择

给报价项目写一页决策卡：受保护资源、目标使用者和买方、至少两个竞争解释、质量/责任门槛、现金回收时间、区分实验、可承受损失与下一次行动。继续、缩小、合作、融资、保持服务或停止都可成为结论，不能预先规定“服务→SaaS→平台”。

迁移题：每任务模型费减半，而销售周期翻倍，是否值得扩张？仅凭$m$增加无法回答，需回款、固定成本、客户容量与资金边界。若首单愿付费但后续不用，至少区分一次性服务、信任/实施、需求频率和产品适配；不能宣布产品市场匹配。若增长不错却自主性下降，比较合同、固定成本、客户集中、平台和员工责任，而非只看估值。
