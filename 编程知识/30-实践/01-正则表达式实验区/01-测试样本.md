# 正则表达式测试样本

所有数据均为虚构内容，域名使用 `example.com`，IP 使用文档保留地址。每次只复制当前练习需要的几行，避免无关格式影响结果。

## A · 基础文本

```text
ERR-404 request missing
WARN-404 cache stale
ERR-42 short code
prefix ERR-500 suffix
ERR-1234 long code
```

预期重点：字面前缀、三位数字、搜索与更长数字的边界。

## B · 标识符

```text
dev_01
Alpha9
abc
a12345678901
a123456789012
ab
1dev
dev-name
abcdefghijklmn
```

预期重点：ASCII 字母开头，总长度 3 到 12，后续只允许 ASCII 字母、数字和下划线。其中 `abc` 是长度 3 下界，`a12345678901` 是长度 12 上界，`a123456789012` 是长度 13 反例。

## C · 订单编号

```text
PO-2026-0042
SO-2026-1200
XO-2026-0042
PO-26-0042
PO-2026-42
PO-2026-0042-extra
```

预期重点：选择分支、非捕获组、精确量词、完整匹配。

## D · 日志字段

```text
2026-08-31 level=ERROR code=E104 message=timeout
2026-08-31 level=INFO code=I200 message=ready
2026-08-31 level=debug code=D100 message=hidden
2026-08-31 level=ERROR code=E10 message=short code
```

预期重点：命名组、受限分支、捕获与替换。

## E · 引号字段

```text
name="alpha" status="ready"
name="beta value" status="blocked"
name="unfinished status="unknown"
```

预期重点：贪婪、惰性、排除式字符类，以及未闭合引号的边界。

## F · 上下文断言

```text
ticket=1234 ticket=98765 ref=4321
ticket=0007
ticket=42
```

预期重点：捕获上下文与后行断言、数字右边界。

## G · Unicode 对照

```text
hello_42
中文
１２３
café
🙂
é
```

最后一行视觉上类似带重音的 `é`，但可能由 `e` 与组合附加符号构成。不要假设复制、规范化或字体显示后底层表示一定相同。

## H · 短性能样本

```text
aaaa
aaaa!
alpha beta gamma
alpha  beta
report.log
report.log.tmp
```

这里只用短输入观察正确性。不要为了“看出变慢”而构造极长字符串。

## I · 综合日志

```text
2026-08-31T09:30:15Z level=ERROR code=E104 message=request timeout
2026-08-31T09:31:00Z level=INFO code=I200 message=request complete
2026-08-31T09:32:01Z level=debug code=D100 message=hidden
2026-08-31 09:33:00 level=WARN code=W300 message=bad timestamp
2026-08-31T09:34:00Z level=WARN code=W30 message=short code
2026-08-31T09:35:00Z level=WARN code=W301 message=
2026-08-31T09:36:00Z code=W302 message=missing level
```

## J · 日期与姓名

```text
31/08/2026
31-08-2026
31/08-2026
31/13/2026

Lovelace, Ada
Turing, Alan
Hopper, Grace Brewster
```

日期形状匹配后仍须交给日期库验证；姓名样本只代表本练习定义的简化格式。

姓名边界反例中，`␠` 表示一个普通空格；测试时把它替换成真实空格：

```text
␠Lovelace, Ada
Lovelace, Ada␠
Lovelace,Ada
Lovelace␠, Ada
␠␠␠, Ada
Lovelace, ␠␠
```

预期：这些行都应拒绝，不能把行首、行尾、逗号前空格或纯空格字段捕获为姓名。
