# 热调节复算：先预测，再运行

本实验用Python标准库，不需NumPy或绘图库。数学对象是一阶集中参数热模型，x单位K、u/d单位W、时间单位s；没有测过真实温度、功率、执行器或deadline。源码 [thermal_control_lab.py](thermal_control_lab.py) 是真源，[[控制论/80-实践/01-热调节/code-sync/thermal_control_lab|逐字源码镜像]]供笔记内阅读。

## 固定输入和运行命令

C=10 J/K、h=1 W/K、kₚ=3 W/K、kᵢ=0.4 W/(K·s)、x₀=0、z₀=0。基准r=2 K；每个案例另写Ts、d和bias，有限幅案例取u∈[−10,10] W。模型中P=10+u W、环境20 °C、工作点30 °C；表格与CSV记录偏差量，不把K标成绝对温度。

从Vault根目录复算，可将输出写到自己新建的临时目录：

```bash

  --output-dir '/private/tmp/wwl-thermal-reader-run'
```

脚本中的assert核手算一步、解析闭环轨迹、RK4缩步、指定极点及有限偏置/饱和例。固定数值和解析递推能发现符号、单位或索引错误；它们不是一般控制器自动认证器。C、h、kₚ等常量在源码顶部；修改后先重新给解析预测，再运行，原文固定数值的assert须随新的明确基准调整。函数trajectory还接受reference、disturbance、bias、limit、integral，便于在独立副本中改单个条件。

## 撤去方法提示的实践题

1. 在相同无延迟数字比例结构中，C=10、h=1、kₚ=3、Ts=1，将d从−2 W改成+2 W。给第一步、最终温差、最终功率偏差；说明哪部分是有限观察，哪部分可以给全时结论。
2. 同样r=2，把功率偏差上限改为3 W，下限仍−10 W，d=−2 W。任何积分律都能保证真实x→2吗？给必要平衡条件，再讨论anti-windup。
3. 保持所有参数，把更新顺序改成“先zₖ₊₁=zₖ+Ts(r−yₖ)，再uₖ=hr+kₚ(r−yₖ)+kᵢzₖ₊₁”。写新误差矩阵并判断Ts=1 s的齐次稳定性。不能用旧PI极点当答案。

> [!question]- 题解与判断依据
> 1. u₀=8 W，x₁=b(8+2)=0.951625820 K；稳定平衡x*=2+2/4=2.5 K，u*=h×2.5−2=0.5 W。无噪声未限幅递推给qₖ=fᵏq₀+b d(1−fᵏ)/(1−f)，这是所有k的解析式；有限CSV仅支持记录点。
> 2. 真正目标需要u*=hr−d=4 W，超过3 W，因此无论积分怎样更新都不可达；有限幅下最大平衡x*=(3−2)/1=1 K。anti-windup可以帮助状态恢复，但不会扩大功率可达集。
> 3. 新矩阵为[[f−bkᵢTs,bkᵢ],[−Ts,1]]，trace=1+f−bkᵢTs，det=f。Ts=1时trace≈1.581284639、det≈0.619349672；二阶Schur三项约0.0380650、3.2006343、0.3806503均正，故齐次稳定，极点不同于旧状态版本。接受由特征根、Schur条件或合法等价证据完成的判断。
