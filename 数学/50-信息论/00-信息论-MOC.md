# 信息论 MOC

这里从高中阶段的指数、对数和加权平均出发，建立语言模型中最常见的一条数学主线：

> logits → Softmax 概率 → 对数概率 → 交叉熵 / KL 散度 → 训练、蒸馏、偏好优化与模型漂移评测

本目录是这些概念的**数学定义与推导的唯一权威位置**。AI 笔记只解释具体模型怎样使用它们，并链接回这里，不复制一套可能逐渐分叉的推导。

## 你将学会什么

- 区分真实或来源分布 $P$、模型分布 $Q$ 与单个已观测样本 $y$；
- 理解熵、交叉熵、负对数似然、KL 散度、互信息各自回答什么问题；
- 从指数和对数推导 Softmax、LogSumExp、log-softmax 与数值稳定形式；
- 看懂 next-token 训练、偏好目标、知识蒸馏、温度采样和模型分布比较中的公式角色；
- 用纯 Python 复现实数溢出、稳定平移和概率归一化。

## 建议先修

- 会解读 $a^b$、$\log a$、求和符号 $\sum$ 和加权平均；
- 知道概率非负且总和为 $1$；
- 建议先读 [[数学/30-概率与统计/00-概率与统计-MOC|概率与统计 MOC]]；若该页仍在建设，可先凭本目录给出的离散概率复习继续学习。

## 一张角色地图

| 符号 | 角色 | 在语言模型里的常见含义 |
| --- | --- | --- |
| $z_i$ | 尚未归一化的分数 | 词表中第 $i$ 个 token 的 logit |
| $Q(i)$ | 被评估或被训练的分布 | 当前模型给出的 next-token 概率 |
| $P(i)$ | 参照、目标或数据来源分布 | 真实分布、教师模型、参考模型或基线模型 |
| $y$ | 从数据中观察到的一个结果 | 训练语料里的正确 next token |
| $-\log Q(y)$ | 一个样本的损失 | token 级负对数似然 |
| $H(P,Q)$ | 在 $P$ 下平均评估 $Q$ | 期望交叉熵 |
| $D_{\mathrm{KL}}(P\Vert Q)$ | 用 $Q$ 代替 $P$ 的额外编码代价 | 教师到学生或基线到修改后模型的分布漂移 |

> [!warning] 方向不能省略
> $D_{\mathrm{KL}}(P\Vert Q)$ 一般不等于 $D_{\mathrm{KL}}(Q\Vert P)$。任何工程文档只写“KL”却不说明谁是 $P$、谁是 $Q$、在哪些输入与哪些 token 上平均，都还不够完整。

## 面向 AI 的出口

- next-token 训练：一个样本给出 $-\log Q_\theta(y_t\mid y_{<t})$，许多 token 的平均估计交叉熵；
- 蒸馏：教师分布作 $P$、学生分布作 $Q$，最小化 $H(P,Q)$ 等价于最小化 $D_{\mathrm{KL}}(P\Vert Q)$；
- 偏好目标：常比较候选回答的条件序列 log-prob；具体 DPO、ORPO、KTO 目标与变体由 AI 应用页维护；
- 采样：温度先重塑 logits，top-k / top-p 再截断并重新归一化，因此实际采样分布不一定等于原始 Softmax；
- 模型分布比较：先写清 KL 方向、输入分布、token 或序列范围与聚合方式；局部低 KL 不能单独证明全部能力被保留。

这些出口的公式与边界均在前两课展开；应用笔记应链接到对应小节。

## 完成检查

完成本单元后，你应能不看答案完成以下口头检查：

1. 给定 $P=(0.5,0.5)$ 与 $Q=(0.9,0.1)$，指出熵、交叉熵和 KL 分别对哪个分布取平均。
2. 解释为什么单个标签 $y$ 的损失 $-\log Q(y)$ 不是“模型分布自身的熵”。
3. 写出 $\operatorname{LSE}(z)$ 的减最大值形式，并说明它为何数值稳定。
4. 说明温度 $T<1$ 与 $T>1$ 分别怎样改变 Softmax 分布。
5. 看到一个模型修改前后的 KL 数字时，主动追问 KL 的方向、输入集、token 或序列范围、精度和聚合方式。

成功标准：以上五题都能回答，并能运行实验页的伴随 Python，看到所有断言通过。
