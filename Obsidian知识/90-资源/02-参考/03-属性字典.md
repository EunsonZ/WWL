# 属性字典

本页定义 Playground 推荐的属性名称、类型和值域。它是**约定**，不是 Obsidian 强制 schema；自己的 Vault 可以删减，但同一属性名应在整个 Vault 中保持同一含义和类型。

> [!important] 最小原则
> 只保存会用于搜索、排序、过滤、模板或回顾的结构化信息。正文事实放正文，笔记关系优先用链接，流程状态才用属性或标签。

## Obsidian 支持的属性类型

| 类型 | YAML 示例 | 适合 | 注意 |
| --- | --- | --- | --- |
| Text | `status: ready` | 单值状态、短说明、URL | 不渲染 Markdown；不要放长段正文 |
| List | 多行 `- value` | topics、platforms、links | 同一列表尽量保持相同值类型 |
| Number | `rating: 4` | 评分、时长、金额 | 必须是字面数字，不写 `4/5` 或公式 |
| Checkbox | `fixture_reviewed: false` | 教学样例的复习勾选 | 只用 `true` / `false`；不表示个人掌握或内容认证 |
| Date | `created: 2026-08-30` | 创建、截止、复习日期 | 推荐 ISO `YYYY-MM-DD` |
| Date & time | `captured_at: 2026-08-30T14:30:00` | 精确采集/事件时间 | 含时区需求时额外统一规则 |
| Tags | `tags:` 列表 | Obsidian 标签 | 只适用于保留属性名 `tags` |

链接不是单独的 Properties 属性类型：`related: "[[另一篇笔记]]"` 存储为 Text，多个链接使用 List；Bases 中解释这些值时可以得到 Link 对象。这两个层次不能混用。依据：[Properties](https://obsidian.md/help/properties) 与 [Bases syntax](https://obsidian.md/help/bases/syntax)，2026-09-08 已核对。

Obsidian 当前不在属性界面中完整支持嵌套属性，也不在属性值中渲染 Markdown。需要可读和可查询时，优先使用扁平、原子的键值。

## 官方保留属性

| 属性 | 类型 | 用途 | 示例 |
| --- | --- | --- | --- |
| `tags` | Tags/List | 标签 | `playground/reference` |
| `aliases` | List | 该笔记的替代名称 | `Markdown速查表` |
| `cssclasses` | List | 给特定笔记添加 CSS 类 | `wide-page` |
| `publish` | Checkbox | Publish 是否发布 | `false` |
| `permalink` | Text | Publish 固定链接 | `guide/markdown` |
| `description` | Text | Publish/链接预览说明 | 一句话摘要 |
| `image` / `cover` | Text | Publish/卡片封面 | 附件路径或 URL |

不要新写已弃用的 `tag`、`alias`、`cssclass`；分别改用 `tags`、`aliases`、`cssclasses`。

## Playground 课程属性

| 属性 | 类型 | 推荐值/格式 | 用途 |
| --- | --- | --- | --- |
| `type` | Text | 见下表 | 笔记职责；最重要的单值属性 |
| `stage` | Number | 非负整数，例如 `0`、`1`、`2` | 课程阶段；参考角色使用独立的 `course_role: reference` |
| `status` | Text | `draft`、`ready`、`in-progress`、`complete`、`archived`、`inbox`、`seed`、`active` | 内容或工作流状态；按 `type` 解释 |
| `difficulty` | Text | `入门`、`进阶`、`挑战` | 课程难度；本中文 Playground 使用中文值域 |
| `estimated_minutes` | Number | 正整数 | 预计完成时间，不写“15 分钟” |
| `topics` | List | 简短主题名 | 横向主题；不带 `#` |
| `plugins` | List | 插件 ID 或稳定短名，例如 `dataview` | 社区插件实验页实际讨论的插件；不是所有课程都需要此属性 |
| `risk_level` | Text | `low`、`medium`、`high`、`critical`；混合索引可为 `mixed` | 操作与集成风险提示；不表示掌握度、安装或已验证运行状态 |
| `platforms` | List | `desktop`、`mobile`、`ios`、`android` | 课程/功能适用平台 |
| `core_plugins` | List | 核心插件显示名称 | 课程依赖的核心插件 |
| `community_plugins` | List | 社区插件显示名称 | 课程依赖的社区插件；无依赖时用空列表或省略 |
| `prerequisites` | List | 带引号的内部链接 | 前置课程 |

### `type` 推荐值

| 值 | 含义 | 典型内容 |
| --- | --- | --- |
| `moc` | Map of Content 导航页 | 学习路线、主题入口 |
| `guide` | 连续说明与路线建议 | 上手指南、工作流指南 |
| `lesson` | 可独立完成的一课 | 原理、步骤、检查点 |
| `plugin-lab` | 社区插件实验课 | 原生替代、风险、退出条件与可检查实验 |
| `exercise` | 可修改的练习 | 填空、修复、动手任务 |
| `challenge` | 综合挑战 | 检索、链接迷宫、毕业任务 |
| `example` | 已完成示例 | 对照用来源/概念/项目笔记 |
| `reference` | 速查资料 | 本目录中的字典、矩阵、术语表 |
| `template` | 模板源文件 | 日记、来源、会议、项目模板 |
| `workflow` | 端到端流程 | 收集到常青笔记、会议到行动 |
| `source` | 外部资料记录 | 书、文章、视频、PDF |
| `concept` | 可复用观点/概念 | 原子化知识笔记 |
| `project` | 有完成条件的工作 | 目标、下一步、状态、资料 |
| `daily` | 日期笔记 | 日志、采集、日计划、日复盘 |
| `meeting` | 会议记录 | 议题、决定、行动项 |

`plugin-lab` 表示社区插件实验课；承担路线、索引和取舍说明的页面按本约定使用 `moc`。历史页面的类型可能不同，Base 应按实际集合明确排除索引页，不为迁就旧筛选批量改写课程。

> [!tip] `type` 与标签不重复
> `type: concept` 已说明文件职责，就不必再加 `#type/concept`。标签应表达真正需要跨目录聚合的主题或状态。

## 知识与来源属性

| 属性 | 类型 | 示例 | 用途 |
| --- | --- | --- | --- |
| `created` | Date | `2026-08-30` | 笔记建立日期；不是文件系统时间的替代 |
| `updated` | Date | `2026-08-30` | 有明确维护流程时才使用；不要手工制造负担 |
| `revision` | Number | `2` | 内容的数字修订号；保留现有编号，不与日期混用 |
| `revision_date` | Date | `2026-09-06` | 既有内容修订日期；不代表全页已核验或个人已掌握 |
| `review_date` | Date | `2026-09-06` | 下次复习日期 |
| `fixture_reviewed` | Checkbox | `false` | 虚构教学样例是否标作已复习；不记录个人掌握，也不表示内容认证 |
| `source` | Text | `https://obsidian.md/help/` | 单一外部来源 URL |
| `sources` | List | URL 或 `"[[来源笔记]]"` | 多来源；与 `source` 二选一并保持一致 |
| `author` | Text | `作者名` | 单一作者 |
| `authors` | List | `- 作者甲` | 多作者；与 `author` 二选一 |
| `published` | Date | `2026-08-01` | 原始材料发布日期 |
| `related` | List | `- "[[相关概念]]"` | 少量显式关系；正文中有上下文链接时可省略 |
| `rating` | Number | `4` | 评分；在说明中固定范围，例如 1–5 |
| `summary` | Text | 一句话摘要 | 卡片视图或搜索预览；长摘要放正文 |

历史原稿或剪藏中的 `author` 可能是列表；保留其来源格式。上表的 Text 是活动模板的单作者约定，不据此改写原稿，也不为未解析的作者链接自动创建人物页。

## 项目与工作流属性

| 属性 | 类型 | 推荐值/格式 | 用途 |
| --- | --- | --- | --- |
| `status` | Text | `inbox`、`seed`、`active`、`waiting`、`complete`、`archived` | 当前流程状态 |
| `project` | Text | `"[[项目笔记]]"` | 从任务/会议/来源链接到所属项目 |
| `area` | Text/List | `writing`、`learning` | 长期责任领域；确有回顾需要再使用 |
| `start` | Date | `2026-08-30` | 项目计划开始日 |
| `due` | Date | `2026-09-15` | 文件级截止日期；行内 Tasks 截止日有自己的语法 |
| `completed` | Date | `2026-09-10` | 完成日期；不是布尔值 |
| `priority` | Text | `low`、`normal`、`high` | 固定小词表；不要混用数字和文字 |
| `next_review` | Date | `2026-09-06` | 项目/领域下次回顾 |
| `owner` | Text | 人名或 `"[[人物笔记]]"` | 负责人；个人 Vault 可省略 |

## 属性中的内部链接

```yaml
related:
  - "[[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/双向链接]]"
  - "[[Obsidian知识/10-基础/02-链接与知识网络/原子笔记/局部图谱]]"
project: "[[Obsidian知识/30-实践/03-示例项目/周末读书会/00-周末读书会项目主页]]"
```

- 必须加引号，避免 YAML 把方括号解析成自己的数组语法。
- 属性链接适合机器筛选；正文链接带有解释上下文。重要关系可以两处都有，但不要为了“图谱更密”机械重复。

## Tags 的推荐分工

| 前缀 | 示例 | 何时使用 |
| --- | --- | --- |
| `playground/` | `playground/reference` | 教学区域或课程集合 |
| `topic/` | `topic/search` | 少量需要点击聚合的主题 |
| `status/` | `status/inbox` | 需要 Tags view 的流程状态；若已有 `status` 属性可只保留一种 |
| `source/` | `source/book` | 来源媒介确实用于筛选时 |

不要让 `topics: [search]`、`tags: [topic/search]`、文件夹 `Search/`、链接 `[[Search]]` 四者无差别重复。每种结构都应回答不同问题。

## 变更属性前的检查

1. 在 Properties view 查同名属性的现有类型和用法。
2. 用 Search 查询 `[property]`，估算影响范围。
3. 先在实验文件验证新的值域、模板和 Base 过滤。
4. 批量修改前建立 Git/文件备份；Sync 不是独立备份。
5. 修改后检查 Bases、Search、Dataview、Templates 和移动端显示。

## 常见错误

| 错误 | 后果 | 修正 |
| --- | --- | --- |
| `estimated_minutes: 15 分钟` | 变成文本，不能可靠数值比较 | `estimated_minutes: 15` |
| `fixture_reviewed: yes` | 可能被解释为文本而非 Checkbox | `fixture_reviewed: true` |
| `related: [[笔记]]` | YAML/链接解析可能异常 | `related: "[[笔记]]"` |
| 同一 `rating` 有 `4`、`4/5`、`good` | Bases 排序不一致 | 固定 Number 1–5 |
| `tags: topic one` | 空格不能构成一个标签 | `tags: [topic-one]` 或多行列表 |
| 嵌套对象 | 属性界面不能完整编辑 | 展平为多个属性或把复杂结构放正文 |
| 同时维护 `tag` 与 `tags` | 旧新属性并存 | 只保留 `tags`，必要时用 Format converter |
