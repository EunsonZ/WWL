# 01 · 匹配思维与最小单位

## 本课目标

理解正则引擎在文本中寻找什么，区分字面字符与元字符，并知道“找到一个片段”与“整个输入都符合规则”是两件不同的事。

## 正则描述的是一组字符串

表达式 `cat` 不只是三个字符的写法，它描述“连续出现 `c`、`a`、`t` 的位置”。在下面的文本中，它会命中两次：

```text
cat concatenate
```

第二次命中来自 `concatenate` 的中间。若需求是“只匹配独立单词 cat”，还需要边界；若需求是“整个输入必须等于 cat”，还需要完整字符串约束。

可以把一次匹配想成三个问题：

1. **从哪里开始尝试？** 搜索通常会从左到右寻找可行起点。
2. **每个模式单元消费什么？** 字面字符消费自己，字符类消费集合中的一个字符，量词让前一单元重复。
3. **什么时候算成功？** 模式全部满足时得到一次匹配；全局模式可能继续寻找下一次。

## 字面字符与元字符

大多数字母和数字按字面匹配。下面这些字符在模式中通常有特殊意义：

```text
. ^ $ * + ? { } [ ] \ | ( )
```

例如点号 `.` 通常表示“任意一个字符（默认不含换行）”：

```regex
c.t
```

它可以匹配 `cat`、`c7t` 和 `c t`。如果真的要匹配句点，需要转义：

```regex
\.
```

## 搜索、完整匹配与全部查找

如果你还没有运行环境，先用 [[编程知识/30-实践/01-正则表达式实验区/04-5分钟运行与测试模板|5 分钟运行与测试模板]] 在 Python 或 JavaScript 中二选一。下面的 API 名称可以边运行边认识，不需要先背下来。

不同 API 的默认行为不一样：

| 行为 | 含义 | 常见入口 |
| --- | --- | --- |
| 搜索一次 | 找到任意位置的第一个匹配 | Python `re.search`、JavaScript `RegExp.test`（不带 `g` / `y`） |
| 从开头匹配 | 只允许起点位于字符串开头 | Python `re.match`，或模式使用 `^` |
| 完整匹配 | 整个输入都必须被模式覆盖 | Python `re.fullmatch`，或显式使用完整边界 |
| 查找全部 | 返回所有不重叠匹配 | Python `re.findall` / `finditer`、JavaScript `matchAll` 配合 `g` 标志 |

同一个模式 `\d+`：

- 搜索 `item-42-ready` 会得到 `42`；
- 完整匹配 `item-42-ready` 会失败；
- 完整匹配 `42` 会成功。

所以“表达式看起来正确”仍不够，还要知道调用它的 API。

> [!warning] JavaScript 的有状态正则
> 带 `g` 或 `y` 的 `RegExp` 对象会更新 `lastIndex`。复用同一对象连续调用 `test()` 时可能一真一假；单值校验不要带 `g` / `y`，或在每次测试前明确重置状态。

> [!info]- 写进代码时再看：宿主字符串与双重转义
> 正则常被写在另一种语言的字符串里。此时可能同时存在两层语法：
>
> ```python
> pattern = r"\d+\.\d+"
> ```
>
> Python 原始字符串 `r"..."` 让反斜杠更接近正则原貌。普通字符串可能需要把一个反斜杠写成两个。JavaScript 正则字面量则可写为：
>
> ```javascript
> const pattern = /\d+\.\d+/;
> ```
>
> 复制表达式时，要分清你复制的是**正则本体**，还是已经为 JSON、Shell、Python 字符串等宿主语法转义过的文本。

## 可观察例子

目标：在一段文本中找到版本号形状，例如 `v2.14`。

```regex
v\d+\.\d+
```

| 输入 | 结果 | 原因 |
| --- | --- | --- |
| `release v2.14 ready` | `v2.14` | 搜索到完整片段 |
| `v2x14` | 不匹配 | 模式要求字面点号 |
| `vv2.14` | `v2.14` | 当前没有限制前一个字符 |
| `v2.14.1` | `v2.14` | 当前模式只描述两段数字 |

后两行提醒我们：先写清楚需求，再决定是否增加边界或更多分段。

## 练习

打开 [[编程知识/30-实践/01-正则表达式实验区/01-测试样本#A · 基础文本|测试样本 A]]，写一个表达式，找出所有形如 `ERR-` 后跟三位数字的片段。

要求：

1. `ERR-404` 应匹配；
2. `ERR-42` 不应匹配；
3. `WARN-404` 不应匹配；
4. 使用**全部查找**，并写出匹配数量；
5. 入门版暂时允许从 `ERR-1234` 截取 `ERR-123`，必须把这个缺口和实际结果写进备注。学完第 6 课后再回来完成严格版。

## 成功标准

- 我能说出 `.` 与 `\.` 的区别。
- 我能说明使用的是搜索、完整匹配还是全部查找。
- 我能解释为什么同一表达式放进不同语言字符串后，反斜杠数量可能变化。
- 我的练习至少包含一个正例、一个反例和一个已知边界。
