# 部署反馈复算：重训稳定与部署风险

主解释见[[AI/65-可信AI与真实数据实践/04-区间代价分组失败与发布漂移#部署改变分布时的重训与风险|同一两点分布]]。全部计算都是已声明合成机制的精确总体量，不运行真实模型、网络部署或有限样本训练；标准库即可，程序只读同目录输入并向标准输出报告。

## 输入、运行与预期

[deployment_inputs.json](deployment_inputs.json) 指定起点0、十次重训和不随部署反应的控制分布均值1/4、噪声幅度1/10。反应机制固定为正文的 $Z_\theta=\theta/2+1/4+\theta U$，$U=\pm1$ 各半概率，允许参数区间 $[0,1/2]$。到本目录运行：

```bash
python3 -B deployment.py
python3 -B deployment.py | python3 -B verify_deployment.py
```

[deployment.py](deployment.py) 输出0至10步共11个值、稳定点、风险最优点、两风险以及固定分布对照。[verify_deployment.py](verify_deployment.py) 不导入计算实现，直接枚举两个可能结果：核各次均值重训、闭式序列、支持区间和风险；在0、1/4、1/2三点的风险恢复二次系数，核正曲率、区间内最优点及风险。有限点恢复系数利用本模型已知是二次函数；一般函数不能据三点宣称全局最优。

预期结果：十步后 `1023/2048`；稳定点 `1/2`、风险 `1/4`；风险最优点 `1/10`、风险 `1/20`；从最优点再冻结分布重训得 `3/10`。不响应的分布结果 `3/20,7/20` 下，稳定点和风险最优点均 `1/4`、风险 `1/100`。

oracle针对本页固定输入。改变起点、步数或控制分布时，应先独立写出新预期再调整对应核对；不要为了通过把计算输出抄为答案。非作者需另核“固定当前分布”和“改变部署分布”的对象区别，以及机制是给定而非已识别。程序通过不能替代该独立语义审阅，也不认证福利目标、真实部署、客户端显示或学习效果。执行结果按实际运行另记，不能以文件存在代替已运行。
