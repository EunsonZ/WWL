## 字符串算法保存的是“未来仍有用的过去”

暴力匹配失败后重新检查大量已知字符，是因为没有摘要化过去。KMP 的状态 j 表示：已消费文本的后缀中，能够匹配模式前缀的最长长度。失败时不是忘掉全部过去，而是寻找下一长的候选前缀。

模式的前缀函数 $\pi[i]$ 是子串 `pattern[0:i+1]` 的最长真前缀与后缀的共同长度。“真”表示不能取整串本身。它是边界长度，不是字符下标，也不是任意位置出现过的最长重复子串。自动机视角与 Princeton 的 KMP 实现对应，但本课采用前缀函数表示而非完整字符转移矩阵。[^kmp]

## 把 ababaca 的每一步算清楚

模式 `ababaca` 的前缀函数为 `[0,0,1,2,3,0,1]`。到 i=4 的 `ababa`，最长边界为 `aba`，长度 3。接着字符 c 到来，先尝试让这个边界继续增长，需要比较 `pattern[3]='b'` 与 c，失败。

下一候选不是长度 2，而是已知边界 `aba` 的最长真边界，长度 `pi[2]=1`。再比较 `pattern[1]='b'` 与 c，仍失败；退到 0，比较 a 与 c，失败，因此该位置为 0。

为什么不尝试长度 2？因为当前匹配后缀的任何更短可行边界，必须同时是当前最长边界的边界。长度 2 的 `ab` 不是 `aba` 的后缀，已被结构信息排除。跳跃不是碰运气，而是排除了不可能状态。

```python
def prefix_function(pattern: str) -> list[int]:
    pi = [0] * len(pattern)
    for i in range(1, len(pattern)):
        j = pi[i - 1]
        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j
    return pi
```

匹配文本时 j 同样沿 pi 回退，文本位置不倒退。每次成功扩展 j 最多加 1，回退总量受先前扩展限制，所以整个扫描线性。这里是摊还分析，不是宣称 while 永远执行一次。空模式要单独定义，例如匹配所有 n+1 个字符间隙，不能在代码里访问 pattern[0]。

## 匹配完成后不要丢掉重叠答案

用模式 `aaa` 匹配 `aaaaa`，答案从 0、1、2 开始。每次 j 达到模式长度后，应记录答案并回退到 `pi[j-1]`，保留可能的重叠前缀；若直接重置到 0，就漏掉重叠位置。

字符单位也要明确。Python str 按 Unicode 码点索引，不等同于用户感知的字素簇；UTF-8 字节序列的下标更不等同于码点下标。大小写折叠或 Unicode 规范化可能改变长度，搜索结果映射回原文需要单独维护位置关系。

## 后缀数组把全体后缀变成有序索引

对 `banana`，排序后的后缀依次为 `a`、`ana`、`anana`、`banana`、`na`、`nana`，所以后缀数组为 `[5,3,1,0,4,2]`。令 `h[r]` 为排序位置 r 与 r-1 的后缀的最长公共前缀，且 h[0]=0，得到 `[0,1,3,0,0,2]`。[^suffix]

若两个后缀的排序位置为 l<r，它们的 LCP 等于 `min(h[l+1:r+1])`。直觉是：字典序中夹在它们之间的字符串必须共享同一公共前缀；链中最短的相邻公共前缀限制两端。于是字符串比较可转成 [[计算机知识/50-数据结构与算法/10-数据结构系统课程/09-懒标记的代数与完整实现|区间最小值摘要]]，但不要使用求和线段树而不修改合并运算。

不同非空子串总数为

$$
\frac{n(n+1)}2-\sum_{r=1}^{n-1}h[r].
$$

每个后缀贡献它的全部非空前缀，已被前一个排序后缀覆盖的前 h[r] 个前缀不再计数。banana 有 21 个按位置计数的子串，减去 6 个重复贡献，得到 15 个不同子串。本轮用集合枚举作为小输入基准验证这个计数，不依赖“看起来像 15”。

直接构造所有后缀再排序可用于小实验，但 Python 切片复制和长串比较使它不是高效后缀数组实现。倍增法按 `(rank[i],rank[i+k])` 重排，每轮 k 加倍；排序策略不同，复杂度可能为 $O(n\log^2 n)$ 或使用计数排序达到 $O(n\log n)$。Kasai 的线性 LCP 构造又需要自己的摊还证明，不能把所有版本统称为线性。

## 多模式与子串索引：两个容易混淆的自动机

Aho–Corasick 把多个模式放入 trie，失败边指向可继续尝试的后缀状态；输出还须包含沿失败链继承的模式。复杂度要计算真实报告的匹配数量，文本很短也可能匹配大量模式。后缀自动机则把子串按 endpos 等价类组织，link 连向更短的等价类，状态记录最长长度，并以 `len[v]-len[link[v]]` 计数该状态代表的不同子串长度。两者都画成有向图，但状态含义完全不同。

本课深入到 KMP 与后缀数组的完整可复算路径。Aho–Corasick、后缀自动机、后缀树、Z 函数、BWT/FM-index 的实现细节继续由原字符串专题承接；本轮没有把这些算法全部宣称为已实现和已验证。

滚动哈希是另一种摘要：相同哈希不能无条件推出相同字符串。双哈希降低特定随机模型下的碰撞风险，不把概率结果变成确定证明；对抗性输入和种子暴露又改变模型，关联 [[计算机知识/50-数据结构与算法/20-算法设计系统课程/11-归约方向随机误差与近似保证|概率保证的量词]]。

**自测**：banana 中后缀 1 的 `anana` 与后缀 3 的 `ana`，排名分别 2 与 1，LCP 是 h[2]=3。若查后缀 0 与 2，排名 3 与 5，区间最小值为 min(0,2)=0，与首字符 b/n 不同一致。
