# 核心插件目录

核心插件随 Obsidian 安装，由 Obsidian 官方构建和支持，可在 **Settings → Core plugins** 中按 Vault 开关。它们不是社区插件，不需要关闭 Restricted mode。

> [!important] 三个边界
> **Sync** 与 **Publish** 是连接官方付费服务的核心插件；关闭插件不等于取消订阅。**Importer** 与 **Maps** 由 Obsidian 官方维护，但经社区插件商店分发，仍运行第三方插件包。**Web Clipper** 是官方浏览器扩展，不是 Vault 内核心插件。

## 建议先开启的基础组

| 核心插件 | 解决什么 | Playground 练习 | 桌面/移动端 |
| --- | --- | --- | --- |
| File explorer | 浏览、创建、移动、重命名文件与文件夹 | 在实验区创建、移动一篇笔记 | 两端都有；移动端从侧栏进入，长按代替右键 |
| Command palette | 用模糊搜索执行任何已注册命令 | `Cmd/Ctrl + P` 搜索“backlinks” | 桌面键盘最强；移动端下拉 Quick Action 默认打开它 |
| Quick switcher | 按文件名/别名打开或创建笔记 | `Cmd/Ctrl + O` 在两篇笔记间切换 | 移动端未编辑时点底部中央加号 |
| Search | 全文、路径、标签、任务、属性和正则检索 | 完成 [[Obsidian知识/90-资源/02-参考/02-搜索语法速查表\|02-搜索语法速查表]] 中三个查询 | 桌面 `Cmd/Ctrl + Shift + F`；移动端从侧栏/命令打开 |
| Backlinks | 查看谁链接到当前笔记以及未链接提及 | 创建链接后到目标页观察 Linked mentions | 两端都有；移动端通常在侧栏下拉中 |
| Outgoing links | 查看当前笔记链接到哪里 | 检查断链和未解析链接 | 两端都有 |
| Page preview | 悬停/长按预览内部链接 | 不离开当前页预览来源笔记 | 桌面常用 `Cmd/Ctrl` + 悬停；移动端使用触控菜单/预览 |
| Properties view | 查看当前/全 Vault 属性和类型 | 找出 `status` 的所有使用 | 两端都有；窄屏时在侧栏操作 |
| Tags view | 显示标签与嵌套标签 | 展开 `playground/` | 两端都有 |
| Outline | 根据标题显示当前笔记结构 | 点击标题跳转到小节 | 两端都有 |
| Bookmarks | 收藏文件、文件夹、搜索、标题、块和 URL | 收藏“未完成练习”搜索 | 两端都有；不是复制内容 |
| Word count | 显示当前笔记字数/字符数 | 比较来源摘录与自己的摘要 | 桌面在状态栏更直观；移动端界面位置不同 |
| File recovery | 保存本机 Markdown/Canvas 快照并恢复 | 只观察设置和恢复界面，不故意清空历史 | 两端都有；快照设备本地、不是完整备份 |

## 写作与重构组

| 核心插件 | 解决什么 | 适用时机 | 重要边界 |
| --- | --- | --- | --- |
| Templates | 插入预定义文本、`{{title}}`、日期和时间 | 日记、来源、会议、项目结构稳定后 | 不执行复杂逻辑；动态脚本属于 Templater 等社区插件 |
| Slash commands | 在编辑器输入 `/` 搜索命令 | 触屏或不想离开光标时 | 与 Command palette 是不同入口；可关闭 |
| Footnotes view | 汇总当前笔记脚注 | 长文、研究和来源笔记 | 脚注正文仍在 Markdown 文件中 |
| Note composer | 合并两篇笔记或把选区提取为新笔记 | 拆分过长笔记、合并重复概念 | 操作会改文件与链接；先在实验区试用 |
| Format converter | 把其他 Markdown 风格转换为 Obsidian 格式 | 导入旧 Vault 或清理旧 frontmatter | 可能批量改写；先备份并抽样验证 |
| Unique note creator | 用时间编码创建唯一笔记 | Zettelkasten/快速原子记录 | 时间戳标题不是必需方法，不要与 Daily Notes 混淆 |
| Random note | 随机打开一篇笔记 | 轻量回顾、偶遇旧笔记 | 随机不等于有计划的复习系统 |
| Audio recorder | 录音并保存到 Vault | 移动采集、访谈草稿 | 关注权限、附件体积、隐私与备份 |

## 时间与工作区组

| 核心插件 | 解决什么 | Playground 练习 | 桌面/移动端 |
| --- | --- | --- | --- |
| Daily notes | 按日期创建/打开普通 Markdown 笔记 | 用模板创建今天的日记 | 两端都有；可加入移动 Quick Action |
| Workspaces | 保存并切换标签页/侧栏布局 | 保存“学习”“写作”两个布局 | 桌面价值最高；移动布局应独立验证，不假定完全相同 |
| Slides | 从 Markdown 分隔段落制作演示 | 把一篇短教程变成 3 页幻灯片 | 制作和演示更适合桌面；移动端以实际命令为准 |

## 连接、数据与可视化组

| 核心插件 | 解决什么 | Playground 练习 | 重要边界 |
| --- | --- | --- | --- |
| Graph view | 自动显示内部链接形成的全局/局部网络 | 先看 Local Graph，再过滤 Global Graph | 节点多不代表知识质量高；线来自真实链接 |
| Canvas | 在二维无限空间中人工排列笔记、附件、网页与卡片 | 画“收集→整理→回顾”流程 | 纯文本卡片不产生 Backlinks，转成文件后才参与网络 |
| Bases | 根据文件属性提供表格、列表、卡片、地图等视图 | 建“课程清单”并过滤 `status` | 数据仍在 Markdown 属性中；不是把笔记搬进数据库 |

## 导入、浏览与发布组

| 核心插件/入口 | 分类 | 解决什么 | 费用与安全边界 |
| --- | --- | --- | --- |
| Web viewer | 免费核心插件 | 在 Obsidian 标签页打开网页、收藏链接 | 网页仍来自互联网；不要把登录状态或不可信网页等同于本地笔记 |
| Sync | 核心插件 + 官方付费服务 | 跨设备同步 Vault、配置和历史 | 订阅服务；同步不是独立备份，删除/错误修改也会传播 |
| Publish | 核心插件 + 官方付费服务 | 把选择的笔记发布为网站 | 订阅服务；发布前检查隐私、嵌入和插件生成内容 |
| Importer | 官方维护的商店插件 | 从 Notion、Evernote、OneNote 等导入 | 免费开源但仍是商店插件；批量写入前备份 |
| Maps | 官方维护的商店插件 | 为 Bases 增加地图视图 | 从商店安装；需要位置数据和地图资源时检查隐私/网络 |
| Web Clipper | 官方浏览器扩展 | 从网页高亮、套模板并保存到 Vault | 不是核心插件；浏览器权限与模板内容单独评估 |

以下状态来自 WorkWithLLM 的 `.obsidian/core-plugins.json` 历史快照；它不描述 WWL。用户可在各自 Vault 的 Settings 中自行开关，未来版本也可能改变可用插件。

| 已启用 | 当前未启用 |
| --- | --- |
| File explorer、Search、Quick switcher、Graph view、Backlinks、Canvas、Outgoing links、Tags view、Footnotes view、Properties view、Page preview、Daily notes、Templates、Note composer、Command palette、Slash commands、Editor status、Bookmarks、Unique note creator、Random note、Outline、Word count、Slides、Workspaces、File recovery、Bases、Web viewer | Format converter、Audio recorder、Publish、Sync |

> [!note] 未启用不等于“不支持”
> Playground 可在课程需要时让用户手动开启；不要为了展示目录而一次性开启全部插件。

## 核心插件选择口诀

```text
动作不知在哪 → Command palette
标题已经知道 → Quick switcher
只记得正文/条件 → Search
想看谁提到我 → Backlinks
想看我指向谁 → Outgoing links
想按属性整理 → Bases
想自由排布思路 → Canvas
想观察真实链接 → Local Graph
每天一个入口 → Daily notes
固定结构复用 → Templates
误删/误改应急 → File recovery，然后仍要查独立备份
```

## 常见误解

- 核心插件是内置功能，不是每个都必须开启。
- Graph 自动依据内部链接；Canvas 连接线由用户手工表达，两者不是同一数据。
- Templates 插入内容；它不会像 Templater 一样任意执行 JavaScript 或系统命令。
- Bases 是视图层，源数据仍是文件与属性。
- File Recovery 是有限、本机、按设备的快照，不是完整备份。
- Sync 和 Publish 是付费服务入口，不属于社区插件；开关与订阅状态不是一回事。
- 官方维护的 Importer/Maps 在商店分发，安装它们仍需要社区插件机制。
