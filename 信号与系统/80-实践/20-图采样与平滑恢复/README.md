# 图采样与平滑恢复：同输入、不同信息责任

六个节点、三个读数，为什么有时能恢复、有时无噪声仍错？先从[[信号与系统/60-空间与方向信号/02-图信号频谱采样与稳定恢复|硬带限课]]预测rank/最小增益与别名，再从[[信号与系统/60-空间与方向信号/03-图平滑正则恢复与迭代证书|平滑课]]预测唯一性、偏差与停止条件。这里实际执行固定小图的实现核查；一般定理在主课证明，不能用20个采样集替代一般量词。

## 固定合同与可检查输入

规范源码：[graph_sampling_lab.py](graph_sampling_lab.py)；[固定输入](inputs.json)和[全部结果](results/results.json)均为UTF-8 JSON。程序无随机数、无需下载数据，不把采样电压训练成最有利的图；默认不读外部输入，而从源码具名常量复建同一夹具。节点按0…5排列，全部权/图算子/μ/α无量纲，x/y/噪声单位V。它是经统一单位标定的**合成电压**，边表示给定相似/平滑偏好，没有被声明为真实电导、传播时延或人体连接。

主输入为无权六环，$L=D-W,H=I-L/4$。H每节点输出自身1/2加两个相邻节点各1/4；完整谱为0,1,1,3,3,4，硬低带包含λ≤1的全部三维空间。真值 $x_B=(3,3,2,1,1,2)$ V，$Hx_B=(2.75,2.75,2,1.25,1.25,2)$ V。全节点预置扰动为(.01,−.02,.015,0,.005,−.01) V；均匀Ω={0,2,4}和簇状Ω={0,1,2}各取其对应位置，均是**滤波/采样后**加扰动。两个集合看到同一固定全节点记录，却有不同的噪声子向量范数；比较最坏稳定性使用最小增益，不把两份实际误差差距全归因于采样几何。

另外三组具名变条件不混入上述准确带限输入：

- 在同一x_B上另加λ3尾 $.3\cos(2\pi j/3)$ V，无噪声，检验带外别名；另取最高模式检验H零方向。反例不是给新算法重新调参的训练集。
- 连通四节点边{01,02,12,23}、完整λ≤1低带，Ω={0,1}；它保持m=K、连通、带内h非0，B仍秩1。双三角形只观第一分量另检验分量常数缺测。零读数六环Ω={0,3}、真值u_s检验“唯一优化解”与“可辨真值”分离。
- 全节点平滑使用均匀组三个带扰动读数，固定μ=.1；μ列表[.0001,.001,.01,.1,1,10]全部公开，不根据真图误差挑参数。错图只改w01为1.01，H′与A′一起变，同y下比较两个极小点。簇状组的系数岭α列表[0,.01,.1,1]同样全部保留；没有宣布加入岭一定更准。

基内旋转、完整节点重编号、固定前向时L乘7/μ除7均核同一问题的不变性。图变更若也改H，就不能只补μ。源码用边循环实现L/H/前向/伴随，另构矩阵对照；LS用SVD，不以满秩正规方程自证稳定。

## 每个断言的证据责任

预设矩阵容差5e−12、数值2e−10、界容差2e−9、rank阈值1e−10、LS rcond1e−12、GD停止证书1e−10 V；在首次运行前已写入规范源，失败将非零退出。浮点rank是固定尺度下的数值判断，不能认证任意近零边精确消失。下列“独立预期”由手算模式/一般公式给出，非作者另用有理消元等路线复核，不靠调用源码生成期望；复生和显示层在交接中分别列明。

| 具体断言 | 重要性与理由 | 独立预期、失败条件 | 实际结果所在 |
| --- | --- | --- | --- |
| 完整带限rank、Err、核交Unique、GD/Stop与Model | 高：决定结论适用的对象和量词 | 主课一般证明交非作者逐链核；有限PASS不能替代；少条件须撤回结论 | 主课02/03与十题答案 |
| L/H/前向与伴随的节点顺序 | 中：转置或混合顺序错会直接改读数 | 手算Hx_B及一次相邻差；矩阵/边循环和内积对照误差≤5e−12 | l/h/hx、band两组与断言 |
| 整个重根空间与采样最小增益 | 高：薄SVD/任意截半会误报可辨 | 均匀Gram diag(1/2,9/32,9/32)，簇状谱9/32及(25±√561)/64；20组三点最优恰两交错组；值误差≤2e−10 | design、band、cut_repeated_ranks |

| 输入拒绝 | 中：防止静默接受别的对象 | 负/非有限/重复/自环边、非法节点/样本、μ0、y错shape、不可辨LS/不唯一smooth共13分支均ValueError | rejected |
| 真实图/混合校准与独立真值 | 高：L/H错了上述预算无从取得 | 下节给字段/观察/预留接口，本包未执行，不从合成PASS填写已验 | 外部验证接口 |

## 外部验证接口：当前没有真实测量

将此图模型接到现实对象前，先冻结下面输入与观察协议。重要性高，因为“图上相似”及H的混合顺序均可能错；合成电压不能更名充当脑电、交通或器件数据。

1. `nodes.csv`固定node_id、物理对象/位置（如适用）、value_unit、读出增益/零偏及不确定度。`measurements.csv`保留node_id、timestamp、value、unit、saturation、同步/缺失标志；同一快照不能把不同时刻值当同时读数。节点编号与采样顺序需显式对应。
2. `edges.csv`保留端点、weight、边含义/单位、构建规则与版本。若从数据学图，只用预先声明训练数据；不得看最终test真值/标签或以最小恢复误差反选图。确定是否确为非负无向对象；有向/符号关系须另立理论，不偷偷对称化后声称同一物理对象。
3. H须有独立校准：若系统允许已知节点激励，逐输入取得全读出/参考通道，估每列响应及偏差、延时与线性范围；否则给能够识别H的其他独立实验。检验实际响应是否符合I−L/4，报告测量不确定度与不能覆盖的输入方向。由同一欠采样y同时挑L/H/x一般无法自动分离这些未知量。
4. 先按应用规格固定Ω、β或μ与噪声/尾预算，在独立对象或时段保留全节点参考（含仪器不确定度）后盲评。分别报告样本拟合、全节点误差、带外尾、图能量和求解证书；预算ε/δ/ΔA/ΔL应有校准/独立数据依据，不能从本算法输出单独宣布。若图来自同一群体或相邻时刻，划分按对象/时间组，防止样本共享造成泄漏。
5. 一个待采用工程合同可要求全节点范数误差≤0.1 V、参考不确定度≤0.01 V；这两个值是示例规格，不是已完成性能。未过时先区分同步/标定、图先验、带外尾和优化误差；若应用值是°C或车辆数，全部单位和损失权重须重写。没有相应硬件/记录，本包此层仍为未执行，真人迁移与Obsidian客户端显示也未认证。

回两主课独立完成十道迁移题，再看完整答案；改变边权、采样、H零点或μ时，须先指出是哪条条件变了。完整一般线性采样/二次图平滑代表主线已经可连续学习；其他S13雷达、声纳、生医、音视频等方向以及更广图模型独立保留，不由此实践一并完成。
