# HMM：前向、后向与 Viterbi

观察同一句话后，三种问题仍然不同：句子有多大概率；某位置最可能是什么词性；整条词性路径哪条最可能。HMM（隐马尔可夫模型）给出词性与词的联合生成模型，再从它做三种推断。本课用原创的 `fish fish fish` 重复歧义词例，参数人为指定，服务计算而不代表真实英语词性统计。

## 联合生成模型及它的条件

词为 $x_{1:T}$，词性状态为 $y_{1:T}\in\{N,V\}^T$。初始分布 $\pi$ shape 为 $K$，转移 $A$ 为 $K\times K$，行是前状态、列是后状态；发射表 $B$ 为 $K\times |Vocab|$。所有数都是无单位的概率，每行非负且和为 1。

\[
P(x,y)=\pi_{y_1}B_{y_1}(x_1)\prod_{t=2}^T A_{y_{t-1},y_t}B_{y_t}(x_t).
\]

这要求一阶状态 Markov 假设，以及给定状态后每个观测仅由当前位置状态发射。模型先生成标签，再发射词；不意味着语言中词性实际“因果地产生”词。本例**固定长度 T**，没有 EOS 转移，避免将终止概率偷偷漏入递推。

| 参数 | N | V |
| --- | ---: | ---: |
| 初始 π | .2 | .8 |
| 前 N 的转移行 | .2 | .8 |
| 前 V 的转移行 | .4 | .6 |
| 发射 fish | .6 | .4 |
| 发射 swim | .4 | .6 |

最后两行是两个观测的列展示：N 的发射行是 `(fish=.6, swim=.4)`，V 的是 `(.4,.6)`。每个词都可取 N 或 V；三词有 $2^3=8$ 条路径。

## 前向求和：把所有原因算进句子概率

定义 $\alpha_t(j)=P(x_{1:t},y_t=j)$。初值 $\alpha_1(j)=\pi_j B_j(x_1)$；递推与终值为

\[
\alpha_t(j)=B_j(x_t)\sum_i\alpha_{t-1}(i)A_{ij},\qquad
P(x)=\sum_j\alpha_T(j).
\]

求和来自互斥的前状态事件划分。例如第二格 N：$(.12\times.2+.32\times.4)\times.6=.0912$。

| t / 词 | α(N) | α(V) | 列和 P(x前缀) |
| --- | ---: | ---: | ---: |
| 1 / fish | .12 | .32 | .44 |
| 2 / fish | .0912 | .1152 | .2064 |
| 3 / fish | .038592 | .056832 | .095424 |

这不是最佳路径的概率。完整穷举核对：

| 路径 | 联合概率 P(x,y) |
| --- | ---: |
| NNN | .001728 |
| NNV | .004608 |
| NVN | .009216 |
| NVV | .009216 |
| VNN | .009216 |
| VNV | .024576 |
| VVN | .018432 |
| VVV | .018432 |

八项总和 .095424，最大项 .024576。表内多个完全相同的小数是本例参数的性质，不是舍入后随意认定并列。

## 后向与后验：当前位置要同时听取过去和未来

定义 $\beta_t(i)=P(x_{t+1:T}\mid y_t=i)$，空后缀令 $\beta_T(i)=1$。向左递推：

\[
\beta_t(i)=\sum_j A_{ij}B_j(x_{t+1})\beta_{t+1}(j),\qquad
\gamma_t(j)=P(y_t=j\mid x)=\frac{\alpha_t(j)\beta_t(j)}{P(x)}.
\]

| t | β(N) | β(V) | γ(N) | γ(V) |
| --- | ---: | ---: | ---: | ---: |
| 1 | .2064 | .2208 | .259557 | .740443 |
| 2 | .44 | .48 | .420523 | .579477 |
| 3 | 1 | 1 | .404427 | .595573 |

各位置的 $\alpha\beta$ 和都应回到 .095424；各后验行和为 1。只把前向当前列除以列和，得到的是过滤 $P(y_t\mid x_{1:t})$，没有使用未来词，不能冒充整句后验。比如第 2 位过滤 N 为 `.0912/.2064≈.44186`，整句后验 N 则约 .420523。

## Viterbi 最大值与回溯：保留整条路径的兼容性

$\delta_t(j)$ 是以 j 结尾的前缀**最大联合概率**，递推将 sum 改为 max：

\[
\delta_t(j)=B_j(x_t)\max_i\delta_{t-1}(i)A_{ij},\quad
\psi_t(j)=\arg\max_i\delta_{t-1}(i)A_{ij}.
\]

| t | δ(N) | ψ(N) | δ(V) | ψ(V) |
| --- | ---: | --- | ---: | --- |
| 1 | .12 | 初始 | .32 | 初始 |
| 2 | .0768 | V | .0768 | V |
| 3 | .018432 | V | .024576 | N |

终点选 V；看第 3 格 V 的指针，前一格是 N；再看第 2 格 N 的指针，第一格是 V。回溯得到 `V N V`，其条件路径概率 `.024576/.095424≈.257545`。不能直接在每个 δ 列选最大值：本例第 2 列并列时随手选 V 就可能失去正确前缀。

逐位置后验最大却是 `V V V`。它在各位置的 0–1 标签损失下分别最优（本例无相等最大值），但联合路径概率 `.018432` 小于 `V N V`。路径 MAP 优化整条链 0–1 损失；边缘决策优化标签错误数期望。若存在禁用转移，分别取边缘最大还可能组成非法路径；需要受约束决策而非声称两个 argmax 相同。

## 数值、训练与模型边界

实现对零概率用 $-\infty$，乘法变加法，求和用 log-sum-exp。长序列的 log 概率仍可表示，即使将它取 exp 后下溢为 0。若全部路径概率为 0，则 $P(x)=0$，后验分母为 0：代码返回 `logZ=-inf`，后验与路径 `None`，不伪造均匀后验。空序列在固定长度约定下只有空路径，概率 1；未知词报错，调用者须先提供映射或平滑。参数必须校验行归一、shape 与有限性。

本课的 $\pi,A,B$ 是为手算指定的；下一步只换参数来源，不换 Viterbi 要回答的问题：给定一串词，找联合概率最高的整条标签路径。有带 POS 的训练语料时，可以从带标签的序列数初始标签、相邻标签和标签内词频，再按各自目标空间平滑；无标签时，若用 EM/Baum–Welch 估计参数，还需要后验与参数更新。本课计算后验，没有实现参数训练，不能把一次 forward/backward 称为已训练 HMM。真实语料路线先固定输入身份、投影与切分，再从 train 估计这些量，最后仍对句子逐条运行 Viterbi：[[AI/35-传统NLP/10-真实语料序列标注/01-固定语料投影与切分|固定语料与边界]] → [[AI/35-传统NLP/10-真实语料序列标注/02-监督HMM训练与解码|训练计数与解码]]。时间 $O(TK^2)$；存全表与回溯为 $O(TK)$。

与 [[AI/40-语音与音频模型/03-CTC路径求和流式延迟与语音评测#动态规划如何避免枚举指数多路径|CTC 前向表]] 比较时，只复用隐藏路径求和的思想：CTC 折叠重复/blank 的对齐规则、输出长度和允许跳转与本课逐词发射模型不同，参数含义也不同。

## 跟算练习与答案

1. 第 3 格 α(V) 怎么算？答案：`(.0912×.8+.1152×.6)×.4=.056832`。
2. 第 2 格后验 N 的分子是多少？答案：`.0912×.44=.040128`，除以 .095424 得 .420523。
3. 前向总概率能小于最大联合路径概率吗？答案：不能，前者为非负路径概率之和，必须至少与最大项一样大；若发生，多半是转移、终值或取 log 的口径错了。
4. 参数给 `fish` 在所有状态发射概率 0，后验是什么？答案：不定义；不能除以 0，也不能把 Viterbi 默认指针当有效路径。
