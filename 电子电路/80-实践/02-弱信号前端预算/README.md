# U4：弱信号前端的第一份预算

1 mV信号如何经偏置、噪声、带宽、摆幅和采样建立可靠数字化？本实验把同一条链的限制放进可复算账本。它认证明示教学模型内的预算，不宣称真实硬件合格。

基础入口：先读 [[电子电路/40-反馈噪声与混合信号/03-ADC驱动建立与弱信号预算#一份失败规格与可行重设计|失败规格与重设计]]，手算半LSB和RC残差再运行。快进入口：先核对下表的SI单位、PSD单边及源独立假设，读源码中的 `evaluate`；两入口最终都比较同一份 `budget-results.json` 的good/bad/transfer。

## 固定参数与复算范围

| 项目 | 成功教学预算 |
|---|---|
| 输入 | 共同基准1.65 V，信号峰值1 mV/1 kHz，源电阻2 kΩ，300 K |
| 级1/级2非反相增益与噪声增益 | 20/10；A0各10⁶；GBW各20 MHz；正弦SR各1 V/μs |
| 噪声电压ASD、输入电流ASD（每个输入） | 级1：8 nV/√Hz、0.3 pA/√Hz；级2：12 nV/√Hz、0.5 pA/√Hz |
| 电压噪声1/f拐角 | 20/10 Hz；其他白项不误乘同样拐角 |
| 源/反馈电阻等效 | 级1 Rs2 kΩ、Rf∥Rg1 kΩ；级2前驱Rs100 Ω、Rf∥Rg2 kΩ |
| 可实现电阻比（理想名义） | 级1 Rg≈1052.632 Ω、Rf=20 kΩ；级2 Rg≈2222.222 Ω、Rf=20 kΩ。实际比值容差需另预算 |
| DC界 | 纯源/基准差10 μV；纯Vos1/2=5/10 μV；参考差1/5 μV；四端DC Ib界默认各0 A，有限A中心移动另算 |
| 抗混叠 | 指定稳定四阶Butterworth5 kHz；100 kS/s；99 kHz/0.1 V峰值滤波器输入干扰 |
| 采集 | 16位/3.3 V；5 μs窗口；200 Ω及等效20 pF；驱动极点20 MHz、SR10 V/μs |
| 附加RMS | 滤波器/驱动ADC端合成30 μV；ADC端合成20 μV；均独立，来自教学预算分配，不是数据手册实测 |
| 积分 | 模拟单边0.1 Hz–1 MHz；两级教学模型频响与滤波器；上尾有保守解析界 |
| 门槛 | 输入等效2 μVrms，DC界20 μV，幅度误差1%，输出/共模0.5–2.8 V，采集半LSB，指定混叠单音5 μV峰值 |

这是工作规格与教学参数，不是采购清单。`sensor_dc`是纯源/基准DC差，`vos1/2`为纯失调，不包含偏置电流。两级两输入DC电流的绝对界由新增 `ibplus1/ibminus1/ibplus2/ibminus2` 给定，A为单位，默认全为0；实际器件不能沿用这一零电流假设。非反相端贡献 Ibplus×Rs（级2用r2），反相端贡献 Ibminus×(Rf∥Rg)，二者分别加到各级输入等效绝对DC界。一级10 nA反相电流、Req1=1 kΩ就额外增加约9.99970 μV全链输入等效DC，原18.40696 μV变为28.40666 μV，超过20 μV。偏置电流不是0.3 pA/√Hz的随机ASD；匹配抵消需要有符号电流/失配证据，本模型保守相加。每级两个输入电流噪声、源与反馈电阻噪声均进入各自端口；任何真实相关噪声须替换独立假设。

## 只在库外运行

复制本目录到新的可写位置，保证输入源码版本一致。已有主库.venv包含本批所需numpy/matplotlib/CairoSVG；不自动安装。两个生成程序都要求显式输出路径，导入与测试不写生成资产。`plot_frontend_budget.generate(output)` 在调用时才加载绘图库并设置图参数；导入时不修改调用者的 rcParams，也不初始化 matplotlib 缓存。CLI 的 `main(argv=None)` 接受明确参数；缺少 `--output` 时退出码为 2。

```bash
python -B -m unittest discover -s . -p test_frontend_budget.py -v
python -B frontend_budget.py --output /private/tmp/u4-my-run
python -B plot_frontend_budget.py --output /private/tmp/u4-my-run
```

自行选择库外输出位置，不把上例视为允许覆盖已存在目录。若没有绘图库，CPU预算的stdlib计算仍可运行，图层记未运行。

`frontend_budget.py`给参数、10项规格布尔栏和原始量，不只给总PASS。`noise_spectra`由不同注入端口进入ADC的传递平方生成PSD；`integrate_log`用log频率变量积分时明确Jacobian df=f dx，避免遗漏低频段与单位。4096与2048点收敛核对，高频尾部界未被删掉；低于0.1 Hz的随机漂移/偏置不是这次积分认证范围。

`loop_metrics`只对1–3个稳定实极点、无零点/延迟/隐状态的单环模型给裕度与Routh真值。返回null不是随便填0：无有限−180°交越的GM或未出现单位交越的PM都有明确语义。完整电路必须自己检查内部稳定。驱动死区加双极点模型只作为有明示定义的误判反例，不代替真实SAR开关网络。

## 输出与判读

![[电子电路/80-实践/02-弱信号前端预算/assets/frontend-chain.svg|425]]

成功链输入等效RMS约0.799767 μV，SNR58.93 dB，DC界18.40696 μV、输出1.446319–1.852988 V，所列10项模型门槛同时满足。失败链的正弦SR仍可通过，却在共模、窗口、DC、带宽、建立和指定干扰上失败；某一栏通过不会填补另一栏。

`noise-integral.svg`和CSV展示谱与累计积分；`settling-swing.svg`显示以半LSB为单位的采集残差和确定性输出包络。SVG是可编辑真图；425PNG实际从SVG经CairoSVG渲染，检查的就是正文所用SVG画布，不拿另一张Matplotlib PNG替代。

陌生条件迁移及多解评分在 [[电子电路/40-反馈噪声与混合信号/03-ADC驱动建立与弱信号预算#陌生条件迁移与等价评分|共同迁移题]]；先独立预测再看结果字典。可行重设计包含延长采集时间到2 μs，也需保留真实ADC转换/调度未知。

## 证据与生产责任

源码与测试/画图三个真源及 [[电子电路/80-实践/02-弱信号前端预算/04-预算源码与验证|三个逐字code-sync镜像]] 是一个交付单元。SNR预算要求严格正的信号峰值，peak=0在validate明确拒绝，不把log10偶发异常当参数校验。作者行为测试含偏置电流端口独立反例、零幅度显式拒绝、解析积分、独立特征根、独立RK4建立、相关交叉项、SI尺度、失败规格及非法输入；独立审阅后才可发布，不把作者自检当独审。

现实验证应由设计人员把电阻/参考/运放/滤波器/ADC具体型号和保证条件填回预算，重验工差、温度PVT、失配、时钟抖动、INL/DNL、1/f测量带宽、相关源和内部稳定；按电源/负载条件分别测偏置、幅相、输入短接噪声、带外干扰注入、全量程跨通道采集/周期恢复与饱和恢复。SPICE模型参数覆盖、PCB布线、电荷库/探头加载、仪器校准及批次/环境测试需独立证据。本批实际只有CPU教学复算与图，不具备这些硬件层证据。
