# 哲学与文化

这里是与数学、AI、计算机知识和编程知识并列的独立知识域，用来整理哲学问题、文化比较、政治思想与制度分析。内容按“问题—论证—证据—反例”的结构组织，保留争议、反例、证据状态与来源入口，避免把一条连续论证切成失去语境的碎片。

## 从这里开始

可以从独立哲学问题进入，也可继续原有文化政治专题：

- [[哲学与文化/20-论证知识与规范/00-论证知识与规范-MOC|论证、知识与规范三问入口]]：从“材料一致就知道了吗”“多数同意就能强制吗”“预测正确就解释了吗”任选一问；三课各有基础/快进入口、经典原文范围、反对意见与可评分迁移题，无需技术先修。

- [[哲学与文化/30-理论哲学/01-同一性变化与持续|同一性、变化与持续]]：从逐件维修与旧件重装的两艘船比较完整材料和连续结构史，固定标准后检验解体、丢件与分叉；相似、同名和同用途分别判断，不从器物外推人格或法律身份。

- [[哲学与文化/30-理论哲学/02-指称描述与语境|指称、描述与语境]]：从空缺或多人任职比较量化条件与具体使用的预设，核否定范围，再把同一句的两树与不同说者接回语境；解析成功不独自证明指称、理解或意识。

- [[哲学与文化/40-伦理与政治哲学/01-道德分歧规范理由与元伦理|道德分歧、规范理由与元伦理]]：从阅读室留位区分查事实、辩原则与真值承诺，重建Moore、Mackie、Railton和Stevenson的竞争理由；改变承诺或退出条件后返回行动，不因意见不同直接证明相对主义。

- [[哲学与文化/40-伦理与政治哲学/02-德性实践智慧与行动判断|德性、实践智慧与行动判断]]：区分一次做对、行动动机和稳定品格，重建中道、人的善与实践智慧互需的理由；改变预约服务条件后回应最强反方，不把善意或技术成功当完整德性。

- [[哲学与文化/40-伦理与政治哲学/03-公平协议与权利起点|公平协议与权利起点]]：比较Rawls的公平代表条件与Nozick的取得／转让／矫正理由，改变身份信息或持有历史后重判；实际同意、收入不等与制度正当性分别论证。

- [[哲学与文化/40-伦理与政治哲学/04-关怀依赖与责任分工|关怀、依赖与责任分工]]：从同一场馆的熟人协助与机构支持，核需要、关系、照护劳动和公平分工；改变负担事实或责任规范桥后重判，不以热心、付费或同意自动证明照护已做好。

- [[哲学与文化/40-伦理与政治哲学/05-真实机会支配与政治正当性|真实机会、支配与政治正当性]]：比较同额资源与实际机会、善待与不受任意权力支配，再核共同强制权力的公共理由；改变转换或控制条件后，区分正当、最佳与合法律性。

- [[哲学与文化/40-伦理与政治哲学/06-控制知识与共同责任|控制、知识与共同责任]]：区分个人归责、角色与结构性责任，连接代际／环境义务；用真实IPCC评估与明确合成本地条件完成综合撤提示题，修改收费资格后重判，不把未测本馆效果写成已验证。

- [[哲学与文化/50-哲学史/01-先秦人性与教化问题#先确认读的是谁的话，为什么提出这个问题|先秦人性与教化问题]]：围绕孟子与荀子怎样解释善的来源和培养，读完整原典论证，区分端绪／成品、性／伪以及可以／实际做到；它是中国哲学问题史的一个单元。

- [[哲学与文化/50-哲学史/02-阿维森纳悬置者与自我意识|阿维森纳悬置者与自我意识]]：从一个无身体知觉的主体读《治疗之书》原段，重建自我肯定与非身体灵魂之间的桥接理由；改触觉、表象和概念能力，检查哪步还成立。

- [[哲学与文化/50-哲学史/03-性理情欲与经典重读|性理情欲与经典重读]]：接孟子、朱熹注与戴震反读，核同一词怎样换工作、解释收益与文本代价；改变译词或弱者表达条件后，分别判断规范理由和历史因果。

- [[哲学与文化/50-哲学史/04-心身区分与互动的通信争论|心身区分与互动的通信争论]]：从《第六沉思》进入伊丽莎白与笛卡尔1643年五封信，重建区分、联合与因果要求；只改因果全称或可分离桥后重判，不把解释不足写成已证不可能。

- [[哲学与文化/50-哲学史/05-劳动异化与商品物神|劳动异化与商品物神]]：从1844手稿进入《资本论》商品形式，比较人的活动反成制约的连续问题与解释变化；只改认识或规范桥后重判，不把收入、主观不满和社会形式混为一项。

- [[哲学与文化/50-哲学史/06-缘起性空与不真空|缘起性空与不真空]]：先读《中论》四谛品的强反对与回应，再读僧肇的实际援引和汉语重述；保留偈／释、空／无、真／假与待缘限定，检验空为何不自动取消因果与实践。

- [[哲学与文化/50-哲学史/07-自律义务与伦理制度|自律义务与伦理制度]]：对读Kant普遍立法／人格与Hegel的形式主义批评，追问具体义务从哪里取得内容、制度何以实现自由；增加规范前提或撤去自由实现前提后重判。

- [[哲学与文化/50-哲学史/08-政治理念与现实社会|政治理念与现实社会]]：从Hegel国家段进入Marx1843逐段批评与1845实践笔记，分概念构成、现实生成和规范辩护；改解释任务或教育者豁免后保留其它未知，再接05劳动与社会形式。

- [[哲学与文化/50-哲学史/09-相等标准与分离形式|相等标准与分离形式]]：从《斐多》相等／回忆与形式理由进入亚里士多德A9，区分判断标准、性质根据与运动起源；改变欠缺全称或补运动条件后，保留双方仍欠的解释。

- [[哲学与文化/50-哲学史/10-本性与普遍谓述|本性与普遍谓述]]：接Z13个体实体难题与Aquinas本性／普遍意向区分，核同定义不等于数值同一、绝对考量不等于第三界；换谓词后检查跨层误读。

- [[哲学与文化/60-美学与艺术哲学/01-作品语境解释与价值判断|作品、语境、解释与价值判断]]：从《春望》的完整文本核作品证据，比较竞争读法，再说明评价理由与强异议；改读《登高》时重新检验解释，不把史传、声誉或点赞当审美裁决。

- [[哲学与文化/60-美学与艺术哲学/02-可见形式与艺术身份|可见形式与艺术身份]]：对读Bell形式体验与Danto理论／历史条件，用真实Brillo箱记录和同PNG合成展示，分艺术分类、个人情感与成功评价；改史证可靠性或一人反应后重判。

- [[哲学与文化/60-美学与艺术哲学/03-审美经验普遍性与境界|审美经验、普遍性与境界]]：以Kant判断根据与王国维词论深读宋祁词，保留两套概念与强异议；接[[哲学与文化/60-美学与艺术哲学/04-表达制度与作品演出|表达、制度与作品演出]]分复制、实例、错误与评价，再到[[哲学与文化/60-美学与艺术哲学/05-艺术道德与可见作品集合|艺术、道德与可见作品集合]]核感染／内容、少数理由和同均值不同准入。

- [[哲学与文化/70-宗教哲学与宗教学/01-信仰理由苦难与解释范围|信仰理由、苦难与解释范围]]：限定全知、全能、全善神论，重建逻辑恶、自由意志与证据性苦难的强论证；改变一个前提后说明回应是否仍成立，不以组织功能或信仰身份裁定真假。接读[[哲学与文化/70-宗教哲学与宗教学/02-神圣隐蔽性与非抗拒不信|神圣隐蔽性与非抗拒不信]]，检验完美爱是否要求每个相应时点开放关系，区分缺信念、缺体验与拒绝关系。 另从[[哲学与文化/70-宗教哲学与宗教学/03-宗教经验的第一人称与公共证据|宗教经验的第一人称与公共证据]]比较个人报告、实验量表与竞争解释，检查体验怎样给信念以理由。

- [[哲学与文化/10-主题/01-文化政治与组织结构/00-文化政治与组织结构-MOC|文化政治与组织结构]]：围绕宗教、国家、社会组织、民主、科学与文化心理之间的关系，重建一套多层次解释框架。

## 本知识域如何组织

```text
哲学与文化/
├── 00-开始/       # 首页与阅读路线
├── 10-主题/       # 按完整问题群组织的专题
├── 20-论证知识与规范/ # 三个独立哲学入门单元
├── 30-理论哲学/  # 器物同一性、变化与持续的代表单元

└── 90-资源/       # 原始材料、参考来源与研究说明
```

专题内部通常保留三种页面：

1. **MOC**：说明核心问题、论证地图和阅读顺序；
2. **中等粒度专题笔记**：每篇承载一段完整论证，而不是只放一句结论；
3. **来源索引**：记录材料出处、内容覆盖和需要进一步核验的地方。

> [!note] 研究边界
> 文化政治专题整理自一份对话式研究材料。属性 `status: research-map` 表示导航与论证结构可用，`review_status: source-synthesis` 表示内容仍是材料综合；它们不表示史实与因果结论已经独立证实。使用其中观点写作前，请回到 [[哲学与文化/90-资源/01-原始材料与参考来源索引|原始材料与参考来源索引]] 检查命题台账和证据状态。

## 研究生方向的范围与下一完整单元

本表以2026-10-04已选范围内的正文及同义表达定位为基础，中国哲学史与形而上学行于2026-10-12据现有单元更新；“部分”表示相关教学切片，“未定位”只限此次定位范围，均不代表来源、客户端或个人学习已通过。“下一完整单元”仍为计划名称；其中量词与证言两条此前计划已交付，现有定位和下一步分开登记。P0为范围校准，P2为共同理论与方法，P3为方向纵深，P4为真实研究；阶段表示依赖深度，不要求等其它学科全批完成。每个单元仍需正文、原始依据、反例、迁移任务与独立复核。
