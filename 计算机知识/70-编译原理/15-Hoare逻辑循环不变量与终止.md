# Hoare 逻辑：循环退出时正确，怎样再证明一定退出？

考虑 `s:=0; x:=N; while x>0 do s:=s+1; x:=x-1 end`。期望 s=N。看几个输出还不够：N 的范围是什么，循环体中间何时能使用不变量，怎样排除永远循环？本课把 [[数学/12-离散数学与逻辑/04-递推归纳不变量与图模型|可达状态归纳与Euclid不变量]] 的方法写成 Hoare 规则，提供赋值前置条件和循环终止的完整例子。

## 1. 这是另一种语言：整数状态与命令

不复用 STLC 的 Bool/箭头类型环境。状态 σ 是变量名到数学整数 ℤ 的映射；正文理论采用所有变量都有值的总映射，实验用字典，只运行引用变量均已初始化的子集，未初始化显式拒绝。N 是不被命令修改的输入常量，假定 N∈ℕ={0,1,…}。加减没有机器溢出。

```text
a ::= n | x | a+a | a-a           n∈ℤ
b ::= a>a
c ::= skip | x:=a | c;c | while b do c end
```

⟦a⟧σ 是算术表达式整数值，⟦b⟧σ 是布尔比较；所有有限表达式的求值终止，无除零。断言 P 是状态谓词 σ↦true/false，可写量词、等式及逻辑联结，不局限于程序中 `>` 的语法。`σ[x↦k]` 只更新 x。

配置为 ⟨c,σ⟩，小步规则全部如下（`→` 此处连接配置）：

| 命令 | 下一配置 |
| --- | --- |
| ⟨x:=a,σ⟩ | ⟨skip,σ[x↦⟦a⟧σ]⟩ |
| ⟨skip;c₂,σ⟩ | ⟨c₂,σ⟩ |
| ⟨c₁;c₂,σ⟩ 且 ⟨c₁,σ⟩→⟨c₁′,σ′⟩ | ⟨c₁′;c₂,σ′⟩ |
| ⟨while b do body end,σ⟩，⟦b⟧σ=true | ⟨body;while b do body end,σ⟩ |
| 同上，⟦b⟧σ=false | ⟨skip,σ⟩ |

skip 本身终止、无步；while 每次检查条件后才进入体。体中的两个赋值按顺序，第二个看到第一个的新状态；未把循环体冒充一步原子操作。

## 2. 部分正确与全正确分别量化什么

部分正确三元组 `{P} c {Q}` 的定义是：任意 σ，若 P(σ)，并且从 ⟨c,σ⟩ 经有限步终止到 ⟨skip,σ′⟩，则 Q(σ′)。它只约束会终止的运行。全正确 `[P] c [Q]` 另外要求对每个满足 P 的 σ 都存在这样的有限终止运行。此语言确定且表达式总求值，因此不需区分多个调度分支。

例如 `{true} while 1>0 do skip end {false}` 部分正确成立，因为没有终止结果可违反后件；全正确失败。三元组不一定意味着有人“得到 false 状态”，它是逻辑蕴含中终止前提永远不成立。若加入异常、死锁或非确定性，必须重新声明何为终止、失败以及全正确是否要求所有路径，本课没有这些扩展。

## 3. 赋值规则为什么从后件倒推

定义断言替换 `Q[x:=a](σ)=Q(σ[x↦⟦a⟧σ])`，不是立即更新真实机器，而是问“执行赋值之后是否满足 Q”。于是

$$\{Q[x:=a]\}\ x:=a\ \{Q\}.$$

证明：若前件在 σ 成立，赋值规则给 σ′=σ[x↦⟦a⟧σ]，前件的定义正是 Q(σ′)。赋值总终止，所以同一规则也支持全正确。

例：后件 x=5，命令 x:=x+1，前件是 x+1=5，即 x=4。若错写 `{x=5} x:=x+1 {x=5}`，输入5得到6，立刻失败。后件 x=y+1、命令 x:=y，前件 y=y+1，无整数解，因此不是“赋值后总会成立”。只替换后件的自由 x；带量词的断言要避捕获，最稳的是上述状态函数定义。

另外三条组合规则：skip 保持任意 P；顺序由 `{P} c₁ {R}`、`{R} c₂ {Q}` 得 `{P} c₁;c₂ {Q}`；后果规则由 P⇒P′、`{P′}c{Q′}`、Q′⇒Q 得 `{P}c{Q}`。全正确顺序要求两个前提都全正确；不能让第一段发散，再以第二段正确冒充整体终止。

## 4. 循环不变量给退出时的保证

I 是每次**循环头检查条件之前**成立的状态断言。部分正确循环规则为

$$\frac{\{I\land b\}\ body\ \{I\}}
{\{I\}\ while\ b\ do\ body\ end\ \{I\land\neg b\}}.$$

这里 b 在断言中表示 ⟦b⟧σ=true。证明考虑任意有限终止运行：其循环体执行次数 k 有限。对 k 归纳：k=0 时 guard 为假，原 I 与 ¬b 即后件；k>0 时原 I∧b，体的前提给下一个头 I，剩余 k−1 次用归纳假设。只证明终止路径，完全未排除无限 k。

对计数循环，取

$$I\equiv s+x=N\land x\ge0.$$

初始化 s:=0、x:=N 后 I 成立。体入口 I∧x>0，设旧值 s₀,x₀，则第一步 s=s₀+1、x=x₀，暂时 s+x=N+1，I 可以暂时不成立！第二步 x=x₀−1，恢复 s+x=(s₀+1)+(x₀−1)=N；整数 x₀>0 蕴含 x₀≥1，故新 x≥0。

也可用赋值规则倒推体：后件 I 对最后 `x:=x-1` 的替换为 R≡s+(x−1)=N∧x−1≥0；再对 `s:=s+1` 替换得 (s+1)+(x−1)=N∧x−1≥0，即 s+x=N∧x≥1，由 I∧x>0 蕴含。R 只要求在两个赋值之间成立，不把它当头部不变量。

退出时 I∧¬(x>0) 给 x≥0 与 x≤0，因此 x=0，继而 s=N。若不变量只取 x≥0，虽保持却无法推出 s=N，属于过弱；若误写 s=N，N=3 初始化 s=0 就失败，属于不能建立。

![N=3循环头与两个赋值的状态变化](assets/semantics-loop.svg)

| 程序位置，N=3 | s | x | s+x | I |
| --- | --- | --- | --- | --- |
| 初始循环头 | 0 | 3 | 3 | 真 |
| 第1次 s:=s+1 后 | 1 | 3 | 4 | 假，可允许 |
| 第1次 x:=x-1 后/第2头 | 1 | 2 | 3 | 真 |
| 第3头 | 2 | 1 | 3 | 真 |
| 第4头/退出 | 3 | 0 | 3 | 真 |

## 5. 加上严格下降的 variant 才能证明终止

令 V(σ)=x，值域为非负整数。要得到全正确，须证明每次头部 I∧b 下，**循环体自身全终止**，重新建立 I，且 V_new<V_old，并保持 V_new≥0。常用规则用新的逻辑常数 m 冻结旧度量：对所有 m∈ℕ，

$$[I\land b\land V=m]\ body\ [I\land 0\le V<m],\qquad I\Rightarrow V\in\mathbb N.$$

m 不是命令变量，体不能修改它。在本语言表达式求值和两个赋值总终止；入口 x=m>0，体后 x=m−1≥0，且 m−1<m。因此若无限循环，就得到非负整数的无限严格下降链，违反良序；结合部分正确可得 `[N≥0] 初始化;循环 [s=N∧x=0]`。对N=0，体执行0次；对任意N，恰执行N次体，因为第k头 x=N−k。实验计入 skip 消除和 guard 检查的小步数，是5N+1；这是初始化之后的循环步数，并不是循环迭代次数。

下降但无下界不够：`while 1>0 do x:=x-1 end` 在 ℤ 上一直下降仍无限。非负但不严格下降也不够：`while x>0 do skip end` 以 x=1 进入，永远为1。仅证外层 V 下降也不够，若体本身无限循环，永远到不了下一头。若输入N<0，本例直接退出，s=0≠N，故前件N≥0真实必要。

数学整数的证明不能直接移植到固定宽度有符号机器整数：溢出改变表达式和不变量是否合法；若程序采用模运算或带异常加法，须按相应语言规范另证。这也连接 [[计算机知识/70-编译原理/11-优化正确性语义保持与验证测试|优化改写的语义前提]]。

## 6. 练习与解答

1. 如果把体改成只有 x:=x−1，I=s+x=N还保持吗？解：从(s,x)=(0,1)、N=1一步变成(0,0)，和为0。程序终止但后件错误，variant正确不补救错误不变量。
2. 若换成 s:=s+x，再 x:=x−1，应取什么不变量？解：令F(k)=k(k+1)/2，I为s+F(x)=F(N)∧x≥0。体后s′+F(x′)=s+x+F(x−1)=s+F(x)，因为F(x)−F(x−1)=x。variant仍x，退出得s=F(N)；乘除出现在断言中，不要求当前算术程序语法有这些操作。
3. 用赋值规则为 x:=x−1、后件 x≥0 求前件。解：x−1≥0，即x≥1。若只给x≥0，旧x=0反例使新x=−1。
4. 31组输入通过能证明所有N吗？解：不能。一般结论来自建立、保持、退出和良基下降的证明；测试仅核对实现与每个实际循环头。
