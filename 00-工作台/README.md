# 工作台

记得领域，从 [学科入口](../README.md) 进入；记得问题，从 [[00-工作台/按问题找知识|问题入口]] 进入；需要翻阅和筛选，打开 [[00-工作台/知识目录.base|知识目录]]。想把机器学习、系统与算法的基础依赖串起来时，使用 [[00-工作台/基础理论学习路线|基础理论学习路线]]，或打开 [[00-工作台/基础理论总览.canvas|基础理论总览 Canvas]] 查看关系后双击文件节点进入正文；社会科学入口为 [[社会科学/00-开始/00-社会科学-首页|社会科学首页]]。

随手疑问和未整理内容放在 [[00-工作台/收件箱/README|收件箱]]。需要时使用 [[00-工作台/模板/知识页|知识页模板]] 或 [[00-工作台/模板/学习记录|学习记录模板]]，不必每次都填完整模板，也不由 AI 代填已经掌握、已经完成。

## 与 AI 协作，不替 AI 管项目

直接指出读者问题和相关页面即可，无须先选模型或填写 JSON。AI 应先检查已有说明，再交付必要改动、可核对依据、未解决项和撤销范围；没有缺口时返回准确定位，不为交差增加笔记。

你可以继续阅读、记录和编辑其他页面。只在准备发布时协调这一小组目标；目标出现新批注、未保存内容或同步冲突时，AI 应保留候选而不是覆盖。没有真实阅读反馈，不把模拟读者评分写成你的掌握程度。

临时队列、候选与代理会话留在库外，不在这里生成几十份机器任务。需要了解机制时再读 [[00-工作台/并行协作与模型路由|并行协作与模型路由]]；实际结果从 [[CHANGES|CHANGES.md]] 进入。
