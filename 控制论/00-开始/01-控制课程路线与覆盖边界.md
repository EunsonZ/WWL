# 控制课程路线与覆盖边界

本课程从“什么结果算合格”出发，让读者交出对象、信息、行动、模型、设计、证明与实现条件。已有知识保持主解释原位；这张地图负责说明何时带着什么问题去读，以及回来需要做什么。

## 起点诊断和逐步路线

先看 [[控制论/10-系统课程/01-调节目标信息与行动#先做一个无需微积分的诊断|有限调节表]]：能说明观察分组为何造成无解，就已有信息边界的起点。再读 [[控制论/10-系统课程/02-热模型从物理到连续反馈#先固定对象和每个端口|热模型端口]]：能用 J/K、W/K、W 和 K 把方程每项对齐，就可进入反馈设计。不熟悉导数时，把它读成“每秒温度变化率”，先手算初始变化率再回补微积分。

继续C01时沿 [[控制论/10-系统课程/04-耦合热对象状态与端口能力|二维端口能力]] → [[控制论/10-系统课程/05-状态反馈观测器与平衡目标|反馈与观测器]] → [[控制论/10-系统课程/06-多变量互联矩阵顺序与实现条件|MIMO互联与采样]]，回来交两状态rank与退化判断、K/L和平衡目标、4×4稳定责任、端口矩阵shape与实际保持模型。它增加了一段连续学习正文，完整C01及C02–C08目标继续保留。

应用链继续沿 [[控制论/10-系统课程/07-有限时域最优控制Hamiltonian与终点条件|固定终点最优]] → [[控制论/10-系统课程/08-约束预测控制从有限QP到终端保证|两步约束QP]] → [[控制论/10-系统课程/09-有界扰动不变管与模型误差|有界扰动与参数误差]]，回来交协态终点条件与充分性证明、带界可达判断、KKT证书、终端移位及扰动管归纳。实践 [[控制论/80-实践/03-最优与约束热调节/README|03]] 复用热对象，独立运行轻量代码。它补清C04的有限例和C05参数误差接口，完整多变量最优/鲁棒MPC仍需继续。

辨识/自适应应用继续沿 [[控制论/10-系统课程/10-闭环辨识从激励到控制条件|闭环辨识条件]] → [[控制论/10-系统课程/11-直接MRAC有界跟踪与参数收敛|直接MRAC证明与PE]] → [[控制论/10-系统课程/12-扰动下的σ修正与数字实现边界|σ修正和数字保持]]。回来交噪声端口与回归秩、OLS偏差/IV正交条件、真实闭环反例、全时有界/跟踪与PE参数证明、无激励不变量、泄漏残差界及数字局部采样条件；[[控制论/80-实践/04-辨识与MRAC/README|实践04]] 分别复算。它落实C05的一个闭环辨识有限链和C06的指定直接标量链；一般间接自适应、多参数/未知输入增益与现实采样保证继续保留。

混杂/网络应用继续沿 [[控制论/10-系统课程/13-混杂事件切换与驻留保证|事件、切换与驻留]] → [[控制论/10-系统课程/14-网络采样时延与允许更新序列|时延与允许更新序列]]。回来分别交guard/reset/驻留证书和信息集/保持/允许序列/全时界；[[控制论/80-实践/05-混杂与网络/README|实践05]] 检查有限模型。一般非线性混杂/可达、时变时延/多变量网络、时钟/测量误差和真实设备deadline仍按完整课程责任处理。

起步段的验收任务是：读者自行从 C、h、工作点推导热模型，选择满足给定稳定/误差条件的增益，写出采样时序，并用一个条件变化推翻过强结论。正文和运行记录支持任务核查，没有据此填写真人掌握程度。

下表是完整课程的边界。没有落盘的单元保留任务说明，不制造页面链接；起步段不是关闭整个课程的依据。

| C01 建模与线性设计 | 本课程02–03的一阶P/PI，04–06的二维可控可观、反馈/观测器、MIMO端口与采样；既有rank/Gramian、PID、LQR/LQG与反馈稳定 | 更广MIMO互联与一般反馈/观测器设计算法；积分内模的一般条件；瞬态、噪声、带宽和幅度联合设计。 |
| C02 非线性与能量 | [[数学/46-数理方程/30-非线性动力系统/02-阻尼摆Lyapunov与LaSalle\|Lyapunov与LaSalle]] | 控制律设计、吸引域、ISS输入界、无源互联、相对阶及内部零动态反例。 |
