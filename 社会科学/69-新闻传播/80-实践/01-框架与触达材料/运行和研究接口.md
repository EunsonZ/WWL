# 固定材料复算与尚未运行的受众研究接口

返回 [[社会科学/69-新闻传播/01-新闻框架触达与受众解释|正文]]。此组是完整合成教学材料，不是真实机构新闻、平台分发或受众研究。

## 输入、单位、命令与独立预期

[固定曝光记录.csv](固定曝光记录.csv)逐行列出2000名合格者，两组各1000且ID互不重叠；ID为A0001—A1000、B0001—B1000的架空代号。每组同一固定24小时窗口，曝光／点击按人去重。A曝光A0001—A0100、点击A0001—A0020；B曝光B0001—B0500、点击B0001—B0020及B0101—B0130。其余行保留在合格分母，不能删成曝光者名单。

曝光标记只表示题设确认至少一次标题卡完整显示，点击标记表示至少一次点开，不代表注视、读完、理解或赞同。CSV没有展示事件次数或点击事件次数。字面ID顺序只是合成数据生成规则，不暗示真实分发按用户编号，也没有随机处理分配。

计算真源为 [count_reach.py](count_reach.py)，Obsidian可读 [源码镜像](code-sync/count_reach.md) 逐字同步；仅用标准库 `csv`、`fractions`、`json` 等。从库根运行：

```bash
python3 -B 社会科学/69-新闻传播/80-实践/01-框架与触达材料/count_reach.py
```

默认读同目录CSV，打印并写 [精确计数JSON](results/exact-counts.json)。若要改数据，复制到自己的输入并指定新的输出，保留原固定案例：

```bash
python3 -B 社会科学/69-新闻传播/80-实践/01-框架与触达材料/count_reach.py --input /绝对路径/新输入.csv --output /绝对路径/新结果.json
```

先手推预期再运行：A曝光 $1/10$、CTR（人）$1/5$、全目标点击 $1/50$；B曝光 $1/2$、CTR（人）$1/10$、全目标点击 $1/20$。两边各满足后两层集合乘法关系。百分数为10／20／2与50／10／5，分母与顺序不能省。没有曝光时条件比例输出空值，不捏造0%；重复ID、非0/1标记、点击者不属于曝光者等输入会拒绝。

2026-10-16本机在共享两槽runner内以1线程实际复算，固定计数与上述预期一致；这只核有限合成记录和分数，不是实验或传播效果验证。正文、码表与两篇事实同集另外核对，不用程序的断言代替语义审阅。素材没有需要数值曲线解释的对象，因此不造一张图来充当实验。

## A/B框架效果：待运行设计

此处只准备接口，**没有招募、随机分配、实际曝光或真人答卷**。若未来获相应研究授权，先明确问题是“分配这两个固定版本会怎样”，而不是事后把点击率命名为说服力。

- **输入与对象。** 记录同意参与者的必要阅读语言、相关先验知识和是否已看过资料／答案；选定目标招募范围。A/B正文、标题、来源署名、图像、布局和显示位置固定并留实际版本；不让B同时多一条新事实。图书馆例明确架空，不把他人的真实困境当操纵材料。
- **分配与暴露。** 在同一招募范围内预先随机分配A/B并规定比例、顺序和时间窗口；实际分配、是否显示、显示版本、点开、退出、跨组看到及讨论分列。若使用真实平台算法且无法固定，处理就包含组合分发策略，不能自动分拆标题效果。当前1000／100／20等只是教学日志，不是该试验的样本量或随机化证据。
- **结果。** 先在无提示下请读者复述“这篇最主要讲什么，哪些仍未知”；再用事先定义的四点理解任务核六周、长期未知、预算上限、人次非人数；政策赞同与重要议题排名另列。四点得分不等于态度，也不覆盖全部理解；不同语言表达允许等价答案，需检查题意等值。编码者先对不带版本标签的原答编码，分歧与理由保留，不能编造已达到盲法或一致率。
- **比较。** 主分析按原随机分配比较预定结果；只看曝光者／点击者／完整答卷者均可能选择。若无法观察全部已分配者，失访／技术失败／撤回分别记，预先规定缺失与敏感性分析，不能将未答填成未理解或只删失败者。样本量／功效、主要结果、分析与停止协议需在确认性运行前定好，本材料不提供虚构精度。
- **可反驳预测。** 预试可用于修订造成额外事实误读的标题；正式比较按原分配整体并列报告理解和自发提及，不按处理后理解正确或点击筛选再估框架效果。预测A较常自发提及服务可达，B较常提及投入／持续；若只出现事实误读或无差异，修订“考虑权重改变”的机制，不能删掉误读者来保护它。先前经验可能使低位信息更突出，记录可检的异质性而非事后按满意分组。受众之间转发讨论、外部事件及重复提问影响后测，须纳入干扰与暴露边界。

一名读者的形成性试读可揭露误读或材料问题，不能估计总体因果；看到问题后改题／改标题是形成性修订。若途中改事实或问题，新版本另记，不能把新旧结果混成原处理效果。确认性检验不因“先写了显著即停”便自动获得固定样本误报率；通用条件复用既有因果／统计主解释。

## 更正触达：另一个待运行设计

先区分“更正发布者做了什么”和“原错误受众发生什么”。在明确合成、事先同意的教学情境内，若未来让参与者阅读错误版本，再研究更正方式，须事先说明材料测试性质，结束时提供正确材料；不把本接口用于实际散布虚假新闻。

1. 固定T0原错误句、更正稿和事实参照M1／M4；记原错误版本及去重曝光集合E。原帖点开与相信原句不是同一个变量，有需要则在不诱导的条件下另测，且承认测量本身会改变注意。
2. 在E对应的获同意受众中，预先分配“原帖尾注更正”或“同一位置独立显示更正”等方式；两组使用同一更正内容、相同观察窗口，保留实际可达位置和显示记录。必要支持不因分组撤除；若方式同时改内容，处理重新命名为组合。
3. 记更正曝光集合C及交集E∩C，主要触达分母为原错误曝光者E；同时报去重覆盖、重复曝光与未知匹配。展示数不是人数，身份无法可靠链接时不造交集；只向新读者扩散更正也不意味着覆盖旧受众。
4. 收原答后按两个目标检查：能否指出“永久决定”未经材料支持，能否区分“尚未决定”与“决定停止”。自报看过、点赞或点开不能替代这两项理解。是否改变相信、政策态度及多长时间保持另设结果，不默认为同一量。
5. 未显示、未答、退出、看过另一组、记不清、期间又看了原错误分别保留；不把缺失当纠正成功。任何总体推断先定分配单位、干扰、样本、缺失和停止协议。全部正确答卷也只支持已观测对象与条件，不认证真实平台或长期纠错。

两项未来研究的原答默认保留在同意的私密位置，公开匿名摘要／节录另按同意范围；不建数据库、追踪平台或个人能力档案。没有真人时写未运行，不用作者写出的合理解释或代理作答补成效果。当前可接收的是材料、算术、来源与可反驳接口，实际理解验证保持未验。
