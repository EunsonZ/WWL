# README-导入与范围

## 导入方式

将压缩包解压到你的Obsidian Vault根目录，或先解到临时文件夹检查后，把其中`计算机知识`目录合并进Vault根目录。最终应得到：

```text
你的Vault/
└── 计算机知识/
    └── Kali/
        ├── README-导入与范围.md
        ├── 00-导航与方法/
        ├── 01-系统与网络基础/
        ├── …
        ├── 07-综合实验/
        ├── 08-模板与速查/
        └── 90-来源与维护/
```

入口是 [[计算机知识/Kali/00-导航与方法/00-Kali知识地图|00-Kali知识地图]]。也可以把**解压后包含`计算机知识`的那一层目录**作为新Vault打开；不要把Kali子目录本身作为根，否则完整路径链接不再对应原设计。

## 已有同名内容时先审阅

v5 基于当前实际可读取的 v3 专题 ZIP 与原维护契约进行审阅。当前环境未发现此前答复所称的 v4 ZIP，未声称继承或合并该不存在于本轮输入中的版本；没有获得你在本地导入后可能做出的修改，因此不能声称已合并或保留未提供的本地版本。已有`计算机知识/Kali`时先做备份与差异比较，不直接全选覆盖；保留用户笔记与真实实验记录。已有根`CHANGE.md`或更细路径约定时，应先按本机实际规则决定导入范围。

本包不含`.obsidian`、插件、API凭据或自动启动配置，也不修改现有根`AGENTS.md`。支持原生双链、标题/块引用、callout、属性、搜索与Canvas；特定界面效果未在本次构建中实机检查。

## 覆盖与诚实边界

这是一套按任务和原理组织的主要常用工具课程，不是Kali全部软件包的穷尽替代手册。[[计算机知识/Kali/00-导航与方法/05-常用工具覆盖矩阵|覆盖矩阵]] 明确哪些有实操模板、哪些为概览或高风险边界；“正文出现了名字”不计为同等深入掌握。具体命令先核对本机版本与帮助。

技术正文为官方资料核查与原创教学，附件只提供写作/维护规则。日期与来源在 [[计算机知识/Kali/90-来源与维护/01-来源索引与核验边界|来源索引]]，本轮研究与未运行项目在 [[计算机知识/Kali/90-来源与维护/06-v5深度研究与结构梳理记录|v5 研究与验收记录]]；旧版实际运行只见 [[计算机知识/Kali/90-来源与维护/05-v3深度审阅与变更记录|v3 历史验收]]；[[计算机知识/Kali/90-来源与维护/03-验收与构建记录|首次构建记录]] 保留为历史。不把文档查阅、静态检查、离线单测、Kali实机和Obsidian界面混称为“全部验证”。

本轮重点是工具功能与理论。已有基础者优先读 [[计算机知识/Kali/00-导航与方法/07-问题驱动的工具选择与理论路线|七条问题驱动的理论路线]]，再进入正文的具体机制与例子。无需运行实验即可阅读本轮新增内容。

公开导出只含合成资料、源码和维护证据。压缩包内`MANIFEST.sha256`可核对文件内容；摘要能发现不一致，但不能替代可信来源认证。维护方法见 [[计算机知识/Kali/90-来源与维护/02-导入维护与扩展规范|导入与维护]]。
