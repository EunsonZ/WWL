# 三个有限模型，各自能证到哪里

所有输入是**合成教学经济或博弈**，没有国家、真实家庭、平台或真人成绩。三页相互连接，但不被拼成一个已估计的一般均衡：04总量行为与汇率制度；05另外给两户禀赋、世界利率和可执行额度；06另外给预测—政策行动与损失。先做 [[社会科学/20-经济流动与宏观/40-宏观经济学/80-实践/03-开放信用与承诺/迁移题|三道迁移题]]，再展开答案。代码复算不是学习效果，也不是现实政策因果证据。

## 一次阅读往返：从冲击到谁能支付

先在04临时财政情境中定位：当期增支由谁纳税，$CA=NX$ 又额外假定了什么；再依次重建IS、UIP、实际利差与日期1到0的求解。然后到05把“消费倾向”拆成受约束A与能平滑B，核存款/贷款/国外对应，问同总收入的转移怎样改变今天可用资源；回到14家庭资源页与真实机会的期限，撤回仅凭总量就说所有人受益的判断。最后到06将给定预期换为先行预测与后续最优选择，问制度执行是否真的改变偏离收益。

## 真实识别与学习的未验接口

开放政策识别的重要输入是：经济体/日期与政策前冻结的数据版本；真实报价与频率、名义/实际利率、预期发布时点、P与M口径、政策工具和税支融资、进口结构、资本制度及外币头寸；原始时间戳与修订历史。先定义目标量，如给定制度与信息集的意外货币冲击对随后Y/NX的效应，不能把制度选择本身当随机。需交代政策新闻/工具变量/可比较组的分配机制、排除限制与提前反应，政策响应衰退、同步财政/国外冲击、资本限制和市场溢出是具体威胁。记录选择、暴露、缺失、修订与失败；若未来汇率锚或融资工具不符，(8)不再是所检验的模型。观察到贸易余额不等识别私人/储备毛流。

信用接口的单位是同一家庭决策前后的收入分布、额度要约及执行、资产估值与债权人；区分申请、获批、实际借款和其他渠道。先冻结“提高可用额度对当期消费”的目标与分配/阈值设计，再定资格、不遵从、缺失和替代渠道的处理。若Q因收入消息变化，须另识别价格变化与收入风险，不能用$\theta Qh$这个结构式宣布排除限制成立。反复观察低/高收入及事前信念可反驳单记录风险竞争模型；若拟合完整结构，至少估计收入过程/偏好/额度执行，报告哪些参数由什么观测或外生变动区分、哪些只靠校准。联合拟合消费不自动区分风险与额度，先保留参数集合及竞争反事实，而非只报一个最优拟合数。

承诺接口的单位是制度、政策者、受影响主体与预期形成日期。记录执行规则是否真的约束行动、谁能免除成本、规则发布和预测/价格/工资合同的先后、政策偏好和冲击。若研究制度变更对预期的作用，须说明制度进入的选择机制、信息与其他政策同步变化、可比较组及提前预期；不能以较低通胀单独证明F提高，也不能以零点被支持就忽略另一个均衡。失效观察包括可无成本豁免、预期并未改变、政策偏好目标改变或冲击使原收益关系不适用。
