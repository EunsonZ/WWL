# 预算税制、转移支付与地方债（现实基线）

## 核对范围与日期

- 核对日期：**2026-08-18**。
- 范围：国家预算体系、主要税收立法层级、中央与地方财政关系、转移支付、地方政府法定举债及其公开接口。
- 本文只描述在截点已经生效的制度。年度预算文件用于观察当年运行，不等同于永久性制度；政策意见与法律、行政法规分层表述。

## 制度状态

| 模块 | 截点状态 |
|---|---|
| 预算 | 现行主干为2018年修正的《预算法》和2020年修订的《预算法实施条例》，实行中央与地方分级预算、全口径预算和法定审查批准程序。 |
| 税制 | 各税种分别由法律或行政法规规范；增值税法及其实施条例已于**2026-01-01**施行，原增值税暂行条例退出该税种的主干规范位置。 |
| 财政关系 | 分税分成、共同财政事权和转移支付并存；2022年省以下财政体制改革意见仍是省内划分收入、事权和转移支付的重要政策接口。 |
| 地方债 | 地方政府只能在法定限额内，以省级政府发行的一般债券或专项债券举借；预算调整、资金用途、偿还和信息公开均受预算制度约束。 |
| 运行观察 | 2026年中央预算、2025年中央决算和2026年上半年财政收支均已有官方公开，但数据会继续随决算、审计和口径说明更新。 |

## 现行结构摘要

1. **四本预算、五级编制。** 一般公共预算、政府性基金预算、国有资本经营预算、社会保险基金预算分别编制并保持衔接；中央、省、市、县、乡镇按法定层级形成预算。人大及其常委会承担批准、调整和决算监督，政府财政部门组织编制与执行，审计机关实施审计监督。
2. **收入按税种和权限组织。** 中央税、地方税、中央地方共享税及非税收入共同构成财政收入。税收征管由税务机关依法实施，税种立法、优惠、征收口径和收入归属并非同一层次的决定。
3. **财力通过转移支付再分配。** 一般性转移支付侧重均衡基本财力和共同财政事权保障，专项转移支付绑定特定政策目标；省以下还要继续划分市县事权、收入和补助责任。
4. **地方债纳入预算。** 一般债券主要以一般公共预算收入偿还；专项债券对应有一定收益的公益性项目，通常由政府性基金或专项收入偿还。新增限额由国家层面批准后分配，存量债务则依期限还本付息、再融资或依法置换。
5. **国库、采购、资产和绩效相连。** 预算执行经国库集中收付，政府采购、行政事业性国有资产、投资项目和绩效评价形成支出链条，但各系统公开颗粒度并不完全一致。

## 关键制度接口

| 接口 | 现实中的连接方式 |
|---|---|
| 立法监督—行政执行 | 预算、预算调整和决算由同级人大体系审查批准；财政部门执行并报告，审计结果另行公开。 |
| 中央—地方 | 税收归属、事权与支出责任、共同财政事权补助及均衡性转移支付共同决定地方可用财力。 |
| 土地—政府性基金 | 国有土地使用权出让收入进入政府性基金预算，是部分地方建设与偿债安排的重要资金接口，受房地产和土地市场波动影响。 |
| 项目—专项债 | 项目储备、收益与融资平衡、发行、资金拨付、资产形成和偿还应形成全生命周期链条。 |
| 法定债务—其他融资 | 政府债券属于显性法定债务；融资平台经营债务、政府购买服务、特许经营和担保承诺需按实质识别是否形成政府责任。 |
| 预算—信息公开 | 预算、决算、债券发行和存续期信息已有分层公开平台，但项目级数据、口径和机器可读性仍不统一。 |

## 可观察约束与信息缺口

- 四本预算之间存在调入、调出和结转结余，公众较难从单份报告复原完整资金流。
- 地方基本公共服务责任与稳定自有收入并不总是同步，转移支付测算因素、共同事权分担比例和省以下再分配会影响县级可用财力。
- 土地相关收入波动会同时影响建设资金、专项债项目现金流和地方资产负债安排；跨年度风险不易从年度预算单独识别。
- 法定地方债披露较规范，但地方国企、融资平台与政府之间的资产、合同、补贴、担保和救助预期尚缺统一穿透式报表。
- 专项债项目收益预测、建设进度、运营收入、资产登记和实际偿债表现的项目级持续披露不齐。
- 税收优惠的预算成本、受益主体和政策效果尚未形成覆盖完整、可持续比较的“税式支出”公开体系。

## 古国改革需回答的问题

1. 四本预算是否合并为一张可追踪的公共资金总表，预算外承诺如何依法入表？
2. 中央、地区和基层的事权怎样与稳定收入一一匹配，转移支付公式由谁制定、复核和申诉？
3. 税种、税率、减免和收费分别需要何种立法层级，如何公开税式支出与分配效果？
4. 地方借款的总量、用途、期限、偿还来源和破产或重整边界如何设定？
5. 如何把专项债从“发行合规”推进到项目成本、收益、资产和绩效的全周期公开？
6. 怎样穿透识别公共企业、特许经营和政府合同中的隐性财政承诺，又不把一般商业风险自动归为政府债务？
7. 预算数据应以何种统一科目、开放格式和更新频率供公众核验？
