# 语法与文件练习

## 任务：汇总一组虚构消费记录

新建 `expenses.py`，处理下面的标准库数据：

```python
records = [
    {"category": "book", "amount": 88.0},
    {"category": "food", "amount": 26.5},
    {"category": "book", "amount": 42.0},
    {"category": "travel", "amount": 15.5},
]
```

实现：

```python
def summarize(records: list[dict[str, object]]) -> dict[str, float]:
    """按 category 汇总 amount；非法记录抛出 ValueError。"""
```

程序还要把结果写入 UTF-8 JSON 文件 `summary.json`，再读回并验证内容。

## 分步要求

1. 用 `for` 和字典累加各类别金额；
2. 缺少 `category` / `amount`、类别不是字符串、金额不是数字时抛出带说明的 `ValueError`；
3. 使用 `pathlib.Path` 与 `json`，不要手工拼 JSON；
4. 写文件时显式传 `encoding="utf-8"`；
5. 在 `if __name__ == "__main__":` 中运行示例；
6. 至少写三个测试：正常数据、空列表、非法记录。

## 自测接口

可以先用标准库断言：

```python
assert summarize([]) == {}
assert summarize(records) == {
    "book": 130.0,
    "food": 26.5,
    "travel": 15.5,
}
```

再补一个非法记录：

```python
try:
    summarize([{"category": "book", "amount": "88"}])
except ValueError as exc:
    assert "amount" in str(exc)
else:
    raise AssertionError("非法金额没有被拒绝")
```

再验证“记录本身不是映射”也会得到约定的异常：

```python
try:
    summarize(["not-a-record"])
except ValueError as exc:
    assert "record 0" in str(exc)
else:
    raise AssertionError("非法记录没有被拒绝")
```

## 可重复的标准库测试入口

在和 `expenses.py` 相同的临时目录新建 `test_expenses.py`。这份测试只依赖标准库，因此不需要为了完成本练习先安装 pytest；它也要求 `expenses.py` 把示例运行放在 `if __name__ == "__main__":` 内，避免 `import` 时写入真实文件。

```python
import unittest

from expenses import summarize


class SummarizeTests(unittest.TestCase):
    def test_groups_amounts_by_category(self) -> None:
        records = [
            {"category": "book", "amount": 88.0},
            {"category": "book", "amount": 42.0},
            {"category": "food", "amount": 26.5},
        ]
        self.assertEqual(summarize(records), {"book": 130.0, "food": 26.5})

    def test_empty_records_produce_empty_summary(self) -> None:
        self.assertEqual(summarize([]), {})

    def test_rejects_non_numeric_amount(self) -> None:
        with self.assertRaisesRegex(ValueError, "amount"):
            summarize([{"category": "book", "amount": "88"}])


if __name__ == "__main__":
    unittest.main()
```

先在当前临时目录执行语法检查，再执行测试：

```bash
python -m py_compile expenses.py test_expenses.py
python -m unittest -v
```

预期会看到三个测试和 `OK`。若某项失败，保留完整 traceback，先对照失败的测试名称缩小输入边界；不要先用宽泛的 `except` 让测试变绿。需要使用 pytest、断点、日志或类型检查时，转到 [[计算机知识/10-编程语言/01-Python/14-测试调试与代码质量|测试、调试与代码质量]]。
