# 阵列空间采样与波束形成：同数据有限核查

先读[[信号与系统/60-空间与方向信号/01-阵列空间采样与波束形成|主课]]的方向、Pa单位与复共轭约定，再预测哪两方向会混叠、哪个奇异问题能得零代价。这个实验只核固定有限模型的实现；它不测麦克风、天线或水听器，也不把一个结果推广成其他 S13 方向已经完成。

## 具体对象、源码与预先可算的参照

源码：[array_beamforming.py](array_beamforming.py)。参数固定在 `main()`：M=8、c=343 m/s、f₀=3430 Hz、λ=0.1 m、d=0.05 m、q₀=0、干扰qᵢ=0.3。目标包络功率1 Pa²、干扰100 Pa²、通道噪声模型1 Pa²；加载δ=10 Pa²为事先给定的教学参数，未用测试误差择优。

训练长度128、测试长度256，复基带采样率32 Hz。非零DFT行 $F_{kn}=e^{2\pi i kn/T}$ 满足 $FF^H/T=I$，行均值0。训练用k=1作干扰、k=2…9作八通道噪声；测试用k=1作目标、k=2作干扰、k=3…10作噪声。最高实际包络频率是训练的2.25 Hz，包含在声明的[−2.5,2.5] Hz内，32 Hz采样足够。窄带相位尺度 $\pi BD/c\approx0.01603$ rad；这些周期复指数不是全实轴上的有限能量信号，此处只说明各模态的延迟相位尺度，不把它们代入主课的 $L^2(\mathbb R)$ 误差范数。代码直接采用窄带理想模型，没有模拟这个近似误差或指定远场距离。

这些是确定性正交夹具：构造的二阶矩精确等于指定R，数值浮点只近似等于。它们不具有白随机过程的独立性或遍历性；训练/测试采用不同长度、权重不读取测试误差，**不宣称随机独立留出、一般估计一致性或现实泛化**。公开真值只用于固定机制复算。

已声明的解析参照不依赖通用求解器：令 $C=\sum_{m=0}^7e^{-i0.3\pi m}$，固定权重噪声代价 $1/8+100|C|^2/64$；MVDR代价 $[8-100|C|^2/801]^{-1}$。用 rank-one 逆构造另一权重公式，逐元素对照 `solve`。三算法都消费同一测试 X 和同一真值s，测试MSE由各分量正交性等于 $w^HRw$。

## 真实阵列校准：可执行接口，当前没有实测结果

外部验证的重要性高，因为载频相位误差可以被算法误认成方向。要把当前模型接到真实8通道声阵列，先固定以下输入，不能只交一段 WAV：

1. 保留原始同步8通道记录与采样率/时钟/通道顺序；记录每传感器位置r_m（m）及不确定度、测量温度与采用波速c。以参考声压计或可溯源声源给每通道Pa/V比例和相位响应；用共同时标或已知同步激励测通道相对延迟，不用待估方向反过来校时。
2. 在已量测位置和距离R的标定源上验证远场条件；若不能让曲率误差低于指定容限，改用球面模型，不靠加大δ隐藏。记录源的f₀/B、源位置与阵列朝向、反射环境。来源方向由测量几何给真值，不由本算法输出充任真值。
3. 用一组标定方向估计相对复响应 $a_{\rm measured}$（参考通道归一化，参考幅度须远离0）；另留未用于拟合的方向和另一时段核对。逐方向报告 $\|a_{\rm measured}-a_{\rm model}\|_2$、重复测量变动和几何/仪器不确定度；有限角点不能自行认证连续角域的统一ε。可针对已验方向用误差上界和 $\varepsilon\|w\|$ 检查目标响应，未覆盖角域保持未知。
4. 噪声/干扰训练记录与独立评价记录分开，保留权重更新时刻；分别采目标单独、干扰单独及同时存在的记录。报告真实目标复增益、噪声功率、干扰泄漏和残差，而不只报一条输出波形；目标/干扰相关、场景变化时重新审查用R_total代R_noise的条件。

一个具体验收合同可以事先要求保留方向的目标幅度误差≤0.1、相位误差≤5°，并将仪器不确定度计入界；这两个数是待采用的工程规格，不是本课已完成的性能事实。若不满足，应区分同步、单元响应、近场/多径与权重设计原因。没有硬件/标定记录，本包这一层为**未执行**。

最后回主课独立完成四道迁移题。改变d、目标方向、带宽或R的秩时先预测结论，再改代码；只贴新的曲线不能替代“哪一条条件改变”的回答。阵列算法首单元的完成不代表雷达、声纳、生医、图信号等独立课程或现实验证已经完成。
