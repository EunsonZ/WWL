# 02 · 列表、任务与表格

## 无序、有序与嵌套列表

**源码：**

```markdown
- 水果
  - 苹果
  - 梨
- 蔬菜

1. 收集材料
2. 写出草稿
   1. 先列大纲
   2. 再补例子
3. 回顾并链接
```

**渲染效果：**

- 水果
  - 苹果
  - 梨
- 蔬菜

1. 收集材料
2. 写出草稿
   1. 先列大纲
   2. 再补例子
3. 回顾并链接

> [!tip] 缩进是结构，不只是外观
> 子项通常缩进两个或四个空格。保持同一篇笔记内一致，可减少不同编辑器的解析差异；[[Obsidian知识/20-功能/02-社区插件实验室/06-Advanced-Tables-Editing-Toolbar与Linter|Linter]] 能协助统一格式。

## 任务清单

**源码：**

```markdown
- [ ] 未完成任务
- [x] 已完成任务
  - [ ] 一个子任务
```

**渲染效果：**

- [ ] 点一下复选框，观察源码变化
- [x] 我已经是一项完成任务
  - [ ] 我是一个子任务

Obsidian 的核心 Search 可用 `task-todo:` 查找 Markdown 未完成任务行；任务类社区插件的任务查询需另行评估。[Bases](https://obsidian.md/help/bases) 的记录粒度是文件及其属性，不能直接把一篇 Markdown 中的各个复选框行当作独立记录。若每项任务各有一篇笔记，才可用 Bases 汇总这些任务笔记的属性。基础 Markdown 任务最耐久：一个 `x` 就代表完成。

## 表格

第二行控制列的对齐方式，冒号分别表示左、中、右对齐。

**源码：**

```markdown
| 功能 | 用途 | 熟练度 |
| :--- | :---: | ---: |
| 链接 | 建立关系 | 2 |
| 标签 | 跨目录归类 | 1 |
| 属性 | 结构化数据 | 1 |
```

**渲染效果：**

| 功能 | 用途 | 熟练度 |
| :--- | :---: | ---: |
| 链接 | 建立关系 | 2 |
| 标签 | 跨目录归类 | 1 |
| 属性 | 结构化数据 | 1 |

表格单元格内若要显示竖线，需写成 `\|`。复杂、段落很多的数据不必硬塞进表格，可以拆成独立笔记，再用属性或 Bases 汇总。

> [!example] 插件接力
> 到 [[Obsidian知识/30-实践/01-实验区/Markdown/02-表格练习场|表格练习场]] 手工改表格，再对照 [[Obsidian知识/20-功能/02-社区插件实验室/06-Advanced-Tables-Editing-Toolbar与Linter|Advanced Tables]] 课程体验 Tab 导航和自动对齐。插件改变的是编辑体验，底层仍是普通 Markdown 表格。
