# Lorentz介质色散实践

先读 [[物理/20-电磁学/12-Lorentz介质色散储能与群速#场与材料先共同守恒，再谈平均储能|场与材料账本]]，再预测：靠近无损共振时，相同峰值会把更多能量放进振子，群速应怎样变？本实践从四项储能、传播常数频差与群导数比较同一卡；另从零初值实际推进有限外加电场驱动，核对功、储能与热。两种计算分别是已准备的体单色波和局域材料初值问题。

## 复制到可写目录后复建

将本目录的 `lorentz_medium.py` 和 `inputs.json` 复制到自己的可写实验目录。Python 3.10+，仅标准库，无依赖安装；在那个目录执行：

```bash
python3 lorentz_medium.py --input inputs.json --out run-default
```

`run-default` 必须尚不存在，其父目录须存在；源码拒绝覆盖旧结果。输入不合法时在创建输出目录之前退出，退出码2。仓库作者/维护者的短数值运行用已有外部 guard：

```bash
python3 /private/tmp/numerical_guard.py --threads 1 --timeout 60 -- \
  python3 lorentz_medium.py --input inputs.json --out run-guarded
```

guard 是本机执行资源护栏，不是学生源码依赖，也不在此目录假造一个替代脚本。

输出恰为七个文件：`transparent.csv`、`lossy.csv`、`pulse.csv`、`results.json`、`dispersion.svg`、`storage-interface.svg`、`pulse-budget.svg`。本页嵌入的 `assets/` 来自同一输入的真实运行；JSON 的 `elapsed_s` 是那次执行观察值，不用于数值等式。源码是计算真源，[[物理/80-实践/44-Lorentz介质色散/SOURCE|源码镜像与来源]] 保留逐字同步全文。

## 输入各字段代表什么

卡不认证真实材料。正时间峰值相量、背景 $\epsilon_\infty=1$、$\mu=\mu_0$、局域线性各向同性的约定在正文固定。源码用 $\epsilon_0=8.8541878128\times10^{-12}$ F/m、$c=299792458$ m/s，并由 $\mu_0=1/(\epsilon_0c^2)$ 保持内部一致。

| 输入字段 | 默认及允许范围 |
| --- | --- |
| `f0_hz` | 1e9 Hz；1e3至1e15 |
| `strength` | $s=F/\omega_0^2=0.5$；0.01至2 |
| `Epeak_V_m` | 100 V/m；0.001至1e6；线性教学卡范围不构成真实强场认证 |
| `main_ratio` | $\omega/\omega_0=0.75$；0.05至4且在下述透明支 |
| `area_m2`, `length_m` | 周期面积1e-6 m²、开放控制长0.002 m；1e-12至1、1e-9至1 |
| `loss_gamma_ratio` | 0.08；0.001至0.4；时域同时跑0和此值 |
| `sweep_intervals` | 两个不相接且升序的区间，默认[[0.2,0.9],[1.3,2.0]]；端点0.05至4 |
| `sweep_points_per_band` | 每支101点；整数11至401，含两个端点 |
| `loss_interval` | [0.7,1.5]；升序端点0.05至4，固定401点，可含吸收区 |
| `pulse_duration_tau`, `pulse_final_tau` | 40、80；5至100、10至200；最终须至少比脉冲结束大5 |
| `pulse_drive_ratio` | 0.75；0.05至4；这里不要求透明单色传播条件 |
| `pulse_steps` | 8000；整数1000至40000；默认网格及内部加密网格各一次，$\Delta\tau\le0.02$ |

透明主频及两个完整扫区均须满足 $x\le0.98$ 或 $x\ge\sqrt{1+s}+0.02$。这两个人为安全余量用于避开共振极点和传播零点，不是物理吸收线宽；源码直接检查整个区间，不能只靠离散点侥幸没踩极点。改 $s$ 后高频支起点可能须调整，拒绝不合法旧扫区是正确行为。顶层字段须恰与示例相同；重复键、布尔冒充数、NaN/Infinity、非整数点数均拒绝。

## 三条独立表达怎样互相检查

`transparent.csv` 每行给四项能量（J/m³）、Brillouin和、$n,k$导数的群速、$S/u$能量速度与中心频差速度（m/s）。中心频差步长按距极点与传播零点缩小，固定全部材料参数；它是有限差分，不能把与解析导数的小差说成材料效应。`band` 为0或1，每支均单独绘制。

默认主频应得 $n=1.4638501094$、$v_g=v_E\approx1.2148988644\times10^8$ m/s、$\overline u\approx1.5991747376\times10^{-7}$ J/m³。七个图/数据文件共用输入。`results.json` 记录 $R+T$、储能两式、速度两式和有损热两式的残差；默认透明全扫的频差相对差最大约 $6.12\times10^{-9}$。$R,T$ 是真空到半空间界面通量比，体内指定 $E_0$ 与界面归一入射幅有不同用途，见 [[物理/20-电磁学/12-Lorentz介质色散储能与群速#完整合成卡：有限能量段与界面功率分别计量|完整卡]]。

`lossy.csv` 给正时间号下负的介电虚部与折射率虚部、正幅衰减系数（m⁻¹），以及两条独立公式的正热（W/m³）。这里不输出透明储能/群速/R-T，不能把吸收区列混入透明CSV插值。

`pulse.csv` 两卡均保留默认步长的所有点，行的 `gamma_ratio` 区分无损/有损卡。`tau` 为无量纲、`time_s` 为秒；`polarization_scaled=P/(eps0 Epeak)`、`velocity_scaled=d polarization_scaled/dtau`。能量、功和热的 `_scaled` 均须乘 $\epsilon_0E_0^2$ 才是 J/m³；切勿把速度列当作 m/s。`balance_scaled=work_scaled-stored_scaled-heat_scaled`。上图每1000点左右抽取已有记录，CSV仍有全部16002行。

对 $p,p',W,Q_h$ 同时用四阶 RK 进行因果初值推进；每卡另用两倍步数完整重算，在 JSON 记录最终状态差及加密网格全程余额。默认两个末态的最大状态差约 $5.51\times10^{-9}$、$1.62\times10^{-9}$ 个对应无量纲单位；不同状态分量各有不同含义，这个最大值只作数值诊断。代码的同方程残差与加密检查不能单独替代不同路线的独立核算。

## 先预测再改卡

复制输入成新文件，一次只改一个物理条件，并使用新输出目录。完整答案见 [[物理/80-实践/44-Lorentz介质色散/ANSWERS|迁移答案]]。

- 改 `strength` 为0.25：预测材料能量下降、群速上升；同一频率扫区仍合法。不要把改变参数的材料当作同一材料随时间发生了充电或结构变化。
- 改 `Epeak_V_m` 为200：预测所有SI能量/功率变四倍，而无量纲局部响应、折射率、速度与反射率不变。源码归一变量可不随幅度改变；这不表示实际P没变。
- 改 `loss_gamma_ratio` 为0.16：重新计算有损局部运动和做功，不能只把旧热列乘2。无损透明卡仍使用0阻尼，另有损扫区/脉冲使用新阻尼。
- 改 `main_ratio` 为1.1：默认 $s=.5$ 时在负介电禁带，预期拒绝；不存在这份合同的实传播群速。局域受迫振子在该频率仍可计算，空间传播条件与局部ODE不是同一判据。
- 改 `pulse_steps` 为16000：使用新目录，看终态差与余额缩小；无损尾后自由振荡不会因步长缩小而物理消失。

本实践完成有限合成材料卡的透明体波、界面通量和零态局部能量收支。没有空间自洽脉冲传播、前沿测试、真实材料数据拟合、空间色散、饱和/Maxwell–Bloch或任意有损导模求解。回到 [[物理/20-电磁学/12-Lorentz介质色散储能与群速|主解释]]，带走的是材料能量与频率导数的关系。
