## 问题与验证对象

计算时延、窗口和子网；实现能接受任意拆分的长度前缀协议；解释超时后业务结果为何可能未知。

实际脚本检验：全部双段切法、逐字节分帧、EOF/上限、CRC、子网、本地 socket。HTTP/TLS/QUIC 分别处理语义、安全和传输；无线、SDN、共识等进阶分支给出坐标，不冒充部署指南。

## 执行方式

在 Vault 根目录执行。先阅读源码；不要启用 Python `-O` 或 C/C++ `NDEBUG`，否则断言可能被删除。

```bash
python 计算机知识/_labs/round3/NET/network_models.py
```

统一运行器只使用系统已有工具，不下载依赖；编译产物写在临时目录并清理，每次运行的结果写入 `Logs/运行/round3-labs/<运行时间戳>/计算机知识/round3_lab_results.json`。缺少工具明确 SKIP，不伪造通过。Python 要求 3.11+；C/C++ 编译器需支持 C17/C++20 与所用消毒器；TypeScript 需本机 tsc 和 Node。

## 源码与修改练习

- [network_models.py](network_models.py)

先预测结果，再运行；然后只破坏一个不变量，观察哪个断言首先失败，并恢复正确实现。比较“正常输入通过”与“错误路径被拒绝”的证据强度。实验只验证列出的模型和输入，不证明整门学科的所有实现都正确。
