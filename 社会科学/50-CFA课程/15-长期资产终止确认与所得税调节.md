# 长期资产处置与所得税：利润8为什么可能交税4.5

卖掉一台账面30的设备收38，账面收益8，却可能当期交税4.5；剩下2.5来自过去折旧已经少交的税。把交易拆成资产移除、当期税与递延税转回，就能解释为什么现金税率不能替有效税率。本课延伸[[社会科学/50-CFA课程/11-收入存货长期资产与报表调整#3. 减值要同时追资产、利润、税和现金|11课减值双路]]，不重写其主例。以下确认、处置、税桥是三个分开的原创案例，单位万元；不改变澄河2026主账本。

## 先确定资产从哪里来

同样花20研发或买一个技术权利，不能一律得到同额无形资产。IFRS的三个入口如下；成本与公允价值是不同计量对象。

| 独立取得路径 | 原创输入与首日结果 | 分析要看什么 |
|---|---|---|
| 单独购入技术许可 | 现金20，权利可辨认、控制、满足确认；初始成本20 | 合同权利、直接归属成本、期限，不能把自己称赞的品牌估20入账 |
| 内部项目 | 研究8费用化；达到全部开发确认条件后另发生合格开发12，资本化12 | 确认条件满足的时点及证据；已经费用化的8不因后来成功重新入账 |
| 企业合并取得可辨认品牌 | 假设收购100，含品牌20在内的可辨认净资产公允价值80；无非控股/分步收购/税复杂度 | 品牌20单独确认，剩余商誉100－80＝20；不能把品牌再加到商誉20上 |

开发确认要求能够证明技术可行、完成意图、使用/出售能力、未来利益、足够资源与可靠成本计量；必须全部满足，营销口号不能替可行性/资源证据。基础定位[IAS 38 §§21–33、54–67、71](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ias-38-intangible-assets.pdf)与[IFRS 3 §§10–18、32、B31–B34](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ifrs-3-business-combinations.pdf)。美国一般R&D费用化原则不能直接等同IFRS开发六条件；[FASB ASU 2010-07中ASC 730-10-25-1](https://storage.fasb.org/ASU2010-07.pdf)重现一般规则。软件、替代用途资产、取得研发及合同研究等有专门范围，本表不把所有美国“研发”都写成同一种处理。

有限寿命许可20、残值0、可用时起寿命5年、均匀消耗，则每年摊销4，第一年净额16；尚未可用时不能提前用此摊销。无限寿命无形资产不摊销但定期复核寿命并作相应减值测试，“无限”不是永远不会减值；商誉不能按上述5年许可算法摊销。依据IAS 38 §§97–109以及[IAS 36官方说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-36-impairment-of-assets/)中商誉/无限寿命对象测试。无形资产有独立现金流时可用11课可收回金额路线；没有时需现金产生单元，不能自己给每个品牌编一条可独立现金流。

若上述许可第一年净额16出现迹象，可收回金额12，则损失4。独立无税情景资产和权益各少4，当期利润少4，现金不变；若以后符合转回条件，普通资产转回受未减值账面上限约束，商誉减值不转回。这些基础定位IAS 36 §§18、22、110–125；不覆盖美国减值筛选/计量差异，不能称两体系转换已完成。

## 终止确认是清掉账面，不是把收款全当利润

原创设备片段：出售前资产只有设备净额30、现金0；税基20、原DTL2.5，权益27.5，30＝2.5＋27.5。假设已经累计折旧使账税基不同；这是与澄河基线**分离的片段**，不是往无DTL的澄河账上偷偷补2.5。设备控制交付后收款38、无处置成本、无售后回租、无其他经营；本期结束前缴清税款，税法按售价减税基纳税，税率25%。

1. 移除账面30、收现金38，账面收益8。设备原始成本和累计折旧可分别冲销，净额是同一个30；没移除旧设备会让资产和利润虚高30。
2. 应税收益38－20＝18，当期税18×25%＝4.5，实际缴4.5。
3. 设备账税差消失，原DTL2.5转回形成递延税收益2.5，总税费4.5－2.5＝2，正好8×25%；本期净利润6。
4. 期末只有现金33.5、负债0、权益27.5＋6＝33.5；资产和权益增加3.5，与净利润6差的2.5来自负债清偿/转回，不是缺了现金。

| 处置片段的税前/税后桥 | 金额 |
|---|---:|
| 净处置款－账面＝会计收益 | 38－30＝8 |
| 净处置款－税基＝应税收益 | 38－20＝18 |
| 当前税－DTL转回＝总税费 | 4.5－2.5＝2 |
| 会计收益－总税费＝净利润 | 8－2＝6 |
| 净处置款－现金税＝现金净流入 | 38－4.5＝33.5 |

[IAS 16 §§67–72](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ias-16-property-plant-and-equipment.pdf)要求处置或不再预期利益时终止确认，收益按净处置款减账面，普通设备处置收益不列销售收入；经常出租后出售的特定营业模式另有规定。无形资产按[IAS 38 §§112–117](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ias-38-intangible-assets.pdf)有相应终止确认逻辑。非经常处置8可能真实且诚实，但不能把它当持续销售毛利。

现金分类须写政策。本片段4.5税款能明确归属于投资处置，按IAS 7 §§35–36列CFI：CFI＝38－4.5＝33.5，CFO0。由NI6到CFO，可移除处置收益8并加回整个处置总税费2（相应税付现都移到投资）得0。若某题设不能明确归属而税款CFO，则CFO＝6－8－DTL减少2.5＝－4.5，CFI38，总现金仍33.5。两种展示不得交叉混用：已将税移CFI，不能又在CFO扣4.5。

处置对比率的影响不能只说“ROA上升”：处置一次性利润抬高分子，资产出售降低分母，但平均资产、原经营贡献、税、未来现金均可能变。比较持续经营需在调节桥中剔除收益及关联税，之后预测被卖设备的替代资本开支、产能与维护，而不是把利润6每年重复。

## 65税前利润的三个税率

另起一个独立完整损益税片段，税前利润65已包含**不可扣罚款4和永久免税收入6**；这65是给定合成利润，不是将4/6额外再叠加澄河65。会计折旧40、税折旧60，税法多扣20以后反转；税率25%，无期初当前税余额及DTL，无亏损抵扣/税收抵免/OCI税/税率变更，当期支付12。

应税所得＝65＋4－6－20＝43，当期税10.75。PPE账面比税基高20形成DTL5、递延税费用5；总所得税费用15.75、税后利润49.25。付12比当期应付10.75多1.25，期末是当前税净应收1.25，不能列正应付1.25。

| 总税费调节，从法定率走到有效率 | 税额 | 除65的税率影响 |
|---|---:|---:|
| 按25%给65计算 | 16.25 | 25.000000% |
| 不可扣罚款4 | ＋1 | ＋1.538462个百分点 |
| 永久免税收入6 | －1.5 | －2.307692个百分点 |
| 暂时多扣折旧20 | 当前税－5，递延税＋5，合计0 | 0 |
| 合计 | **15.75** | **24.230769%** |

法定25%是题设税制度率；有效税率＝损益总税费/税前会计利润＝15.75/65＝24.230769%；本课现金税率**定义为已付现金所得税/税前会计利润**＝12/65＝18.461538%。有些分析采用现金税/应税所得或CFO等分母，须另命名并明确，本例不把它们混成一条唯一通用公式。

## 递延税附注怎样变成分析

先按差异类型取期初、新增、反转、税率变动、并购/OCI/外汇变化及期末余额。本例只有PPE税折旧，DTL0→5；如果直接用期末－期初作为损益递延费，在有OCI或并购时会错。多法域税率调节要分清利润地域组合、地方税、税收优惠、永久项目、税率变动和DTA可利用性，不能把所有偏离25%都解释成避税。

DTA不是无条件资产。原创独立边界：亏损抵扣40、税率25%、理论税额10，但根据到期/利润/税收筹划证据只很可能可使用24，则IFRS在此条件下确认6、其余潜在4不确认并作相关披露；若次年可用性恶化到16，DTA降4、在本例全属损益时递延税费2、NI降2，现金当期不自动减少2。美国通常确认递延税资产并对不满足more-likely-than-not实现部分用valuation allowance，表面gross/allowance展示与IFRS直接确认范围不同，其原始原则可定位[FASB历史Statement 109 §17(d)](https://storage.fasb.org/fas109.pdf)，该历史文本不是完整现行ASC 740；本课数例按IFRS“probable”基础，不把概率口语解释成两个体系完全同阈值。真实亏损还要核对到期和使用限制，不能只预测销售增长就判可用。

长期资产附注勾稽也要走期初净额＋增加/并购－折旧/摊销－减值－处置±重估/汇率＝期末。另设资产附注独立例：PPE期初200，增加60，折旧40，减值10，处置净额30，则期末180；处置款38不能代替表中处置净额30。无形期初20，新增12，摊销4，减值3，处置净额5，则期末20。正文指标若沿用澄河PPE220，便和此新附注不匹配。这个工作表是读附注的方法，不应编成澄河真实新事实。

## 题目、答案和边界

**题1：** 设备售价改25、账面30、税基20、税率25%并可立即利用相关税效果。会计损益、当前税、递延与现金分别是多少？**答：** 损失5，当前税1.25，原DTL2.5转回，总税费－1.25即收益，NI－3.75；现金净23.75。资产净减少6.25、负债减少2.5、权益减少3.75，等式成立。账面亏损不等于税务也亏损。

**题2：** 税片段的税折旧与账面相同，其他65/4/6/12条件不变。**答：** 应税所得63，当期税15.75、递延0、总费15.75，当前税应付3.75；有效率仍24.230769%、现金率仍18.461538%。删除暂时差异改变支付义务分配，不改变永久差异造成的总费。

**题3：** 年底税率已颁布从未来25%降20%，未反转的PPE应税暂时差异20适用20%。**答：** DTL应为4，相对已按25%形成的5重估减少1；本例差异全属损益，则递延税收益1、总税费较不变率少1，但本期现金税仍受本期适用率影响。实际须判断颁布/实质颁布、反转方式和税归属；85的固定率函数不支持这个变化。

**题4：** 管理层给“调整利润”加回全部税费15.75并声称未来免税，证据够吗？**答：** 不够。须按永久6、罚款4、折旧反转20和可利用性/法域逐项辨别，已付12也不是未来税额。加回整项会掩盖正常税负。
