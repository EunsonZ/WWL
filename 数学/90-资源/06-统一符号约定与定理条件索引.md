# 统一符号约定与定理条件索引

## 先看对象，再看字母

$\mathbb N$ 是否包含0按局部说明；出现级数时明确起点。底域通常为 $\mathbb R$ 或 $\mathbb C$，抽象代数用 $F$。$I$ 可表示单位矩阵或区间，$i$ 可表示索引或虚数单位，必须从定义区分，不能仅凭字形猜测。

列向量为默认约定。对 $f:\mathbb R^n\to\mathbb R^m$，Jacobian $J_f$ 是 $m\times n$，$J_fv$ 为 $m\times1$，$u^TJ_f$ 为 $1\times n$，等价的列形式是 $J_f^Tu$。标量函数梯度为列向量，$df=\nabla f^Tdx$。写梯度链式法则时应先检查每个乘积的维数。

$A^T$ 是转置，$A^*=\overline A^T$ 是共轭转置，实矩阵中二者相同。$A^{-1}$ 只在可逆时使用；$A^+$ 是 Moore–Penrose 伪逆，不可随意按普通逆消去。$\ker A$、$\operatorname{im}A$ 分别为核与像。

## 复内积与投影

本库默认 $\langle x,y\rangle=y^*x$，对第一变量线性、第二变量共轭线性。部分教材使用相反约定；交换约定会改变展开系数的写法，但不改变正交关系。若正文临时取实内积，两种约定合并；复空间推广时应显式加入共轭，不能直接照抄 $x^Ty$。

在当前约定下，正交归一基 $e_j$ 的展开为 $x=\sum_j\langle x,e_j\rangle e_j$。复 Hilbert 空间的 Riesz 表示也要匹配泛函在哪个变量上线性。有关实变分的专题已明确使用实空间，避免凭空混用约定。

## 范数与误差

向量默认欧氏范数；矩阵 $\|A\|_2$ 是诱导二范数，即最大奇异值；$\|A\|_F=(\sum_{ij}|a_{ij}|^2)^{1/2}$ 是 Frobenius 范数。函数 $L^p$ 范数与一致范数的下标必须明确。相同的“最优逼近”在不同范数中可能有不同解和不同唯一性条件。

$O(h^p)$ 表示在所说明的极限及参数范围内被常数倍 $|h|^p$ 控制；$o(h^p)$ 表示对应比值趋零。多元 $o(\|h\|)$ 要同时控制所有靠近方向。若常数依赖参数，不能未经说明把逐点误差升级为一致误差。

条件数描述问题对数据的敏感性，算法稳定性描述计算过程引入的误差。残差 $b-A\hat x$ 小，不自动意味着 $\hat x-x$ 小。相对误差的分母为零时，应改用绝对误差或明确约定。

## 积分、方向与变换

普通实积分取 Lebesgue 或 Riemann 框架应从局部定义识别；反常积分中的每个端点要分别检查。Cauchy 主值允许特定对称抵消，不等于普通反常积分。多重积分换元使用 $|\det DT|$；有向微分形式的拉回保留行列式符号。

闭曲线在平面中默认正向为内部在行进左侧，简单外边界即逆时针；孔洞的诱导边界为顺时针。曲面的边界方向由法向与右手规则决定。通量公式中的单位法向乘面积元，可合写为叉积向量面积元，不能再多乘一次叉积模长。

Laplace 算子默认 $\Delta=\sum_i\partial_{x_i}^2$；常用正算子是 $-\Delta$。因此 $-\Delta u=f$ 的基本解满足 $-\Delta\Phi=\delta$。热方程通常写 $u_t=\kappa\Delta u$，$\kappa>0$；波方程写 $u_{tt}=c^2\Delta u$。看到不同符号时先对照模型，不直接复制 Green 函数符号。

连续 Fourier 变换默认
$$\widehat f(\xi)=\int_{\mathbb R}f(x)e^{-ix\xi}\,dx,\qquad f(x)=\frac1{2\pi}\int_{\mathbb R}\widehat f(\xi)e^{ix\xi}\,d\xi,$$
在适用的可积或 $L^2$ 意义下理解。采用频率 $\nu$ 的工程式 $e^{-2\pi ix\nu}$ 会把 $2\pi$ 移到不同位置；原信号页有局部约定时以该页为准。离散 DFT 的归一化、单边谱和功率谱密度还需要额外说明，不能把原始模平方直接叫作任何单位下的密度。

## 最常误用的条件清单

| 结论 | 必须检查的条件 | 缺失时的典型问题 |
| --- | --- | --- |
| 闭区间连续函数有最值 | 定义域非空且紧致，函数连续 | 开区间可无最大值；一般闭有界度量子集未必紧 |
| 中值定理 | 闭区间连续、开区间可导 | 间断或不可导点可阻断结论 |
| 偏导推出全微分 | 偏导在邻域存在且在该点连续是一组充分条件 | 仅该点偏导存在不足 |
| 导数与函数列极限交换 | 一点函数值收敛、导数适当一致收敛等 | 原函数一致收敛也未必允许交换导数 |
| 支配收敛 | 可测、几乎处处收敛、同一个可积支配函数 | 高尖峰或质量向无穷远移动 |
| Fubini | 乘积空间条件及绝对可积 | 两个有限累次积分可能不同 |
| 对角化 | 最小多项式在底域分裂且无重因子 | 重特征值未必失败，也未必成功 |
| 谱定理 | 实对称或复正规等具体框架 | 一般矩阵不能用酉相似对角化 |
| Lagrange/KKT 必要性 | 可微及适当约束资格条件 | 资格条件失效时最优点可无乘子 |
| Cauchy 定理与原函数 | 全纯、围道与域的拓扑条件 | 绕孔洞积分可非零 |
| Neumann 唯一性 | 加归一化并检查相容条件 | 常数核导致不唯一或无解 |
| Lax–Milgram | Hilbert、连续双线性型、强制性、连续载荷 | 存在唯一性不能仅由对称推出 |
| 数值格式收敛 | 一致性、稳定性及相应适定框架 | 缩小时间步不自动修复错误边界或空间离散 |
