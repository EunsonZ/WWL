# 四条课程路线与知识连接审计

## 链接够不够

七个知识目录共 **1130篇 Markdown，1128篇从根首页可达**。这个分母包含课程、实验说明、资源及历史维护页；不是1130门课。另有35篇仅MOC入链，89篇仅导航类页面入链，属于优先抽查线索，不能自动判错或强制补链。

限定公开知识范围确认 **19次非教学断链**：数学历史验收的公式解析证据1次、迁移后历史维护路径18次。另有2次故意断链和1个教学孤岛，应按教学原意保留。全库另外3次历史日志断链、1次私有笔记断链不在这19次之内。

更影响连续阅读的是“文件存在，但下一步不明确”：概率→泛化→金融风险、完整SVD→AI PCA、银行→货币政策、自回归→评测等路线缺直接出口；外存→存储→恢复、因果ML→DAG→政策评估则已有较好的连续解释。逐跳位置和全部公开断链见 [[00-工作台/审计/2026-09-17/链接与阅读质量审计|链接与阅读质量审计]]。这类缺口需要一句准确的阅读目的，不能只靠提高双链数量解决。

## 先处理的具体问题

1. **Simpson公式索引源文本损坏。** [[数学/15-微积分/07-积分应用与数值积分几何物理和误差|数值积分页]]第48–50行的奇偶下标破损，需要恢复明确求和范围，并用两组权重、三次多项式精确性及实际渲染验收。
2. **股权估值的现金口径不明确。** [[社会科学/30-金融市场与风险/03-股票所有权现金流与估值|股票估值页]]第33–35行同时使用“加非经营资产、减净债务”。若两项都处理同一现金，可能重复计入。先规定资产集合，再比较“减总债务”与“减净债务”两种等价写法。
3. **概率加深链接没有兑现极限定理主解释。** 大数定律只概述“适当条件”，CLT有准确陈述但未给证明；跳转到测度/DCT/谱背景并不补上这段课程。
4. **关键例子仍缺中间表。** PGM消元、CTC递推、检测匹配/AP、SVM原始问题到核预测，需要同一小例贯穿对象、公式、图与可核算结果；算法原始对偶页还需展开一般成本上界证明。

这些问题已列入规划；本次仅记录，没有默默改写原知识正文。读者仍可使用其他已明确边界的解释。
