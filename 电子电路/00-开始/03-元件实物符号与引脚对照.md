# 元件实物、符号与引脚的三次对照

**读者问题：桌上的一只元件，怎样回到原理图中的正确节点？** 基础入口先数能看见的端子，再认外观标记；快进入口先确定厂商、完整型号、封装和观察方向，逐项核pin number→功能→net。两条路线都要留下“已看见什么、参考来自哪版、什么还不知道”的记录。外观、符号与引脚表是三个对象：照片记录空间，符号记录端口关系，厂商表将编号绑定功能；任何一项都不能自动补齐另一项。

## 七类实物与可编辑符号

下面七幅使用保留原字节的授权实物照片，旁边是原创可编辑SVG符号和有限参考表。不是照片转成的拟真绘图，也不是供电搭建指南。照片文件、作者、日期、权利和修改方式见 [[电子电路/80-实践/44-元件实物符号引脚图鉴/SOURCES|图像出处]]。R/L及电容的完整厂商MPN未知，图中a/b只是在本页认两端的局部名字，不是供应商pin1/2。

### R：Axial resistor / MPN unknown

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/r.svg]]

轴向外形和色环支持识别电阻候选；本组不把来源页“most likely0.25W”推测当额定。理想电阻的端口式v_ab=Ri_ab不随画法改变；翻转符号只需一起调整参考方向。照片不能证明其在温度或脉冲下仍满足R。

### C：Ceramic code224 / MPN unknown

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/c.svg]]

实拍可见224，通常三位容量码22×10⁴pF=220nF=0.22μF；来源页也标220nF。这是标称线索，未测值。两陶瓷引脚无本图规定的正负；耐压、公差、温漂和介质仍未知。换成电解，极性和型号合同要重新核。

### L：EC24 source family / MPN unknown

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/l.svg]]

来源辨识EC24轴向电感；绿色涂层、色环和外形并不能自行区分电感与电阻。i为a→b时理想v_ab=L di/dt；实物直流电阻与饱和电流需具体MPN，不能把“直流导通”判作短路损坏。

### D：1N4148 source identification

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/d.svg]]

Vishay1N4148 Rev1.6（2024-11-07）p3 DO35外形实际标出Cathode identification，色带对应K，另端A。本照片来源标1N4148，厂商未知；只有在该型号/标记合同成立时才能用此带色判读。符号横线是K，符号旋转不让实体带色换端。

### MOS：IRF630 marking / vendor unverified

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/mos.svg]]

照片可见IRF630与未认证标识；VishayIRF630文档91031 RevC（2021-08-02）p1实际绘出TO220AB参考G/D/S。参考前面向读者、脚向下的顺序G-D-S，金属tab同D；不把此表当照片制造商认证，也不从最大额定得出教学供电电压。图中分段沟道为增强型NMOS的简化端口符号，未绘体端与体二极管；它不替代厂商完整内部图，也不决定封装脚距。

### BJT：BC547 marking / vendor unverified

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/bjt.svg]]

照片可见BC547、平面和三脚；原PNG还带Warddr后期C/B/E字母与符号，不是实体上的功能丝印，也不是本课的厂家认证。制造商与完整suffix未知。官方onsemi BC546/D（2021-08 Rev8）p1文本实际读到1=Collector、2=Base、3=Emitter；这只绑定该参考的CASE29 STYLE17。图上的C(1)/B(2)/E(3)标符号端口，照片不强贴未经核准的1/2/3：照片左右位置、数据表脚号和底视方向要另核。原官方下载403已保留，本轮官方native网页能读p1文本，截图请求未获得可独立认证的封装像素；不借网络成功补造观察方向。

### OP：LM358 / pin1 photo unclear

![[电子电路/80-实践/44-元件实物符号引脚图鉴/assets/op.svg]]

## 从端子到节点的完整小例

假设选中并核实的Vishay1N4148 DO35带色端作K，将限流电阻R的b端和A相接、K接局部0。记录R.a=IN、R.b=D.A=N、D.K=0；N是相同导线组成的节点，不是“在图中央”。教学取R=1kΩ、IN=1V及恒压近似V_AK=0.6V，则I=(1−0.6)/1000=0.4mA、P_R=I²R=0.16mW。这里的1k/0.6V是假设模型值，不是从照片测得，也不证明任何照片器件额定；真实二极管应由I-V模型和工作点重新求。把照片带色端接N将改变二极管方向，不能靠把符号镜像“修复”实物。

先去 [[电子电路/50-PCB布局与调试/01-符号引脚封装与BOM替代#符号管连接，封装管焊盘，实体管额定|符号到焊盘合同]] 读pin→pad的映射，带回型号/视角/编号三项再核实体。继续学 [[电子电路/10-电路基础/01-电压电流功率与电路模型|电压电流参考方向]] 时带v_ab和i_ab，回来分清端子名与正负参考；本页不平行重讲KCL或器件输运。进入实践44只复算照片哈希和符号标注，不给实体上电资格。

## 四道读图迁移题

1. 照片电容224能填写220nF±5%、50V吗？**只能据码与来源填写标称220nF线索；公差/耐压未知。** 完整MPN和厂商条件才补规格。
2. 有三个脚就能按MOS的G-D-S接BJT吗？**不能。** NPN端口C/B/E、NMOS端口D/G/S属于不同模型；型号/封装脚号另核。
3. LM358字朝上可指定左下pin1吗？**不能。** 先核pin1标记和top/bottom视图；本照片pin1不清，停在未定位状态。
4. 从PCB背面看原正面左侧端子，功能会换吗？**功能不换，空间左右镜像。** net与pin是稳定身份；照片x坐标不是身份。下一板级图鉴把两视图分开。
