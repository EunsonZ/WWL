# 同轴静电边值与参数复算

本实践消费 [[物理/20-电磁学/02-静电边值与电介质#完整同轴例：圆环势变成电容|E01 同轴边值解]] 的几何、介质和电位，再分别用解析式、分段数值积分和界面残差检查同一对象。它没有运行有限元、全波仿真或硬件测量，数值一致不证明任意材料与几何的定律。

## 输入、源码与一次真实运行

真源为 [solve_coax.py](solve_coax.py)，固定输入为 [inputs.json](inputs.json)。只需已有 Python 3 标准库，不安装依赖。输入有 SI 单位：$a=0.001$ m、$b=0.004$ m、$\ell=0.1$ m、$V=1$ V、$I=0.02$ A；均匀介质 $\epsilon_r=4,\mu_r=1$，两层算例 $c=0.002$ m、$\epsilon_r=(2,8)$，迁移题 $c=0.003$ m、$\epsilon_r=(3,6)$。每层数值积分固定2000个正偶数小区间，在界面分别使用本层 $\epsilon$，避免用另一侧端点场混入积分。

常数合同：$c_0=299792458$ m/s，采用近似 $\mu_0=4\pi10^{-7}$ H/m，再用 $\epsilon_0=1/(\mu_0c_0^2)$ 保持一致；这个近似 $\mu_0$ 不宣称为现行 SI 精确常数。输入的 $\epsilon_r$ 是理想教学材料参数。

在本实践目录运行：

```bash
python3 -B solve_coax.py --input inputs.json --output-dir results
```

2026-10-11 在隔离候选的本目录实际执行的是：

```bash
python3 -B solve_coax.py --input inputs.json --output-dir results > results/stdout.json
```

Python 版本为3.14.7，退出码0。命令输出保留在 [stdout.json](results/stdout.json)，脚本同时写 [values.json](results/values.json)、[uniform-fields.csv](results/uniform-fields.csv) 与两张 SVG。源码与输入留在这里即可复算，不需要另外复制整库快照。若要保留原结果，换用一个新 `--output-dir`；原命令会覆盖指定目录内同名结果文件。

## 先预测，再改一个条件

1. 复制输入到另一个本地文件，只把均匀 `epsilon_r` 从4改8。预测 $C',L',Z_0,v_p$ 如何改变，再指定新输出目录运行。答案：$C'$翻倍，$L'$不变，$Z_0,v_p$均除以 $\sqrt2$，与电压/工作点比值无关。
2. 只改 `layer_interface_m`。预测界面两侧 $E$ 的比值是否改变，再看势、电容和两层电压。答案：若材料比仍为2/8且无自由界面源，$E_1/E_2=4$不变，但 $R_\epsilon$随两个对数厚度改变，故电容与分压改变。
3. 完成 E01 的撤提示题后再读 `transfer` 输出；若答案用了平均 $\epsilon_r$，找出它违反的连续通量和电压积分条件。脚本只接受无自由界面源模型，加表面源必须改求解方程，不能只改名称。

需要区分公式边界、有限精度积分与真实设备。运行这里的代码不验收开放端部、导电/介质损耗、场击穿、动态高阶模、波导、天线、Obsidian显示或真人理解。理论与代码的独立复核另由未参与作者修改者完成；本页只记录作者实际运行。
