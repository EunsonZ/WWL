# 标准库、工程与扩展全景：从脚本走向可维护工具

> **学习位置**：[[计算机知识/00-开始/课程地图/04-Python-课程地图|Python课程地图]] · **适用边界**：Python 3.11+；CPython 实现细节明确注明。

## 以稳定边界组织项目

原有 Python 课程已经详细讲解安装、pip、PyPI、项目布局和虚拟环境。本页把这些操作放回架构：领域计算尽量写成不依赖网络和全局状态的函数；命令行入口负责解析参数；适配层负责文件、数据库和 HTTP；所有边界共享清楚的错误模型。

可安装项目使用 `pyproject.toml` 声明构建与元数据，`src` 布局可减少“直接从源码目录导入掩盖安装缺失”的情况。不要在模块导入时联网、改日志全局配置或执行数据库迁移；导入应该是可预测的。`__all__` 表示公开导出意图，不是访问控制。

## 依赖锁定究竟锁住什么

顶层需求说明你想用什么，解析结果说明实际选中了什么，锁定和哈希约束帮助复现具体制品。`--require-hashes` 不会自动推导传递依赖的版本与哈希。只写 `sampleproject==4.0.0` 的 wheel 哈希但漏掉它的 `peppercorn` 依赖，不构成可完整安装的锁定集合。不同平台、Python 版本、可选依赖和 wheel 类型也会影响结果。

锁文件不等于可信供应链：构建后端、安装脚本、制品来源和被依赖代码仍须信任。升级依赖需要回归测试与变更审阅，而不是永久固定到旧版本。教程里的版本快照应标注核验日期，不能把某次示例数字叫作“永远最新”。

## 标准库按问题分类

数据结构使用 `collections`、`heapq`、`bisect`、`array`；迭代组合使用 `itertools`、`functools`、`operator`。文本和二进制边界涉及 `re`、`codecs`、`struct`、`unicodedata`。数值涉及 `math`、`statistics`、`decimal`、`fractions`，安全随机数使用 `secrets` 而非把 `random` 当密码学生成器。

文件与数据交换涉及 `pathlib`、`os`、`shutil`、`tempfile`、`csv`、`json`、`sqlite3`、压缩与归档模块；解压不可信归档要限制路径、大小和文件类型。时间处理涉及 `datetime`、`zoneinfo` 和单调时钟：带时区时间用于日历语义，单调时间用于测量间隔，夏令时会使某些本地时间重复或不存在。

工程诊断涉及 `logging`、`warnings`、`argparse`、`unittest`、`doctest`、`pdb`、`traceback`、`cProfile`、`tracemalloc`。网络与并发涉及 `socket`、`ssl`、`urllib`、`http`、`asyncio`、`threading`、`multiprocessing`、`concurrent.futures`。反射与插件涉及 `inspect`、`importlib`、`importlib.metadata`、`ast`；元编程功能不应成为绕过可读性和安全审查的理由。

## 扩展接口与科学计算的边界

NumPy 等数组库把大量工作移到本地代码，因此 Python 层循环的经验不能直接推断向量化程序性能。零复制视图可能共享缓冲区；转置、步长、对齐、dtype 和生命周期会改变是否需要复制。与 C 交互可经缓冲区协议、`ctypes`、扩展模块等途径，但调用约定、所有权、错误传播和线程状态必须匹配。扩展崩溃可能直接终止解释器，Python 异常机制不是内存安全屏障。

## 综合项目：可恢复的记录导入器

实现从 CSV 读取、验证、分批写入 SQLite 并输出汇总的工具。支持 `--dry-run`；拒绝记录输出独立文件；成功统计、拒绝统计与实际提交行数一致；中途异常能回滚当前批次；重复导入用唯一键实现定义好的幂等策略。给出安装后的命令行测试、畸形输入测试和峰值内存测量。

这项任务现在有连续正文与完整源码：先到 [[计算机知识/10-编程语言/01-Python/10-系统课程/11-记录流统计与数据语义|第11讲]] 核对身份、单位与分母，再到 [[计算机知识/10-编程语言/01-Python/10-系统课程/12-可恢复导入器与安装交付|第12讲]] 预测批回滚、干跑与安装行为；[[计算机知识/80-实践/01-Python/04-测量记录导入与分析/README|实践项目]] 提供固定输入、独立测试和可重建图。性能和并发扩展需继续验证。

进阶方向至少认识：打包原生扩展、稳定 ABI、子解释器、free-threaded 构建、国际化、无障碍 CLI、插件隔离与软件物料清单。它们有明确入口，不代表学完基础课就自动具备生产维护能力。先完成上述可复现项目，再按实际瓶颈深化。
